    原則解説 — 目次

    Obsidian の「48_原則」ノートをもとにした解説ページの入口です。KISS・DRY・SOLID のような設計・プログラミングの原則そのもの——定義・背景・誤解・使いどころ——を、汎用原則・構造の原則・オブジェクト指向の原則・パッケージとアーキテクチャの原則・法則と経験則・思想と美徳・付録まで、全36ページで解説します。

    もとにしたノート：MOC_原則体系 と、10〜90 の各フォルダのノート

    1.このサイトの読み方

    ページは MOC のフォルダ構成（原則が効く範囲：汎用 → 構造 → オブジェクト指向 → パッケージ・アーキテクチャ、そのあとに法則・経験則、思想・美徳、付録）と同じ順番に並んでいます。各ページの下にある「前のページ／次のページ」で順に読み進められ、上部の「原則解説」からいつでもこの目次に戻れます。どのページも単体で読めるように書いてあるので、気になる原則から読んでもかまいません。

    48 章は原則の一般論の本拠地です。それぞれの単位での使い方は、メソッドなら メソッド設計解説（46）、クラスなら クラス設計・デザインパターン解説（44）、モジュール・パッケージなら モジュール設計解説（43）、アーキテクチャなら アーキテクチャ解説（41）で扱います。原則どうしがぶつかったときは 原則同士の衝突と使い分け、用語をさっと引きたいときは 原則の用語集 を使ってください。

    はじめて学ぶなら

    まず 全体像 で地図を手に入れ、DRY・KISS・YAGNI から読み始めるのがおすすめです。

    歴史から理解したいなら

    設計原則の変遷 で、KISS（1960年頃）から SOLID（2000年）まで、各原則が何の課題を解決したかをたどります。

    SOLID を押さえたいなら

    SOLID の全体像 で5原則を一覧し、SRP → OCP → LSP → ISP → DIP の順に読みます。

    2.00 全体像

    原則という分野の地図と、その歴史。

    00-1

    原則の全体像

    48章が扱うもの（定義・背景・誤解・使いどころ）、効く範囲によるフォルダの分け方、フォルダごとの問い、新しいノートの置き場所、本拠地の表（41〜46・59との分担）

     00-2

    設計原則の変遷

    KISS・高凝集/低結合・SoC・YAGNI・DRY・SOLID の年表、各原則の背景となった課題と解決の考え方、原則が効くレイヤー

    3.10 汎用原則

    どの単位のコードにも効く原則。作りすぎていないか・重複していないか。

    10-1

    DRY・KISS・YAGNI

    3原則の定義と必要な理由、悪い例と良い例、適用例、過度な抽象化と偶然の重複、3原則の関係と組み合わせた実践例

     10-2

    DRY・YAGNI の落とし穴と実践的判断

    DRY の本来の意味（知識の重複）、偶然の重複と本質的な重複、DRY と SRP の衝突、間違った抽象化・Rule of Three・AHA、YAGNI の前提条件、ベテランの勘、判断フロー

     10-3

    コードの重複と DRY 原則違反

    バリデーション・DB クエリ・エラーハンドリング・フォーマット処理・設定値の5つの重複パターンと集約先、DRY 原則チェックリスト

     10-4

    驚き最小の原則

    名前と動きのズレ、副作用、戻り値・慣習・引数順のチェックポイント、驚きの基準は使う人の常識

     10-5

    ボーイスカウトの規則

    来たときよりも美しく、Robert C. Martin、ついでの小さな改善、きれいにする範囲の目安、割れ窓理論

    4.20 構造の原則

    分け方・つなぎ方の原則。どう分けて、どうつなぐか。

    20-1

    関心の分離

    「関心」とは何か、詰め込んだ関数と分けた関数の比較、レイヤー・機能・横断的関心事で分ける軸、SRP との関係、過剰分離への注意、Web アプリでの関心の置き場所

     20-2

    デメテルの法則

    知り合いの知り合いと話さない、呼んでよい4種類の相手、メソッドチェーンを「頼む」形に書き直す例、ドットの数の目安と例外、実務でよくある違反パターン

     20-3

    高凝集・低結合

    凝集度と結合度、Constantine（1974）、何でも屋 Utils、2つをセットで考える、結合ゼロ・分けすぎの誤解

     20-4

    情報隠蔽

    Parnas（1972）、変わりそうな決定を隠す、カプセル化との違い、何を隠すべきか、getter/setter の落とし穴

     20-5

    コマンド・クエリ分離（CQS）

    クエリとコマンド、Meyer と Eiffel、在庫チェックの例、pop・並行処理の例外、CQS と CQRS の違い

     20-6

    機構と方針の分離

    機構と方針、Hydra・マイクロカーネル、リトライ処理の分離、sort・権限・Strategy などの身近な例、分けすぎない

    5.30 オブジェクト指向の原則

    クラス・インターフェースの原則。OOP の道具でどう実現するか。

    30-1

    SOLID の全体像

    SOLID の成り立ち、5原則の一覧、各原則の定義と概要、各ページへの入口、他章（41・42・44）での扱い

     30-2

    単一責任の原則（SRP）

    変更理由は1つだけ、複数の責任を持つクラスの問題、ユーザー管理と注文処理の分離例、過度な分割の誤解、判断基準とチェックリスト

     30-3

    開放閉鎖の原則（OCP）

    拡張に開き修正に閉じる、if-else をポリモーフィズムに置き換える例（図形・割引・通知）、継承・インターフェース・戦略パターン、過度な抽象化

     30-4

    リスコフの置換原則（LSP）

    定義と提唱者、契約（事前条件・事後条件・不変条件）、正方形と長方形・鳥・コレクションの例、違反パターン、判断基準

     30-5

    インターフェース分離の原則（ISP）

    太ったインターフェースの問題、労働者・プリンター・データベースの分離例、ロールインターフェースとアダプター、分けすぎの失敗

     30-6

    依存性逆転の原則（DIP）

    高レベル・低レベル・抽象、直接依存の悪い例と抽象への依存、依存性注入の3パターン、DI コンテナとファクトリー、テストでのモック

     30-7

    継承より合成

    is-a と has-a、GoF の原文、ホワイトボックス／ブラックボックス再利用、継承の4つの問題、部品を持たせる書き方（Strategy）、継承を使ってよい場面

     30-8

    ハリウッド原則・制御の反転

    ハリウッドの決まり文句、IoC・DI の用語整理、ライブラリとフレームワークの違い、Template Method と DI の例、IoC と DIP の違い、反転しすぎの副作用

     30-9

    GRASP の原則としての位置づけ

    9パターンの一覧、目的・評価軸・具体的な手の3層、他の原則との対応、SOLID との役割分担、情報エキスパートの例、純粋人工物と貧血モデル

    6.40 パッケージ・アーキテクチャの原則

    大きな単位ではどうなるか。本体は 43・41 章にあります。

    40-1

    パッケージ・アーキテクチャの原則への案内

    本体が 43・41 章にある理由、REP・CCP・CRP・ADP・SDP・SAP と高凝集・低結合・依存性のルールの対応表、各原則のひとこと説明

    7.50 法則・経験則

    観察から得られた法則。「〜すべき」ではなく、現場で何が起きがちか。

    50-1

    コンウェイの法則

    法則の中身、Conway の論文（1967/1968）と Brooks、技術レイヤーごとのチーム分け、分割発注、分散モノリス、逆コンウェイ戦略、境界と組織の壁

     50-2

    ブルックスの法則・銀の弾丸はない

    人月の神話、連絡経路 n(n−1)/2、人を足すときの付き合い方、No Silver Bullet、本質的な複雑さと偶有的な複雑さ、新技術への過度な期待

     50-3

    ハイラムの法則

    Hyrum Wright と xkcd #1172、並び順やエラー文言への依存、見せるものを減らす、保証しない挙動を揺らす、エラーコード、使う側の心得

     50-4

    ポステルの法則

    堅牢性原則、RFC 760/793、入力の正規化、HTML の寛容すぎた例、RFC 9413 の批判、場面ごとの方針、境界で吸収する

     50-5

    90 対 90 の法則・ホフスタッターの法則

    Tom Cargill と Bentley、Hofstadter（GEB）、最後の10%が長い理由、パーキンソンの法則と学生症候群、完成の定義、小さな分割、実績で見積もる

    8.60 思想・美徳

    考え方・哲学。どういう姿勢で作るか（動画「プリンシプルオブライフ」シリーズのノートから）。

    60-1

    銀の弾丸はない

    銀の弾丸の意味、ブルックスの論文（本質的困難と偶然の困難）、「王道はない。しかし道はある」、人生への読み替え、No Silver Bullet Refired

     60-2

    情報隠蔽は正義

    情報隠蔽の2つのメリット（経費精算の例）、パルナスの規則、ブラックボックスとの違い、API と REST、ステートレスと冪等性、提供情報の最小化

     60-3

    プログラマの三大美徳

    リファクタリング、コードの臭い、その場しのぎと any、命名は最重要課題、怠惰・短気・傲慢、傲慢をクリエイターの矜持として読む

     60-4

    UNIX 哲学

    McIlroy の4原則、Salus の3行要約、Gancarz の9定理、Raymond の17ルール、パイプの例、関数の合成、他原則との関係、現代での活かし方

     60-5

    Worse is Better

    Gabriel の論考、The Right Thing と New Jersey 流の比較、PC loser-ing と EINTR、「悪いほう」が広まる理由、MVP、YAGNI・KISS との関係

     60-6

    Zen of Python

    PEP 20 と Tim Peters、19行の原文・訳・解説、明示的 import、ガード節、例外を黙らせない、他原則との対応、レビューでの使い方

    9.90 付録

    原則を横断して引くための一覧と、原則どうしがぶつかったときの判断。

    90-1

    原則の用語集

    10〜60 の原則・法則・思想の略称、一言の意味、提唱者、解説ページへのリンク

     90-2

    原則同士の衝突と使い分け

    衝突10組と判断基準、DRY vs SRP、YAGNI vs OCP、デメテル vs 凝集、DRY vs 疎結合、迷ったときの順番
