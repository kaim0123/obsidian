# MOC_AIアプリ開発体系

35_AIアプリ開発 の入口ノート。**自分のアプリに LLM（大規模言語モデル）を API 経由で組み込み、機能として本番で動かす**ための知識を扱う。2026 年時点の AI エンジニア向けロードマップで共通して挙がる柱（LLM API・RAG・エージェント・評価・運用）をそのまま分野にしている。

> モデルをゼロから学習させる知識は、いまの実務ではほとんど求められない。ファインチューニング（LoRA など）も一部の専門領域の扱い。ここでは **「できあがったモデルを、API で上手に使う」** ことに絞る。
