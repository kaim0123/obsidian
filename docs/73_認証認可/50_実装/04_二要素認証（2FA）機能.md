# 二要素認証（2FA）機能の実装方法とベストプラクティス

## 概要

二要素認証（2FA）は、パスワードに加えて別の認証要素を使用することで、アカウントのセキュリティを大幅に向上させる機能です。複数の認証方式を組み合わせることで、強固なセキュリティを実現できます。

## 認証要素の種類

### 知識要素（Something You Know）
- パスワード
- PIN
- セキュリティ質問

### 所持要素（Something You Have）
- スマートフォン（認証アプリ）
- ハードウェアトークン
- SMS/音声通話

### 生体要素（Something You Are）
- 指紋認証
- 顔認証
- 音声認証

## 実装方式の比較

| 方式 | セキュリティ | ユーザビリティ | 実装コスト | デバイス依存 |
|------|-------------|---------------|-----------|-------------|
| **TOTP（認証アプリ）** | ⭐⭐⭐ 高い | ⭐⭐⭐ 良い | ⭐⭐ 中程度 | ⭐⭐ 中程度 |
| **SMS認証** | ⭐⭐ 中程度 | ⭐⭐⭐ 良い | ⭐ 低い | ⭐ 低い |
| **ハードウェアトークン** | ⭐⭐⭐ 最高 | ⭐⭐ 中程度 | ⭐⭐⭐ 高い | ⭐⭐⭐ 高い |
| **音声認証** | ⭐⭐ 中程度 | ⭐⭐ 中程度 | ⭐⭐ 中程度 | ⭐ 低い |

## 1. TOTP（Time-based One-Time Password）認証

### 概要
Google Authenticator、Authy等の認証アプリを使用した時間ベースのワンタイムパスワード

### バックエンド実装

```javascript
// バックエンド（Node.js + Express + speakeasy）
const speakeasy = require('speakeasy');
const QRCode = require('qrcode');

// TOTP設定開始
app.post('/api/auth/setup-mfa', requireAuth, async (req, res) => {
  try {
    const user = req.user;
    
    // 既にMFAが設定されている場合はエラー
    if (user.mfaEnabled) {
      return res.status(400).json({ error: 'MFA is already enabled' });
    }
    
    // シークレットキー生成
    const secret = speakeasy.generateSecret({
      name: `MyApp (${user.email})`,
      issuer: 'MyApp',
      length: 32
    });
    
    // QRコード生成
    const qrCodeUrl = await QRCode.toDataURL(secret.otpauth_url);
    
    // 一時的にシークレットを保存（検証後に永続化）
    user.tempMfaSecret = secret.base32;
    user.tempMfaBackupCodes = generateBackupCodes();
    await user.save();
    
    res.json({
      secret: secret.base32,
      qrCode: qrCodeUrl,
      manualEntryKey: secret.base32,
      backupCodes: user.tempMfaBackupCodes
    });
    
  } catch (error) {
    console.error('MFA setup error:', error);
    res.status(500).json({ error: 'MFA setup failed' });
  }
});

// バックアップコード生成
const generateBackupCodes = () => {
  const codes = [];
  for (let i = 0; i < 10; i++) {
    codes.push(crypto.randomBytes(4).toString('hex').toUpperCase());
  }
  return codes;
};

// MFA検証（初回設定時）
app.post('/api/auth/verify-mfa-setup', requireAuth, async (req, res) => {
  try {
    const { token } = req.body;
    const user = req.user;
    
    if (!user.tempMfaSecret) {
      return res.status(400).json({ error: 'MFA setup not initiated' });
    }
    
    // トークン検証
    const verified = speakeasy.totp.verify({
      secret: user.tempMfaSecret,
      encoding: 'base32',
      token: token,
      window: 2 // 2分の許容範囲
    });
    
    if (verified) {
      // MFAを有効化
      user.mfaSecret = user.tempMfaSecret;
      user.mfaBackupCodes = user.tempMfaBackupCodes;
      user.mfaEnabled = true;
      user.tempMfaSecret = undefined;
      user.tempMfaBackupCodes = undefined;
      await user.save();
      
      res.json({ 
        success: true, 
        message: 'MFA enabled successfully',
        backupCodes: user.mfaBackupCodes
      });
    } else {
      res.status(400).json({ error: 'Invalid MFA token' });
    }
    
  } catch (error) {
    console.error('MFA verification error:', error);
    res.status(500).json({ error: 'MFA verification failed' });
  }
});

// MFA認証（ログイン時）
app.post('/api/auth/verify-mfa', requireAuth, async (req, res) => {
  try {
    const { token, backupCode } = req.body;
    const user = req.user;
    
    if (!user.mfaEnabled) {
      return res.status(400).json({ error: 'MFA not enabled' });
    }
    
    let verified = false;
    
    // バックアップコードの確認
    if (backupCode) {
      const codeIndex = user.mfaBackupCodes.indexOf(backupCode.toUpperCase());
      if (codeIndex !== -1) {
        // バックアップコードを使用
        user.mfaBackupCodes.splice(codeIndex, 1);
        await user.save();
        verified = true;
        
        // セキュリティログ記録
        await SecurityLog.create({
          userId: user.id,
          action: 'mfa_backup_code_used',
          ipAddress: req.ip,
          userAgent: req.get('User-Agent')
        });
      }
    } else if (token) {
      // TOTPトークンの確認
      verified = speakeasy.totp.verify({
        secret: user.mfaSecret,
        encoding: 'base32',
        token: token,
        window: 2
      });
    }
    
    if (verified) {
      // セッションにMFA検証済みフラグを設定
      req.session.mfaVerified = true;
      req.session.mfaVerifiedAt = new Date();
      
      res.json({ 
        success: true, 
        verified: true,
        message: 'MFA verification successful'
      });
    } else {
      res.status(400).json({ error: 'Invalid MFA token or backup code' });
    }
    
  } catch (error) {
    console.error('MFA verification error:', error);
    res.status(500).json({ error: 'MFA verification failed' });
  }
});

// MFA無効化
app.post('/api/auth/disable-mfa', requireAuth, async (req, res) => {
  try {
    const { password } = req.body;
    const user = req.user;
    
    // パスワード確認
    const isValidPassword = await bcrypt.compare(password, user.password);
    if (!isValidPassword) {
      return res.status(401).json({ error: 'Invalid password' });
    }
    
    // MFAを無効化
    user.mfaEnabled = false;
    user.mfaSecret = undefined;
    user.mfaBackupCodes = undefined;
    await user.save();
    
    // セキュリティログ記録
    await SecurityLog.create({
      userId: user.id,
      action: 'mfa_disabled',
      ipAddress: req.ip,
      userAgent: req.get('User-Agent')
    });
    
    res.json({ 
      success: true, 
      message: 'MFA disabled successfully' 
    });
    
  } catch (error) {
    console.error('MFA disable error:', error);
    res.status(500).json({ error: 'MFA disable failed' });
  }
});

// MFA必須チェックミドルウェア
const requireMFA = async (req, res, next) => {
  const user = req.user;
  
  if (user.mfaEnabled) {
    const mfaVerified = req.session.mfaVerified;
    const mfaVerifiedAt = req.session.mfaVerifiedAt;
    
    // MFA検証が30分以内かチェック
    if (!mfaVerified || !mfaVerifiedAt || 
        (Date.now() - mfaVerifiedAt.getTime()) > 30 * 60 * 1000) {
      return res.status(403).json({ 
        error: 'MFA verification required',
        requiresMFA: true 
      });
    }
  }
  
  next();
};
```

## 2. SMS認証

### バックエンド実装

```javascript
// バックエンド（Node.js + Express + Twilio）
const twilio = require('twilio');
const client = twilio(process.env.TWILIO_SID, process.env.TWILIO_TOKEN);

// SMS認証コード送信
app.post('/api/auth/send-sms-code', requireAuth, async (req, res) => {
  try {
    const user = req.user;
    
    if (!user.phone) {
      return res.status(400).json({ error: 'Phone number not registered' });
    }
    
    // レート制限チェック
    const rateLimitKey = `sms_code:${user.id}`;
    const attempts = await redis.get(rateLimitKey);
    
    if (attempts && parseInt(attempts) >= 3) {
      return res.status(429).json({ 
        error: 'Too many SMS code requests. Please try again later.' 
      });
    }
    
    // 6桁の認証コード生成
    const code = Math.floor(100000 + Math.random() * 900000).toString();
    
    // SMS送信
    await client.messages.create({
      body: `Your MyApp verification code is: ${code}. This code will expire in 5 minutes.`,
      from: process.env.TWILIO_PHONE,
      to: user.phone
    });
    
    // コードを一時保存（5分間有効）
    user.smsCode = code;
    user.smsCodeExpiry = new Date(Date.now() + 5 * 60 * 1000);
    await user.save();
    
    // レート制限カウンターを増加
    await redis.incr(rateLimitKey);
    await redis.expire(rateLimitKey, 300); // 5分間
    
    res.json({ success: true });
    
  } catch (error) {
    console.error('SMS sending error:', error);
    res.status(500).json({ error: 'SMS sending failed' });
  }
});

// SMS認証コード検証
app.post('/api/auth/verify-sms-code', requireAuth, async (req, res) => {
  try {
    const { code } = req.body;
    const user = req.user;
    
    if (!user.smsCode || new Date() > user.smsCodeExpiry) {
      return res.status(400).json({ error: 'SMS code expired' });
    }
    
    if (user.smsCode !== code) {
      return res.status(400).json({ error: 'Invalid SMS code' });
    }
    
    // セッションにMFA検証済みフラグを設定
    req.session.mfaVerified = true;
    req.session.mfaVerifiedAt = new Date();
    
    // 使用済みコードをクリア
    user.smsCode = undefined;
    user.smsCodeExpiry = undefined;
    await user.save();
    
    res.json({ success: true, verified: true });
    
  } catch (error) {
    console.error('SMS verification error:', error);
    res.status(500).json({ error: 'SMS verification failed' });
  }
});
```

## 4. ハードウェアトークン（FIDO2/WebAuthn）

### バックエンド実装

```javascript
// バックエンド（Node.js + Express + @simplewebauthn/server）
const { generateRegistrationOptions, verifyRegistrationResponse } = require('@simplewebauthn/server');

// WebAuthn登録オプション生成
app.post('/api/auth/webauthn/register/begin', requireAuth, async (req, res) => {
  try {
    const user = req.user;
    
    const options = await generateRegistrationOptions({
      rpName: 'MyApp',
      rpID: process.env.RP_ID,
      userID: user.id,
      userName: user.email,
      userDisplayName: user.name,
      attestationType: 'direct',
      authenticatorSelection: {
        authenticatorAttachment: 'platform',
        userVerification: 'required',
        residentKey: 'required'
      }
    });
    
    // チャレンジを一時保存
    user.webauthnChallenge = options.challenge;
    await user.save();
    
    res.json(options);
    
  } catch (error) {
    console.error('WebAuthn registration begin error:', error);
    res.status(500).json({ error: 'WebAuthn registration failed' });
  }
});

// WebAuthn登録完了
app.post('/api/auth/webauthn/register/complete', requireAuth, async (req, res) => {
  try {
    const { credential } = req.body;
    const user = req.user;
    
    const verification = await verifyRegistrationResponse({
      credential,
      expectedChallenge: user.webauthnChallenge,
      expectedOrigin: process.env.FRONTEND_URL,
      expectedRPID: process.env.RP_ID
    });
    
    if (verification.verified) {
      // 認証器情報を保存
      await WebAuthnCredential.create({
        userId: user.id,
        credentialID: verification.registrationInfo.credentialID,
        credentialPublicKey: verification.registrationInfo.credentialPublicKey,
        counter: verification.registrationInfo.counter,
        transports: credential.transports
      });
      
      user.webauthnChallenge = undefined;
      await user.save();
      
      res.json({ success: true });
    } else {
      res.status(400).json({ error: 'WebAuthn registration verification failed' });
    }
    
  } catch (error) {
    console.error('WebAuthn registration complete error:', error);
    res.status(500).json({ error: 'WebAuthn registration failed' });
  }
});
```

### 2. セキュリティログと監視

```javascript
// MFA活動の監視
const monitorMFAActivity = async () => {
  const suspiciousActivity = await SecurityLog.aggregate([
    {
      $match: {
        action: { $in: ['mfa_failed', 'mfa_backup_code_used'] },
        timestamp: { $gt: new Date(Date.now() - 24 * 60 * 60 * 1000) }
      }
    },
    {
      $group: {
        _id: '$userId',
        failedAttempts: { $sum: { $cond: [{ $eq: ['$action', 'mfa_failed'] }, 1, 0] } },
        backupCodeUsage: { $sum: { $cond: [{ $eq: ['$action', 'mfa_backup_code_used'] }, 1, 0] } }
      }
    },
    {
      $match: {
        $or: [
          { failedAttempts: { $gte: 10 } },
          { backupCodeUsage: { $gte: 3 } }
        ]
      }
    }
  ]);
  
  if (suspiciousActivity.length > 0) {
    await notifySecurityTeam({
      type: 'suspicious_mfa_activity',
      data: suspiciousActivity
    });
  }
};
```

```javascript
    // 新しいバックアップコード生成
    const newBackupCodes = generateBackupCodes();
    user.mfaBackupCodes = newBackupCodes;
    await user.save();
    
    res.json({ 
      success: true, 
      backupCodes: newBackupCodes 
    });
    
  } catch (error) {
    res.status(500).json({ error: 'Backup code regeneration failed' });
  }
});
```

## 実装の選択指針

| アプリケーションタイプ | 推奨MFA方式 | 理由 |
|---------------------|-------------|------|
| **一般Webアプリ** | TOTP + SMS | バランスの取れたセキュリティとUX |
| **企業システム** | TOTP + ハードウェアトークン | 高セキュリティ要件 |
| **モバイルアプリ** | TOTP + 生体認証 | デバイス連携の利便性 |
| **金融アプリ** | 複数方式の組み合わせ | 最高レベルのセキュリティ |

## 2026年の事例から：MFA を突破する攻撃（追記 2026-10-17）

MFA は今も効果の大きい対策ですが、2026年には **MFA を前提にした攻撃** も報告されています（全体は [[10_2026年_国内情報漏洩の動向と対策]]）。

| 手口 | 内容 |
|---|---|
| ヘルプデスク・従業員への電話誘導 | 攻撃者がサポートを装って電話し、SSO のパスワードと MFA コードを聞き出す。さらに **攻撃者の MFA デバイスを登録させる**（ShinyHunters 系の活動） |
| 漏えいした認証情報での VPN ログイン | 国内ランサムウェアの主な入口は VPN と漏えいした認証情報（警察庁、2026年上半期）。**VPN に MFA がない** と、ID とパスワードだけで入られる |

### 実装・運用での対策

- **フィッシングに強い方式を優先する**：FIDO2 / WebAuthn（パスキー）は、偽サイトや電話でコードを聞き出す攻撃に強い。TOTP や SMS のコードは人が読み上げられてしまう
- **MFA デバイスの登録・リセットを高リスク操作として扱う**
  - 既存の要素での再認証を求める。ヘルプデスク経由のリセットでは本人確認を強くする
  - 登録したことを **登録済みの全連絡先に通知** する
  - 登録の直後は、データのエクスポートや権限変更などの高リスク操作を一定時間制限する
- **検知**：パスワードリセットの直後に MFA デバイスが登録された、などの組み合わせをアラートにする（[[A09_ログとモニタリングの不備]]）
- **VPN・管理画面・SaaS の管理者には MFA を必須にする**（[[03_ゼロトラスト]]）
