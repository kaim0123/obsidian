### コンテキスト間の関係（抜粋）

| 関係 | 意味 |
|------|------|
| 共有カーネル | モデルの一部を共有 |
| 顧客/供給者 | 下流が上流に依存 |
| 腐敗防止層（ACL） | 外部モデルを変換して取り込む |
| 別々の道 | 連携しない |
