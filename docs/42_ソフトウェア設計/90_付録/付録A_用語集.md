# 付録A　用語集

本教材で登場する主要用語の一覧です。

---

## あ行

| 用語 | 説明 |
|------|------|
| **アンチパターン** | よくある悪い設計のパターン。避けるべき例 |
| **アプリケーションサービス** | ユースケースをオーケストレーションする層 |
| **ADR** | Architecture Decision Record。設計判断の記録 |

## か行

| 用語 | 説明 |
|------|------|
| **カプセル化** | 内部を隠し、公開操作だけを提供すること |
| **凝集度** | 1 部品の中身が 1 つの目的にまとまっている度合い |
| **結合度** | 部品同士の依存の強さ |
| **コンテキストマップ** | 境界づけられたコンテキスト間の関係図 |

## さ行

| 用語 | 説明 |
|------|------|
| **責務** | 部品が担当すべき仕事 |
| **境界づけられたコンテキスト** | モデルと用語が有効な範囲 |
| **境界** | 部品の内側と外側を分ける線 |

## た行

| 用語 | 説明 |
|------|------|
| **ドメイン** | ソフトウェアが扱う事業領域・業務の世界 |
| **ドメインイベント** | ドメイン内で起きた意味のある出来事 |
| **ドメインサービス** | 特定エンティティに属さないドメイン処理 |

## な行

| 用語 | 説明 |
|------|------|
| **値オブジェクト** | 値で比較する不変のオブジェクト（Money 等） |

## は行

| 用語 | 説明 |
|------|------|
| **パラダイム** | プログラムの組み立て方の考え方（手続き・OOP・関数型） |
| **貧血ドメインモデル** | エンティティがデータ入れ物でロジックがサービスに集中した状態 |
| **副作用** | 関数が戻り値以外に外部へ与える影響 |

## ま行

| 用語 | 説明 |
|------|------|
| **メッセージ** | オブジェクト同士のやりとりの単位 |

## や行

| 用語 | 説明 |
|------|------|
| **ユビキタス言語** | チーム全員が共有するドメインの用語 |
| **YAGNI** | You Aren't Gonna Need It。今必要ないものは作らない |

## ら行

| 用語 | 説明 |
|------|------|
| **リポジトリ** | 集約の永続化を抽象化するパターン |
| **Leaky Abstraction** | 隠すはずの詳細が外に漏れる抽象化 |

## わ行・英語

| 用語 | 説明 |
|------|------|
| **OCP** | 開放閉鎖の原則。拡張に開き変更に閉じる |
| **SRP** | 単一責任の原則。変化の理由を 1 つに |
| **SoC** | 関心の分離 |
| **DDD** | ドメイン駆動設計 |
| **EDA** | イベント駆動アーキテクチャ |
| **冪等性** | 同じ操作を複数回しても結果が同じであること |
| **結果整合性** | 即時ではなく時間とともに整合が収束すること |
