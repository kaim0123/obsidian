# MOC_ソフトウェア設計体系

42_ソフトウェア設計 の入口ノート。**コードを「どんな考え方で分け、組み立てるか」——設計の原則・パラダイム・ドメインモデリング・設計の進め方**を扱う。骨格は SWEBOK の Software Design（原則 → 考え方 → プロセス → 品質）と roadmap.sh Software Design & Architecture（パラダイム → OOP → 原則）。DDD は「戦略的設計 → 戦術的設計」の順で学ぶ構成にした。

フォルダは **テーマ別**、教材（旧 第01〜08部・全26章）を読む **学習順** は下の「学習順インデックス」で持つ。各テーマフォルダには「教材の章（入門）」と「単体ノート（深掘り）」が並ぶ。
