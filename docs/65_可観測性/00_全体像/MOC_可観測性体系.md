# MOC_可観測性体系

65_可観測性 の入口ノート。**本番で動くシステムの内部状態を、外に出したデータ（ログ・メトリクス・トレース）から理解する**ための仕組みを扱う。『Observability Engineering』と OpenTelemetry のシグナル分類、Google SRE 本 6章「Monitoring Distributed Systems」を軸にしている。62〜69 全体の地図は [[MOC_運用領域マップ]]。

## 読む順番
10 → 60 → 90 の順に「前へ / 次に読む」でつながっている。最初は [[01_監視と可観測性の違い]]。手を動かすなら [[04_Node.jsアプリの計装例]] から。SLO の**方針**（予算を使い切ったらどうするか）は 67 の [[03_エラーバジェット方針]]、ここ 60 は**計測とアラートの仕組み**。
