# ChatGPTの設定と使い方

ChatGPTは、OpenAIが開発した対話型AIです。この章では、ChatGPTの効果的な設定方法と使い方について解説します。

## 📖 ChatGPTとは

ChatGPTは、自然言語で対話できるAIアシスタントです。コード生成、コードレビュー、ドキュメント作成など、様々な開発タスクに活用できます。

**主な特徴**:
- 自然言語での対話
- コード生成とレビュー
- ドキュメント作成
- 複数の会話履歴の管理

## 1. カスタムインストラクションの設定

### 設定方法

1. ChatGPTの設定画面を開く
2. 「Custom instructions」を選択
3. 以下のような指示を設定

### 推奨設定例

```
あなたは経験豊富なソフトウェア開発者です。以下の原則に従ってコードを生成してください:

## アーキテクチャ
- MVCパターンに従う
- 各層の責務を明確に分離する
- モデル層にHTMLを含めない
- ビュー層にビジネスロジックを含めない
- コントローラー層に過度なロジックを含めない

## セキュリティ
- SQLインジェクション対策: プリペアドステートメントを使用
- XSS対策: エスケープ処理を実装
- CSRF対策: CSRFトークンの検証
- 機密情報: 環境変数を使用
- 認証・認可: 適切に実装

## コード品質
- DRY原則に従う（コードの重複を避ける）
- 適切なエラーハンドリングを含める
- テストコードを提案する
- コメントを適切に追加する
- 命名規則を統一する

## エラーハンドリング
- try-catchブロックで非同期処理を囲む
- 適切なHTTPステータスコードを返す
- エラーログを記録
- ユーザーに分かりやすいエラーメッセージを返す

## 出力形式
- コードと説明を含める
- セキュリティ上の注意点を明記する
- 改善案を提案する
- 各ファイルを分けて提示する
```

### カスタムインストラクションの効果

カスタムインストラクションを設定することで、以下の効果が得られます：

1. **一貫性の向上**: すべての会話で一貫したコードスタイル
2. **ミスの防止**: よくあるミス（MVC違反、セキュリティ対策の不足など）を防ぐ
3. **効率の向上**: 毎回同じ指示を繰り返す必要がなくなる

## 2. システムプロンプトの使い方

各会話の最初に、システムプロンプトを設定することで、AIの動作を制御できます。

### システムプロンプトの例

```
あなたはNode.js + Express.jsの専門家です。
以下の要件に従ってコードを生成してください:

1. MVCパターンに従う
2. セキュリティベストプラクティスを適用
3. エラーハンドリングを含める
4. テストコードを提案する

プロジェクトの技術スタック:
- Node.js 18+
- Express.js 4.x
- MySQL 8.0
- JWT認証
- bcrypt（パスワードハッシュ化）

アーキテクチャ:
- MVCパターン
- モデル層: データとビジネスロジック
- ビュー層: 表示のみ
- コントローラー層: 入力処理と調整
```

## 3. 効果的なプロンプトの書き方

### コード生成のプロンプト

```
❌ 悪い例:
「認証機能を作って」
```

```
✅ 良い例:
あなたはNode.js + Express.jsの専門家です。

以下の要件を満たすユーザー認証機能を実装してください:

要件:
- JWTトークンを使用した認証
- パスワードはbcryptでハッシュ化（ラウンド数: 10）
- ログイン、登録、トークン検証のエンドポイント
- セキュリティベストプラクティスに従う
- エラーハンドリングを含める

アーキテクチャ:
- MVCパターンに従う
- models/User.js: ユーザーモデル
- controllers/auth_controller.js: 認証コントローラー
- routes/auth.js: 認証ルート
- middleware/auth.js: 認証ミドルウェア

セキュリティ要件:
- SQLインジェクション対策: プリペアドステートメント
- XSS対策: エスケープ処理
- 機密情報: 環境変数

出力形式:
- 各ファイルを分けて提示
- コードにコメントを追加
- セキュリティ上の注意点を明記
```

### コードレビューのプロンプト

```
❌ 悪い例:
「このコードをレビューして」
```

```
✅ 良い例:

レビュー観点:
1. セキュリティ脆弱性（SQLインジェクション、XSS、CSRFなど）
2. MVCパターンへの準拠
3. エラーハンドリングの適切性
4. コードの重複（DRY原則）
5. 命名規則の一貫性
6. パフォーマンスの問題

コード:

出力形式:
- 問題点を箇条書きで提示
- 各問題に対して改善案を提示
- 修正後のコード例を提示
```

### リファクタリングのプロンプト

```

要件:

3. 適切な命名規則に従う
4. エラーハンドリングを追加
5. コメントを追加

コード:

出力形式:
- リファクタリング前後の比較
- 変更点の説明
- 改善された点の説明
```

## 4. よくあるミスを防ぐプロンプト

### MVC違反を防ぐ

```
以下のコードを生成してください。
MVCパターンに厳密に従い、以下の点を確認してください:
- モデル層にHTMLを含めない
- ビュー層にビジネスロジックを含めない
- コントローラー層に過度なロジックを含めない
- 各層の責務を明確に分離する
```

### セキュリティ対策を含める

```
以下の機能を実装してください。
セキュリティベストプラクティスに従い、以下を含めてください:
- SQLインジェクション対策（プリペアドステートメント）
- XSS対策（エスケープ処理）
- CSRF対策（CSRFトークンの検証）
- 機密情報の保護（環境変数）
- 認証・認可の実装
```

### エラーハンドリングを含める

```
以下のコードにエラーハンドリングを追加してください:
- try-catchブロックで非同期処理を囲む
- 適切なHTTPステータスコードを返す
- エラーログを記録
- ユーザーに分かりやすいエラーメッセージを返す
```

## 5. 会話履歴の管理

### 会話の整理

- 関連するトピックごとに会話を分ける
- 長い会話は定期的に整理する
- 重要な情報は会話の最初にまとめる

### コンテキストの維持

会話が長くなると、コンテキストが失われる可能性があります。重要な情報は定期的に再提示します。

## 6. セキュリティ設定

### 機密情報の保護

1. **環境変数の使用**: 機密情報は環境変数に保存
2. **コードレビュー**: 生成されたコードに機密情報が含まれていないか確認
3. **会話履歴の管理**: 機密情報を含む会話は削除

### プライバシー設定

- 機密情報を含むコードを扱う際は注意
- 会話履歴を定期的に整理
- 必要に応じて会話を削除

## ✅ ChatGPT設定チェックリスト

ChatGPTを使用する前に、以下の点を確認しましょう：

- [ ] カスタムインストラクションを設定したか
- [ ] システムプロンプトを適切に設定しているか
- [ ] 効果的なプロンプトの書き方を理解しているか
- [ ] よくあるミスを防ぐプロンプトを含めているか
- [ ] セキュリティ設定が適切か
- [ ] 会話履歴を適切に管理しているか

## 🎯 まとめ

ChatGPTを効果的に使用するためには、以下の点が重要です：

1. **カスタムインストラクション**: 常に適用される指示を設定
2. **システムプロンプト**: 各会話の最初に設定
3. **効果的なプロンプト**: 具体的で明確なプロンプトを書く
4. **よくあるミスを防ぐ**: プロンプトにミスを防ぐ指示を含める
5. **セキュリティ**: 機密情報の保護に注意

適切に設定し、効果的に使用することで、開発効率を大幅に向上させることができます。
