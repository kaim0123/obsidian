# コーディング規約 — 教材目次（ゼロからの全体像）

本フォルダの内容を、**初めて学ぶ人向けの章立て**に並べ直した学習用の目次です。各章は既存ノートに対応づけています。Part 0 だけ、短い導入ノートを新規に置く余地を残しています。

---

## 学習のすすめ方

1. まず **「なぜ規約が必要か」** と **「読みやすさ」** で動機と目的を掴む。
2. 次に **命名**（ケース、原則、略語、用語、不統一）を順に扱うと、以降のコメント・Lintと矛盾なく理解しやすい。
3. **コメント** → **整形とLint** の順は、人間向けの記述のあと、ツールで機械的に揃える流れに合う。

## Part 5　（任意）拡張トピック

本フォルダに**専用ノートはない**が、ゼロからの「コーディング規約」教材を一周したあとに足すとよい題材。

- 言語・公式スタイルガイドへのリンク集（例：PEP 8、Airbnb 等）— 05 内言語別の扱いを索引化してもよい
- プロジェクト内規約（ADR、例外ルール、レガシー扱い）
- アクセシビリティ・セキュリティの「最低限の記述」規約
- コントリビューションガイド（PR・コミットメッセージ）
