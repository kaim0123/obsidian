# コードの読みやすさ

## はじめに

プログラミングでは、コードを書く時間よりも、コードを読む時間の方が長いと言われています。読みやすいコードを書くことは、とても重要なスキルです。

この章では、コードを読みやすくする方法を学びます。

## 読みやすいコードとは

読みやすいコードとは、以下のような特徴があります：

- **理解しやすい**：何をしているかがすぐに分かる
- **修正しやすい**：変更したい部分がすぐに見つかる
- **拡張しやすい**：新しい機能を追加しやすい

## 読みやすくするための原則

### 1. 明確な変数名を使う

**悪い例**：
```python
x = 10
y = 20
z = x + y
```

**良い例**：
```python
price = 10
tax = 20
total = price + tax
```

変数名から、何を表しているかがすぐに分かります。

### 2. 関数は1つのことをする

**悪い例**：
```python
def process_data(data):
    # データを検証
    if not data:
        return None
    
    # データを変換
    result = []
    for item in data:
        result.append(item.upper())
    
    # データを保存
    with open("output.txt", "w") as f:
        f.write(str(result))
    
    # データを表示
    print(result)
    
    return result
```

**良い例**：
```python
def validate_data(data):
    """データを検証する"""
    return data is not None and len(data) > 0

def transform_data(data):
    """データを変換する"""
    return [item.upper() for item in data]

def save_data(data, filename):
    """データを保存する"""
    with open(filename, "w") as f:
        f.write(str(data))

def process_data(data):
    """データを処理する（メイン関数）"""
    if not validate_data(data):
        return None
    
    transformed = transform_data(data)
    save_data(transformed, "output.txt")
    print(transformed)
    
    return transformed
```

1つの関数が1つのことをするようにすると、理解しやすくなります。

### 3. マジックナンバーを避ける

**悪い例**：
```python
if age >= 18:
    print("成人です")
```

**良い例**：
```python
ADULT_AGE = 18

if age >= ADULT_AGE:
    print("成人です")
```

数値に意味を持たせると、コードが理解しやすくなります。

### 4. 長い関数を分割する

**悪い例**：
```python
def process_order(order):
    # 50行以上のコード...
    pass
```

**良い例**：
```python
def validate_order(order):
    """注文を検証する"""
    pass

def calculate_total(order):
    """合計金額を計算する"""
    pass

def process_payment(order):
    """支払いを処理する"""
    pass

def process_order(order):
    """注文を処理する"""
    if not validate_order(order):
        return False
    
    total = calculate_total(order)
    return process_payment(order, total)
```

長い関数を小さな関数に分割すると、理解しやすくなります。

### 5. コメントは「なぜ」を説明する

**悪い例**：
```python
# 変数xに10を代入
x = 10

# 変数yに20を代入
y = 20

# xとyを足す
z = x + y
```

**良い例**：
```python
# 商品価格（税抜き）
price = 10

# 消費税率（10%）
tax_rate = 0.1

# 税込価格を計算
total = price * (1 + tax_rate)
```

コードを見れば分かることは書かず、なぜそうしているかを説明します。

### 6. 一貫性を保つ

**悪い例**：
```python
def getUserName():
    pass

def get_user_age():
    pass

def GetUserEmail():
    pass
```

**良い例**：
```python
def get_user_name():
    pass

def get_user_age():
    pass

def get_user_email():
    pass
```

命名規則を統一すると、コードが読みやすくなります。

## コードの構造を改善する

### 1. 早期リターンを使う

**悪い例**：
```python
def process_data(data):
    if data:
        if len(data) > 0:
            if all(isinstance(x, int) for x in data):
                # 実際の処理
                result = sum(data)
                return result
            else:
                return None
        else:
            return None
    else:
        return None
```

**良い例**：
```python
def process_data(data):
    if not data:
        return None
    
    if len(data) == 0:
        return None
    
    if not all(isinstance(x, int) for x in data):
        return None
    
    # 実際の処理
    result = sum(data)
    return result
```

早期リターンを使うと、ネストが減り、読みやすくなります。

### 2. 条件式を簡潔にする

**悪い例**：
```python
if x > 0 and x < 100 and x % 2 == 0:
    print("条件を満たしています")
```

**良い例**：
```python
def is_valid_number(x):
    return 0 < x < 100 and x % 2 == 0

if is_valid_number(x):
    print("条件を満たしています")
```

複雑な条件式は、関数に分けると読みやすくなります。

### 3. リスト内包表記を適切に使う

**悪い例**：
```python
result = []
for x in range(10):
    if x % 2 == 0:
        result.append(x * 2)
```

**良い例**：
```python
result = [x * 2 for x in range(10) if x % 2 == 0]
```

ただし、複雑すぎる場合は通常のループの方が読みやすいこともあります。

## 実践例

### 例1：リファクタリング前

```python
def calc(x, y, z):
    if x > 0:
        if y > 0:
            if z > 0:
                a = x * y
                b = a * z
                c = b / 2
                return c
            else:
                return 0
        else:
            return 0
    else:
        return 0
```

### 例2：リファクタリング後

```python
def calculate_volume(length, width, height):
    """
    直方体の体積を計算する
    
    Args:
        length: 長さ
        width: 幅
        height: 高さ
    
    Returns:
        体積（すべて正の値の場合）、それ以外は0
    """
    if not (length > 0 and width > 0 and height > 0):
        return 0
    
    volume = length * width * height
    return volume / 2
```

## まとめ

- 明確な変数名と関数名を使う
- 関数は1つのことをする
- マジックナンバーを避ける
- 長い関数を分割する
- コメントは「なぜ」を説明する
- 一貫性を保つ
- 早期リターンでネストを減らす

読みやすいコードを書くことは、チーム開発でも個人開発でも重要です。意識して練習しましょう！
