# MOC_モジュール設計体系

43_モジュール設計 の入口ノート。**コードを「どこで区切り、どうつなぎ、どこに置くか」——モジュール・パッケージ単位の設計**を扱う。骨格は『Clean Architecture』第4部（コンポーネントの原則：REP/CCP/CRP・ADP/SDP/SAP）。そこに Ousterhout『A Philosophy of Software Design』の「深いモジュール・情報隠蔽」と、Khononov『Balancing Coupling in Software Design』（2024）の「結合の強度・距離・変動性」を加える構成にした。

フォルダは **テーマ別**、教材（旧 第01〜08部・全22章）を読む **学習順** は下の「学習順インデックス」で持つ。各テーマフォルダには「教材の章（入門）」と「単体ノート（深掘り）」が並ぶ。
