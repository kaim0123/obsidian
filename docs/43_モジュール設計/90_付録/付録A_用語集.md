# 付録A　用語集

本教材で登場する主要用語の一覧です。

---

## あ行

| 用語 | 説明 |
|------|------|
| **アダプタ** | ポートの具体実装。HTTP, DB など外部を接続 |
| **アンチパターン** | よくある悪い設計のパターン |
| **ACL** | Anti-Corruption Layer。外部モデルを内部モデルに変換する層 |

## か行

| 用語 | 説明 |
|------|------|
| **カプセル化** | 内部を隠し、公開操作だけを提供すること |
| **凝集度** | 1 モジュールの中身が 1 つの目的にまとまっている度合い |
| **結合度** | モジュール同士の依存の強さ |
| **コンテキスト** | モデルと用語が有効な範囲（Bounded Context） |

## さ行

| 用語 | 説明 |
|------|------|
| **責務** | モジュールが担当すべき仕事 |
| **境界** | モジュールの内側と外側を分ける線 |
| **公開面** | 外に export する API の総量（Surface Area） |

## た行

| 用語 | 説明 |
|------|------|
| **DTO** | Data Transfer Object。モジュール間で渡すデータ構造 |
| **DIP** | 依存逆転の原則。詳細が抽象に依存する |
| **ドメイン** | ソフトウェアが扱う事業・業務の世界 |
| **Driving Port** | 外からコアを呼び出す入口（Primary Port） |
| **Driven Port** | コアが外部に要求するインターフェース（Secondary Port） |

## な行

| 用語 | 説明 |
|------|------|
| **モジュール** | 責務を持つ、境界で囲まれた部品の塊 |
| **モック / スタブ** | テスト用の偽実装 |

## は行

| 用語 | 説明 |
|------|------|
| **バレルファイル** | `index.ts` など、公開 API をまとめるファイル |
| **ポート** | コアと外部の接点となるインターフェース |
| **Leaky Abstraction** | 隠すはずの詳細が外に漏れる抽象化 |

## ま行

| 用語 | 説明 |
|------|------|
| **マイクロサービス** | 独立デプロイ可能な小さなサービス群 |
| **モノリス** | 1 つのデプロイ単位にまとまったアプリケーション |

## や行

| 用語 | 説明 |
|------|------|
| **ユビキタス言語** | チーム全員が共有するドメインの用語 |
| **YAGNI** | You Aren't Gonna Need It。今必要ないものは作らない |

## ら行

| 用語 | 説明 |
|------|------|
| **レイヤー** | 関心ごとに水平分割した層 |
| **リポジトリ** | 永続化を抽象化するパターン |
| **結果整合性** | 時間差で整合性が取れる方式（Eventual Consistency） |

## わ行・英語

| 用語 | 説明 |
|------|------|
| **OCP** | 開放閉鎖の原則。拡張に開き変更に閉じる |
| **SoC** | 関心の分離（Separation of Concerns） |
| **SRP** | 単一責任の原則。変化の理由を 1 つに |
