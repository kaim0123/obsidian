# Analytics（GA4・GTM）目次

Webサイトの **計測・分析** を行うためのGoogle系ツール群をまとめる領域。

- **GA4**（Google Analytics 4）: 計測・集計・分析の本体
- **GTM**（Google Tag Manager）: 計測タグの管理・発火制御

→ 最終的なゴールは **LPの問い合わせボタン・送信ボタンなどのCV計測を実務レベルで扱えるようになる** こと。

## 🔑 用語ミニ辞典

| 用語 | 一言で |
|------|-------|
| 計測ID / Measurement ID | `G-XXXXXXXXXX` 形式のGA4ストリーム識別子 |
| コンテナID | `GTM-XXXXXXX` 形式のGTM識別子 |
| プロパティ | GA4の計測対象1つ分（通常=1サイト） |
| データストリーム | プロパティ内のデータ入口（Web/iOS/Android） |
| イベント | ユーザーの1つの行動 |
| パラメータ | イベントの詳細情報 |
| ユーザープロパティ | ユーザー自身の属性 |
| キーイベント | GA4のCV（旧コンバージョン） |
| タグ | GTMで発火する計測コード片 |
| トリガー | タグを発火させる条件 |
| 変数 | 動的な値のプレースホルダ（`{{変数名}}` で参照） |
| dataLayer | JS配列。サイトから計測ツールへの公式伝言板 |
| Consent Mode v2 | 同意状況をGoogleタグへ伝える仕組み |
| サーバーサイドGTM | 自社サーバーで計測中継する構成 |
