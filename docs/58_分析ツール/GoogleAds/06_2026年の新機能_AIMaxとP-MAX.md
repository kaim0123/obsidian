# 2026年の新機能: AI Max と P-MAX

- 2026年の主役キャンペーン **P-MAX** と **AI Max for Search** の全体像をつかむ

- 2026年の最新アップデート（ネガキワ1万個・AIナレーション等）をキャッチアップ

## 1. 2026年の Google広告は「AI運用時代」

### 主要トレンド

| トレンド | 意味 |
|---------|------|
| **AI Max for Search**（β→GA） | キーワード指定不要の検索広告 |
| **P-MAX の勢力拡大** | 全CVの45%、全クリックの62% |

→ **広告運用の仕事は縮小ではなく、高付加価値化**

## 2. P-MAX（Performance Max）

### 概要

**全Googleチャネル横断のAI最適化キャンペーン**。
広告主は「素材」と「シグナル」を提供し、配信判断はすべてGoogle AIに任せる。

### 配信面

```
1つのP-MAXキャンペーンが同時に配信:
  ├ Google検索
  ├ ディスプレイネットワーク
  ├ YouTube (動画・ショート)
  ├ Gmail (プロモーションタブ)
  ├ Google Discover
  └ Google マップ
```

### 2026年時点のシェア

- **全CVの45%**
- **全クリックの62%**
- EC・リード獲得・BtoCで主力キャンペーンとして定着

### 入力する素材

| 素材 | 推奨個数 | 仕様 |
|------|--------|-----|
| 見出し | 15個 | 最大30文字 |
| 長い見出し | 5個 | 最大90文字 |
| 説明文 | 5個 | 最大90文字 |
| 画像 | 20個 | 複数アスペクト比 |
| ロゴ | 5個 | 1:1, 4:1 |
| 動画 | 任意（強く推奨） | 10〜60秒 |
| CTAテキスト | 1個 | "資料請求" 等から選択 |

### オーディエンスシグナル

**AIに「こういうユーザーに配信してほしい」と伝えるヒント**:

```
オーディエンスシグナル:
  ├ 自社の顧客リスト (Customer Match)
  ├ カスタムセグメント:
  │   ├ キーワード "リフォーム 東京"
  │   ├ 閲覧URL "example.com/..."
  │   └ インストール済みアプリ
  ├ 詳細な属性 (年齢・収入)
  └ 興味関心 (カテゴリ)
```

シグナルは **「厳守する設定」ではなく「学習のヒント」**。
実際の配信は AI が広く探索して最適化します。

## 3. P-MAXの2026年アップデート（重要）

### ① ネガティブキーワード 10,000個まで

以前は制限が厳しかったが、**1キャンペーンあたり10,000個** まで追加可能に。
検索・ショッピング面のブランド名・競合名・不適切ワードを大量除外できます。

### ② 検索テーマ 50個

**「検索テーマ」** とは P-MAX に対して「このテーマの検索に配信して」と与えるヒント。
2026年は **1アセットグループあたり50個** まで設定可能になりました。

### ③ デバイス・デモグラフィック ターゲティング

以前は「すべて自動」だったが、2026年は **デバイス（モバイル/PC/タブレット）** や **デモグラフィック（年齢・性別）** の手動制限が可能に。
※ AI学習には影響するので、制限しすぎると効果減。

### ④ アセット別パフォーマンス評価

**どの見出し・画像がCVに貢献したか** がレポートで確認可能。

### ⑤ 検索語レポート・配信先レポート

- **検索語レポート**: 検索面から来たクエリを確認
- **配信先レポート**: ディスプレイ・YouTubeで実際に表示されたサイト一覧

これにより「ブラックボックス」批判が改善されました。

### ⑥ AI ナレーション自動生成（2026年3月〜）

```
動画アセットに AIナレーションを自動追加
  ├ 見出し・説明文を読み上げる音声
  ├ 無音動画に AI 音声を付与
  └ 既存動画の別バージョンとして保存
```

⚠️ **デフォルトでON（オプトアウト式）**。

望まない場合は以下をOFF:
```
P-MAX キャンペーン設定 → アセットの生成 → AI ナレーション → 無効化
```

### ⑦ 動画アセットのAI生成

見出し・画像から **自動で動画を生成** する機能が拡張。
「動画を用意する工数が無い」悩みをAIが解決。

## 4. P-MAXの運用のコツ

### 成功させる5原則

1. **CV計測の精度が成否を決める**
   - 拡張コンバージョン必須
   - 月50CV以上で学習が安定
2. **素材は多様性を持って大量に**
   - 画像20個・動画複数・見出し15個フル活用
3. **オーディエンスシグナル はファーストパーティデータで強化**
   - 顧客リストのアップロードが効く
4. **ネガティブキーワードで純度を保つ**
   - 2026年仕様を活用（1万個）
5. **学習期間（4〜6週間）はいじらない**
   - 頻繁な編集で AIの学習が再スタート

### よくある失敗

| 失敗 | 原因 |
|------|-----|
| CPAが下がらない | 素材不足 / CV計測不備 / 予算過小 |
| 検索面ばかりで他チャネルが弱い | 画像・動画素材不足 |
| 誤ったキーワードで配信 | ネガティブキーワード不足 |
| ブランドワードで安く出ている | ブランド保護のためブランドキャンペーンを別に作る |

## 5. AI Max for Search

### 概要

従来の検索キャンペーンの **AI自動化バージョン**。
キーワード・広告文の作成を **AIに全委託** する新種別。

### 入力項目（驚くほど少ない）

```
- ランディングページURL
- 1日の予算
- 目標CPA または ROAS
- オーディエンスシグナル (任意)
```

これだけ。**キーワード選定ゼロ・広告文作成ゼロ**。

### AIが代わりにやること

1. LPの内容を解析
2. 関連する検索クエリを予測
3. 広告見出し・説明文を生成
4. 入札を最適化
5. A/Bテストを自動実行

### 2026年のロールアウト

- **2025年後半**: β版で一部アカウントに公開
- **2026年1月**: 北米全MCCで有効化オプション展開
- **2026年中**: 日本含む世界展開進行中

### 従来の検索広告との違い

| 項目 | 従来検索 | AI Max for Search |
|------|---------|------------------|
| キーワード設定 | 必要 | 不要 |
| 広告文作成 | 手動 | 自動生成 |
| マッチタイプ | 選択必要 | 不要 |
| 入札調整 | 細かい | AIに一任 |
| 工数 | 多い | 極小 |
| ブランド コントロール | 強い | 弱い |

### 向いているケース

- **少人数・個人事業主** で運用工数を減らしたい
- LPの内容が **頻繁に変わる** サイト（AIが追従）
- **新しいサービス** で何のキーワードが効くか未知

### 向いていないケース

- **ブランド名の厳密なコントロール** が必要
- **競合への入札回避** が重要
- 特定キーワードで **独自の広告文** を出したい

## 6. AI Max と P-MAX の違い

| 観点 | AI Max for Search | P-MAX |
|------|------------------|-------|
| 配信面 | **検索のみ** | 全チャネル |
| 入力 | URL + 予算 + KPI | 素材 + シグナル |
| 主な用途 | 顕在層の刈り取り | 幅広いCV獲得 |
| 素材 | 不要（AI生成） | 大量必要 |
| 向いている業態 | リード獲得・BtoB | EC・BtoC・リード獲得 |

→ **併用が推奨** されています（Google推奨 "Power Pack" 構成）

## 7. Power Pack: 2026年の推奨予算配分

Google 推奨の標準構成:

```
月予算100%の配分:
  ├ P-MAX:           50〜60% (全チャネル横断CV)
  ├ AI Max (Search): 30〜40% (顕在層刈り取り)
  └ Demand Gen:      10〜20% (認知・検討)
```

小規模運用では:

```
月予算 10〜30万円:
  ├ P-MAX:           70%
  └ 検索 (手動管理): 30%  (ブランド保護用)
```

## 8. AI活用の注意点

### ブラックボックス化への対処

- **素材別レポート** を必ず確認
- **検索語レポート** でクエリ品質をチェック
- **月次で振り返り** し、効果の低い素材を入れ替え

### AIの学習期間を尊重

- **最低4〜6週間** は設定を触らない
- 頻繁な編集は学習リセットにつながる
- 編集するなら **大きな単位で一度に**

### データ品質を守る

- CV計測に漏れがあると **AIが間違って学習**
- 拡張コンバージョン・Consent Mode v2 は必須レベル

## 9. 2026年のその他の大きなアップデート

### Demand Gen の機能強化（2026年1月 Demand Gen Drop）

- **Shoppable CTV**: YouTubeコネクテッドTV視聴中に購入可能
- **新クリエイティブフォーマット**
- **より精緻なターゲティング**

### Cross-channel budgeting（ベータ）

- Google広告・GA4・Googleマーチャントが連携
- **予算配分を自動最適化** する提案機能
- GA4の Analytics Advisor と連携

### コンバージョン管理強化（ベータ）

- GA4と広告で **キーイベント状態が双方向同期**
- 片方で変更すると自動反映

### 2026-06-15 の同意扱い変更

- Google Analytics データ: **Google Signals 制御**
- Google Ads データ: **ad_storage 単独制御**
- GA4が広告データをコントロールする関係性が終了
