# GTMでの広告タグ設置

## 🎯 このページのゴール

- GTMで **Google広告関連の3種類のタグ** を設置できる
- **コンバージョンリンカー** を正しく入れる理由を理解する
- タグ発火順序・Consent設定を適切に行える

---

## 1. GTMで設置する Google広告タグの種類

Google広告に関連してGTMで扱うタグは主に4つ:

| タグ名 | 役割 | 必須度 |
|-------|------|-------|
| **Google タグ** | GA4と兼用の基本タグ。広告ID (AW-...) も兼ねられる | ★★★★★ |
| **コンバージョン リンカー** | 広告クリックIDをCookieに保存 | ★★★★★ |
| **Google 広告 コンバージョン トラッキング** | CV発生イベントを広告に送る | ★★★★★ |
| **Google 広告 リマーケティング** | 訪問ユーザーをリマケリストに追加 | ★★★ |

---

## 2. タグの発火順序（重要）

```
[ユーザーが広告クリックでLP到着]
       ↓  URLに "?gclid=XXXXX" が付く
[ページ読み込み開始]
       ↓
[Googleタグ (or GA4 Config)] ← 最初に必ず発火
       ↓
[コンバージョン リンカー] ← gclid をCookieに保存
       ↓
[リマーケティングタグ] ← 訪問記録を残す
       ↓
[ユーザーが操作]
       ↓ CV発生
[Google広告コンバージョン タグ] ← CV送信
```

**順序を間違えると:**
- gclidが保存されない → CVが記録されない
- リマケタグが先に動いてもユーザー特定できず効果が薄い

---

## 3. 必須タグ①: コンバージョン リンカー

### 何をするタグ？

広告クリック時にURL末尾に付く **`?gclid=XXXXX`**（クリックID）を読み取り、**Cookieに保存** します。このCookieがCV発生時にGoogle広告に送られることで、「どのクリックからCVに至ったか」を正確に紐付けます。

### 設置方法

```
GTM → 新しいタグ → 種類: コンバージョン リンカー
  設定: すべてデフォルトで可
  トリガー: All Pages
```

設定画面にほぼ項目がないほどシンプルです。

### 2026年の重要性

- **iOS Safari の ITP** が第三者Cookieを制限するため、コンバージョン リンカーが **ファーストパーティCookie** で `gclid` を保存する役割が決定的に重要
- **入れ忘れるとCV計測が大幅に劣化** します（5〜20%のCV喪失）

### 有効化チェック

Chrome DevTools → Application → Cookies で `_gcl_aw` や `_gcl_au` という Cookie が作成されているか確認。

---

## 4. 必須タグ②: Google タグ

GA4とGoogle広告で共用できる **基本の計測タグ**。

### 設置方法

```
GTM → 新しいタグ → 種類: Google タグ
  タグID: 
    G-XXXXXXXXXX (GA4)
    または
    AW-XXXXXXXXX (Google広告)
    または
    両方 (Googleタグは複数IDを受け付ける)
  構成パラメータ:
    send_page_view: true
  イベント パラメータ:
    (全イベントに共通で付けたい値)
  ユーザー プロパティ:
    (全ユーザーに付けたい属性)
  Consent Settings:
    必要な同意: analytics_storage, ad_storage
  トリガー: All Pages
```

### 1つのGoogleタグで複数IDを配信する

2026年現在、**1つのGoogleタグで GA4 と Google広告の両方に配信** できます:

```
タグID: G-XXXXXXXXXX  (メインID)

その他の設定 → 追加IDを設定:
  AW-YYYYYYYYY (Google広告)
```

→ **2つのタグに分けなくてよい**。メンテコストが下がります。

---

## 5. 必須タグ③: Google 広告 コンバージョン トラッキング

CV発生時に **「このページがCV」** と広告に教えるタグ。

### 設置方法

```
GTM → 新しいタグ → 種類: Google 広告 コンバージョン トラッキング
  設定:
    コンバージョン ID:    AW-XXXXXXXXX       (Google広告のアカウント番号)
    コンバージョン ラベル: abcdEFGhij12345    (CVアクション固有のラベル)
    コンバージョン値:      {{DLV - revenue}}   (動的 or 固定)
    通貨コード:           JPY
    注文 ID:              {{DLV - order_id}}  (重複排除用・任意)
  拡張コンバージョン:
    → 有効化してユーザーデータをマッピング
  トリガー: サンクスページPV or カスタムイベント form_submit_success
```

### コンバージョン ID・ラベルの取得方法

```
Google広告 → ツールと設定 → 測定 → コンバージョン
  → 該当CVをクリック
  → 「タグの設定」セクションに AW-XXXX と abcdEFG... が表示
```

### トリガー設定の典型

| CVタイプ | トリガー |
|---------|---------|
| フォーム送信（サンクスページ遷移） | ページビュー: `/thanks` |
| フォーム送信（SPA・Ajax） | カスタムイベント: `form_submit_success` |
| 電話タップ | リンククリック: Click URL starts with `tel:` |
| EC購入完了 | カスタムイベント: `purchase` |

### 拡張コンバージョンの有効化

```
Google 広告 コンバージョン トラッキング タグ の詳細設定
  → 拡張コンバージョンを有効化
  → ユーザーデータの提供方法:
      ・ダイレクト入力 (フィールドマッピング)
      ・コード
      ・既存のGoogleタグから取得
  → フィールドマッピング例:
      email: {{DLV - user_email}}
      phone: {{DLV - user_phone}}
```

## 6. 任意タグ④: Google 広告 リマーケティング

訪問ユーザーを **リマーケティングリスト** に追加し、後日他サイト等で再訴求するためのタグ。

### 設置方法（通常パターン）

```
GTM → 新しいタグ → 種類: Google 広告 リマーケティング
  設定:
    コンバージョン ID: AW-XXXXXXXXX
    カスタム パラメータを送信: 任意 (ECならユーザー属性を追加)
  トリガー: All Pages
```

**すべてのページで発火** させておくのが基本。

### ダイナミックリマーケティング（EC向け）

商品を見たユーザーに **同じ商品の広告を再表示** する高度なリマケ:

```
GTM → 新しいタグ → Google 広告 リマーケティング
  イベント パラメータ:
    ecomm_prodid:   {{DLV - product_id}}
    ecomm_pagetype: {{DLV - page_type}}
    ecomm_totalvalue: {{DLV - product_price}}
```

→ Google Merchant Center と連動した商品フィードと突合して動く

## 7. 実装パターン集

### パターンA: 最小構成（BtoB/リード獲得 LP）

```
┌ タグ1: Google タグ
│   ID: G-XXXXXXXXXX (GA4)
│   追加ID: AW-YYYYYYYYY (Google広告)
│   トリガー: All Pages
│
├ タグ2: コンバージョン リンカー
│   トリガー: All Pages
│
├ タグ3: Google 広告 コンバージョン (フォーム送信用)
│   コンバージョン ID: AW-YYYYYYYYY
│   ラベル: formSubmitAbcDef
│   値: 3000  通貨: JPY
│   拡張コンバージョン: 有効
│   トリガー: Custom - form_submit_success
│
└ タグ4: Google 広告 リマーケティング
    トリガー: All Pages
```

### パターンB: GA4インポート使う場合（推奨）

タグ3（ネイティブCVタグ）は **不要**。

```
┌ タグ1: Google タグ (GA4 + 広告)
├ タグ2: コンバージョン リンカー
├ タグ3: GA4 イベント (generate_lead)
│   → GA4側で計測 → 広告にインポート
│   拡張CV: Googleタグ側で一元化
└ タグ4: Google 広告 リマーケティング
```

**メリット**: CVタグを個別に作らなくていい・拡張CVも一括で管理・GA4とGoogle広告で値が揃う

### パターンC: フルEC構成

```
├ Google タグ
├ コンバージョン リンカー
├ GA4 イベント: view_item / add_to_cart / begin_checkout / purchase
├ Google 広告 コンバージョン: purchase（バックアップ用、セカンダリ）
├ Google 広告 リマーケティング（動的）
│   ecomm_prodid, ecomm_pagetype, ecomm_totalvalue
└ Merchant Center との商品フィード連携
```

## 8. Consent Mode との連携

2026年はConsent Mode v2 対応が必須レベル。

### 各タグの Consent 要件

| タグ | 必要な同意カテゴリ |
|------|------------------|
| Google タグ（GA4） | `analytics_storage` |
| Google タグ（広告） | `ad_storage` |
| コンバージョン リンカー | `ad_storage` |
| Google 広告 コンバージョン | `ad_storage`, `ad_user_data` |
| Google 広告 リマーケティング | `ad_storage`, `ad_user_data`, `ad_personalization` |
| 拡張コンバージョン（first-party） | `ad_user_data` |

### GTMでの設定方法

```
各タグ の 詳細設定 → Consent Settings
  → 「追加の同意チェックが必要」を選択
  → 必要な同意カテゴリにチェック
```

これにより、**同意が得られていないユーザーではそのタグが発火しない** 制御が効きます。

### Advanced Consent Mode（推奨）

同意拒否時も **匿名のping送信** でモデリング補完:

```
Google タグ
  → Consent Settings → 「設定なし（デフォルト動作）」に
  → GTMの別途「同意の初期化」タグで各カテゴリを"denied"に
  → 拒否でも cookieless ping が送られる
```

## 9. デバッグ・確認方法

### GTM プレビューモード

通常通りプレビューで:
- **Tags Fired** に全タグが出ているか
- **Consent** タブで各同意ステータスが正しいか

### Google Tag Assistant（Chrome拡張）

- 実ページで **`AW-XXXX` のリクエスト** が発火しているか
- **`_gcl_aw` Cookie** が作成されているか

### Google広告の診断ツール

```
Google広告 → ツールと設定 → 測定 → コンバージョン
  → 該当CV → ステータス確認
```

| ステータス | 対応 |
|----------|------|
| 記録中 | ✓ 正常 |
| 未確認 | まだCVが発生していない（1日〜） |
| タグが見つかりません | タグ未設置・発火していない |
| 重複タグを検出 | ネイティブ + GA4インポートで二重 |

### URL に gclid が付くかテスト

テスト用に自分の広告リンクをクリック → LPのURL末尾に `?gclid=...` が付いていればOK。これがないとCV記録されません。

## 10. よくあるトラブル

### トラブル1: サンクスページで CV が記録されない

- **コンバージョン リンカーが設置されていない** → 最優先で確認
- **トリガー条件が誤り** → `/thanks` vs `/thanks/` の違い等

### トラブル2: 自動タグ設定が OFF になっている

```
Google広告 → ツールと設定 → 設定 → アカウント設定
  → 自動タグ設定 を有効化
```

これがOFFだと URLに `gclid` が付かず、CV計測が機能しません。

### トラブル3: GA4とGoogle広告でCV数が大きく違う

- アトリビューション期間が違う（GA4は即時・広告は30日までクリックを遡る）
- 計測対象イベントが違う（GA4の「キーイベント」と広告の「プライマリ」が不一致）
- セッション開始の定義が違う

### トラブル4: 拡張コンバージョンが無効化される

- **HTTPSでないページで発火**（HTTP不可）
- ユーザーデータが **空** または形式が不正
- **同意が得られていない**（ad_user_data denied）

### トラブル5: タグが CMP で永遠にブロック

- CMPが同意前に全タグをブロックする設計
- → **Advanced Consent Mode** に切替で緩和
