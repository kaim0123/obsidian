# アカウント作成と初期設定

## 🎯 このページのゴール

- Google広告アカウントを **作れる** ようになる
- 最初に必ず設定すべき **8つの初期項目** を押さえる
- スマートモード/エキスパートモードの **違いと切替** を理解する

---

## 1. アカウント作成の全体フロー

```
Step1. Googleアカウント準備
   ↓
Step2. https://ads.google.com にアクセス
   ↓
Step3. 「今すぐ開始」→ 質問に答える
   ↓
Step4. スマートモードが立ち上がる
   ↓
Step5. エキスパートモードに切り替え (重要!)
   ↓
Step6. 初期キャンペーンを一時停止 / 下書き保存
   ↓
Step7. 請求先 (支払い方法) を登録
   ↓
Step8. 初期設定 (8項目、後述) を完了
   ↓
Step9. GA4 / GTMと連携
```

---

## 2. 最初の落とし穴: スマートモード vs エキスパートモード

新規アカウント作成時、Googleは **「スマートモード」** に誘導します。

| モード | 特徴 | 向いている人 |
|-------|------|------------|
| **スマートモード** | 設定項目が少なく初心者向け | 個人事業主・小規模店舗 |
| **エキスパートモード** | 全機能が使える・推奨 | LP運用・代理店・本気運用 |

### 🚨 重要: スマートモードで作ると

- **P-MAX・AI Max・拡張コンバージョン** など主要機能が使えない
- **GTM連携・GA4連携** の選択肢が限定的
- 後から切替は可能だが手間

→ **作成直後に必ず「エキスパートモードに切り替え」** をクリック

### 切替方法

```
アカウント作成後の画面で:
  画面右下 または メニュー「設定」→ 「エキスパートモードに切り替える」
  (確認ダイアログ→「エキスパートモードに切り替える」)
```

---

## 3. キャンペーン作成をスキップする裏技

アカウント作成フローでは **キャンペーン作成を強制** されるように見えます。でも実は:

```
「エキスパートモードに切り替える」をクリック
  → 「キャンペーンなしでアカウントを作成」 (画面下にある小さいリンク)
```

これで **キャンペーンを作らずにアカウントだけ開設** できます。初期設定を整えてから本番キャンペーンを作るのが安全。

---

## 4. 必ずやる初期設定 8項目

### ① タイムゾーンと通貨

```
ツールと設定 → 請求 → 設定
  タイムゾーン: 日本
  通貨:         日本円 (JPY)
```

⚠️ **後から変更不可** の項目。レポート日時・請求金額に影響するので最初に必ず確認。

### ② アカウント情報（事業者名・住所）

```
ツールと設定 → 設定 → アカウント設定
  → 事業者情報を正しく入力
```

広告審査で使われる。虚偽・不一致があると広告停止のリスク。

### ③ 請求先の設定（支払い方法）

```
ツールと設定 → 請求 → 支払い方法
  → クレジットカード / 銀行振込 を登録
```

**自動支払い** と **手動支払い** がある:

| 種類 | 挙動 |
|------|-----|
| 自動支払い | 月末または閾値到達で自動請求 |
| 手動支払い | 事前にチャージした金額の範囲で配信 |

日本では **自動支払い** が主流。予算管理したいなら **キャンペーン予算** で制御。

### ④ コンバージョン設定

```
ツールと設定 → 測定 → コンバージョン
  → CV計測を設定 (GA4インポート推奨)
```

→ 詳細は [[03_コンバージョン設定とGA4連携]]

### ⑤ Google アナリティクス連携

```
ツールと設定 → 設定 → リンクされているアカウント → Google アナリティクス (GA4)
  → GA4プロパティとリンク
```

### ⑥ Google Tag Manager 連携

```
ツールと設定 → 設定 → リンクされているアカウント → Google Tag Manager
```

GTMコンテナを認識させることで、**タグ配信状況** の診断ができるようになる。

### ⑦ 同意モード（Consent Mode）の設定

```
ツールと設定 → 測定 → コンバージョン → 設定 → ユーザーデータの収集
  Consent Mode v2 の動作を確認
```

→ 詳細は [[06_2026年の新機能とプライバシー対応]]

### ⑧ 2段階認証の有効化

**広告アカウントの乗っ取り** は実際に起きる重大事故。Googleアカウント側で必ず:

```
Google アカウント → セキュリティ → 2 段階認証プロセス → ON
```

## 5. MCC（クライアントセンター）アカウント

代理店や複数アカウント管理者向けの「管理者アカウント」。

```
https://ads.google.com/home/tools/manager-accounts/
```

- 複数のGoogle広告アカウントを **1画面で管理**
- 個別アカウントにログインし直さなくて済む
- 2026年時点で **MCC単位でのAI Max自動有効化** 機能が広まっている
- **社内運用でも管理しやすい** ので、個人事業主以外は最初から作る価値あり

## 6. アカウント階層の設計ガイド

### 基本の構造

```
アカウント
  └ キャンペーン (予算・配信面・入札戦略の単位)
      └ 広告グループ (テーマ・オーディエンスの単位)
          ├ 広告 (見出し・説明・画像等)
          └ キーワード / ターゲット
```

### 初心者向けの推奨構成

```
アカウント (自社アカウント 1つ)
  ├ キャンペーン1 "検索 - ブランド名"
  │   └ 広告グループ: ブランド名 + 派生ワード
  ├ キャンペーン2 "検索 - サービスカテゴリ"
  │   ├ 広告グループ: カテゴリA
  │   └ 広告グループ: カテゴリB
  ├ キャンペーン3 "P-MAX - 全商品"
  └ キャンペーン4 "リマーケティング"
```

### 命名規則の例

```
{種別} - {対象} - {地域}

例:
検索 - ブランド - 全国
検索 - リフォーム - 東京
PMax - 全商品 - 全国
リマケ - CV未達成 - 全国
```

→ 詳細は [[08_命名規則_運用ルール]]（GTM寄りだが考え方は共通）

## 7. 予算とその扱い

### 予算の2階層

| レベル | 設定値 | 挙動 |
|-------|-------|------|
| **アカウントレベル** | 月額の上限 | 共有予算を複数CPに配る |
| **キャンペーンレベル** | 1日の平均予算 | 日予算 × 30.4 が月の上限目安 |

### 日予算の動き方

Googleは **1日の平均予算の2倍** までその日に使うことがあります（前日使い残した分を翌日回収する動き）。

- 日予算 3,000円 → ある日 6,000円使うことも
- **月合計では必ず「日予算 × 30.4」以内**
- 驚く前に理解しておく

### 最低推奨予算

- 検索広告: **日2,000円〜** （月6万円〜）
- P-MAX: **日5,000円〜** （月15万円〜・AI学習に要50CV/月が目安）
- ディスプレイ: 日500円〜でも形にはなる

## 8. 広告審査のルール（最低限）

広告を入稿すると **Googleの自動審査 + 人間によるレビュー** が入ります。

### よくある不承認理由

| 理由 | 対策 |
|------|-----|
| 誇大表現（「No.1」「世界一」） | 客観データ付き or 外す |
| 金融・医療・美容の規制表現 | 業種別ガイドラインに沿う |
| LPに **プライバシーポリシー** が無い | 公開・リンク設置 |
| LPに **運営者情報** が無い | 特定商取引法の表記 |
| 比較広告 | 事実ベースで公平に |
| 景品表示法 | 虚偽表示を避ける |

審査は **通常1営業日以内**、複雑なものは数日。
