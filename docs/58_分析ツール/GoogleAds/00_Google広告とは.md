# Google広告とは

## 🎯 このページのゴール

- Google広告（旧 Google AdWords）が **何をするツールか** を理解する
- GA4・GTMとの **役割分担** を整理する
- 2026年時点での **主要キャンペーン種別の全体像** をつかむ

## 1. Google広告 の一行定義

> **Google広告は、Googleが提供する「広告配信プラットフォーム」。** Google検索・YouTube・Gmail・提携サイト（ディスプレイネットワーク）等にクリック課金やインプレッション課金で広告を出せる。

### 対応できる配信面

| チャネル | どこに出る？ |
|---------|------------|
| Google検索 | 検索結果の上下 |
| ディスプレイ | 200万以上の提携サイト・アプリのバナー枠 |
| YouTube | 動画広告・バンパー・インストリーム・ショート |
| Gmail | プロモーションタブ |
| Google マップ | 店舗検索時の広告 |
| Google Discover | モバイルのDiscoverフィード |
| Google ショッピング | ショッピングタブの商品リスト |

**1つの管理画面（Google広告アカウント）から全部制御できる** のが特徴。

## 2. GA4 / GTM との役割分担

```
[ユーザー]
   ↓ 検索・閲覧
[Google広告] ─ 広告配信
   ↓ クリック
[LP]
   ↓ 計測タグ経由で
[GTM] ── 発火制御
   ↓
[GA4] ── 集計・分析
   ↓ CVデータ共有
[Google広告] ── CV最適化 (AI学習)
```

### 3ツールのざっくり役割

| ツール | 役割 |
|-------|------|
| **Google広告** | **集客**（トラフィックを買う）・広告配信・予算配分 |
| **GTM** | 広告計測タグの **配置・発火制御** |
| **GA4** | LPでの **行動分析・CV集計**・広告へ連携 |

### データの流れ

1. Google広告 → LP に誘導
2. LP上でGTMが Google広告の「コンバージョンタグ」を発火
3. Google広告が「このクリックはCVに繋がった」と学習
4. **AIが学習した結果を元に、次の広告配信を最適化** する

→ つまり **CV計測の精度 = 広告効果の天井**。計測がずれると広告費も無駄になる。

## 3. 2026年のキャンペーン種別（ざっくり俯瞰）

Google広告にはキャンペーン種別が複数あり、「何を達成したいか」で選びます。

| キャンペーン | 主な配信面 | 特徴 | どんな目的に？ |
|------------|-----------|------|--------------|
| **検索（Search）** | Google検索 | キーワード検索連動 | 顕在ニーズ層の獲得 |
| **AI Max for Search**（2026〜） | Google検索 | キーワード不要・URLとKPIだけ指定 | 検索広告のAI自動運用 |
| **パフォーマンスマックス（P-MAX）** | 全チャネル横断 | AIが自動最適化 | 幅広いCV獲得（2026年主力） |
| **ディスプレイ（Display）** | 提携サイトバナー | 幅広い認知 | ブランド認知・リマケ |
| **動画（YouTube）** | YouTube | 動画広告 | 認知・視聴維持 |
| **デマンドジェン（Demand Gen）** | YouTube/Gmail/Discover | ビジュアル主体・中間層 | 検討段階のユーザー獲得 |
| **ショッピング（Shopping）** | 検索・ショッピングタブ | Merchant Center連動 | EC商品販売 |
| **アプリ（App）** | 各チャネル | アプリのインストール促進 | モバイルアプリ |

> 📘 詳細は [[02_キャンペーン種別の選び方]] で

### 2026年の主力は「Power Pack」構成

Google推奨の **Power Pack** と呼ばれる予算配分:

- **P-MAX**（50〜60%）: 全チャネル横断のAI最適化
- **AI Max for Search**（30〜40%）: 高意向な検索をAIで刈り取り
- **Demand Gen**（10〜20%）: 認知・潜在層の育成

## 4. 課金方式（入札戦略）

### 主な課金方式

| 方式 | 略称 | 課金タイミング |
|------|-----|-------------|
| クリック単価 | **CPC** | 広告がクリックされた時 |
| インプレッション単価 | CPM | 広告が1000回表示された時 |
| 視聴単価 | CPV | 動画が視聴された時 |
| コンバージョン単価 | **CPA** | CVが発生した時の目標単価 |
| 広告費用対効果 | **ROAS** | 目標広告費用対効果 |

### 入札戦略（2026年はスマート入札が主流）

| 戦略 | 何をAIに任せるか |
|------|----------------|
| **目標コンバージョン単価（tCPA）** | CV単価を指定額に近づける |
| **目標広告費用対効果（tROAS）** | 広告費1円あたりの売上を最大化 |
| **コンバージョン数の最大化** | 予算内で最大数のCV |
| **コンバージョン値の最大化** | CV金額合計を最大化 |
| 手動CPC | 人間がキーワードごとに単価設定（廃止傾向） |

→ スマート入札の精度は **GA4/広告のCV計測品質に完全依存**

## 5. Google広告を使う前提条件

LPで広告を出すために **最低限必要なもの**:

1. **Google広告アカウント**（無料で作れる、支払い方法の登録は必要）
2. **配信先のLP**（可能な限りモバイル対応）
3. **GA4 + GTM**（必須ではないが、CV計測の精度が段違いに上がる）
4. **CVポイントの定義**（問い合わせ送信 / 購入 / 資料DL 等）
5. **予算**（1日数百円〜。業界相場は後述）
6. **クリエイティブ**（広告文・画像・動画）
7. **プライバシーポリシー**（リマーケティング使用時は必須）
8. **Consent Mode v2対応**（EU圏ユーザーがいる場合・2026年推奨）

## 6. Google広告の画面の全体構成

Google広告の管理画面は階層構造:

```
Google広告アカウント
  └ キャンペーン (予算・配信面・入札戦略の単位)
      └ 広告グループ (テーマ・オーディエンスの単位)
          ├ 広告 (見出し・説明・画像等)
          └ キーワード / ターゲット
```

### 左サイドバーの主要メニュー

| メニュー | 役割 |
|---------|------|
| 概要 | ダッシュボード |
| キャンペーン | キャンペーン一覧・編集 |
| オーディエンス | ターゲットとなるユーザー群 |
| **ツールと設定** | **コンバージョン・GA4連携・Tag Manager連携** |
| 分析情報 | AIによる改善提案 |
| レポート | カスタムレポート |

### Google広告エディタ（デスクトップアプリ）

- 複数キャンペーン・大量の変更を **一括編集** できる無料アプリ
- 手動CPC時代の名残だが、**多量のキーワード管理** には今でも便利

## 7. 2026年の大きなトレンド

### ① AI運用が完全に主流

- P-MAXが **全CVの45%・全クリックの62%** を占めるまで成長
- 手動CPC・手動入札は **ほぼ消滅**
- 人間の仕事は「**AIに何を学習させるか**」の設計に

### ② プライバシー対応が計測精度を左右

- **Consent Mode v2**・**拡張コンバージョン** の実装が必須
- **2026年6月15日** 以降、Google広告データは **ad_storage の同意のみ** で制御
- 同意取得できない場合、**リマーケティング母数が減少**

### ③ ファーストパーティデータの重要性

- Cookieが使えない環境が増え、**顧客リスト（Customer Match）** が重要に
- 拡張コンバージョンで **ハッシュ化した顧客情報** をGoogleに送る運用が定着

### ④ 動画AIの自動生成

- 2026年3月から **P-MAXで AIナレーション自動生成** が追加（デフォルトON）
- 動画制作コストが下がる一方、質のコントロールは手動になる

## 8. よくある疑問

### Q. 広告代理店に頼んだ方がいい？

- **月予算10万円以下**: 自前運用の方がマージン取られない分、費用対効果が良いことも多い
- **月予算30万円以上**: 運用代理店の工数が見合う
- 代理店に頼んでも、**CV計測の仕組み** は自社で理解しておくべき

### Q. 最低予算はいくら？

- 業界・地域・競合による
- 検索広告: **最低月3〜5万円**（日2000円）が目安
- P-MAX: **最低月10万円**（AIの学習に最低50CV/月が目安）
- 「試しに月1万円」では **AIが学習できず結果が出ない**

### Q. SEOとの違いは？

- **SEO**: 検索結果の自然枠に出る・無料・時間がかかる
- **Google広告（リスティング）**: 検索結果の広告枠に出る・有料・即時
- 両方併用が王道（両方の指標を追う必要あり）

### Q. 他の広告プラットフォームと何が違う？

- **Google広告**: 検索ニーズを捕まえるのが最大の強み
- **Meta広告（Facebook/Instagram）**: 属性・興味ターゲティングが強い
- **LINE広告**: 日本の既存顧客への再訴求・友だち獲得
- **Yahoo!広告**: ビジネス層・年齢層高めの日本ユーザー
- 2026年現在、**LP運用ではGoogle広告 + Meta広告** が定番構成
