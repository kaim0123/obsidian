# 外部リンク・ファイルダウンロードの計測

## 🎯 このページのゴール

- 外部サイトへのリンククリックを計測できる
- 資料PDF等のファイルダウンロードを計測できる
- SNSシェア・LINE登録ボタンなど、**離脱系アクション** をCVとして扱えるようになる

---

## 1. GA4の自動計測で取れるもの

GA4の拡張計測機能では、以下が自動で計測されます:

| イベント | 条件 |
|---------|------|
| `click`（outbound=true） | **外部ドメイン**へのリンククリック |
| `file_download` | リンク先が pdf/doc/xlsx/zip/mp3/mp4 等のファイル |

有効化は `GA4 → 管理 → データストリーム → 拡張計測機能` で。

---

## 2. 外部リンククリック（自動計測）

### 送られるパラメータ

```
event: click
  link_url:       クリックされたURL
  link_domain:    リンク先のドメイン
  link_classes:   要素のclass
  link_id:        要素のid
  outbound:       true
```

### 注意点

- 自分のドメインと **違うドメインを持つリンクのみ** 対象
- サブドメインまたぎ（`www.example.com` ↔ `blog.example.com`）でも「外部」扱い
- **内部リンク** は対象外

---

## 3. 外部リンク: GTMでより細かく拾う

自動計測を使わず、GTMで明示的に拾うパターン:

### トリガー

```
トリガー > 新規
  タイプ: クリック - リンクのみ
  このトリガーの発火場所: 一部のリンククリック
  条件:
    Click URL matches RegEx   ^https?://(?!(www\.)?example\.com)
  名前: Link Click - Outbound
```

（`example.com` は自ドメインに置換）

### タグ

```
タグ > 新規
  タイプ: GA4 イベント
  イベント名: outbound_click
  パラメータ:
    link_url     = {{Click URL}}
    link_domain  = (カスタムJSで抽出)
    link_text    = {{Click Text}}
  トリガー: Link Click - Outbound
```

### `link_domain` の抽出用カスタムJS変数

```js
function() {
  try {
    var a = document.createElement('a');
    a.href = {{Click URL}};
    return a.hostname;
  } catch (e) {
    return '';
  }
}
```

## 4. ファイルダウンロード計測

### 自動計測で取れる拡張子

GA4 の `file_download` は以下を対象:

```
pdf, doc/docx, xls/xlsx, ppt/pptx,
csv, txt, rtf,
zip, rar, 7z,
mp3, m4a, wav,
mp4, mov, avi, wmv
```

### 送られるパラメータ

```
event: file_download
  file_extension:  拡張子
  file_name:       ファイル名
  link_url:        フルURL
  link_classes:    class
  link_id:         id
  link_text:       リンクテキスト
```

### GTMで自前実装する場合

```
トリガー:
  タイプ: クリック - リンクのみ
  条件: Click URL matches RegEx  \.(pdf|docx?|xlsx?|pptx?|zip)(\?|$)

タグ:
  イベント名: file_download
  パラメータ:
    file_url       = {{Click URL}}
    file_extension = (カスタムJSで抽出)
    file_name      = (カスタムJSで抽出)
```

#### カスタムJS: 拡張子抽出

```js
function() {
  var url = {{Click URL}};
  var m = url.match(/\.([a-z0-9]+)(?:\?|$)/i);
  return m ? m[1].toLowerCase() : '';
}
```

#### カスタムJS: ファイル名抽出

```js
function() {
  var url = {{Click URL}};
  var path = url.split('?')[0];      // クエリ除去
  return decodeURIComponent(path.substring(path.lastIndexOf('/') + 1));
}
```

## 5. LP実務: 資料ダウンロードをCV化する

「ホワイトペーパーをダウンロード」「料金表PDFをDL」などはリードの強い指標:

### パターンA: 自動計測の `file_download` をCV化

1. GA4 → 管理 → イベント → `file_download`
2. **「キーイベントとしてマーク」** をON
3. 特定ファイルだけCVにしたい場合は、「イベントを作成」で条件付きイベント化:
   ```
   新規イベント名: whitepaper_download
   条件:
     event_name equals file_download
     file_name contains whitepaper
   ```

### パターンB: DLフォーム経由 → dataLayer

DL前にフォーム入力を必須にする場合:

```js
document.querySelector('#dl-form').addEventListener('submit', async function(e) {
  e.preventDefault();
  // サーバーでリード登録
  await fetch('/api/leads', { method: 'POST', body: new FormData(this) });

  // CV送信
  window.dataLayer.push({
    event: 'whitepaper_download',
    file_name: 'whitepaper-2026.pdf',
    lead_source: 'lp-hero'
  });

  // ファイルダウンロード実行
  window.location.href = '/files/whitepaper-2026.pdf';
});
```

GTMで **カスタムイベント `whitepaper_download`** で拾い、GA4へ送信 → キーイベント化。

## 6. SNSシェア / 外部サービス遷移の計測例

### LINE公式アカウント登録ボタン

```html
<a href="https://line.me/R/ti/p/@yourlineid" class="line-register">
  友だち追加
</a>
```

```
トリガー: Click URL contains "line.me"
タグ: イベント名 line_add_friend
```

### Twitter/X シェア

```html
<a href="https://x.com/intent/tweet?url=..." class="share-x">
  Xでシェア
</a>
```

```
トリガー: Click URL contains "x.com/intent" OR "twitter.com/intent"
タグ: イベント名 share  パラメータ method=twitter
```

### LINE公式への遷移をCV化するかどうか

- 広告運用している場合、**LINE登録をCV化** して広告最適化の学習に使うのが定石
- 同じ計測を **LINE Tag（LAP）** にも送り、LINE広告側のCV連携もする

## 7. タグの発火を待機（Link遷移時の保険）

外部リンクはクリック即遷移するため、**タグが送信を完了する前にページが閉じる** 可能性があります。

### 対策: 「タグの発火を待機」オプション

トリガー設定で:

```
[ ] このトリガーが発火するまでタグの発火を待機
  最大待機時間: 2000 ms
```

- 👍 確実に送信完了してから遷移
- 👎 ユーザー体験が遅くなる（体感できるほどではないが）

### 2026年の標準: Transport Beacon

GA4 の Measurement Protocol は **`navigator.sendBeacon`** を使う設計なので、ページ離脱時も **ほぼ確実に送信** されます。

通常は **「発火を待機」をOFF** のままで問題なし。発火抜けが気になる場合のみON。

## 8. 計測の優先度マトリクス

LPで「どのクリックを計測すべきか？」の目安:

| クリック種別 | 優先度 | 備考 |
|-------------|-------|------|
| CTAボタン（問い合わせ/申込） | ★★★★★ | 最重要CV候補 |
| 電話/メールリンク | ★★★★★ | モバイル主戦場のLP必須 |
| フォーム送信完了 | ★★★★★ | 最重要CV |
| 資料DL | ★★★★ | 準CV・マイクロCV |
| LINE登録 | ★★★★ | 広告CV連携対象 |
| SNSシェア | ★★ | 余裕があれば |
| 外部サイトへのリンク | ★★ | 自動計測で十分 |
| サイト内アンカーリンク | ★ | 通常は不要 |
