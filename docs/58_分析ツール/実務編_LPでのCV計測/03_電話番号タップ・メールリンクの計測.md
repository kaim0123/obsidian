# 電話番号タップ・メールリンクの計測

## 🎯 このページのゴール

- モバイルLPで **電話タップをCVとして計測** できる
- `mailto:` リンクのクリックを計測できる
- タップ位置（固定ボタン / コンテンツ内 / ヘッダー）別に **分析軸** を持たせる

---

## 1. 想定シナリオ

モバイル経由の問い合わせは **電話 > フォーム** という業種も多く（士業・医療・不動産・リフォーム等）、電話タップ計測は **ほぼ必須** です。

```html
<!-- 固定の電話CTAボタン（モバイル画面下部） -->
<a href="tel:0312345678" class="tel-fixed" data-tel-position="fixed">
  今すぐ電話する
</a>

<!-- ヘッダー内の電話番号 -->
<a href="tel:0312345678" class="header-tel" data-tel-position="header">
  03-1234-5678
</a>

<!-- メール問い合わせリンク -->
<a href="mailto:info@example.com" class="mail-link" data-mail-position="footer">
  メールでのお問い合わせ
</a>
```

---

## 2. 電話タップ計測の設定

### Step1: 組み込み変数の有効化

```
変数 > 組み込み変数 > 次をチェック:
  ☑ Click URL
  ☑ Click Element
  ☑ Click Classes
  ☑ Click Text
```

### Step2: トリガー作成

```
トリガー > 新規
  タイプ: クリック - リンクのみ
  このトリガーの発火場所: 一部のリンククリック
  条件: Click URL  starts with  "tel:"
  名前: Link Click - Tel
```

### Step3: タグ作成

```
タグ > 新規
  タイプ: GA4 イベント
  イベント名: tel_tap
  パラメータ:
    phone_number  = {{Click URL}}
    tel_position  = {{Click Classes}}     (or data属性変数)
    page_path     = {{Page Path}}
  トリガー: Link Click - Tel
```

### 位置情報を綺麗に取るなら data属性変数を使う

HTMLで `data-tel-position` を付けておき、その値をカスタムJS変数で拾う:

```js
function() {
  return {{Click Element}}.getAttribute('data-tel-position') || 'unknown';
}
```

→ 変数名 `JS - Tel Position`

タグのパラメータを `tel_position = {{JS - Tel Position}}` に差し替える。

## 3. 電話番号の表記ゆれ対応

HTMLに書かれた電話番号の書き方はバラバラ:

- `tel:0312345678`
- `tel:+81312345678`
- `tel:03-1234-5678`

レポートで同じ番号として集計したいなら、**正規化した文字列** を送る:

```js
function() {
  var url = {{Click URL}};
  // "tel:" を除去、ハイフン・プラス除去、+81を03に戻す
  return url.replace(/^tel:/, '')
            .replace(/-/g, '')
            .replace(/^\+81/, '0');
}
```

## 4. メールリンク計測の設定

### トリガー

```
トリガー > 新規
  タイプ: クリック - リンクのみ
  条件: Click URL  starts with  "mailto:"
  名前: Link Click - Mail
```

### タグ

```
タグ > 新規
  タイプ: GA4 イベント
  イベント名: mail_click
  パラメータ:
    mail_to        = {{Click URL}}
    mail_position  = (data属性変数)
    page_path      = {{Page Path}}
  トリガー: Link Click - Mail
```

## 5. モバイル / デスクトップの切り分け

電話タップは **モバイル発生** が圧倒的多数ですが、**デスクトップからの誤クリック** も拾ってしまいます。

### 方法A: Device Category で切り分け

GA4側の探索レポートで **デバイス カテゴリ** を軸に入れれば、モバイル/デスクトップ別に集計可能。

### 方法B: UserAgentで判定してpush

```js
function() {
  var ua = navigator.userAgent;
  return /Mobi|Android|iPhone/.test(ua) ? 'mobile' : 'desktop';
}
```

→ 変数 `JS - Device Type` を作り、パラメータに `device_type` として付与。

## 6. GA4でキーイベント化

電話CVをCVとして扱うなら:

1. リアルタイムで `tel_tap` が届くのを確認
2. 管理 → イベント → `tel_tap` を **キーイベント化**
3. 価値が分かっているなら「イベントを作成」で `value` 付きの別イベントを生成:
   ```
   新規イベント名: tel_tap_lead
   条件: event_name equals tel_tap
   パラメータの変更/追加:
     value    = 5000
     currency = JPY
   ```

### 電話CVは"タップ = CV"としていい？

- 👍 タップ = 本気度が高いユーザー、妥当な判定
- 👎 タップしたが実際には電話しなかったケースを含む

**実通話数と突き合わせる** には:
- **CallRail / CallTracking Japan** など通話計測ツールと連携
- その計測IDをGTMで送り、後日 BigQuery で突合
- 小規模なら「タップ数 ≒ CV」と割り切るのもアリ

---

## 7. 「クリックして電話する」ボタンのUXベストプラクティス

計測と合わせて、ボタン自体のデザインも改善ポイント:

- **モバイルでは画面下固定**（fixed footer）にする
- **デスクトップでは電話番号をテキスト表示**（数字を人間が見える形で）
- **営業時間内/外で表示切り替え**（時間外は「フォームから」を推奨）

## 8. 広告との連携

### Google Ads の電話コンバージョン

1. Google Adsに **電話コンバージョン** アクションを作成
2. GTMで対応する **Google Ads コンバージョン トラッキング** タグを作成
3. 同じ `Link Click - Tel` トリガーで発火

### 動的電話番号表示（Google広告のCall Forwarding番号）

- Google広告では **広告専用の転送番号** を表示する機能がある
- JS側では Google の代替番号が挿入される → GA4でもその番号をそのまま送ればOK

---

## 9. 計測漏れの典型パターン

### iOSのSafariで計測されない

- iOS Safariは `click` ではなく **`touchend`** で動作することがある
- GTMの「リンクのみ」トリガーは基本対応するが、念のためテスト

### Android Chromeでリダイレクト挟まる

- 一部キャリア回線で電話アプリ起動前に遷移 → タグ発火前にページ離脱
- 対策: トリガーで **「タグの発火を待機」** を100〜500msに設定

### `tel:` の大文字 `TEL:`

- まれにHTMLコーダーが `TEL:` と書いている
- 対策: `starts with` ではなく **`matches RegEx` で `^tel:|^TEL:`** に広げる
