# 主要レポートと指標

## 🎯 このページのゴール

- GA4 の画面構成（**レポート / 探索 / 広告 / 管理**）を把握する
- 初心者が **まず見るべき4つの定番レポート** を知る
- UAとは違う **GA4特有の指標（エンゲージメント率 等）** を理解する

---

## 1. GA4 の画面は4つのメニューで構成される

左サイドバーに並んでいる4つ:

| メニュー | 役割 |
|---------|------|
| **ホーム** | 直近のサマリー・AI要約（2026年以降は Analytics Advisor が常駐） |
| **レポート** | あらかじめ用意された **定型レポート**（PV/ユーザー/集客/CV） |
| **探索** | 自由に軸を組み合わせて分析する **カスタムレポート** 領域 |
| **広告** | 広告流入のアトリビューション分析（Google Ads連携時に充実） |
| **管理（歯車）** | プロパティ設定・キーイベント登録・カスタム定義など |

---

## 2. まず見るべき定番レポート 4選

### ①「リアルタイム」レポート

**いまこの瞬間** サイトにいるユーザーを表示。

- 設置直後の動作確認に使う
- イベント発火テスト（ボタンクリックが送られているか）に最適
- レポート > リアルタイム

### ②「ユーザー獲得」レポート

流入経路（検索/広告/SNS/直接）別のユーザー数を把握。

- レポート > 集客 > ユーザー獲得
- 主要な列:
  - **セッションの参照元/メディア**: どこから来たか
  - **新規ユーザー**: 初訪問ユーザー数
  - **エンゲージメントのあったセッション数**: 有効に見られた数

### ③「ページとスクリーン」レポート

どのページが見られているかを確認。

- レポート > エンゲージメント > ページとスクリーン
- 主要な列:
  - **ページビュー数**
  - **ユーザー数**
  - **ユーザーあたりの表示回数**
  - **平均エンゲージメント時間**

### ④「キーイベント」レポート（旧「コンバージョン」）

CVがどれくらい達成されたかを確認。

- レポート > エンゲージメント > キーイベント
- キーイベント別に達成回数・達成ユーザー数・CV率を見る

## 3. GA4 特有の重要指標

UAから来た人が **一番戸惑うのがここ**。指標が別物になっています。

| 指標 | 意味 | UAでの近い概念 |
|------|------|---------------|
| **ユーザー** | 計測対象となった人の数（重複排除） | ユーザー |
| **新規ユーザー** | 初訪問ユーザー | 新規ユーザー |
| **セッション** | 訪問1回分（デフォルト30分の無操作で切れる） | セッション |
| **エンゲージメント セッション** | **有効な訪問** とみなされたセッション | ≒ "非直帰セッション" |
| **エンゲージメント率** | エンゲージメントセッション / 全セッション | ≒ 1 − 直帰率 |
| **平均エンゲージメント時間** | ページが前面にある時間の平均 | 平均セッション時間 |
| **表示回数（ビュー）** | ページビュー + スクリーンビュー | ページビュー |

### 「エンゲージメント セッション」の定義（重要）

次のいずれかを満たすセッション:

1. **10秒以上** ページが前面にあった
2. **2ページ以上** 閲覧した
3. **キーイベントを1回以上** 発火した

→ 直帰率ではなく **これが主要な品質指標** になっている

## 4. 「探索（Explorations）」の使い方

定型レポートで物足りない時は **探索レポート** で自由分析します。

### よく使う探索テンプレート

| 探索タイプ | 使いどころ |
|-----------|-----------|
| **自由形式** | 任意のディメンションと指標を組み合わせた表/グラフ |
| **目標到達プロセス** | 入口 → CTA → フォーム → 完了 の離脱ポイントを可視化 |
| **経路探索** | 「このページの次に何を見たか」のフロー |
| **セグメントの重複** | 2条件を同時に満たすユーザー抽出（ベン図） |
| **コホート** | 日次/週次でのリテンション分析 |
| **ユーザーライフタイム** | ライフタイムバリュー（LTV）分析 |

> 💡 探索のデータは **データ保持期間** に影響される。管理 > プロパティ > データ保持 を **14か月** に変更しておくこと（初期値2か月は短すぎる）。

---

## 5. ディメンションと指標の違い

レポートを作るときに出てくる2つの概念。

| 概念 | 説明 | 例 |
|------|------|-----|
| **ディメンション** | データの **"属性"**（カテゴリ軸） | ページタイトル・参照元・デバイス・国 |
| **指標** | データの **"数値"** | ユーザー数・セッション数・CV数 |

**表の作り方**:
- 縦軸（行）にディメンション、横軸（列）に指標を並べるのが基本

---

## 6. データが反映されるまでの時間

| 場所 | 反映まで |
|------|---------|
| リアルタイムレポート | ほぼ即時（数秒〜1分） |
| 定型レポート | 最大24〜48時間 |
| 探索レポート | 最大24〜48時間 |
| BigQuery連携 | 数時間〜1日 |

> 💡 「昨日のデータがまだ全部集計されていない」場合があるので、**施策判断は最低2日待ってから** が安全。

---

## 7. レポート共有・エクスポート

- **PDFエクスポート**: レポート右上の「共有」→「ファイルをダウンロード」
- **CSVエクスポート**: 同上
- **Looker Studio 連携**: ダッシュボードを作って自動更新（GA4コネクタが公式提供）
- **BigQuery Export**: 生データをSQLで分析（2026年から **無料プランでも利用可能**）

---

## 8. 2026年のトピック

- **Analytics Advisor**: ホーム画面で「今週のハイライト」をAI要約
- **Home画面の generated insights**: アクセスするたび主要な変化を自動抽出
- **キーイベント ベースのアトリビューション分析**: ベータ版で提供
- **cross-channel budgeting（ベータ）**: 広告予算配分の最適化提案
