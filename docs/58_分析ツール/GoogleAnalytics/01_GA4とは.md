# GA4とは

## 🎯 このページのゴール

- GA4（Google Analytics 4）が **何のためのツールか** を理解する
- 旧UAとの根本的な違い（**イベントベース**）を理解する
- プロパティ・データストリーム・イベント など **用語の地図** を頭に入れる

---

## 1. GA4 の一行定義

> **GA4 は、Googleが提供する無料のWeb/アプリ分析ツール。** サイトやアプリでユーザーが起こした行動を「イベント」として記録し、集計・可視化して、改善の意思決定に役立てる。

---

## 2. なぜ GA4 になったのか（UAとの違い）

GA4 の前身は **Universal Analytics（UA）** で、2023年7月に計測停止しました。2026年現在、GA4 が唯一の現行バージョンです。

| 観点 | UA（旧） | GA4（現行） |
|------|---------|------------|
| 計測の基本単位 | **セッション**（訪問単位） | **イベント**（行動単位） |
| Web/アプリ | 別ツール | **同じプロパティで統合計測** |
| コンバージョン | 「目標（Goal）」設定 | **キーイベント**としてマーク |
| レポート | 固定のレポート中心 | **探索レポート**で自由に分析 |
| 機械学習 | ほぼなし | 予測指標・AIインサイトあり |
| プライバシー対応 | Cookie依存 | Cookielessを視野に入れた設計 |

### 特に重要: 「イベントベース」って何？

UAでは「PV」「セッション」「目標達成」などの **カテゴリが固定** されていました。
GA4では **すべての行動が `event` として一元化** されています。

```
UA の世界観:
  └ セッション
      ├ ページビュー
      ├ イベント（別カテゴリ）
      └ 目標

GA4 の世界観:
  └ すべて "イベント"
      ├ page_view    ← 自動で送られる
      ├ scroll       ← 自動で送られる
      ├ click        ← 自動で送られる（特定条件のみ）
      ├ form_submit  ← 自分で送信設定
      └ 独自イベント（例: cta_click, download_pdf）
```

---

## 3. GA4 の用語マップ

最初は用語で混乱します。この階層図で地図を掴みましょう。

```
アカウント (Account)
  └ プロパティ (Property)         ← GA4では1サイト=1プロパティが基本
      └ データストリーム (Data Stream)  ← Web用/iOS用/Android用を並列に持てる
          └ イベント (Event)       ← 各ユーザー行動
              └ パラメータ (Parameter)  ← イベントの詳細情報
```

### 用語の一行説明

| 用語 | 一言でいうと |
|------|-------------|
| アカウント | GA全体の契約単位。会社単位で1つ作ることが多い |
| プロパティ | 計測する **サイト/アプリ1つ分** のデータ入れ物 |
| データストリーム | プロパティに流れ込む **データの入口**（Web/iOS/Android別に作る） |
| イベント | ユーザーの1つの行動（例: ボタンクリック） |
| パラメータ | イベントの付随情報（例: clickされたボタンのテキスト） |
| ユーザープロパティ | そのユーザー自身の属性（例: 有料会員かどうか） |
| キーイベント | ビジネス上重要なイベント（旧「コンバージョン」） |
| 計測ID | データストリームごとに振られる `G-XXXXXXXXXX` の識別子 |

> 📘 詳しくは [[03_イベント・パラメータ・ユーザープロパティ]] へ

## 4. GA4 が自動で拾ってくれる「拡張計測機能」

GA4 のWebデータストリームを作ると、以下は **設定ONで自動計測** されます（2026年現在）。

| 自動イベント | 何を測る？ |
|-------------|-----------|
| `page_view` | ページ閲覧（SPAでも履歴API経由で拾う） |
| `scroll` | 90%スクロールで1回発火 |
| `click` | **外部ドメインへのリンククリックのみ** |
| `view_search_results` | サイト内検索（URLに特定クエリがある場合） |
| `video_start / video_progress / video_complete` | YouTube埋め込み動画 |
| `file_download` | pdf/doc/xlsx等へのリンククリック |
| `form_start / form_submit` | フォーム操作（2024年以降、精度は要検証） |

⚠️ **内部ボタンや独自フォームのクリックは自動計測の対象外** → GTMで自前で送る必要あり（これが `実務編_LPでのCV計測/` の主題）

## 5. GA4 の「できること」の全体像

| やれること | 典型的なレポート |
|-----------|-----------------|
| 訪問数・ユーザー数を見る | レポート > 集客 |
| 流入元（検索/広告/SNS）を見る | レポート > 集客 > ユーザー獲得 |
| ページごとの人気度 | レポート > エンゲージメント > ページとスクリーン |
| コンバージョン（キーイベント）達成数 | レポート > エンゲージメント > キーイベント |
| 任意の2軸での分析 | 探索 > 自由形式 |
| 離脱率の高い経路 | 探索 > 経路探索 |
| 購入までのファネル | 探索 > ファネルデータ探索 |

## 6. 2026年のアップデートで押さえるべきもの

- **Analytics Advisor**（2025年12月公開）: 自然言語で「先週と比べてCVが落ちた原因は？」と聞くと要約してくれるAIアシスタント
- **Home画面の自動サマリー**: 最終アクセス以降の主要な3つの変化を自動表示
- **オンボーディングアシスタント**: 業種に合わせた初期設定を自動提案
- **2026年6月15日からの同意扱い変更**: GA側のad_storage制御が変わる（広告連携時は要確認）
