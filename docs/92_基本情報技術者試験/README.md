## ファイルの内容

- **教材_*.md**: その分野の考え方や流れを解説した教材
- **用語集_*.md**: その分野の用語一覧（`[[用語名]]` 形式でObsidianリンク）と解説メモ用の表
- **用語解説テンプレート.md**: 個別用語の解説ノートを作るときに使うテンプレート

## 参照リンク

- **用語の詳しい解説**: [基本情報技術者用語集 - e-Words](https://e-words.jp/p/e-fe-list.html)
- **試験概要・シラバス**: [IPA 情報処理技術者試験](https://www.ipa.go.jp/shiken/kubun/fe.html)

## 学習の進め方の例

1. `基本情報技術者.md` から目次を確認し、苦手分野を特定する
2. 各系のサブフォルダから**教材**を開いて、概念や流れを理解する
3. 理解できたら**用語集**で用語を確認し、`[[用語名]]` をクリックして詳細を学ぶ
4. 個別用語のノートがない場合は `用語解説テンプレート.md` をコピーして作成する
5. 各ノート末尾の「解説メモ」の表に、自分用のメモや覚え方を追記する
