# 基本情報技術者 用語集・学習インデックス

IPAが公表している基本情報技術者試験のシラバスおよび過去問題に含まれる主な用語を、[IT用語辞典 e-Words 基本情報技術者用語集](https://e-words.jp/p/e-fe-list.html)の構成に沿って整理しています。

## 使い方

- **教材**は「考え方」を理解するために、**用語一覧**は用語の確認・メモ用に使えます。まず教材で流れを押さえ、不明な用語は用語一覧や e-Words で補強すると効率的です。
- 各サブカテゴリのノートに**用語一覧**と**学習メモ用の解説テンプレート**を用意しています。
- 用語の詳細は e-Words の各用語ページで確認できます。
- Obsidian のリンク `[[用語名]]` でノート間を関連付けできます。
