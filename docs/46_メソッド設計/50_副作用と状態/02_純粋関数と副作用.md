# 純粋関数と副作用

## この章の目的

**純粋関数** と **副作用** を理解し、テストしやすいメソッドの書き方を学ぶ章です。

---

## 1. 純粋関数とは — 同じ入力 → 同じ出力

**純粋関数（Pure Function）** とは、次の 2 つを満たす関数です。

1. **同じ入力に対し、常に同じ出力** を返す
2. **副作用がない**（戻り値以外に外部へ影響しない）

```javascript
// 純粋関数
function add(a, b) {
  return a + b;
}

function calculateTotal(items) {
  return items.reduce((sum, i) => sum + i.price * i.qty, 0);
}
```

純粋関数は **予測可能** で、**テストが最も簡単** です。

---

## 2. 副作用の種類（I/O・グローバル状態・例外・時刻）

| 副作用 | 例 |
|--------|-----|
| **I/O** | ファイル読み書き、DB、HTTP |
| **グローバル状態** | モジュール変数の変更、シングルトン |
| **例外** | throw（議論の余地あり） |
| **時刻・乱数** | `Date.now()`, `Math.random()` |

```javascript
// 副作用あり: 同じ入力でも出力が変わる
function createId() {
  return Date.now().toString();  // 時刻依存
}

function saveOrder(order) {
  db.insert(order);  // I/O
}
```

---

## 3. テストしやすい関数の書き方

**副作用を境界に押し出し**、核を純粋関数にします。

```javascript
// 悪い例: 全部混在
function processOrder(order) {
  const total = order.items.reduce(/* ... */);
  db.save({ ...order, total });
  email.send(order.customer);
}

// 良い例: 計算は純粋、I/O は外
function calculateOrderTotal(items) {
  return items.reduce((s, i) => s + i.price * i.qty, 0);
}

function processOrder(order, db, email) {
  const total = calculateOrderTotal(order.items);
  db.save({ ...order, total });
  email.send(order.customer);
}
```

`calculateOrderTotal` だけ **入力と出力** でテストできます。

---

## 4. 依存を引数で明示する

**依存性注入（DI）** のメソッド版 — 副作用の源を **引数** で渡します。

```javascript
// 時刻依存を引数化
function isExpired(deadline, now = Date.now()) {
  return now > deadline;
}

// テスト
isExpired(futureDate, fixedTimestamp);  // 固定時刻でテスト
```

グローバルな `db` や `config` を直接参照せず、引数またはコンストラクタで渡すとテストが容易です（[[01_テストしやすいメソッド設計]]）。

---

## 5. 並行処理との関係

副作用と **共有 mutable 状態** は、並行処理でバグの温床になります。

```javascript
// 危険: グローバルカウンタ
let count = 0;
function increment() {
  count++;  // 競合状態
}

// 安全: 純粋関数 + 新しい値を返す
function increment(count) {
  return count + 1;
}
```

純粋関数は **スレッドセーフ** で、並行処理と相性が良いです。  
Functional Core, Imperative Shell（[[03_Functional_Core_Imperative_Shell]]）で実践します。

---

## まとめ

- 純粋関数 = 同じ入力 → 同じ出力、副作用なし
- 副作用は I/O・グローバル・時刻等。境界に押し出す
- 依存を引数で明示し、テスト容易性を上げる
- 並行処理では純粋関数が安全
