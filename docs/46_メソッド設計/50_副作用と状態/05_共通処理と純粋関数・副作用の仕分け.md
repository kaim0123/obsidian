# 共通処理と純粋関数・副作用の仕分け

関連: [[02_純粋関数と副作用]] / [[03_Functional_Core_Imperative_Shell]]


共通化

- **認証・認可**: Supabase Auth、権限チェック、ロール判定
- **API層**: Supabaseへのアクセスをラップした共通関数
- **UIコンポーネント**: ボタン、フォーム、テーブル、モーダルなど
- **フォーム処理**: バリデーション、送信、エラー表示
- **ユーティリティ**: 日付・金額・文字列・UUID・CSV・PDFなどの共通関数
- **通知**: トースト表示、メール送信、Slack/LINE通知
- **ファイル処理**: Supabase Storageへのアップロード・ダウンロード
- **監査ログ**: 誰がいつ何を変更したかの記録
- **マスタデータ取得**: 部署・社員・役職・都道府県などの共通取得処理
- **型定義**: 共通のTypeScript型やZodスキーマ
- **定数・設定**: ルート、権限名、環境設定、エラーメッセージ
