# 付録A　用語集

本教材で登場する主要用語の一覧です。

---

## あ行

| 用語 | 説明 |
|------|------|
| **アンチパターン** | よくある悪い設計のパターン。避けるべき例 |
| **Extract Method** | 意味の塊を新しい関数に切り出すリファクタリング |

## か行

| 用語 | 説明 |
|------|------|
| **Guard Clause** | 異常系を先に弾き早期 return する書き方 |
| **カプセル化** | 内部を隠し、公開操作だけを提供すること |
| **Command** | CQS における状態を変える操作 |
| **CQS** | Command-Query Separation。読むと書くを分離 |
| **CQRS** | システム全体で読み取りと書き込みモデルを分離 |
| **循環的複雑度** | 分岐の多さを測る指標（McCabe） |

## さ行

| 用語 | 説明 |
|------|------|
| **責務** | 部品が担当すべき仕事 |
| **副作用** | 関数が戻り値以外に外部へ与える影響 |
| **Shell** | FCIS における I/O 層（Imperative Shell） |
| **SRP** | 単一責任の原則。変化の理由を 1 つに |
| **SoC** | 関心の分離 |

## た行

| 用語 | 説明 |
|------|------|
| **段階的詳細化** | 大きな処理を小さな関数に段階的に分解する手法 |
| **Tell, Don't Ask** | データを取り出さずオブジェクトにお願いする |

## な行

| 用語 | 説明 |
|------|------|
| **純粋関数** | 同じ入力 → 同じ出力、副作用なし |

## は行

| 用語 | 説明 |
|------|------|
| **バリデーション** | 入力が条件を満たすか検証すること |
| **貧血モデル** | エンティティがデータ入れ物でロジックがサービスに集中した状態 |
| **Fail Fast** | 異常を早い段階で検出し即座に失敗させる |
| **Functional Core** | FCIS における純粋関数の核 |
| **フラグ引数** | boolean 等で関数の振る舞いを切り替える引数 |

## ま行

| 用語 | 説明 |
|------|------|
| **メソッド** | オブジェクトに属する関数 |
| **モック地獄** | テストで過剰なモックが必要になる状態 |

## や行

| 用語 | 説明 |
|------|------|
| **YAGNI** | You Aren't Gonna Need It。今必要ないものは作らない |

## ら行

| 用語 | 説明 |
|------|------|
| **リファクタリング** | 振る舞いを変えず内部構造を改善すること |

## わ行・英語

| 用語 | 説明 |
|------|------|
| **DbC** | Design by Contract。前置条件・後置条件による契約 |
| **DRY** | Don't Repeat Yourself。同じ知識を二重に書かない |
| **FCIS** | Functional Core, Imperative Shell |
| **KISS** | Keep It Simple, Stupid。単純さを優先 |
| **Parameter Object** | 関連する引数を 1 オブジェクトにまとめるパターン |
| **Query** | CQS における値を返す操作（副作用なし） |
| **Result 型** | 成功/失敗を型で表現する戻り値 |
