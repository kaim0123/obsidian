# 付録C　Clean Code 関数ルール早見表

Robert C. Martin（*Clean Code*, 2008）の関数ルールをメソッド設計向けに整理した早見表です。

---

## 基本ルール

| ルール | 内容 | 本教材での章 |
|--------|------|-------------|
| **小さく** | 1 画面に収まる長さ | [[01_サイズと抽象度]] |
| **1 つのこと** | 1 関数 1 責任 | [[02_関心の分離と単一責任]] |
| **1 抽象度** | ステップの抽象度を揃える | [[01_メソッドの分割]] |
| **少ない引数** | 0〜2 が理想 | [[02_引数の設計]] |
| **副作用なし** | Query に副作用を入れない | [[01_CQS]] |
| **説明的な名前** | 意図が伝わる命名 | [[01_命名]] |

---

## 行数・複雑度の目安

| 指標 | 目安 | 超えたら |
|------|------|----------|
| 行数 | 20 行以下 | Extract Method |
| 行数（上限） | 50 行 | 必ず分割検討 |
| 循環的複雑度 | 10 以下 | 分岐の分割 |
| インデント | 2 段以下 | Guard Clause |
| 引数 | 3 個以下 | Parameter Object |

---

## 命名ルール

| 種類 | 形式 | 例 |
|------|------|-----|
| 一般 | 動詞 + 目的語 | `calculateTotal()` |
| 真偽値 | `is` / `has` / `can` | `isValid()` |
| 取得 | `get` + 名詞 | `getOrder()` |
| 禁止（単独） | 曖昧名 | `process`, `handle`, `data` |

---

## コード例

```javascript
// Clean Code に沿った関数
function registerUser(user) {
  validateUser(user);
  const hashed = hashPassword(user.password);
  persistUser({ ...user, password: hashed });
  notifyNewUser(user);
}
```

## 限界

- 20 行は **目安** — 宣言的マッピング等は例外あり
- **複雑度** とセットで判断（[[03_複雑度と分岐]]）
- 小規模プロジェクトでは KISS を優先（[[03_KISS・DRY・YAGNI]]）
