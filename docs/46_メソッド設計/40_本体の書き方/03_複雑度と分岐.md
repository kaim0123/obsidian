# 複雑度と分岐

## この章の目的

**循環的複雑度** と分岐の多さを理解し、複雑な関数を分割する技法を学ぶ章です。

---

## 1. 循環的複雑度（McCabe）— 分岐の多さを測る

Thomas McCabe（1976）の **循環的複雑度（Cyclomatic Complexity）** は、プログラムの **分岐の多さ** を数値化します。

**概算**: 1 + 分岐点の数（`if`, `else`, `for`, `while`, `case`, `&&`, `||`, `?` 等）

```javascript
function example(a, b) {
  if (a) {        // +1
    if (b) {      // +1
      return 1;
    }
  }
  return 0;
}
// 複雑度 ≈ 3
```

**目安**: 1 関数あたり **10 以下** が望ましい。15 超は分割を検討。

---

## 2. 複雑度が高い関数の見分け方

| サイン | 説明 |
|--------|------|
| **分岐だらけ** | if / switch が 5 個以上 |
| **テストケース爆発** | 分岐の組み合わせでテストが書けない |
| **「とりあえず else」** | すべての分岐を網羅する else が増える |
| **Lint 警告** | complexity ルールに引っかかる |

```javascript
// 複雑度が高い典型
function getShippingCost(order) {
  if (order.region === 'JP') {
    if (order.weight < 1) { /* ... */ }
    else if (order.weight < 5) { /* ... */ }
    else { /* ... */ }
  } else if (order.region === 'US') {
    // さらに分岐...
  }
}
```

## 3. 分岐の分割 — 小関数・ポリモーフィズム・ルックアップ

複雑度を下げる **3 つの手法** です。

### 小関数への Extract Method

```javascript
function getShippingCost(order) {
  if (order.region === 'JP') return getJpShipping(order);
  if (order.region === 'US') return getUsShipping(order);
  return getDefaultShipping(order);
}
```

### ポリモーフィズム（クラス設計と連携）

地域ごとに `ShippingCalculator` サブクラスを用意（[[MOC_クラス設計体系|44 クラス設計]]）。

### ルックアップテーブル

```javascript
const SHIPPING = {
  JP: getJpShipping,
  US: getUsShipping,
};
function getShippingCost(order) {
  const fn = SHIPPING[order.region] ?? getDefaultShipping;
  return fn(order);
}
```

---

## 4. Lint / CI での閾値設定

チームで **複雑度の上限** を CI に組み込みます。

```json
// ESLint 例
{
  "rules": {
    "complexity": ["warn", 10]
  }
}
```

- **warn** — レビューのきっかけ
- **error** — マージをブロック（段階的導入を推奨）

行数（`max-lines-per-function`）と **併用** すると効果的です。

---

## 5. 行数だけでは測れない複雑さ

| 例 | 行数 | 複雑度 |
|----|------|--------|
| 50 行の直線的処理 | 多い | 低い |
| 20 行の分岐だらけ | 少ない | 高い |

**行数と複雑度は別物** です。20 行でも分岐が多ければ読みにくい。  
Clean Code の「20 行」は目安であり、**複雑度とセット** で判断します（[[01_サイズと抽象度]]）。

---

## まとめ

- 循環的複雑度 = 分岐の多さ。10 以下が目安
- 高複雑度は Extract Method・ポリモーフィズム・ルックアップで下げる
- Lint / CI で閾値を設定し、可視化する
- 行数だけでなく複雑度も見る
