**200 行の `handleRequest()`** を題材に、第1〜7部の技法を統合する演習です。

## 1. 200 行の `handleRequest()` を読む

### Before（抜粋）

```javascript
function handleRequest(req) {
  if (!req) return { error: 'no request' };
  if (!req.token) return { error: 'unauthorized' };
  // ... 認証 30 行 ...
  if (!req.body?.orderId) return { error: 'invalid' };
  // ... バリデーション 40 行 ...
  const order = db.getOrder(req.body.orderId);
  // ... 計算 50 行 ...
  order.status = 'processed';
  db.save(order);
  email.send(order.customer);
  // ... レスポンス 30 行 ...
}
```

| 問題 | 内容 |
|------|------|
| 行数 | 200 行超 |
| 関心 | 認証・検証・計算・保存・通知が混在 |
| テスト | DB・メール必須 |
| 命名 | `handleRequest` が曖昧 |

## 2. Guard Clause と Extract Method で分割する

**Step 1**: Guard Clause で異常系を入口に集約

```javascript
function handleRequest(req) {
  const authError = authenticate(req);
  if (authError) return authError;

  const validationError = validateOrderRequest(req.body);
  if (validationError) return validationError;

  return processOrderRequest(req.body);
}
```

**Step 2**: Extract Method でブロックを切り出す

```javascript
function authenticate(req) {
  if (!req?.token) return { error: 'unauthorized' };
  // ...
  return null;
}

function validateOrderRequest(body) {
  if (!body?.orderId) return { error: 'invalid orderId' };
  // ...
  return null;
}
```

## 3. CQS と SoC で責任を整理する

```javascript
function processOrderRequest(body) {
  const order = loadOrder(body.orderId);           // Query（読み）
  const updated = applyProcessing(order);            // Command 準備
  persistOrder(updated);                             // Command（書き）
  notifyCustomer(updated);                           // Command
  return buildSuccessResponse(updated);            // Query
}
```

| 関数 | 関心 | CQS |
|------|------|-----|
| `authenticate` | 認証 | Query |
| `validateOrderRequest` | 入力検証 | Query |
| `applyProcessing` | 業務ルール | 純粋に近い |
| `persistOrder` | 永続化 | Command |
| `notifyCustomer` | 通知 | Command |

---

## 4. 純粋関数に切り出す部分の特定

**計算・判定** は Core に切り出します。

```javascript
// Core: 純粋
function calculateOrderTotal(items) {
  return items.reduce((s, i) => s + i.price * i.qty, 0);
}

function applyProcessing(order) {
  const total = calculateOrderTotal(order.items);
  return { ...order, total, status: 'processed' };
}

// Shell: I/O
function processOrderRequest(body) {
  const order = loadOrder(body.orderId);
  const updated = applyProcessing(order);
  persistOrder(updated);
  notifyCustomer(updated);
  return buildSuccessResponse(updated);
}
```

`calculateOrderTotal` と `applyProcessing` は **モックなし** でテスト可能です。
