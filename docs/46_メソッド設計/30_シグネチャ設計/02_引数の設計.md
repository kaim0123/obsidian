# 引数の設計

## この章の目的

**引数の数・形・意味** を設計する章です。  
Parameter Object、フラグ引数の問題、出力引数の回避、リファクタリング実践を学びます。

---

## 1. 引数の数 — 0〜2 が理想、3 以上は要検討

Clean Code では **引数は少ないほどよい** とされます。

| 引数の数 | 評価 |
|----------|------|
| 0（niladic） | 理想。状態を持つメソッドや、コンテキストが明確なとき |
| 1（monadic） | よくある |
| 2（dyadic） | 許容範囲 |
| 3 以上 | **要検討** — Parameter Object を検討 |

```javascript
// 3 引数以上 → オブジェクト化を検討
function createUser(name, email, age, address, phone) { /* ... */ }
```

---

## 2. Parameter Object — 引数の塊をオブジェクト化

**Parameter Object** は、関連する引数を 1 つのオブジェクトにまとめるパターンです。

```javascript
// Before
function sendInvoice(to, subject, body, cc, bcc, template) { /* ... */ }

// After
function sendInvoice(options) {
  const { to, subject, body, cc, bcc, template } = options;
  /* ... */
}

// または型・クラスで
class InvoiceMailOptions {
  constructor(to, subject, body) { /* ... */ }
}
```

**メリット**: 引数追加時のシグネチャ変更が少ない、名前付きで呼び出せる、バリデーションを 1 か所に集約できる。

---

## 3. フラグ引数（boolean）の問題

**フラグ引数** は、1 つの関数が **2 つの異なる処理** をすることを示すサインです。

```javascript
// 悪い例: フラグで分岐
function render(report, isHtml) {
  if (isHtml) { /* HTML 出力 */ }
  else { /* テキスト出力 */ }
}

// 良い例: 関数を分ける
function renderHtml(report) { /* ... */ }
function renderText(report) { /* ... */ }
```

フラグ引数は **SRP 違反** の兆候です（[[02_関心の分離と単一責任]]）。

---

## 4. 出力引数（副作用で値を返す）の回避

**出力引数** とは、引数として渡したオブジェクトを **関数内で変更** して結果を返す手法です。

```javascript
// 悪い例: 出力引数（C 言語的）
function fillResult(input, result) {
  result.total = input.price * input.qty;
}

// 良い例: 戻り値で返す
function calculateTotal(input) {
  return input.price * input.qty;
}
```

戻り値で返す方が **読みやすく・テストしやすい** です。複数値はオブジェクトや配列で返します。

---

## 5. 引数リストのリファクタリング実践

**Introduce Parameter Object** の手順:

1. 3 個以上の関連引数を特定
2. 新しいクラスまたは型を定義
3. 引数を 1 オブジェクトに置き換え
4. 呼び出し側を更新
5. テストで振る舞いが同じことを確認

```javascript
// 段階的に
function search(query, page, pageSize, sortBy, sortOrder) { /* ... */ }

// → SearchCriteria オブジェクトへ
function search(criteria) {
  const { query, page, pageSize, sortBy, sortOrder } = criteria;
}
```

詳細は [[付録D_リファクタリング技法早見表]] を参照。

## まとめ

- 引数 0〜2 が理想。3 以上は Parameter Object を検討
- フラグ引数は関数分割のサイン
- 出力引数より戻り値
- Introduce Parameter Object で段階的に改善
