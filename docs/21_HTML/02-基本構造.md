## 🏗️ HTMLドキュメントの基本構造

すべてのHTMLファイルは以下の基本構造を持ちます：

```html
<!DOCTYPE html>
<html lang="ja">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>ページのタイトル</title>
</head>
<body>
    <!-- ここにページの内容を書きます -->
</body>
</html>
```

---

## 📋 各要素の説明

### 1. DOCTYPE宣言
```html
<!DOCTYPE html>
```
- HTML5を使用することを宣言
- ファイルの最初に必ず記述

### 2. html要素
```html
<html lang="ja">
```
- HTMLドキュメントのルート要素
- `lang="ja"`で日本語ページであることを指定

### 3. head要素
```html
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>ページのタイトル</title>
</head>
```

#### head要素の内容：
- **meta charset="UTF-8"**: 文字エンコーディングを指定
- **meta name="viewport"**: モバイル表示の設定
- **title**: ブラウザのタブに表示されるタイトル

### 4. body要素
```html
<body>
    <!-- ページの内容 -->
</body>
```
- 実際にブラウザに表示される内容を記述

## 💻 最初のHTMLファイルを作成しよう

### 手順1：ファイルの作成
1. テキストエディタを開く
2. 新しいファイルを作成
3. 以下のコードを入力

```html
<!DOCTYPE html>
<html lang="ja">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>私の最初のWebページ</title>
</head>
<body>
    <h1>こんにちは！</h1>
    <p>これは私の最初のHTMLページです。</p>
</body>
</html>
```

### 手順2：ファイルの保存
- ファイル名：`index.html`
- 文字エンコーディング：UTF-8

### 手順3：ブラウザで確認
- 保存したファイルをダブルクリック
- ブラウザでWebページが表示される

## 🔍 HTMLタグの基本ルール

### 1. 開始タグと終了タグ
```html
<タグ名>内容</タグ名>
```

### 2. 自己終了タグ
```html
<タグ名 />
```

### 3. 属性の記述
```html
<タグ名 属性名="値">内容</タグ名>
```

---

## ⚠️ よくある間違い

### 1. DOCTYPE宣言の忘れ
```html
<!-- 間違い -->
<html>
<!-- 正しい -->
<!DOCTYPE html>
<html>
```

### 2. 文字エンコーディングの指定忘れ
```html
<!-- 間違い -->
<head>
    <title>タイトル</title>
</head>
<!-- 正しい -->
<head>
    <meta charset="UTF-8">
    <title>タイトル</title>
</head>
```

### 3. タグの閉じ忘れ
```html
<!-- 間違い -->
<h1>見出し
<p>段落
<!-- 正しい -->
<h1>見出し</h1>
<p>段落</p>
```
