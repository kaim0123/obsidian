# 第4章：段落とテキスト

## 📖 この章で学ぶこと

- 段落タグ（p）の使い方
- テキストの装飾タグ
- 改行とスペースの扱い
- コメントの書き方

---

## 📝 段落タグ（p）

段落タグは、**テキストを段落として表現するためのHTMLタグ**です。

### 基本的な使い方
```html
<p>これは段落です。</p>
<p>これは別の段落です。</p>
```

### 段落の特徴
- 段落間に自動的に余白が追加される
- 段落内では改行が無視される
- 意味のあるまとまりで使用する

---

## 🔤 テキストの装飾タグ

### 1. 太字（strong, b）
```html
<strong>重要なテキスト</strong>
<b>太字のテキスト</b>
```
- `strong`: 意味的に重要なテキスト
- `b`: 見た目だけの太字

### 2. 斜体（em, i）
```html
<em>強調されたテキスト</em>
<i>斜体のテキスト</i>
```
- `em`: 意味的に強調されたテキスト
- `i`: 見た目だけの斜体

### 3. 下線（u）
```html
<u>下線付きテキスト</u>
```

### 4. 取り消し線（s, del）
```html
<s>取り消されたテキスト</s>
<del>削除されたテキスト</del>
```

### 5. マーク（mark）
```html
<mark>ハイライトされたテキスト</mark>
```

---

## 📄 改行とスペースの扱い

### 改行タグ（br）
```html
<p>1行目のテキスト<br>
2行目のテキスト</p>
```

### スペースの扱い
```html
<p>この文章では    複数のスペースが    1つにまとめられます</p>
```

### 整形済みテキスト（pre）
```html
<pre>
この文章では
改行やスペースが
そのまま表示されます
</pre>
```

---

## 💬 コメントの書き方

HTMLでは`<!-- -->`を使ってコメントを書くことができます：

```html
<!-- これはコメントです -->
<p>この段落は表示されます</p>

<!-- 
複数行の
コメントも
書けます
-->
```

### コメントの用途
- コードの説明
- 一時的な無効化
- セクションの区切り

---

## 💻 実践例

### 例1：ブログ記事
```html
<h1>今日の天気</h1>

<p>今日は<strong>晴れ</strong>で、気温は<em>25度</em>でした。</p>

<p>明日は<mark>雨の予報</mark>なので、傘を持って出かけることをお勧めします。</p>

<!-- 天気予報の情報 -->
<p>週末の天気：<br>
土曜日：曇り<br>
日曜日：晴れ</p>
```

### 例2：商品説明
```html
<h2>商品名</h2>

<p>この商品は<strong>高品質</strong>で<em>使いやすい</em>設計になっています。</p>

<p>通常価格：<s>¥10,000</s><br>
セール価格：<mark>¥8,000</mark></p>

<p>特徴：</p>
<pre>
• 軽量設計
• 耐久性抜群
• 簡単操作
</pre>
```

## ⚠️ よくある間違い

### 1. 段落の不適切な使用
```html
<!-- 間違い -->
<p>短い文章</p>
<p>短い文章</p>
<p>短い文章</p>

<!-- 正しい -->
<p>短い文章。短い文章。短い文章。</p>
```

### 2. 改行の乱用
```html
<!-- 間違い -->
<p>文章<br><br><br>文章</p>

<!-- 正しい -->
<p>文章</p>
<p>文章</p>
```

### 3. 装飾タグの不適切な使用
```html
<!-- 間違い -->
<p><strong><em><u>過度に装飾されたテキスト</u></em></strong></p>

<!-- 正しい -->
<p><strong>重要なテキスト</strong></p>
```

## 🎯 テキストタグの使い方のコツ

### 1. 意味を重視する
```html
<!-- 良い例 -->
<p>この商品は<strong>安全性</strong>を重視して設計されています。</p>

<!-- 悪い例 -->
<p>この商品は<b>安全性</b>を重視して設計されています。</p>
```

### 2. 適度な装飾
```html
<!-- 良い例 -->
<p>重要な<strong>ポイント</strong>と<em>補足情報</em>を明確に区別します。</p>

<!-- 悪い例 -->
<p><strong><em><u><mark>すべて装飾されたテキスト</mark></u></em></strong></p>
```

### 3. 読みやすさを意識
```html
<!-- 良い例 -->
<p>段落は適切な長さで区切り、読みやすさを重視します。</p>

<!-- 悪い例 -->
<p>非常に長い段落を一つのpタグで書くと、読みにくくなってしまいます。特にモバイルデバイスでは、長い段落はスクロールが必要になり、ユーザーにとって負担になります。そのため、適切な長さで段落を区切ることが重要です。</p>
```
