## 📊 テーブルとは？

テーブルは、**データを行と列に整理して表示するためのHTMLタグ**です。

### テーブルの基本構造
```html
<table>
    <tr>
        <td>セル1</td>
        <td>セル2</td>
    </tr>
    <tr>
        <td>セル3</td>
        <td>セル4</td>
    </tr>
</table>
```

---

## 🏗️ テーブルの要素

### table要素
テーブル全体を囲む要素です。

### tr要素（Table Row）
テーブルの行を表す要素です。

### td要素（Table Data）
テーブルのセル（データ）を表す要素です。

### th要素（Table Header）
テーブルのヘッダーセルを表す要素です。

## 🎯 テーブルの属性

### border属性
テーブルの境界線を指定します。

```html
<table border="1">
    <tr>
        <th>商品名</th>
        <th>価格</th>
    </tr>
    <tr>
        <td>りんご</td>
        <td>100円</td>
    </tr>
</table>
```

### width属性
テーブルの幅を指定します。

```html
<table border="1" width="400">
    <tr>
        <th>商品名</th>
        <th>価格</th>
    </tr>
    <tr>
        <td>りんご</td>
        <td>100円</td>
    </tr>
</table>
```

### cellpadding属性
セル内の余白を指定します。

```html
<table border="1" cellpadding="10">
    <tr>
        <th>商品名</th>
        <th>価格</th>
    </tr>
    <tr>
        <td>りんご</td>
        <td>100円</td>
    </tr>
</table>
```

### cellspacing属性
セル間の余白を指定します。

```html
<table border="1" cellspacing="5">
    <tr>
        <th>商品名</th>
        <th>価格</th>
    </tr>
    <tr>
        <td>りんご</td>
        <td>100円</td>
    </tr>
</table>
```

## 🔗 セルの結合

### 列の結合（colspan）
横方向にセルを結合します。

```html
<table border="1">
    <tr>
        <th colspan="2">商品情報</th>
    </tr>
    <tr>
        <td>りんご</td>
        <td>100円</td>
    </tr>
    <tr>
        <td>みかん</td>
        <td>80円</td>
    </tr>
</table>
```

### 行の結合（rowspan）
縦方向にセルを結合します。

```html
<table border="1">
    <tr>
        <th>カテゴリ</th>
        <th>商品名</th>
        <th>価格</th>
    </tr>
    <tr>
        <td rowspan="2">フルーツ</td>
        <td>りんご</td>
        <td>100円</td>
    </tr>
    <tr>
        <td>みかん</td>
        <td>80円</td>
    </tr>
</table>
```

### 複雑な結合
```html
<table border="1">
    <tr>
        <th rowspan="2">カテゴリ</th>
        <th colspan="2">商品情報</th>
    </tr>
    <tr>
        <th>商品名</th>
        <th>価格</th>
    </tr>
    <tr>
        <td rowspan="2">フルーツ</td>
        <td>りんご</td>
        <td>100円</td>
    </tr>
    <tr>
        <td>みかん</td>
        <td>80円</td>
    </tr>
</table>
```

## ⚠️ よくある間違い

### 1. テーブル構造の間違い
```html
<!-- 間違い -->
<table>
    <td>セル1</td>
    <td>セル2</td>
</table>

<!-- 正しい -->
<table>
    <tr>
        <td>セル1</td>
        <td>セル2</td>
    </tr>
</table>
```

### 2. 結合の計算間違い
```html
<!-- 間違い -->
<table border="1">
    <tr>
        <th colspan="2">ヘッダー</th>
        <td>セル</td>  <!-- 余分なセル -->
    </tr>
</table>

<!-- 正しい -->
<table border="1">
    <tr>
        <th colspan="2">ヘッダー</th>
    </tr>
    <tr>
        <td>セル1</td>
        <td>セル2</td>
    </tr>
</table>
```

### 3. レスポンシブ対応の忘れ
```html
<!-- 間違い -->
<table border="1" width="800">
    <!-- 幅が固定でモバイルで見にくい -->
</table>

<!-- 正しい -->
<div style="overflow-x: auto;">
    <table border="1" style="min-width: 600px;">
        <!-- スクロール可能 -->
    </table>
</div>
```

## 🎯 テーブルの使い方のコツ

### 1. 適切なヘッダーの使用
```html
<!-- 良い例 -->
<table>
    <tr>
        <th>商品名</th>
        <th>価格</th>
    </tr>
    <tr>
        <td>りんご</td>
        <td>100円</td>
    </tr>
</table>

<!-- 悪い例 -->
<table>
    <tr>
        <td><strong>商品名</strong></td>
        <td><strong>価格</strong></td>
    </tr>
    <tr>
        <td>りんご</td>
        <td>100円</td>
    </tr>
</table>
```

### 2. 適切な結合の使用
```html
<!-- 良い例 -->
<table>
    <tr>
        <th colspan="2">商品情報</th>
    </tr>
    <tr>
        <td>りんご</td>
        <td>100円</td>
    </tr>
</table>

<!-- 悪い例 -->
<table>
    <tr>
        <th>商品情報</th>
        <th></th>  <!-- 空のセル -->
    </tr>
    <tr>
        <td>りんご</td>
        <td>100円</td>
    </tr>
</table>
```

### 3. レスポンシブ対応
```html
<!-- 良い例 -->
<div style="overflow-x: auto;">
    <table style="min-width: 500px;">
        <!-- テーブル内容 -->
    </table>
</div>

<!-- 悪い例 -->
<table width="800">
    <!-- 固定幅でモバイルで見にくい -->
</table>
```
