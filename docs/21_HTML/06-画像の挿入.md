# 第6章：画像の挿入

## 📖 この章で学ぶこと

- 画像タグ（img）の基本

- 画像のサイズ調整
- レスポンシブ画像

---

## 🖼️ 画像タグ（img）とは？

画像タグは、**Webページに画像を表示するためのHTMLタグ**です。

### 基本的な使い方
```html
<img src="画像ファイルのパス" alt="代替テキスト">
```

---

## 📁 画像ファイルの指定方法

### 同じフォルダ内の画像
```html
<img src="photo.jpg" alt="写真">
```

### サブフォルダ内の画像
```html
<img src="images/photo.jpg" alt="写真">
```

### 上位フォルダの画像
```html
<img src="../images/photo.jpg" alt="写真">
```

### 外部の画像（URL）
```html
<img src="https://example.com/image.jpg" alt="外部画像">
```

---

## 🎯 画像の属性

### src属性（必須）
画像ファイルのパスを指定します。

### alt属性（推奨）
画像が表示できない場合や、スクリーンリーダーで読み上げられる代替テキストを指定します。

```html
<img src="cat.jpg" alt="かわいい猫の写真">
```

### width属性とheight属性
画像の幅と高さを指定します。

```html
<img src="photo.jpg" alt="写真" width="300" height="200">
```

### title属性
マウスを乗せた時に表示される説明文を指定します。

```html
<img src="photo.jpg" alt="写真" title="美しい風景写真">
```

---

## 📏 画像のサイズ調整

### 幅のみ指定（高さは自動調整）
```html
<img src="photo.jpg" alt="写真" width="300">
```

### 高さのみ指定（幅は自動調整）
```html
<img src="photo.jpg" alt="写真" height="200">
```

### 幅と高さを両方指定
```html
<img src="photo.jpg" alt="写真" width="300" height="200">
```

### パーセンテージで指定
```html
<img src="photo.jpg" alt="写真" width="50%">
```

---

## 📱 レスポンシブ画像

### 基本的なレスポンシブ画像
```html
<img src="photo.jpg" alt="写真" style="max-width: 100%; height: auto;">
```

### 複数の画像サイズを用意
```html
<img src="photo-small.jpg" 
     srcset="photo-small.jpg 300w, photo-medium.jpg 600w, photo-large.jpg 900w"
     sizes="(max-width: 600px) 300px, (max-width: 900px) 600px, 900px"
     alt="写真">
```

---

## 🖼️ 画像の種類と形式

### よく使われる画像形式

#### JPEG（.jpg, .jpeg）
- 写真に適している
- ファイルサイズが小さい
- 透明度をサポートしない

#### PNG（.png）
- 透明度をサポート
- ファイルサイズが大きい
- ロゴやアイコンに適している

#### GIF（.gif）
- アニメーションをサポート
- 色数が限られている
- ファイルサイズが小さい

#### WebP（.webp）
- 新しい形式
- 高圧縮率
- ブラウザの対応状況に注意

## 💻 実践例

### 例1：シンプルな画像表示
```html
<h1>私の写真</h1>
<img src="my-photo.jpg" alt="私の写真" width="400">
<p>これは私の写真です。</p>
```

### 例2：レスポンシブ画像
```html
<div class="image-container">
    <img src="landscape.jpg" 
         alt="美しい風景" 
         style="max-width: 100%; height: auto;">
</div>
```

### 例3：画像ギャラリー
```html
<div class="gallery">
    <img src="photo1.jpg" alt="写真1" width="200" height="150">
    <img src="photo2.jpg" alt="写真2" width="200" height="150">
    <img src="photo3.jpg" alt="写真3" width="200" height="150">
</div>
```

### 例4：ロゴ画像
```html
<header>
    <img src="logo.png" alt="会社ロゴ" width="150" height="50">
    <nav>
        <a href="index.html">ホーム</a>
        <a href="about.html">会社概要</a>
    </nav>
</header>
```

## ⚠️ よくある間違い

### 1. alt属性の忘れ
```html
<!-- 間違い -->
<img src="photo.jpg">

<!-- 正しい -->
<img src="photo.jpg" alt="写真の説明">
```

### 2. ファイルパスの間違い
```html
<!-- 間違い -->
<img src="photo.jpg" alt="写真">  <!-- ファイルが存在しない -->

<!-- 正しい -->
<img src="images/photo.jpg" alt="写真">
```

### 3. 不適切なalt属性
```html
<!-- 間違い -->
<img src="photo.jpg" alt="画像">

<!-- 正しい -->
<img src="photo.jpg" alt="美しい夕日">
```

---

## 🎯 画像の使い方のコツ

### 1. 適切なalt属性を設定
```html
<!-- 良い例 -->
<img src="product.jpg" alt="赤いTシャツ">

<!-- 悪い例 -->
<img src="product.jpg" alt="商品画像">
```

### 2. 適切なサイズを指定
```html
<!-- 良い例 -->
<img src="photo.jpg" alt="写真" width="300">

<!-- 悪い例 -->
<img src="large-photo.jpg" alt="写真">  <!-- 大きな画像をそのまま表示 -->
```

### 3. レスポンシブ対応
```html
<!-- 良い例 -->
<img src="photo.jpg" alt="写真" style="max-width: 100%; height: auto;">

<!-- 悪い例 -->
<img src="photo.jpg" alt="写真" width="800">  <!-- モバイルで見にくい -->
```
