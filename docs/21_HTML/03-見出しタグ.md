# 第3章：見出しタグ

## 📖 この章で学ぶこと

- 見出しタグの種類と使い方
- 見出しの階層構造
- 適切な見出しの使い方

---

## 📝 見出しタグとは？

見出しタグは、**Webページのタイトルやセクションの見出しを表現するためのHTMLタグ**です。

見出しタグには6つのレベル（h1〜h6）があり、数字が小さいほど重要度が高くなります。

---

## 🏷️ 見出しタグの種類

### h1タグ（最重要見出し）
```html
<h1>メインタイトル</h1>
```
- ページで最も重要な見出し
- 通常、1ページに1つだけ使用
- 最も大きなフォントサイズで表示

### h2タグ（大見出し）
```html
<h2>セクションのタイトル</h2>
```
- 主要なセクションの見出し
- h1の下位に配置

### h3タグ（中見出し）
```html
<h3>サブセクションのタイトル</h3>
```
- h2の下位に配置
- より詳細な分類に使用

### h4〜h6タグ（小見出し）
```html
<h4>小さな見出し</h4>
<h5>さらに小さな見出し</h5>
<h6>最も小さな見出し</h6>
```
- より細かい分類に使用
- 通常はh4までがよく使われる

---

## 📊 見出しの階層構造

見出しは階層構造で使用することが重要です：

```html
<h1>プログラミング入門</h1>

<h2>HTMLの基礎</h2>
<h3>HTMLとは</h3>
<h3>HTMLの構造</h3>

<h2>CSSの基礎</h2>
<h3>CSSとは</h3>
<h3>セレクタの使い方</h3>
<h4>クラスセレクタ</h4>
<h4>IDセレクタ</h4>
```

### 階層構造のルール
1. **順序を飛ばさない**（h1→h3は避ける）
2. **論理的な構造にする**
3. **適切なレベルを選択する**

---

## 💻 実践例

### 例1：ブログ記事の構造
```html
<h1>今日の料理レシピ</h1>

<h2>材料</h2>
<h3>主材料</h3>
<h3>調味料</h3>

<h2>作り方</h2>
<h3>下準備</h3>
<h3>調理手順</h3>
<h4>1. 材料の準備</h4>
<h4>2. 調理開始</h4>
```

### 例2：企業サイトの構造
```html
<h1>株式会社サンプル</h1>

<h2>会社概要</h2>
<h3>企業理念</h3>
<h3>沿革</h3>

<h2>サービス</h2>
<h3>Web制作</h3>
<h3>システム開発</h3>
```

## ⚠️ よくある間違い

### 1. 見出しレベルの飛び越し
```html
<!-- 間違い -->
<h1>タイトル</h1>
<h3>見出し</h3>  <!-- h2を飛ばしている -->

<!-- 正しい -->
<h1>タイトル</h1>
<h2>見出し</h2>
<h3>見出し</h3>
```

### 2. 見出しの乱用
```html
<!-- 間違い -->
<h1>タイトル</h1>
<h1>別のタイトル</h1>  <!-- h1を複数使用 -->

<!-- 正しい -->
<h1>メインタイトル</h1>
<h2>別のタイトル</h2>
```

### 3. 見出しの不適切な使用
```html
<!-- 間違い -->
<h1>これは見出しではありません</h1>

<!-- 正しい -->
<p>これは段落です</p>
```

---

## 🎯 見出しタグの使い方のコツ

### 1. 内容を簡潔に
```html
<!-- 良い例 -->
<h2>HTMLの基本構造</h2>

<!-- 悪い例 -->
<h2>HTMLの基本構造について詳しく説明します</h2>
```

### 2. キーワードを含める
```html
<!-- 良い例 -->
<h2>HTML見出しタグの使い方</h2>

<!-- 悪い例 -->
<h2>使い方</h2>
```

### 3. 一貫性を保つ
```html
<!-- 良い例 -->
<h2>HTMLの基礎</h2>
<h2>CSSの基礎</h2>
<h2>JavaScriptの基礎</h2>
```
