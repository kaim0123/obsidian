---

## 📝 フォームとは？

フォームは、**ユーザーから情報を入力してもらうためのHTMLタグ**です。

### フォームの基本構造
```html
<form action="送信先URL" method="送信方法">
    <!-- フォームの内容 -->
    <input type="submit" value="送信">
</form>
```

---

## 🏗️ フォームの要素

### form要素
フォーム全体を囲む要素です。

### input要素
ユーザーが入力するフィールドを作成します。

### label要素
入力フィールドの説明ラベルを表示します。

### button要素
ボタンを作成します。

---

## 📋 基本的なフォーム

### シンプルなフォーム
```html
<form action="/submit" method="post">
    <label for="name">名前：</label>
    <input type="text" id="name" name="name">
    
    <label for="email">メールアドレス：</label>
    <input type="email" id="email" name="email">
    
    <input type="submit" value="送信">
</form>
```

### フォームの属性

#### action属性
フォームの送信先URLを指定します。

#### method属性
フォームの送信方法を指定します。
- `get`: URLにパラメータを付けて送信
- `post`: データを隠して送信

## 🎯 入力フィールドの種類

### テキスト入力
```html
<!-- 通常のテキスト -->
<input type="text" name="username" placeholder="ユーザー名を入力">

<!-- パスワード -->
<input type="password" name="password" placeholder="パスワードを入力">

<!-- メールアドレス -->
<input type="email" name="email" placeholder="メールアドレスを入力">

<!-- 数字 -->
<input type="number" name="age" min="0" max="120" placeholder="年齢を入力">

<!-- 電話番号 -->
<input type="tel" name="phone" placeholder="電話番号を入力">

<!-- URL -->
<input type="url" name="website" placeholder="URLを入力">
```

### 選択フィールド
```html
<!-- チェックボックス -->
<input type="checkbox" name="hobby" value="reading" id="reading">
<label for="reading">読書</label>

<input type="checkbox" name="hobby" value="sports" id="sports">
<label for="sports">スポーツ</label>

<!-- ラジオボタン -->
<input type="radio" name="gender" value="male" id="male">
<label for="male">男性</label>

<input type="radio" name="gender" value="female" id="female">
<label for="female">女性</label>
```

### ドロップダウン
```html
<label for="country">国を選択：</label>
<select name="country" id="country">
    <option value="">選択してください</option>
    <option value="japan">日本</option>
    <option value="usa">アメリカ</option>
    <option value="uk">イギリス</option>
</select>
```

### テキストエリア
```html
<label for="message">メッセージ：</label>
<textarea name="message" id="message" rows="5" cols="40" placeholder="メッセージを入力してください"></textarea>
```

### ファイルアップロード
```html
<label for="file">ファイルを選択：</label>
<input type="file" name="file" id="file">
```

### 日付と時刻
```html
<!-- 日付 -->
<input type="date" name="birthday" id="birthday">

<!-- 時刻 -->
<input type="time" name="meeting" id="meeting">

<!-- 日時 -->
<input type="datetime-local" name="event" id="event">
```

## 🎨 フォームのスタイリング

### 基本的なスタイリング
```html
<form style="max-width: 400px; margin: 0 auto;">
    <div style="margin-bottom: 15px;">
        <label for="name" style="display: block; margin-bottom: 5px;">名前：</label>
        <input type="text" id="name" name="name" style="width: 100%; padding: 8px; border: 1px solid #ccc;">
    </div>
    
    <div style="margin-bottom: 15px;">
        <label for="email" style="display: block; margin-bottom: 5px;">メールアドレス：</label>
        <input type="email" id="email" name="email" style="width: 100%; padding: 8px; border: 1px solid #ccc;">
    </div>
    
    <input type="submit" value="送信" style="background-color: #007bff; color: white; padding: 10px 20px; border: none; cursor: pointer;">
</form>
```

## ✅ フォームの検証

### 必須フィールド
```html
<input type="text" name="name" required>
```

### パターンマッチング
```html
<!-- 電話番号の形式 -->
<input type="tel" name="phone" pattern="[0-9]{3}-[0-9]{4}-[0-9]{4}" placeholder="000-0000-0000">

<!-- 郵便番号の形式 -->
<input type="text" name="postal" pattern="[0-9]{3}-[0-9]{4}" placeholder="000-0000">
```

### 最小・最大値
```html
<!-- 年齢（0-120歳） -->
<input type="number" name="age" min="0" max="120">

<!-- 文字数制限 -->
<input type="text" name="username" minlength="3" maxlength="20">
```

## ⚠️ よくある間違い

### 1. labelとinputの関連付け
```html
<!-- 間違い -->
<label>名前：</label>
<input type="text" name="name">

<!-- 正しい -->
<label for="name">名前：</label>
<input type="text" id="name" name="name">
```

### 2. フォームの送信先の指定忘れ
```html
<!-- 間違い -->
<form>
    <input type="text" name="name">
    <input type="submit" value="送信">
</form>

<!-- 正しい -->
<form action="/submit" method="post">
    <input type="text" name="name">
    <input type="submit" value="送信">
</form>
```

### 3. 適切なinput typeの選択
```html
<!-- 間違い -->
<input type="text" name="email">

<!-- 正しい -->
<input type="email" name="email">
```

## 🎯 フォームの使い方のコツ

### 1. 適切なinput typeの使用
```html
<!-- 良い例 -->
<input type="email" name="email" placeholder="example@email.com">
<input type="tel" name="phone" placeholder="000-0000-0000">
<input type="date" name="birthday">

<!-- 悪い例 -->
<input type="text" name="email">
<input type="text" name="phone">
<input type="text" name="birthday">
```

### 2. 分かりやすいラベル
```html
<!-- 良い例 -->
<label for="username">ユーザー名（3-20文字）：</label>
<input type="text" id="username" name="username" minlength="3" maxlength="20">

<!-- 悪い例 -->
<label for="username">名前：</label>
<input type="text" id="username" name="username">
```

### 3. 適切な検証
```html
<!-- 良い例 -->
<input type="email" name="email" required>
<input type="password" name="password" minlength="8" required>

<!-- 悪い例 -->
<input type="text" name="email">
<input type="text" name="password">
```
