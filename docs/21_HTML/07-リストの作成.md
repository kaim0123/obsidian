---

## 📋 リストとは？

リストは、**関連する項目を整理して表示するためのHTMLタグ**です。

HTMLには3種類のリストがあります：
1. **順序付きリスト（ol）** - 番号付きのリスト
2. **順序なしリスト（ul）** - 箇条書きのリスト
3. **定義リスト（dl）** - 用語と説明のリスト

---

## 🔢 順序付きリスト（ol）

順序付きリストは、**番号が自動的に付くリスト**です。

### 基本的な使い方
```html
<ol>
    <li>最初の項目</li>
    <li>2番目の項目</li>
    <li>3番目の項目</li>
</ol>
```

### 表示結果
1. 最初の項目
2. 2番目の項目
3. 3番目の項目

### 属性の指定
```html
<!-- 数字で開始 -->
<ol type="1">
    <li>項目1</li>
    <li>項目2</li>
</ol>

<!-- アルファベットで開始 -->
<ol type="A">
    <li>項目A</li>
    <li>項目B</li>
</ol>

<!-- 小文字アルファベットで開始 -->
<ol type="a">
    <li>項目a</li>
    <li>項目b</li>
</ol>

<!-- ローマ数字で開始 -->
<ol type="I">
    <li>項目I</li>
    <li>項目II</li>
</ol>

<!-- 開始番号を指定 -->
<ol start="5">
    <li>項目5</li>
    <li>項目6</li>
</ol>
```

## 📝 順序なしリスト（ul）

順序なしリストは、**箇条書きで表示されるリスト**です。

### 基本的な使い方
```html
<ul>
    <li>項目1</li>
    <li>項目2</li>
    <li>項目3</li>
</ul>
```

### 表示結果
• 項目1
• 項目2
• 項目3

### 属性の指定
```html
<!-- 円形のマーカー（デフォルト） -->
<ul type="disc">
    <li>項目1</li>
    <li>項目2</li>
</ul>

<!-- 四角形のマーカー -->
<ul type="square">
    <li>項目1</li>
    <li>項目2</li>
</ul>

<!-- 中抜き円のマーカー -->
<ul type="circle">
    <li>項目1</li>
    <li>項目2</li>
</ul>
```

---

## 📚 定義リスト（dl）

定義リストは、**用語とその説明をペアで表示するリスト**です。

### 基本的な使い方
```html
<dl>
    <dt>HTML</dt>
    <dd>HyperText Markup Languageの略で、Webページを作成するためのマークアップ言語です。</dd>
    
    <dt>CSS</dt>
    <dd>Cascading Style Sheetsの略で、Webページのスタイルを定義する言語です。</dd>
    
    <dt>JavaScript</dt>
    <dd>Webページに動的な機能を追加するためのプログラミング言語です。</dd>
</dl>
```

### 表示結果
**HTML**
HyperText Markup Languageの略で、Webページを作成するためのマークアップ言語です。

**CSS**
Cascading Style Sheetsの略で、Webページのスタイルを定義する言語です。

**JavaScript**
Webページに動的な機能を追加するためのプログラミング言語です。

## 🔗 ネストしたリスト

リストの中にリストを入れることができます。

### 順序なしリストのネスト
```html
<ul>
    <li>フルーツ
        <ul>
            <li>りんご</li>
            <li>みかん</li>
            <li>バナナ</li>
        </ul>
    </li>
    <li>野菜
        <ul>
            <li>にんじん</li>
            <li>ブロッコリー</li>
            <li>トマト</li>
        </ul>
    </li>
</ul>
```

### 順序付きリストのネスト
```html
<ol>
    <li>準備
        <ol>
            <li>材料を用意する</li>
            <li>道具を準備する</li>
        </ol>
    </li>
    <li>調理
        <ol>
            <li>材料を切る</li>
            <li>火にかける</li>
        </ol>
    </li>
</ol>
```

### 混合リスト
```html
<ol>
    <li>朝の準備
        <ul>
            <li>起床</li>
            <li>洗顔</li>
            <li>朝食</li>
        </ul>
    </li>
    <li>通勤
        <ul>
            <li>電車に乗る</li>
            <li>会社に到着</li>
        </ul>
    </li>
</ol>
```

## 💻 実践例

### 例1：レシピの手順
```html
<h1>カレーの作り方</h1>

<ol>
    <li>材料を準備する
        <ul>
            <li>肉（300g）</li>
            <li>玉ねぎ（2個）</li>
            <li>にんじん（2本）</li>
            <li>カレールー（1箱）</li>
        </ul>
    </li>
    <li>野菜を切る</li>
    <li>肉を炒める</li>
    <li>野菜を加える</li>
    <li>水を加えて煮込む</li>
    <li>カレールーを溶かす</li>
</ol>
```

### 例2：ナビゲーションメニュー
```html
<nav>
    <ul>
        <li><a href="index.html">ホーム</a></li>
        <li><a href="about.html">会社概要</a>
            <ul>
                <li><a href="about.html#history">沿革</a></li>
                <li><a href="about.html#mission">企業理念</a></li>
            </ul>
        </li>
        <li><a href="products.html">商品</a></li>
        <li><a href="contact.html">お問い合わせ</a></li>
    </ul>
</nav>
```

### 例3：用語集
```html
<h1>プログラミング用語集</h1>

<dl>

    <dd>Webページの構造を定義するマークアップ言語</dd>
    
    <dt>CSS</dt>

</dl>
```

## ⚠️ よくある間違い

### 1. リスト項目の不適切な使用
```html
<!-- 間違い -->
<ul>
    項目1
    項目2
    項目3
</ul>

<!-- 正しい -->
<ul>
    <li>項目1</li>
    <li>項目2</li>
    <li>項目3</li>
</ul>
```

### 2. ネストの構造の間違い
```html
<!-- 間違い -->
<ul>
    <li>項目1</li>
    <ul>
        <li>サブ項目</li>
    </ul>
</ul>

<!-- 正しい -->
<ul>
    <li>項目1
        <ul>
            <li>サブ項目</li>
        </ul>
    </li>
</ul>
```

### 3. 定義リストの不適切な使用
```html
<!-- 間違い -->
<dl>
    <dt>項目1</dt>
    <dt>項目2</dt>
    <dd>説明</dd>
</dl>

<!-- 正しい -->
<dl>
    <dt>項目1</dt>
    <dd>説明1</dd>
    <dt>項目2</dt>
    <dd>説明2</dd>
</dl>
```

## 🎯 リストの使い方のコツ

### 1. 適切なリストの選択
```html
<!-- 手順や順序が重要な場合 -->
<ol>
    <li>最初のステップ</li>
    <li>2番目のステップ</li>
</ol>

<!-- 関連項目の列挙 -->
<ul>
    <li>項目1</li>
    <li>項目2</li>
</ul>

<!-- 用語と説明 -->
<dl>
    <dt>用語</dt>
    <dd>説明</dd>
</dl>
```

### 2. 一貫性を保つ
```html
<!-- 良い例 -->
<ul>
    <li>りんご</li>
    <li>みかん</li>
    <li>バナナ</li>
</ul>

<!-- 悪い例 -->
<ul>
    <li>りんご</li>
    <p>みかん</p>
    <li>バナナ</li>
</ul>
```

### 3. 適切なネスト
```html
<!-- 良い例 -->
<ul>
    <li>フルーツ
        <ul>
            <li>りんご</li>
            <li>みかん</li>
        </ul>
    </li>
</ul>

<!-- 悪い例 -->
<ul>
    <li>フルーツ</li>
    <ul>
        <li>りんご</li>
        <li>みかん</li>
    </ul>
</ul>
```
