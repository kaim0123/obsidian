# 3-5. イベント処理（onClick/onChange）

## 🎯 この章で学ぶこと

- onClick / onChange / onSubmit の使い方
- イベントハンドラに引数を渡す書き方
- 「event オブジェクト」の中身

---

## 📖 概念の説明

### イベントとは

ユーザーの操作（クリック、入力、送信など）を検知する仕組み。

| HTMLイベント | JSXでの書き方 |
| --- | --- |
| `onclick` | `onClick` |
| `onchange` | `onChange` |
| `onsubmit` | `onSubmit` |
| `oninput` | `onInput` |
| `onkeydown` | `onKeyDown` |

→ **キャメルケース**で書きます。

### 値は「関数」を渡す

```jsx
<button onClick={handleClick}>クリック</button>
```

`handleClick` は関数。クリックされると呼ばれます。

---

## 💻 onClick

### 基本

```jsx
function App() {
  function handleClick() {
    alert('クリックされた');
  }
  return <button onClick={handleClick}>クリック</button>;
}
```

### インラインで書く（短い処理）

```jsx
<button onClick={() => alert('クリック')}>クリック</button>
```

### 引数を渡したいとき

```jsx
function deleteItem(id) {
  console.log(`${id}を削除`);
}

// ❌ NG：呼び出してしまう（クリック前に発動）
<button onClick={deleteItem(1)}>削除</button>

// ✅ アロー関数で囲む
<button onClick={() => deleteItem(1)}>削除</button>
```

---

## 💻 onChange（input）

### テキスト入力

```jsx
function Search() {
  const [text, setText] = useState('');

  return (
    <input
      type="text"
      value={text}
      onChange={(e) => setText(e.target.value)}
      placeholder="検索..."
    />
  );
}
```

`e.target.value` で**入力値**を取れる。

### チェックボックス

```jsx
const [checked, setChecked] = useState(false);

<input
  type="checkbox"
  checked={checked}
  onChange={(e) => setChecked(e.target.checked)}
/>
```

`e.target.checked` でチェック状態。

### セレクトボックス

```jsx
const [color, setColor] = useState('red');

<select value={color} onChange={(e) => setColor(e.target.value)}>
  <option value="red">赤</option>
  <option value="blue">青</option>
</select>
```

## 💻 onSubmit（フォーム送信）

```jsx
function Form() {
  const [name, setName] = useState('');

  function handleSubmit(e) {
    e.preventDefault(); // ★ デフォルトのページ遷移を止める
    console.log(name);
  }

  return (
    <form onSubmit={handleSubmit}>
      <input value={name} onChange={(e) => setName(e.target.value)} />
      <button type="submit">送信</button>
    </form>
  );
}
```

`e.preventDefault()` を忘れると、ブラウザがフォーム送信して**ページ全体がリロード**する。

---

## 📦 event オブジェクト

イベントハンドラの第1引数が `event`（慣習で `e`）。

```jsx
<input onChange={(e) => {
  console.log(e.target.value);     // 値
  console.log(e.target.name);       // name属性
  console.log(e.type);              // 'change'
  console.log(e.currentTarget);     // ハンドラを付けた要素
}} />
```

| プロパティ | 意味 |
| --- | --- |
| `e.target` | イベントが発生した要素 |
| `e.currentTarget` | イベントハンドラが付けられた要素 |
| `e.preventDefault()` | デフォルト動作を止める |
| `e.stopPropagation()` | 親への伝播を止める |

## 💻 よく使うパターン集

### 親へ通知（onClickをpropsで渡す）

```jsx
function Button({ onClick, children }) {
  return <button onClick={onClick}>{children}</button>;
}

<Button onClick={() => alert('Hi')}>クリック</Button>
```

### ボタンが連続クリックされるのを防ぐ

```jsx
const [submitting, setSubmitting] = useState(false);

async function handleSubmit() {
  if (submitting) return; // 二重防止
  setSubmitting(true);
  try {
    await sendData();
  } finally {
    setSubmitting(false);
  }
}

<button onClick={handleSubmit} disabled={submitting}>
  {submitting ? '送信中...' : '送信'}
</button>
```

詳しくは [[8-8-送信フローの状態管理]]。

### キー入力（Enterで送信）

```jsx
<input
  onKeyDown={(e) => {
    if (e.key === 'Enter') handleSubmit();
  }}
/>
```

## 📋 イベント名クイックリファレンス（旧 `07-events` 章より）

| イベント名 | 説明 |
| --- | --- |
| `onClick` | クリック |
| `onChange` | 入力値の変更 |
| `onSubmit` | フォーム送信 |
| `onMouseOver` / `onMouseOut` | マウスが乗った / 離れた |
| `onKeyDown` など | キー操作（`onKeyUp`, `onKeyPress`） |
| `onFocus` / `onBlur` | フォーカス取得 / 喪失 |

HTML の `onclick` ではなく、**キャメルケース**（`onClick`）で渡す。

---

## ❌ よくある間違い

### 関数を呼び出してしまう

```jsx
// ❌ レンダー時に即実行
<button onClick={alert('Hi')}>

// ✅ 関数を渡す
<button onClick={() => alert('Hi')}>
```

### `e.preventDefault()` 忘れ

```jsx
// ❌ ページがリロードされる
<form onSubmit={() => console.log('送信')}>

// ✅
<form onSubmit={(e) => { e.preventDefault(); console.log('送信'); }}>
```

### onChangeにvalueを付けない（uncontrolled）

```jsx
// △ 動くけど React的には推奨しない
<input onChange={(e) => setText(e.target.value)} />

// ✅ valueも紐づけてcontrolledにする
<input value={text} onChange={(e) => setText(e.target.value)} />
```

詳しくは [[3-6-フォーム入力の基本]]。

---

## ✅ ベストプラクティス

1. ハンドラ名は **`handle〇〇`**（handleClick, handleSubmit）
2. 引数を渡すときは **アロー関数**で囲む
3. **onSubmitでは preventDefault**
4. **連続クリックを止める**（disabled + フラグ）
5. ハンドラの中身が長くなったら**関数に抽出**

## 🔬 実践演習

「いいねボタン」を作ってください。

要件：

- 押すたびにカウントが増える
- ハートのアイコンの色が変わる（押すと赤）
- 連続クリック禁止のため、押した瞬間に一度disabledにして、500ms後に解除

---

## 📝 まとめ

- イベントはキャメルケース（onClick, onChangeなど）
- 値は「関数」を渡す。引数を渡すときはアロー関数で
- フォーム送信は preventDefault を忘れない
- e.target.value / e.target.checked で値を取る
