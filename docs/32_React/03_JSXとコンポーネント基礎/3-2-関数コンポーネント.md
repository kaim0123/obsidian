# 3-2. 関数コンポーネント（props/再利用）

## 🎯 この章で学ぶこと

- 関数コンポーネントの作り方
- propsで「外から値を受け取る」仕組み
- コンポーネントを再利用するメリット

---

## 📖 概念の説明

### コンポーネントとは

**「画面の部品」**。Reactでは画面を小さな部品に分けて作ります。

例：

- ヘッダー
- ボタン
- 商品カード
- 検索ボックス

各部品が「**関数**」になっているのが関数コンポーネントです。

### 関数コンポーネントの最小形

```jsx
function Greeting() {
  return <h1>こんにちは</h1>;
}
```

ルール：

- **大文字始まり**の名前（`greeting`はNG、`Greeting`がOK）
- 戻り値はJSX（または `null`）

### コンポーネントを使う

```jsx
function App() {
  return (
    <div>
      <Greeting />
      <Greeting />
    </div>
  );
}
```

`<Greeting />` のようにHTMLタグのように呼びます。何回でも使い回せる。

---

## 📁 ファイルに分ける（import / export）

別ファイルにすると再利用とテストがしやすい（旧 `03-components` 章より）。

1. 例：`src/components/Welcome.jsx` を作成
2. コンポーネントを定義し、末尾で `export default Welcome;`
3. 使う側で `import Welcome from './components/Welcome';`

```jsx
// Welcome.jsx
function Welcome() {
  return (
    <div>
      <h1>ようこそ！</h1>
      <p>Reactの世界へ</p>
    </div>
  );
}

export default Welcome;
```

```jsx
// App.jsx
import Welcome from './components/Welcome';

function App() {
  return (
    <div>
      <Welcome />
    </div>
  );
}
```

CSS を当てるときは `import './Welcome.css';` をコンポーネント側に書く。

### フォルダ構成の例

```
src/
├── components/
│   ├── Header.jsx
│   ├── Footer.jsx
│   └── Button.jsx
├── App.jsx
└── main.jsx
```

コンポーネント名は **パスカルケース**、ファイル名も揃えると迷わない。

---

## 📎 レイアウトの組み合わせ例

ページを Header / Main / Footer に分けるパターン。

```jsx
function Header() {
  return (
    <header>
      <h1>マイアプリ</h1>
      <nav>
        <a href="/">ホーム</a>
        <a href="/about">会社概要</a>
      </nav>
    </header>
  );
}

function Main() {
  return (
    <main>
      <h2>メインコンテンツ</h2>
      <p>ここにコンテンツが入ります</p>
    </main>
  );
}

function Footer() {
  return (
    <footer>
      <p>&copy; 2026 マイアプリ</p>
    </footer>
  );
}

function App() {
  return (
    <div>
      <Header />
      <Main />
      <Footer />
    </div>
  );
}
```

## 💻 props（プロップス）：外から値を受け取る

### 基本

`props` は、親が子に渡す**引数**のようなもの。

```jsx
function Greeting({ name }) {
  return <h1>こんにちは、{name}さん</h1>;
}

// 使う側
<Greeting name="太郎" />
<Greeting name="花子" />
```

→ 表示：

```text
こんにちは、太郎さん
こんにちは、花子さん
```

### 複数のpropsを渡す

```jsx
function Profile({ name, age, job }) {
  return (
    <div>
      <h2>{name}（{age}歳）</h2>
      <p>職業: {job}</p>
    </div>
  );
}

// 使う側
<Profile name="太郎" age={25} job="エンジニア" />
```

ポイント：

- 文字列は `name="太郎"`
- それ以外（数字、配列、オブジェクト、関数など）は `{ }` で囲む：`age={25}`

### propsで関数を渡す（コールバック）

```jsx
function Button({ label, onClick }) {
  return <button onClick={onClick}>{label}</button>;
}

// 使う側
<Button
  label="保存"
  onClick={() => alert('保存しました')}
/>
```

子は親から渡された関数を呼ぶだけ。実際の処理は親が決める。

### children も props の一種

```jsx
function Card({ title, children }) {
  return (
    <div className="card">
      <h2>{title}</h2>
      <div>{children}</div>
    </div>
  );
}

// 使う側
<Card title="お知らせ">
  <p>新機能をリリースしました！</p>
</Card>
```

`{children}` の場所に `<p>` が入ります。

## 📎 propsをもう一歩（旧 `05-props` から統合）

### デフォルト値

省略されたときの表示を決めます。

```jsx
function Greeting({ name = 'ゲスト' }) {
  return <h1>こんにちは、{name}さん！</h1>;
}

// <Greeting name="太郎" /> → こんにちは、太郎さん！
// <Greeting />            → こんにちは、ゲストさん！
```

```jsx
function UserCard({
  name = '名無し',
  age = 0,
  email = 'no-email@example.com',
}) {
  return (
    <div>
      <h2>{name}</h2>
      <p>年齢: {age}歳</p>
      <p>メール: {email}</p>
    </div>
  );
}
```

### オブジェクト・配列をまとめて渡す

```jsx
function UserProfile({ user }) {
  return (
    <div>
      <h2>{user.name}</h2>
      <p>年齢: {user.age}歳</p>
      <p>趣味: {user.hobbies.join('、')}</p>
    </div>
  );
}

// <UserProfile user={{ name: '太郎', age: 25, hobbies: ['読書', '旅行'] }} />
```

```jsx
function TodoList({ todos }) {
  return (
    <ul>
      {todos.map((todo, i) => (
        <li key={i}>{todo}</li>
      ))}
    </ul>
  );
}
```

リストでは可能なら **安定した `id` を `key` に**（[[3-4-リストレンダリングとkey]]）。

### 欠損に強い表示（任意 props）

```jsx
function UserCard({ name, age, email }) {
  return (
    <div>
      <h2>{name}</h2>
      {age != null && age !== '' && <p>年齢: {age}歳</p>}
      {email && <p>メール: {email}</p>}
    </div>
  );
}
```

## 💻 再利用の威力

### 同じ部品を何回も使える

```jsx
function ProductCard({ name, price }) {
  return (
    <div>
      <h3>{name}</h3>
      <p>{price}円</p>
    </div>
  );
}

function App() {
  return (
    <div>
      <ProductCard name="りんご" price={150} />
      <ProductCard name="みかん" price={100} />
      <ProductCard name="ぶどう" price={500} />
    </div>
  );
}
```

`ProductCard` を直す = 全カードが直る。コピペ地獄を防げます。

### 配列から作る（mapと組み合わせる）

```jsx
const products = [
  { id: 1, name: 'りんご', price: 150 },
  { id: 2, name: 'みかん', price: 100 },
];

function App() {
  return (
    <div>
      {products.map((p) => (
        <ProductCard key={p.id} name={p.name} price={p.price} />
      ))}
    </div>
  );
}
```

→ 詳しくは [[3-4-リストレンダリングとkey]]

## ❌ よくある間違い

### 小文字始まりの名前

```jsx
function greeting() { return <h1>...</h1>; }
// ❌ HTMLタグだとReactが解釈してしまう
```

→ ✅ 大文字始まり：`function Greeting()`。

### propsを直接書き換える

```jsx
function User({ user }) {
  user.name = '新しい名前'; // ❌ propsは読み取り専用
  return <p>{user.name}</p>;
}
```

→ ✅ 親に変更を依頼するか、自分でstateを持つ。

### propsの渡し方ミス

```jsx
// ❌ JSと値を区別していない
<Profile age=25 />        // 文字列の "25" になる
<Profile age=true />       // エラー

// ✅
<Profile age={25} />
<Profile age={true} />
```

### exportを忘れる

```jsx
// ❌ ファイルから取り出せない
function Button() { ... }
```

→ ✅ `export default Button;` または最初から `export default function Button() { ... }`

---

## ✅ ベストプラクティス

1. **コンポーネント名は大文字始まり**
2. **propsは読み取り専用**（書き換えない）
3. ファイル1つに**1コンポーネント**を基本に
4. **再利用を意識**して propsで違いを表現
5. props の数が多すぎたら**分割を検討**

## 🔬 実践演習

`Tag` コンポーネントを作ってください。

要件：

- props: `text`（文字列）, `color`（色名）
- 角丸の小さなラベルを表示
- `<Tag text="新着" color="red" />` のように使える
- 5種類くらい呼び出して並べてみる

---

## 📝 まとめ

- コンポーネント = 画面の部品（関数）
- 大文字始まりの名前
- propsで親から値を受け取る（読み取り専用）
- childrenはタグの中身、propsの一種
- 再利用とmapで強力になる
