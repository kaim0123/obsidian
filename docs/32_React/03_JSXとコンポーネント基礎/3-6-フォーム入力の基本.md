# 3-6. フォーム入力の基本（controlled/uncontrolled）

## 🎯 この章で学ぶこと

- 「controlled（制御）」と「uncontrolled（非制御）」の違い
- どちらを使うべきか
- フォーム要素ごとの典型的な書き方

---

## 📖 概念の説明

### Controlled（制御コンポーネント）

**入力値をReactのstateで管理する**書き方。

```jsx
const [name, setName] = useState('');

<input
  value={name}                                  // ★ stateと紐づけ
  onChange={(e) => setName(e.target.value)}    // ★ 入力でstateを更新
/>
```

- React が**真実の源**
- 値の検証・変換を入力中にできる

### Uncontrolled（非制御コンポーネント）

**ブラウザのDOMが値を持ち**、必要なときだけ取得する書き方。

```jsx
const inputRef = useRef(null);

function handleSubmit(e) {
  e.preventDefault();
  console.log(inputRef.current.value); // 必要時に取り出す
}

<input ref={inputRef} />
```

- DOM が**真実の源**
- 入力中はReactが介入しない

### どちらを使う？

| 状況 | 推奨 |
| --- | --- |
| **値を見ながら何かしたい**（リアルタイムバリデーション、文字数表示など） | controlled |
| **送信時だけ取れればいい**（パフォーマンスを意識） | uncontrolled |
| **シンプルなフォーム**（連絡先入力など） | controlled が無難 |

→ **迷ったらcontrolled**。Reactの考え方と相性が良い。

## 💻 Controlled の例

### テキスト入力

```jsx
function NameForm() {
  const [name, setName] = useState('');

  return (
    <div>
      <input
        value={name}
        onChange={(e) => setName(e.target.value)}
        placeholder="名前"
      />
      <p>こんにちは、{name || 'ゲスト'}さん</p>
      <p>{name.length}/20文字</p>
    </div>
  );
}
```

→ 入力するたび、画面下のメッセージと文字数がリアルタイム更新。

### チェックボックス

```jsx
const [agreed, setAgreed] = useState(false);

<label>
  <input
    type="checkbox"
    checked={agreed}
    onChange={(e) => setAgreed(e.target.checked)}
  />
  利用規約に同意する
</label>

<button disabled={!agreed}>送信</button>
```

### ラジオボタン

```jsx
const [size, setSize] = useState('M');

{['S', 'M', 'L'].map((s) => (
  <label key={s}>
    <input
      type="radio"
      name="size"
      value={s}
      checked={size === s}
      onChange={(e) => setSize(e.target.value)}
    />
    {s}
  </label>
))}
```

### セレクトボックス

```jsx
const [country, setCountry] = useState('jp');

<select value={country} onChange={(e) => setCountry(e.target.value)}>
  <option value="jp">日本</option>
  <option value="us">アメリカ</option>
</select>
```

### テキストエリア

```jsx
const [message, setMessage] = useState('');

<textarea
  value={message}
  onChange={(e) => setMessage(e.target.value)}
  rows={5}
/>
```

## 💻 複数フィールドを1つの state オブジェクトで（旧 `10-forms` 章より）

`name` 属性と `[name]: value` で、1つの `handleChange` にまとめる書き方。

```jsx
const [formData, setFormData] = useState({
  name: '',
  email: '',
  age: '',
});

const handleChange = (e) => {
  const { name, value } = e.target;
  setFormData((prev) => ({
    ...prev,
    [name]: value,
  }));
};

return (
  <form onSubmit={(e) => { e.preventDefault(); console.log(formData); }}>
    <input type="text" name="name" value={formData.name} onChange={handleChange} />
    <input type="email" name="email" value={formData.email} onChange={handleChange} />
    <input type="number" name="age" value={formData.age} onChange={handleChange} />
    <button type="submit">送信</button>
  </form>
);
```

バリデーション・送信中フラグ・API 連携などの深い話は [[8-6-フォームの状態設計]] 〜 [[8-8-送信フローの状態管理]] を参照。

## 💻 Uncontrolled の例

```jsx
function Form() {
  const nameRef = useRef(null);
  const emailRef = useRef(null);

  function handleSubmit(e) {
    e.preventDefault();
    const name = nameRef.current.value;
    const email = emailRef.current.value;
    console.log({ name, email });
  }

  return (
    <form onSubmit={handleSubmit}>
      <input ref={nameRef} defaultValue="太郎" />
      <input ref={emailRef} type="email" />
      <button type="submit">送信</button>
    </form>
  );
}
```

注意：`value` ではなく **`defaultValue`** を使う（最初の値を渡すだけ）。

## 💻 FormDataで一気に取る（uncontrolledの便利パターン）

```jsx
function handleSubmit(e) {
  e.preventDefault();
  const data = new FormData(e.currentTarget);
  // それぞれの input は name 属性で識別
  console.log({
    name: data.get('name'),
    email: data.get('email'),
  });
}

<form onSubmit={handleSubmit}>
  <input name="name" />
  <input name="email" />
  <button>送信</button>
</form>
```

→ stateで管理しない代わりに、送信時にまとめて取れる。シンプルなフォームに便利。詳しくは [[8-7-FormDataとcontrolled-uncontrolled]]。

## ❌ よくある間違い

### controlledで `value` を渡し忘れる

```jsx
// ❌ valueなしだと React が「これは uncontrolled？」と警告を出すことがある
<input onChange={(e) => setText(e.target.value)} />

// ✅
<input value={text} onChange={(e) => setText(e.target.value)} />
```

### controlled の初期値に `undefined` を入れる

```jsx
// ❌ undefined → null → 'a' のようになると React が警告
const [text, setText] = useState();

// ✅ 必ず初期値を入れる
const [text, setText] = useState('');
```

### uncontrolledに `value` を直接渡す

```jsx
// ❌ valueを渡すなら onChange も必須
<input value="initial" />
```

→ ✅ `defaultValue="initial"`

---

## ✅ ベストプラクティス

1. **迷ったらcontrolled**（Reactの考え方と相性◎）
2. パフォーマンスが重要なら **FormData + uncontrolled** も検討
3. **初期値は必ずセット**（`useState('')`）
4. **入力ごとにバリデーション**したいなら controlled
5. **大きなフォーム**は `react-hook-form` を検討（後の章）

ユーザー登録フォームを作る：

- 名前、メール、パスワード、利用規約チェック

---

## 📝 まとめ

- Controlled = state管理、Uncontrolled = DOM管理
- 迷ったらcontrolled
- 大きいフォームはFormDataやライブラリを検討
- 初期値は必ずセット
