# 11-3. イベント型（ChangeEventなど）

## 🎯 この章で学ぶこと

- イベントハンドラの型を正しく付ける
- 主要なイベント型（Change, Click, Submit, Keyboardなど）
- 型推論を活かす書き方

---

## 📖 主なイベント型

| イベント | 型 |
| --- | --- |
| onChange (input) | `ChangeEvent<HTMLInputElement>` |
| onChange (textarea) | `ChangeEvent<HTMLTextAreaElement>` |
| onChange (select) | `ChangeEvent<HTMLSelectElement>` |
| onClick (button) | `MouseEvent<HTMLButtonElement>` |
| onSubmit (form) | `FormEvent<HTMLFormElement>` |
| onKeyDown | `KeyboardEvent<HTMLInputElement>` |
| onFocus / onBlur | `FocusEvent<...>` |

---

## 💻 onChange

```tsx
import type { ChangeEvent } from 'react';

function NameInput() {
  const [name, setName] = useState('');

  function handleChange(e: ChangeEvent<HTMLInputElement>) {
    setName(e.target.value);
  }

  return <input value={name} onChange={handleChange} />;
}
```

### インラインなら型推論される

```tsx
<input
  value={name}
  onChange={(e) => setName(e.target.value)} // ← e は自動で型推論
/>
```

JSXに直接書くなら明示は不要。**別関数に切り出すと型を付ける**。

---

## 💻 onClick

```tsx
import type { MouseEvent } from 'react';

function handleClick(e: MouseEvent<HTMLButtonElement>) {
  console.log(e.currentTarget); // HTMLButtonElement
}

<button onClick={handleClick}>クリック</button>
```

---

## 💻 onSubmit

```tsx
import type { FormEvent } from 'react';

function handleSubmit(e: FormEvent<HTMLFormElement>) {
  e.preventDefault();
  const data = new FormData(e.currentTarget);
  console.log(data.get('name'));
}

<form onSubmit={handleSubmit}>
  <input name="name" />
  <button>送信</button>
</form>
```

---

## 💻 onKeyDown

```tsx
import type { KeyboardEvent } from 'react';

function handleKey(e: KeyboardEvent<HTMLInputElement>) {
  if (e.key === 'Enter') doSomething();
}

<input onKeyDown={handleKey} />
```

---

## 💻 SyntheticEvent の汎用型

特定の要素に縛らない場合：

```tsx
import type { SyntheticEvent } from 'react';

function handle(e: SyntheticEvent) {
  e.preventDefault();
}
```

または、要素は明示しないけど一般的なイベント：

```tsx
function handleAny(e: Event) { ... }
```

---

## 💻 onChange の値が string とは限らない

```tsx
function NumberInput() {
  const [num, setNum] = useState(0);

  return (
    <input
      type="number"
      value={num}
      onChange={(e) => setNum(Number(e.target.value))} // string → number 変換
    />
  );
}
```

`e.target.value` は**常にstring**。数値や日付は変換が必要。

---

## 💻 ハンドラ型の prop 渡し

```tsx
type FormProps = {
  onSubmit: (e: FormEvent<HTMLFormElement>) => void;
  onChange: (e: ChangeEvent<HTMLInputElement>) => void;
};
```

または値ベース（推奨）：

```tsx
type FormProps = {
  onSubmit: (data: { name: string; email: string }) => void;
  onChange: (value: string) => void;
};
```

→ 値ベースの方が**呼び出し側の自由度が高い**。

---

## 💻 標準HTMLハンドラ型を利用

```tsx
import type { ChangeEventHandler, FormEventHandler } from 'react';

type Props = {
  onChange?: ChangeEventHandler<HTMLInputElement>;
  onSubmit?: FormEventHandler<HTMLFormElement>;
};
```

`...EventHandler<...>` で書けばタイプ少なく済む。

---

## 💻 ファイル input

```tsx
function FileUpload() {
  function handleChange(e: ChangeEvent<HTMLInputElement>) {
    const file = e.target.files?.[0];
    if (!file) return;
    console.log(file.name);
  }

  return <input type="file" onChange={handleChange} />;
}
```

`files` は **`FileList | null`**。

---

## 💻 currentTarget vs target

| | currentTarget | target |
| --- | --- | --- |
| 意味 | ハンドラを付けた要素 | イベント発生元 |
| 型 | 安全（指定通り） | EventTarget（型が広い） |

```tsx
function handle(e: MouseEvent<HTMLButtonElement>) {
  e.currentTarget.disabled = true;  // ✅ HTMLButtonElement
  e.target.disabled = true;          // ❌ EventTarget には disabled がない
}
```

→ 通常は `currentTarget` が使いやすい。

---

## ❌ よくある間違い

### `any` で逃げる

```ts
function handleChange(e: any) { ... }
```

→ ✅ 具体的な型を付ける。

### `e.target.value` を non-input で使う

```tsx
function handleClick(e: MouseEvent<HTMLDivElement>) {
  console.log(e.target.value); // ❌ DivにはvalueはNg
}
```

→ ✅ inputでだけ。

### 値の型変換忘れ

```tsx
<input type="number" onChange={(e) => setAge(e.target.value)} />
// age が string になる
```

→ ✅ `Number(e.target.value)`。

---

## ✅ ベストプラクティス

1. **インラインは型推論**を活かす
2. **別関数に切り出すなら型明示**
3. **値ベースのハンドラ**を作って自由度を上げる
4. **e.currentTarget**を優先
5. **数値・日付は変換**忘れずに

## 📝 まとめ

- ChangeEvent, MouseEvent, FormEvent などを使い分け
- インラインは推論、関数に切り出すと型付け
- e.target.value は string、変換必要な場合あり
- currentTarget を優先
