# 9-4. リスト最適化（windowing/virtualization）

## 🎯 この章で学ぶこと

- 大量リストが重くなる理由
- 仮想化（virtualization）の考え方
- react-window / @tanstack/react-virtual の使い方

---

## 📖 概念の説明

### 大量リストが重い理由

1000件・10000件のアイテムを表示すると：

- DOMノードが1万個以上
- スクロールで全部レイアウト計算
- メモリ使用量が増加

→ ブラウザが追いつかなくなる。

### 仮想化（windowing）とは

「**画面に映る分（+前後の余白）だけ実際にレンダーする**」テクニック。

```text
全データ：1000件
    ↓ 仮想化
画面：30件 + 上下5件ずつ余白
    ↓ スクロールに合わせて切り替え
```

DOMは数十個で済む。

## 💻 react-window

```bash
npm install react-window
```

```jsx
import { FixedSizeList } from 'react-window';

function BigList({ items }) {
  return (
    <FixedSizeList
      height={500}        // 表示エリアの高さ
      itemCount={items.length}
      itemSize={40}       // 各行の高さ
      width="100%"
    >
      {({ index, style }) => (
        <div style={style}>
          {items[index].name}
        </div>
      )}
    </FixedSizeList>
  );
}
```

ポイント：

- `style` を必ず適用（位置調整に使う）
- `itemSize` 固定なら FixedSizeList、可変なら VariableSizeList

### 可変サイズ

```jsx
import { VariableSizeList } from 'react-window';

const getItemSize = (index) => items[index].height;

<VariableSizeList itemSize={getItemSize} ...>
```

## 💻 @tanstack/react-virtual

より柔軟な仮想化ライブラリ。

```bash
npm install @tanstack/react-virtual
```

```jsx
import { useVirtualizer } from '@tanstack/react-virtual';

function BigList({ items }) {
  const parentRef = useRef(null);

  const virtualizer = useVirtualizer({
    count: items.length,
    getScrollElement: () => parentRef.current,
    estimateSize: () => 40,
  });

  return (
    <div ref={parentRef} style={{ height: 500, overflow: 'auto' }}>
      <div style={{ height: virtualizer.getTotalSize(), position: 'relative' }}>
        {virtualizer.getVirtualItems().map((vItem) => (
          <div
            key={vItem.key}
            style={{
              position: 'absolute',
              top: vItem.start,
              left: 0,
              width: '100%',
              height: vItem.size,
            }}
          >
            {items[vItem.index].name}
          </div>
        ))}
      </div>
    </div>
  );
}
```

→ react-windowより柔軟、テーブルやグリッドにも対応。

## 💡 別解：ページネーション

仮想化が複雑なら、**ページネーション**でデータを分ける手も。

```jsx
const [page, setPage] = useState(1);
const pageSize = 50;
const visible = items.slice((page - 1) * pageSize, page * pageSize);
```

→ 詳しくは [[16-6-検索-絞込-ソート-ページネーション]]。

### 無限スクロール

スクロール下端で次ページを取得する方式：

```jsx
const observer = useRef();
const lastItemRef = useCallback((node) => {
  if (observer.current) observer.current.disconnect();
  observer.current = new IntersectionObserver((entries) => {
    if (entries[0].isIntersecting) loadMore();
  });
  if (node) observer.current.observe(node);
}, [loadMore]);

return items.map((item, i) => (
  <Item ref={i === items.length - 1 ? lastItemRef : null} ... />
));
```

→ TanStack Query の `useInfiniteQuery` も便利。

## 💻 テーブルの仮想化

```jsx
import { useVirtualizer } from '@tanstack/react-virtual';

function VirtualTable({ rows }) {
  const parentRef = useRef(null);
  const virtualizer = useVirtualizer({
    count: rows.length,
    getScrollElement: () => parentRef.current,
    estimateSize: () => 32,
  });

  return (
    <div ref={parentRef} style={{ height: 600, overflow: 'auto' }}>
      <table>
        <thead>
          <tr><th>ID</th><th>名前</th></tr>
        </thead>
        <tbody style={{ height: virtualizer.getTotalSize(), position: 'relative' }}>
          {virtualizer.getVirtualItems().map((vItem) => {
            const row = rows[vItem.index];
            return (
              <tr key={row.id} style={{
                position: 'absolute',
                top: vItem.start,
                width: '100%',
                height: vItem.size,
              }}>
                <td>{row.id}</td>
                <td>{row.name}</td>
              </tr>
            );
          })}
        </tbody>
      </table>
    </div>
  );
}
```

## ❌ よくある間違い

### 仮想化しないで全件レンダー

→ 1000件以上は速度低下。仮想化を検討。

### 仮想化のサイズ計算ミス

→ 各アイテムの高さが正しくないとガタつく。estimateSize で近い値を返す。

### スクロール位置が消える

→ 状態管理 + URL同期で対応。

### keyを正しく付けない

→ スクロールでDOMが入れ替わるとき、keyが正しくないと中身がズレる。

---

## ✅ ベストプラクティス

1. **数百件以上なら仮想化**を検討
2. **react-window** か **@tanstack/react-virtual**
3. **ページネーション・無限スクロール**も選択肢
4. **TanStack Queryの useInfiniteQuery** で楽
5. アイテムサイズが固定なら FixedSizeList が最適

## 🔬 実践演習

10000件のリストを表示する：

- 通常レンダーで動作確認（重い）
- react-window で仮想化（軽い）
- 検索フィルタを足す
- スクロール位置を保存
