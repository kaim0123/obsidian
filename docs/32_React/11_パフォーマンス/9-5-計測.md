## 📖 計測の重要性

「**測ってから対策**」が鉄則。感覚でmemoを付けまくると逆効果になることも。

```text
計測 → ボトルネック特定 → 対策 → 再計測
```

このサイクルを繰り返すのが王道。

---

## 🛠 React DevTools Profiler

### 起動方法

1. ブラウザに **React Developer Tools** をインストール
2. F12 → 「Components」タブの隣に「Profiler」タブ
3. 録画ボタン（●）を押す
4. アプリを操作
5. 停止ボタン

### 表示の見方

```text
[Flamegraph]
 App (5.2ms)
  ├─ Header (0.5ms)
  ├─ Sidebar (1.8ms)
  └─ Main (2.9ms)
     └─ ItemList (2.1ms)
        ├─ Item (0.05ms)
        ├─ Item (0.05ms)
        └─ ... × 100
```

色：

- **青〜緑**：速い
- **黄〜オレンジ**：そこそこ
- **赤**：重い

「赤いコンポーネント」がボトルネック候補。

### Ranked タブ

「**実行時間が長い順**」にソートして表示。すぐに重い箇所が見える。

## 💻 Profiler API（プログラム的に計測）

```jsx
import { Profiler } from 'react';

function onRender(id, phase, actualDuration) {
  console.log({ id, phase, actualDuration });
}

<Profiler id="MyApp" onRender={onRender}>
  <App />
</Profiler>
```

`actualDuration` が実際にかかった時間（ms）。本番でも使えますが、ホットパスでは外す。

## 🛠 Chrome DevTools Performance タブ

### 起動

1. F12 → Performance タブ
2. 録画ボタン → アプリ操作 → 停止
3. タイムラインが表示

### 注目するもの

- **Long Tasks**：50ms以上のタスク（ユーザー操作をブロック）
- **Scripting**：JS実行時間（Reactのレンダー含む）
- **Rendering**：レイアウト・描画
- **FPS**：1秒60フレームが理想（緑バー）

### Webvitals

- **LCP**（Largest Contentful Paint）：最大コンテンツ表示まで（2.5秒以内）
- **FID/INP**（Input Delay/Interaction to Next Paint）：操作の遅延（200ms以内）
- **CLS**（Cumulative Layout Shift）：レイアウトずれ（0.1以内）

## 💻 console.time / console.timeEnd

簡易計測：

```jsx
function handleSearch(query) {
  console.time('filter');
  const result = items.filter(...);
  console.timeEnd('filter');
  // → filter: 12.3ms
}
```

## 💻 Performance API

```jsx
performance.mark('fetch-start');
await fetch(...);
performance.mark('fetch-end');
performance.measure('fetch', 'fetch-start', 'fetch-end');

const measures = performance.getEntriesByName('fetch');
console.log(measures[0].duration);
```

ログ・分析サービスに送るときに使える。

## ❌ よくある間違い

### 開発モードで計測

→ 開発モードはStrictModeなどで遅い。**本番ビルド** (`npm run build && npm run preview`) で測る。

### 1回だけ測って結論

→ ばらつきがあるので **複数回測る**。

### 数値の単位を間違える

→ ms（ミリ秒）と s（秒）を確認。

### 「赤＝悪」と思い込む

→ 全体時間に対する比率を見る。1msが赤でも問題なし。

5. 再計測して比較
