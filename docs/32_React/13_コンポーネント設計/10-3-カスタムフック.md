# 10-3. カスタムフック（抽出の基準）

## 🎯 この章で学ぶこと

- カスタムフックの作り方とルール
- いつ抽出するか / しないか
- よく使う実用パターン

---

## 📖 概念の説明

### カスタムフックとは

「**`use`で始まる関数**」で、内部で他のフックを呼び出せるもの。

```jsx
function useCounter(initial = 0) {
  const [count, setCount] = useState(initial);
  const increment = () => setCount((c) => c + 1);
  const reset = () => setCount(initial);
  return { count, increment, reset };
}

// 使う側
function App() {
  const { count, increment, reset } = useCounter(0);
  return (
    <div>
      <p>{count}</p>
      <button onClick={increment}>+</button>
      <button onClick={reset}>Reset</button>
    </div>
  );
}
```

### ルール

1. **名前は `use` で始める**（フックの規則）
2. **コンポーネント or 別のカスタムフックの中でだけ呼ぶ**
3. **トップレベルで呼ぶ**（条件分岐・ループの中で呼ばない）

---

## 💡 抽出の判断基準

### ✅ 抽出する

- 同じロジックを2か所以上で使う
- ロジックが**20行以上**
- 「動詞」で名付けられる（fetch, debounce, toggle...）
- テストを書きたい
- 名前を付けて見通しを良くしたい

### ❌ 抽出しない

- 1か所しか使わない、かつ短い
- フックを使わない普通の関数で済む

## 💻 実用パターン集

### ① useToggle

```jsx
function useToggle(initial = false) {
  const [value, setValue] = useState(initial);
  const toggle = () => setValue((v) => !v);
  return [value, toggle];
}

// 使う
const [isOpen, toggleOpen] = useToggle();
<button onClick={toggleOpen}>{isOpen ? '閉じる' : '開く'}</button>
```

### ② useDebouncedValue

```jsx
function useDebouncedValue(value, delay = 500) {
  const [debounced, setDebounced] = useState(value);
  useEffect(() => {
    const id = setTimeout(() => setDebounced(value), delay);
    return () => clearTimeout(id);
  }, [value, delay]);
  return debounced;
}

// 使う
const [text, setText] = useState('');
const debouncedText = useDebouncedValue(text, 300);
```

### ③ useLocalStorage

```jsx
function useLocalStorage(key, initial) {
  const [value, setValue] = useState(() => {
    const stored = localStorage.getItem(key);
    return stored ? JSON.parse(stored) : initial;
  });
  useEffect(() => {
    localStorage.setItem(key, JSON.stringify(value));
  }, [key, value]);
  return [value, setValue];
}

// 使う
const [theme, setTheme] = useLocalStorage('theme', 'light');
```

### ④ useFetch

```jsx
function useFetch(url) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    const controller = new AbortController();
    setLoading(true);
    fetch(url, { signal: controller.signal })
      .then((r) => r.json())
      .then(setData)
      .catch((err) => {
        if (err.name !== 'AbortError') setError(err);
      })
      .finally(() => setLoading(false));
    return () => controller.abort();
  }, [url]);

  return { data, loading, error };
}
```

→ ただし、本格的なAPI管理は **TanStack Query** が便利（[[7-5-データ取得ライブラリ]]）。

### ⑤ usePrevious

```jsx
function usePrevious(value) {
  const ref = useRef();
  useEffect(() => {
    ref.current = value;
  });
  return ref.current;
}

// 使う
const prevCount = usePrevious(count);
```

### ⑥ useMediaQuery

```jsx
function useMediaQuery(query) {
  const [matches, setMatches] = useState(() => window.matchMedia(query).matches);
  useEffect(() => {
    const mql = window.matchMedia(query);
    const handler = (e) => setMatches(e.matches);
    mql.addEventListener('change', handler);
    return () => mql.removeEventListener('change', handler);
  }, [query]);
  return matches;
}

// 使う
const isMobile = useMediaQuery('(max-width: 600px)');
```

### ⑦ useOnClickOutside

```jsx
function useOnClickOutside(ref, handler) {
  useEffect(() => {
    function listener(e) {
      if (!ref.current || ref.current.contains(e.target)) return;
      handler(e);
    }
    document.addEventListener('mousedown', listener);
    return () => document.removeEventListener('mousedown', listener);
  }, [ref, handler]);
}

// 使う：モーダル外クリックで閉じる
const ref = useRef();
useOnClickOutside(ref, () => setOpen(false));
return <div ref={ref}>...</div>;
```

## 💻 戻り値の形式

### 配列（useState風）

```jsx
const [open, toggle] = useToggle();
```

→ **2つまで**ならこの形式が使いやすい。

### オブジェクト

```jsx
const { count, increment, reset } = useCounter();
```

→ 3つ以上、もしくは部分利用したいときに。

---

## ❌ よくある間違い

### `use` で始まらない

```jsx
function counter() { useState(0); } // ❌
```

→ ✅ `useCounter`。

### 条件付きで呼ぶ

```jsx
if (something) {
  useCounter(); // ❌
}
```

→ ✅ トップレベルで呼ぶ。

### コンポーネント内じゃない場所で呼ぶ

```jsx
const { count } = useCounter(); // ❌ 普通の関数の中
```

→ ✅ コンポーネント or 別のカスタムフックの中。

### useEffect忘れでメモリリーク

→ クリーンアップを必ず書く。

---

## ✅ ベストプラクティス

1. **`use` で始める**
2. **2回以上使うときに抽出**
3. **動詞名で表現**
4. **戻り値は配列 or オブジェクト**
5. **クリーンアップを忘れない**

---

## 📁 置き場所と「1ファイルに何を書くか」（実務の型）

### 置き場所の基本

- **共通フック**：`src/hooks/`（例：`useDebounce.ts`、`useLocalStorage.ts`）
- **機能専用フック**：`src/features/<feature>/hooks/`（例：`features/auth/hooks/useAuth.ts`）

（小規模なら最初は `src/hooks/` だけで十分。増えてきたら `features/` 側へ寄せます。）

### 1ファイルに書くことの目安

1. **ファイル名**：`use` から始める（例：`useUserList.ts`）
2. **export**：中心は `export function useUserList() { ... }` を1つ
3. **中身**：
   - `useState` で **状態**（ローディング、エラー、データ）
   - `useEffect` で **マウント時の取得**／**購読**（必要な場合）
   - イベント・操作関数は `useCallback` などで安定化（必要な場合）
4. **返す値**：コンポーネントが **使う最小限**（`{ data, loading, error, reload }` など）
5. **原則**：フックの呼び出しは **トップレベルのみ**（条件分岐・ループの中で呼ばない）

### 1ファイルに複数のフックを置く？

- 小規模なら **関連が強い** ものだけ同居もあり
- 迷ったら **1カスタムフック＝1ファイル** が探索しやすい

## 🔬 実践演習

`useWindowSize` を作る：

- 現在のウィンドウサイズ（width, height）を返す
- リサイズで自動更新
- アンマウントでリスナー解除

## 📝 まとめ

- カスタムフック = `use`で始まる、再利用可能なロジック
- ルール：トップレベルで呼ぶ、useから始める
- 2回以上使うときに抽出
- クリーンアップ忘れに注意
