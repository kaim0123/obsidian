# セッション管理機能

## 概要
セッション管理機能は、ユーザーの状態を維持し、認証情報やユーザーデータを安全に管理します。

## 基本機能

### セッション作成・維持
- **セッション開始** - ログイン時のセッション作成
- **セッション維持** - アクティビティに基づく延長
- **セッション終了** - ログアウト時のクリーンアップ

### セキュリティ機能
- **セッション固定攻撃対策** - セッションIDの再生成
- **CSRF対策** - トークンベースの保護
- **セッションタイムアウト** - 自動的なセッション終了

## 実装方法

### Node.js + Express での実装例
```javascript
const express = require('express');
const session = require('express-session');
const RedisStore = require('connect-redis')(session);

const app = express();

// セッション設定
app.use(session({
  store: new RedisStore({
    host: 'localhost',
    port: 6379,
    ttl: 86400 // 24時間
  }),
  secret: process.env.SESSION_SECRET,
  resave: false,
  saveUninitialized: false,
  cookie: {
    secure: process.env.NODE_ENV === 'production',
    httpOnly: true,
    maxAge: 24 * 60 * 60 * 1000 // 24時間
  }
}));

// セッション管理ミドルウェア
const sessionManager = (req, res, next) => {
  if (req.session.userId) {
    // セッション延長
    req.session.cookie.maxAge = 24 * 60 * 60 * 1000;
  }
  next();
};

app.use(sessionManager);
```

### React でのセッション管理
```javascript
import { createContext, useContext, useEffect, useState } from 'react';

const SessionContext = createContext();

export const SessionProvider = ({ children }) => {
  const [user, setUser] = useState(null);
  const [isLoading, setIsLoading] = useState(true);

  useEffect(() => {
    // セッション復元
    const restoreSession = async () => {
      try {
        const response = await fetch('/api/session');
        if (response.ok) {
          const userData = await response.json();
          setUser(userData);
        }
      } catch (error) {
        console.error('セッション復元エラー:', error);
      } finally {
        setIsLoading(false);
      }
    };

    restoreSession();
  }, []);

  const login = async (credentials) => {
    const response = await fetch('/api/login', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(credentials)
    });

    if (response.ok) {
      const userData = await response.json();
      setUser(userData);
    }
  };

  const logout = async () => {
    await fetch('/api/logout', { method: 'POST' });
    setUser(null);
  };

  return (
    <SessionContext.Provider value={{ user, login, logout, isLoading }}>
      {children}
    </SessionContext.Provider>
  );
};

export const useSession = () => useContext(SessionContext);
```

## セッションストレージの選択

### メモリベース
- **メリット**: 高速、シンプル
- **デメリット**: サーバー再起動で消失、スケーリング困難

### Redis
- **メリット**: 高速、永続化、スケーリング対応
- **デメリット**: 追加インフラが必要

### データベース
- **メリット**: 永続化、トランザクション対応
- **デメリット**: パフォーマンスの課題

## セキュリティ考慮事項

### セッションID管理
- 十分な長さとランダム性
- 定期的な再生成
- 安全なCookie設定

### セッション固定攻撃対策
```javascript
const regenerateSession = (req) => {
  return new Promise((resolve, reject) => {
    req.session.regenerate((err) => {
      if (err) reject(err);
      else resolve();
    });
  });
};
```

### CSRF対策
```javascript
const csrf = require('csurf');
const csrfProtection = csrf({ cookie: true });

app.use(csrfProtection);

// トークン取得エンドポイント
app.get('/api/csrf-token', (req, res) => {
  res.json({ csrfToken: req.csrfToken() });
});
```
