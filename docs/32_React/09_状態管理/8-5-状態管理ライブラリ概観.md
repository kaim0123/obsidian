## 💻 Zustand：最小コード

```bash
npm install zustand
```

```jsx
import { create } from 'zustand';

const useStore = create((set) => ({
  count: 0,
  increment: () => set((state) => ({ count: state.count + 1 })),
  reset: () => set({ count: 0 }),
}));

function Counter() {
  const { count, increment, reset } = useStore();
  return (
    <div>
      <p>{count}</p>
      <button onClick={increment}>+</button>
      <button onClick={reset}>Reset</button>
    </div>
  );
}
```

利点：

- **Provider不要**
- 1ファイル数行
- TypeScript と相性良し

### Selector で必要な部分だけ購読（再レンダー削減）

```jsx
const count = useStore((state) => state.count); // count だけ
const increment = useStore((state) => state.increment);
```

## 💻 Redux Toolkit：標準的な大規模向け

```bash
npm install @reduxjs/toolkit react-redux
```

### slice（reducer + actions）

```jsx
import { createSlice, configureStore } from '@reduxjs/toolkit';
import { Provider, useSelector, useDispatch } from 'react-redux';

const counterSlice = createSlice({
  name: 'counter',
  initialState: { value: 0 },
  reducers: {
    increment: (state) => { state.value += 1 }, // immer内蔵で書き換え風OK
    reset:     (state) => { state.value = 0 },
  },
});

export const { increment, reset } = counterSlice.actions;
export const store = configureStore({ reducer: { counter: counterSlice.reducer } });
```

### 利用

```jsx
function Counter() {
  const count = useSelector((s) => s.counter.value);
  const dispatch = useDispatch();
  return (
    <div>
      <p>{count}</p>
      <button onClick={() => dispatch(increment())}>+</button>
    </div>
  );
}

function App() {
  return <Provider store={store}><Counter /></Provider>;
}
```

利点：

- **DevTools が強力**（時間遡及デバッグ）
- 大規模で構造を保ちやすい
- ミドルウェア（thunk、saga）

## 💻 Jotai：atomベース

```bash
npm install jotai
```

```jsx
import { atom, useAtom } from 'jotai';

const countAtom = atom(0);

function Counter() {
  const [count, setCount] = useAtom(countAtom);
  return (
    <div>
      <p>{count}</p>
      <button onClick={() => setCount(count + 1)}>+</button>
    </div>
  );
}
```

利点：

- atomごとに細かく管理
- 派生atom（computed）が書きやすい

## 💡 選び方の指針

```text
状態の規模は？
  ├─ 小（個別のフォーム・モーダル）
  │   → useState / useReducer
  ├─ 中（アプリ全体で共有する状態がいくつか）
  │   → Zustand / Jotai
  └─ 大（複雑な業務ロジック、長期保守）
      → Redux Toolkit

サーバ状態の管理は？
  → TanStack Query（並用が一般的）
```

---

## ❌ よくある間違い

### サーバ状態をstoreに入れる

→ TanStack Query に任せる。store はクライアント状態用。

### Redux で書きすぎる

→ 小さなアプリに Redux はオーバーキル。Zustand から始める。

### Provider の入れ忘れ（Redux）

→ Zustand には不要。Reduxは必須。

### 1つのstoreに全部詰める

→ 関心ごとに slice や atom に分ける。

---

## ✅ ベストプラクティス

1. **小さく始める**（useState → Context → Zustand → Redux）
2. **サーバ状態と分離**（TanStack Query 並用）
3. **Selectorで必要な部分だけ購読**
4. TypeScript で型を活かす
5. **DevTools** を最初に設定
