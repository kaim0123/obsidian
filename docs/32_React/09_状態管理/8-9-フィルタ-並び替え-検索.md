# 8-9. フィルタ・並び替え・検索（表示条件の状態）

## 🎯 この章で学ぶこと

- 一覧画面でよく使う「表示条件」を state で管理する
- フィルタ・ソート・検索を組み合わせる設計
- URL に同期して、戻るボタンで条件が復元される実装

---

## 📖 概念の説明

### 一覧画面の3つの条件

| 条件 | 例 |
| --- | --- |
| **検索** | 商品名でフィルタ |
| **絞込（フィルタ）** | カテゴリ、価格範囲、在庫あり |
| **並び替え** | 新着順、価格安い順 |

これらは「**サーバから取った原データ + 表示条件**」の組み合わせで決まる。

---

## 💻 基本実装：クライアント側でフィルタ

```jsx
function ProductList({ allProducts }) {
  const [keyword, setKeyword] = useState('');
  const [category, setCategory] = useState('all');
  const [sort, setSort] = useState('new');

  // 派生値（state にしない）
  const filtered = useMemo(() => {
    let list = allProducts;
    if (keyword) {
      list = list.filter((p) => p.name.includes(keyword));
    }
    if (category !== 'all') {
      list = list.filter((p) => p.category === category);
    }
    if (sort === 'price-asc') list = [...list].sort((a, b) => a.price - b.price);
    if (sort === 'price-desc') list = [...list].sort((a, b) => b.price - a.price);
    if (sort === 'new') list = [...list].sort((a, b) => b.createdAt - a.createdAt);
    return list;
  }, [allProducts, keyword, category, sort]);

  return (
    <>
      <input value={keyword} onChange={(e) => setKeyword(e.target.value)} placeholder="検索" />

      <select value={category} onChange={(e) => setCategory(e.target.value)}>
        <option value="all">すべて</option>
        <option value="food">食品</option>
        <option value="book">書籍</option>
      </select>

      <select value={sort} onChange={(e) => setSort(e.target.value)}>
        <option value="new">新着順</option>
        <option value="price-asc">価格安い順</option>
        <option value="price-desc">価格高い順</option>
      </select>

      <ul>
        {filtered.map((p) => <li key={p.id}>{p.name}（{p.price}円）</li>)}
      </ul>
    </>
  );
}
```

ポイント：

- 条件は state で持つ
- `filtered` は state ではなく **派生値**（useMemo）

## 💻 サーバ側でフィルタ（大量データ向け）

データが大きい・サーバ側でクエリすべき場合：

```jsx
function ProductList() {
  const [keyword, setKeyword] = useState('');
  const [category, setCategory] = useState('all');

  const { data: products = [] } = useQuery({
    queryKey: ['products', keyword, category],
    queryFn: () => fetch(`/api/products?q=${keyword}&category=${category}`).then((r) => r.json()),
  });

  return (
    <>
      <input value={keyword} onChange={(e) => setKeyword(e.target.value)} />
      <select value={category} onChange={(e) => setCategory(e.target.value)}>...</select>
      <ul>{products.map((p) => <li key={p.id}>{p.name}</li>)}</ul>
    </>
  );
}
```

`queryKey` に条件を入れると、条件が変わるたび自動で再取得 + キャッシュ。

## 💡 デバウンス（連打を抑える）

検索キーワードをタイプするたびにAPIを叩くのは無駄。**500ms 入力が止まったら**叩く：

```jsx
function useDebounced(value, delay = 500) {
  const [debounced, setDebounced] = useState(value);
  useEffect(() => {
    const id = setTimeout(() => setDebounced(value), delay);
    return () => clearTimeout(id);
  }, [value, delay]);
  return debounced;
}

const debouncedKeyword = useDebounced(keyword, 500);

useQuery({
  queryKey: ['products', debouncedKeyword],
  queryFn: () => fetch(`/api/products?q=${debouncedKeyword}`).then((r) => r.json()),
});
```

## 💻 URLに同期する（戻るボタン対応）

`react-router-dom` の `useSearchParams` を使う：

```jsx
import { useSearchParams } from 'react-router-dom';

function ProductList() {
  const [params, setParams] = useSearchParams();
  const keyword = params.get('q') ?? '';
  const category = params.get('category') ?? 'all';

  function update(updates) {
    setParams((prev) => {
      const next = new URLSearchParams(prev);
      Object.entries(updates).forEach(([k, v]) => {
        if (v) next.set(k, v);
        else next.delete(k);
      });
      return next;
    });
  }

  return (
    <>
      <input
        value={keyword}
        onChange={(e) => update({ q: e.target.value })}
      />
      <select value={category} onChange={(e) => update({ category: e.target.value })}>
        ...
      </select>
    </>
  );
}
```

→ URLに状態が乗るので、**シェアできる、戻るで復元できる**。詳しくは [[6-5-URLと連動する状態]]。

## 💡 ページネーションと組み合わせる

```jsx
const [params, setParams] = useSearchParams();
const page = Number(params.get('page') ?? '1');

useQuery({
  queryKey: ['products', keyword, page],
  queryFn: () => fetch(`/api/products?q=${keyword}&page=${page}`).then((r) => r.json()),
  keepPreviousData: true, // ページ移動でちらつかない
});
```

## ❌ よくある間違い

### filteredItems を state にする

```jsx
const [items, setItems] = useState([]);
const [filtered, setFiltered] = useState([]); // ❌
```

→ ✅ 派生値は計算で（useMemo）。

### 検索のたびにAPI叩く（重い）

→ ✅ デバウンスを入れる。

### 並び替えで `sort` を直接使う

```jsx
items.sort(...); // 元配列を破壊
```

→ ✅ `[...items].sort(...)`。

### 条件をstate に持つだけでURLに残さない

→ 戻るボタンで条件が消える。**重要な条件はURLに**。

---

## ✅ ベストプラクティス

1. **条件をstateで管理**（filtered は派生値）
2. **デバウンス**で API 呼び出しを抑制
3. **URLに同期**（共有・戻るボタン）
4. **TanStack Queryの queryKey** に条件を含める
5. ページネーションは `keepPreviousData`

## 🔬 実践演習

商品一覧ページ：

- 検索（デバウンスあり）
- カテゴリ絞込
- 価格範囲（最小・最大）
- 並び替え（4種類）
- ページ切り替え
- すべてURLに同期

## 📝 まとめ

- 条件は state、結果は派生値
- 重い検索はデバウンス
- 重要な条件はURLに同期
- TanStack Query で再取得・キャッシュ
