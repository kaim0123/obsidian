## 📖 PWAとは

「**Progressive Web Apps**」＝ Webサイトをアプリのように扱える仕組み。

特徴：

- **オフラインでも動く**（Service Worker）
- **ホーム画面に追加**（manifest）
- **プッシュ通知**
- **インストールがApp Store不要**

```bash
npm install -D vite-plugin-pwa
```

## 💡 Service Worker の仕組み

ブラウザの裏側で動くJSワーカー。**ネットワークリクエストをインターセプト**できる。

```text
[ブラウザ] → [Service Worker] → [ネットワーク or キャッシュ]
```

→ オフライン中でも、キャッシュからレスポンスを返せる。

---

## 💻 キャッシュ戦略

### NetworkFirst（API向き）

```js
{ urlPattern: /api/, handler: 'NetworkFirst' }
```

→ まずネットワーク、ダメならキャッシュ。データの鮮度重視。

### CacheFirst（画像・フォント向き）

```js
{ urlPattern: /\.(png|jpg|woff2)$/, handler: 'CacheFirst' }
```

→ まずキャッシュ、なければネットワーク。速度重視。

### StaleWhileRevalidate（バランス）

```js
{ urlPattern: /\.css$/, handler: 'StaleWhileRevalidate' }
```

→ キャッシュを返しつつ、裏でネットワーク取得して更新。

## 💻 更新戦略

### autoUpdate（自動）

```js
VitePWA({ registerType: 'autoUpdate' });
```

→ 新しいSWが見つかると自動でインストール、次回読み込みで反映。

### prompt（ユーザーに確認）

```js
VitePWA({ registerType: 'prompt' });
```

```jsx
import { useRegisterSW } from 'virtual:pwa-register/react';

function App() {
  const { needRefresh, updateServiceWorker } = useRegisterSW({
    onRegistered: (r) => console.log('SW registered'),
    onRegisterError: (e) => console.error(e),
  });

  return needRefresh && (
    <div>
      新しいバージョンがあります
      <button onClick={() => updateServiceWorker(true)}>更新</button>
    </div>
  );
}
```

→ 「更新があります」と通知 → ユーザーがクリックで反映。

## 💻 インストールプロンプト

```jsx
function InstallButton() {
  const [deferredPrompt, setDeferredPrompt] = useState(null);

  useEffect(() => {
    function handler(e) {
      e.preventDefault();
      setDeferredPrompt(e);
    }
    window.addEventListener('beforeinstallprompt', handler);
    return () => window.removeEventListener('beforeinstallprompt', handler);
  }, []);

  if (!deferredPrompt) return null;

  return (
    <button onClick={async () => {
      deferredPrompt.prompt();
      const { outcome } = await deferredPrompt.userChoice;
      console.log(outcome); // 'accepted' or 'dismissed'
      setDeferredPrompt(null);
    }}>
      アプリをインストール
    </button>
  );
}
```

→ ユーザーが許可するとアプリのようにインストール。

## ❌ よくある間違い

### 古いSWが残ってキャッシュ汚染

→ DevToolsの Application → Service Workers → 「Update on reload」「Unregister」で対処。

### キャッシュ戦略を間違えてAPI古いまま

→ APIは NetworkFirst が無難。

### manifest のアイコンサイズ不足

→ 192px と 512px は必須。

### SW を https以外で動かそうとする

→ HTTPS（または localhost）でしか動かない。

4. **manifest にアイコン必須**

## 概要

この記事では、Webアプリケーションにネイティブアプリのような体験を提供する「PWA（Progressive Web App）」について、実践的な実装方法を詳しく解説します。初心者でも理解できるよう、基本的な概念から高度な実装まで段階的に説明します。

## PWAとは

PWA（Progressive Web App）は、Webアプリケーションにネイティブアプリのような機能と体験を提供する技術です。以下の特徴があります：

### PWAの主要特徴

1. **プログレッシブ**: すべてのブラウザで動作し、機能が向上する
2. **レスポンシブ**: あらゆるデバイスサイズに対応
3. **接続に依存しない**: Service Workerによるオフライン対応
4. **アプリライク**: ネイティブアプリのような体験
5. **常に最新**: 自動更新機能
6. **安全**: HTTPS必須
7. **発見可能**: 検索エンジンで発見可能
8. **再エンゲージ可能**: プッシュ通知など
9. **インストール可能**: ホーム画面に追加可能
10. **リンク可能**: URLで共有可能

## Service Worker の詳細実装

### 1. 基本的なService Worker

```javascript
// public/sw.js
const CACHE_VERSION = 'v1.0.0';
const CACHE_NAME = `pwa-cache-${CACHE_VERSION}`;
const API_CACHE_NAME = `pwa-api-cache-${CACHE_VERSION}`;

// キャッシュするリソース
const STATIC_CACHE_URLS = [
  '/',
  '/static/css/main.css',
  '/static/js/main.js',
  '/static/js/vendor.js',
  '/icons/icon-192x192.png',
  '/icons/icon-512x512.png',
  '/offline.html'
];

// インストール時の処理
self.addEventListener('install', (event) => {
  console.log('Service Worker installing...');
  
  event.waitUntil(
    caches.open(CACHE_NAME)
      .then((cache) => {
        console.log('Caching static resources');
        return cache.addAll(STATIC_CACHE_URLS);
      })
      .then(() => {
        // 新しいService Workerを即座にアクティブにする
        return self.skipWaiting();
      })
  );
});

// アクティベート時の処理
self.addEventListener('activate', (event) => {
  console.log('Service Worker activating...');
  
  event.waitUntil(
    caches.keys()
      .then((cacheNames) => {
        // 古いキャッシュを削除
        return Promise.all(
          cacheNames.map((cacheName) => {
            if (cacheName !== CACHE_NAME && cacheName !== API_CACHE_NAME) {
              console.log('Deleting old cache:', cacheName);
              return caches.delete(cacheName);
            }
          })
        );
      })
      .then(() => {
        // すべてのクライアントを制御下に置く
        return self.clients.claim();
      })
  );
});

// フェッチイベントの処理
self.addEventListener('fetch', (event) => {
  const { request } = event;
  const url = new URL(request.url);

  // 異なるオリジンのリクエストは処理しない
  if (url.origin !== location.origin) {
    return;
  }

  // キャッシュ戦略の選択
  if (request.method === 'GET') {
    if (url.pathname.startsWith('/api/')) {
      // APIリクエスト: ネットワークファースト
      event.respondWith(networkFirstStrategy(request, API_CACHE_NAME));
    } else if (isStaticResource(request)) {
      // 静的リソース: キャッシュファースト
      event.respondWith(cacheFirstStrategy(request, CACHE_NAME));
    } else {
      // HTMLページ: ストール・リバリデート
      event.respondWith(staleWhileRevalidateStrategy(request, CACHE_NAME));
    }
  }
});

// キャッシュファースト戦略
async function cacheFirstStrategy(request, cacheName) {
  const cache = await caches.open(cacheName);
  const cachedResponse = await cache.match(request);
  
  if (cachedResponse) {
    return cachedResponse;
  }

  try {
    const networkResponse = await fetch(request);
    if (networkResponse.ok) {
      cache.put(request, networkResponse.clone());
    }
    return networkResponse;
  } catch (error) {
    console.error('Network request failed:', error);
    throw error;
  }
}

// ネットワークファースト戦略
async function networkFirstStrategy(request, cacheName) {
  const cache = await caches.open(cacheName);
  
  try {
    const networkResponse = await fetch(request);
    if (networkResponse.ok) {
      cache.put(request, networkResponse.clone());
    }
    return networkResponse;
  } catch (error) {
    const cachedResponse = await cache.match(request);
    if (cachedResponse) {
      return cachedResponse;
    }
    
    // オフライン用のレスポンスを返す
    if (request.headers.get('accept')?.includes('application/json')) {
      return new Response(
        JSON.stringify({ error: 'オフラインです', offline: true }),
        {
          status: 503,
          headers: { 'Content-Type': 'application/json' }
        }
      );
    }
    
    throw error;
  }
}

// ストール・リバリデート戦略
async function staleWhileRevalidateStrategy(request, cacheName) {
  const cache = await caches.open(cacheName);
  const cachedResponse = await cache.match(request);
  
  // バックグラウンドで更新
  const fetchPromise = fetch(request).then((networkResponse) => {
    if (networkResponse.ok) {
      cache.put(request, networkResponse.clone());
    }
    return networkResponse;
  }).catch(() => {
    // ネットワークエラーの場合は何もしない
  });

  // キャッシュがあれば即座に返す
  return cachedResponse || fetchPromise;
}

// 静的リソースかどうかを判定
function isStaticResource(request) {
  const url = new URL(request.url);
  return url.pathname.match(/\.(js|css|png|jpg|jpeg|gif|svg|woff|woff2|ico)$/);
}
```

### 2. 高度なService Worker実装

```javascript
// public/sw-advanced.js
class AdvancedServiceWorker {
  constructor() {
    this.cacheVersion = 'v2.0.0';
    this.cacheNames = {
      static: `static-cache-${this.cacheVersion}`,
      dynamic: `dynamic-cache-${this.cacheVersion}`,
      api: `api-cache-${this.cacheVersion}`,
      images: `images-cache-${this.cacheVersion}`
    };
    
    this.cacheStrategies = {
      static: 'cache-first',
      dynamic: 'stale-while-revalidate',
      api: 'network-first',
      images: 'cache-first'
    };
  }

  // インストール処理
  async install() {
    console.log('Advanced Service Worker installing...');
    
    const cache = await caches.open(this.cacheNames.static);
    await cache.addAll(this.getStaticResources());
    
    await self.skipWaiting();
  }

  // アクティベート処理
  async activate() {
    console.log('Advanced Service Worker activating...');
    
    const cacheNames = await caches.keys();
    const oldCaches = cacheNames.filter(name => 
      !Object.values(this.cacheNames).includes(name)
    );
    
    await Promise.all(oldCaches.map(name => caches.delete(name)));
    await self.clients.claim();
  }

  // フェッチ処理
  async fetch(event) {
    const { request } = event;
    const url = new URL(request.url);

    if (url.origin !== location.origin) {
      return;
    }

    const strategy = this.getCacheStrategy(request);
    const cacheName = this.getCacheName(request);

    switch (strategy) {
      case 'cache-first':
        return this.cacheFirst(request, cacheName);
      case 'network-first':
        return this.networkFirst(request, cacheName);
      case 'stale-while-revalidate':
        return this.staleWhileRevalidate(request, cacheName);
      default:
        return fetch(request);
    }
  }

  // キャッシュ戦略を決定
  getCacheStrategy(request) {
    const url = new URL(request.url);
    
    if (url.pathname.startsWith('/api/')) {
      return this.cacheStrategies.api;
    }
    
    if (this.isStaticResource(request)) {
      return this.cacheStrategies.static;
    }
    
    if (this.isImage(request)) {
      return this.cacheStrategies.images;
    }
    
    return this.cacheStrategies.dynamic;
  }

  // キャッシュ名を決定
  getCacheName(request) {
    const url = new URL(request.url);
    
    if (url.pathname.startsWith('/api/')) {
      return this.cacheNames.api;
    }
    
    if (this.isImage(request)) {
      return this.cacheNames.images;
    }
    
    if (this.isStaticResource(request)) {
      return this.cacheNames.static;
    }
    
    return this.cacheNames.dynamic;
  }

  // 静的リソースかどうかを判定
  isStaticResource(request) {
    const url = new URL(request.url);
    return url.pathname.match(/\.(js|css|woff|woff2)$/);
  }

  // 画像かどうかを判定
  isImage(request) {
    const url = new URL(request.url);
    return url.pathname.match(/\.(png|jpg|jpeg|gif|svg|webp)$/);
  }

  // 静的リソースのリスト
  getStaticResources() {
    return [
      '/',
      '/static/css/main.css',
      '/static/js/main.js',
      '/static/js/vendor.js',
      '/icons/icon-192x192.png',
      '/icons/icon-512x512.png',
      '/offline.html'
    ];
  }

  // キャッシュファースト戦略
  async cacheFirst(request, cacheName) {
    const cache = await caches.open(cacheName);
    const cachedResponse = await cache.match(request);
    
    if (cachedResponse) {
      return cachedResponse;
    }

    try {
      const networkResponse = await fetch(request);
      if (networkResponse.ok) {
        cache.put(request, networkResponse.clone());
      }
      return networkResponse;
    } catch (error) {
      if (this.isImage(request)) {
        return this.getOfflineImage();
      }
      throw error;
    }
  }

  // ネットワークファースト戦略
  async networkFirst(request, cacheName) {
    const cache = await caches.open(cacheName);
    
    try {
      const networkResponse = await fetch(request);
      if (networkResponse.ok) {
        cache.put(request, networkResponse.clone());
      }
      return networkResponse;
    } catch (error) {
      const cachedResponse = await cache.match(request);
      if (cachedResponse) {
        return cachedResponse;
      }
      
      if (request.headers.get('accept')?.includes('application/json')) {
        return this.getOfflineAPIResponse();
      }
      
      throw error;
    }
  }

  // ストール・リバリデート戦略
  async staleWhileRevalidate(request, cacheName) {
    const cache = await caches.open(cacheName);
    const cachedResponse = await cache.match(request);
    
    const fetchPromise = fetch(request).then((networkResponse) => {
      if (networkResponse.ok) {
        cache.put(request, networkResponse.clone());
      }
      return networkResponse;
    }).catch(() => {
      // ネットワークエラーの場合は何もしない
    });

    return cachedResponse || fetchPromise;
  }

  // オフライン画像を返す
  getOfflineImage() {
    return new Response(
      '<svg xmlns="http://www.w3.org/2000/svg" width="200" height="200" viewBox="0 0 200 200"><rect width="200" height="200" fill="#f0f0f0"/><text x="100" y="100" text-anchor="middle" fill="#666">オフライン</text></svg>',
      {
        headers: { 'Content-Type': 'image/svg+xml' }
      }
    );
  }

  // オフラインAPIレスポンスを返す
  getOfflineAPIResponse() {
    return new Response(
      JSON.stringify({ 
        error: 'オフラインです', 
        offline: true,
        message: 'ネットワーク接続を確認してください'
      }),
      {
        status: 503,
        headers: { 'Content-Type': 'application/json' }
      }
    );
  }
}

// Service Workerインスタンス
const sw = new AdvancedServiceWorker();

// イベントリスナー

  event.waitUntil(sw.install());
});

self.addEventListener('activate', (event) => {
  event.waitUntil(sw.activate());
});

self.addEventListener('fetch', (event) => {
  event.respondWith(sw.fetch(event));
});
```

```javascript
// PWA状態管理フック
function usePWAStatus() {
  const [isInstalled, setIsInstalled] = useState(false);
  const [canInstall, setCanInstall] = useState(false);
  const [isOnline, setIsOnline] = useState(navigator.onLine);

  useEffect(() => {
    // インストール状態のチェック
    const checkInstallStatus = () => {
      const isStandalone = window.matchMedia('(display-mode: standalone)').matches;
      const isIOSStandalone = window.navigator.standalone === true;
      setIsInstalled(isStandalone || isIOSStandalone);
    };

    // オンライン状態の監視
    const handleOnline = () => setIsOnline(true);
    const handleOffline = () => setIsOnline(false);

    // インストールプロンプトの監視
    const handleBeforeInstallPrompt = (e) => {
      e.preventDefault();
      setCanInstall(true);
    };

    // イベントリスナーを追加
    window.addEventListener('beforeinstallprompt', handleBeforeInstallPrompt);
    window.addEventListener('online', handleOnline);
    window.addEventListener('offline', handleOffline);

    checkInstallStatus();

    return () => {
      window.removeEventListener('beforeinstallprompt', handleBeforeInstallPrompt);
      window.removeEventListener('online', handleOnline);
      window.removeEventListener('offline', handleOffline);
    };
  }, []);

  return { isInstalled, canInstall, isOnline };
}
```

### 1. プッシュ通知管理

```javascript
// プッシュ通知管理クラス
class PushNotificationManager {
  constructor() {
    this.registration = null;
    this.subscription = null;
    this.isSupported = 'Notification' in window && 'serviceWorker' in navigator;
  }

  // 通知許可をリクエスト
  async requestPermission() {
    if (!this.isSupported) {
      throw new Error('プッシュ通知はサポートされていません');
    }

    const permission = await Notification.requestPermission();
    
    if (permission === 'granted') {
      console.log('通知許可が得られました');
      return true;
    } else {
      console.log('通知許可が拒否されました');
      return false;
    }
  }

  // プッシュ通知を登録
  async registerPushNotification() {
    if (!this.isSupported) {
      throw new Error('プッシュ通知はサポートされていません');
    }

    // Service Workerの登録
    this.registration = await navigator.serviceWorker.ready;

    // プッシュ通知の購読
    this.subscription = await this.registration.pushManager.subscribe({
      userVisibleOnly: true,
      applicationServerKey: this.urlBase64ToUint8Array(
        process.env.REACT_APP_VAPID_PUBLIC_KEY
      )
    });

    // サーバーに購読情報を送信
    await this.sendSubscriptionToServer(this.subscription);

    return this.subscription;
  }

  // プッシュ通知の購読を解除
  async unsubscribe() {
    if (this.subscription) {
      await this.subscription.unsubscribe();
      this.subscription = null;
      
      // サーバーに購読解除を通知
      await this.sendUnsubscriptionToServer();
    }
  }

  // ローカル通知を表示
  showLocalNotification(title, options = {}) {
    if (!this.isSupported || Notification.permission !== 'granted') {
      return;
    }

    const notification = new Notification(title, {
      icon: '/icons/icon-192x192.png',
      badge: '/icons/icon-72x72.png',
      ...options
    });

    notification.onclick = () => {
      window.focus();
      notification.close();
    };

    return notification;
  }

  // サーバーに購読情報を送信
  async sendSubscriptionToServer(subscription) {
    try {
      const response = await fetch('/api/push/subscribe', {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json'
        },
        body: JSON.stringify(subscription)
      });

      if (!response.ok) {
        throw new Error('購読情報の送信に失敗しました');
      }

      console.log('購読情報をサーバーに送信しました');
    } catch (error) {
      console.error('購読情報送信エラー:', error);
      throw error;
    }
  }

  // サーバーに購読解除を通知
  async sendUnsubscriptionToServer() {
    try {
      await fetch('/api/push/unsubscribe', {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json'
        }
      });

      console.log('購読解除をサーバーに通知しました');
    } catch (error) {
      console.error('購読解除通知エラー:', error);
    }
  }

  // VAPIDキーを変換
  urlBase64ToUint8Array(base64String) {
    const padding = '='.repeat((4 - base64String.length % 4) % 4);
    const base64 = (base64String + padding)
      .replace(/-/g, '+')
      .replace(/_/g, '/');

    const rawData = window.atob(base64);
    const outputArray = new Uint8Array(rawData.length);

    for (let i = 0; i < rawData.length; ++i) {
      outputArray[i] = rawData.charCodeAt(i);
    }
    return outputArray;
  }

  // 通知設定を取得
  getNotificationSettings() {
    return {
      isSupported: this.isSupported,
      permission: Notification.permission,
      isSubscribed: !!this.subscription
    };
  }
}
```

```javascript
// Service Workerでのプッシュ通知処理
self.addEventListener('push', (event) => {
  console.log('Push event received:', event);

  let data = {};
  if (event.data) {
    try {
      data = event.data.json();
    } catch (error) {
      data = { title: '新しい通知', body: event.data.text() };
    }
  }

  const options = {
    body: data.body || '新しい通知があります',
    icon: data.icon || '/icons/icon-192x192.png',
    badge: data.badge || '/icons/icon-72x72.png',
    tag: data.tag || 'default',
    data: data.data || {},
    actions: data.actions || [],
    requireInteraction: data.requireInteraction || false,
    silent: data.silent || false
  };

  event.waitUntil(
    self.registration.showNotification(data.title || '通知', options)
  );
});

// 通知クリック時の処理
self.addEventListener('notificationclick', (event) => {
  console.log('Notification clicked:', event);

  event.notification.close();

  const data = event.notification.data;
  const url = data.url || '/';

  event.waitUntil(
    clients.matchAll({ type: 'window' })
      .then((clientList) => {
        // 既存のウィンドウを探す
        for (const client of clientList) {
          if (client.url === url && 'focus' in client) {
            return client.focus();
          }
        }

        // 新しいウィンドウを開く
        if (clients.openWindow) {
          return clients.openWindow(url);
        }
      })
  );
});

// 通知閉じる時の処理
self.addEventListener('notificationclose', (event) => {

    headers: {
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      tag: event.notification.tag,
      timestamp: new Date().toISOString()
    })
  }).catch(error => {
    console.error('Notification close tracking failed:', error);
```
