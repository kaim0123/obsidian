# 4-6. UIの表示切り替え（モーダル・タブ・トースト）

## 🎯 この章で学ぶこと

- 「開く・閉じる」「タブ切り替え」をstateで実装する
- モーダル、タブ、トースト（通知）の最小実装
- ESCキー閉じる、自動消去などの基本機能

---

## 📖 概念の説明

### 表示切り替えはほぼ同じパターン

| 名前 | 説明 |
| --- | --- |
| **モーダル** | 中央に出るウィンドウ。背景を覆う |
| **タブ** | 同じ場所で内容を切り替える |
| **トースト** | 画面端に一時的に出る通知 |

すべて、**「state（boolean / string）で表示を切り替える」**だけ。

---

## 💻 ① モーダル

### 最小実装

```jsx
function App() {
  const [isOpen, setIsOpen] = useState(false);

  return (
    <>
      <button onClick={() => setIsOpen(true)}>開く</button>

      {isOpen && (
        <div className="modal-overlay" onClick={() => setIsOpen(false)}>
          <div className="modal-content" onClick={(e) => e.stopPropagation()}>
            <h2>モーダル</h2>
            <p>本文</p>
            <button onClick={() => setIsOpen(false)}>閉じる</button>
          </div>
        </div>
      )}
    </>
  );
}
```

ポイント：

- `isOpen` で表示/非表示
- 背景クリックで閉じる（オーバーレイの onClick）
- 中身クリックで閉じない（`stopPropagation`）

### ESCキーで閉じる

```jsx
useEffect(() => {
  function handleEsc(e) {
    if (e.key === 'Escape') setIsOpen(false);
  }
  window.addEventListener('keydown', handleEsc);
  return () => window.removeEventListener('keydown', handleEsc);
}, []);
```

→ クリーンアップを忘れずに（[[5-3-クリーンアップ]]）。

### body のスクロール禁止

```jsx
useEffect(() => {
  if (isOpen) document.body.style.overflow = 'hidden';
  else document.body.style.overflow = '';
  return () => { document.body.style.overflow = ''; };
}, [isOpen]);
```

## 💻 ② タブ

### 最小実装

```jsx
function Tabs() {
  const [active, setActive] = useState('home');

  return (
    <div>
      <nav>
        <button onClick={() => setActive('home')} disabled={active === 'home'}>
          ホーム
        </button>
        <button onClick={() => setActive('profile')} disabled={active === 'profile'}>
          プロフィール
        </button>
        <button onClick={() => setActive('settings')} disabled={active === 'settings'}>
          設定
        </button>
      </nav>

      <div>
        {active === 'home' && <p>ホームの内容</p>}
        {active === 'profile' && <p>プロフィールの内容</p>}
        {active === 'settings' && <p>設定の内容</p>}
      </div>
    </div>
  );
}
```

### 配列で書き換え（tabsデータ駆動）

```jsx
const tabs = [
  { id: 'home', label: 'ホーム', content: <Home /> },
  { id: 'profile', label: 'プロフィール', content: <Profile /> },
];

function Tabs() {
  const [active, setActive] = useState(tabs[0].id);
  const current = tabs.find((t) => t.id === active);
  return (
    <div>
      {tabs.map((t) => (
        <button
          key={t.id}
          onClick={() => setActive(t.id)}
          aria-selected={active === t.id}
        >{t.label}</button>
      ))}
      <div>{current.content}</div>
    </div>
  );
}
```

## 💻 ③ トースト（通知）

### 最小実装

```jsx
function Toast({ message, onClose }) {
  useEffect(() => {
    const id = setTimeout(onClose, 3000); // 3秒後に消す
    return () => clearTimeout(id);
  }, [onClose]);

  return <div className="toast">{message}</div>;
}

function App() {
  const [toasts, setToasts] = useState([]);

  function showToast(message) {
    const id = Date.now();
    setToasts((prev) => [...prev, { id, message }]);
  }

  function removeToast(id) {
    setToasts((prev) => prev.filter((t) => t.id !== id));
  }

  return (
    <div>
      <button onClick={() => showToast('保存しました')}>保存</button>

      <div className="toast-container">
        {toasts.map((t) => (
          <Toast
            key={t.id}
            message={t.message}
            onClose={() => removeToast(t.id)}
          />
        ))}
      </div>
    </div>
  );
}
```

ポイント：

- 複数のトーストを **配列** で管理
- 各トーストは自分で setTimeout して消える

## 🛠 アクセシビリティ

### モーダル

```jsx
<div role="dialog" aria-modal="true" aria-labelledby="modal-title">
  <h2 id="modal-title">タイトル</h2>
  ...
</div>
```

- `role="dialog"`、`aria-modal="true"`：スクリーンリーダーに「モーダル」と伝える
- フォーカスを最初の要素に移動
- 閉じたら開く前のフォーカス位置に戻す

詳しくは [[12-4-アクセシビリティ]]。

---

## ❌ よくある間違い

### モーダルの中をクリックしたら閉じる

```jsx
// ❌ 中身を押しても閉じてしまう
<div className="overlay" onClick={onClose}>
  <div className="content">中身</div>
</div>
```

→ ✅ 中身のクリックを `stopPropagation` で止める。

### useEffect クリーンアップ忘れ

```jsx
useEffect(() => {
  window.addEventListener('keydown', handleEsc);
  // ❌ クリーンアップなし → メモリリーク
}, []);
```

→ ✅ `return () => window.removeEventListener(...)`。

### トーストが追加されすぎる

→ 上限（例：5件）を設けるか、同じメッセージは無視する。

### タブ切り替えで状態が消える

```jsx
{active === 'home' && <Home />} // タブを離れると Home の state は消える
```

→ stateを保ちたいなら**全部マウントしてCSSで隠す**：

```jsx
<Home style={{ display: active === 'home' ? 'block' : 'none' }} />
```

---

## ✅ ベストプラクティス

1. **ESC・背景クリック**で閉じられる（モーダル）
2. **ARIA属性**でアクセシブルに
3. トーストは**配列**で管理し、一意のIDをつける
4. クリーンアップは必ず書く
5. UIライブラリ（Radix UIなど）を活用するのも◎

---

## 🔬 実践演習

「削除確認モーダル」を作る：

- 削除ボタンをクリックすると確認モーダル
- 「キャンセル」「削除」ボタン
- 削除を実行したら成功トーストを出す
- ESCで閉じる

---

## 📝 まとめ

- 表示切り替えはstateで（boolean / string）
- モーダル：ESC・背景クリックで閉じる、ARIA対応
- タブ：active stateで切り替え、stateを保ちたい場合は全マウント
- トースト：配列管理、setTimeoutで自動消去
