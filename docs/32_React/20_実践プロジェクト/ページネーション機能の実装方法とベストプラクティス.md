# ページネーション機能の実装方法とベストプラクティス

## 概要

ページネーション機能は、大量のデータを複数のページに分割して表示する重要な機能です。基本的なページネーションから高度な機能まで、様々な実装方法とそのベストプラクティスを詳しく解説します。

## ページネーション機能の種類と比較表

| 項目 | 基本ページネーション | 番号付きページネーション | 無限スクロール | 仮想ページネーション |
|------|-------------------|----------------------|---------------|-------------------|
| **実装の複雑さ** | ⭐ 簡単 | ⭐⭐ 中程度 | ⭐⭐⭐ 複雑 | ⭐⭐⭐ 複雑 |
| **パフォーマンス** | ⭐⭐⭐ 高速 | ⭐⭐⭐ 高速 | ⭐⭐ 中程度 | ⭐⭐⭐ 高速 |
| **ユーザビリティ** | ⭐⭐ 中程度 | ⭐⭐⭐ 高い | ⭐⭐⭐ 高い | ⭐⭐ 中程度 |
| **SEO対応** | ✅ 対応 | ✅ 対応 | ❌ 非対応 | ✅ 対応 |
| **ブックマーク可能** | ✅ 可能 | ✅ 可能 | ❌ 不可 | ✅ 可能 |
| **メモリ使用量** | ⭐⭐⭐ 軽量 | ⭐⭐⭐ 軽量 | ⭐ 重い | ⭐⭐⭐ 軽量 |
| **モバイル対応** | ⭐⭐ 中程度 | ⭐⭐ 中程度 | ⭐⭐⭐ 優秀 | ⭐⭐ 中程度 |

### 推奨使用場面

| ページネーションタイプ | 最適な使用場面 | 例 |
|----------------------|----------------|-----|
| **基本ページネーション** | シンプルなリスト | 管理画面、設定画面 |

## 1. 基本ページネーション

### 概要
前へ・次へボタンによるシンプルなページネーション機能

### 実装例

```javascript
// 基本的なページネーション
function BasicPagination({ items, itemsPerPage = 10 }) {
  const [currentPage, setCurrentPage] = useState(1);
  const totalPages = Math.ceil(items.length / itemsPerPage);

  const startIndex = (currentPage - 1) * itemsPerPage;
  const endIndex = startIndex + itemsPerPage;
  const currentItems = items.slice(startIndex, endIndex);

  const goToPreviousPage = () => {
    setCurrentPage(prev => Math.max(prev - 1, 1));
  };

  const goToNextPage = () => {
    setCurrentPage(prev => Math.min(prev + 1, totalPages));
  };

  return (
    <div>
      <div className="items-list">
        {currentItems.map(item => (
          <div key={item.id} className="item">
            <h3>{item.name}</h3>
            <p>{item.description}</p>
          </div>
        ))}
      </div>

      <div className="pagination">
        <button
          onClick={goToPreviousPage}
          disabled={currentPage === 1}
          className="pagination-button"
        >
          前へ
        </button>
        
        <span className="page-info">
          {currentPage} / {totalPages} ページ
        </span>
        
        <button
          onClick={goToNextPage}
          disabled={currentPage === totalPages}
          className="pagination-button"
        >
          次へ
        </button>
      </div>
    </div>
  );
}
```

### URLパラメータ対応の基本ページネーション

```javascript
// URLパラメータと連動したページネーション
import { useRouter } from 'next/router';
import { useEffect, useState } from 'react';

function URLPagination({ items, itemsPerPage = 10 }) {
  const router = useRouter();
  const [currentPage, setCurrentPage] = useState(1);

  // URLパラメータからページ番号を取得
  useEffect(() => {
    if (router.isReady && router.query.page) {
      const page = parseInt(router.query.page);
      if (page > 0 && page <= Math.ceil(items.length / itemsPerPage)) {
        setCurrentPage(page);
      }
    }
  }, [router.isReady, router.query.page, items.length, itemsPerPage]);

  const totalPages = Math.ceil(items.length / itemsPerPage);
  const startIndex = (currentPage - 1) * itemsPerPage;
  const endIndex = startIndex + itemsPerPage;
  const currentItems = items.slice(startIndex, endIndex);

  const goToPage = (page) => {
    if (page >= 1 && page <= totalPages) {
      setCurrentPage(page);
      router.push({
        pathname: router.pathname,
        query: { ...router.query, page }
      }, undefined, { shallow: true });
    }
  };

  const goToPreviousPage = () => goToPage(currentPage - 1);
  const goToNextPage = () => goToPage(currentPage + 1);

  return (
    <div>
      <div className="items-list">
        {currentItems.map(item => (
          <div key={item.id} className="item">
            <h3>{item.name}</h3>
            <p>{item.description}</p>
          </div>
        ))}
      </div>

      <div className="pagination">
        <button
          onClick={goToPreviousPage}
          disabled={currentPage === 1}
          className="pagination-button"
        >
          前へ
        </button>
        
        <span className="page-info">
          {currentPage} / {totalPages} ページ
          ({items.length}件中 {startIndex + 1}-{Math.min(endIndex, items.length)}件を表示)
        </span>
        
        <button
          onClick={goToNextPage}
          disabled={currentPage === totalPages}
          className="pagination-button"
        >
          次へ
        </button>
      </div>
    </div>
  );
}
```

### メリット
- ✅ **実装が簡単**: 基本的なロジックで実装可能
- ✅ **軽量**: 最小限のリソースで動作
- ✅ **SEO対応**: URLパラメータで検索エンジン対応
- ✅ **ブックマーク可能**: 特定のページをブックマーク可能

### デメリット
- ❌ **ユーザビリティ**: 大量ページでの移動が困難
- ❌ **情報不足**: 全体のページ数が分かりにくい
- ❌ **モバイル対応**: 小さな画面では操作しにくい

### 使用場面
- ⚙️ **管理画面**: シンプルなデータ一覧
- 📝 **設定画面**: 設定項目の表示
- 📊 **レポート**: 基本的なデータ表示

## 2. 番号付きページネーション

### 概要
ページ番号を表示して直接ジャンプできる高度なページネーション機能

### 実装例

```javascript
// 番号付きページネーション
function NumberedPagination({ items, itemsPerPage = 10 }) {
  const [currentPage, setCurrentPage] = useState(1);
  const totalPages = Math.ceil(items.length / itemsPerPage);

  const startIndex = (currentPage - 1) * itemsPerPage;
  const endIndex = startIndex + itemsPerPage;
  const currentItems = items.slice(startIndex, endIndex);

  // 表示するページ番号を計算
  const getVisiblePages = () => {
    const delta = 2; // 現在のページの前後に表示するページ数
    const range = [];
    const rangeWithDots = [];

    for (let i = Math.max(2, currentPage - delta); 
         i <= Math.min(totalPages - 1, currentPage + delta); 
         i++) {
      range.push(i);
    }

    if (currentPage - delta > 2) {
      rangeWithDots.push(1, '...');
    } else {
      rangeWithDots.push(1);
    }

    rangeWithDots.push(...range);

    if (currentPage + delta < totalPages - 1) {
      rangeWithDots.push('...', totalPages);
    } else if (totalPages > 1) {
      rangeWithDots.push(totalPages);
    }

    return rangeWithDots;
  };

  const goToPage = (page) => {
    if (page >= 1 && page <= totalPages && page !== currentPage) {
      setCurrentPage(page);
    }
  };

  const visiblePages = getVisiblePages();

  return (
    <div>
      <div className="items-list">
        {currentItems.map(item => (
          <div key={item.id} className="item">
            <h3>{item.name}</h3>
            <p>{item.description}</p>
          </div>
        ))}
      </div>

      <div className="pagination">
        <button
          onClick={() => goToPage(currentPage - 1)}
          disabled={currentPage === 1}
          className="pagination-button"
        >
          « 前へ
        </button>

        {visiblePages.map((page, index) => (
          <button
            key={index}
            onClick={() => typeof page === 'number' && goToPage(page)}
            disabled={page === '...'}
            className={`pagination-button ${
              page === currentPage ? 'active' : ''
            } ${page === '...' ? 'dots' : ''}`}
          >
            {page}
          </button>
        ))}

        <button
          onClick={() => goToPage(currentPage + 1)}
          disabled={currentPage === totalPages}
          className="pagination-button"
        >
          次へ »
        </button>
      </div>

      <div className="pagination-info">
        <span>
          {items.length}件中 {startIndex + 1}-{Math.min(endIndex, items.length)}件を表示
        </span>
        <span>
          ページ {currentPage} / {totalPages}
        </span>
      </div>
    </div>
  );
}
```

```javascript
  itemsPerPage = 10,
  onPageChange,
  showPageSizeSelector = true,
  showJumpToPage = true
}) {
```

## 3. 無限スクロール

### 概要
スクロールに応じて自動的に次のページを読み込むページネーション機能

### 実装例

```javascript
// 基本的な無限スクロール
function InfiniteScroll({ items, itemsPerPage = 10 }) {
  const [currentPage, setCurrentPage] = useState(1);
  const [isLoading, setIsLoading] = useState(false);
  const [hasMore, setHasMore] = useState(true);

  const totalPages = Math.ceil(items.length / itemsPerPage);
  const displayedItems = items.slice(0, currentPage * itemsPerPage);

  const loadMore = useCallback(() => {
    if (isLoading || !hasMore) return;

    setIsLoading(true);
    
    // 実際のアプリケーションではAPIリクエストをここで実行
    setTimeout(() => {
      setCurrentPage(prev => {
        const nextPage = prev + 1;
        setHasMore(nextPage < totalPages);
        setIsLoading(false);
        return nextPage;
      });
    }, 1000);
  }, [isLoading, hasMore, totalPages]);

  // スクロールイベントの監視
  useEffect(() => {
    const handleScroll = () => {
      if (window.innerHeight + document.documentElement.scrollTop 
          >= document.documentElement.offsetHeight - 1000) {
        loadMore();
      }
    };

    window.addEventListener('scroll', handleScroll);
    return () => window.removeEventListener('scroll', handleScroll);
  }, [loadMore]);

  return (
    <div>
      <div className="items-list">
        {displayedItems.map(item => (
          <div key={item.id} className="item">
            <h3>{item.name}</h3>
            <p>{item.description}</p>
          </div>
        ))}
      </div>

      {isLoading && (
        <div className="loading">
          <div className="spinner"></div>
          <p>読み込み中...</p>
        </div>
      )}

      {!hasMore && (
        <div className="no-more">
          <p>すべてのアイテムを表示しました</p>
        </div>
      )}

      {hasMore && !isLoading && (
        <div className="load-more">
          <button onClick={loadMore} className="load-more-button">
            さらに読み込む
          </button>
        </div>
      )}
    </div>
  );
}
```

```javascript
function IntersectionInfiniteScroll({ items, itemsPerPage = 10 }) {
  const [currentPage, setCurrentPage] = useState(1);
  const [isLoading, setIsLoading] = useState(false);
  const [hasMore, setHasMore] = useState(true);
  const observerRef = useRef();

  const totalPages = Math.ceil(items.length / itemsPerPage);
  const displayedItems = items.slice(0, currentPage * itemsPerPage);

  const loadMore = useCallback(() => {
    if (isLoading || !hasMore) return;

    setIsLoading(true);
    
    // APIリクエストをシミュレート
    setTimeout(() => {
      setCurrentPage(prev => {
        const nextPage = prev + 1;
        setHasMore(nextPage < totalPages);
        setIsLoading(false);
        return nextPage;
      });
    }, 1000);
  }, [isLoading, hasMore, totalPages]);

  // Intersection Observerの設定
  useEffect(() => {
    const observer = new IntersectionObserver(
      (entries) => {
        if (entries[0].isIntersecting) {
          loadMore();
        }
      },
      { threshold: 0.1 }
    );

    if (observerRef.current) {
      observer.observe(observerRef.current);
    }

    return () => {
      if (observerRef.current) {
        observer.unobserve(observerRef.current);
      }
    };
  }, [loadMore]);

  return (
    <div>
      <div className="items-list">
        {displayedItems.map(item => (
          <div key={item.id} className="item">
            <h3>{item.name}</h3>
            <p>{item.description}</p>
          </div>
        ))}
      </div>

      {isLoading && (
        <div className="loading">
          <div className="spinner"></div>
          <p>読み込み中...</p>
        </div>
      )}

      {hasMore && (
        <div ref={observerRef} className="observer-trigger">
          {/* この要素が画面に入ると次のページを読み込む */}
        </div>
      )}

      {!hasMore && (
        <div className="no-more">
          <p>すべてのアイテムを表示しました</p>
        </div>
      )}
    </div>
  );
}
```

### 仮想化対応の無限スクロール

```javascript
// 仮想化と組み合わせた無限スクロール
import { FixedSizeList as List } from 'react-window';

function VirtualizedInfiniteScroll({ 
  items, 
  itemsPerPage = 50,
  itemHeight = 100 
}) {
  const [currentPage, setCurrentPage] = useState(1);
  const [isLoading, setIsLoading] = useState(false);
  const [hasMore, setHasMore] = useState(true);

  const totalPages = Math.ceil(items.length / itemsPerPage);
  const displayedItems = items.slice(0, currentPage * itemsPerPage);

  const loadMore = useCallback(() => {
    if (isLoading || !hasMore) return;

    setIsLoading(true);
    
    setTimeout(() => {
      setCurrentPage(prev => {
        const nextPage = prev + 1;
        setHasMore(nextPage < totalPages);
        setIsLoading(false);
        return nextPage;
      });
    }, 1000);
  }, [isLoading, hasMore, totalPages]);

  const ItemRenderer = ({ index, style }) => {
    const item = displayedItems[index];
    
    if (!item) {
      return (
        <div style={style} className="loading-item">
          <div className="spinner"></div>
        </div>
      );
    }

    return (
      <div style={style} className="item">
        <h3>{item.name}</h3>
        <p>{item.description}</p>
      </div>
    );
  };

  const onItemsRendered = ({ visibleStopIndex }) => {
    // 表示されている最後のアイテムが近づいたら次のページを読み込む
    if (visibleStopIndex >= displayedItems.length - 5 && hasMore && !isLoading) {
      loadMore();
    }
  };

  return (
    <div>
      <List
        height={600}
        itemCount={displayedItems.length + (hasMore ? 1 : 0)}
        itemSize={itemHeight}
        onItemsRendered={onItemsRendered}
      >
        {ItemRenderer}
      </List>

      {!hasMore && (
        <div className="no-more">
          <p>すべてのアイテムを表示しました</p>
        </div>
      )}
    </div>
  );
}
```

```javascript
    }

  return (
```

### 高度な仮想ページネーション

```javascript
// 動的サイズ対応の仮想ページネーション
import { VariableSizeList as List } from 'react-window';

function AdvancedVirtualPagination({ items, itemsPerPage = 100 }) {
  const [currentPage, setCurrentPage] = useState(1);
  const [itemHeights, setItemHeights] = useState({});
  const listRef = useRef();

  const totalPages = Math.ceil(items.length / itemsPerPage);
  const startIndex = (currentPage - 1) * itemsPerPage;
  const endIndex = startIndex + itemsPerPage;
  const currentPageItems = items.slice(startIndex, endIndex);

  const getItemSize = (index) => {
    const item = currentPageItems[index];
    return itemHeights[item.id] || 100; // デフォルトの高さ
  };

  const ItemRenderer = ({ index, style }) => {
    const item = currentPageItems[index];
    
    const handleResize = (height) => {
      setItemHeights(prev => ({
        ...prev,
        [item.id]: height
      }));
    };

    return (
      <div style={style} className="item">
        <ItemCard 
          item={item} 
          onResize={handleResize}
        />
      </div>
    );
  };

  const goToPage = (page) => {
    if (page >= 1 && page <= totalPages) {
      setCurrentPage(page);
      // ページ変更時にリストを先頭にスクロール
      listRef.current?.scrollToItem(0);
    }
  };

  return (
    <div>
      <div className="pagination-controls">
        <button
          onClick={() => goToPage(1)}
          disabled={currentPage === 1}
        >
          «« 最初
        </button>
        
        <button
          onClick={() => goToPage(currentPage - 1)}
          disabled={currentPage === 1}
        >
          « 前へ
        </button>
        
        <span>
          ページ {currentPage} / {totalPages}
        </span>
        
        <button
          onClick={() => goToPage(currentPage + 1)}
          disabled={currentPage === totalPages}
        >
          次へ »
        </button>
        
        <button
          onClick={() => goToPage(totalPages)}
          disabled={currentPage === totalPages}
        >
          最後 »»
        </button>
      </div>

      <List
        ref={listRef}
        height={600}
        itemCount={currentPageItems.length}
        itemSize={getItemSize}
        estimatedItemSize={100}
      >
        {ItemRenderer}
      </List>

      <div className="pagination-info">
        {items.length}件中 {startIndex + 1}-{endIndex}件を表示
        (仮想化により高速表示)
      </div>
    </div>
  );
}

// アイテムカードコンポーネント
function ItemCard({ item, onResize }) {
  const cardRef = useRef();

  useEffect(() => {
    if (cardRef.current && onResize) {
      const height = cardRef.current.offsetHeight;
      onResize(height);
    }
  }, [onResize]);

  return (
    <div ref={cardRef} className="item-card">
      <h3>{item.name}</h3>
      <p>{item.description}</p>
      <div className="item-meta">
        <span>ID: {item.id}</span>
        <span>作成日: {new Date(item.createdAt).toLocaleDateString()}</span>
      </div>
    </div>
  );
}
```

```javascript
// ページの遅延読み込み
function LazyPagination({ items, itemsPerPage = 10 }) {
  const [currentPage, setCurrentPage] = useState(1);
  const [loadedPages, setLoadedPages] = useState(new Set([1]));

  const loadPage = useCallback(async (page) => {
    if (loadedPages.has(page)) return;

    // APIリクエストをシミュレート
    await new Promise(resolve => setTimeout(resolve, 500));
    
    setLoadedPages(prev => new Set([...prev, page]));
  }, [loadedPages]);

  const goToPage = async (page) => {
    await loadPage(page);
    setCurrentPage(page);
  };

  return (
    <div>
      {/* ページネーションUI */}
      <PaginationControls 
        currentPage={currentPage}
        totalPages={Math.ceil(items.length / itemsPerPage)}
        onPageChange={goToPage}
      />
      
      {/* アイテム表示 */}
      <PaginatedItems 
        items={items}
        currentPage={currentPage}
        itemsPerPage={itemsPerPage}
      />
    </div>
  );
}
```

```javascript
// 次のページのプリフェッチ
function PrefetchPagination({ items, itemsPerPage = 10 }) {
  const [currentPage, setCurrentPage] = useState(1);
  const [prefetchedPages, setPrefetchedPages] = useState(new Set());

  const prefetchPage = useCallback(async (page) => {
    if (prefetchedPages.has(page)) return;

    // バックグラウンドでページデータをプリフェッチ
    setTimeout(() => {
      setPrefetchedPages(prev => new Set([...prev, page]));
    }, 100);
  }, [prefetchedPages]);

  const goToPage = (page) => {
    setCurrentPage(page);
    
    // 次のページをプリフェッチ
    if (page < Math.ceil(items.length / itemsPerPage)) {
      prefetchPage(page + 1);
    }
  };

  return (
    <div>
      <PaginationControls 
        currentPage={currentPage}
        totalPages={Math.ceil(items.length / itemsPerPage)}
        onPageChange={goToPage}
      />
      
      <PaginatedItems 
        items={items}
        currentPage={currentPage}
        itemsPerPage={itemsPerPage}
      />
    </div>
  );
}
```

```javascript
// ページデータのキャッシュ
function CachedPagination({ items, itemsPerPage = 10 }) {
  const [currentPage, setCurrentPage] = useState(1);
  const [pageCache, setPageCache] = useState(new Map());

  const getPageData = useCallback((page) => {
    if (pageCache.has(page)) {
      return pageCache.get(page);
    }

    const startIndex = (page - 1) * itemsPerPage;
    const endIndex = startIndex + itemsPerPage;
    const pageData = items.slice(startIndex, endIndex);
    
    setPageCache(prev => new Map(prev).set(page, pageData));
    return pageData;
  }, [items, itemsPerPage, pageCache]);

  const currentPageData = getPageData(currentPage);

  return (
    <div>
      <PaginationControls 
        currentPage={currentPage}
        totalPages={Math.ceil(items.length / itemsPerPage)}
        onPageChange={setCurrentPage}
      />
      
      <div>
        {currentPageData.map(item => (
          <ItemCard key={item.id} item={item} />
        ))}
      </div>
    </div>
  );
}
```

## まとめ

| ページネーションタイプ | 適用場面 | 主なメリット | 主なデメリット |
|----------------------|---------|-------------|---------------|
| **基本ページネーション** | シンプルなリスト | 実装が簡単、軽量 | ユーザビリティが低い |
| **番号付きページネーション** | 大量データの閲覧 | ユーザビリティ、効率性 | 実装が複雑 |
| **無限スクロール** | モバイル・SNS | ユーザビリティ、エンゲージメント | SEO対応なし |
| **仮想ページネーション** | 超大量データ | 高性能、スケーラブル | 実装が複雑 |

### 選択の指針

1. **シンプルなリスト** → 基本ページネーション
2. **大量データの閲覧** → 番号付きページネーション
3. **モバイル・SNS** → 無限スクロール
4. **超大量データ** → 仮想ページネーション
5. **複数の要件** → 組み合わせパターン
