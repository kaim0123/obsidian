# テーマ・カスタマイズの実装方法とベストプラクティス

## 概要

テーマ・カスタマイズ機能は、ユーザーがアプリケーションの外観を自由に変更できる機能です。色、フォント、レイアウトなどをカスタマイズすることで、ユーザーエクスペリエンスを向上させ、アクセシビリティを高めることができます。

## テーマカスタマイズの種類と比較表

| 項目 | プリセットテーマ | カラーピッカー | 高度なカスタマイズ | ユーザー生成テーマ |
|------|-----------------|---------------|-------------------|------------------|
| **実装の複雑さ** | ⭐ 簡単 | ⭐⭐ 中程度 | ⭐⭐⭐ 複雑 | ⭐⭐⭐ 複雑 |
| **ユーザビリティ** | ⭐⭐⭐ 高い | ⭐⭐ 中程度 | ⭐ 低い | ⭐⭐ 中程度 |
| **柔軟性** | ⭐ 低い | ⭐⭐ 中程度 | ⭐⭐⭐ 高い | ⭐⭐⭐ 高い |
| **パフォーマンス** | ⭐⭐⭐ 高速 | ⭐⭐⭐ 高速 | ⭐⭐ 中程度 | ⭐⭐ 中程度 |
| **メンテナンス性** | ⭐⭐⭐ 高い | ⭐⭐ 中程度 | ⭐ 低い | ⭐ 低い |

## 1. プリセットテーマ

### 概要
事前に定義された複数のテーマから選択する方式

### 実装例

```javascript

const presetThemes = {

    colors: {

    colors: {
      primary: '#e17055',

      success: '#00b894',
      danger: '#e84393',
      warning: '#fdcb6e',
      info: '#fd79a8',
      light: '#ffeaa7',
      dark: '#2d3436'
    }
  }
};

// テーマ管理クラス
class PresetThemeManager {
  constructor() {
    this.currentTheme = this.getStoredTheme() || 'default';
    this.applyTheme(this.currentTheme);
  }

  getStoredTheme() {
    return localStorage.getItem('presetTheme');
  }

  applyTheme(themeKey) {
    const theme = presetThemes[themeKey];
    if (!theme) return;

    const root = document.documentElement;
    Object.entries(theme.colors).forEach(([key, value]) => {
      root.style.setProperty(`--color-${key}`, value);
    });

    this.currentTheme = themeKey;
    localStorage.setItem('presetTheme', themeKey);
  }

  getAvailableThemes() {
    return Object.entries(presetThemes).map(([key, theme]) => ({
      key,
      name: theme.name
    }));
  }
}

// Reactコンポーネント
function PresetThemeSelector() {
  const [currentTheme, setCurrentTheme] = useState('default');
  const themeManager = new PresetThemeManager();

  const handleThemeChange = (themeKey) => {
    themeManager.applyTheme(themeKey);
    setCurrentTheme(themeKey);
  };

  return (
    <div className="theme-selector">
      <h3>テーマを選択</h3>
      <div className="theme-grid">
        {themeManager.getAvailableThemes().map(theme => (
          <button
            key={theme.key}
            onClick={() => handleThemeChange(theme.key)}
            className={`theme-option ${currentTheme === theme.key ? 'active' : ''}`}
            style={{
              '--theme-primary': presetThemes[theme.key].colors.primary,
              '--theme-secondary': presetThemes[theme.key].colors.secondary
            }}
          >
            <div className="theme-preview">
              <div className="preview-primary"></div>
              <div className="preview-secondary"></div>
            </div>
            <span>{theme.name}</span>
          </button>
        ))}
      </div>
    </div>
  );
}
```

## 2. カラーピッカー

### 概要
ユーザーが色を直接選択できるカラーピッカー機能

### 実装例

```javascript
// カラーピッカーコンポーネント
function ColorPicker({ label, value, onChange }) {
  const [isOpen, setIsOpen] = useState(false);

  return (
    <div className="color-picker-container">
      <label>{label}</label>
      <div className="color-picker-wrapper">
        <button
          className="color-preview"
          style={{ backgroundColor: value }}
          onClick={() => setIsOpen(!isOpen)}
          aria-label={`${label}の色を変更`}
        />
        <input
          type="color"
          value={value}
          onChange={(e) => onChange(e.target.value)}
          className="color-input"
        />
        {isOpen && (
          <div className="color-palette">
            {[
              '#007bff', '#6c757d', '#28a745', '#dc3545',
              '#ffc107', '#17a2b8', '#f8f9fa', '#343a40',
              '#0066cc', '#4a90e2', '#00b894', '#e17055',
              '#fdcb6e', '#74b9ff', '#ddd6fe', '#2d3436'
            ].map(color => (
              <button
                key={color}
                className="color-option"
                style={{ backgroundColor: color }}
                onClick={() => {
                  onChange(color);
                  setIsOpen(false);
                }}
              />
            ))}
          </div>
        )}
      </div>
    </div>
  );
}

// カスタムテーマエディター
function CustomThemeEditor() {
  const [customTheme, setCustomTheme] = useState({
    primary: '#007bff',
    secondary: '#6c757d',
    success: '#28a745',
    danger: '#dc3545',
    warning: '#ffc107',
    info: '#17a2b8',
    light: '#f8f9fa',
    dark: '#343a40'
  });

  const applyCustomTheme = () => {
    const root = document.documentElement;
    Object.entries(customTheme).forEach(([key, value]) => {
      root.style.setProperty(`--color-${key}`, value);
    });
    localStorage.setItem('customTheme', JSON.stringify(customTheme));
  };

  const resetTheme = () => {
    const defaultTheme = {
      primary: '#007bff',
      secondary: '#6c757d',
      success: '#28a745',
      danger: '#dc3545',
      warning: '#ffc107',
      info: '#17a2b8',
      light: '#f8f9fa',
      dark: '#343a40'
    };
    setCustomTheme(defaultTheme);
  };

  return (
    <div className="custom-theme-editor">
      <h3>カスタムテーマ</h3>
      <div className="color-controls">
        {Object.entries(customTheme).map(([key, value]) => (
          <ColorPicker
            key={key}
            label={key}
            value={value}
            onChange={(newColor) => 
              setCustomTheme(prev => ({ ...prev, [key]: newColor }))
            }
          />
        ))}
      </div>
      <div className="theme-actions">
        <button onClick={applyCustomTheme}>適用</button>
        <button onClick={resetTheme}>リセット</button>
      </div>
    </div>
  );
}
```

## 3. 高度なカスタマイズ

### 概要
フォント、スペーシング、アニメーションなど詳細なカスタマイズ

### 実装例

```javascript
// 高度なカスタマイズ設定
const advancedCustomization = {
  typography: {
    fontFamily: {
      options: [
        { value: 'system-ui', label: 'システムフォント' },
        { value: 'Inter', label: 'Inter' },
        { value: 'Roboto', label: 'Roboto' },
        { value: 'Open Sans', label: 'Open Sans' }
      ]
    },
    fontSize: {
      base: { min: 12, max: 20, default: 16 },
      heading: { min: 18, max: 48, default: 24 }
    }
  },
  spacing: {
    padding: { min: 8, max: 64, default: 16 },
    margin: { min: 8, max: 64, default: 16 },
    borderRadius: { min: 0, max: 24, default: 8 }
  },
  animation: {
    duration: { min: 0, max: 2000, default: 300 },
    easing: [
      { value: 'ease', label: 'Ease' },
      { value: 'ease-in', label: 'Ease In' },
      { value: 'ease-out', label: 'Ease Out' },
      { value: 'ease-in-out', label: 'Ease In Out' }
    ]
  }
};

// スライダーコンポーネント
function CustomSlider({ label, value, min, max, onChange }) {
  return (
    <div className="custom-slider">
      <label>
        {label}: {value}
        <input
          type="range"
          min={min}
          max={max}
          value={value}
          onChange={(e) => onChange(parseInt(e.target.value))}
        />
      </label>
    </div>
  );
}

// 高度なカスタマイズエディター
function AdvancedCustomizationEditor() {
  const [settings, setSettings] = useState({
    typography: {
      fontFamily: 'system-ui',
      fontSize: { base: 16, heading: 24 }
    },
    spacing: {
      padding: 16,
      margin: 16,
      borderRadius: 8
    },
    animation: {
      duration: 300,
      easing: 'ease'
    }
  });

  const applySettings = () => {
    const root = document.documentElement;
    
    // タイポグラフィ
    root.style.setProperty('--font-family', settings.typography.fontFamily);
    root.style.setProperty('--font-size-base', `${settings.typography.fontSize.base}px`);
    root.style.setProperty('--font-size-heading', `${settings.typography.fontSize.heading}px`);
    
    // スペーシング
    root.style.setProperty('--spacing-padding', `${settings.spacing.padding}px`);
    root.style.setProperty('--spacing-margin', `${settings.spacing.margin}px`);
    root.style.setProperty('--border-radius', `${settings.spacing.borderRadius}px`);
    
    // アニメーション
    root.style.setProperty('--animation-duration', `${settings.animation.duration}ms`);
    root.style.setProperty('--animation-easing', settings.animation.easing);
    
    localStorage.setItem('advancedSettings', JSON.stringify(settings));
  };

  return (
    <div className="advanced-customization">
      <h3>高度なカスタマイズ</h3>
      
      <div className="customization-section">
        <h4>タイポグラフィ</h4>
        <select
          value={settings.typography.fontFamily}
          onChange={(e) => setSettings(prev => ({
            ...prev,
            typography: { ...prev.typography, fontFamily: e.target.value }
          }))}
        >
          {advancedCustomization.typography.fontFamily.options.map(option => (
            <option key={option.value} value={option.value}>
              {option.label}
            </option>
          ))}
        </select>
        
        <CustomSlider
          label="ベースフォントサイズ"
          value={settings.typography.fontSize.base}
          min={advancedCustomization.typography.fontSize.base.min}
          max={advancedCustomization.typography.fontSize.base.max}
          onChange={(value) => setSettings(prev => ({
            ...prev,
            typography: { ...prev.typography, fontSize: { ...prev.typography.fontSize, base: value } }
          }))}
        />
      </div>

      <div className="customization-section">
        <h4>スペーシング</h4>
        <CustomSlider
          label="パディング"
          value={settings.spacing.padding}
          min={advancedCustomization.spacing.padding.min}
          max={advancedCustomization.spacing.padding.max}
          onChange={(value) => setSettings(prev => ({
            ...prev,
            spacing: { ...prev.spacing, padding: value }
          }))}
        />
      </div>

      <button onClick={applySettings}>設定を適用</button>
    </div>
  );
}
```

## 4. ユーザー生成テーマ

### 概要
ユーザーが作成したテーマを保存・共有する機能

### 実装例

```javascript
// ユーザー生成テーマ管理
class UserThemeManager {
  constructor() {
    this.userThemes = this.loadUserThemes();
  }

  loadUserThemes() {
    const saved = localStorage.getItem('userThemes');
    return saved ? JSON.parse(saved) : [];
  }

  saveUserTheme(theme) {
    const newTheme = {
      id: Date.now().toString(),
      name: theme.name,
      colors: theme.colors,
      createdAt: new Date().toISOString()
    };
    
    this.userThemes.push(newTheme);
    localStorage.setItem('userThemes', JSON.stringify(this.userThemes));
    return newTheme;
  }

  deleteUserTheme(themeId) {
    this.userThemes = this.userThemes.filter(theme => theme.id !== themeId);
    localStorage.setItem('userThemes', JSON.stringify(this.userThemes));
  }

  exportTheme(theme) {
    const dataStr = JSON.stringify(theme, null, 2);
    const dataBlob = new Blob([dataStr], { type: 'application/json' });
    const url = URL.createObjectURL(dataBlob);
    
    const link = document.createElement('a');
    link.href = url;
    link.download = `${theme.name}.json`;
    link.click();
    
    URL.revokeObjectURL(url);
  }

  importTheme(file) {
    return new Promise((resolve, reject) => {
      const reader = new FileReader();
      reader.onload = (e) => {
        try {
          const theme = JSON.parse(e.target.result);
          const savedTheme = this.saveUserTheme(theme);
          resolve(savedTheme);
        } catch (error) {
          reject(error);
        }
      };
      reader.readAsText(file);
    });
  }
}

// テーマ作成・管理コンポーネント
function UserThemeManager() {
  const [userThemes, setUserThemes] = useState([]);
  const [isCreating, setIsCreating] = useState(false);
  const [newTheme, setNewTheme] = useState({
    name: '',
    colors: {
      primary: '#007bff',
      secondary: '#6c757d',
      success: '#28a745',
      danger: '#dc3545'
    }
  });

  const themeManager = new UserThemeManager();

  useEffect(() => {
    setUserThemes(themeManager.loadUserThemes());
  }, []);

  const handleSaveTheme = () => {
    if (!newTheme.name.trim()) return;
    
    const savedTheme = themeManager.saveUserTheme(newTheme);
    setUserThemes(prev => [...prev, savedTheme]);
    setIsCreating(false);
    setNewTheme({
      name: '',
      colors: {
        primary: '#007bff',
        secondary: '#6c757d',
        success: '#28a745',
        danger: '#dc3545'
      }
    });
  };

  const handleDeleteTheme = (themeId) => {
    themeManager.deleteUserTheme(themeId);
    setUserThemes(prev => prev.filter(theme => theme.id !== themeId));
  };

  const handleExportTheme = (theme) => {
    themeManager.exportTheme(theme);
  };

  const handleImportTheme = (event) => {
    const file = event.target.files[0];
    if (file) {
      themeManager.importTheme(file)
        .then(savedTheme => {
          setUserThemes(prev => [...prev, savedTheme]);
        })
        .catch(error => {
          alert('テーマのインポートに失敗しました');
        });
    }
  };

  return (
    <div className="user-theme-manager">
      <h3>ユーザーテーマ</h3>
      
      <div className="theme-actions">
        <button onClick={() => setIsCreating(true)}>
          新しいテーマを作成
        </button>
        <label className="import-button">
          テーマをインポート
          <input
            type="file"
            accept=".json"
            onChange={handleImportTheme}
            style={{ display: 'none' }}
          />
        </label>
      </div>

      {isCreating && (
        <div className="theme-creator">
          <h4>テーマを作成</h4>
          <input
            type="text"
            placeholder="テーマ名"
            value={newTheme.name}
            onChange={(e) => setNewTheme(prev => ({ ...prev, name: e.target.value }))}
          />
          
          <div className="color-controls">
            {Object.entries(newTheme.colors).map(([key, value]) => (
              <ColorPicker
                key={key}
                label={key}
                value={value}
                onChange={(newColor) => 
                  setNewTheme(prev => ({
                    ...prev,
                    colors: { ...prev.colors, [key]: newColor }
                  }))
                }
              />
            ))}
          </div>
          
          <div className="creator-actions">
            <button onClick={handleSaveTheme}>保存</button>
            <button onClick={() => setIsCreating(false)}>キャンセル</button>
          </div>
        </div>
      )}

      <div className="user-themes-list">
        {userThemes.map(theme => (
          <div key={theme.id} className="user-theme-item">
            <div className="theme-preview">
              {Object.entries(theme.colors).map(([key, color]) => (
                <div
                  key={key}
                  className="color-swatch"
                  style={{ backgroundColor: color }}
                />
              ))}
            </div>
            <div className="theme-info">
              <h4>{theme.name}</h4>
              <p>{new Date(theme.createdAt).toLocaleDateString()}</p>
            </div>
            <div className="theme-actions">
              <button onClick={() => themeManager.applyTheme(theme)}>
                適用
              </button>
              <button onClick={() => handleExportTheme(theme)}>
                エクスポート
              </button>
              <button onClick={() => handleDeleteTheme(theme.id)}>
                削除
              </button>
            </div>
          </div>
        ))}
      </div>
    </div>
  );
}
```

## まとめ

| カスタマイズタイプ | 適用場面 | 主なメリット | 主なデメリット |
|-------------------|---------|-------------|---------------|
| **プリセットテーマ** | 一般的なアプリ | シンプル、ユーザビリティ | 柔軟性の制限 |
| **カラーピッカー** | カスタマイズ重視 | 直感的、柔軟性 | 実装の複雑さ |
| **高度なカスタマイズ** | プロ向けアプリ | 詳細な制御 | 学習コスト |
| **ユーザー生成テーマ** | コミュニティ重視 | 共有、拡張性 | 管理の複雑さ |

### 選択の指針

1. **一般的なアプリ** → プリセットテーマ
2. **カスタマイズ重視** → カラーピッカー
3. **プロ向けアプリ** → 高度なカスタマイズ
4. **コミュニティ重視** → ユーザー生成テーマ
