# ツールチップ・ヘルプの実装方法とベストプラクティス

## 概要

ツールチップ・ヘルプは、ユーザーに追加情報や説明を提供するための重要なUI要素です。ホバーやクリックで表示される小さなポップアップで、ユーザビリティとアクセシビリティを向上させることができます。

## ツールチップ・ヘルプの種類と比較表

| 項目 | 基本ツールチップ | リッチツールチップ | ヘルプボタン | コンテキストヘルプ |
|------|-----------------|------------------|-------------|------------------|
| **実装の複雑さ** | ⭐ 簡単 | ⭐⭐ 中程度 | ⭐⭐ 中程度 | ⭐⭐⭐ 複雑 |
| **ユーザビリティ** | ⭐⭐⭐ 高い | ⭐⭐⭐ 高い | ⭐⭐ 中程度 | ⭐⭐⭐ 高い |
| **情報量** | ⭐ 少ない | ⭐⭐⭐ 多い | ⭐⭐ 中程度 | ⭐⭐⭐ 多い |
| **アクセシビリティ** | ⭐⭐ 中程度 | ⭐⭐ 中程度 | ⭐⭐⭐ 高い | ⭐⭐ 中程度 |
| **モバイル対応** | ⭐ 低い | ⭐⭐ 中程度 | ⭐⭐⭐ 優秀 | ⭐⭐ 中程度 |

## 1. 基本ツールチップ

### 概要
ホバーで表示されるシンプルなツールチップ

### 実装例

```javascript
// 基本ツールチップコンポーネント
function Tooltip({ 
  children, 
  content, 
  position = 'top',
  delay = 500,
  disabled = false 
}) {
  const [isVisible, setIsVisible] = useState(false);
  const [timeoutId, setTimeoutId] = useState(null);
  const tooltipRef = useRef(null);

  const showTooltip = () => {
    if (disabled) return;
    
    const id = setTimeout(() => {
      setIsVisible(true);
    }, delay);
    setTimeoutId(id);
  };

  const hideTooltip = () => {
    if (timeoutId) {
      clearTimeout(timeoutId);
      setTimeoutId(null);
    }
    setIsVisible(false);
  };

  const getPositionClass = () => {
    const positions = {
      top: 'tooltip-top',
      bottom: 'tooltip-bottom',
      left: 'tooltip-left',
      right: 'tooltip-right'
    };
    return positions[position] || positions.top;
  };

  return (
    <div 
      className="tooltip-wrapper"
      onMouseEnter={showTooltip}
      onMouseLeave={hideTooltip}
      onFocus={showTooltip}
      onBlur={hideTooltip}
    >
      {children}
      
      {isVisible && (
        <div 
          ref={tooltipRef}
          className={`tooltip ${getPositionClass()}`}
          role="tooltip"
          aria-hidden="false"
        >
          {content}
        </div>
      )}
    </div>
  );
}

// 使用例
function App() {
  return (
    <div>
      <Tooltip content="これはツールチップです" position="top">
        <button>ホバーしてください</button>
      </Tooltip>
      
      <Tooltip content="右側に表示されます" position="right">
        <span>右側ツールチップ</span>
      </Tooltip>
    </div>
  );
}
```

## 2. リッチツールチップ

### 概要
より多くの情報を含むリッチなツールチップ

### 実装例

```javascript
// リッチツールチップコンポーネント
function RichTooltip({ 
  children, 
  title, 
  content, 
  image,
  actions,
  position = 'top',
  maxWidth = 300
}) {
  const [isVisible, setIsVisible] = useState(false);
  const [timeoutId, setTimeoutId] = useState(null);
  const tooltipRef = useRef(null);

  const showTooltip = () => {
    const id = setTimeout(() => {
      setIsVisible(true);
    }, 300);
    setTimeoutId(id);
  };

  const hideTooltip = () => {
    if (timeoutId) {
      clearTimeout(timeoutId);
      setTimeoutId(null);
    }
    setIsVisible(false);
  };

  const getPositionClass = () => {
    const positions = {
      top: 'rich-tooltip-top',
      bottom: 'rich-tooltip-bottom',
      left: 'rich-tooltip-left',
      right: 'rich-tooltip-right'
    };
    return positions[position] || positions.top;
  };

  return (
    <div 
      className="rich-tooltip-wrapper"
      onMouseEnter={showTooltip}
      onMouseLeave={hideTooltip}
    >
      {children}
      
      {isVisible && (
        <div 
          ref={tooltipRef}
          className={`rich-tooltip ${getPositionClass()}`}
          style={{ maxWidth }}
          role="tooltip"
        >
          {image && (
            <div className="rich-tooltip-image">
              <img src={image} alt="" />
            </div>
          )}
          
          <div className="rich-tooltip-content">
            {title && (
              <h3 className="rich-tooltip-title">{title}</h3>
            )}
            
            <div className="rich-tooltip-text">
              {content}
            </div>
            
            {actions && (
              <div className="rich-tooltip-actions">
                {actions.map((action, index) => (
                  <button
                    key={index}
                    className="rich-tooltip-action"
                    onClick={action.onClick}
                  >
                    {action.label}
                  </button>
                ))}
              </div>
            )}
          </div>
        </div>
      )}
    </div>
  );
}

// 使用例
function ProductCard({ product }) {
  const actions = [
    { label: '詳細を見る', onClick: () => console.log('詳細') },
    { label: 'カートに追加', onClick: () => console.log('カート追加') }
  ];

  return (
    <div className="product-card">
      <RichTooltip
        title={product.name}
        content={product.description}
        image={product.image}
        actions={actions}
        position="bottom"
        maxWidth={250}
      >
        <img src={product.thumbnail} alt={product.name} />
      </RichTooltip>
    </div>
  );
}
```

## 3. ヘルプボタン

### 概要
クリックで表示されるヘルプ情報

### 実装例

```javascript
// ヘルプボタンコンポーネント
function HelpButton({ 
  content, 
  title = 'ヘルプ',
  position = 'top',
  size = 'small'
}) {
  const [isVisible, setIsVisible] = useState(false);
  const helpRef = useRef(null);

  useEffect(() => {
    const handleClickOutside = (event) => {
      if (helpRef.current && !helpRef.current.contains(event.target)) {
        setIsVisible(false);
      }
    };

    document.addEventListener('mousedown', handleClickOutside);
    return () => document.removeEventListener('mousedown', handleClickOutside);
  }, []);

  const toggleHelp = () => {
    setIsVisible(!isVisible);
  };

  const getPositionClass = () => {
    const positions = {
      top: 'help-top',
      bottom: 'help-bottom',
      left: 'help-left',
      right: 'help-right'
    };
    return positions[position] || positions.top;
  };

  const getSizeClass = () => {
    const sizes = {
      small: 'help-small',
      medium: 'help-medium',
      large: 'help-large'
    };
    return sizes[size] || sizes.small;
  };

  return (
    <div className="help-button-wrapper" ref={helpRef}>
      <button
        className={`help-button ${getSizeClass()}`}
        onClick={toggleHelp}
        aria-label="ヘルプを表示"
        aria-expanded={isVisible}
      >
        ?
      </button>
      
      {isVisible && (
        <div className={`help-content ${getPositionClass()}`}>
          <div className="help-header">
            <h3 className="help-title">{title}</h3>
            <button 
              className="help-close"
              onClick={() => setIsVisible(false)}
              aria-label="ヘルプを閉じる"
            >
              ×
            </button>
          </div>
          <div className="help-body">
            {content}
          </div>
        </div>
      )}
    </div>
  );
}

// 使用例
function FormField({ label, helpText, ...props }) {
  return (
    <div className="form-field">
      <label className="form-label">
        {label}
        <HelpButton 
          content={helpText}
          title={`${label}について`}
          position="right"
        />
      </label>
      <input {...props} />
    </div>
  );
}
```

## 4. コンテキストヘルプ

### 概要
コンテキストに応じて表示されるヘルプ情報

### 実装例

```javascript
// コンテキストヘルプコンポーネント
function ContextHelp({ 
  children, 
  helpContent, 
  trigger = 'hover',
  position = 'top'
}) {
  const [isVisible, setIsVisible] = useState(false);
  const [timeoutId, setTimeoutId] = useState(null);
  const helpRef = useRef(null);

  const showHelp = () => {
    if (timeoutId) {
      clearTimeout(timeoutId);
    }
    setIsVisible(true);
  };

  const hideHelp = () => {
    const id = setTimeout(() => {
      setIsVisible(false);
    }, 200);
    setTimeoutId(id);
  };

  const handleMouseEnter = () => {
    if (trigger === 'hover') {
      showHelp();
    }
  };

  const handleMouseLeave = () => {
    if (trigger === 'hover') {
      hideHelp();
    }
  };

  const handleClick = () => {
    if (trigger === 'click') {
      setIsVisible(!isVisible);
    }
  };

  const getPositionClass = () => {
    const positions = {
      top: 'context-help-top',
      bottom: 'context-help-bottom',
      left: 'context-help-left',
      right: 'context-help-right'
    };
    return positions[position] || positions.top;
  };

  return (
    <div 
      className="context-help-wrapper"
      ref={helpRef}
      onMouseEnter={handleMouseEnter}
      onMouseLeave={handleMouseLeave}
      onClick={handleClick}
    >
      {children}
      
      {isVisible && (
        <div className={`context-help ${getPositionClass()}`}>
          <div className="context-help-content">
            {helpContent}
          </div>
        </div>
      )}
    </div>
  );
}

// 使用例
function FormWithContextHelp() {
  return (
    <form>
      <div className="form-group">
        <label>
          パスワード
          <ContextHelp
            trigger="hover"
            position="right"
            helpContent={
              <div>
                <p>パスワードの要件:</p>
                <ul>
                  <li>8文字以上</li>
                  <li>大文字と小文字を含む</li>
                  <li>数字を含む</li>
                  <li>特殊文字を含む</li>
                </ul>
              </div>
            }
          >
            <span className="help-icon">ℹ</span>
          </ContextHelp>
        </label>
        <input type="password" />
      </div>
    </form>
  );
}
```

## まとめ

| ヘルプタイプ | 適用場面 | 主なメリット | 主なデメリット |
|-------------|---------|-------------|---------------|
| **基本ツールチップ** | シンプルな説明 | シンプル、軽量 | 情報量が限定的 |
| **リッチツールチップ** | 詳細な情報 | 情報量、視覚的 | 実装が複雑 |
| **ヘルプボタン** | クリック式ヘルプ | アクセシビリティ、モバイル対応 | 発見性が低い |
| **コンテキストヘルプ** | 状況に応じたヘルプ | ユーザビリティ、情報量 | 実装が複雑 |

### 選択の指針

1. **シンプルな説明** → 基本ツールチップ
2. **詳細な情報** → リッチツールチップ
3. **クリック式ヘルプ** → ヘルプボタン
4. **状況に応じたヘルプ** → コンテキストヘルプ
