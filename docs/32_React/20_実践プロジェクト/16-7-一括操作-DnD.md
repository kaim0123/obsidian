# 16-7 一括操作/ドラッグ&ドロップ（操作系UI）

## 🎯 この章で学ぶこと

- 複数選択 + 一括操作（バッチアクション）の UI パターンを学ぶ
- `Set` を使った選択状態の効率的な管理
- ドラッグ&ドロップ（DnD）の基礎と、`@dnd-kit/core` の使い方
- 楽観的更新と並び替えの組み合わせ
- アクセシビリティ（キーボード操作）も配慮した実装

## 📖 概念の説明

### なぜ一括操作が必要か

10 件のタスクをまとめて完了にしたいときに、1 件ずつ「完了」ボタンを押させるのは UX として最悪です。チェックボックスで選択 → 「選択中の項目を完了にする」ボタンで一発、というパターンが業務系 UI の基本です。

### 選択状態は `Set` で管理する

配列でも実装できますが、

- 含まれているか判定: `arr.includes(id)` は O(n)、 `set.has(id)` は O(1)
- 重複が起きない
- 追加削除のコードが直感的

という理由から `Set<string>` がおすすめです。

### ドラッグ&ドロップとは

「マウスでつかんで動かす」操作。ファイルをアップロードしたり、リストを並び替えたりするときに使います。React で実装するときは、HTML5 の `draggable` 属性を使う方法と、`@dnd-kit/core` のようなライブラリを使う方法があります。

学習用には HTML5 の方が短く書けますが、本格的に使うならライブラリ一択です。理由はキーボード操作・タッチ・スクリーンリーダー対応が必要だから。

### 楽観的並び替え

ドラッグして離した瞬間にサーバへ「順序が変わった」を送信し、結果を待たずに画面を更新します。これがないと、「離した→数百ミリ秒待つ→順番が変わる」というモッサリ感が出ます。

## 💻 コード例

### 一括選択の状態管理

```ts
// src/features/tasks/useSelection.ts
import { useCallback, useState } from "react";

export function useSelection<T>(getId: (item: T) => string) {
  const [selected, setSelected] = useState<Set<string>>(new Set());

  const toggle = useCallback((id: string) => {
    setSelected((prev) => {
      const next = new Set(prev);
      next.has(id) ? next.delete(id) : next.add(id);
      return next;
    });
  }, []);

  const selectAll = useCallback(
    (items: T[]) => setSelected(new Set(items.map(getId))),
    [getId]
  );

  const clear = useCallback(() => setSelected(new Set()), []);

  return { selected, toggle, selectAll, clear };
}
```

### 一括操作 UI

```tsx
function TaskListWithBulk({ items }: { items: Task[] }) {
  const { selected, toggle, selectAll, clear } = useSelection<Task>(
    (t) => t.id
  );
  const bulkDone = useBulkUpdate();
  const bulkDelete = useBulkDelete();

  const allChecked = items.length > 0 && items.every((t) => selected.has(t.id));
  const someChecked = items.some((t) => selected.has(t.id)) && !allChecked;

  return (
    <>
      {selected.size > 0 && (
        <div role="toolbar" aria-label="選択中の操作">
          <span>{selected.size} 件選択中</span>
          <button
            onClick={() => bulkDone.mutate([...selected], { onSuccess: clear })}
          >
            完了にする
          </button>
          <button
            onClick={() =>
              confirm("削除しますか？") &&
              bulkDelete.mutate([...selected], { onSuccess: clear })
            }
          >
            削除
          </button>
          <button onClick={clear}>選択解除</button>
        </div>
      )}

      <table>
        <thead>
          <tr>
            <th>
              <input
                type="checkbox"
                aria-label="すべて選択"
                checked={allChecked}
                ref={(el) => el && (el.indeterminate = someChecked)}
                onChange={(e) =>
                  e.target.checked ? selectAll(items) : clear()
                }
              />
            </th>
            <th>タイトル</th>
            <th>期限</th>
          </tr>
        </thead>
        <tbody>
          {items.map((t) => (
            <tr key={t.id}>
              <td>
                <input
                  type="checkbox"
                  checked={selected.has(t.id)}
                  onChange={() => toggle(t.id)}
                  aria-label={`${t.title} を選択`}
                />
              </td>
              <td>{t.title}</td>
              <td>{t.dueDate ?? "-"}</td>
            </tr>
          ))}
        </tbody>
      </table>
    </>
  );
}
```

`indeterminate`（中間状態）の見た目を出すには ref で直接代入する必要があるのがポイント。

### 一括 mutation

```ts
function useBulkUpdate() {
  const qc = useQueryClient();
  return useMutation({
    mutationFn: (ids: string[]) =>
      api("/tasks/bulk-done", {
        method: "POST",
        body: JSON.stringify({ ids }),
      }),
    onSuccess: () => qc.invalidateQueries({ queryKey: ["tasks"] }),
  });
}
```

サーバ側で 1 リクエストにまとめると、ネットワーク往復回数が激減します。

### ドラッグ&ドロップ: `@dnd-kit/core`

```bash
npm i @dnd-kit/core @dnd-kit/sortable @dnd-kit/utilities
```

```tsx
import {
  DndContext,
  closestCenter,
  KeyboardSensor,
  PointerSensor,
  useSensor,
  useSensors,
  DragEndEvent,
} from "@dnd-kit/core";
import {
  arrayMove,
  SortableContext,
  sortableKeyboardCoordinates,
  useSortable,
  verticalListSortingStrategy,
} from "@dnd-kit/sortable";
import { CSS } from "@dnd-kit/utilities";

function SortableRow({ task }: { task: Task }) {
  const { attributes, listeners, setNodeRef, transform, transition } =
    useSortable({ id: task.id });

  const style = {
    transform: CSS.Transform.toString(transform),
    transition,
  };

  return (
    <li ref={setNodeRef} style={style} {...attributes} {...listeners}>
      <span aria-hidden>≡</span>
      {task.title}
    </li>
  );
}

export function ReorderableList({ initial }: { initial: Task[] }) {
  const [items, setItems] = useState(initial);
  const reorder = useMutation({
    mutationFn: (ids: string[]) =>
      api("/tasks/reorder", {
        method: "POST",
        body: JSON.stringify({ ids }),
      }),
  });

  const sensors = useSensors(
    useSensor(PointerSensor),
    useSensor(KeyboardSensor, {
      coordinateGetter: sortableKeyboardCoordinates,
    })
  );

  function onDragEnd(e: DragEndEvent) {
    const { active, over } = e;
    if (!over || active.id === over.id) return;

    const oldIndex = items.findIndex((t) => t.id === active.id);
    const newIndex = items.findIndex((t) => t.id === over.id);
    const next = arrayMove(items, oldIndex, newIndex);
    setItems(next); // 楽観的更新
    reorder.mutate(next.map((t) => t.id));
  }

  return (
    <DndContext
      sensors={sensors}
      collisionDetection={closestCenter}
      onDragEnd={onDragEnd}
    >
      <SortableContext
        items={items.map((t) => t.id)}
        strategy={verticalListSortingStrategy}
      >
        <ul>
          {items.map((t) => (
            <SortableRow key={t.id} task={t} />
          ))}
        </ul>
      </SortableContext>
    </DndContext>
  );
}
```

`@dnd-kit` は `KeyboardSensor` を使うと矢印キーでも並び替えできるのが嬉しいポイント。

### HTML5 だけで簡易 DnD（学習用）

```tsx
function MiniDnd() {
  const [items, setItems] = useState(["A", "B", "C"]);
  const dragIndex = useRef<number | null>(null);

  return (
    <ul>
      {items.map((it, i) => (
        <li
          key={it}
          draggable
          onDragStart={() => (dragIndex.current = i)}
          onDragOver={(e) => e.preventDefault()}
          onDrop={() => {
            if (dragIndex.current === null || dragIndex.current === i) return;
            const next = [...items];
            const [moved] = next.splice(dragIndex.current, 1);
            next.splice(i, 0, moved);
            setItems(next);
            dragIndex.current = null;
          }}
        >
          {it}
        </li>
      ))}
    </ul>
  );
}
```

短くて学習向きですが、キーボード対応・タッチ対応・スクリーンリーダー対応はないので本番では非推奨。

## ❌ よくある間違い

### 1. 選択状態を配列で持って `includes` を多用

行数が増えると体感できる遅延が出ます。`Set` を使いましょう。

### 2. 全選択チェックボックスの indeterminate を実装しない

部分選択時に「全選択チェックボックス」が空に見えてしまい、ユーザーが混乱します。`ref` 経由で `indeterminate` を立てましょう。

### 3. ドラッグ&ドロップでサーバ通信を待ってから UI 更新

体感が重いです。先に `setItems(next)` で見た目を変え、裏でサーバ送信。失敗したらロールバック。

### 4. キーボード操作を諦める

`@dnd-kit` の `KeyboardSensor` を使えば、フォーカス + 矢印キーで並び替えできます。アクセシビリティの基本要件です。

### 5. 一括操作で `Promise.all(items.map(api))` する

一見動きますが、API レート制限・サーバ負荷を考えるとサーバ側で一括 API を作るべきです。

## ✅ ベストプラクティス

1. **`Set` で選択管理**: 計算量と可読性が両立。
2. **一括操作はサーバ API を 1 本作る**: クライアントで N 回叩くより速くて安全。
3. **DnD は `@dnd-kit` を使う**: アクセシビリティをタダで手に入れられる。
4. **楽観的更新でサクサク感を演出**: 失敗時のロールバックを忘れずに。
5. **ツールバーは選択時のみ表示**: 普段は隠して画面をすっきり保つ。

## 📝 まとめ

- 一括操作は「複数選択 + 1 アクション」で UX が劇的に向上
- 選択状態は `Set` で持つと O(1) 判定ができ快適
- DnD は `@dnd-kit` を使うとキーボード対応も自動で得られる
- 並び替えは楽観的更新 + サーバ反映が定番
- `indeterminate` チェックボックスで部分選択を可視化する
