# 一括操作の実装方法とベストプラクティス

## 概要

一括操作（複数選択、一括削除・更新）の実装には主に3つの方法があります。それぞれの特徴、メリット・デメリット、使用場面を詳しく解説します。

## 実装方法の比較表

| 項目 | チェックボックス | 選択モード | ドラッグ選択 |
|------|---------------|--------------|----------------|
| **実装の複雑さ** | ⭐ 簡単 | ⭐⭐ 中程度 | ⭐⭐⭐ 複雑 |
| **ユーザビリティ** | ⭐⭐⭐ 直感的 | ⭐⭐⭐ 直感的 | ⭐⭐ 中程度 |
| **選択の精度** | ⭐⭐⭐ 高精度 | ⭐⭐ 中程度 | ⭐⭐ 中程度 |
| **モバイル対応** | ⭐⭐ 中程度 | ⭐⭐⭐ 良好 | ⭐ 困難 |
| **アクセシビリティ** | ⭐⭐⭐ 良好 | ⭐⭐ 中程度 | ⭐ 困難 |
| **パフォーマンス** | ⭐⭐ 中程度 | ⭐⭐⭐ 良好 | ⭐⭐ 中程度 |
| **選択範囲** | ⭐ 個別のみ | ⭐⭐⭐ 範囲選択可能 | ⭐⭐⭐ 範囲選択可能 |
| **視覚的フィードバック** | ⭐⭐⭐ 明確 | ⭐⭐ 中程度 | ⭐⭐ 中程度 |
| **学習コスト** | ⭐ 低い | ⭐⭐ 中程度 | ⭐⭐⭐ 高い |
| **実装コスト** | ⭐ 低い | ⭐⭐ 中程度 | ⭐⭐⭐ 高い |

### 推奨使用場面

| 実装方法 | 最適な使用場面 | 例 |
|----------|----------------|-----|
| **チェックボックス** | 少量の個別選択 | メール削除、ファイル管理、設定変更 |
| **選択モード** | 大量データの範囲選択 | 画像ギャラリー、楽曲プレイリスト、表データ |
| **ドラッグ選択** | 直感的な範囲選択 | ファイルエクスプローラー、画像編集、表計算 |

## 1. チェックボックス

### 概要
各アイテムにチェックボックスを配置し、個別に選択できる方法

### 実装例

```javascript
import { useState, useMemo } from 'react';

function CheckboxBulkOperations() {
  const [items, setItems] = useState([
    { id: 1, name: 'アイテム1', category: 'A', selected: false },
    { id: 2, name: 'アイテム2', category: 'B', selected: false },
    { id: 3, name: 'アイテム3', category: 'A', selected: false },
    { id: 4, name: 'アイテム4', category: 'C', selected: false },
    { id: 5, name: 'アイテム5', category: 'B', selected: false }
  ]);

  // 選択状態の管理
  const toggleItemSelection = (id) => {
    setItems(items.map(item => 
      item.id === id ? { ...item, selected: !item.selected } : item
    ));
  };

  const toggleAllSelection = () => {
    const allSelected = items.every(item => item.selected);
    setItems(items.map(item => ({ ...item, selected: !allSelected })));
  };

  // 選択されたアイテムの取得
  const selectedItems = useMemo(() => 
    items.filter(item => item.selected), [items]
  );

  const selectedCount = selectedItems.length;
  const totalCount = items.length;
  const allSelected = selectedCount === totalCount;
  const someSelected = selectedCount > 0 && selectedCount < totalCount;

  // 一括操作
  const bulkDelete = () => {
    if (!confirm(`${selectedCount}個のアイテムを削除しますか？`)) return;
    
    setItems(items.filter(item => !item.selected));
  };

  const bulkUpdateCategory = (newCategory) => {
    setItems(items.map(item => 
      item.selected ? { ...item, category: newCategory } : item
    ));
  };

  const clearSelection = () => {
    setItems(items.map(item => ({ ...item, selected: false })));
  };

  return (
    <div>
      {/* 一括操作コントロール */}
      <div style={{ 
        padding: '10px', 
        backgroundColor: '#f5f5f5', 
        marginBottom: '10px',
        display: selectedCount > 0 ? 'block' : 'none'
      }}>
        <strong>{selectedCount}個選択中</strong>
        <button onClick={bulkDelete} style={{ marginLeft: '10px' }}>
          削除
        </button>
        <select 
          onChange={(e) => bulkUpdateCategory(e.target.value)}
          style={{ marginLeft: '10px' }}
        >
          <option value="">カテゴリを変更</option>
          <option value="A">カテゴリA</option>
          <option value="B">カテゴリB</option>
          <option value="C">カテゴリC</option>
        </select>
        <button onClick={clearSelection} style={{ marginLeft: '10px' }}>
          選択解除
        </button>
      </div>

      {/* 全選択コントロール */}
      <div style={{ marginBottom: '10px' }}>
        <label>
          <input
            type="checkbox"
            checked={allSelected}
            ref={input => {
              if (input) input.indeterminate = someSelected;
            }}
            onChange={toggleAllSelection}
          />
          すべて選択 ({selectedCount}/{totalCount})
        </label>
      </div>

      {/* アイテムリスト */}
      <ul style={{ listStyle: 'none', padding: 0 }}>
        {items.map(item => (
          <li 
            key={item.id} 
            style={{ 
              padding: '8px',
              backgroundColor: item.selected ? '#e3f2fd' : 'white',
              border: '1px solid #ddd',
              marginBottom: '2px'
            }}
          >
            <label style={{ display: 'flex', alignItems: 'center', cursor: 'pointer' }}>
              <input
                type="checkbox"
                checked={item.selected}
                onChange={() => toggleItemSelection(item.id)}
                style={{ marginRight: '10px' }}
              />
              <span style={{ flex: 1 }}>{item.name}</span>
              <span style={{ 
                fontSize: '12px', 
                color: '#666',
                backgroundColor: '#f0f0f0',
                padding: '2px 6px',
                borderRadius: '3px'
              }}>
                {item.category}
              </span>
            </label>
          </li>
        ))}
      </ul>
    </div>
  );
}
```

### メリット
- ✅ **実装が簡単**: 基本的なチェックボックス機能で実装可能
- ✅ **直感的**: ユーザーにとって理解しやすい操作
- ✅ **アクセシビリティ**: スクリーンリーダー対応が容易
- ✅ **個別選択**: 必要なアイテムのみを正確に選択可能
- ✅ **視覚的フィードバック**: 選択状態が明確に表示される

### デメリット
- ❌ **大量データ**: アイテム数が多いと操作が煩雑
- ❌ **範囲選択**: 連続したアイテムの選択が困難
- ❌ **UIの複雑さ**: チェックボックスでUIが散らかる
- ❌ **モバイル対応**: 小さな画面での操作が困難

### 使用場面
- 📧 **メール管理**: 個別メールの選択と削除
- 📁 **ファイル管理**: 特定ファイルの選択と操作
- ⚙️ **設定管理**: 個別設定項目の一括変更
- 📊 **小規模データ**: 100個以下のアイテム管理

## 2. 選択モード

### 概要
選択モードを有効にし、タップやクリックでアイテムを選択できる方法

### 実装例

```javascript
import { useState, useMemo, useCallback } from 'react';

function SelectionModeBulkOperations() {
  const [items, setItems] = useState([
    { id: 1, name: '画像1.jpg', size: '2.3MB', selected: false },
    { id: 2, name: '画像2.png', size: '1.8MB', selected: false },
    { id: 3, name: '画像3.gif', size: '3.1MB', selected: false },
    { id: 4, name: '画像4.jpg', size: '2.7MB', selected: false },
    { id: 5, name: '画像5.png', size: '1.5MB', selected: false }
  ]);

  const [selectionMode, setSelectionMode] = useState(false);
  const [lastSelectedIndex, setLastSelectedIndex] = useState(-1);

  // 選択状態の管理
  const toggleItemSelection = useCallback((id, index) => {
    if (!selectionMode) return;

    setItems(prevItems => 
      prevItems.map(item => 
        item.id === id ? { ...item, selected: !item.selected } : item
      )
    );
    setLastSelectedIndex(index);
  }, [selectionMode]);

  const selectRange = useCallback((startIndex, endIndex) => {
    if (!selectionMode) return;

    const start = Math.min(startIndex, endIndex);
    const end = Math.max(startIndex, endIndex);

    setItems(prevItems => 
      prevItems.map((item, index) => 
        index >= start && index <= end ? { ...item, selected: true } : item
      )
    );
  }, [selectionMode]);

  const handleItemClick = useCallback((id, index, event) => {
    if (selectionMode) {
      if (event.shiftKey && lastSelectedIndex !== -1) {
        // Shift+クリックで範囲選択
        selectRange(lastSelectedIndex, index);
      } else {
        // 通常のクリック
        toggleItemSelection(id, index);
      }
    }
  }, [selectionMode, lastSelectedIndex, toggleItemSelection, selectRange]);

  // 選択されたアイテムの取得
  const selectedItems = useMemo(() => 
    items.filter(item => item.selected), [items]
  );

  const selectedCount = selectedItems.length;
  const totalSize = useMemo(() => 
    selectedItems.reduce((sum, item) => sum + parseFloat(item.size), 0).toFixed(1)
  , [selectedItems]);

  // 一括操作
  const bulkDelete = () => {
    if (!confirm(`${selectedCount}個のファイルを削除しますか？`)) return;
    
    setItems(items.filter(item => !item.selected));
    exitSelectionMode();
  };

  const bulkDownload = () => {
    // ダウンロード処理の実装
    console.log('ダウンロード:', selectedItems.map(item => item.name));
    exitSelectionMode();
  };

  const exitSelectionMode = () => {
    setSelectionMode(false);
    setItems(items.map(item => ({ ...item, selected: false })));
    setLastSelectedIndex(-1);
  };

  const enterSelectionMode = () => {
    setSelectionMode(true);
  };

  return (
    <div>
      {/* 選択モードのコントロール */}
      {selectionMode ? (
        <div style={{ 
          padding: '10px', 
          backgroundColor: '#2196f3', 
          color: 'white',
          marginBottom: '10px',
          display: 'flex',
          justifyContent: 'space-between',
          alignItems: 'center'
        }}>
          <div>
            <strong>{selectedCount}個選択中</strong>
            {selectedCount > 0 && (
              <span style={{ marginLeft: '10px', fontSize: '14px' }}>
                (合計: {totalSize}MB)
              </span>
            )}
          </div>
          <div>
            {selectedCount > 0 && (
              <>
                <button 
                  onClick={bulkDownload}
                  style={{ 
                    marginRight: '10px',
                    padding: '5px 10px',
                    backgroundColor: 'white',
                    color: '#2196f3',
                    border: 'none',
                    borderRadius: '3px'
                  }}
                >
                  ダウンロード
                </button>
                <button 
                  onClick={bulkDelete}
                  style={{ 
                    marginRight: '10px',
                    padding: '5px 10px',
                    backgroundColor: '#f44336',
                    color: 'white',
                    border: 'none',
                    borderRadius: '3px'
                  }}
                >
                  削除
                </button>
              </>
            )}
            <button 
              onClick={exitSelectionMode}
              style={{ 
                padding: '5px 10px',
                backgroundColor: 'white',
                color: '#2196f3',
                border: 'none',
                borderRadius: '3px'
              }}
            >
              キャンセル
            </button>
          </div>
        </div>
      ) : (
        <div style={{ marginBottom: '10px' }}>
          <button 
            onClick={enterSelectionMode}
            style={{ 
              padding: '8px 16px',
              backgroundColor: '#2196f3',
              color: 'white',
              border: 'none',
              borderRadius: '4px'
            }}
          >
            選択モード
          </button>
        </div>
      )}

      {/* アイテムグリッド */}
      <div style={{ 
        display: 'grid', 
        gridTemplateColumns: 'repeat(auto-fill, minmax(200px, 1fr))', 
        gap: '10px' 
      }}>
        {items.map((item, index) => (
          <div
            key={item.id}
            onClick={(e) => handleItemClick(item.id, index, e)}
            style={{
              padding: '15px',
              border: '2px solid',
              borderColor: item.selected ? '#2196f3' : '#ddd',
              borderRadius: '8px',
              backgroundColor: item.selected ? '#e3f2fd' : 'white',
              cursor: 'pointer',
              transition: 'all 0.2s ease',
              position: 'relative'
            }}
          >
            {selectionMode && (
              <div style={{
                position: 'absolute',
                top: '8px',
                right: '8px',
                width: '20px',
                height: '20px',
                border: '2px solid #2196f3',
                borderRadius: '50%',
                backgroundColor: item.selected ? '#2196f3' : 'white',
                display: 'flex',
                alignItems: 'center',
                justifyContent: 'center'
              }}>
                {item.selected && (
                  <span style={{ color: 'white', fontSize: '12px' }}>✓</span>
                )}
              </div>
            )}
            
            <div style={{ textAlign: 'center' }}>
              <div style={{ fontSize: '24px', marginBottom: '8px' }}>📷</div>
              <div style={{ fontWeight: 'bold', marginBottom: '4px' }}>
                {item.name}
              </div>
              <div style={{ fontSize: '12px', color: '#666' }}>
                {item.size}
              </div>
            </div>
          </div>
        ))}
      </div>

      {/* ヘルプテキスト */}
      {selectionMode && (
        <div style={{ 
          marginTop: '20px', 
          padding: '10px', 
          backgroundColor: '#f9f9f9',
          fontSize: '14px',
          color: '#666'
        }}>
          <strong>操作ヒント:</strong>
          <br />• アイテムをクリックして選択/解除
          <br />• Shift+クリックで範囲選択
          <br />• 選択後は上部のボタンで一括操作
        </div>
      )}
    </div>
  );
}
```

### メリット
- ✅ **大量データ対応**: 効率的に多くのアイテムを選択可能
- ✅ **範囲選択**: Shift+クリックで連続選択が可能
- ✅ **UIがすっきり**: 選択モード時のみ選択UIが表示
- ✅ **モバイル対応**: タップ操作で直感的に選択可能
- ✅ **パフォーマンス**: 必要な時のみ選択状態を管理

### デメリット
- ❌ **学習コスト**: ユーザーが選択モードを理解する必要
- ❌ **実装の複雑さ**: 範囲選択のロジックが複雑
- ❌ **アクセシビリティ**: キーボード操作の実装が複雑
- ❌ **状態管理**: 選択モードの状態管理が必要

### 使用場面
- 📱 **モバイルアプリ**: 写真、動画、音楽の管理
- 🖼️ **画像ギャラリー**: 大量の画像選択と操作
- 📊 **データテーブル**: 表データの範囲選択
- 🎵 **メディアプレイヤー**: 楽曲の一括操作

## 3. ドラッグ選択

### 概要
マウスドラッグで範囲を選択し、その範囲内のアイテムを一括選択する方法

### 実装例

```javascript
import { useState, useRef, useCallback, useEffect } from 'react';

function DragSelectionBulkOperations() {
  const [items, setItems] = useState(
    Array.from({ length: 50 }, (_, i) => ({
      id: i + 1,
      name: `ファイル${i + 1}.txt`,
      size: `${Math.floor(Math.random() * 1000) + 100}KB`,
      selected: false
    }))
  );

  const [isDragging, setIsDragging] = useState(false);
  const [dragStart, setDragStart] = useState({ x: 0, y: 0 });
  const [dragEnd, setDragEnd] = useState({ x: 0, y: 0 });
  const containerRef = useRef(null);

  // アイテムの位置とサイズを計算
  const getItemBounds = useCallback((index) => {
    const itemsPerRow = 5;
    const itemWidth = 120;
    const itemHeight = 100;
    const gap = 10;
    
    const row = Math.floor(index / itemsPerRow);
    const col = index % itemsPerRow;
    
    return {
      left: col * (itemWidth + gap),
      top: row * (itemHeight + gap),
      right: col * (itemWidth + gap) + itemWidth,
      bottom: row * (itemHeight + gap) + itemHeight
    };
  }, []);

  // ドラッグ開始
  const handleMouseDown = useCallback((e) => {
    if (e.target === containerRef.current) {
      setIsDragging(true);
      const rect = containerRef.current.getBoundingClientRect();
      setDragStart({
        x: e.clientX - rect.left,
        y: e.clientY - rect.top
      });
      setDragEnd({
        x: e.clientX - rect.left,
        y: e.clientY - rect.top
      });
    }
  }, []);

  // ドラッグ中
  const handleMouseMove = useCallback((e) => {
    if (!isDragging) return;
    
    const rect = containerRef.current.getBoundingClientRect();
    setDragEnd({
      x: e.clientX - rect.left,
      y: e.clientY - rect.top
    });
  }, [isDragging]);

  // ドラッグ終了
  const handleMouseUp = useCallback(() => {
    if (!isDragging) return;
    
    setIsDragging(false);
    
    // 選択範囲内のアイテムを選択
    const selectionRect = {
      left: Math.min(dragStart.x, dragEnd.x),
      top: Math.min(dragStart.y, dragEnd.y),
      right: Math.max(dragStart.x, dragEnd.x),
      bottom: Math.max(dragStart.y, dragEnd.y)
    };

    setItems(prevItems => 
      prevItems.map((item, index) => {
        const bounds = getItemBounds(index);
        const isInSelection = !(
          bounds.right < selectionRect.left ||
          bounds.left > selectionRect.right ||
          bounds.bottom < selectionRect.top ||
          bounds.top > selectionRect.bottom
        );
        
        return isInSelection ? { ...item, selected: true } : item;
      })
    );
  }, [isDragging, dragStart, dragEnd, getItemBounds]);

  // イベントリスナーの設定
  useEffect(() => {
    if (isDragging) {
      document.addEventListener('mousemove', handleMouseMove);
      document.addEventListener('mouseup', handleMouseUp);
      
      return () => {
        document.removeEventListener('mousemove', handleMouseMove);
        document.removeEventListener('mouseup', handleMouseUp);
      };
    }
  }, [isDragging, handleMouseMove, handleMouseUp]);

  // 一括操作
  const selectedItems = items.filter(item => item.selected);
  const selectedCount = selectedItems.length;

  const bulkDelete = () => {
    if (!confirm(`${selectedCount}個のファイルを削除しますか？`)) return;
    setItems(items.filter(item => !item.selected));
  };

  const clearSelection = () => {
    setItems(items.map(item => ({ ...item, selected: false })));
  };

  const selectAll = () => {
    setItems(items.map(item => ({ ...item, selected: true })));
  };

  return (
    <div>
      {/* 操作コントロール */}
      <div style={{ 
        padding: '10px', 
        backgroundColor: '#f5f5f5', 
        marginBottom: '10px',
        display: 'flex',
        justifyContent: 'space-between',
        alignItems: 'center'
      }}>
        <div>
          <strong>{selectedCount}個選択中</strong>
        </div>
        <div>
          <button onClick={selectAll} style={{ marginRight: '10px' }}>
            すべて選択
          </button>
          <button onClick={clearSelection} style={{ marginRight: '10px' }}>
            選択解除
          </button>
          {selectedCount > 0 && (
            <button onClick={bulkDelete} style={{ 
              backgroundColor: '#f44336',
              color: 'white',
              border: 'none',
              padding: '5px 10px',
              borderRadius: '3px'
            }}>
              削除
            </button>
          )}
        </div>
      </div>

      {/* アイテムグリッド */}
      <div
        ref={containerRef}
        onMouseDown={handleMouseDown}
        style={{
          position: 'relative',
          display: 'grid',
          gridTemplateColumns: 'repeat(5, 120px)',
          gap: '10px',
          padding: '10px',
          backgroundColor: '#fafafa',
          minHeight: '400px',
          cursor: isDragging ? 'crosshair' : 'default'
        }}
      >
        {items.map((item, index) => (
          <div
            key={item.id}
            style={{
              width: '120px',
              height: '100px',
              padding: '10px',
              border: '2px solid',
              borderColor: item.selected ? '#2196f3' : '#ddd',
              borderRadius: '8px',
              backgroundColor: item.selected ? '#e3f2fd' : 'white',
              display: 'flex',
              flexDirection: 'column',
              alignItems: 'center',
              justifyContent: 'center',
              fontSize: '12px',
              textAlign: 'center',
              userSelect: 'none'
            }}
          >
            <div style={{ fontSize: '20px', marginBottom: '4px' }}>📄</div>
            <div style={{ fontWeight: 'bold' }}>{item.name}</div>
            <div style={{ color: '#666' }}>{item.size}</div>
          </div>
        ))}

        {/* 選択範囲の表示 */}
        {isDragging && (
          <div
            style={{
              position: 'absolute',
              left: Math.min(dragStart.x, dragEnd.x),
              top: Math.min(dragStart.y, dragEnd.y),
              width: Math.abs(dragEnd.x - dragStart.x),
              height: Math.abs(dragEnd.y - dragStart.y),
              backgroundColor: 'rgba(33, 150, 243, 0.2)',
              border: '1px solid #2196f3',
              pointerEvents: 'none'
            }}
          />
        )}
      </div>

      {/* ヘルプテキスト */}
      <div style={{ 
        marginTop: '20px', 
        padding: '10px', 
        backgroundColor: '#f9f9f9',
        fontSize: '14px',
        color: '#666'
      }}>
        <strong>操作方法:</strong>
        <br />• 空いている部分をドラッグして範囲選択
        <br />• 選択されたアイテムは上部のボタンで一括操作
        <br />• Ctrl+クリックで個別選択/解除も可能
      </div>
    </div>
  );
}
```

### メリット
- ✅ **直感的**: ドラッグ操作で範囲選択が可能
- ✅ **効率的**: 大量のアイテムを一度に選択可能
- ✅ **視覚的**: 選択範囲が明確に表示される
- ✅ **範囲選択**: 矩形範囲での一括選択が可能
- ✅ **高速操作**: 素早く多くのアイテムを選択可能

### デメリット
- ❌ **実装が複雑**: ドラッグロジックと座標計算が必要
- ❌ **モバイル対応**: タッチ操作での実装が困難
- ❌ **アクセシビリティ**: キーボード操作の対応が困難
- ❌ **学習コスト**: ユーザーがドラッグ操作を理解する必要
- ❌ **誤操作**: 意図しない範囲選択が発生しやすい

### 使用場面
- 💻 **デスクトップアプリ**: ファイルエクスプローラー
- 🖼️ **画像編集ソフト**: 画像の範囲選択
- 📊 **表計算ソフト**: セルの範囲選択
- 🎨 **デザインツール**: オブジェクトの範囲選択

## 組み合わせパターン

実際のアプリケーションでは、複数の方法を組み合わせて使用することが多いです。

### パターン1: チェックボックス + 選択モード

```javascript
function HybridBulkOperations() {
  const [selectionMode, setSelectionMode] = useState(false);
  const [items, setItems] = useState([]);

  return (
    <div>
      {/* 選択モード切り替え */}
      <button onClick={() => setSelectionMode(!selectionMode)}>
        {selectionMode ? '通常モード' : '選択モード'}
      </button>

      {/* 選択モード時はチェックボックス、通常時は通常表示 */}
      {selectionMode ? (
        <CheckboxList items={items} onItemsChange={setItems} />
      ) : (
        <NormalList items={items} />
      )}
    </div>
  );
}
```

## まとめ

| 実装方法 | 適用場面 | 主なメリット | 主なデメリット |
|---------|---------|-------------|---------------|
| **チェックボックス** | 少量の個別選択 | 実装が簡単、直感的 | 大量データで操作が煩雑 |
| **選択モード** | 大量データの範囲選択 | 効率的、モバイル対応 | 学習コスト、実装の複雑さ |
| **ドラッグ選択** | 直感的な範囲選択 | 直感的、高速操作 | 実装が複雑、モバイル困難 |

### 選択の指針

1. **少量データ（<100個）** → チェックボックス
2. **大量データ（>100個）** → 選択モード
3. **デスクトップ中心** → ドラッグ選択
4. **複数の要件** → 組み合わせパターン
