## 概要

レポート機能は、データを分析・集計し、構造化された形式で出力する重要な機能です。PDF出力、Excel出力、CSV出力、HTMLレポートなど、様々な出力形式とその実装方法を詳しく解説します。

## レポート機能の種類と比較表

| 項目 | PDF出力 | Excel出力 | CSV出力 | HTMLレポート | 印刷レポート |
|------|---------|-----------|---------|-------------|-------------|
| **実装の複雑さ** | ⭐⭐⭐ 複雑 | ⭐⭐ 中程度 | ⭐ 簡単 | ⭐⭐ 中程度 | ⭐⭐ 中程度 |
| **パフォーマンス** | ⭐⭐ 中程度 | ⭐⭐ 中程度 | ⭐⭐⭐ 高速 | ⭐⭐⭐ 高速 | ⭐⭐ 中程度 |
| **カスタマイズ性** | ⭐⭐⭐ 高い | ⭐⭐ 中程度 | ⭐ 低い | ⭐⭐⭐ 高い | ⭐⭐ 中程度 |
| **データ量対応** | ⭐⭐ 中程度 | ⭐⭐ 中程度 | ⭐⭐⭐ 高い | ⭐⭐⭐ 高い | ⭐⭐ 中程度 |

## 1. PDF出力

### 概要
構造化された文書としてPDF形式でレポートを出力する機能

### 実装例

```javascript
// PDF出力の基本的な実装
import jsPDF from 'jspdf';
import 'jspdf-autotable';

function PDFReportGenerator({ data, reportType }) {
  const generatePDF = () => {
    const doc = new jsPDF();
    
    // ヘッダーの追加
    doc.setFontSize(20);
    doc.text('売上レポート', 20, 30);
    
    doc.setFontSize(12);
    doc.text(`生成日時: ${new Date().toLocaleString()}`, 20, 45);
    doc.text(`レポート期間: ${data.period}`, 20, 55);
    
    // サマリー情報の追加
    doc.setFontSize(14);
    doc.text('サマリー', 20, 75);
    
    doc.setFontSize(10);
    doc.text(`総売上: ¥${data.totalSales.toLocaleString()}`, 20, 90);
    doc.text(`注文数: ${data.totalOrders.toLocaleString()}件`, 20, 100);
    doc.text(`平均注文額: ¥${data.averageOrder.toLocaleString()}`, 20, 110);
    
    // テーブルの追加
    doc.autoTable({
      startY: 130,
      head: [['期間', '売上', '注文数', '平均注文額']],
      body: data.monthlyData.map(item => [
        item.period,
        `¥${item.sales.toLocaleString()}`,
        `${item.orders.toLocaleString()}件`,
        `¥${item.average.toLocaleString()}`
      ]),
      styles: {
        fontSize: 10,
        cellPadding: 5
      },
      headStyles: {
        fillColor: [66, 139, 202],
        textColor: 255
      }
    });
    
    // チャートの追加（画像として）
    if (data.chartImage) {
      doc.addImage(data.chartImage, 'PNG', 20, doc.lastAutoTable.finalY + 20, 150, 100);
    }
    
    // フッターの追加
    const pageCount = doc.internal.getNumberOfPages();
    for (let i = 1; i <= pageCount; i++) {
      doc.setPage(i);
      doc.setFontSize(8);
      doc.text(
        `ページ ${i} / ${pageCount}`,
        doc.internal.pageSize.width - 40,
        doc.internal.pageSize.height - 10
      );
    }
    
    // PDFの保存
    doc.save(`売上レポート_${new Date().toISOString().split('T')[0]}.pdf`);
  };

  return (
    <div className="pdf-generator">
      <button onClick={generatePDF} className="generate-pdf-btn">
        📄 PDFレポートを生成
      </button>
    </div>
  );
}
```

// CSV出力の基本的な実装
function CSVReportGenerator({ data }) {
  const generateCSV = () => {
    // CSVヘッダー
    const headers = ['期間', '売上', '注文数', '平均注文額', '前月比売上', '前月比注文数'];
    
    // CSVデータの生成
    const csvData = [
      headers,
      ...data.monthlyData.map(item => [
        item.period,
        item.sales,
        item.orders,
        item.average,
        item.salesGrowth,
        item.ordersGrowth
      ])
    ];
    
    // CSV文字列の生成
    const csvContent = csvData.map(row => 
      row.map(field => `"${field}"`).join(',')
    ).join('\n');
    
    // BOMを追加（Excelでの文字化け対策）
    const BOM = '\uFEFF';
    const csvWithBOM = BOM + csvContent;
    
    // ファイルのダウンロード
    const blob = new Blob([csvWithBOM], { type: 'text/csv;charset=utf-8;' });
    const link = document.createElement('a');
    const url = URL.createObjectURL(blob);
    
    link.setAttribute('href', url);
    link.setAttribute('download', `売上データ_${new Date().toISOString().split('T')[0]}.csv`);
    link.style.visibility = 'hidden';
    
    document.body.appendChild(link);
    link.click();
    document.body.removeChild(link);
  };

  return (
    <div className="csv-generator">
      <button onClick={generateCSV} className="generate-csv-btn">
        📄 CSVデータを出力
      </button>
    </div>
  );
}

// 複数のCSVファイルを生成
function AdvancedCSVReport({ data }) {
  const generateMultipleCSV = () => {
    const reports = [
      {
        name: '売上データ',
        filename: 'sales_data.csv',
        data: data.salesData
      },
      {
        name: '顧客データ',
        filename: 'customer_data.csv',
        data: data.customerData
      },
      {
        name: '商品データ',
        filename: 'product_data.csv',
        data: data.productData
      }
    ];
    
    reports.forEach(report => {
      const csvContent = generateCSVContent(report.data);
      downloadCSV(csvContent, report.filename);
    });
  };
  
  const generateCSVContent = (data) => {
    if (!data || data.length === 0) return '';
    
    const headers = Object.keys(data[0]);
    const csvData = [
      headers,
      ...data.map(row => headers.map(header => row[header]))
    ];
    
    return csvData.map(row => 
      row.map(field => `"${String(field).replace(/"/g, '""')}"`).join(',')
    ).join('\n');
  };
  
  const downloadCSV = (content, filename) => {
    const BOM = '\uFEFF';
    const csvWithBOM = BOM + content;
    
    const blob = new Blob([csvWithBOM], { type: 'text/csv;charset=utf-8;' });
    const link = document.createElement('a');
    const url = URL.createObjectURL(blob);
    
    link.setAttribute('href', url);
    link.setAttribute('download', filename);
    link.style.visibility = 'hidden';
    
    document.body.appendChild(link);
    link.click();
    document.body.removeChild(link);
  };

  return (
    <button onClick={generateMultipleCSV} className="generate-multiple-csv-btn">
      📊 複数CSVファイルを出力
    </button>
  );
}

- ✅ **可読性**: 人間が読みやすい形式

### デメリット

- ❌ **セキュリティ**: 悪意のあるスクリプトの実行リスク
- ❌ **互換性**: ブラウザによって表示が異なる可能性
- ❌ **編集制限**: 一部のアプリケーションで編集が困難

function StreamingReportGenerator({ data }) {
  const generateStreamingReport = async () => {
    const stream = new ReadableStream({
      start(controller) {
        // データをチャンクごとに出力
        data.forEach((chunk, index) => {
          if (index % 100 === 0) {
            controller.enqueue(chunk);
          }
        });
        controller.close();
      }
    });
    
    const response = new Response(stream);
    const blob = await response.blob();
    
    // ファイルのダウンロード
    downloadBlob(blob, 'report.csv');
  };
  
  return (

    </button>
  );
}

## まとめ

| 出力形式 | 適用場面 | 主なメリット | 主なデメリット |
|---------|---------|-------------|---------------|
| **PDF出力** | 正式な文書 | レイアウト制御、共有性 | 実装が複雑 |
| **Excel出力** | データ分析 | 編集可能、計算式 | ファイルサイズ |
| **CSV出力** | データ移行 | 実装が簡単、軽量 | レイアウト制限 |
| **HTMLレポート** | Web表示 | 可読性、スタイリング | セキュリティリスク |

### 選択の指針

1. **正式な文書** → PDF出力
2. **データ分析** → Excel出力
3. **データ移行** → CSV出力
4. **Web表示** → HTMLレポート
5. **大量データ** → ストリーミング出力
