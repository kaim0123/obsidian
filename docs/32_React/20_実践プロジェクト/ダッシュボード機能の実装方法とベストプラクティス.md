# ダッシュボード機能の実装方法とベストプラクティス

## 概要

ダッシュボード機能は、複数のデータソースから情報を集約し、ユーザーが一目で状況を把握できるようにする重要な機能です。レイアウト、ウィジェット、リアルタイム更新など、様々な要素とその実装方法を詳しく解説します。

## ダッシュボードの種類と比較表

| 項目 | 静的ダッシュボード | インタラクティブダッシュボード | リアルタイムダッシュボード | カスタマイズ可能ダッシュボード |
|------|-------------------|---------------------------|-------------------------|---------------------------|
| **実装の複雑さ** | ⭐ 簡単 | ⭐⭐ 中程度 | ⭐⭐⭐ 複雑 | ⭐⭐⭐ 複雑 |
| **パフォーマンス** | ⭐⭐⭐ 高速 | ⭐⭐ 中程度 | ⭐⭐ 中程度 | ⭐⭐ 中程度 |
| **ユーザビリティ** | ⭐⭐ 中程度 | ⭐⭐⭐ 高い | ⭐⭐⭐ 高い | ⭐⭐⭐ 高い |
| **カスタマイズ性** | ⭐ 低い | ⭐⭐ 中程度 | ⭐⭐ 中程度 | ⭐⭐⭐ 高い |
| **リアルタイム性** | ❌ なし | ❌ なし | ✅ あり | ⭐⭐ 中程度 |
| **学習コスト** | ⭐ 低い | ⭐⭐ 中程度 | ⭐⭐⭐ 高い | ⭐⭐⭐ 高い |

### 推奨使用場面

| ダッシュボードタイプ | 最適な使用場面 | 例 |
|---------------------|----------------|-----|
| **静的ダッシュボード** | 基本的な情報表示 | 管理画面、レポート画面 |
| **インタラクティブダッシュボード** | データの詳細分析 | ビジネス分析、KPI監視 |
| **リアルタイムダッシュボード** | 監視・監視システム | システム監視、株価表示 |
| **カスタマイズ可能ダッシュボード** | 個人化された画面 | 個人ダッシュボード、設定可能な画面 |

## 1. 静的ダッシュボード

### 概要
固定されたレイアウトで情報を表示する基本的なダッシュボード

### 実装例

```javascript
// 基本的な静的ダッシュボード
function StaticDashboard({ data }) {
  return (
    <div className="dashboard-container">
      <div className="dashboard-header">
        <h1>ダッシュボード</h1>
        <div className="last-updated">
          最終更新: {new Date().toLocaleString()}
        </div>
      </div>

      <div className="dashboard-grid">
        {/* KPIカード */}
        <div className="kpi-cards">
          <KPICard
            title="総売上"
            value={data.totalSales}
            change={data.salesChange}
            icon="💰"
          />
          <KPICard
            title="新規ユーザー"
            value={data.newUsers}
            change={data.usersChange}
            icon="👥"
          />
          <KPICard
            title="注文数"
            value={data.orders}
            change={data.ordersChange}
            icon="📦"
          />
          <KPICard
            title="コンバージョン率"
            value={data.conversionRate}
            change={data.conversionChange}
            icon="📈"
          />
        </div>

        {/* チャートエリア */}
        <div className="charts-section">
          <div className="chart-row">
            <div className="chart-half">
              <SalesChart data={data.salesData} />
            </div>
            <div className="chart-half">
              <UsersChart data={data.usersData} />
            </div>
          </div>
          <div className="chart-full">
            <OrdersChart data={data.ordersData} />
          </div>
        </div>

        {/* テーブルエリア */}
        <div className="table-section">
          <RecentOrdersTable data={data.recentOrders} />
        </div>
      </div>
    </div>
  );
}

// KPIカードコンポーネント
function KPICard({ title, value, change, icon }) {
  const isPositive = change >= 0;
  
  return (
    <div className="kpi-card">
      <div className="kpi-header">
        <span className="kpi-icon">{icon}</span>
        <h3 className="kpi-title">{title}</h3>
      </div>
      <div className="kpi-value">{value.toLocaleString()}</div>
      <div className={`kpi-change ${isPositive ? 'positive' : 'negative'}`}>
        {isPositive ? '↗' : '↘'} {Math.abs(change)}%
      </div>
    </div>
  );
}
```

### メリット
- ✅ **実装が簡単**: 基本的なレイアウトで実装可能
- ✅ **高速**: 静的なデータで高速表示
- ✅ **安定性**: シンプルで安定した動作
- ✅ **保守性**: コードが理解しやすい

### デメリット
- ❌ **柔軟性が低い**: レイアウトの変更が困難
- ❌ **インタラクションなし**: ユーザーとの対話ができない
- ❌ **リアルタイム性なし**: データの自動更新がない

### 使用場面
- 📊 **基本的な管理画面**: 管理者向けの情報表示
- 📈 **レポート画面**: 定期的なレポート表示
- 🎯 **シンプルな監視**: 基本的なKPI監視

## 2. インタラクティブダッシュボード

### 概要
ユーザーが操作できるインタラクティブな要素を持つダッシュボード

### 実装例

```javascript
// インタラクティブダッシュボード
function InteractiveDashboard({ initialData }) {
  const [data, setData] = useState(initialData);
  const [filters, setFilters] = useState({
    dateRange: '30days',
    category: 'all',
    region: 'all'
  });
  const [selectedChart, setSelectedChart] = useState('sales');

  // フィルターに基づくデータの更新
  const filteredData = useMemo(() => {
    return applyFilters(data, filters);
  }, [data, filters]);

  const handleFilterChange = (filterType, value) => {
    setFilters(prev => ({
      ...prev,
      [filterType]: value
    }));
  };

  const handleDataPointClick = (chartType, dataPoint) => {
    console.log(`${chartType}のデータポイントがクリックされました:`, dataPoint);
    // 詳細モーダルの表示など
  };

  return (
    <div className="interactive-dashboard">
      <div className="dashboard-header">
        <h1>インタラクティブダッシュボード</h1>
        <div className="dashboard-controls">
          <FilterControls 
            filters={filters}
            onChange={handleFilterChange}
          />
        </div>
      </div>

      <div className="dashboard-content">
        {/* サイドバー */}
        <div className="dashboard-sidebar">
          <ChartSelector
            selectedChart={selectedChart}
            onSelect={setSelectedChart}
          />
          <QuickStats data={filteredData} />
        </div>

        {/* メインコンテンツ */}
        <div className="dashboard-main">
          <div className="chart-container">
            {selectedChart === 'sales' && (
              <SalesChart 
                data={filteredData.sales} 
                onDataPointClick={(data) => handleDataPointClick('sales', data)}
              />
            )}
            {selectedChart === 'users' && (
              <UsersChart 
                data={filteredData.users} 
                onDataPointClick={(data) => handleDataPointClick('users', data)}
              />
            )}
            {selectedChart === 'orders' && (
              <OrdersChart 
                data={filteredData.orders} 
                onDataPointClick={(data) => handleDataPointClick('orders', data)}
              />
            )}
          </div>

          <div className="details-panel">
            <DataTable data={filteredData.tableData} />
          </div>
        </div>
      </div>
    </div>
  );
}

// フィルターコントロール
function FilterControls({ filters, onChange }) {
  return (
    <div className="filter-controls">
      <select
        value={filters.dateRange}
        onChange={(e) => onChange('dateRange', e.target.value)}
      >
        <option value="7days">過去7日</option>
        <option value="30days">過去30日</option>
        <option value="90days">過去90日</option>
        <option value="1year">過去1年</option>
      </select>

      <select
        value={filters.category}
        onChange={(e) => onChange('category', e.target.value)}
      >
        <option value="all">すべてのカテゴリ</option>
        <option value="electronics">電子機器</option>
        <option value="clothing">衣類</option>
        <option value="books">書籍</option>
      </select>

      <select
        value={filters.region}
        onChange={(e) => onChange('region', e.target.value)}
      >
        <option value="all">すべての地域</option>
        <option value="tokyo">東京</option>
        <option value="osaka">大阪</option>
        <option value="nagoya">名古屋</option>
      </select>
    </div>
  );
}
```

### メリット
- ✅ **ユーザビリティ**: ユーザーが操作できる
- ✅ **柔軟性**: フィルターや選択肢でデータを絞り込み
- ✅ **詳細分析**: データの詳細を確認可能
- ✅ **エンゲージメント**: ユーザーの関与を高める

### デメリット
- ❌ **実装が複雑**: インタラクションの実装が必要
- ❌ **パフォーマンス**: フィルター処理で若干重い
- ❌ **学習コスト**: ユーザーが機能を理解する必要

### 使用場面
- 📊 **ビジネス分析**: データの詳細分析
- 📈 **KPI監視**: 指標の詳細確認
- 🎯 **レポート**: インタラクティブなレポート

## 3. リアルタイムダッシュボード

### 概要
リアルタイムでデータが更新されるダッシュボード

### 実装例

```javascript
// リアルタイムダッシュボード
function RealtimeDashboard() {
  const [data, setData] = useState({
    metrics: {},
    charts: {},
    alerts: []
  });
  const [connectionStatus, setConnectionStatus] = useState('connecting');
  const [lastUpdate, setLastUpdate] = useState(new Date());

  // WebSocket接続
  useEffect(() => {
    const ws = new WebSocket('ws://localhost:8080/dashboard');
    
    ws.onopen = () => {
      setConnectionStatus('connected');
    };
    
    ws.onmessage = (event) => {
      const update = JSON.parse(event.data);
      setData(prevData => ({
        ...prevData,
        ...update
      }));
      setLastUpdate(new Date());
    };
    
    ws.onclose = () => {
      setConnectionStatus('disconnected');
    };
    
    ws.onerror = () => {
      setConnectionStatus('error');
    };
    
    return () => {
      ws.close();
    };
  }, []);

  return (
    <div className="realtime-dashboard">
      <div className="dashboard-header">
        <h1>リアルタイムダッシュボード</h1>
        <div className="status-indicators">
          <ConnectionStatus status={connectionStatus} />
          <LastUpdate time={lastUpdate} />
        </div>
      </div>

      <div className="dashboard-grid">
        {/* リアルタイムメトリクス */}
        <div className="realtime-metrics">
          <RealtimeMetric
            title="アクティブユーザー"
            value={data.metrics.activeUsers}
            trend={data.metrics.userTrend}
          />
          <RealtimeMetric
            title="売上（今日）"
            value={data.metrics.todaySales}
            trend={data.metrics.salesTrend}
          />
          <RealtimeMetric
            title="エラー率"
            value={data.metrics.errorRate}
            trend={data.metrics.errorTrend}
            isAlert={data.metrics.errorRate > 5}
          />
        </div>

        {/* リアルタイムチャート */}
        <div className="realtime-charts">
          <RealtimeChart
            title="リアルタイム売上"
            data={data.charts.sales}
            type="line"
          />
          <RealtimeChart
            title="ユーザーアクティビティ"
            data={data.charts.activity}
            type="bar"
          />
        </div>

        {/* アラートパネル */}
        <div className="alerts-panel">
          <AlertsList alerts={data.alerts} />
        </div>
      </div>
    </div>
  );
}

// リアルタイムメトリクスコンポーネント
function RealtimeMetric({ title, value, trend, isAlert = false }) {
  return (
    <div className={`realtime-metric ${isAlert ? 'alert' : ''}`}>
      <div className="metric-header">
        <h3>{title}</h3>
        <div className={`trend-indicator ${trend > 0 ? 'up' : 'down'}`}>
          {trend > 0 ? '↗' : '↘'} {Math.abs(trend)}%
        </div>
      </div>
      <div className="metric-value">
        {typeof value === 'number' ? value.toLocaleString() : value}
      </div>
      {isAlert && (
        <div className="alert-badge">⚠️ アラート</div>
      )}
    </div>
  );
}
```

### メリット
- ✅ **リアルタイム性**: 最新のデータを即座に表示
- ✅ **監視機能**: リアルタイムでの監視が可能
- ✅ **アラート**: 異常値の即座な検知
- ✅ **最新性**: 常に最新の情報を提供

### デメリット
- ❌ **実装が複雑**: WebSocketやリアルタイム処理が必要
- ❌ **リソース使用量**: 継続的な接続でリソースを消費
- ❌ **ネットワーク依存**: 接続状態に依存
- ❌ **パフォーマンス**: 頻繁な更新で重くなる可能性

### 使用場面
- 📊 **システム監視**: サーバーやアプリケーションの監視
- 📈 **株価表示**: リアルタイムの価格表示
- 🎮 **ゲーム**: リアルタイムのスコア表示
- 📱 **チャット**: リアルタイムのメッセージ表示

## 4. カスタマイズ可能ダッシュボード

### 概要
ユーザーがレイアウトやウィジェットをカスタマイズできるダッシュボード

### 実装例

```javascript
// カスタマイズ可能ダッシュボード
function CustomizableDashboard() {
  const [layout, setLayout] = useState(defaultLayout);
  const [widgets, setWidgets] = useState(defaultWidgets);
  const [isEditMode, setIsEditMode] = useState(false);

  const handleLayoutChange = (newLayout) => {
    setLayout(newLayout);
    // レイアウトの保存
    saveLayout(newLayout);
  };

  const handleWidgetAdd = (widgetType) => {
    const newWidget = createWidget(widgetType);
    setWidgets(prev => [...prev, newWidget]);
  };

  const handleWidgetRemove = (widgetId) => {
    setWidgets(prev => prev.filter(w => w.id !== widgetId));
  };

  const handleWidgetMove = (widgetId, newPosition) => {
    setLayout(prev => ({
      ...prev,
      [widgetId]: newPosition
    }));
  };

  return (
    <div className="customizable-dashboard">
      <div className="dashboard-header">
        <h1>マイダッシュボード</h1>
        <div className="dashboard-controls">
          <button
            onClick={() => setIsEditMode(!isEditMode)}
            className={`edit-mode-btn ${isEditMode ? 'active' : ''}`}
          >
            {isEditMode ? '完了' : '編集'}
          </button>
        </div>
      </div>

      {isEditMode && (
        <div className="widget-palette">
          <h3>ウィジェットを追加</h3>
          <div className="widget-types">
            <button onClick={() => handleWidgetAdd('chart')}>
              📊 チャート
            </button>
            <button onClick={() => handleWidgetAdd('table')}>
              📋 テーブル
            </button>
            <button onClick={() => handleWidgetAdd('metric')}>
              📈 メトリクス
            </button>
            <button onClick={() => handleWidgetAdd('text')}>
              📝 テキスト
            </button>
          </div>
        </div>
      )}

      <div className="dashboard-grid">
        <GridLayout
          className="layout"
          cols={12}
          rowHeight={60}
          width={1200}
          layout={layout}
          onLayoutChange={handleLayoutChange}
          isDraggable={isEditMode}
          isResizable={isEditMode}
        >
          {widgets.map(widget => (
            <div key={widget.id} className="widget-container">
              <Widget
                {...widget}
                isEditMode={isEditMode}
                onRemove={() => handleWidgetRemove(widget.id)}
              />
            </div>
          ))}
        </GridLayout>
      </div>
    </div>
  );
}

// ウィジェットコンポーネント
function Widget({ type, data, isEditMode, onRemove, ...props }) {
  const renderWidget = () => {
    switch (type) {
      case 'chart':
        return <ChartWidget data={data} />;
      case 'table':
        return <TableWidget data={data} />;
      case 'metric':
        return <MetricWidget data={data} />;
      case 'text':
        return <TextWidget data={data} />;
      default:
        return <div>不明なウィジェットタイプ</div>;
    }
  };

  return (
    <div className={`widget ${type}`}>
      {isEditMode && (
        <div className="widget-controls">
          <button onClick={onRemove} className="remove-btn">
            ×
          </button>
        </div>
      )}
      {renderWidget()}
    </div>
  );
}
```

### メリット
- ✅ **個人化**: ユーザーのニーズに合わせたカスタマイズ
- ✅ **柔軟性**: 自由なレイアウトとウィジェット配置
- ✅ **ユーザビリティ**: 使いやすい画面の構築
- ✅ **エンゲージメント**: ユーザーの関与を高める

### デメリット
- ❌ **実装が複雑**: ドラッグ&ドロップやレイアウト管理が必要
- ❌ **状態管理**: 複雑な状態管理が必要
- ❌ **パフォーマンス**: 動的なレイアウトで重くなる可能性
- ❌ **テスト**: 複雑な機能でテストが困難

### 使用場面
- 👤 **個人ダッシュボード**: ユーザー個人のカスタマイズ
- 🏢 **企業ダッシュボード**: 部署や役職に応じたカスタマイズ
- 🎯 **設定可能な画面**: ユーザーが設定できる画面

// 大量データの仮想化
function VirtualizedDashboard({ data }) {
  const [visibleWidgets, setVisibleWidgets] = useState([]);

  useEffect(() => {
    // 表示領域内のウィジェットのみを表示
    const visible = data.widgets.filter(widget => 
      isInViewport(widget.id)
    );
    setVisibleWidgets(visible);
  }, [data]);

  return (
    <div>
      {visibleWidgets.map(widget => (
        <Widget key={widget.id} {...widget} />
      ))}
    </div>
  );
}

## まとめ

| ダッシュボードタイプ | 適用場面 | 主なメリット | 主なデメリット |
|---------------------|---------|-------------|---------------|
| **静的ダッシュボード** | 基本的な情報表示 | 実装が簡単、高速 | 柔軟性が低い |
| **インタラクティブダッシュボード** | データ分析 | ユーザビリティ、柔軟性 | 実装が複雑 |
| **リアルタイムダッシュボード** | 監視システム | リアルタイム性、最新性 | 実装が複雑 |
| **カスタマイズ可能ダッシュボード** | 個人化 | 個人化、柔軟性 | 実装が複雑 |

### 選択の指針

1. **基本的な情報表示** → 静的ダッシュボード
2. **データ分析** → インタラクティブダッシュボード
3. **監視・監視** → リアルタイムダッシュボード
4. **個人化** → カスタマイズ可能ダッシュボード
