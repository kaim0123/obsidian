## フィードバック機能とは

フィードバック機能は、ユーザーからサービスやコンテンツに対する意見や評価を収集する機能です。ユーザーの声を聞くことで、サービス改善やユーザーエクスペリエンスの向上に活用できます。

### 主な特徴
- **意見収集**: ユーザーの生の声を収集
- **評価システム**: 5段階評価やスコアリング
- **分類機能**: フィードバックの種類別管理
- **分析機能**: データの可視化と分析

## フロントエンド実装例

### React での実装
```jsx
import React, { useState } from 'react';

const FeedbackModal = ({ isOpen, onClose, onSubmit }) => {
  const [formData, setFormData] = useState({
    type: '',
    rating: 0,
    message: ''
  });
  const [loading, setLoading] = useState(false);

  const handleSubmit = async (e) => {
    e.preventDefault();
    setLoading(true);

    try {
      await onSubmit(formData);
      setFormData({ type: '', rating: 0, message: '' });
      onClose();
    } catch (error) {
      console.error('フィードバック送信エラー:', error);
    } finally {
      setLoading(false);
    }
  };

  const handleInputChange = (e) => {
    const { name, value } = e.target;
    setFormData(prev => ({
      ...prev,
      [name]: value
    }));
  };

  if (!isOpen) return null;

  return (
    <div className="feedback-modal">
      <div className="feedback-content">
        <div className="feedback-header">
          <h2>フィードバック</h2>
          <button className="close-btn" onClick={onClose}>
            &times;
          </button>
        </div>

        <form className="feedback-form" onSubmit={handleSubmit}>
          <div className="feedback-type">
            <label>フィードバックの種類</label>
            <select
              name="type"
              value={formData.type}
              onChange={handleInputChange}
              required
            >
              <option value="">選択してください</option>
              <option value="bug">バグ報告</option>
              <option value="feature">機能要望</option>
              <option value="improvement">改善提案</option>
              <option value="general">その他</option>
            </select>
          </div>

          <div className="feedback-rating">
            <label>満足度</label>
            <div className="star-rating">
              {[5, 4, 3, 2, 1].map(star => (
                <React.Fragment key={star}>
                  <input
                    type="radio"
                    name="rating"
                    value={star}
                    id={`star${star}`}
                    checked={formData.rating == star}
                    onChange={handleInputChange}
                  />
                  <label htmlFor={`star${star}`}>★</label>
                </React.Fragment>
              ))}
            </div>
          </div>

          <div className="feedback-message">
            <label htmlFor="message">メッセージ</label>
            <textarea
              name="message"
              id="message"
              value={formData.message}
              onChange={handleInputChange}
              rows="5"
              placeholder="ご意見・ご要望をお聞かせください"
            />
          </div>

          <div className="feedback-actions">
            <button
              type="button"
              className="cancel-btn"
              onClick={onClose}
            >
              キャンセル
            </button>
            <button
              type="submit"
              className="submit-btn"
              disabled={loading}
            >
              {loading ? '送信中...' : '送信'}
            </button>
          </div>
        </form>
      </div>
    </div>
  );
};

const FeedbackSystem = () => {
  const [isModalOpen, setIsModalOpen] = useState(false);

  const handleSubmitFeedback = async (feedbackData) => {
    const response = await fetch('/api/feedback', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
      },
      body: JSON.stringify({
        ...feedbackData,
        timestamp: new Date().toISOString(),
        userAgent: navigator.userAgent,
        url: window.location.href
      })
    });

    if (!response.ok) {
      throw new Error('フィードバックの送信に失敗しました');
    }

    // 成功メッセージの表示
    alert('フィードバックを送信しました。ありがとうございます！');
  };

  return (
    <>
      <button
        className="feedback-trigger"
        onClick={() => setIsModalOpen(true)}
      >
        <span>💬</span>
        フィードバック
      </button>

      <FeedbackModal
        isOpen={isModalOpen}
        onClose={() => setIsModalOpen(false)}
        onSubmit={handleSubmitFeedback}
      />
    </>
  );
};

export default FeedbackSystem;
```

## バックエンド実装例

### Node.js + Express での実装
```javascript
const express = require('express');
const router = express.Router();

// フィードバックの送信
router.post('/feedback', async (req, res) => {
  try {
    const { type, rating, message, timestamp, userAgent, url } = req.body;
    const userId = req.user?.id || null;
    const ipAddress = req.ip;

    // フィードバックを保存
    const feedback = await Feedback.create({
      userId,
      type,
      rating: parseInt(rating),
      message,
      userAgent,
      url,
      ipAddress,
      createdAt: new Date(timestamp)
    });

    // 管理者に通知（オプション）
    await notifyAdmins(feedback);

    res.json({ 
      message: 'フィードバックを受け付けました',
      id: feedback.id 
    });
  } catch (error) {
    console.error('フィードバック保存エラー:', error);
    res.status(500).json({ error: 'サーバーエラーが発生しました' });
  }
});

// フィードバック一覧の取得（管理者用）
router.get('/feedback', authenticateAdmin, async (req, res) => {
  try {
    const { page = 1, limit = 20, type, rating } = req.query;
    const offset = (page - 1) * limit;

    let whereClause = {};
    if (type) whereClause.type = type;
    if (rating) whereClause.rating = rating;

    const { count, rows: feedbacks } = await Feedback.findAndCountAll({
      where: whereClause,
      include: [
        {
          model: User,
          attributes: ['id', 'name', 'email']
        }
      ],
      order: [['createdAt', 'DESC']],
      limit: parseInt(limit),
      offset: parseInt(offset)
    });

    res.json({
      feedbacks,
      total: count,
      page: parseInt(page),
      totalPages: Math.ceil(count / limit)
    });
  } catch (error) {
    console.error('フィードバック取得エラー:', error);
    res.status(500).json({ error: 'サーバーエラーが発生しました' });
  }
});

// フィードバックの統計情報
router.get('/feedback/stats', authenticateAdmin, async (req, res) => {
  try {
    const stats = await Feedback.findAll({
      attributes: [
        'type',
        'rating',
        [sequelize.fn('COUNT', sequelize.col('id')), 'count']
      ],
      group: ['type', 'rating'],
      raw: true
    });

    const totalCount = await Feedback.count();
    const averageRating = await Feedback.findOne({
      attributes: [
        [sequelize.fn('AVG', sequelize.col('rating')), 'avgRating']
      ],
      raw: true
    });

    res.json({
      totalCount,
      averageRating: averageRating.avgRating,
      breakdown: stats
    });
  } catch (error) {
    console.error('フィードバック統計エラー:', error);
    res.status(500).json({ error: 'サーバーエラーが発生しました' });
  }
});

// 管理者通知機能
const notifyAdmins = async (feedback) => {
  try {
    const admins = await User.findAll({
      where: { role: 'admin' },
      attributes: ['email']
    });

    const emailContent = `
      新しいフィードバックが送信されました。
      
      種類: ${feedback.type}
      評価: ${feedback.rating}/5
      メッセージ: ${feedback.message}
      送信日時: ${feedback.createdAt}
    `;

    // メール送信処理（実装例）
    for (const admin of admins) {
      await sendEmail(admin.email, '新しいフィードバック', emailContent);
    }
  } catch (error) {
    console.error('管理者通知エラー:', error);
  }
};

module.exports = router;
```

## データベース設計

### MySQL テーブル設計
```sql
-- フィードバックテーブル
CREATE TABLE feedback (
    id INT PRIMARY KEY AUTO_INCREMENT,
    user_id INT,
    type ENUM('bug', 'feature', 'improvement', 'general') NOT NULL,
    rating TINYINT CHECK (rating >= 1 AND rating <= 5),
    message TEXT,
    user_agent TEXT,
    url VARCHAR(500),
    ip_address VARCHAR(45),
    status ENUM('new', 'in_progress', 'resolved', 'closed') DEFAULT 'new',
    admin_response TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    
    INDEX idx_user_id (user_id),
    INDEX idx_type (type),
    INDEX idx_rating (rating),
    INDEX idx_status (status),
    INDEX idx_created_at (created_at),
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE SET NULL
);

-- フィードバック分析用の集計テーブル
CREATE TABLE feedback_analytics (
    id INT PRIMARY KEY AUTO_INCREMENT,
    date DATE NOT NULL,
    type ENUM('bug', 'feature', 'improvement', 'general') NOT NULL,
    rating TINYINT,
    count INT DEFAULT 1,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    
    UNIQUE KEY unique_date_type_rating (date, type, rating),
    INDEX idx_date (date),
    INDEX idx_type (type)
);
```

### 2. データ分析と可視化
```javascript
// フィードバック分析ダッシュボード
const getFeedbackAnalytics = async (req, res) => {
  try {
    const { period = '30d' } = req.query;
    
    // 期間の計算
    const endDate = new Date();
    const startDate = new Date();
    startDate.setDate(startDate.getDate() - parseInt(period));

    // 時系列データの取得
    const timeSeriesData = await sequelize.query(`
      SELECT 
        DATE(created_at) as date,
        type,
        AVG(rating) as avg_rating,
        COUNT(*) as count
      FROM feedback
      WHERE created_at BETWEEN :startDate AND :endDate
      GROUP BY DATE(created_at), type
      ORDER BY date
    `, {
      replacements: { startDate, endDate },
      type: sequelize.QueryTypes.SELECT
    });

    // カテゴリ別分析
    const categoryAnalysis = await Feedback.findAll({
      attributes: [
        'type',
        [sequelize.fn('COUNT', sequelize.col('id')), 'count'],
        [sequelize.fn('AVG', sequelize.col('rating')), 'avgRating']
      ],
      where: {
        createdAt: {
          [Op.between]: [startDate, endDate]
        }
      },
      group: ['type'],
      raw: true
    });

    res.json({
      timeSeries: timeSeriesData,
      categoryAnalysis,
      period
    });
  } catch (error) {
    console.error('分析データ取得エラー:', error);
    res.status(500).json({ error: 'サーバーエラーが発生しました' });
  }
};
```

## よくある問題と解決方法

### 1. スパム対策
**問題**: 大量のスパムフィードバックが送信される
**解決方法**:
```javascript
// コンテンツフィルタリング
const filterSpamContent = (message) => {
  const spamKeywords = ['spam', 'advertisement', 'promotion'];
  const suspiciousPatterns = [
    /https?:\/\/[^\s]+/g, // URL
    /[A-Z]{10,}/g, // 大文字の連続
    /(.)\1{4,}/g // 同じ文字の5回以上繰り返し
  ];

  // キーワードチェック
  const hasSpamKeywords = spamKeywords.some(keyword => 
    message.toLowerCase().includes(keyword)
  );

  // パターンチェック
  const hasSuspiciousPatterns = suspiciousPatterns.some(pattern => 
    pattern.test(message)
  );

  return hasSpamKeywords || hasSuspiciousPatterns;
};
```

```javascript
// フィードバック対応システム
const updateFeedbackStatus = async (feedbackId, status, adminResponse) => {
  try {
    const feedback = await Feedback.findByPk(feedbackId);
    
    if (!feedback) {
      throw new Error('フィードバックが見つかりません');
    }

    await feedback.update({
      status,
      adminResponse,
      updatedAt: new Date()
    });

    // ユーザーに通知（メールなど）
    if (feedback.userId) {
      await notifyUserResponse(feedback.userId, adminResponse);
    }

    return feedback;
  } catch (error) {
    console.error('フィードバック更新エラー:', error);
    throw error;
  }
};
```

## まとめ

フィードバック機能は、ユーザーの声を直接聞くことができる重要な機能です。適切な実装により：

- **サービス改善**: ユーザーの意見に基づいた継続的な改善
- **ユーザー満足度向上**: 意見を聞いてもらえる満足感
- **データ分析**: 定量的なユーザー満足度の測定

実装時は、スパム対策、データ分析、適切な対応フローの構築を考慮し、ユーザーにとって使いやすく、管理者にとって価値のあるフィードバックシステムを構築しましょう。
