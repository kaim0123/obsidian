# 検索機能の実装方法とベストプラクティス

## 概要

検索機能は、ユーザーが大量のデータから目的の情報を効率的に見つけるための重要な機能です。キーワード検索、全文検索、ファジー検索など、様々な検索手法とその実装方法を詳しく解説します。

## 検索機能の種類と比較表

| 項目 | キーワード検索 | 全文検索 | ファジー検索 | 音声検索 |
|------|---------------|----------|-------------|----------|
| **実装の複雑さ** | ⭐ 簡単 | ⭐⭐⭐ 複雑 | ⭐⭐ 中程度 | ⭐⭐⭐ 複雑 |
| **検索精度** | ⭐⭐ 中程度 | ⭐⭐⭐ 高精度 | ⭐⭐ 中程度 | ⭐⭐ 中程度 |
| **検索速度** | ⭐⭐⭐ 高速 | ⭐⭐ 中程度 | ⭐⭐ 中程度 | ⭐⭐ 中程度 |
| **部分一致** | ✅ 対応 | ✅ 対応 | ✅ 対応 | ❌ 非対応 |
| **スペルミス対応** | ❌ 非対応 | ❌ 非対応 | ✅ 対応 | ✅ 対応 |
| **多言語対応** | ⭐⭐ 中程度 | ⭐⭐⭐ 高精度 | ⭐⭐ 中程度 | ⭐⭐ 中程度 |
| **インデックス必要** | ❌ 不要 | ✅ 必要 | ✅ 必要 | ✅ 必要 |
| **サーバーリソース** | ⭐⭐⭐ 軽量 | ⭐⭐ 中程度 | ⭐⭐ 中程度 | ⭐ 重い |

### 推奨使用場面

| 検索タイプ | 最適な使用場面 | 例 |
|-----------|----------------|-----|
| **キーワード検索** | シンプルな検索 | 商品名検索、ユーザー名検索 |
| **全文検索** | 文書・記事検索 | ブログ、ニュース、ドキュメント |

## 1. キーワード検索

### 概要
単純な文字列マッチングによる検索機能

### 実装例

```javascript
// 基本的なキーワード検索
function KeywordSearch({ items, onSearch }) {
  const [searchTerm, setSearchTerm] = useState('');
  const [searchResults, setSearchResults] = useState([]);

  const handleSearch = useCallback((term) => {
    if (!term.trim()) {
      setSearchResults([]);
      return;
    }

    const results = items.filter(item => 
      item.name.toLowerCase().includes(term.toLowerCase()) ||
      item.description.toLowerCase().includes(term.toLowerCase())
    );
    
    setSearchResults(results);
    onSearch(results);
  }, [items, onSearch]);

  // デバウンス付き検索
  const debouncedSearch = useDebouncedCallback(handleSearch, 300);

  useEffect(() => {
    debouncedSearch(searchTerm);
  }, [searchTerm, debouncedSearch]);

  return (
    <div>
      <input
        type="text"
        placeholder="キーワードで検索..."
        value={searchTerm}
        onChange={(e) => setSearchTerm(e.target.value)}
        className="search-input"
      />
      
      {searchResults.length > 0 && (
        <div className="search-results">
          {searchResults.map(item => (
            <div key={item.id} className="search-result-item">
              <h3>{item.name}</h3>
              <p>{item.description}</p>
            </div>
          ))}
        </div>
      )}
    </div>
  );
}
```

### 高度なキーワード検索

```javascript
// 複数キーワード対応の検索
function AdvancedKeywordSearch({ items }) {
  const [searchTerm, setSearchTerm] = useState('');
  const [searchResults, setSearchResults] = useState([]);

  const searchItems = useCallback((term) => {
    if (!term.trim()) {
      setSearchResults([]);
      return;
    }

    // キーワードを分割（スペース区切り）
    const keywords = term.toLowerCase().split(/\s+/);
    
    const results = items.filter(item => {
      const searchableText = `${item.name} ${item.description} ${item.tags.join(' ')}`.toLowerCase();
      
      // すべてのキーワードが含まれているかチェック
      return keywords.every(keyword => searchableText.includes(keyword));
    });

    // 関連度でソート
    const sortedResults = results.sort((a, b) => {
      const aScore = calculateRelevanceScore(a, keywords);
      const bScore = calculateRelevanceScore(b, keywords);
      return bScore - aScore;
    });

    setSearchResults(sortedResults);
  }, [items]);

  const calculateRelevanceScore = (item, keywords) => {
    let score = 0;
    const searchableText = `${item.name} ${item.description}`.toLowerCase();
    
    keywords.forEach(keyword => {
      // タイトルに含まれている場合は高スコア
      if (item.name.toLowerCase().includes(keyword)) {
        score += 10;
      }
      // 説明に含まれている場合は中スコア
      if (item.description.toLowerCase().includes(keyword)) {
        score += 5;
      }
      // タグに含まれている場合は低スコア
      if (item.tags.some(tag => tag.toLowerCase().includes(keyword))) {
        score += 2;
      }
    });
    
    return score;
  };

  const debouncedSearch = useDebouncedCallback(searchItems, 300);

  useEffect(() => {
    debouncedSearch(searchTerm);
  }, [searchTerm, debouncedSearch]);

  return (
    <div>
      <input
        type="text"
        placeholder="複数キーワードで検索（スペース区切り）..."
        value={searchTerm}
        onChange={(e) => setSearchTerm(e.target.value)}
      />
      
      {searchResults.length > 0 && (
        <div>
          <p>検索結果: {searchResults.length}件</p>
          {searchResults.map(item => (
            <div key={item.id}>
              <h3>{item.name}</h3>
              <p>{item.description}</p>
              <div>
                {item.tags.map(tag => (
                  <span key={tag} className="tag">{tag}</span>
                ))}
              </div>
            </div>
          ))}
        </div>
      )}
    </div>
  );
}
```

### メリット
- ✅ **実装が簡単**: 基本的な文字列操作で実装可能
- ✅ **高速**: インデックス不要で高速検索
- ✅ **軽量**: サーバーリソースをほとんど使用しない
- ✅ **リアルタイム**: 入力と同時に検索結果を表示

### デメリット
- ❌ **検索精度が低い**: 完全一致のみで部分一致が限定的
- ❌ **スペルミス対応なし**: タイプミスがあると検索できない
- ❌ **多言語対応が困難**: 言語固有の検索ができない

### 使用場面
- 🔍 **商品名検索**: ECサイトでの商品検索
- 👤 **ユーザー検索**: 管理画面でのユーザー検索
- 📝 **シンプルなリスト検索**: 設定項目の検索

## 2. 全文検索

### 概要
文書全体を対象とした高度な検索機能

### 実装例（Elasticsearch使用）

```javascript
// Elasticsearchを使った全文検索
import { Client } from '@elastic/elasticsearch';

const client = new Client({
  node: 'http://localhost:9200'
});

// 検索インデックスの作成
async function createSearchIndex() {
  await client.indices.create({
    index: 'articles',
    body: {
      mappings: {
        properties: {
          title: {
            type: 'text',
            analyzer: 'kuromoji' // 日本語対応
          },
          content: {
            type: 'text',
            analyzer: 'kuromoji'
          },
          tags: {
            type: 'keyword'
          },
          createdAt: {
            type: 'date'
          }
        }
      }
    }
  });
}

// 文書のインデックス化
async function indexDocument(article) {
  await client.index({
    index: 'articles',
    id: article.id,
    body: {
      title: article.title,
      content: article.content,
      tags: article.tags,
      createdAt: article.createdAt
    }
  });
}

// 全文検索の実行
async function fullTextSearch(query, options = {}) {
  const {
    page = 1,
    size = 10,
    sortBy = 'relevance',
    filters = {}
  } = options;

  const searchBody = {
    query: {
      bool: {
        must: [
          {
            multi_match: {
              query: query,
              fields: ['title^3', 'content^1'], // タイトルに重み付け
              type: 'best_fields',
              fuzziness: 'AUTO' // ファジー検索も併用
            }
          }
        ],
        filter: []
      }
    },
    highlight: {
      fields: {
        title: {},
        content: {
          fragment_size: 150,
          number_of_fragments: 3
        }
      }
    },
    from: (page - 1) * size,
    size: size
  };

  // フィルターの追加
  if (filters.tags && filters.tags.length > 0) {
    searchBody.query.bool.filter.push({
      terms: { tags: filters.tags }
    });
  }

  if (filters.dateRange) {
    searchBody.query.bool.filter.push({
      range: {
        createdAt: {
          gte: filters.dateRange.from,
          lte: filters.dateRange.to
        }
      }
    });
  }

  // ソートの設定
  if (sortBy === 'date') {
    searchBody.sort = [{ createdAt: { order: 'desc' } }];
  } else if (sortBy === 'title') {
    searchBody.sort = [{ 'title.keyword': { order: 'asc' } }];
  }

  const response = await client.search({
    index: 'articles',
    body: searchBody
  });

  return {
    hits: response.body.hits.hits.map(hit => ({
      ...hit._source,
      id: hit._id,
      score: hit._score,
      highlights: hit.highlight
    })),
    total: response.body.hits.total.value,
    page,
    size
  };
}
```

## 3. ファジー検索

### 概要
スペルミスや表記揺れに対応した検索機能

### 実装例

```javascript
// ファジー検索の実装
function FuzzySearch({ items }) {
  const [query, setQuery] = useState('');
  const [results, setResults] = useState([]);

  // レーベンシュタイン距離の計算
  const levenshteinDistance = (str1, str2) => {
    const matrix = [];
    
    for (let i = 0; i <= str2.length; i++) {
      matrix[i] = [i];
    }
    
    for (let j = 0; j <= str1.length; j++) {
      matrix[0][j] = j;
    }
    
    for (let i = 1; i <= str2.length; i++) {
      for (let j = 1; j <= str1.length; j++) {
        if (str2.charAt(i - 1) === str1.charAt(j - 1)) {
          matrix[i][j] = matrix[i - 1][j - 1];
        } else {
          matrix[i][j] = Math.min(
            matrix[i - 1][j - 1] + 1,
            matrix[i][j - 1] + 1,
            matrix[i - 1][j] + 1
          );
        }
      }
    }
    
    return matrix[str2.length][str1.length];
  };

  // ファジー検索の実行
  const fuzzySearch = useCallback((searchTerm) => {
    if (!searchTerm.trim()) {
      setResults([]);
      return;
    }

    const threshold = Math.max(1, Math.floor(searchTerm.length * 0.3)); // 30%の誤差を許容
    const searchLower = searchTerm.toLowerCase();

    const matches = items.map(item => {
      const nameLower = item.name.toLowerCase();
      const distance = levenshteinDistance(searchLower, nameLower);
      
      if (distance <= threshold) {
        return {
          ...item,
          distance,
          similarity: 1 - (distance / Math.max(searchLower.length, nameLower.length))
        };
      }
      return null;
    }).filter(Boolean);

    // 類似度でソート
    const sortedResults = matches.sort((a, b) => b.similarity - a.similarity);
    setResults(sortedResults);
  }, [items]);

  const debouncedSearch = useDebouncedCallback(fuzzySearch, 300);

  useEffect(() => {
    debouncedSearch(query);
  }, [query, debouncedSearch]);

  return (
    <div>
      <input
        type="text"
        placeholder="ファジー検索（スペルミス対応）..."
        value={query}
        onChange={(e) => setQuery(e.target.value)}
      />
      
      {results.length > 0 && (
        <div>
          <p>検索結果: {results.length}件</p>
          {results.map(item => (
            <div key={item.id} className="fuzzy-result">
              <h3>{item.name}</h3>
              <p>類似度: {(item.similarity * 100).toFixed(1)}%</p>
              <p>距離: {item.distance}</p>
            </div>
          ))}
        </div>
      )}
    </div>
  );
}
```

```javascript
// Fuse.jsを使った高度なファジー検索
import Fuse from 'fuse.js';

function AdvancedFuzzySearch({ items }) {
  const [query, setQuery] = useState('');
  const [results, setResults] = useState([]);

  // Fuse.jsの設定
  const fuseOptions = {
    keys: [
      { name: 'name', weight: 0.7 },
      { name: 'description', weight: 0.3 },
      { name: 'tags', weight: 0.2 }
    ],
    threshold: 0.4, // 0.0 = 完全一致、1.0 = すべてマッチ
    distance: 100,
    minMatchCharLength: 2,
    includeScore: true,
    includeMatches: true
  };

  const fuse = useMemo(() => new Fuse(items, fuseOptions), [items]);

  const searchItems = useCallback((searchTerm) => {
    if (!searchTerm.trim()) {
      setResults([]);
      return;
    }

    const searchResults = fuse.search(searchTerm);
    setResults(searchResults);
  }, [fuse]);

  const debouncedSearch = useDebouncedCallback(searchItems, 300);

  useEffect(() => {
    debouncedSearch(query);
  }, [query, debouncedSearch]);

  return (
    <div>
      <input
        type="text"
        placeholder="高度なファジー検索..."
        value={query}
        onChange={(e) => setQuery(e.target.value)}
      />
      
      {results.length > 0 && (
        <div>
          <p>検索結果: {results.length}件</p>
          {results.map((result, index) => (
            <div key={result.item.id} className="fuzzy-result">
              <h3>{result.item.name}</h3>
              <p>{result.item.description}</p>
              <div className="match-info">
                <span>スコア: {result.score?.toFixed(3)}</span>
                {result.matches && (
                  <div className="matches">
                    {result.matches.map((match, i) => (
                      <span key={i} className="match">
                        {match.key}: {match.value}
                      </span>
                    ))}
                  </div>
                )}
              </div>
            </div>
          ))}
        </div>
      )}
    </div>
  );
}
```

## 4. 音声検索

### 概要
音声入力を使用した検索機能

### 実装例

```javascript
// 音声検索の実装
function VoiceSearch({ onSearchResult }) {
  const [isListening, setIsListening] = useState(false);
  const [transcript, setTranscript] = useState('');
  const [error, setError] = useState('');

  const recognition = useMemo(() => {
    if (typeof window === 'undefined') return null;
    
    const SpeechRecognition = window.SpeechRecognition || window.webkitSpeechRecognition;
    if (!SpeechRecognition) {
      setError('音声認識がサポートされていません');
      return null;
    }

    const recognition = new SpeechRecognition();
    recognition.continuous = false;
    recognition.interimResults = false;
    recognition.lang = 'ja-JP'; // 日本語設定

    recognition.onstart = () => {
      setIsListening(true);
      setError('');
    };

    recognition.onresult = (event) => {
      const transcript = event.results[0][0].transcript;
      setTranscript(transcript);
      onSearchResult(transcript);
    };

    recognition.onerror = (event) => {
      setError(`音声認識エラー: ${event.error}`);
      setIsListening(false);
    };

    recognition.onend = () => {
      setIsListening(false);
    };

    return recognition;
  }, [onSearchResult]);

  const startListening = () => {
    if (recognition) {
      recognition.start();
    }
  };

  const stopListening = () => {
    if (recognition) {
      recognition.stop();
    }
  };

  return (
    <div className="voice-search">
      <button
        onClick={isListening ? stopListening : startListening}
        className={`voice-button ${isListening ? 'listening' : ''}`}
        disabled={!recognition}
      >
        {isListening ? '🎤 音声認識中...' : '🎤 音声検索'}
      </button>
      
      {transcript && (
        <div className="transcript">
          <p>認識結果: {transcript}</p>
        </div>
      )}
      
      {error && (
        <div className="error">
          <p>{error}</p>
        </div>
      )}
    </div>
  );
}
```

### メリット
- ✅ **アクセシビリティ**: 視覚障害者や手が不自由な人に優しい
- ✅ **モバイル対応**: スマートフォンでの入力が簡単
- ✅ **多言語対応**: 言語設定で対応可能
- ✅ **ハンズフリー**: 手を使わずに検索可能

### デメリット
- ❌ **精度の問題**: 音声認識の精度に依存
- ❌ **環境依存**: 騒音環境では精度が低下
- ❌ **プライバシー**: 音声データの取り扱い
- ❌ **ブラウザ対応**: すべてのブラウザでサポートされていない

### 使用場面
- 📱 **モバイルアプリ**: スマートフォンでの検索
- 🚗 **車載システム**: ハンズフリー検索
- ♿ **アクセシブルアプリ**: 障害者向けアプリケーション
- 🏠 **スマートホーム**: 音声アシスタント連携

### 1. デバウンスの実装

```javascript
// カスタムデバウンスフック
function useDebounce(value, delay) {
  const [debouncedValue, setDebouncedValue] = useState(value);

  useEffect(() => {
    const handler = setTimeout(() => {
      setDebouncedValue(value);
    }, delay);

    return () => {
      clearTimeout(handler);
    };
  }, [value, delay]);

  return debouncedValue;
}

// 使用例
function OptimizedSearch({ items }) {
  const [query, setQuery] = useState('');
  const debouncedQuery = useDebounce(query, 300);

  useEffect(() => {
    if (debouncedQuery) {
      performSearch(debouncedQuery);
    }
  }, [debouncedQuery]);
}
```

### 4. キャッシュの実装

```javascript
// 検索結果のキャッシュ
const searchCache = new Map();

function CachedSearch({ items }) {
  const [query, setQuery] = useState('');
  const [results, setResults] = useState([]);

  const searchWithCache = useCallback(async (searchQuery) => {
    if (searchCache.has(searchQuery)) {
      setResults(searchCache.get(searchQuery));
      return;
    }

    const searchResults = await performSearch(searchQuery);
    searchCache.set(searchQuery, searchResults);
    setResults(searchResults);
  }, []);

  useEffect(() => {
    if (query) {
      searchWithCache(query);
    }
  }, [query, searchWithCache]);
}
```

## まとめ

| 検索タイプ | 適用場面 | 主なメリット | 主なデメリット |
|-----------|---------|-------------|---------------|
| **キーワード検索** | シンプルな検索 | 実装が簡単、高速 | 検索精度が低い |
| **全文検索** | 文書検索 | 高精度、関連度スコア | 実装が複雑 |
| **ファジー検索** | ユーザビリティ重視 | スペルミス対応 | 計算コストが高い |
| **音声検索** | モバイル・アクセシビリティ | ハンズフリー | 精度に依存 |

### 選択の指針

1. **シンプルな検索** → キーワード検索
2. **文書・記事検索** → 全文検索
3. **ユーザビリティ重視** → ファジー検索
4. **モバイル・アクセシビリティ** → 音声検索
5. **複数の要件** → 組み合わせパターン
