# ソート機能の実装方法とベストプラクティス

## 概要

ソート機能は、データを特定の基準に基づいて並び替える重要な機能です。昇順・降順、複数条件ソート、カスタムソートなど、様々なソート手法とその実装方法を詳しく解説します。

## ソート機能の種類と比較表

| 項目 | 単一条件ソート | 複数条件ソート | カスタムソート | 動的ソート |
|------|---------------|---------------|---------------|------------|
| **実装の複雑さ** | ⭐ 簡単 | ⭐⭐ 中程度 | ⭐⭐⭐ 複雑 | ⭐⭐⭐ 複雑 |
| **パフォーマンス** | ⭐⭐⭐ 高速 | ⭐⭐ 中程度 | ⭐⭐ 中程度 | ⭐⭐ 中程度 |
| **柔軟性** | ⭐ 低い | ⭐⭐ 中程度 | ⭐⭐⭐ 高い | ⭐⭐⭐ 高い |
| **ユーザビリティ** | ⭐⭐ 中程度 | ⭐⭐⭐ 高い | ⭐⭐⭐ 高い | ⭐⭐⭐ 高い |
| **メモリ使用量** | ⭐⭐⭐ 軽量 | ⭐⭐ 中程度 | ⭐⭐ 中程度 | ⭐⭐ 中程度 |
| **学習コスト** | ⭐ 低い | ⭐⭐ 中程度 | ⭐⭐⭐ 高い | ⭐⭐⭐ 高い |

### 推奨使用場面

| ソートタイプ | 最適な使用場面 | 例 |
|-------------|----------------|-----|
| **単一条件ソート** | シンプルなリスト | 商品一覧、ユーザー一覧 |
| **複数条件ソート** | 複雑なデータ | 商品検索結果、レポート |

## 1. 単一条件ソート

### 概要
一つの条件でデータを並び替える基本的なソート機能

### 実装例

```javascript
// 基本的な単一条件ソート
function SimpleSort({ items }) {
  const [sortField, setSortField] = useState('name');
  const [sortOrder, setSortOrder] = useState('asc');

  const sortedItems = useMemo(() => {
    return [...items].sort((a, b) => {
      let aValue = a[sortField];
      let bValue = b[sortField];

      // 文字列の場合は小文字に変換
      if (typeof aValue === 'string') {
        aValue = aValue.toLowerCase();
        bValue = bValue.toLowerCase();
      }

      // 日付の場合はDateオブジェクトに変換
      if (sortField.includes('Date') || sortField.includes('date')) {
        aValue = new Date(aValue);
        bValue = new Date(bValue);
      }

      if (aValue < bValue) {
        return sortOrder === 'asc' ? -1 : 1;
      }
      if (aValue > bValue) {
        return sortOrder === 'asc' ? 1 : -1;
      }
      return 0;
    });
  }, [items, sortField, sortOrder]);

  const handleSort = (field) => {
    if (sortField === field) {
      setSortOrder(sortOrder === 'asc' ? 'desc' : 'asc');
    } else {
      setSortField(field);
      setSortOrder('asc');
    }
  };

  return (
    <div>
      <div className="sort-controls">
        <button 
          onClick={() => handleSort('name')}
          className={sortField === 'name' ? 'active' : ''}
        >
          名前 {sortField === 'name' && (sortOrder === 'asc' ? '↑' : '↓')}
        </button>
        <button 
          onClick={() => handleSort('price')}
          className={sortField === 'price' ? 'active' : ''}
        >
          価格 {sortField === 'price' && (sortOrder === 'asc' ? '↑' : '↓')}
        </button>
        <button 
          onClick={() => handleSort('createdAt')}
          className={sortField === 'createdAt' ? 'active' : ''}
        >
          作成日 {sortField === 'createdAt' && (sortOrder === 'asc' ? '↑' : '↓')}
        </button>
      </div>

      <div className="items-list">
        {sortedItems.map(item => (
          <div key={item.id} className="item">
            <h3>{item.name}</h3>
            <p>価格: ¥{item.price.toLocaleString()}</p>
            <p>作成日: {new Date(item.createdAt).toLocaleDateString()}</p>
          </div>
        ))}
      </div>
    </div>
  );
}
```

```javascript
// 型安全なソート機能
function TypeSafeSort({ items }) {
  const [sortConfig, setSortConfig] = useState({
    field: 'name',
    direction: 'asc'
  });

  const sortItems = useCallback((items, field, direction) => {
    return [...items].sort((a, b) => {
      const aValue = a[field];
      const bValue = b[field];

      // 型に応じた比較
      let comparison = 0;
      
      if (typeof aValue === 'string' && typeof bValue === 'string') {
        comparison = aValue.localeCompare(bValue, 'ja');
      } else if (typeof aValue === 'number' && typeof bValue === 'number') {
        comparison = aValue - bValue;
      } else if (aValue instanceof Date && bValue instanceof Date) {
        comparison = aValue.getTime() - bValue.getTime();
      } else if (typeof aValue === 'boolean' && typeof bValue === 'boolean') {
        comparison = aValue === bValue ? 0 : aValue ? 1 : -1;
      } else {
        // 型が異なる場合は文字列として比較
        comparison = String(aValue).localeCompare(String(bValue), 'ja');
      }

      return direction === 'asc' ? comparison : -comparison;
    });
  }, []);

  const sortedItems = useMemo(() => {
    return sortItems(items, sortConfig.field, sortConfig.direction);
  }, [items, sortConfig, sortItems]);

  const handleSort = (field) => {
    setSortConfig(prevConfig => ({
      field,
      direction: prevConfig.field === field && prevConfig.direction === 'asc' 
        ? 'desc' 
        : 'asc'
    }));
  };

  return (
    <div>
      <div className="sort-header">
        {['name', 'price', 'createdAt', 'status'].map(field => (
          <button
            key={field}
            onClick={() => handleSort(field)}
            className={`sort-button ${sortConfig.field === field ? 'active' : ''}`}
          >
            {getFieldLabel(field)}
            {sortConfig.field === field && (
              <span className="sort-indicator">
                {sortConfig.direction === 'asc' ? '↑' : '↓'}
              </span>
            )}
          </button>
        ))}
      </div>

      <div className="items-container">
        {sortedItems.map(item => (
          <ItemCard key={item.id} item={item} />
        ))}
      </div>
    </div>
  );
}

    name: '名前',
    price: '価格',
    createdAt: '作成日',
    status: 'ステータス'
  };
  return labels[field] || field;
}
```

### メリット
- ✅ **実装が簡単**: 基本的な配列ソートで実装可能
- ✅ **高速**: 単純な比較処理で高速
- ✅ **理解しやすい**: ユーザーにとって直感的
- ✅ **メモリ効率**: 最小限のメモリ使用量

### デメリット
- ❌ **柔軟性が低い**: 複雑なソート条件に対応できない
- ❌ **ユーザビリティ**: 複数の条件を組み合わせられない
- ❌ **拡張性**: 新しいソート条件の追加が困難

### 使用場面
- 📝 **シンプルなリスト**: 商品一覧、ユーザー一覧
- 🎯 **基本的な管理画面**: 設定項目の並び替え
- 📊 **単純なレポート**: 数値や日付での並び替え

## 2. 複数条件ソート

```javascript
// 複数条件ソートの実装
function MultiSort({ items }) {
  const [sortCriteria, setSortCriteria] = useState([
    { field: 'category', direction: 'asc', priority: 1 },
    { field: 'price', direction: 'desc', priority: 2 }
  ]);

  const sortedItems = useMemo(() => {
    return [...items].sort((a, b) => {
      // 優先度順にソート条件を適用
      const sortedCriteria = [...sortCriteria].sort((x, y) => x.priority - y.priority);
      
      for (const criterion of sortedCriteria) {
        const aValue = a[criterion.field];
        const bValue = b[criterion.field];
        
        let comparison = 0;
        
        if (typeof aValue === 'string' && typeof bValue === 'string') {
          comparison = aValue.localeCompare(bValue, 'ja');
        } else if (typeof aValue === 'number' && typeof bValue === 'number') {
          comparison = aValue - bValue;
        } else if (aValue instanceof Date && bValue instanceof Date) {
          comparison = aValue.getTime() - bValue.getTime();
        }
        
        if (comparison !== 0) {
          return criterion.direction === 'asc' ? comparison : -comparison;
        }
      }
      
      return 0;
    });
  }, [items, sortCriteria]);

  const addSortCriterion = (field) => {
    const maxPriority = Math.max(...sortCriteria.map(c => c.priority), 0);
    setSortCriteria(prev => [
      ...prev,
      { field, direction: 'asc', priority: maxPriority + 1 }
    ]);
  };

  const removeSortCriterion = (index) => {
    setSortCriteria(prev => prev.filter((_, i) => i !== index));
  };

  const updateSortCriterion = (index, updates) => {
    setSortCriteria(prev => prev.map((criterion, i) => 
      i === index ? { ...criterion, ...updates } : criterion
    ));
  };

  const moveCriterion = (fromIndex, toIndex) => {
    setSortCriteria(prev => {
      const newCriteria = [...prev];
      const [moved] = newCriteria.splice(fromIndex, 1);
      newCriteria.splice(toIndex, 0, moved);
      
      // 優先度を再設定
      return newCriteria.map((criterion, index) => ({
        ...criterion,
        priority: index + 1
      }));
    });
  };

  return (
    <div>
      <div className="multi-sort-controls">
        <h3>ソート条件</h3>
        
        {sortCriteria.map((criterion, index) => (
          <div key={index} className="sort-criterion">
            <span className="priority">#{criterion.priority}</span>
            
            <select
              value={criterion.field}
              onChange={(e) => updateSortCriterion(index, { field: e.target.value })}
            >
              <option value="name">名前</option>
              <option value="category">カテゴリ</option>
              <option value="price">価格</option>
              <option value="createdAt">作成日</option>
              <option value="status">ステータス</option>
            </select>
            
            <select
              value={criterion.direction}
              onChange={(e) => updateSortCriterion(index, { direction: e.target.value })}
            >
              <option value="asc">昇順</option>
              <option value="desc">降順</option>
            </select>
            
            <button onClick={() => removeSortCriterion(index)}>削除</button>
            
            {index > 0 && (
              <button onClick={() => moveCriterion(index, index - 1)}>↑</button>
            )}
            {index < sortCriteria.length - 1 && (
              <button onClick={() => moveCriterion(index, index + 1)}>↓</button>
            )}
          </div>
        ))}
        
        <div className="add-criterion">
          <select onChange={(e) => addSortCriterion(e.target.value)}>
            <option value="">条件を追加</option>
            <option value="name">名前</option>
            <option value="category">カテゴリ</option>
            <option value="price">価格</option>
            <option value="createdAt">作成日</option>
            <option value="status">ステータス</option>
          </select>
        </div>
      </div>

      <div className="items-list">
        {sortedItems.map(item => (
          <div key={item.id} className="item">
            <h3>{item.name}</h3>
            <p>カテゴリ: {item.category}</p>
            <p>価格: ¥{item.price.toLocaleString()}</p>
            <p>作成日: {new Date(item.createdAt).toLocaleDateString()}</p>
            <p>ステータス: {item.status}</p>
          </div>
        ))}
      </div>
    </div>
  );
}
```

```javascript
// カスタムソートの実装
function CustomSort({ items }) {
  const [sortType, setSortType] = useState('default');

  const customSortFunctions = {
    // 優先度付きソート
    priority: (items) => {
      const priorityOrder = { 'high': 3, 'medium': 2, 'low': 1 };
      return [...items].sort((a, b) => {
        const aPriority = priorityOrder[a.priority] || 0;
        const bPriority = priorityOrder[b.priority] || 0;
        return bPriority - aPriority;
      });
    },

    // アルファベット順（日本語対応）
    alphabetical: (items) => {
      return [...items].sort((a, b) => {
        return a.name.localeCompare(b.name, 'ja', {
          numeric: true,
          sensitivity: 'base'
        });
      });
    },

    // 自然順ソート（数値を含む文字列）
    natural: (items) => {
      return [...items].sort((a, b) => {
        const aName = a.name.toLowerCase();
        const bName = b.name.toLowerCase();
        
        return aName.localeCompare(bName, undefined, {
          numeric: true,
          sensitivity: 'base'
        });
      });
    },

    // 距離順ソート（位置情報）
    distance: (items) => {
      const userLocation = { lat: 35.6762, lng: 139.6503 }; // 東京
      
      return [...items].sort((a, b) => {
        const distanceA = calculateDistance(userLocation, a.location);
        const distanceB = calculateDistance(userLocation, b.location);
        return distanceA - distanceB;
      });
    },

    // 関連度順ソート
    relevance: (items) => {
      const searchTerm = 'react'; // 検索キーワード
      
      return [...items].sort((a, b) => {
        const scoreA = calculateRelevanceScore(a, searchTerm);
        const scoreB = calculateRelevanceScore(b, searchTerm);
        return scoreB - scoreA;
      });
    },

    // ランダムソート
    random: (items) => {
      return [...items].sort(() => Math.random() - 0.5);
    }
  };

  const sortedItems = useMemo(() => {
    const sortFunction = customSortFunctions[sortType];
    return sortFunction ? sortFunction(items) : items;
  }, [items, sortType]);

  return (
    <div>
      <div className="custom-sort-controls">
        <h3>カスタムソート</h3>
        <select
          value={sortType}
          onChange={(e) => setSortType(e.target.value)}
        >
          <option value="default">デフォルト</option>
          <option value="priority">優先度順</option>
          <option value="alphabetical">アルファベット順</option>
          <option value="natural">自然順</option>
          <option value="distance">距離順</option>
          <option value="relevance">関連度順</option>
          <option value="random">ランダム</option>
        </select>
      </div>

      <div className="items-list">
        {sortedItems.map(item => (
          <div key={item.id} className="item">
            <h3>{item.name}</h3>
            <p>優先度: {item.priority}</p>
            <p>カテゴリ: {item.category}</p>
            {item.location && (
              <p>距離: {calculateDistance(
                { lat: 35.6762, lng: 139.6503 },
                item.location
              ).toFixed(1)}km</p>
            )}
          </div>
        ))}
      </div>
    </div>
  );
}

// 距離計算関数
function calculateDistance(point1, point2) {
  const R = 6371; // 地球の半径（km）
  const dLat = (point2.lat - point1.lat) * Math.PI / 180;
  const dLng = (point2.lng - point1.lng) * Math.PI / 180;
  const a = Math.sin(dLat/2) * Math.sin(dLat/2) +
    Math.cos(point1.lat * Math.PI / 180) * Math.cos(point2.lat * Math.PI / 180) *
    Math.sin(dLng/2) * Math.sin(dLng/2);
  const c = 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1-a));
  return R * c;
}

// 関連度スコア計算関数
function calculateRelevanceScore(item, searchTerm) {
  let score = 0;
  const term = searchTerm.toLowerCase();
  
  if (item.name.toLowerCase().includes(term)) score += 10;
  if (item.description.toLowerCase().includes(term)) score += 5;
  if (item.tags.some(tag => tag.toLowerCase().includes(term))) score += 3;
  
  return score;
}
```

```javascript
// ユーザーが定義できるカスタムソート
function DynamicCustomSort({ items }) {
  const [customSortRules, setCustomSortRules] = useState([]);
  const [sortExpression, setSortExpression] = useState('');

  const applyCustomSort = useCallback((items, expression) => {
    try {
      // 安全なソート式の評価（実際の実装ではより厳密な検証が必要）
      const sortFunction = new Function('a', 'b', `
        ${expression}
        return 0;
      `);
      
      return [...items].sort(sortFunction);
    } catch (error) {
      console.error('ソート式エラー:', error);
      return items;
    }
  }, []);

  const sortedItems = useMemo(() => {
    if (!sortExpression.trim()) return items;
    return applyCustomSort(items, sortExpression);
  }, [items, sortExpression, applyCustomSort]);

  const addSortRule = (rule) => {
    setCustomSortRules(prev => [...prev, rule]);
  };

  const removeSortRule = (index) => {
    setCustomSortRules(prev => prev.filter((_, i) => i !== index));
  };

  const generateSortExpression = () => {
    const expressions = customSortRules.map(rule => {
      switch (rule.type) {
        case 'field':
          return `if (a.${rule.field} !== b.${rule.field}) return a.${rule.field} ${rule.operator} b.${rule.field} ? ${rule.direction === 'asc' ? '-1' : '1'} : ${rule.direction === 'asc' ? '1' : '-1'};`;
        case 'custom':
          return rule.expression;
        default:
          return '';
      }
    });
    
    setSortExpression(expressions.join('\n'));
  };

  return (
    <div>
      <div className="dynamic-sort-controls">
        <h3>動的カスタムソート</h3>
        
        <div className="sort-rules">
          {customSortRules.map((rule, index) => (
            <div key={index} className="sort-rule">
              <span>ルール {index + 1}:</span>
              {rule.type === 'field' && (
                <span>
                  {rule.field} {rule.operator} {rule.direction}
                </span>
              )}
              {rule.type === 'custom' && (
                <span>{rule.expression}</span>
              )}
              <button onClick={() => removeSortRule(index)}>削除</button>
            </div>
          ))}
        </div>

        <div className="add-rule">
          <select onChange={(e) => {
            if (e.target.value) {
              addSortRule({
                type: 'field',
                field: e.target.value,
                operator: '<',
                direction: 'asc'
              });
            }
          }}>
            <option value="">フィールドを追加</option>
            <option value="name">名前</option>
            <option value="price">価格</option>
            <option value="createdAt">作成日</option>
          </select>
        </div>

        <div className="custom-expression">
          <textarea
            placeholder="カスタムソート式を入力..."
            value={sortExpression}
            onChange={(e) => setSortExpression(e.target.value)}
            rows={5}
          />
          <button onClick={generateSortExpression}>
            ルールから式を生成
          </button>
        </div>
      </div>

      <div className="items-list">
        {sortedItems.map(item => (
          <div key={item.id} className="item">
            <h3>{item.name}</h3>
            <p>価格: ¥{item.price.toLocaleString()}</p>
            <p>作成日: {new Date(item.createdAt).toLocaleDateString()}</p>
          </div>
        ))}
      </div>
    </div>
  );
}
```

```javascript
// リアルタイムソートの実装
function DynamicSort({ initialItems }) {
  const [items, setItems] = useState(initialItems);
  const [sortConfig, setSortConfig] = useState({
    field: 'name',
    direction: 'asc'
  });
  const [isAutoSort, setIsAutoSort] = useState(true);

  // リアルタイムデータの更新をシミュレート
  useEffect(() => {
    const interval = setInterval(() => {
      setItems(prevItems => {
        const newItems = [...prevItems];
        const randomIndex = Math.floor(Math.random() * newItems.length);
        const randomItem = newItems[randomIndex];
        
        // ランダムにデータを更新
        newItems[randomIndex] = {
          ...randomItem,
          price: Math.floor(Math.random() * 10000) + 1000,
          lastUpdated: new Date()
        };
        
        return newItems;
      });
    }, 2000);

    return () => clearInterval(interval);
  }, []);

  const sortedItems = useMemo(() => {
    if (!isAutoSort) return items;
    
    return [...items].sort((a, b) => {
      let aValue = a[sortConfig.field];
      let bValue = b[sortConfig.field];

      if (typeof aValue === 'string' && typeof bValue === 'string') {
        aValue = aValue.toLowerCase();
        bValue = bValue.toLowerCase();
      }

      if (aValue < bValue) {
        return sortConfig.direction === 'asc' ? -1 : 1;
      }
      if (aValue > bValue) {
        return sortConfig.direction === 'asc' ? 1 : -1;
      }
      return 0;
    });
  }, [items, sortConfig, isAutoSort]);

  const handleSort = (field) => {
    setSortConfig(prevConfig => ({
      field,
      direction: prevConfig.field === field && prevConfig.direction === 'asc' 
        ? 'desc' 
        : 'asc'
    }));
  };

  return (
    <div>
      <div className="dynamic-sort-controls">
        <h3>リアルタイムソート</h3>
        
        <div className="sort-options">
          <label>
            <input
              type="checkbox"
              checked={isAutoSort}
              onChange={(e) => setIsAutoSort(e.target.checked)}
            />
            自動ソート
          </label>
        </div>

        <div className="sort-buttons">
          {['name', 'price', 'lastUpdated'].map(field => (
            <button
              key={field}
              onClick={() => handleSort(field)}
              className={sortConfig.field === field ? 'active' : ''}
            >
              {getFieldLabel(field)}
              {sortConfig.field === field && (
                <span>{sortConfig.direction === 'asc' ? '↑' : '↓'}</span>
              )}
            </button>
          ))}
        </div>
      </div>

      <div className="items-list">
        {sortedItems.map(item => (
          <div key={item.id} className="item">
            <h3>{item.name}</h3>
            <p>価格: ¥{item.price.toLocaleString()}</p>
            <p>最終更新: {item.lastUpdated.toLocaleTimeString()}</p>
            {item.lastUpdated.getTime() - new Date().getTime() < 5000 && (
              <span className="updated-indicator">更新済み</span>
            )}
          </div>
        ))}
      </div>
    </div>
  );
}
```

```javascript
// WebSocketでリアルタイムデータを受信
function WebSocketDynamicSort() {
  const [items, setItems] = useState([]);
  const [sortConfig, setSortConfig] = useState({
    field: 'timestamp',
    direction: 'desc'
  });
  const [connectionStatus, setConnectionStatus] = useState('connecting');

  useEffect(() => {
    const ws = new WebSocket('ws://localhost:8080/updates');
    
    ws.onopen = () => {
      setConnectionStatus('connected');
    };
    
    ws.onmessage = (event) => {
      const update = JSON.parse(event.data);
      
      setItems(prevItems => {
        const newItems = [...prevItems];
        const existingIndex = newItems.findIndex(item => item.id === update.id);
        
        if (existingIndex >= 0) {
          newItems[existingIndex] = { ...newItems[existingIndex], ...update };
        } else {
          newItems.push(update);
        }
        
        return newItems;
      });
    };
    
    ws.onclose = () => {
      setConnectionStatus('disconnected');
    };
    
    ws.onerror = () => {
      setConnectionStatus('error');
    };
    
    return () => {
      ws.close();
    };
  }, []);

  const sortedItems = useMemo(() => {
    return [...items].sort((a, b) => {
      const aValue = a[sortConfig.field];
      const bValue = b[sortConfig.field];
      
      if (aValue instanceof Date && bValue instanceof Date) {
        const comparison = aValue.getTime() - bValue.getTime();
        return sortConfig.direction === 'asc' ? comparison : -comparison;
      }
      
      if (typeof aValue === 'number' && typeof bValue === 'number') {
        const comparison = aValue - bValue;
        return sortConfig.direction === 'asc' ? comparison : -comparison;
      }
      
      return 0;
    });
  }, [items, sortConfig]);

  return (
    <div>
      <div className="websocket-status">
        <span className={`status ${connectionStatus}`}>
          接続状態: {connectionStatus}
        </span>
      </div>

      <div className="sort-controls">
        <button
          onClick={() => setSortConfig({ field: 'timestamp', direction: 'desc' })}
          className={sortConfig.field === 'timestamp' ? 'active' : ''}
        >
          時間順（新しい順）
        </button>
        <button
          onClick={() => setSortConfig({ field: 'value', direction: 'desc' })}
          className={sortConfig.field === 'value' ? 'active' : ''}
        >
          値順（大きい順）
        </button>
      </div>

      <div className="items-list">
        {sortedItems.map(item => (
          <div key={item.id} className="item">
            <h3>{item.name}</h3>
            <p>値: {item.value}</p>
            <p>時間: {new Date(item.timestamp).toLocaleString()}</p>
          </div>
        ))}
      </div>
    </div>
  );
}
```

### メリット
- ✅ **リアルタイム性**: データの更新と同時にソート
- ✅ **自動化**: 手動でのソート操作が不要
- ✅ **最新性**: 常に最新のデータでソート
- ✅ **効率性**: データの変更のみを処理

### デメリット

- ❌ **ネットワーク依存**: 接続状態に依存

```javascript
// Web Workerでソート処理
function WorkerSort({ items, sortConfig }) {
  const [sortedItems, setSortedItems] = useState(items);
  const [isSorting, setIsSorting] = useState(false);

  useEffect(() => {
    if (items.length > 10000) { // 大量データの場合のみワーカーを使用
      setIsSorting(true);
      
      const worker = new Worker('/sort-worker.js');
      worker.postMessage({ items, sortConfig });

        setSortedItems(e.data);
        setIsSorting(false);
```

```javascript
// インデックス付きソート
function IndexedSort({ items, sortConfig }) {
  const [indexedItems, setIndexedItems] = useState([]);

  useEffect(() => {
    // インデックスを作成
    const indexed = items.map((item, index) => ({ ...item, originalIndex: index }));
    setIndexedItems(indexed);
  }, [items]);

  const sortedItems = useMemo(() => {
    return [...indexedItems].sort((a, b) => {
      const comparison = compareItems(a, b, sortConfig);
      // 同じ値の場合は元の順序を保持
      return comparison !== 0 ? comparison : a.originalIndex - b.originalIndex;
    });
  }, [indexedItems, sortConfig]);

  return (
    <div>
      {sortedItems.map(item => (
        <ItemCard key={item.id} item={item} />
      ))}
    </div>
  );
}
```

## まとめ

| ソートタイプ | 適用場面 | 主なメリット | 主なデメリット |
|-------------|---------|-------------|---------------|
| **単一条件ソート** | シンプルなリスト | 実装が簡単、高速 | 柔軟性が低い |
| **複数条件ソート** | 複雑なデータ | 柔軟性、ユーザビリティ | 実装が複雑 |
| **カスタムソート** | 特殊な要件 | 柔軟性、拡張性 | 実装が複雑 |
| **動的ソート** | リアルタイム更新 | リアルタイム性、自動化 | 複雑性、パフォーマンス |

### 選択の指針

1. **シンプルなリスト** → 単一条件ソート
2. **複雑なデータ** → 複数条件ソート
3. **特殊な要件** → カスタムソート
4. **リアルタイム更新** → 動的ソート
5. **大量データ** → 仮想化 + ワーカースレッド
