# 無限スクロール機能の実装方法とベストプラクティス

## 概要

無限スクロール機能は、ユーザーがスクロールするたびに自動的に新しいコンテンツを読み込む機能です。モバイルアプリやSNSで広く使用されており、ユーザーエクスペリエンスを向上させる重要な技術です。

## 無限スクロール機能の種類と比較表

| 項目 | 基本無限スクロール | Intersection Observer | 仮想化無限スクロール | ハイブリッド型 |
|------|------------------|---------------------|-------------------|---------------|
| **実装の複雑さ** | ⭐⭐ 中程度 | ⭐⭐ 中程度 | ⭐⭐⭐ 複雑 | ⭐⭐⭐ 複雑 |
| **パフォーマンス** | ⭐⭐ 中程度 | ⭐⭐⭐ 高速 | ⭐⭐⭐ 高速 | ⭐⭐⭐ 高速 |
| **メモリ効率** | ⭐ 低い | ⭐ 低い | ⭐⭐⭐ 高い | ⭐⭐ 中程度 |
| **ユーザビリティ** | ⭐⭐⭐ 高い | ⭐⭐⭐ 高い | ⭐⭐ 中程度 | ⭐⭐⭐ 高い |
| **ブラウザ対応** | ⭐⭐⭐ 優秀 | ⭐⭐ 中程度 | ⭐⭐ 中程度 | ⭐⭐ 中程度 |
| **アクセシビリティ** | ⭐⭐ 中程度 | ⭐⭐ 中程度 | ⭐ 低い | ⭐⭐ 中程度 |

### 推奨使用場面

| 無限スクロールタイプ | 最適な使用場面 | 例 |
|-------------------|----------------|-----|
| **基本無限スクロール** | シンプルなリスト | ブログ記事一覧、商品一覧 |
| **Intersection Observer** | パフォーマンス重視 | 画像ギャラリー、タイムライン |

## 1. 基本無限スクロール

### 概要
スクロールイベントを監視して新しいコンテンツを読み込む基本的な実装

### 実装例

```javascript
// 基本的な無限スクロール
function BasicInfiniteScroll({ items, itemsPerPage = 10 }) {
  const [currentPage, setCurrentPage] = useState(1);
  const [isLoading, setIsLoading] = useState(false);
  const [hasMore, setHasMore] = useState(true);

  const totalPages = Math.ceil(items.length / itemsPerPage);
  const displayedItems = items.slice(0, currentPage * itemsPerPage);

  const loadMore = useCallback(() => {
    if (isLoading || !hasMore) return;

    setIsLoading(true);
    
    // APIリクエストをシミュレート
    setTimeout(() => {
      setCurrentPage(prev => {
        const nextPage = prev + 1;
        setHasMore(nextPage < totalPages);
        setIsLoading(false);
        return nextPage;
      });
    }, 1000);
  }, [isLoading, hasMore, totalPages]);

  // スクロールイベントの監視
  useEffect(() => {
    const handleScroll = () => {
      if (window.innerHeight + document.documentElement.scrollTop 
          >= document.documentElement.offsetHeight - 1000) {
        loadMore();
      }
    };

    window.addEventListener('scroll', handleScroll);
    return () => window.removeEventListener('scroll', handleScroll);
  }, [loadMore]);

  return (
    <div>
      <div className="items-list">
        {displayedItems.map(item => (
          <div key={item.id} className="item">
            <h3>{item.name}</h3>
            <p>{item.description}</p>
          </div>
        ))}
      </div>

      {isLoading && (
        <div className="loading">
          <div className="spinner"></div>
          <p>読み込み中...</p>
        </div>
      )}

      {!hasMore && (
        <div className="no-more">
          <p>すべてのアイテムを表示しました</p>
        </div>
      )}
    </div>
  );
}
```

## 2. Intersection Observer API

### 概要
Intersection Observer APIを使用した効率的な無限スクロール実装

### 実装例

```javascript
// Intersection Observer APIを使った無限スクロール
function IntersectionInfiniteScroll({ items, itemsPerPage = 10 }) {
  const [currentPage, setCurrentPage] = useState(1);
  const [isLoading, setIsLoading] = useState(false);
  const [hasMore, setHasMore] = useState(true);
  const observerRef = useRef();

  const totalPages = Math.ceil(items.length / itemsPerPage);
  const displayedItems = items.slice(0, currentPage * itemsPerPage);

  const loadMore = useCallback(() => {
    if (isLoading || !hasMore) return;

    setIsLoading(true);
    
    setTimeout(() => {
      setCurrentPage(prev => {
        const nextPage = prev + 1;
        setHasMore(nextPage < totalPages);
        setIsLoading(false);
        return nextPage;
      });
    }, 1000);
  }, [isLoading, hasMore, totalPages]);

  // Intersection Observerの設定
  useEffect(() => {
    const observer = new IntersectionObserver(
      (entries) => {
        if (entries[0].isIntersecting) {
          loadMore();
        }
      },
      { 
        threshold: 0.1,
        rootMargin: '100px'
      }
    );

    if (observerRef.current) {
      observer.observe(observerRef.current);
    }

    return () => {
      if (observerRef.current) {
        observer.unobserve(observerRef.current);
      }
    };
  }, [loadMore]);

  return (
    <div>
      <div className="items-list">
        {displayedItems.map(item => (
          <div key={item.id} className="item">
            <h3>{item.name}</h3>
            <p>{item.description}</p>
          </div>
        ))}
      </div>

      {hasMore && (
        <div ref={observerRef} className="observer-trigger">
          {isLoading && (
            <div className="loading">
              <div className="spinner"></div>
              <p>読み込み中...</p>
            </div>
          )}
        </div>
      )}

      {!hasMore && (
        <div className="no-more">
          <p>すべてのアイテムを表示しました</p>
        </div>
      )}
    </div>
  );
}
```

### 高度なIntersection Observer実装

```javascript
// 複数のトリガー要素に対応した無限スクロール
function AdvancedIntersectionInfiniteScroll({ items, itemsPerPage = 10 }) {
  const [currentPage, setCurrentPage] = useState(1);
  const [isLoading, setIsLoading] = useState(false);
  const [hasMore, setHasMore] = useState(true);
  const [error, setError] = useState(null);
  const observerRef = useRef();
  const retryCountRef = useRef(0);

  const totalPages = Math.ceil(items.length / itemsPerPage);
  const displayedItems = items.slice(0, currentPage * itemsPerPage);

  const loadMore = useCallback(async () => {
    if (isLoading || !hasMore) return;

    setIsLoading(true);
    setError(null);
    
    try {
      // APIリクエストをシミュレート
      await new Promise((resolve, reject) => {
        setTimeout(() => {
          if (Math.random() < 0.1) { // 10%の確率でエラー
            reject(new Error('読み込みエラー'));
          } else {
            resolve();
          }
        }, 1000);
      });

      setCurrentPage(prev => {
        const nextPage = prev + 1;
        setHasMore(nextPage < totalPages);
        setIsLoading(false);
        retryCountRef.current = 0;
        return nextPage;
      });
    } catch (err) {
      setError(err.message);
      setIsLoading(false);
    }
  }, [isLoading, hasMore, totalPages]);

  const retry = useCallback(() => {
    retryCountRef.current += 1;
    if (retryCountRef.current <= 3) {
      loadMore();
    }
  }, [loadMore]);

  // Intersection Observerの設定
  useEffect(() => {
    const observer = new IntersectionObserver(
      (entries) => {
        if (entries[0].isIntersecting && !isLoading) {
          loadMore();
        }
      },
      { 
        threshold: 0.1,
        rootMargin: '200px'
      }
    );

    if (observerRef.current) {
      observer.observe(observerRef.current);
    }

    return () => {
      if (observerRef.current) {
        observer.unobserve(observerRef.current);
      }
    };
  }, [loadMore, isLoading]);

  return (
    <div>
      <div className="items-list">
        {displayedItems.map(item => (
          <div key={item.id} className="item">
            <h3>{item.name}</h3>
            <p>{item.description}</p>
          </div>
        ))}
      </div>

      {hasMore && (
        <div ref={observerRef} className="observer-trigger">
          {isLoading && (
            <div className="loading">
              <div className="spinner"></div>
              <p>読み込み中...</p>
            </div>
          )}
          
          {error && (
            <div className="error">
              <p>エラー: {error}</p>
              <button onClick={retry} disabled={retryCountRef.current >= 3}>
                再試行 ({retryCountRef.current}/3)
              </button>
            </div>
          )}
        </div>
      )}

      {!hasMore && (
        <div className="no-more">
          <p>すべてのアイテムを表示しました</p>
        </div>
      )}
    </div>
  );
}
```

### メリット
- ✅ **高性能**: スクロールイベントより効率的
- ✅ **バッテリー効率**: モバイルでのバッテリー消費が少ない
- ✅ **柔軟性**: 複数のトリガー要素に対応

```javascript
function VirtualizedInfiniteScroll({ 
  items, 
  itemsPerPage = 50,
  itemHeight = 100 
}) {
```

```javascript
// ハイブリッド型無限スクロール
function HybridInfiniteScroll({ 
  items, 
  itemsPerPage = 20,
  enableVirtualization = false,
  enablePrefetch = true
}) {
  const [currentPage, setCurrentPage] = useState(1);
  const [isLoading, setIsLoading] = useState(false);
  const [hasMore, setHasMore] = useState(true);
  const [prefetchedPages, setPrefetchedPages] = useState(new Set());
  const observerRef = useRef();

  const totalPages = Math.ceil(items.length / itemsPerPage);
  const displayedItems = items.slice(0, currentPage * itemsPerPage);

  const loadMore = useCallback(async () => {
    if (isLoading || !hasMore) return;

    setIsLoading(true);
    
    try {
      // APIリクエストをシミュレート
      await new Promise(resolve => setTimeout(resolve, 1000));
      
      setCurrentPage(prev => {
        const nextPage = prev + 1;
        setHasMore(nextPage < totalPages);
        setIsLoading(false);
        return nextPage;
      });

      // 次のページをプリフェッチ
      if (enablePrefetch && currentPage + 1 < totalPages) {
        prefetchPage(currentPage + 2);
      }
    } catch (error) {
      console.error('読み込みエラー:', error);
      setIsLoading(false);
    }
  }, [isLoading, hasMore, totalPages, currentPage, enablePrefetch]);

  const prefetchPage = useCallback(async (page) => {
    if (prefetchedPages.has(page)) return;

    try {
      await new Promise(resolve => setTimeout(resolve, 500));
      setPrefetchedPages(prev => new Set([...prev, page]));
    } catch (error) {
      console.error('プリフェッチエラー:', error);
    }
  }, [prefetchedPages]);

  // Intersection Observerの設定
  useEffect(() => {
    const observer = new IntersectionObserver(
      (entries) => {
        if (entries[0].isIntersecting && !isLoading) {
          loadMore();
        }
      },
      { 
        threshold: 0.1,
        rootMargin: '200px'
      }
    );

    if (observerRef.current) {
      observer.observe(observerRef.current);
    }

    return () => {
      if (observerRef.current) {
        observer.unobserve(observerRef.current);
      }
    };
  }, [loadMore, isLoading]);

  if (enableVirtualization) {
    return (
      <VirtualizedInfiniteScroll
        items={items}
        itemsPerPage={itemsPerPage}
      />
    );
  }

  return (
    <div>
      <div className="items-list">
        {displayedItems.map(item => (
          <div key={item.id} className="item">
            <h3>{item.name}</h3>
            <p>{item.description}</p>
          </div>
        ))}
      </div>

      {hasMore && (
        <div ref={observerRef} className="observer-trigger">
          {isLoading && (
            <div className="loading">
              <div className="spinner"></div>
              <p>読み込み中...</p>
            </div>
          )}
        </div>
      )}

      {!hasMore && (
        <div className="no-more">
          <p>すべてのアイテムを表示しました</p>
        </div>
      )}

      {enablePrefetch && (
        <div className="prefetch-info">
          <p>プリフェッチ済みページ: {prefetchedPages.size}</p>
        </div>
      )}
    </div>
  );
}
```

```javascript
function PrefetchInfiniteScroll({ items, itemsPerPage = 10 }) {

  const [prefetchedPages, setPrefetchedPages] = useState(new Set());

  const prefetchPage = useCallback(async (page) => {

    setCurrentPage(prev => {
      const nextPage = prev + 1;
      // 次のページをプリフェッチ
      if (nextPage < Math.ceil(items.length / itemsPerPage)) {
        prefetchPage(nextPage + 1);
      }
      return nextPage;
    });
  };

  return (
    <div>
      <InfiniteScrollItems 
        items={items}
        currentPage={currentPage}
        itemsPerPage={itemsPerPage}
      />
      <LoadMoreButton onLoadMore={loadMore} />
    </div>
  );
}
```

```javascript
// エラーハンドリング付き無限スクロール
function ErrorHandlingInfiniteScroll({ items, itemsPerPage = 10 }) {
  const [currentPage, setCurrentPage] = useState(1);
  const [isLoading, setIsLoading] = useState(false);
  const [hasMore, setHasMore] = useState(true);
  const [error, setError] = useState(null);
  const [retryCount, setRetryCount] = useState(0);

  const loadMore = useCallback(async () => {
    if (isLoading || !hasMore) return;

    setIsLoading(true);
    setError(null);
    
    try {
      // APIリクエストをシミュレート
      await new Promise((resolve, reject) => {
        setTimeout(() => {
          if (Math.random() < 0.1) { // 10%の確率でエラー
            reject(new Error('読み込みエラー'));
          } else {
            resolve();
          }
        }, 1000);
      });

      setCurrentPage(prev => {
        const nextPage = prev + 1;
        setHasMore(nextPage < Math.ceil(items.length / itemsPerPage));
        setIsLoading(false);
        setRetryCount(0);
        return nextPage;
      });
    } catch (err) {
      setError(err.message);
      setIsLoading(false);
    }
  }, [isLoading, hasMore, items.length, itemsPerPage]);

  const retry = () => {
    setRetryCount(prev => prev + 1);
    loadMore();
  };

  return (
    <div>
      <InfiniteScrollItems 
        items={items}
        currentPage={currentPage}
        itemsPerPage={itemsPerPage}
      />
      
      {error && (
        <div className="error">
          <p>エラー: {error}</p>
          <button onClick={retry} disabled={retryCount >= 3}>
            再試行 ({retryCount}/3)
          </button>
        </div>
      )}
    </div>
  );
}
```

```javascript
// アクセシビリティ対応の無限スクロール
function AccessibleInfiniteScroll({ items, itemsPerPage = 10 }) {
  const [currentPage, setCurrentPage] = useState(1);
  const [isLoading, setIsLoading] = useState(false);
  const [hasMore, setHasMore] = useState(true);
  const [announcement, setAnnouncement] = useState('');

  const loadMore = useCallback(() => {
    if (isLoading || !hasMore) return;

    setIsLoading(true);
    
    setTimeout(() => {
      setCurrentPage(prev => {
        const nextPage = prev + 1;
        setHasMore(nextPage < Math.ceil(items.length / itemsPerPage));
        setIsLoading(false);
        
        // スクリーンリーダーに新しいコンテンツを通知
        setAnnouncement(`${nextPage * itemsPerPage}件のアイテムが読み込まれました`);
        setTimeout(() => setAnnouncement(''), 1000);
        
        return nextPage;
      });
    }, 1000);
  }, [isLoading, hasMore, items.length, itemsPerPage]);

  return (
    <div>
      <div 
        role="status" 
        aria-live="polite" 
        aria-atomic="true"
        className="sr-only"
      >
        {announcement}
      </div>

      <InfiniteScrollItems 
        items={items}
        currentPage={currentPage}
        itemsPerPage={itemsPerPage}
      />
      
      {hasMore && (
        <button
          onClick={loadMore}
          disabled={isLoading}
          aria-label={isLoading ? '読み込み中' : 'さらに読み込む'}
        >
          {isLoading ? '読み込み中...' : 'さらに読み込む'}
        </button>
      )}
    </div>
  );
}
```

## まとめ

| 無限スクロールタイプ | 適用場面 | 主なメリット | 主なデメリット |
|-------------------|---------|-------------|---------------|
| **基本無限スクロール** | シンプルなリスト | 実装が簡単、理解しやすい | パフォーマンスが低い |
| **Intersection Observer** | パフォーマンス重視 | 高性能、バッテリー効率 | ブラウザ対応が限定的 |
| **仮想化無限スクロール** | 大量データ | 高性能、メモリ効率 | 実装が複雑 |
| **ハイブリッド型** | 複雑な要件 | 柔軟性、拡張性 | 実装が複雑 |

### 選択の指針

1. **シンプルなリスト** → 基本無限スクロール
2. **パフォーマンス重視** → Intersection Observer
3. **大量データ** → 仮想化無限スクロール
4. **複雑な要件** → ハイブリッド型
