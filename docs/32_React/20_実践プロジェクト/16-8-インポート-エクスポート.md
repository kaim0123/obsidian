# 16-8 インポート/エクスポート（データ連携）

## 🎯 この章で学ぶこと

- ブラウザでの CSV / JSON ファイルのダウンロードとアップロードの基本
- File / Blob / FormData API の役割と使い方
- 大量データを扱うときの注意点（メモリ・タイムアウト）
- CSV のパース時に気をつけるエッジケース（カンマを含む値、改行、文字コード）
- バリデーションエラーをユーザーに分かりやすく見せる UI

## 📖 概念の説明

### なぜインポート/エクスポートが必要か

- 既存の Excel データから移行したい
- 別のサービスにデータを移したい
- バックアップを取りたい
- 大量データをまとめて編集したい

業務系アプリでは「インポート機能ありますか？」が必ず聞かれます。

### Blob と File

- **Blob**: 「中身が任意のバイナリデータ」を表すブラウザ標準オブジェクト
- **File**: Blob を継承していて、ファイル名と更新日時を持つ

`new Blob(["hello"], { type: "text/plain" })` で生成できます。

### CSV のやっかいな仕様

CSV は単純なフォーマットに見えて、罠が多いです。

- 値にカンマが含まれる → ダブルクオートで囲む（`"a,b","c"`）
- 値にダブルクオートが含まれる → 2 重にエスケープ（`"a""b"`）
- 値に改行が含まれる → ダブルクオートで囲めば OK
- Excel で開く前提なら BOM 付き UTF-8 にしないと文字化け

自前パースは推奨しません。`papaparse` のようなライブラリを使いましょう。

### 文字コードと BOM

日本語を扱うとき、BOM（Byte Order Mark）なしの UTF-8 だと Excel で文字化けします。エクスポート時は先頭に `﻿` を付けるのが定番です。

## 💻 コード例

### JSON エクスポート

```ts
function downloadJson(filename: string, data: unknown) {
  const blob = new Blob([JSON.stringify(data, null, 2)], {
    type: "application/json",
  });
  triggerDownload(blob, filename);
}

function triggerDownload(blob: Blob, filename: string) {
  const url = URL.createObjectURL(blob);
  const a = document.createElement("a");
  a.href = url;
  a.download = filename;
  document.body.appendChild(a);
  a.click();
  document.body.removeChild(a);
  URL.revokeObjectURL(url); // メモリ解放
}
```

`URL.revokeObjectURL` を忘れるとメモリリークになります。

### CSV エクスポート（papaparse）

```bash
npm i papaparse
npm i -D @types/papaparse
```

```ts
import Papa from "papaparse";

export function downloadTasksCsv(tasks: Task[]) {
  const rows = tasks.map((t) => ({
    ID: t.id,
    タイトル: t.title,
    完了: t.done ? "はい" : "いいえ",
    期限: t.dueDate ?? "",
    優先度: t.priority,
    タグ: t.tags.join(";"),
    作成日: t.createdAt,
  }));
  const csv = Papa.unparse(rows);
  const bom = "﻿"; // Excel 文字化け対策
  const blob = new Blob([bom + csv], { type: "text/csv;charset=utf-8" });
  triggerDownload(blob, `tasks_${new Date().toISOString().slice(0, 10)}.csv`);
}
```

### CSV インポート UI

```tsx
import Papa from "papaparse";

type ParsedRow = { title: string; dueDate?: string; priority?: string };
type RowError = { line: number; message: string };

function ImportTasks() {
  const [errors, setErrors] = useState<RowError[]>([]);
  const [success, setSuccess] = useState<number | null>(null);
  const importMutation = useMutation({
    mutationFn: (rows: ParsedRow[]) =>
      api("/tasks/import", {
        method: "POST",
        body: JSON.stringify({ rows }),
      }),
  });

  function handleFile(file: File) {
    Papa.parse(file, {
      header: true,
      skipEmptyLines: true,
      complete: (result) => {
        const valid: ParsedRow[] = [];
        const errs: RowError[] = [];
        result.data.forEach((row: any, i: number) => {
          const line = i + 2; // 1 行目はヘッダ
          if (!row["タイトル"] || row["タイトル"].length > 100) {
            errs.push({ line, message: "タイトルは 1〜100 文字で必須です" });
            return;
          }
          valid.push({
            title: row["タイトル"],
            dueDate: row["期限"] || undefined,
            priority: row["優先度"] || "medium",
          });
        });
        setErrors(errs);
        if (errs.length === 0) {
          importMutation.mutate(valid, {
            onSuccess: () => setSuccess(valid.length),
          });
        }
      },
    });
  }

  return (
    <div>
      <input
        type="file"
        accept=".csv"
        aria-label="CSV ファイル"
        onChange={(e) => {
          const f = e.target.files?.[0];
          if (f) handleFile(f);
        }}
      />
      {success !== null && <p>{success} 件をインポートしました。</p>}
      {errors.length > 0 && (
        <ul role="alert">
          {errors.map((e, i) => (
            <li key={i}>
              {e.line} 行目: {e.message}
            </li>
          ))}
        </ul>
      )}
    </div>
  );
}
```

### ファイルアップロード（FormData）

画像など、ファイルそのものをサーバへ送るパターン。

```ts
async function uploadAvatar(file: File) {
  const fd = new FormData();
  fd.append("file", file);
  return fetch("/api/me/avatar", {
    method: "POST",
    body: fd,
    // Content-Type は手動で設定しない。fetch が自動で multipart 境界を付ける
  });
}
```

### ドラッグ&ドロップでのファイル受け取り

```tsx
function FileDropzone({ onFile }: { onFile: (file: File) => void }) {
  const [over, setOver] = useState(false);
  return (
    <div
      onDragOver={(e) => {
        e.preventDefault();
        setOver(true);
      }}
      onDragLeave={() => setOver(false)}
      onDrop={(e) => {
        e.preventDefault();
        setOver(false);
        const f = e.dataTransfer.files[0];
        if (f) onFile(f);
      }}
      style={{
        padding: 40,
        border: `2px dashed ${over ? "blue" : "#ccc"}`,
        textAlign: "center",
      }}
    >
      ファイルをここにドロップ、または
      <input
        type="file"
        onChange={(e) => e.target.files?.[0] && onFile(e.target.files[0])}
      />
    </div>
  );
}
```

### 大量データ: ストリームでパース

数十 MB の CSV を `Papa.parse(file)` で一括読み込みすると重くなることがあります。`step` オプションで行ごとに処理しましょう。

```ts
Papa.parse(file, {
  header: true,
  worker: true, // Web Worker で別スレッド処理
  step: (row, parser) => {
    processOneRow(row.data);
    if (shouldStop) parser.abort();
  },
  complete: () => console.log("done"),
});
```

### サーバ側: チャンク分割アップロード

100 MB を超えるようなデータは、フロントで分割して送るパターンも有効です。

```ts
async function uploadInChunks(file: File, chunkSize = 1024 * 1024) {
  const total = Math.ceil(file.size / chunkSize);
  for (let i = 0; i < total; i++) {
    const blob = file.slice(i * chunkSize, (i + 1) * chunkSize);
    const fd = new FormData();
    fd.append("chunk", blob);
    fd.append("index", String(i));
    fd.append("total", String(total));
    await fetch("/api/upload-chunk", { method: "POST", body: fd });
  }
}
```

## ❌ よくある間違い

### 1. CSV を `split(",")` で自前パース

カンマや改行入りの値を扱った瞬間に破綻します。素直に `papaparse` を使いましょう。

### 2. BOM なし UTF-8 で日本語 CSV を出力

Excel で開くと文字化けします。`﻿` を先頭に付ける。

### 3. ダウンロードリンクの Blob URL を解放しない

`URL.revokeObjectURL` を呼ばないとメモリリークします。クリック後に呼ぶのが基本。

### 4. 大量データを `JSON.stringify` で一気に作る

数万件以上だとブラウザがフリーズします。サーバから NDJSON で受け取り、ストリームで処理するなどの工夫を。

### 5. アップロード時に `Content-Type` を手動指定

```ts
fetch("/upload", { headers: { "Content-Type": "multipart/form-data" } });
// ❌ boundary が付かず壊れる
```

`FormData` を渡すときはヘッダを書かないのが正解です。

## ✅ ベストプラクティス

1. **CSV は papaparse、JSON は標準 API**: 自前で頑張らない。
2. **Excel 互換のために BOM 付き UTF-8**: 日本語ユーザーのために必須。
3. **インポートはまず検証、次に投入**: バリデーションエラーを行番号付きで表示。
4. **大きなファイルはストリーム処理**: メインスレッドを止めない。
5. **進捗表示を必ず出す**: 数秒以上かかる処理にはプログレスバー or スピナー。

## 📝 まとめ

- ブラウザのファイル機能は Blob / File / FormData の 3 役で完結
- CSV は奥が深いのでライブラリに任せる
- Excel 文字化け対策に BOM、メモリ対策に Blob URL の解放
- インポートはバリデーション結果を行番号付きで表示するのが親切
- 大容量はストリーム処理 + チャンク分割で快適に
