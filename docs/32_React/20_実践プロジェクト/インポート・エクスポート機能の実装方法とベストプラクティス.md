# インポート・エクスポート機能の実装方法とベストプラクティス

## 概要

インポート・エクスポート機能の実装には主に3つの方法があります。それぞれの特徴、メリット・デメリット、使用場面を詳しく解説します。

## 実装方法の比較表

| 項目 | CSV形式 | Excel形式 | JSON形式 |
|------|---------|-----------|----------|
| **実装の複雑さ** | ⭐ 簡単 | ⭐⭐ 中程度 | ⭐ 簡単 |
| **データ容量** | ⭐⭐ 中程度 | ⭐ 大きい | ⭐⭐⭐ 小さい |
| **可読性** | ⭐⭐ 中程度 | ⭐⭐⭐ 高い | ⭐ 低い |
| **構造化データ** | ⭐⭐ 中程度 | ⭐⭐⭐ 優秀 | ⭐⭐⭐ 優秀 |
| **互換性** | ⭐⭐⭐ 優秀 | ⭐⭐⭐ 優秀 | ⭐⭐ 中程度 |
| **処理速度** | ⭐⭐⭐ 高速 | ⭐⭐ 中程度 | ⭐⭐⭐ 高速 |
| **メタデータ対応** | ❌ 不可 | ✅ 可能 | ✅ 可能 |
| **画像・ファイル** | ❌ 不可 | ✅ 可能 | ⭐ 限定的 |
| **バリデーション** | ⭐⭐ 中程度 | ⭐⭐ 中程度 | ⭐⭐⭐ 優秀 |
| **エラーハンドリング** | ⭐⭐ 中程度 | ⭐⭐ 中程度 | ⭐⭐⭐ 優秀 |

### 推奨使用場面

| 実装方法 | 最適な使用場面 | 例 |
|----------|----------------|-----|
| **CSV形式** | シンプルな表データ | ユーザー一覧、商品データ、売上データ |
| **Excel形式** | 複雑な表データ | 財務データ、レポート、複数シート |
| **JSON形式** | 構造化データ | 設定データ、APIデータ、アプリケーション状態 |

## 1. CSV形式

### 概要
カンマ区切り値（CSV）を使用したシンプルなインポート・エクスポート

### 実装例

```javascript
import Papa from 'papaparse';

function CSVImportExport() {
  const [data, setData] = useState([]);
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState(null);
  const [importResult, setImportResult] = useState(null);

  // CSVエクスポート
  const exportToCSV = () => {
    if (data.length === 0) {
      alert('エクスポートするデータがありません');
      return;
    }

    const csv = Papa.unparse(data, {
      header: true,
      delimiter: ',',
      newline: '\n'
    });

    // ファイルダウンロード
    const blob = new Blob([csv], { type: 'text/csv;charset=utf-8;' });
    const link = document.createElement('a');
    const url = URL.createObjectURL(blob);
    
    link.setAttribute('href', url);
    link.setAttribute('download', `export_${new Date().toISOString().split('T')[0]}.csv`);
    link.style.visibility = 'hidden';
    
    document.body.appendChild(link);
    link.click();
    document.body.removeChild(link);
  };

  // CSVインポート
  const handleFileUpload = (event) => {
    const file = event.target.files[0];
    if (!file) return;

    setLoading(true);
    setError(null);
    setImportResult(null);

    Papa.parse(file, {
      header: true,
      skipEmptyLines: true,
      complete: (results) => {
        setLoading(false);
        
        if (results.errors.length > 0) {
          setError(`CSV解析エラー: ${results.errors[0].message}`);
          return;
        }

        // データバリデーション
        const validationResult = validateCSVData(results.data);
        
        if (validationResult.isValid) {
          setData(validationResult.data);
          setImportResult({
            success: true,
            imported: validationResult.data.length,
            errors: validationResult.errors
          });
        } else {
          setError(`データ検証エラー: ${validationResult.errors.join(', ')}`);
        }
      },
      error: (error) => {
        setLoading(false);
        setError(`ファイル読み込みエラー: ${error.message}`);
      }
    });
  };

  // データバリデーション
  const validateCSVData = (csvData) => {
    const errors = [];
    const validData = [];

    const requiredFields = ['name', 'email', 'age'];
    
    csvData.forEach((row, index) => {
      const rowErrors = [];
      
      // 必須フィールドのチェック
      requiredFields.forEach(field => {
        if (!row[field] || row[field].trim() === '') {
          rowErrors.push(`${field}は必須です`);
        }
      });

      // メールアドレスの形式チェック
      if (row.email && !isValidEmail(row.email)) {
        rowErrors.push('メールアドレスの形式が正しくありません');
      }

      // 年齢の数値チェック
      if (row.age && (isNaN(row.age) || parseInt(row.age) < 0 || parseInt(row.age) > 150)) {
        rowErrors.push('年齢は0-150の数値で入力してください');
      }

      if (rowErrors.length > 0) {
        errors.push(`行${index + 2}: ${rowErrors.join(', ')}`);
      } else {
        // データの正規化
        validData.push({
          ...row,
          age: parseInt(row.age),
          email: row.email.toLowerCase().trim()
        });
      }
    });

    return {
      isValid: errors.length === 0,
      data: validData,
      errors
    };
  };

  // メールアドレス検証
  const isValidEmail = (email) => {
    const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
    return emailRegex.test(email);
  };

  // テンプレートダウンロード
  const downloadTemplate = () => {
    const templateData = [
      { name: '山田太郎', email: 'yamada@example.com', age: 30 },
      { name: '佐藤花子', email: 'sato@example.com', age: 25 }
    ];

    const csv = Papa.unparse(templateData, {
      header: true
    });

    const blob = new Blob([csv], { type: 'text/csv;charset=utf-8;' });
    const link = document.createElement('a');
    const url = URL.createObjectURL(blob);
    
    link.setAttribute('href', url);
    link.setAttribute('download', 'template.csv');
    link.style.visibility = 'hidden';
    
    document.body.appendChild(link);
    link.click();
    document.body.removeChild(link);
  };

  return (
    <div style={{ padding: '20px' }}>
      <h2>CSV インポート・エクスポート</h2>

      {/* エラーメッセージ */}
      {error && (
        <div style={{ 
          padding: '10px', 
          backgroundColor: '#ffebee', 
          color: '#c62828',
          borderRadius: '4px',
          marginBottom: '20px'
        }}>
          {error}
        </div>
      )}

      {/* インポート結果 */}
      {importResult && (
        <div style={{ 
          padding: '10px', 
          backgroundColor: importResult.success ? '#e8f5e8' : '#ffebee',
          color: importResult.success ? '#2e7d32' : '#c62828',
          borderRadius: '4px',
          marginBottom: '20px'
        }}>
          {importResult.success ? (
            <div>
              <strong>インポート完了:</strong> {importResult.imported}件のデータをインポートしました
              {importResult.errors.length > 0 && (
                <div style={{ marginTop: '5px', fontSize: '14px' }}>
                  警告: {importResult.errors.length}件のデータに問題がありました
                </div>
              )}
            </div>
          ) : (
            <div>
              <strong>インポートエラー:</strong> {importResult.errors.join(', ')}
            </div>
          )}
        </div>
      )}

      {/* 操作ボタン */}
      <div style={{ marginBottom: '20px' }}>
        <input
          type="file"
          accept=".csv"
          onChange={handleFileUpload}
          style={{ marginRight: '10px' }}
        />
        <button 
          onClick={downloadTemplate}
          style={{ 
            marginRight: '10px',
            padding: '8px 16px',
            backgroundColor: '#2196f3',
            color: 'white',
            border: 'none',
            borderRadius: '4px'
          }}
        >
          テンプレートダウンロード
        </button>
        <button 
          onClick={exportToCSV}
          disabled={data.length === 0}
          style={{ 
            padding: '8px 16px',
            backgroundColor: '#4caf50',
            color: 'white',
            border: 'none',
            borderRadius: '4px'
          }}
        >
          エクスポート
        </button>
        {loading && <span style={{ marginLeft: '10px' }}>読み込み中...</span>}
      </div>

      {/* データ表示 */}
      {data.length > 0 && (
        <div>
          <h3>データ一覧 ({data.length}件)</h3>
          <table style={{ 
            width: '100%', 
            borderCollapse: 'collapse',
            border: '1px solid #ddd'
          }}>
            <thead>
              <tr style={{ backgroundColor: '#f5f5f5' }}>
                <th style={{ border: '1px solid #ddd', padding: '8px' }}>名前</th>
                <th style={{ border: '1px solid #ddd', padding: '8px' }}>メール</th>
                <th style={{ border: '1px solid #ddd', padding: '8px' }}>年齢</th>
              </tr>
            </thead>
            <tbody>
              {data.map((row, index) => (
                <tr key={index}>
                  <td style={{ border: '1px solid #ddd', padding: '8px' }}>{row.name}</td>
                  <td style={{ border: '1px solid #ddd', padding: '8px' }}>{row.email}</td>
                  <td style={{ border: '1px solid #ddd', padding: '8px' }}>{row.age}</td>
                </tr>
              ))}
            </tbody>
          </table>
        </div>
      )}
    </div>
  );
}
```

### メリット
- ✅ **実装が簡単**: 基本的な文字列処理で実装可能
- ✅ **互換性が高い**: ほとんどのアプリケーションで対応
- ✅ **処理速度が速い**: 軽量で高速な処理
- ✅ **人間が読みやすい**: テキストエディタで確認可能
- ✅ **ファイルサイズが小さい**: 効率的なデータ保存

### デメリット
- ❌ **構造化データ**: 複雑なデータ構造に対応困難
- ❌ **メタデータ**: データの説明や設定情報を保存不可
- ❌ **画像・ファイル**: バイナリデータの保存不可
- ❌ **エンコーディング**: 文字化けの問題が発生しやすい
- ❌ **型情報**: データ型の情報が失われる

### 使用場面
- 👥 **ユーザー管理**: ユーザー一覧のインポート・エクスポート
- 🛒 **商品データ**: 商品情報の一括登録
- 📊 **売上データ**: 売上レポートの出力
- 📋 **リスト管理**: シンプルな一覧データの管理

## 2. Excel形式

### 概要
Excelファイル（.xlsx）を使用した高機能なインポート・エクスポート

### 実装例

```javascript
import * as XLSX from 'xlsx';

function ExcelImportExport() {
  const [data, setData] = useState([]);
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState(null);
  const [sheets, setSheets] = useState([]);

  // Excelエクスポート
  const exportToExcel = () => {
    if (data.length === 0) {
      alert('エクスポートするデータがありません');
      return;
    }

    // 複数シートのワークブックを作成
    const wb = XLSX.utils.book_new();

    // メインデータシート
    const ws1 = XLSX.utils.json_to_sheet(data);
    XLSX.utils.book_append_sheet(wb, ws1, 'データ一覧');

    // サマリーシート
    const summaryData = [
      { 項目: '総件数', 値: data.length },
      { 項目: 'エクスポート日時', 値: new Date().toLocaleString() },
      { 項目: 'データ形式', 値: 'Excel (.xlsx)' }
    ];
    const ws2 = XLSX.utils.json_to_sheet(summaryData);
    XLSX.utils.book_append_sheet(wb, ws2, 'サマリー');

    // ファイル出力
    XLSX.writeFile(wb, `export_${new Date().toISOString().split('T')[0]}.xlsx`);
  };

  // Excelインポート
  const handleFileUpload = (event) => {
    const file = event.target.files[0];
    if (!file) return;

    setLoading(true);
    setError(null);

    const reader = new FileReader();
    reader.onload = (e) => {
      try {
        const data = new Uint8Array(e.target.result);
        const workbook = XLSX.read(data, { type: 'array' });

        // シート一覧を取得
        const sheetNames = workbook.SheetNames;
        setSheets(sheetNames);

        // 最初のシートからデータを読み込み
        const firstSheet = workbook.Sheets[sheetNames[0]];
        const jsonData = XLSX.utils.sheet_to_json(firstSheet, { 
          header: 1,
          defval: '' 
        });

        // ヘッダーとデータを分離
        const [headers, ...rows] = jsonData;
        
        // データをオブジェクト形式に変換
        const formattedData = rows.map(row => {
          const obj = {};
          headers.forEach((header, index) => {
            if (header) {
              obj[header] = row[index] || '';
            }
          });
          return obj;
        });

        // データバリデーション
        const validationResult = validateExcelData(formattedData);
        
        if (validationResult.isValid) {
          setData(validationResult.data);
        } else {
          setError(`データ検証エラー: ${validationResult.errors.join(', ')}`);
        }

      } catch (error) {
        setError(`ファイル読み込みエラー: ${error.message}`);
      } finally {
        setLoading(false);
      }
    };

    reader.readAsArrayBuffer(file);
  };

  // データバリデーション
  const validateExcelData = (excelData) => {
    const errors = [];
    const validData = [];

    const requiredFields = ['name', 'email'];
    
    excelData.forEach((row, index) => {
      const rowErrors = [];
      
      // 空行をスキップ
      if (!row.name && !row.email) return;

      // 必須フィールドのチェック
      requiredFields.forEach(field => {
        if (!row[field] || row[field].toString().trim() === '') {
          rowErrors.push(`${field}は必須です`);
        }
      });

      // メールアドレスの形式チェック
      if (row.email && !isValidEmail(row.email)) {
        rowErrors.push('メールアドレスの形式が正しくありません');
      }

      if (rowErrors.length > 0) {
        errors.push(`行${index + 2}: ${rowErrors.join(', ')}`);
      } else {
        validData.push({
          ...row,
          email: row.email.toString().toLowerCase().trim(),
          age: row.age ? parseInt(row.age) || 0 : 0
        });
      }
    });

    return {
      isValid: errors.length === 0,
      data: validData,
      errors
    };
  };

  // メールアドレス検証
  const isValidEmail = (email) => {
    const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
    return emailRegex.test(email);
  };

  // テンプレートダウンロード
  const downloadTemplate = () => {
    const wb = XLSX.utils.book_new();
    
    // データシート
    const templateData = [
      { name: '山田太郎', email: 'yamada@example.com', age: 30, department: '営業部' },
      { name: '佐藤花子', email: 'sato@example.com', age: 25, department: '開発部' }
    ];
    const ws1 = XLSX.utils.json_to_sheet(templateData);
    XLSX.utils.book_append_sheet(wb, ws1, 'データ');

    // 説明シート
    const instructionData = [
      { 項目: '説明', 内容: '以下の形式でデータを入力してください' },
      { 項目: 'name', 内容: '氏名（必須）' },
      { 項目: 'email', 内容: 'メールアドレス（必須）' },
      { 項目: 'age', 内容: '年齢（数値）' },
      { 項目: 'department', 内容: '部署名' }
    ];
    const ws2 = XLSX.utils.json_to_sheet(instructionData);
    XLSX.utils.book_append_sheet(wb, ws2, '入力説明');

    XLSX.writeFile(wb, 'template.xlsx');
  };

  return (
    <div style={{ padding: '20px' }}>
      <h2>Excel インポート・エクスポート</h2>

      {/* エラーメッセージ */}
      {error && (
        <div style={{ 
          padding: '10px', 
          backgroundColor: '#ffebee', 
          color: '#c62828',
          borderRadius: '4px',
          marginBottom: '20px'
        }}>
          {error}
        </div>
      )}

      {/* シート情報 */}
      {sheets.length > 0 && (
        <div style={{ 
          padding: '10px', 
          backgroundColor: '#e3f2fd',
          borderRadius: '4px',
          marginBottom: '20px'
        }}>
          <strong>シート一覧:</strong> {sheets.join(', ')}
        </div>
      )}

      {/* 操作ボタン */}
      <div style={{ marginBottom: '20px' }}>
        <input
          type="file"
          accept=".xlsx,.xls"
          onChange={handleFileUpload}
          style={{ marginRight: '10px' }}
        />
        <button 
          onClick={downloadTemplate}
          style={{ 
            marginRight: '10px',
            padding: '8px 16px',
            backgroundColor: '#2196f3',
            color: 'white',
            border: 'none',
            borderRadius: '4px'
          }}
        >
          テンプレートダウンロード
        </button>
        <button 
          onClick={exportToExcel}
          disabled={data.length === 0}
          style={{ 
            padding: '8px 16px',
            backgroundColor: '#4caf50',
            color: 'white',
            border: 'none',
            borderRadius: '4px'
          }}
        >
          エクスポート
        </button>
        {loading && <span style={{ marginLeft: '10px' }}>読み込み中...</span>}
      </div>

      {/* データ表示 */}
      {data.length > 0 && (
        <div>
          <h3>データ一覧 ({data.length}件)</h3>
          <div style={{ overflowX: 'auto' }}>
            <table style={{ 
              width: '100%', 
              borderCollapse: 'collapse',
              border: '1px solid #ddd',
              minWidth: '600px'
            }}>
              <thead>
                <tr style={{ backgroundColor: '#f5f5f5' }}>
                  {Object.keys(data[0]).map(key => (
                    <th key={key} style={{ border: '1px solid #ddd', padding: '8px' }}>
                      {key}
                    </th>
                  ))}
                </tr>
              </thead>
              <tbody>
                {data.map((row, index) => (
                  <tr key={index}>
                    {Object.values(row).map((value, valueIndex) => (
                      <td key={valueIndex} style={{ border: '1px solid #ddd', padding: '8px' }}>
                        {value}
                      </td>
                    ))}
                  </tr>
                ))}
              </tbody>
            </table>
          </div>
        </div>
      )}
    </div>
  );
}
```

### メリット
- ✅ **構造化データ**: 複雑なデータ構造に対応
- ✅ **複数シート**: 複数のデータセットを管理可能
- ✅ **メタデータ**: データの説明や設定情報を保存可能
- ✅ **フォーマット**: セルの書式設定が可能
- ✅ **互換性**: Excel以外のアプリケーションでも対応

### デメリット
- ❌ **ファイルサイズ**: CSVよりファイルサイズが大きい
- ❌ **処理速度**: 複雑な構造のため処理が重い
- ❌ **実装の複雑さ**: ライブラリの学習が必要
- ❌ **メモリ使用量**: 大きなファイルでメモリを大量消費
- ❌ **ブラウザ制限**: 一部の古いブラウザで対応不可

### 使用場面
- 📊 **財務データ**: 複雑な帳票の管理
- 📋 **レポート**: 複数シートを含む詳細レポート
- 🏢 **企業データ**: 組織構造や人事データ
- 📈 **分析データ**: 統計や分析結果の保存

## 3. JSON形式

### 概要
JSON形式を使用した構造化データのインポート・エクスポート

### 実装例

```javascript
function JSONImportExport() {
  const [data, setData] = useState({
    users: [],
    settings: {},
    metadata: {
      version: '1.0.0',
      exportDate: null,
      totalRecords: 0
    }
  });
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState(null);

  // JSONエクスポート
  const exportToJSON = () => {
    const exportData = {
      ...data,
      metadata: {
        ...data.metadata,
        exportDate: new Date().toISOString(),
        totalRecords: data.users.length
      }
    };

    const jsonString = JSON.stringify(exportData, null, 2);
    
    const blob = new Blob([jsonString], { type: 'application/json' });
    const link = document.createElement('a');
    const url = URL.createObjectURL(blob);
    
    link.setAttribute('href', url);
    link.setAttribute('download', `export_${new Date().toISOString().split('T')[0]}.json`);
    link.style.visibility = 'hidden';
    
    document.body.appendChild(link);
    link.click();
    document.body.removeChild(link);
  };

  // JSONインポート
  const handleFileUpload = (event) => {
    const file = event.target.files[0];
    if (!file) return;

    setLoading(true);
    setError(null);

    const reader = new FileReader();
    reader.onload = (e) => {
      try {
        const jsonData = JSON.parse(e.target.result);
        
        // スキーマバリデーション
        const validationResult = validateJSONSchema(jsonData);
        
        if (validationResult.isValid) {
          setData(validationResult.data);
        } else {
          setError(`データ検証エラー: ${validationResult.errors.join(', ')}`);
        }

      } catch (error) {
        setError(`JSON解析エラー: ${error.message}`);
      } finally {
        setLoading(false);
      }
    };

    reader.readAsText(file);
  };

  // スキーマバリデーション
  const validateJSONSchema = (jsonData) => {
    const errors = [];
    
    // 必須フィールドのチェック
    if (!jsonData.users || !Array.isArray(jsonData.users)) {
      errors.push('usersフィールドが配列として存在しません');
    }

    if (!jsonData.metadata || typeof jsonData.metadata !== 'object') {
      errors.push('metadataフィールドがオブジェクトとして存在しません');
    }

    // ユーザーデータのバリデーション
    if (jsonData.users && Array.isArray(jsonData.users)) {
      jsonData.users.forEach((user, index) => {
        if (!user.id || !user.name || !user.email) {
          errors.push(`ユーザー${index + 1}: id, name, emailは必須です`);
        }

        if (user.email && !isValidEmail(user.email)) {
          errors.push(`ユーザー${index + 1}: メールアドレスの形式が正しくありません`);
        }
      });
    }

    // データの正規化
    const normalizedData = {
      users: jsonData.users || [],
      settings: jsonData.settings || {},
      metadata: {
        version: jsonData.metadata?.version || '1.0.0',
        exportDate: jsonData.metadata?.exportDate || null,
        totalRecords: jsonData.users?.length || 0
      }
    };

    return {
      isValid: errors.length === 0,
      data: normalizedData,
      errors
    };
  };

  // メールアドレス検証
  const isValidEmail = (email) => {
    const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
    return emailRegex.test(email);
  };

  // テンプレートダウンロード
  const downloadTemplate = () => {
    const templateData = {
      users: [
        {
          id: 1,
          name: '山田太郎',
          email: 'yamada@example.com',
          age: 30,
          department: '営業部',
          role: 'manager',
          permissions: ['read', 'write'],
          preferences: {
            theme: 'light',
            language: 'ja'
          }
        },
        {
          id: 2,
          name: '佐藤花子',
          email: 'sato@example.com',
          age: 25,
          department: '開発部',
          role: 'developer',
          permissions: ['read'],
          preferences: {
            theme: 'dark',
            language: 'en'
          }
        }
      ],
      settings: {
        maxUsers: 100,
        allowRegistration: true,
        defaultRole: 'user'
      },
      metadata: {
        version: '1.0.0',
        exportDate: new Date().toISOString(),
        totalRecords: 2
      }
    };

    const jsonString = JSON.stringify(templateData, null, 2);
    
    const blob = new Blob([jsonString], { type: 'application/json' });
    const link = document.createElement('a');
    const url = URL.createObjectURL(blob);
    
    link.setAttribute('href', url);
    link.setAttribute('download', 'template.json');
    link.style.visibility = 'hidden';
    
    document.body.appendChild(link);
    link.click();
    document.body.removeChild(link);
  };

  // データの追加
  const addUser = () => {
    const newUser = {
      id: Date.now(),
      name: '',
      email: '',
      age: 0,
      department: '',
      role: 'user',
      permissions: ['read'],
      preferences: {
        theme: 'light',
        language: 'ja'
      }
    };

    setData(prev => ({
      ...prev,
      users: [...prev.users, newUser]
    }));
  };

  // ユーザーの更新
  const updateUser = (id, updates) => {
    setData(prev => ({
      ...prev,
      users: prev.users.map(user => 
        user.id === id ? { ...user, ...updates } : user
      )
    }));
  };

  // ユーザーの削除
  const deleteUser = (id) => {
    setData(prev => ({
      ...prev,
      users: prev.users.filter(user => user.id !== id)
    }));
  };

  return (
    <div style={{ padding: '20px' }}>
      <h2>JSON インポート・エクスポート</h2>

      {/* エラーメッセージ */}
      {error && (
        <div style={{ 
          padding: '10px', 
          backgroundColor: '#ffebee', 
          color: '#c62828',
          borderRadius: '4px',
          marginBottom: '20px'
        }}>
          {error}
        </div>
      )}

      {/* 操作ボタン */}
      <div style={{ marginBottom: '20px' }}>
        <input
          type="file"
          accept=".json"
          onChange={handleFileUpload}
          style={{ marginRight: '10px' }}
        />
        <button 
          onClick={downloadTemplate}
          style={{ 
            marginRight: '10px',
            padding: '8px 16px',
            backgroundColor: '#2196f3',
            color: 'white',
            border: 'none',
            borderRadius: '4px'
          }}
        >
          テンプレートダウンロード
        </button>
        <button 
          onClick={exportToJSON}
          disabled={data.users.length === 0}
          style={{ 
            marginRight: '10px',
            padding: '8px 16px',
            backgroundColor: '#4caf50',
            color: 'white',
            border: 'none',
            borderRadius: '4px'
          }}
        >
          エクスポート
        </button>
        <button 
          onClick={addUser}
          style={{ 
            padding: '8px 16px',
            backgroundColor: '#ff9800',
            color: 'white',
            border: 'none',
            borderRadius: '4px'
          }}
        >
          ユーザー追加
        </button>
        {loading && <span style={{ marginLeft: '10px' }}>読み込み中...</span>}
      </div>

      {/* メタデータ表示 */}
      <div style={{ 
        padding: '10px', 
        backgroundColor: '#f5f5f5',
        borderRadius: '4px',
        marginBottom: '20px'
      }}>
        <h4>メタデータ</h4>
        <div>バージョン: {data.metadata.version}</div>
        <div>エクスポート日時: {data.metadata.exportDate || '未設定'}</div>
        <div>総レコード数: {data.metadata.totalRecords}</div>
      </div>

      {/* ユーザー一覧 */}
      <div>
        <h3>ユーザー一覧 ({data.users.length}件)</h3>
        {data.users.map(user => (
          <div key={user.id} style={{
            border: '1px solid #ddd',
            borderRadius: '4px',
            padding: '15px',
            marginBottom: '10px',
            backgroundColor: '#fafafa'
          }}>
            <div style={{ display: 'flex', justifyContent: 'space-between', alignItems: 'center' }}>
              <h4 style={{ margin: 0 }}>{user.name}</h4>
              <button 
                onClick={() => deleteUser(user.id)}
                style={{ 
                  padding: '4px 8px',
                  backgroundColor: '#f44336',
                  color: 'white',
                  border: 'none',
                  borderRadius: '3px'
                }}
              >
                削除
              </button>
            </div>
            <div>メール: {user.email}</div>
            <div>年齢: {user.age}</div>
            <div>部署: {user.department}</div>
            <div>役割: {user.role}</div>
            <div>権限: {user.permissions?.join(', ')}</div>
            <div>設定: {JSON.stringify(user.preferences)}</div>
          </div>
        ))}
      </div>

      {/* 設定情報 */}
      {Object.keys(data.settings).length > 0 && (
        <div style={{ marginTop: '20px' }}>
          <h3>設定情報</h3>
          <pre style={{ 
            backgroundColor: '#f5f5f5',
            padding: '10px',
            borderRadius: '4px',
            overflow: 'auto'
          }}>
            {JSON.stringify(data.settings, null, 2)}
          </pre>
        </div>
      )}
    </div>
  );
}
```

### メリット
- ✅ **構造化データ**: 複雑なネストしたデータに対応
- ✅ **型情報**: データ型の情報を保持
- ✅ **処理速度**: 高速なパースとシリアライズ
- ✅ **バリデーション**: スキーマベースの検証が可能
- ✅ **メタデータ**: 豊富なメタデータを保存可能

### デメリット
- ❌ **可読性**: 人間には読みにくい形式
- ❌ **ファイルサイズ**: 構造化のためサイズが大きくなる
- ❌ **互換性**: 一部のアプリケーションで対応不可
- ❌ **エディタ**: 専用のエディタが必要
- ❌ **エラー処理**: 構文エラーが発生しやすい

### 使用場面
- ⚙️ **設定データ**: アプリケーションの設定情報
- 🔌 **APIデータ**: REST APIのレスポンスデータ
- 📊 **分析データ**: 複雑な分析結果の保存
- 🎮 **ゲームデータ**: ゲームの状態やセーブデータ

## まとめ

| 実装方法 | 適用場面 | 主なメリット | 主なデメリット |
|---------|---------|-------------|---------------|
| **CSV形式** | シンプルな表データ | 実装が簡単、互換性が高い | 構造化データに不向き |
| **Excel形式** | 複雑な表データ | 構造化データ、複数シート | ファイルサイズが大きい |
| **JSON形式** | 構造化データ | 型情報保持、高速処理 | 可読性が低い |

### 選択の指針

1. **シンプルな表データ** → CSV形式
2. **複雑な表データ** → Excel形式
3. **構造化データ** → JSON形式
4. **複数の要件** → 組み合わせパターン
