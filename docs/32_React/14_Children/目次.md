# 14_Children 目次

`children` は「親が JSX で包んだ内容」が自動で渡される特別な prop。複数要素の列挙・変換・1件だけ許可するときなどに、`React.Children` や（必要なら）`cloneElement` を使います。

## 推奨順序

1. `14-1-childrenとは.md` — `children` の意味と受け渡しの基本
2. `14-2-React.Childrenユーティリティ.md` — `map` / `toArray` / `only` / `count` / `forEach`
3. `14-3-cloneElementと合成.md` — props の注入と合成、`isValidElement` のひとこと
4. `14-4-落とし穴と代替パターン.md` — Fragment・key、`cloneElement` の限界、設計での代替案

## メモ

- 現代の UI ライブラリでは、**名前付き props や Compound + Context** の方が追いやすいことが多い。`React.Children` は「親が渡した匿名の子リストを処理したい」ときに効くツールとして知っておくとよい。
