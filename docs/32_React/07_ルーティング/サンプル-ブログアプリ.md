# サンプル：ブログアプリ（React Router v6）

## 目的

- 一覧 → 詳細への遷移（`Link`）
- 動的ルート（`/posts/:id` と `useParams`）
- 最小限の画面構成（Home / Posts / Post Detail / About）

## コード例（1ファイルで最小構成）

```jsx
import { BrowserRouter, Routes, Route, Link, useParams } from 'react-router-dom';

function Home() {
  return (
    <div>
      <h1>ブログホーム</h1>
      <p>最新の記事一覧</p>
      <p>
        <Link to="/posts">記事一覧へ</Link>
      </p>
    </div>
  );
}

function PostList() {
  const posts = [
    { id: 1, title: 'React入門', excerpt: 'Reactの基本を学びましょう' },
    { id: 2, title: 'Hooksの使い方', excerpt: 'useStateとuseEffectについて' },
    { id: 3, title: 'ルーティング', excerpt: 'React Routerの基本' },
  ];

  return (
    <div>
      <h1>記事一覧</h1>
      <ul>
        {posts.map((post) => (
          <li key={post.id}>
            <Link to={`/posts/${post.id}`}>{post.title}</Link>
            <p>{post.excerpt}</p>
          </li>
        ))}
      </ul>
      <p>
        <Link to="/">ホームへ</Link>
      </p>
    </div>
  );
}

function PostDetail() {
  const { id } = useParams();

  return (
    <div>
      <h1>記事詳細</h1>
      <p>記事ID: {id}</p>
      <p>
        <Link to="/posts">記事一覧に戻る</Link>
      </p>
    </div>
  );
}

function About() {
  return (
    <div>
      <h1>このブログについて</h1>
      <p>Reactの学習記録を書いています</p>
      <p>
        <Link to="/">ホームへ</Link>
      </p>
    </div>
  );
}

function Navigation() {
  return (
    <nav>
      <Link to="/">ホーム</Link>{' | '}
      <Link to="/posts">記事一覧</Link>{' | '}
      <Link to="/about">このブログについて</Link>
    </nav>
  );
}

export default function App() {
  return (
    <BrowserRouter>
      <Navigation />
      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/posts" element={<PostList />} />
        <Route path="/posts/:id" element={<PostDetail />} />
        <Route path="/about" element={<About />} />
      </Routes>
    </BrowserRouter>
  );
}
```

## 練習問題（このサンプルの発展）

1. 記事一覧に「カテゴリ」フィルタを追加し、`?category=react` のようにURLに反映してください（`useSearchParams`）。
2. `posts/:id` の下にネストして `posts/:id/comments` を追加し、`<Outlet />` で切り替えてください。
3. 未ログインの場合、`/posts/:id` を `/login` にリダイレクトする保護ルートを作ってください。
