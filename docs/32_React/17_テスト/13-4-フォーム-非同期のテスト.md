# 13-4. フォーム/非同期のテスト

---

## 💻 フォーム入力のテスト

### 例：シンプルなフォーム

```tsx
import { render, screen } from '@testing-library/react';
import userEvent from '@testing-library/user-event';

it('入力して送信できる', async () => {
  const onSubmit = vi.fn();
  const user = userEvent.setup();

  render(<ContactForm onSubmit={onSubmit} />);

  await user.type(screen.getByLabelText('名前'), '太郎');
  await user.type(screen.getByLabelText('メール'), 'taro@example.com');
  await user.click(screen.getByRole('button', { name: '送信' }));

  expect(onSubmit).toHaveBeenCalledWith({
    name: '太郎',
    email: 'taro@example.com',
  });
});
```

## 💻 バリデーションのテスト

```tsx
it('空欄で送信するとエラー', async () => {
  const user = userEvent.setup();
  render(<ContactForm onSubmit={vi.fn()} />);

  await user.click(screen.getByRole('button', { name: '送信' }));

  expect(screen.getByText('名前は必須です')).toBeInTheDocument();
  expect(screen.getByText('メールは必須です')).toBeInTheDocument();
});

it('メール形式が違うとエラー', async () => {
  const user = userEvent.setup();
  render(<ContactForm onSubmit={vi.fn()} />);

  await user.type(screen.getByLabelText('メール'), 'invalid');
  await user.click(screen.getByRole('button', { name: '送信' }));

  expect(screen.getByText('メール形式が違います')).toBeInTheDocument();
});

it('入力するとエラーが消える', async () => {
  const user = userEvent.setup();
  render(<ContactForm onSubmit={vi.fn()} />);

  await user.click(screen.getByRole('button', { name: '送信' }));
  expect(screen.getByText('名前は必須です')).toBeInTheDocument();

  await user.type(screen.getByLabelText('名前'), '太郎');
  expect(screen.queryByText('名前は必須です')).not.toBeInTheDocument();
});
```

## 💻 チェックボックス・セレクト

it('チェックボックスを切り替える', async () => {
  const user = userEvent.setup();

});

## 💻 非同期処理のテスト

### ローディング → データ表示

```tsx
import { http, HttpResponse } from 'msw';

it('ユーザー一覧を読み込んで表示', async () => {
  render(<UserList />);

  // ローディング表示
  expect(screen.getByText('読込中...')).toBeInTheDocument();

  // データが表示される
  expect(await screen.findByText('太郎')).toBeInTheDocument();
  expect(screen.getByText('花子')).toBeInTheDocument();

  // ローディングが消える
  expect(screen.queryByText('読込中...')).not.toBeInTheDocument();
});
```

`findBy*` は**自動的にリトライ**してくれるので、非同期に強い。

### エラー表示

```tsx
it('API エラー時にメッセージ表示', async () => {
  server.use(
    http.get('/api/users', () => new HttpResponse(null, { status: 500 }))
  );

  render(<UserList />);

  expect(await screen.findByText(/エラー/)).toBeInTheDocument();
});
```

### 空状態

```tsx
it('ユーザーがいない時のメッセージ', async () => {
  server.use(
    http.get('/api/users', () => HttpResponse.json([]))
  );

  render(<UserList />);

  expect(await screen.findByText('ユーザーがいません')).toBeInTheDocument();
});
```

## 💻 フォーム送信（非同期）

```tsx
it('送信中はボタンが無効、成功でメッセージ', async () => {
  const user = userEvent.setup();
  render(<ContactForm />);

  await user.type(screen.getByLabelText('名前'), '太郎');
  await user.type(screen.getByLabelText('メール'), 'taro@example.com');

  const submitBtn = screen.getByRole('button', { name: '送信' });
  await user.click(submitBtn);

  // 送信中：ボタンが disabled、テキストが変わる
  expect(submitBtn).toBeDisabled();
  expect(submitBtn).toHaveTextContent('送信中...');

  // 完了
  expect(await screen.findByText('送信完了！')).toBeInTheDocument();
});
```

### 二重送信防止

```tsx
it('連打しても1回しか送信されない', async () => {
  let count = 0;
  server.use(
    http.post('/api/contact', () => {
      count++;
      return HttpResponse.json({ ok: true });
    })
  );

  const user = userEvent.setup();
  render(<ContactForm />);

  // クリック連打
  const btn = screen.getByRole('button', { name: '送信' });
  await user.tripleClick(btn);

  await screen.findByText('送信完了');
  expect(count).toBe(1);
});
```

## 💻 waitFor で待つ

`findBy` で取れない場合：

```tsx
import { waitFor } from '@testing-library/react';

await waitFor(() => {
  expect(mockApi).toHaveBeenCalledTimes(1);
});

// タイムアウト調整
await waitFor(() => expect(...), { timeout: 3000 });
```

## 💻 React Hook Form のテスト

```tsx
it('zod バリデーションで送信', async () => {
  const onSubmit = vi.fn();
  const user = userEvent.setup();

  render(<HookForm onSubmit={onSubmit} />);

  await user.type(screen.getByLabelText('メール'), 'taro@example.com');
  await user.type(screen.getByLabelText('パスワード'), 'password123');
  await user.click(screen.getByRole('button', { name: 'ログイン' }));

  // useForm の handleSubmit は非同期
  await waitFor(() => {
    expect(onSubmit).toHaveBeenCalledTimes(1);
  });
});
```

## ❌ よくある間違い

### `act` 警告

```ts
Warning: An update to ... inside a test was not wrapped in act(...)
```

→ `await user.*` または `findBy` を使うと自動でactが入る。

### 同期で待つ

```ts
const result = api.fetchUser(); // Promiseのまま
expect(result.name).toBe('太郎'); // ❌
```

→ ✅ `await api.fetchUser()`。

### sleep で待つ

```ts
await new Promise((r) => setTimeout(r, 1000));
expect(...);
```

→ ✅ `findBy` か `waitFor`。

### MSW ハンドラのスコープ漏れ

→ `afterEach(() => server.resetHandlers())` で都度リセット。

---

## ✅ ベストプラクティス

1. **findBy / waitFor** で非同期を扱う
2. **入力 → 操作 → 検証** の流れ
3. **MSWで API モック**
4. **エラー・空状態も忘れずに**
5. **送信中のUIもテスト**
