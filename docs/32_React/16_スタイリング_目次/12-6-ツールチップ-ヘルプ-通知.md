# 12-6. ツールチップ/ヘルプ/通知（アクセシブルな実装）

## 🎯 この章で学ぶこと

- ツールチップの実装と落とし穴
- ヘルプテキストのバリエーション
- 通知（トースト）のアクセシブル実装

---

## 📖 各UIの違い

| UI | 表示 | 用途 |
| --- | --- | --- |
| **Tooltip** | hover/focusで一時表示 | 短い補足、アイコン説明 |
| **Helper Text** | 常時表示（小さめ） | フォームの注意 |
| **Popover** | クリックで開く | 詳しい説明、メニュー |
| **Toast** | 一時的に画面端 | 操作の結果通知 |

## 💻 ① ツールチップ

### 最小実装

```jsx
function Tooltip({ text, children }) {
  const [show, setShow] = useState(false);

  return (
    <span style={{ position: 'relative' }}
          onMouseEnter={() => setShow(true)}
          onMouseLeave={() => setShow(false)}
          onFocus={() => setShow(true)}
          onBlur={() => setShow(false)}>
      {children}
      {show && (
        <span role="tooltip" style={{
          position: 'absolute',
          bottom: '100%',
          left: '50%',
          transform: 'translateX(-50%)',
          padding: '4px 8px',
          background: '#333',
          color: 'white',
          borderRadius: 4,
          whiteSpace: 'nowrap',
        }}>
          {text}
        </span>
      )}
    </span>
  );
}

// 使う
<Tooltip text="保存します">
  <button>💾</button>
</Tooltip>
```

ポイント：

- `onFocus/onBlur` も対応（キーボード）
- `role="tooltip"` でアクセシビリティ

### `aria-describedby` で関連付け

```jsx
<button aria-describedby="tip-1">
  <Icon />
</button>
<span id="tip-1" role="tooltip" hidden={!show}>
  保存します
</span>
```

→ スクリーンリーダーがボタン読み上げのあと「保存します」も読む。

### Radix UI / Floating UI を使う

ツールチップは位置計算（画面端で逆向きに出す等）が複雑。**Radix UIや Floating UI** を使うのが楽：

```jsx
import * as Tooltip from '@radix-ui/react-tooltip';

<Tooltip.Provider>
  <Tooltip.Root>
    <Tooltip.Trigger asChild>
      <button><Icon /></button>
    </Tooltip.Trigger>
    <Tooltip.Content>保存します</Tooltip.Content>
  </Tooltip.Root>
</Tooltip.Provider>
```

## 💻 ③ Popover（詳しい説明）

```jsx
import { useState, useRef } from 'react';

function HelpPopover({ children }) {
  const [open, setOpen] = useState(false);
  const ref = useRef(null);

  // 外側クリックで閉じる
  useEffect(() => {
    function handler(e) {
      if (ref.current && !ref.current.contains(e.target)) setOpen(false);
    }
    document.addEventListener('mousedown', handler);
    return () => document.removeEventListener('mousedown', handler);
  }, []);

  return (
    <div ref={ref} style={{ position: 'relative' }}>
      <button onClick={() => setOpen(!open)} aria-expanded={open}>?</button>
      {open && (
        <div role="dialog" style={{ position: 'absolute', ... }}>
          {children}
        </div>
      )}
    </div>
  );
}
```

→ 複雑なら Radix UI の `<Popover>` 推奨。

## 💻 ④ トースト通知

### 最小実装

```jsx
function Toast({ message, type = 'info', onClose }) {
  useEffect(() => {
    const id = setTimeout(onClose, 3000);
    return () => clearTimeout(id);
  }, [onClose]);

  return (
    <div role="status" aria-live="polite" className={`toast toast-${type}`}>
      {message}
    </div>
  );
}

function App() {
  const [toasts, setToasts] = useState([]);

  function show(message, type = 'info') {
    const id = Date.now();
    setToasts((prev) => [...prev, { id, message, type }]);
  }

  function remove(id) {
    setToasts((prev) => prev.filter((t) => t.id !== id));
  }

  return (
    <>
      <button onClick={() => show('保存しました', 'success')}>保存</button>
      <div className="toast-container">
        {toasts.map((t) => (
          <Toast key={t.id} {...t} onClose={() => remove(t.id)} />
        ))}
      </div>
    </>
  );
}
```

### アクセシビリティ

| 属性 | 用途 |
| --- | --- |
| `role="status"` | 普通の通知 |
| `role="alert"` | 緊急（即読み上げ） |
| `aria-live="polite"` | 邪魔せず通知 |
| `aria-live="assertive"` | 即座に通知 |

### ライブラリ

- **react-hot-toast**：シンプル
- **sonner**：モダン、Vercel製
- **react-toastify**：機能豊富

```jsx
import toast from 'react-hot-toast';

toast.success('保存しました');
toast.error('エラーが発生しました');
```

## ❌ よくある間違い

### ツールチップに長文・操作

→ ホバーで消えるので**短文・読み専用**だけ。長いなら Popover に。

### キーボードで開けないツールチップ

→ ✅ `onFocus/onBlur` も対応。

### トーストが多すぎる

→ 上限（5件）を設ける、重要な操作だけ通知。

### `role="alert"` を全トーストに

→ 緊急じゃないものまで読み上げて邪魔。`role="status"` に。

### z-indexが他のUIより低い

→ モーダルより上に出す（z-index大きく）。

---

## ✅ ベストプラクティス

1. **ツールチップは短文+focus対応**
2. **ヘルプは aria-describedby**
3. **Popover には Radix UI**
4. **トーストは上限+`aria-live`**
5. **緊急度で `role` を使い分け**

## 📝 まとめ

- ツールチップ：短文、focus対応、role="tooltip"
- ヘルプ：常時表示、aria-describedby
- Popover：複雑な説明、外側クリック対応
- トースト：role="status" + aria-live、上限あり
