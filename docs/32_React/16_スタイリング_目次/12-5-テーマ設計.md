# 12-5. テーマ設計（カスタマイズしやすい設計）

## 🎯 この章で学ぶこと

- デザイントークンとは何か
- CSS変数でテーマ切替する仕組み
- Tailwind / CSS-in-JS でのテーマ実装

---

## 📖 デザイントークンとは

「**色・サイズ・スペース・フォント**」など、デザインの**最小単位の値**に名前を付けたもの。

例：

```text
color.primary      = #007bff
spacing.medium     = 16px
font.size.heading  = 24px
border.radius.lg   = 12px
```

→ これらを**全アプリで共有**することで、デザインの一貫性が出る。

---

## 💻 ① CSS 変数（カスタムプロパティ）

```css
:root {
  --color-primary: #007bff;
  --color-bg: #ffffff;
  --color-text: #1a1a1a;
  --spacing-md: 16px;
  --radius-lg: 12px;
}

[data-theme='dark'] {
  --color-bg: #1a1a1a;
  --color-text: #f0f0f0;
}

.button {
  background: var(--color-primary);
  padding: var(--spacing-md);
  border-radius: var(--radius-lg);
}
```

```jsx
<html data-theme="dark">
```

→ 同じCSSで色だけ切り替わる。

---

## 💻 ② Tailwind config でテーマ

```js
// tailwind.config.js
module.exports = {
  theme: {
    extend: {
      colors: {
        primary: {
          50: '#eff6ff',
          500: '#3b82f6',
          900: '#1e3a8a',
        },
        accent: '#f97316',
      },
      spacing: {
        '128': '32rem',
      },
      borderRadius: {
        '4xl': '2rem',
      },
    },
  },
};
```

```jsx
<button className="bg-primary-500 text-white px-spacing-md rounded-4xl">
  ...
</button>
```

→ デザイントークンが Tailwind の class名に直結。

### CSS変数 + Tailwind（柔軟）

```js
// tailwind.config.js
module.exports = {
  theme: {
    extend: {
      colors: {
        primary: 'rgb(var(--color-primary) / <alpha-value>)',
        bg: 'rgb(var(--color-bg) / <alpha-value>)',
      },
    },
  },
};
```

```css
:root {
  --color-primary: 0 123 255;
  --color-bg: 255 255 255;
}
.dark {
  --color-bg: 26 26 26;
}
```

→ CSS変数で**動的に切り替え**可能。

---

## 💻 ③ ThemeProvider（CSS-in-JS）

```jsx
import { ThemeProvider } from 'styled-components';

const lightTheme = {
  colors: { primary: '#007bff', bg: '#fff' },
  spacing: { sm: 8, md: 16 },
};

const darkTheme = {
  colors: { primary: '#3b82f6', bg: '#1a1a1a' },
  spacing: { sm: 8, md: 16 },
};

function App() {
  const [theme, setTheme] = useState('light');
  return (
    <ThemeProvider theme={theme === 'light' ? lightTheme : darkTheme}>
      <Layout />
    </ThemeProvider>
  );
}
```

```jsx
const Button = styled.button`
  background: ${(props) => props.theme.colors.primary};
  padding: ${(props) => props.theme.spacing.md}px;
`;
```

---

## 💡 Tokens を type-safe に

```ts
// theme.ts
export const theme = {
  colors: {
    primary: '#007bff',
    secondary: '#6c757d',
  },
  spacing: {
    sm: 8,
    md: 16,
    lg: 24,
  },
} as const;

export type Theme = typeof theme;
```

→ `theme.colors.primary` のtypoが型でエラーに。

## 💻 ブランドカラー切替（マルチテナント）

```css
[data-brand='blue'] { --color-primary: #007bff; }
[data-brand='red'] { --color-primary: #dc3545; }
[data-brand='green'] { --color-primary: #28a745; }
```

→ ブランドごとに同じUIを違う色で展開できる。

---

## ❌ よくある間違い

### 色をハードコード

```jsx
<button style={{ background: '#007bff' }}>
```

→ ✅ デザイントークンで管理。

### Tailwindのデフォルト色を使い続ける

```jsx
<button className="bg-blue-500">
```

→ ブランドの primary に名前を付ける（`bg-primary`）。

### テーマ切替時に再レンダーが過剰

→ ContextをアプリTOPに置く。子は className で切替。

### Token を文字列で散らばす

→ JS の constオブジェクトか、CSS変数で一元化。
