# 12-3. レスポンシブ・ダークモード（基本）

## 🎯 この章で学ぶこと

- メディアクエリでレスポンシブ対応する基礎
- ダークモードの実装パターン
- ユーザー設定の保存（localStorage）

---

## 📖 レスポンシブとは

画面サイズによって**レイアウトを切り替える**こと。

主なブレイクポイント（Tailwind）：

| 名前 | サイズ |
| --- | --- |
| sm | 640px〜 |
| md | 768px〜 |
| lg | 1024px〜 |
| xl | 1280px〜 |
| 2xl | 1536px〜 |

---

## 💻 CSS でのレスポンシブ

```css
.container {
  padding: 8px;
}

@media (min-width: 768px) {
  .container { padding: 16px; }
}

@media (min-width: 1024px) {
  .container { padding: 24px; }
}
```

「**モバイルファースト**」が現代の主流：小さい画面の指定 → 大きい画面で上書き。

---

## 💻 Tailwind のレスポンシブ

```jsx
<div className="p-2 md:p-4 lg:p-6">
  {/* mobile: 8px、md以上: 16px、lg以上: 24px */}
</div>

<div className="flex flex-col md:flex-row">
  {/* モバイルは縦、デスクトップは横並び */}
</div>

<div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3">
  {/* 画面サイズで列数 */}
</div>
```

接頭辞で簡潔に。

## 💻 useMediaQuery（JS側で判定）

```ts
function useMediaQuery(query) {
  const [matches, setMatches] = useState(() => window.matchMedia(query).matches);
  useEffect(() => {
    const mql = window.matchMedia(query);
    const handler = (e) => setMatches(e.matches);
    mql.addEventListener('change', handler);
    return () => mql.removeEventListener('change', handler);
  }, [query]);
  return matches;
}

// 使う
const isMobile = useMediaQuery('(max-width: 767px)');
return isMobile ? <MobileMenu /> : <DesktopMenu />;
```

→ JS側で出し分けたいとき。CSS で表示制御の方が軽いことも多い。

## 🌙 ダークモード

### 実装の3ステップ

1. **state でモードを保持**（'light' / 'dark'）
2. **<html> や <body> にクラスを付ける**
3. **CSS でクラスごとに色を切替**

### 実装例：Context + localStorage

```jsx
// ThemeContext.jsx
const ThemeContext = createContext();

function ThemeProvider({ children }) {
  const [theme, setTheme] = useState(() => {
    return localStorage.getItem('theme') ?? 'light';
  });

  useEffect(() => {
    document.documentElement.classList.toggle('dark', theme === 'dark');
    localStorage.setItem('theme', theme);
  }, [theme]);

  const toggle = () => setTheme((t) => t === 'light' ? 'dark' : 'light');

  return (
    <ThemeContext.Provider value={{ theme, toggle }}>
      {children}
    </ThemeContext.Provider>
  );
}

function useTheme() {
  return useContext(ThemeContext);
}
```

### 利用

```jsx
function ThemeToggle() {
  const { theme, toggle } = useTheme();
  return <button onClick={toggle}>{theme === 'light' ? '🌙' : '☀️'}</button>;
}
```

## 💻 Tailwind のダークモード

```js
// tailwind.config.js
module.exports = {
  darkMode: 'class', // 'class' or 'media'
};
```

```jsx
<div className="bg-white dark:bg-gray-900 text-black dark:text-white">
  ...
</div>
```

`<html class="dark">` のときだけ `dark:` の class が効く。

## 💻 OS設定に追従（自動）

```jsx
const prefersDark = useMediaQuery('(prefers-color-scheme: dark)');
const [theme, setTheme] = useState(prefersDark ? 'dark' : 'light');
```

```css
@media (prefers-color-scheme: dark) {
  body { background: #222; color: #fff; }
}
```

→ ユーザーのOS設定をそのまま反映。

### 完成形：OS設定 + ユーザー設定上書き

```ts
function getInitialTheme() {
  const saved = localStorage.getItem('theme');
  if (saved) return saved;
  if (window.matchMedia('(prefers-color-scheme: dark)').matches) return 'dark';
  return 'light';
}

const [theme, setTheme] = useState(getInitialTheme);
```

## 💻 FOUC（一瞬白くなる）対策

ダークモードでページを開くと、JSが動く前は light のままで一瞬白くなる。

```html
<!-- index.html の head に -->
<script>
  const saved = localStorage.getItem('theme');
  if (saved === 'dark' || (!saved && window.matchMedia('(prefers-color-scheme: dark)').matches)) {
    document.documentElement.classList.add('dark');
  }
</script>
```

JS実行を待たずにclass付与。

## ❌ よくある間違い

### レスポンシブで `display: none` 多用

→ アクセシビリティ・SEOで不利。**hidden md:block** など要件に合わせて。

### モバイルファーストでなく逆

```css
.container { padding: 24px; }
@media (max-width: 767px) { .container { padding: 8px; } }
```

→ ✅ モバイルファースト：

```css
.container { padding: 8px; }
@media (min-width: 768px) { .container { padding: 24px; } }
```

### ダークモード切替時にちらつく

→ 上記 FOUC 対策。

### 色を直書き

```jsx
<div style={{ background: '#fff' }}>
```

→ ✅ Tailwindなら `bg-white dark:bg-gray-900`、CSS変数で。

---

## ✅ ベストプラクティス

1. **モバイルファースト**で書く
2. **Tailwind の `md:` `lg:`** で簡潔に
3. **ダークモードは class方式**（手動切替も可能）
4. **OS設定を初期値**にする
5. **FOUC対策スクリプト**を入れる

---

## 🔬 実践演習

`ThemeProvider` + ヘッダーにトグルボタン：

- モバイル：縦並び
- デスクトップ：横並び
- ダークモード切替（localStorage保存）
- OS設定に追従

---

## 📝 まとめ

- レスポンシブはモバイルファースト + ブレイクポイント
- ダークモードは class方式 が柔軟
- OS設定 + ユーザー設定の組み合わせ
- FOUC対策を忘れない
