# 型ガードの書き方

## 型ガードとは？

実行時のチェックで、**TypeScript に「この値はこの型だよ」と教える** しくみです。
値の絞り込み（narrowing）が起こり、その分岐内では狭い型として扱えます。

## 組み込みの型ガード

### typeof

```typescript
function format(v: string | number) {
  if (typeof v === "string") {
    v.toUpperCase(); // string と確定
  } else {
    v.toFixed(2);    // number と確定
  }
}
```

プリミティブには `typeof` が一番シンプルで強力。

### instanceof

クラスのインスタンス判定。

```typescript
function describe(e: Error | string) {
  if (e instanceof Error) {
    console.log(e.message);
  } else {
    console.log(e);
  }
}
```

### in 演算子

オブジェクトの **プロパティの有無** で分岐。

```typescript
type Cat = { meow: () => void };
type Dog = { bark: () => void };

function speak(a: Cat | Dog) {
  if ("meow" in a) {
    a.meow();
  } else {
    a.bark();
  }
}
```

判別子なしのユニオンで重宝します。

### 等価チェック（リテラルとの比較）

```typescript
function area(s: { kind: "circle" } | { kind: "square" }) {
  if (s.kind === "circle") {
    // s は { kind: "circle" } 型
  }
}
```

→ 判別可能ユニオンとセットで使う鉄板パターン（→ `discriminated_union.md`）。

## ユーザー定義型ガード（`x is T`）

組み込みでは判定できないとき、自分で型ガード関数を書けます。

```typescript
type User = { id: number; name: string };

function isUser(v: unknown): v is User {
  return (
    typeof v === "object" &&
    v !== null &&
    "id" in v && typeof (v as any).id === "number" &&
    "name" in v && typeof (v as any).name === "string"
  );
}

const data: unknown = JSON.parse(text);

if (isUser(data)) {
  data.name; // OK：User と確定
}
```

戻り値の型を `v is User` と書くのがキモ。中で `true` を返した経路では、`v` が `User` として扱われます。

## アサーション関数（`asserts x is T`）

「**この時点で T でなければ throw する**」と宣言できる関数です。

```typescript
function assertIsUser(v: unknown): asserts v is User {
  if (!isUser(v)) throw new Error("not a user");
}

const data: unknown = JSON.parse(text);
assertIsUser(data);
data.name; // ここから先は User として使える
```

ガード関数と違って **`if` で囲まなくてもよい** のが特徴です。
ただし、戻り値で扱えないので「処理中で確定してしまう」効果。

## NonNullable な絞り込み

```typescript
function isDefined<T>(v: T | null | undefined): v is T {
  return v !== null && v !== undefined;
}

const items = [1, null, 2, undefined, 3];
const filtered = items.filter(isDefined);
// filtered: number[]
```

`Array.prototype.filter` と組み合わせる定石。型ガードを書くと **filter の戻り型が綺麗** になります。

## Zod / valibot などの活用

複雑なオブジェクトの検証は **ライブラリに任せる**のが一番安全です（→ `zod等との組み合わせ.md`）。

```typescript
import { z } from "zod";

const UserSchema = z.object({ id: z.number(), name: z.string() });
type User = z.infer<typeof UserSchema>;

function isUser(v: unknown): v is User {
  return UserSchema.safeParse(v).success;
}
```

## まとめ

- 型ガードは **実行時チェック → 型の絞り込み** を結びつける
- 組み込み：`typeof` / `instanceof` / `in` / 等価比較
- `v is T` でユーザー定義型ガードを作れる
- `asserts v is T` で「失敗なら throw」のスタイルも
- 複雑な検証は **Zod 等のライブラリ** が安全で楽
- 「外から来たデータ」は型ガード or バリデーションで必ず守る
