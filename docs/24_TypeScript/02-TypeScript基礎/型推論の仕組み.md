# 型推論の仕組み

## 型推論とは？

**型推論（type inference）**とは、型注釈を書かなくても TypeScript が「文脈から型を自動的に決めてくれる」しくみです。

```typescript
let count = 10;        // number と推論される
let name = "Alice";    // string と推論される
let flag = true;       // boolean と推論される
```

明示的に型を書く必要はありません。**書きすぎないこと**が、読みやすい TypeScript の第一歩です。

## 推論が働くおもな場面

### 1. 変数の初期化

```typescript
let x = 1;        // number
const y = 1;      // 1（リテラル型に推論されることもある）
let arr = [1, 2]; // number[]
```

`let` と `const` で結果が変わることに注意。`const` で宣言したプリミティブは「リテラル型」として推論されます。

```typescript
const greeting = "hello"; // 型は "hello"（string ではない）
let greeting2 = "hello";  // 型は string
```

### 2. 関数の戻り値

```typescript
// 戻り値の型注釈がなくても OK
function add(a: number, b: number) {
  return a + b; // 戻り値は number と推論
}
```

関数の **引数** には型注釈が必要ですが、戻り値は推論にまかせるのが一般的です。
ただし、公開 API や複雑な処理では明示したほうが安全です。

### 3. 文脈による推論（Contextual Typing）

「使われる場所」から型が決まることもあります。

```typescript
const numbers = [1, 2, 3];
numbers.forEach(n => {
  // n は number と推論される（forEach のシグネチャから）
  console.log(n.toFixed(2));
});
```

引数 `n` に型注釈を書かなくても、`forEach` の定義から `number` だと判明します。

## 推論される型を確認する方法

VS Code などのエディタで変数にホバーすると、推論された型が表示されます。
コード上で確認したいときは、ユーティリティ型のように調べる方法もあります。

```typescript
const user = { name: "Alice", age: 25 };
type User = typeof user;
// type User = { name: string; age: number }
```

`typeof` 演算子（型の文脈での `typeof`）で「変数の型」を取り出せます。

## ベストエスティメート（最適な推論）

複数の値が混ざる配列では、TypeScript は **「全体に当てはまる型」**を計算します。

```typescript
const mixed = [1, "hello", true]; // (string | number | boolean)[]
```

ただし、必ずしも望み通りに広がるわけではありません。

```typescript
const items = ["a", null]; // (string | null)[]
const items2 = [{ a: 1 }, { b: 2 }]; // ({ a: number; b?: undefined } | { ... })[]
```

意図と違うときは型注釈を明示しましょう。

## 型の「広がり」と「絞り込み」

### Widening（型の拡大）

`let` で宣言すると、リテラル型は広いプリミティブ型に「拡大」されます。

```typescript
let s = "hello"; // string（"hello" ではない）
```

これは後で再代入したいだろう、という気遣いです。

### Narrowing（絞り込み）

`if` などで条件分岐すると、TypeScript は型を「絞り込み」ます。

```typescript
function print(value: string | number) {
  if (typeof value === "string") {
    value.toUpperCase(); // ここでは string と確定
  } else {
    value.toFixed(2);    // ここでは number と確定
  }
}
```

絞り込みは型推論の中でもとくに強力で、`typeof` / `instanceof` / `in` / 等価チェックなどで動きます。

## 型注釈を書くべき場面

推論にまかせるのが基本ですが、次のときは明示的に書きましょう。

- **関数の引数**：呼び出し側からは推論できない
- **公開 API・export する関数の戻り値**：意図しない型変化を防ぐ
- **空の配列・オブジェクト**：`let arr = []` は `any[]` になってしまう
- **値が複雑で意図と違う型に推論される**ときの保険

```typescript
const items: string[] = []; // 注釈なしだと any[]
```

## まとめ

- TypeScript は宣言・代入・呼び出し文脈から型を推論する
- `const` はリテラル型に、`let` は広い型に推論される
- ホバーや `typeof x` で推論結果を確認できる
- 引数や export 関数の戻り値など、推論できない/危険な箇所は明示する
- 推論を信頼することで、見やすく壊れにくいコードになる
