## 補足

- 上記の **番号付き章フォルダ**（`04-関数` 〜 `14-型レベルプログラミング` など）と、**ルート直下の単独 `.md`**（英語名・日本語名が混在）が併存しています。
- ルートには **旧系の連番ファイル**（`01-basics.md` … `10-utility-types.md` など）と、**新系の日本語章立て**（`01-型注釈と型推論.md` 配下のサブフォルダ群）の両方があります。

## 未フォルダ（ルート直下）の推奨配置

サブフォルダに入っていない `.md` を、**目次**（[目次](010Programming/目次.md)）の章立てと既存フォルダ名に揃えて置く場合の目安。実際に移すときは **同名・同テーマの既存稿との統合**（マージ or 片方にリダイレクト用リンク）を忘れないこと。

### ルートのままがよいもの（庫内索引・メタ）

| ファイル | 理由 |
|----------|------|
| `目次.md` | 全体の目次。 |
| `00-フォルダ・ファイル構成.md` | 本ノート。 |

### 専用フォルダがまだない章（新設するなら）とその中身

| 新設フォルダ案（目次の節名に対応） | 移すとよいルート上のファイル |
|----------------------------------|------------------------------|
| **`01-環境と導入`** など | `01-basics.md`（導入）, `02-setup.md`（環境・フロー） |
| **`02-超入門`** など | `01-型注釈と型推論.md`, `型推論の仕組み.md`, `02-anyを避ける理由と最小限の逃げ道.md`, `03-unknownと安全な取り扱い.md`, `04-neverの意味.md`, `05-リテラル型とas-const.md`, `06-型アサーションとas-constの違い.md`, `04-TypeScriptの型.md`（型的な全体像）, `型と値の混同.md`, `any_unknown_never.md`, `any禁止の是非.md`, `オプショナルチェーンとnullish合体.md`（演算子と null 系の扱い） |
| **`15-宣言ファイル`**（目次 §15 向け。単一稿なら `12-tsconfig` 直下に置く選択も可） | `宣言ファイル_d_ts_の書き方.md` |

`02-ユーティリティ型/`（古い下位フォルダ名）は、内容が **`10-ユーティリティ型/`** と重複しやすい。整理時は `10-ユーティリティ型/` へ集約し、**重複稿は1本に寄せる**のが安全。

### 重複しやすいポイント（整理のとき）

- **`02-ユーティリティ型/` と `10-ユーティリティ型/`**、**`02-超入門` 案内の6本** と `06-narrowing` / `12-tsconfig` 近辺: 同タイトル・同小見出しが二重登録されないよう、**正本を1つ決める**とよい。
- **ルートの短い英語名**（`条件型.md`, `infer.md` 等）と **`14-型レベルプログラミング/01-04`** は、内容が同じなら **一方に統合**が望ましい。
