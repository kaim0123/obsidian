## 10. 逆引き（困ったらここ）

- **レイアウトが崩れる**: ボックスモデル → Flex/Grid → overflow の順で疑う
- **レスポンシブが破綻する**: 文字/画像/最小幅/改行（line-break）を先に見る
- **なぜ効かない？**: セレクタ/優先順位/継承/読み込み順のどれか
