## 詳しい要約

**テーマ：映像編集の技法をWebページの演出（主にスクロール連動アニメーション）に置き換える**

パララックス、マッチカット、フリーズフレームなどの動画の演出技法25種と、動画以外のWeb独自の演出12種について、「動画での意味 → Webでの具体的なシーン（架空のカフェ・スニーカー・SaaSなど）→ 実装のヒント」の形で整理したノート。各技法には「個性」の強さを星で付けている。最後に1ページの流れとしての組み合わせ例と、演出の使いすぎへの注意をまとめている。

---

### 共通の道具と注意点

- **スクロール連動**：GSAPのScrollTrigger、またはCSSのScroll-driven Animations（`animation-timeline: scroll()` / `view()`）。
- **慣性スクロール**：Lenisで動画のような「間」を作りやすくする。
- **動かすのは `transform` と `opacity` だけ**にするとカクつきにくい（`top` / `left` / `width` はレイアウトのやり直しが起きる）。
- 動きが苦手な人向けに `prefers-reduced-motion: reduce` で演出を弱める。

### 基本の動画技法12種

| 技法 | Webでの例 | 実装の要点 |
|---|---|---|
| **パララックス** | 背景0.3倍・見出し1倍・手前1.5倍で奥行きを出す | レイヤーごとに `translateY` の係数を変える |
| **スピードランプ** | 商品が中央に来た瞬間だけ極端に遅くなり説明を出す | 速い・遅い・速い区間をタイムラインに並べ `scrub` |
| **マッチカット** | コーヒー豆の輪郭がそのまま地球に変形 | SVGパスのモーフィング、`clip-path` |
| **モンタージュ** | 0.3秒ごとに写真を切り替えてロゴで止める | `opacity` の `@keyframes`、画像の事前読み込み |
| **キネティックタイポグラフィ** | 文字が巨大化し、穴を抜けて次のセクションへ | 1文字ずつ `<span>` に分割、`scale` で拡大 |
| **モーションブラー** | カルーセルが動いている間だけブレる | `filter: blur()`、横ブレはSVG `feGaussianBlur` |
| **フリーズフレーム** | 着地の瞬間で動画を止め、説明を展開 | `video.currentTime` 操作、`pin` で固定 |
| **グリッチ** | 見出しが0.2秒だけずれて色分解 | `::before` / `::after` と `clip-path`、点滅は1秒3回以下 |
| **Whip Pan** | 横にビュンと流れて次の行き先へ | `translateX` ＋移動中だけブラー、急加速・急停止 |
| **ロール** | 商品を回転させて面ごとに説明 | Three.js / `<model-viewer>` / 連番画像、`rotateY` |
| **L/Jカット的演出** | 次のセクションを先に見せる、前の見出しを残す | セクションを重ね、開始位置を前倒し |
| **音ハメ** | ビートに合わせて背景や歌詞を切り替える | Web Audio API、自動再生は止められるのでユーザー操作で鳴らす |

### 追加の動画技法13種

- **ドリーズーム**：人物の大きさはそのままで背景だけ伸びる（前景固定・背景を `scale`、Three.jsならカメラ後退＋`fov` を狭める）。
- **ラックフォーカス**：手前と奥の `blur` を逆向きに変化させて視線を誘導。
- **ケン・バーンズ**：静止画を6〜10秒かけてゆっくりズーム・パン。軽くて効果が大きい。
- **アイリス／ワイプ**：`clip-path: circle()` で円が広がる切り替え、ページ遷移はView Transitions APIと組み合わせる。
- **スプリットスクリーン**：ビフォー・アフターの比較スライダー（`clip-path: inset()`）。
- **ワンカット長回し**：Three.jsでカメラ経路をスクロールに結びつけ、家の中を歩くように見せる。
- **クラッシュズーム**：0.2秒程度で `scale` を一気に上げ、最後に小さく揺らす。
- **ジャンプカット**：同じ構図で服だけを瞬時に切り替える。アニメーションをつけないことが演出。
- **タイムラプス**：更地からビルが建つ、窓の外が朝から夜へ変わる（連番画像を `<canvas>`、CSS変数で空の色）。
- **アスペクト比の変化**：上下の黒帯が閉じて映画モードに（`height` ではなく `scaleY`）。
- **カラーグレーディング**：沿革ページで時代ごとにセピアから鮮やかなフルカラーへ（`filter: sepia() saturate()`）。
- **ストップモーション**：`steps(8)` でコマ送り風の手作り感。
- **巻き戻し**：割れたグラスが戻っていく。結果を先に見せ、スクロールで原因に遡る構成にする。

### 動画以外の演出12種

- **カスタムカーソル**（「VIEW」「PLAY」「DRAG」に変わる）、**マグネティックボタン**（距離の30%程度だけ吸い寄せる）。
- **読み進めるとハイライト**（カラオケのように行ごとに濃くなる）、**積み重なるカード**（`position: sticky` で基本形）。
- **画像の歪み（WebGL）**：シェーダーで水面のように揺らす。インパクトは大きいが最も作るのが難しい部類。
- **物理演算**（Matter.jsで要素が落ちて積み重なる404ページ）、**スクラッチ**（`destination-out` で削る）。
- **時間帯で変わるページ**、**タブのタイトル演出**（`visibilitychange`、やりすぎ注意）、**目で追うキャラクター**（`Math.atan2`）。
- **隠しコマンド**（コナミコマンドなど、SNSで話したくなる）、**数字のカウントアップ**（定番で個性は弱いが組み合わせると効く）。

### 組み合わせ例と注意

- 架空のスニーカー特設ページで、モンタージュ → キネティックタイポグラフィ → パララックス → ロール＋スピードランプ → フリーズフレーム → Whip Pan → グリッチと購入ボタン、という流れを提示。
- 1ページに全部入れると疲れる。「ここだけは見てほしい」箇所に1〜2個の強い演出を置き、残りは控えめにするのが基本。

### まとめ

- 映像の技法は、「スクロール量を時間軸として扱う」ことでWebの演出に置き換えられる。
- 実装の中心はGSAP ScrollTriggerやCSSのScroll-driven Animationsで、`transform` と `opacity` を動かすのが軽さのコツ。
- 演出は見せたい一点に絞り、`prefers-reduced-motion` や点滅回数などアクセシビリティにも配慮する。

## 具体例で見る

各技法を「動画での意味 → Webでの具体的なシーン → 実装のヒント」で整理する。例はすべて架空のサイト（カフェ、スニーカー、SaaS など）を想定したもの。

> [!tip] 共通の道具
> - **スクロール連動**：GSAP の ScrollTrigger、または CSS の `animation-timeline: scroll()` / `view()`（Scroll-driven Animations）
> - **慣性スクロール**：Lenis（スクロールを滑らかにして、動画っぽい「間」を作りやすくする）
> - **動かすのは `transform` と `opacity` だけ**にするとカクつきにくい（`top` / `left` / `width` を動かすとレイアウトのやり直しが起きる）
> - 動きが苦手な人向けに `@media (prefers-reduced-motion: reduce)` で演出を弱める

---

### 1. パララックス

**動画での意味**：手前のものは速く、奥のものはゆっくり流れて見える（車窓の景色）。奥行きが出る。

**Webでの具体例**：カフェのトップページ
- 一番奥：山と空の写真 → スクロールの **0.3 倍** の速さでしか動かない
- 真ん中：「朝の一杯を、山の上で。」という見出し → **1 倍**（普通に流れる）
- 手前：湯気の立つカップの切り抜き画像 → **1.5 倍** で速く上へ抜けていく
- → 平面のページなのに「カップの向こうに山がある」ように見える

**実装のヒント**：各レイヤーに `translateY(スクロール量 × 係数)`。GSAP なら `yPercent` を `scrub: true` で動かす。

---

### 2. スピードランプ

**動画での意味**：同じカットの中で、普通の速さ → 急にスロー → また速く、と速度を変える（スポーツのダンクシュートの瞬間だけスローなど）。

**Webでの具体例**：スニーカーの商品ページ
- スクロールすると、靴が画面の右から左へ横切る
- 画面の中央に来た瞬間だけ**動きが極端に遅くなる**（スクロールしてもほとんど進まない）→ その間にソールの素材説明が表示される
- 中央を過ぎると一気に加速して画面外へ消える
- → 「ここを見てほしい」という一点にだけ時間が止まったように感じる

**実装のヒント**：スクロール量と移動量を比例させず、イージングカーブ（中央で平らになる曲線）でつなぐ。GSAP のタイムラインで「速い区間・遅い区間・速い区間」を並べ、ScrollTrigger の `scrub` でスクロールに結びつける。

---

### 3. マッチカット

**動画での意味**：形の似たものでカットをつなぐ（『2001年宇宙の旅』の、投げた骨 → 宇宙船）。

**Webでの具体例**：コーヒーブランドのストーリーページ
- セクション1：丸いコーヒー豆のアップ
- スクロールすると、豆の輪郭が**そのまま丸い地球**に変形する
- セクション2：「世界 12 か国の農園から」という話に切り替わる
- → 話題が変わるのに、形がつながっているので途切れた感じがしない

**実装のヒント**：SVG のパスを別のパスへ変形（GSAP の MorphSVG、または `clip-path` の `circle()` を拡大）。同じ位置・同じ大きさで切り替えるのがコツ。

---

### 4. モンタージュ

**動画での意味**：短いカットを次々つないで、時間の流れや雰囲気を一気に伝える（映画のトレーニングシーン）。

**Webでの具体例**：音楽フェスの告知サイト
- ファーストビューの中央で、**0.3 秒ごと**に写真が切り替わる：観客の手 → ステージの照明 → 汗をかいたドラマー → 夜空の花火 → ロゴ
- 最後にロゴで止まり、「2026.8.15 – 16」が表示される
- → 説明文を読ませなくても「熱いイベント」だと伝わる

**実装のヒント**：画像を重ねて置き、`opacity` を順番に切り替える `@keyframes`。画像は事前に読み込んでおく（途中で白くならないように）。

---

### 5. キネティックタイポグラフィ

**動画での意味**：文字そのものを動かして感情やリズムを伝える（MV の歌詞演出）。

**Webでの具体例**：デザイン事務所のトップページ
- 最初は画面中央に小さく「MAKE」
- スクロールすると「MAKE」が**画面からはみ出すほど巨大化**し、文字の中（「A」の穴）にカメラが突っ込んでいく
- 穴を抜けると次のセクションの作品一覧が現れる
- 別パターン：「IDEAS」が 1 文字ずつバラバラに飛び散って、各文字が作品カードに変わる

**実装のヒント**：文字を 1 文字ずつ `<span>` に分割（GSAP SplitText など）して個別に `transform`。巨大化は `scale` で行う（`font-size` を動かすと重い）。

---

### 6. モーションブラー

**動画での意味**：速く動くものがブレて見える。スピード感が出る。

**Webでの具体例**：EC サイトの商品カルーセル
- 止まっている商品写真はくっきり
- 「次へ」を押してスライドが**素早く横に流れている間だけ**横方向にブレる
- 止まった瞬間にピタッとくっきり戻る
- → ただのスライドよりも「シュッ」と動いた感じが出る

**実装のヒント**：移動速度に応じて `filter: blur()` を一時的にかける（横だけブレさせるなら SVG の `feGaussianBlur` で `stdDeviation="8 0"`）。重いので短時間・小さい範囲に限る。

---

### 7. フリーズフレーム

**動画での意味**：動いている映像を一瞬止めて、テロップや人物紹介を出す（バラエティ番組の「この男、のちに…」）。

**Webでの具体例**：ランニングシューズのブランドサイト
- 背景で、ランナーが走る動画が流れている
- スクロールすると、**足が地面に着いた瞬間で動画が止まる**
- 止まった画面の上に線が引かれ、「着地の衝撃を 30% 吸収」「かかとのクッション」などの説明が靴の各部分を指して展開
- さらにスクロールすると動画が再開する

**実装のヒント**：スクロール量で `video.currentTime` を操作する（または連番画像を `<canvas>` に描く）。止める区間は ScrollTrigger の `pin` で画面を固定し、その間に説明を出す。

---

### 8. グリッチ

**動画での意味**：映像が乱れる・ノイズが走る。デジタル感、不穏さ、切り替わりの強調。

**Webでの具体例**：セキュリティ製品やゲームのサイト
- 見出し「YOUR DATA IS EXPOSED」が表示された瞬間、**0.2 秒だけ**文字が横にずれ、赤・青に色が分かれてチラつく
- すぐに正常な表示に戻る
- ページ切り替え時に画面全体が一瞬ノイズで乱れる、という使い方も

**実装のヒント**：同じ文字を `::before` / `::after` で重ね、色を変えて少しずらし、`clip-path` で横縞に切りながら動かす。**一瞬だけ・たまにだけ**にしないとうるさくなる（点滅は 1 秒に 3 回以下にする）。

---

### 9. Whip Pan（ウィップパン）

**動画での意味**：カメラを横に素早く振って、ブレたまま次のシーンにつなぐ。

**Webでの具体例**：旅行会社の「行き先を選ぶ」ページ
- 「京都」のセクションを見ている状態でスクロール（またはタブをクリック）
- 画面全体が**横にビュンと流れ**（ブレ付き）、次の「沖縄」のセクションでピタッと止まる
- → 縦に読み進めるページなのに、カメラを振って場所を移ったような感覚になる

**実装のヒント**：横に並べたセクションをコンテナごと `translateX` で動かし、移動中だけモーションブラー（6. と同じ）を足す。イージングは「急加速・急停止」（`expo.inOut` など）。

---

### 10. ロール

**動画での意味**：カメラや被写体を回転させて見せる（回転しながら場面転換、商品の 360° 回転）。

**Webでの具体例**：ワイヤレスイヤホンの商品ページ
- スクロールに合わせてイヤホンが**ゆっくり回転**し、正面 → 側面 → 裏側と見せる
- 側面が見えたところで「タッチセンサー」、裏側で「イヤーチップ 3 サイズ」と説明が出る
- 別パターン：セクションの切り替わりで、画面全体が紙をめくるように 3D 回転して次の内容が出てくる

**実装のヒント**：商品は 3D モデル（Three.js / `<model-viewer>`）か、角度を変えて撮った連番画像をスクロールで切り替える。画面の回転は `perspective` ＋ `rotateY`。

---

### 11. L/J カット的演出

**動画での意味**：
- **J カット**：次のシーンの**音が先に**聞こえてから映像が切り替わる
- **L カット**：前のシーンの**音が残った**まま映像が切り替わる

**Webでの具体例**：ドキュメンタリー風の企業ブランディングサイト
- J カット的：「工場」セクションの終わりのほうで、まだ画面は前の内容なのに、**次の「海」セクションの写真が下からうっすら見え始め**、波の音（または「海へ」という小さな見出し）が先に出てくる → 次への期待が生まれる
- L カット的：次のセクションに移っても、前のセクションの大きな見出しが**背景に薄く残ったまま**しばらく一緒にスクロールする → 話がつながって感じる
- 音がなくても「次の要素の一部を先に見せる」「前の要素を少し残す」で同じ効果が出せる

**実装のヒント**：セクション同士を少し重ねて配置し、ScrollTrigger の開始位置を前倒し（`start: "top 120%"` など）。音を使う場合は、ユーザーが音をオンにしたときだけ鳴らす。

---

### 12. 音ハメ

**動画での意味**：BGM のビートに合わせてカットを切り替える・動きを合わせる。

**Webでの具体例**：アーティストの新曲特設サイト
- 「サウンドをオン」ボタンを押すと曲が流れ、**ドラムのキックに合わせて**背景の色が切り替わり、歌詞が 1 行ずつ出る
- ボタンにカーソルを乗せると「ポン」と小さな音、クリックで「カチッ」
- サビに入った瞬間に画面全体がフラッシュしてアートワークが大きく表示される

**実装のヒント**：Web Audio API で再生位置を取り、あらかじめ決めたタイミング（秒数のリスト）で演出を発火する。リアルタイムで音を解析するなら `AnalyserNode`。**自動再生はブラウザに止められる**ので、必ずユーザーの操作で音を出す。

| **クラッシュズーム** | 一瞬で一点に急接近する | ★★★★☆ |
| **ジャンプカット** | 同じ構図のまま中身だけをカクッ、カクッと切り替える | ★★★☆☆ |
| **タイムラプス** | 長い時間の変化をスクロールで早送りする | ★★★★★ |
| **アスペクト比の変化** | 画面の黒帯が開閉して「映画モード」に入る | ★★★★☆ |

### 13. ドリーズーム（めまいショット）

**動画での意味**：カメラを後ろに引きながらズームインする。人物の大きさは変わらないのに背景だけがぐにゃっと伸びる（ヒッチコック『めまい』、『ジョーズ』）。不安・衝撃・気づきの瞬間に使う。

**Webでの具体例**：ホラーゲームの特設サイト
- 廊下の奥に立つ人影がずっと同じ大きさのまま
- スクロールすると、**廊下の壁と床だけが遠くへ引き伸ばされていく**
- 最後に「その廊下は、終わらない。」の文字

**実装のヒント**：前景（人物）と背景を別レイヤーにし、背景だけを `scale` で縮めながら前景は固定。Three.js なら、カメラを後退させながら `fov` を狭めると本物のドリーズームになる。

### 14. ラックフォーカス（ピント送り）

**動画での意味**：手前の物にピントが合っていた状態から、奥の物にピントを移す。見る場所を観客に指示する。

**Webでの具体例**：レストランのページ
- 最初は手前のワイングラスがくっきり、奥のシェフはぼやけている
- スクロールすると、**グラスがぼやけてシェフがくっきり**し、「料理長 ○○」の紹介文が出る

**実装のヒント**：手前と奥を別画像にして、`filter: blur()` を逆向きに変化させる。

### 15. ケン・バーンズ効果

**動画での意味**：古い写真などの静止画を、ゆっくりズーム・パンして映像のように見せる（ドキュメンタリーでおなじみ）。

**Webでの具体例**：老舗旅館の「歴史」ページ
- 昭和の白黒写真が表示され、**数秒かけてゆっくり**番頭さんの顔へ寄っていく
- 写真が切り替わるたびに年号と短い説明が出る
- → 動画素材がなくても、写真だけで映像っぽい語りができる

**実装のヒント**：`transform: scale(1) → scale(1.15)` と `translate` を長め（6〜10 秒）にかける。手軽で、効果のわりに軽い。

### 16. アイリス／ワイプ

**動画での意味**：
- **アイリス**：画面が円形に閉じて（または開いて）切り替わる（昔のアニメの「おしまい」）
- **ワイプ**：線が画面を横切って、次の場面に塗り替わる（『スター・ウォーズ』）

**Webでの具体例**：
- ダークモードのボタンを押すと、**ボタンの位置から円が広がって**画面が黒に塗り替わる
- ページ遷移で、斜めの帯が画面を横切った後ろから次のページが現れる

**実装のヒント**：`clip-path: circle(0% at x y) → circle(150% at x y)`。ページ遷移なら **View Transitions API**（`document.startViewTransition()`）と組み合わせると作りやすい。

---

### 17. スプリットスクリーン

**動画での意味**：画面を分割し、別々の場所の出来事を同時に見せる（電話で話す 2 人、『24』）。

**Webでの具体例**：
- 不動産サイトで、左に「リフォーム前」、右に「リフォーム後」。**境界線をドラッグ**すると比べられる
- 転職サイトで、左に「月曜朝の A さん」、右に「同じ時刻の B さん」。スクロールで両方の 1 日が同時に進む

**実装のヒント**：比較スライダーは 2 枚の画像を重ね、上の画像の `clip-path: inset(0 0 0 X%)` をドラッグ量で変える。左右で同時に進むものは、2 つのカラムを別々の速度で `transform` する。

### 18. ワンカット長回し

**動画での意味**：カットを割らずにカメラを動かし続け、1 本の連続した映像で見せる（『1917』）。没入感が出る。

**Webでの具体例**：家具メーカーのサイト
- 玄関から始まり、スクロールするとカメラが**廊下 → リビング → キッチン → 寝室**と家の中を進む
- 部屋に入るたびに、その部屋の家具の説明が浮かぶ
- 「セクション」という区切りを感じさせず、1 つの空間を歩いている感覚になる

**実装のヒント**：本格的にやるなら Three.js で 3D 空間を作り、カメラの移動経路をスクロール量に結びつける。手軽にやるなら、カメラ移動を撮った動画をスクロールで再生する（7. と同じ仕組み）。

### 19. クラッシュズーム

**動画での意味**：一瞬で被写体に急接近する。驚き・強調・コメディ（バラエティ番組のツッコミ）。

**Webでの具体例**：料金プランのページ
- 3 つのプランが並んでいる状態でスクロール
- 「おすすめ」プランの**価格の数字に、画面がドンッと一気に寄る**（揺れ付き）
- 「月額 980 円」が画面いっぱいに表示される

**実装のヒント**：`scale` を 0.2 秒程度で一気に上げ、最後に小さく揺らす（`translate` を数 px 往復）。

### 20. ジャンプカット

**動画での意味**：同じ構図のまま時間を飛ばし、人物の位置や状態だけが不連続に変わる（YouTuber の編集、ゴダール）。テンポが出る。

**Webでの具体例**：アパレルのコーディネート紹介
- 同じ場所・同じポーズのモデルで、スクロールのたびに**服だけがカクッと切り替わる**（春 → 夏 → 秋 → 冬）
- フェードなどを入れずに瞬時に切り替えるのがポイント

**実装のヒント**：スクロール位置の区間ごとに画像を差し替えるだけ。アニメーションをつけないことが演出になる。

---

### 21. タイムラプス

**動画での意味**：長い時間を早送りして、変化を短時間で見せる（花が咲く、街の 1 日）。

**Webでの具体例**：
- 建設会社のサイトで、スクロールすると**更地 → 骨組み → 完成したビル**へと建物が建っていく
- ホテルのサイトで、スクロールに合わせて客室の窓の外が**朝 → 昼 → 夕焼け → 夜景**と変わる

**実装のヒント**：連番画像を `<canvas>` に描いてスクロールで切り替える。空の色の変化だけなら背景のグラデーションを CSS 変数で変えるだけでもできる。

### 22. アスペクト比の変化（レターボックス）

**動画での意味**：上下に黒帯を入れてシネマスコープ（横長）にする。途中で比率を変えて「ここからが特別」を示す（『ダークナイト』の IMAX シーン）。

**Webでの具体例**：映画の公式サイト
- 「予告編を見る」を押すと、**画面の上下から黒帯がスッと閉じてきて**横長の画面になり、ページの他の要素が消えて予告が始まる
- 閉じると黒帯が開いて元のページに戻る

**実装のヒント**：上下に固定配置した黒い帯の `height` ではなく `scaleY` を変える。

### 23. カラーグレーディング

**動画での意味**：場面ごとに映像全体の色味を変え、時代・感情・場所を表す（過去はセピア、現代は青み）。

**Webでの具体例**：会社の沿革ページ
- 創業期のセクションは**セピア**、成長期は**くすんだカラー**、現在は**鮮やかなフルカラー**
- スクロールするにつれて、画面全体の色が少しずつ現代の色に近づいていく

**実装のヒント**：`filter: sepia() saturate()` をスクロール量で変える。ページ全体の背景色・文字色を CSS 変数にしておき、セクションごとに切り替えるのも効果的。

### 24. ストップモーション（コマ落とし）

**動画での意味**：1 コマずつ撮った写真をつないで動かす。カクカクした手作り感が出る（『ウォレスとグルミット』）。

**Webでの具体例**：手作り雑貨店のサイト
- ロゴの文字が**紙を切り抜いたような見た目で、カクカクと**組み上がる
- 商品写真も、なめらかに動かさず 1 秒に 8 コマくらいでコトコト動く

**実装のヒント**：CSS アニメーションのイージングを `steps(8)` にするだけで、なめらかな動きがコマ送りになる。

---

### 25. 巻き戻し

**動画での意味**：映像を逆再生する。「なぜこうなったのか」を遡るときに使う。

**Webでの具体例**：グラスが割れる写真から始まるページ
- 下にスクロールすると、**割れた破片が集まってグラスに戻っていく**
- 「壊れない理由」として強化ガラスの説明が続く

**実装のヒント**：スクロール連動アニメーションはもともと上にスクロールすれば逆再生される。「最初に結果を見せ、スクロールで原因に遡る」という構成にするのがポイント。

| 演出 | どんなものか | 個性 |

| **マグネティックボタン** | ボタンがカーソルに吸い寄せられる | ★★★★☆ |
| **読み進めるとハイライト** | スクロールに合わせて文章に色がついていく | ★★★☆☆ |
| **積み重なるカード** | スクロールでカードが上に重なっていく | ★★★☆☆ |
| **画像の歪み（WebGL）** | ホバーで画像が水面のように揺れる | ★★★★★ |
| **物理演算** | 要素が落ちる・跳ねる・ドラッグで投げられる | ★★★★★ |
| **スクラッチ** | 表面を削ると下の画像が出てくる | ★★★★☆ |
| **時間帯で変わるページ** | 見ている時刻によってデザインが変わる | ★★★★☆ |

| **数字のカウントアップ** | 実績の数字が 0 から回転して止まる | ★★☆☆☆ |

### カスタムカーソル

- 写真ギャラリーで、写真の上ではカーソルが**「VIEW」と書かれた大きな円**に変わる
- 動画の上では「▶ PLAY」、横スクロールの場所では「← DRAG →」に変わる
- → 説明文なしで「ここで何ができるか」が伝わる
- **実装**：標準カーソルを `cursor: none` で消し、`mousemove` で追いかける要素を置く。少し遅れて追いかけさせると気持ちいい。スマホにはカーソルがないので、タップ操作でも困らないようにしておく

### マグネティックボタン

- 「お問い合わせ」ボタンに近づくと、ボタンが**カーソルのほうへ少し引っ張られる**。離れるとプルンと戻る
- **実装**：ボタン中心からカーソルまでの距離を測り、その 30% くらいだけ `translate` する

### 読み進めるとハイライト

- 会社のメッセージページで、最初は文章全体が薄いグレー
- スクロールすると、**読んでいる行から順に黒くなっていく**（カラオケの歌詞のように）
- → 長文でも「どこまで読んだか」が分かり、1 文ずつ読ませられる
- **実装**：単語ごとに `<span>` で分け、スクロール量に応じて `opacity` を上げる。CSS の `animation-timeline: view()` でも作れる

### 積み重なるカード

- 「サービスの特徴 3 つ」のカードが、スクロールすると**下から来て前のカードの上に重なっていく**
- 下のカードは少し縮んで暗くなり、奥に積まれていく感じが出る
- **実装**：各カードに `position: sticky; top: ○px` を指定し、少しずつずらすだけで基本形ができる

### 画像の歪み（WebGL）

- 作品一覧で、写真にカーソルを乗せると**水面に指を入れたように画像が波打つ**
- 別の写真に切り替わるとき、液体が混ざるように溶け合って変わる
- **実装**：Three.js（または OGL）で画像をテクスチャにし、シェーダーで歪ませる。見た目のインパクトは大きいが、作るのは一番難しい部類

### 物理演算

- 404 ページで、「404」の文字や画面の部品が**ガラガラと下に落ちて積み重なる**。マウスでつかんで投げられる
- 採用ページで、社員のキーワード（「コーヒー好き」「猫派」など）のタグが箱の中に落ちてきて、ドラッグで遊べる
- **実装**：Matter.js で物体の動きを計算し、その位置を HTML 要素に反映する

### スクラッチ

- キャンペーンページで、銀色の部分を**マウスや指でこすると**下から当選結果やクーポンが出てくる
- **実装**：`<canvas>` に銀色を塗り、なぞった部分を `globalCompositeOperation = "destination-out"` で消す

### 時間帯で変わるページ

- カフェのサイトで、**朝に開くと「おはようございます」とモーニングメニュー**、夜に開くと暗い配色で「今夜のワイン」
- **実装**：`new Date().getHours()` で時間帯を判定し、クラスを切り替える

### タブのタイトル演出

- EC サイトを開いたまま別のタブに移ると、元のタブのタイトルが**「👀 カートに商品が残っていますよ」**に変わる。戻ると元のタイトルに戻る
- **実装**：`visibilitychange` イベントで `document.title` を書き換える。やりすぎると嫌がられるので控えめに

### 目で追うキャラクター

- お問い合わせフォームのマスコットキャラが、**カーソルの方向を目で追いかける**
- パスワード欄に入力し始めると、キャラが手で目を隠す
- **実装**：キャラの目（黒目）の位置を、カーソルの方向に数 px だけ動かす。`Math.atan2` で角度を出す

### 隠しコマンド

- キーボードで **↑↑↓↓←→←→BA**（コナミコマンド）を入力すると、ページがレトロゲーム風の見た目に変わる
- ロゴを 10 回クリックすると、開発者の写真や裏話が出てくる
- → 見つけた人がつい SNS で話したくなる
- **実装**：`keydown` を記録して、並びが一致したら演出を実行する

### 数字のカウントアップ

- 実績セクションが画面に入ったとき、「導入企業 **0 → 1,200 社**」とスロットのように数字が回って止まる
- 定番すぎて個性は弱いが、他の演出と組み合わせると効く（例：止まる瞬間にクラッシュズーム）
- **実装**：`IntersectionObserver` で画面に入ったことを検知して数字を増やす

## 組み合わせ例（1 ページの流れ）

架空のスニーカー新作の特設ページで、複数の技法をつなげた場合：

1. **モンタージュ**：街・足元・ロゴの写真が 0.3 秒ずつ切り替わり、ロゴで止まる
2. **キネティックタイポグラフィ**：ロゴの「O」が巨大化し、その穴を抜けて本編へ
3. **パララックス**：奥に街並み、手前にスニーカーが浮かぶ
4. **ロール**＋**スピードランプ**：スニーカーが回転しながら横切り、ソールが見えた瞬間だけスローになって素材の説明
5. **フリーズフレーム**：走る動画が着地の瞬間で止まり、クッションの説明が展開
6. **Whip Pan**：カラー違い（白→黒→赤）を横にビュンと切り替えて紹介
7. **グリッチ**：最後に「発売日」の数字が一瞬乱れてから確定表示 → 購入ボタン

> [!warning] 使いすぎ注意
> 1 ページに全部入れると疲れる。「ここだけは見てほしい」という箇所に 1〜2 個の強い演出を置き、残りは控えめにするのが基本。
