## 必要ツール
- AWS CLI v2 / AWS SAM CLI or AWS CDK
- Git / Node.js or Python / Docker（必要に応じて）
- Cursor（または VS Code）

## 認証とプロファイル
```bash
aws configure --profile dev
# AWS Access Key/Secret は極力 SSO を使用
```

SSO 利用例（AWS IAM Identity Center）:
```bash
aws configure sso --profile dev
aws sso login --profile dev
```

## 基本設定
- 既定リージョン・出力形式・プロファイル名を統一
- 環境変数 `AWS_PROFILE=dev` を活用
