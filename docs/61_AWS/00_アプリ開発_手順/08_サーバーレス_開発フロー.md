## 目的
Cursor ローカル開発でのサーバーレス（Lambda 中心）開発〜デプロイの流れを標準化する。

## 推奨構成
- フレームワーク: AWS SAM（関数中心） or AWS CDK（構成全般）
- 実行/検証: `sam local` / `cdk synth`、必要に応じて LocalStack
- データ: DynamoDB Local など（段階導入）
- 秘密情報: Parameter Store / Secrets Manager（ローカルは `.env`）

## 基本フロー
1. リポジトリ作成（ブランチ保護、CI 連携）
2. テンプレート初期化（SAM or CDK）
3. ローカル実行/デバッグ（Docker 前提のものあり）
4. IaC でスタック作成（テスト環境 → 本番）
5. CI/CD に統合（署名/スキャン/ロールバック設計）
