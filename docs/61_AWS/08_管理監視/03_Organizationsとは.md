# Organizations とは

## 概要

Organizations は、複数の AWS アカウントを統合的に管理する複数アカウント管理サービスです。アカウントの階層化、ポリシーの一元管理、請求の統合により、大規模な AWS 環境の管理を簡素化します。

## 主な機能

### 1. 複数アカウント管理サービス

- 複数 AWS アカウントの統合管理
- 階層的なアカウント構造
- ポリシーの一元管理
- 請求の統合

### 2. ガバナンスの強化

- セキュリティポリシーの統一
- コンプライアンスの確保
- コスト管理の最適化
- アクセス制御の統一

## 組織構造

### 1. ルート（Root）

- 組織の最上位レベル
- すべてのアカウントの親
- 組織全体のポリシー適用
- 組織の設定管理

### 2. 組織単位（OU）

- アカウントの論理的なグループ化
- 階層的な構造
- ポリシーの継承
- 柔軟な管理

#### OU の特徴

- **階層構造**: 親子関係での管理
- **ポリシー継承**: 親 OU から子 OU への継承
- **柔軟性**: 動的なアカウント移動
- **管理効率**: グループ単位での管理

### 3. アカウント

- 個別の AWS アカウント
- リソースの実行環境
- ポリシーの適用対象
- 請求の対象

## サービス制御ポリシー（SCP）

### 1. 機能

- アカウントレベルでの権限制限
- サービス利用の制御
- リソース作成の制限
- セキュリティの強化

#### SCP の特徴

- **権限制限**: アカウントの権限を制限
- **サービス制御**: 特定サービスの利用制限
- **リソース制限**: リソース作成の制限
- **継承**: OU レベルでの継承

### 2. 使用例

- 本番環境での制限
- 開発環境での制限
- コンプライアンス要件
- セキュリティポリシー

## 統合請求（Consolidated Billing）

### 1. 機能

- 複数アカウントの請求統合
- ボリューム割引の適用
- 使用量の集約
- コストの可視化

#### 統合請求の特徴

- **請求統合**: すべてのアカウントの請求を統合
- **ボリューム割引**: 使用量に応じた割引
- **使用量集約**: 全アカウントの使用量を集約
- **コスト可視化**: アカウント別のコスト表示

### 2. メリット

- コストの最適化
- 請求の簡素化
- 割引の最大化
- 予算管理の改善

## まとめ

Organizations は、複数の AWS アカウントを統合的に管理する重要なサービスです。階層的な構造、ポリシーの一元管理、統合請求により、大規模な AWS 環境の管理を簡素化します。適切な設計と運用により、セキュリティとコスト効率を両立した組織管理が可能になります。
