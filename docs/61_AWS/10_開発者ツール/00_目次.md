## CI/CDパイプライン

### 1. ソース管理
- **CodeCommit**: Gitリポジトリ
- **GitHub/GitLab**: 外部リポジトリとの連携

### 2. ビルド・テスト
- **CodeBuild**: 自動ビルドとテスト
- **Lambda**: カスタムビルド処理

### 3. デプロイ
- **CodeDeploy**: アプリケーションデプロイ
- **ECS/EKS**: コンテナデプロイ

### 4. パイプライン管理
- **CodePipeline**: ワークフロー管理
- **Step Functions**: 複雑なワークフロー

## 実践例

### 基本的なCI/CDパイプライン
```
CodeCommit → CodeBuild → CodeDeploy → EC2/ECS
```

### コンテナCI/CDパイプライン
```
CodeCommit → CodeBuild → ECR → ECS/EKS
```

### サーバーレスCI/CDパイプライン
```
CodeCommit → CodeBuild → Lambda → API Gateway
```

---

**注意**: このドキュメントは学習目的で作成されています。本番環境では、プロジェクトの要件に応じて適切なCI/CDパイプラインを設計してください。
