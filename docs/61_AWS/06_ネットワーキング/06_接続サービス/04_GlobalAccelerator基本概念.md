# Global Accelerator とは

## 概要

Global Accelerator は、AWS の**グローバルなネットワーク最適化サービス**です。世界中に配置された AWS のエッジロケーションを使用して、ユーザーからアプリケーションまでの**ネットワークパスを最適化**し、**レイテンシーの削減**と**パフォーマンスの向上**を実現します。

## なぜ Global Accelerator が必要なのか？

### 1. レイテンシーの削減

- ユーザーに最も近いエッジロケーションから接続
- AWS のグローバルネットワークを活用
- インターネットの輻輳を回避

### 2. 可用性の向上

- 複数のエッジロケーションでの冗長化
- 自動フェイルオーバー
- 単一障害点の排除

### 3. パフォーマンスの向上

- 一貫した低レイテンシー
- 高い帯域幅の保証
- ネットワークの予測可能性

## Global Accelerator の仕組み

### 1. エッジロケーション

```
ユーザー（東京） → 東京のエッジロケーション → AWSバックボーン → アプリケーション（米国）
ユーザー（ロンドン） → ロンドンのエッジロケーション → AWSバックボーン → アプリケーション（米国）
```

### 2. 静的 IP アドレス

- **2 つの静的 IP アドレス**を提供
- エッジロケーションから配信
- アプリケーションの IP アドレス変更に影響されない

### 3. ヘルスチェック

- エンドポイントの健全性を監視
- 自動的なトラフィックの振り分け
- 異常なエンドポイントの除外

## Global Accelerator の構成要素

### 1. アクセラレーター

**Global Accelerator のインスタンス**

#### 特徴

- 2 つの静的 IP アドレスを提供
- 複数のリスナーをサポート
- グローバルな配信

### 2. リスナー

**トラフィックを受信するエンドポイント**

#### 種類

- **TCP リスナー**：TCP トラフィック用
- **UDP リスナー**：UDP トラフィック用

### 3. エンドポイントグループ

**複数のエンドポイントをグループ化**

#### 特徴

- 複数のリージョンに配置可能
- 重み付けによるトラフィック分散
- ヘルスチェックの設定

### 4. エンドポイント

**実際のアプリケーション**

#### 種類

- **Application Load Balancer（ALB）**
- **Network Load Balancer（NLB）**
- **EC2 インスタンス**
- **Elastic IP アドレス**

## 実際の構成例

### 1. 基本的な構成

```
Global Accelerator
├── 静的IPアドレス1
├── 静的IPアドレス2
└── リスナー（TCP:443）
    ↓
エンドポイントグループ
├── リージョンA（東京）
│   └── ALB（10.0.1.100）
└── リージョンB（大阪）
    └── ALB（10.1.1.100）
```

### 2. マルチリージョン構成

```
Global Accelerator
├── リスナー（TCP:443）
└── エンドポイントグループ
    ├── リージョンA（東京）
    │   └── ALB
    ├── リージョンB（シンガポール）
    │   └── ALB
    └── リージョンC（バージニア）
        └── ALB
```

### 3. ゲームサーバー構成

```
Global Accelerator
├── リスナー（UDP:7777）
└── エンドポイントグループ
    ├── リージョンA（東京）
    │   └── EC2インスタンス
    └── リージョンB（大阪）
        └── EC2インスタンス
```

## パフォーマンスの最適化

### 1. レイテンシーの最適化

- **エッジロケーション**：ユーザーに最も近い場所
- **AWS バックボーン**：高速な専用回線
- **最適化されたルーティング**：最短経路の選択

### 2. 帯域幅の最適化

- **高帯域幅**：AWS のグローバルネットワーク
- **輻輳の回避**：インターネットの混雑を回避
- **一貫したパフォーマンス**：時間帯による変動が少ない

### 3. 可用性の最適化

- **複数のエッジロケーション**：冗長化
- **自動フェイルオーバー**：異常時の自動切り替え
- **ヘルスチェック**：継続的な監視

## セキュリティ機能

### 1. DDoS 保護

- **AWS Shield Standard**：基本的な DDoS 保護
- **AWS Shield Advanced**：高度な DDoS 保護
- **自動的な攻撃検出**：リアルタイムでの対応

### 2. アクセス制御

- **セキュリティグループ**：インスタンスレベルでの制御
- **ネットワーク ACL**：サブネットレベルでの制御
- **WAF**：アプリケーションレベルでの制御

### 3. 暗号化

- **TLS/SSL**：通信の暗号化
- **証明書管理**：AWS Certificate Manager との連携
- **エンドツーエンド暗号化**：完全な暗号化

## 料金について

### 1. アクセラレーター

- **時間料金**：$0.025/時間（約$18/月）
- **データ転送料金**：$0.01/GB

### 2. 固定料金

- **最初の 10TB/月**：$0.01/GB
- **10TB-40TB/月**：$0.008/GB
- **40TB-100TB/月**：$0.006/GB

### 3. データ転送料金

- **同一リージョン内**：$0.01/GB
- **異なるリージョン間**：$0.01/GB

### 1. エンドポイントの最適化

## CloudFront との比較

| 項目         | Global Accelerator    | CloudFront               |
| ------------ | --------------------- | ------------------------ |
| 用途         | 動的コンテンツ        | 静的コンテンツ           |
| レイヤー     | レイヤー 4（TCP/UDP） | レイヤー 7（HTTP/HTTPS） |
| キャッシュ   | なし                  | あり                     |
| レイテンシー | 低い                  | 非常に低い               |
| コスト       | 中程度                | 低い                     |

## 使用例

### 1. グローバルな Web アプリケーション

```
ユーザー → Global Accelerator → 複数リージョンのALB → アプリケーション
```

### 2. ゲームサーバー

```
ゲーマー → Global Accelerator → 複数リージョンのゲームサーバー
```

### 3. IoT アプリケーション

```
IoTデバイス → Global Accelerator → 複数リージョンのIoTサーバー
```

### 4. リアルタイム通信

```
ユーザー → Global Accelerator → 複数リージョンの通信サーバー
```

## まとめ

Global Accelerator は、グローバルなネットワーク最適化を実現する強力なサービスです。動的コンテンツやリアルタイムアプリケーションにおいて、レイテンシーの削減、可用性の向上、パフォーマンスの向上を同時に実現できます。
