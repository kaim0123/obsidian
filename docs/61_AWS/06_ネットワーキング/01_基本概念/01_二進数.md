# 二進数

## 概要

二進数（Binary）は、0 と 1 の 2 つの数字のみを使用する数値表現方法です。コンピュータは電気信号の ON/OFF で動作するため、二進数が基本となっています。

## なぜ二進数が重要なのか

- **コンピュータの基本**: コンピュータは電気信号の ON（1）と OFF（0）で動作
- **ネットワークの基礎**: IP アドレスやサブネットマスクは二進数で表現
- **AWS の理解**: VPC、サブネット、セキュリティグループの設定で必要

## 二進数の基本

### 桁の重み

二進数の各桁には重みがあります：

```
8  4  2  1  ← 桁の重み
1  0  1  0  ← 二進数
```

この例では：1×8 + 0×4 + 1×2 + 0×1 = 10（十進数）

### 基本的な変換例

| 二進数 | 十進数 | 計算            |
| ------ | ------ | --------------- |
| 0000   | 0      | 0×8+0×4+0×2+0×1 |
| 0001   | 1      | 0×8+0×4+0×2+1×1 |
| 0010   | 2      | 0×8+0×4+1×2+0×1 |
| 0011   | 3      | 0×8+0×4+1×2+1×1 |
| 0100   | 4      | 0×8+1×4+0×2+0×1 |
| 0101   | 5      | 0×8+1×4+0×2+1×1 |
| 0110   | 6      | 0×8+1×4+1×2+0×1 |
| 0111   | 7      | 0×8+1×4+1×2+1×1 |
| 1000   | 8      | 1×8+0×4+0×2+0×1 |

## 8 ビット（1 オクテット）の例

IP アドレスは 8 ビットずつ 4 つの部分に分かれています：

```
192.168.1.1 の二進数表現：
192 = 11000000
168 = 10101000
1   = 00000001
1   = 00000001

全体: 11000000.10101000.00000001.00000001
```

## 重要な二進数の値

| 十進数 | 二進数   | 説明               |
| ------ | -------- | ------------------ |
| 0      | 00000000 | 最小値             |
| 255    | 11111111 | 最大値（8 ビット） |
| 128    | 10000000 | 最上位ビット       |
| 64     | 01000000 | 2 番目のビット     |
| 32     | 00100000 | 3 番目のビット     |
| 16     | 00010000 | 4 番目のビット     |
| 8      | 00001000 | 5 番目のビット     |
| 4      | 00000100 | 6 番目のビット     |
| 2      | 00000010 | 7 番目のビット     |
| 1      | 00000001 | 最下位ビット       |

## AWS での活用例

- **VPC CIDR ブロック**: 10.0.0.0/16 の理解
- **サブネット分割**: 利用可能な IP アドレス数の計算
- **セキュリティグループ**: ポート番号の理解
- **ルートテーブル**: ネットワークルーティングの設定

## 練習問題

1. 二進数 1010 を十進数に変換してください
2. 十進数 15 を二進数に変換してください
3. IP アドレス 172.16.0.1 の各オクテットを二進数で表現してください

## まとめ

二進数はコンピュータとネットワークの基礎です。IP アドレスやサブネットマスクを理解するために必須の知識です。AWS の VPC やサブネット設定でも、この知識が直接活用されます。
