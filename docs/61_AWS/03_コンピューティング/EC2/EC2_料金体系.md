# EC2 料金体系

## 料金モデル

### 1. オンデマンドインスタンス
- **特徴**: 使用した時間分だけ課金
- **適用**: 開発・テスト環境、不定期なワークロード
- **料金**: 最も高いが柔軟性が高い

### 2. リザーブドインスタンス
- **特徴**: 1年または3年の契約で割引
- **適用**: 本番環境、継続的なワークロード
- **料金**: 最大75%の割引

### 3. スポットインスタンス
- **特徴**: 未使用容量を安価で利用
- **適用**: バッチ処理、開発環境
- **料金**: 最大90%の割引（中断の可能性あり）

### 4. Savings Plans
- **特徴**: 使用量に基づく割引プラン
- **適用**: 柔軟性とコスト効率のバランス
- **料金**: 最大72%の割引

## 無料利用枠

```
EC2無料利用枠（12ヶ月間）:
- t2.microインスタンス: 750時間/月
- ストレージ: 30GB
- データ転送: 1GB/月
```

## コスト最適化のポイント

1. **適切なインスタンスタイプの選択**
2. **不要なインスタンスの停止**
3. **リザーブドインスタンスの活用**
4. **スポットインスタンスの検討**
5. **定期的なコスト分析**

## 料金計算の例

### オンデマンド料金（東京リージョン）
```
t3.micro: $0.0104/時間
t3.small: $0.0208/時間
m5.large: $0.096/時間
```

### リザーブドインスタンス料金（1年契約）
```
t3.micro: $0.0068/時間（約35%割引）
t3.small: $0.0136/時間（約35%割引）
m5.large: $0.062/時間（約35%割引）
```

### 月間コスト計算例
```
t3.micro を24時間稼働の場合:
- オンデマンド: $0.0104 × 24 × 30 = $7.49/月
- リザーブド: $0.0068 × 24 × 30 = $4.90/月
- 節約額: $2.59/月（約35%の節約）
```

## コスト管理のベストプラクティス

### 1. タグの活用
```
Environment: production, development, test
Project: my-web-app
Owner: team-name
```

### 2. 定期的な監視
- AWS Cost Explorerでの分析
- 予算アラートの設定
- 未使用リソースの特定

### 3. 自動化
- 開発環境の自動停止・起動
- スケジュールに基づくインスタンス管理
- Auto Scalingの活用
