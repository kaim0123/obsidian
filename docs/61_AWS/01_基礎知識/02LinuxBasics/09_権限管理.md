# 権限管理

## 権限管理とは

Linux システムでは、**権限管理（Permission Management）**は、ファイルやディレクトリへのアクセスを制御する重要なセキュリティ機能です。ユーザー、グループ、その他のユーザーに対して、読み取り、書き込み、実行の権限を細かく設定できます。

## ファイル権限の基本

### 権限の種類

#### 1. 読み取り権限（Read）

- **記号**: r
- **数値**: 4
- **ファイル**: 内容を読むことができる
- **ディレクトリ**: ディレクトリの内容を一覧表示できる

#### 2. 書き込み権限（Write）

- **記号**: w
- **数値**: 2
- **ファイル**: 内容を変更・削除できる
- **ディレクトリ**: ファイルの作成・削除ができる

#### 3. 実行権限（Execute）

- **記号**: x
- **数値**: 1
- **ファイル**: プログラムとして実行できる
- **ディレクトリ**: ディレクトリにアクセスできる

### 権限の対象

#### 1. 所有者（Owner/User）

- ファイルの所有者
- 記号: u

#### 2. グループ（Group）

- ファイルの所有グループ
- 記号: g

#### 3. その他（Others）

- 所有者とグループ以外のユーザー
- 記号: o

#### 4. すべて（All）

- 所有者、グループ、その他すべて
- 記号: a

## 権限の表示

### ls コマンドでの権限確認

```bash
# 詳細情報でファイル一覧を表示
ls -l

# 特定のファイルの権限を確認
ls -l filename

# ディレクトリの権限を確認
ls -ld directory
```

### 権限表示の読み方

```
-rwxr-xr-x 1 user group 1024 Jan 15 10:30 filename
```

#### 各部分の説明

- **1 文字目**: ファイルタイプ（-: 通常ファイル、d: ディレクトリ、l: リンク）
- **2-4 文字目**: 所有者の権限（rwx）
- **5-7 文字目**: グループの権限（r-x）
- **8-10 文字目**: その他の権限（r-x）

### stat コマンドでの詳細確認

```bash
# ファイルの詳細情報を表示
stat filename

# 権限の数値表示
stat -c "%a %n" filename
```

## 権限の変更

### chmod コマンド

#### 記号モード

```bash
# 所有者に実行権限を追加
chmod u+x filename

# グループから書き込み権限を削除
chmod g-w filename

# その他に読み取り権限を設定
chmod o+r filename

# 複数の権限を同時に変更
chmod u+x,g-w,o+r filename

# すべてのユーザーに実行権限を追加
chmod a+x filename
```

#### 数値モード

```bash
# 権限を数値で設定
chmod 755 filename  # rwxr-xr-x
chmod 644 filename  # rw-r--r--
chmod 600 filename  # rw-------
chmod 777 filename  # rwxrwxrwx
```

#### 数値の計算方法

- **読み取り**: 4
- **書き込み**: 2
- **実行**: 1
- **合計**: 各権限の数値を足す

#### よく使用される権限設定

```bash
# 実行可能ファイル
chmod 755 script.sh    # rwxr-xr-x

# 設定ファイル
chmod 644 config.txt   # rw-r--r--

# 秘密ファイル
chmod 600 secret.txt   # rw-------

# 共有ディレクトリ
chmod 755 directory/   # rwxr-xr-x

# 一時ディレクトリ
chmod 777 temp/        # rwxrwxrwx
```

### 再帰的な権限変更

```bash
# ディレクトリとその中身の権限を変更
chmod -R 755 directory/

# 再帰的に実行権限を追加
chmod -R +x directory/
```

## 所有者の変更

### chown コマンド

```bash
# ファイルの所有者を変更
chown newowner filename

# 所有者とグループを同時に変更
chown newowner:newgroup filename

# グループのみ変更
chown :newgroup filename

# 再帰的に所有者を変更
chown -R newowner:newgroup directory/
```

### chgrp コマンド

```bash
# ファイルのグループを変更
chgrp newgroup filename

# 再帰的にグループを変更
chgrp -R newgroup directory/
```

## 特殊な権限

### スティッキービット（Sticky Bit）

```bash
# スティッキービットを設定
chmod +t directory/
chmod 1777 directory/

# スティッキービットの確認
ls -ld /tmp
```

### セットユーザー ID（SUID）

```bash
# SUIDを設定
chmod u+s filename
chmod 4755 filename

# SUIDの確認
ls -l /usr/bin/passwd
```

### セットグループ ID（SGID）

```bash
# SGIDを設定
chmod g+s filename
chmod 2755 filename

# SGIDの確認
ls -l filename
```

## デフォルト権限

### umask コマンド

```bash
# 現在のumask値を確認
umask

# umask値を設定
umask 022

# 新しいファイルの権限を計算
# 666 - 022 = 644 (rw-r--r--)
# 777 - 022 = 755 (rwxr-xr-x)
```

### umask の設定

```bash
# 一時的にumaskを設定
umask 027

# 永続的にumaskを設定（~/.bashrcに追加）
echo "umask 022" >> ~/.bashrc
```

## アクセス制御リスト（ACL）

### ACL の有効化

```bash
# ファイルシステムでACLを有効化
mount -o acl /dev/sda1 /mnt

# ファイルにACLを設定
setfacl -m u:username:rwx filename
setfacl -m g:groupname:r-x filename
```

### ACL の確認

```bash
# ACLを確認
getfacl filename

# デフォルトACLを設定
setfacl -d -m u:username:rwx directory/
```

## 実用的な権限設定例

### ウェブサーバーの設定

```bash
# ウェブディレクトリの権限設定
chmod 755 /var/www/html/
chown -R www-data:www-data /var/www/html/

# ウェブファイルの権限設定
chmod 644 /var/www/html/*.html
chmod 644 /var/www/html/*.css
chmod 644 /var/www/html/*.js
```

### ログファイルの設定

```bash
# ログファイルの権限設定
chmod 644 /var/log/syslog
chown root:adm /var/log/syslog

# ログディレクトリの権限設定
chmod 755 /var/log/
chown root:root /var/log/
```

### 設定ファイルの設定

```bash
# 設定ファイルの権限設定
chmod 600 /etc/ssh/sshd_config
chown root:root /etc/ssh/sshd_config

# 設定ディレクトリの権限設定
chmod 755 /etc/
chown root:root /etc/
```

## セキュリティのベストプラクティス

### ファイル権限の原則

1. **最小権限の原則**: 必要最小限の権限のみ付与
2. **定期的な監査**: 権限設定の定期的な確認
3. **ログの監視**: 権限関連のログを監視

### 危険な権限設定

```bash
# 避けるべき設定
chmod 777 filename    # すべてのユーザーが全権限
chmod 000 filename    # 誰もアクセスできない
chown root:root filename  # 不適切な所有者設定
```

### 安全な権限設定

```bash
# 推奨される設定
chmod 644 filename    # 所有者は読み書き、他は読み取りのみ
chmod 755 directory/  # ディレクトリは実行権限が必要
chmod 600 secret.txt  # 秘密ファイルは所有者のみ
```

## まとめ

権限管理は、Linux システムのセキュリティの基盤となる重要な機能です。適切な権限設定により、システムの安全性を確保し、データの保護を実現できます。chmod、chown、chgrp などのコマンドを適切に使用し、最小権限の原則に従って権限を設定することが重要です。定期的な権限の監査と適切なセキュリティ設定により、安全なシステム運用が可能になります。
