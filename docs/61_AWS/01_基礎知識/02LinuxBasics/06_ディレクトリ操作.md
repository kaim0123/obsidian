# ディレクトリ操作

## ディレクトリとは

**ディレクトリ（Directory）**は、ファイルや他のディレクトリを整理・格納するための特殊なファイルです。Windows のフォルダと同様の概念ですが、Linux ではすべてがファイルとして扱われます。

## ディレクトリ構造

### ルートディレクトリ（/）

```
/
├── bin/          # 基本的なコマンド
├── boot/         # ブートローダー
├── dev/          # デバイスファイル
├── etc/          # 設定ファイル
├── home/         # ユーザーホームディレクトリ
├── lib/          # ライブラリ
├── media/        # リムーバブルメディア
├── mnt/          # マウントポイント
├── opt/          # オプショナルソフトウェア
├── proc/         # プロセス情報
├── root/         # rootユーザーのホーム
├── run/          # 実行時データ
├── sbin/         # システム管理コマンド
├── srv/          # サービスデータ
├── sys/          # システム情報
├── tmp/          # 一時ファイル
├── usr/          # ユーザープログラム
└── var/          # 可変データ
```

## 基本的なディレクトリ操作

### 現在のディレクトリの確認

#### pwd コマンド

```bash
# 現在のディレクトリのパスを表示
pwd
```

### ディレクトリの移動

#### cd コマンド

```bash
# ホームディレクトリに移動
cd
cd ~

# ルートディレクトリに移動
cd /

# 親ディレクトリに移動
cd ..

# 前のディレクトリに戻る
cd -

# 絶対パスで移動
cd /home/user/documents

# 相対パスで移動
cd documents
cd ./documents
```

### ディレクトリの一覧表示

#### ls コマンド

```bash
# 現在のディレクトリの内容を表示
ls

# 詳細情報付きで表示
ls -l

# 隠しファイルも表示
ls -a

# 詳細情報と隠しファイルを表示
ls -la

# 人間が読みやすい形式でサイズ表示
ls -lh

# ディレクトリのみ表示
ls -d */

# 逆順で表示
ls -r

# 更新日時順で表示
ls -t
```

### ディレクトリの作成

#### mkdir コマンド

```bash
# ディレクトリを作成
mkdir directory_name

# 複数ディレクトリを作成
mkdir dir1 dir2 dir3

# 親ディレクトリも一緒に作成
mkdir -p parent/child/grandchild

# 権限を指定して作成
mkdir -m 755 directory_name
```

### ディレクトリの削除

#### rmdir コマンド

```bash
# 空のディレクトリを削除
rmdir directory_name

# 複数の空ディレクトリを削除
rmdir dir1 dir2 dir3
```

#### rm コマンド

```bash
# ディレクトリとその中身を削除
rm -r directory_name

# 確認なしで削除
rm -rf directory_name

# 確認付きで削除
rm -ri directory_name
```

## ディレクトリのコピー・移動

### cp コマンド

```bash
# ディレクトリを再帰的にコピー
cp -r source_dir destination_dir

# 詳細情報を表示しながらコピー
cp -rv source_dir destination_dir

# 上書き確認付きでコピー
cp -ri source_dir destination_dir
```

### mv コマンド

```bash
# ディレクトリを移動
mv source_dir destination_dir

# ディレクトリ名を変更
mv old_name new_name
```

## ディレクトリの検索

### find コマンド

```bash
# ディレクトリを検索
find /path -type d -name "directory_name"

# 現在のディレクトリ以下で検索
find . -type d -name "pattern"

# 最大深度を指定
find /path -maxdepth 2 -type d
```

### locate コマンド

```bash
# ディレクトリ名で検索
locate directory_name
```

## ディレクトリのサイズ確認

### du コマンド

```bash
# ディレクトリのサイズを表示
du directory_name

# 人間が読みやすい形式で表示
du -h directory_name

# サマリーのみ表示
du -sh directory_name

# すべてのサブディレクトリのサイズを表示
du -h --max-depth=1

# 現在のディレクトリのサイズ
du -sh .
```

## ディレクトリの権限

### 権限の確認

```bash
# ディレクトリの権限を確認
ls -ld directory_name

# 詳細な権限情報
stat directory_name
```

### 権限の変更

```bash
# ディレクトリの権限を変更
chmod 755 directory_name

# 再帰的に権限を変更
chmod -R 755 directory_name

# 所有者を変更
chown user:group directory_name

# 再帰的に所有者を変更
chown -R user:group directory_name
```

## 特殊なディレクトリ

### 現在のディレクトリ（.）

```bash
# 現在のディレクトリを参照
ls .
cd .
```

### 親ディレクトリ（..）

```bash
# 親ディレクトリを参照
ls ..
cd ..
```

### ホームディレクトリ（~）

```bash
# ホームディレクトリを参照
ls ~
cd ~
echo $HOME
```

## ディレクトリのマウント

### mount コマンド

```bash
# マウントポイントの確認
mount

# 特定のファイルシステムをマウント
sudo mount /dev/sdb1 /mnt/usb

# マウントを解除
sudo umount /mnt/usb
```

## ディレクトリのリンク

### シンボリックリンク

```bash
# シンボリックリンクを作成
ln -s target_directory link_name

# シンボリックリンクを確認
ls -l link_name

# シンボリックリンクを削除
rm link_name
```

### ハードリンク

```bash
# ハードリンクを作成（ディレクトリには使用不可）
ln target_file link_name
```

## ディレクトリの監視

### inotifywait コマンド

```bash
# ディレクトリの変更を監視
inotifywait -m directory_name

# 特定のイベントを監視
inotifywait -m -e create,delete directory_name
```

## まとめ

ディレクトリ操作は、Linux システムでのファイル管理の基盤です。階層構造を理解し、適切なディレクトリ構造を構築することで、効率的なファイル管理が可能になります。特に、絶対パスと相対パスの使い分け、権限管理、ディレクトリの作成・削除・移動などの基本操作は、日常的な作業で頻繁に使用されるため、しっかりとマスターしておくことが重要です。
