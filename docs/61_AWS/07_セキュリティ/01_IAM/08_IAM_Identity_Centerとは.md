# IAM Identity Center とは

## 概要

IAM Identity Center（旧 AWS SSO）は、AWS アカウントやクラウドアプリケーションへのシングルサインオンアクセスを管理する SSO（シングルサインオン）サービスです。複数のアカウントやアプリケーションへのアクセスを一元管理できます。

## 主な機能

### 1. SSO（シングルサインオン）サービス

- 一度のログインで複数のサービスにアクセス
- パスワードの管理負荷を軽減
- セキュリティの向上

### 2. 中央集権的なアクセス管理

- 複数 AWS アカウントの統合管理
- 外部アプリケーションとの連携
- ユーザーライフサイクルの管理

## 主要コンポーネント

### 1. IdP（ID プロバイダー）

- ユーザーの認証を行うサービス
- ユーザー情報の管理
- 認証方式の提供

#### サポートする IdP

- **AWS SSO**: AWS が提供する IdP
- **Active Directory**: オンプレミスの AD
- **外部 IdP**: SAML 2.0 対応の IdP
- **Google Workspace**: Google の IdP
- **Okta**: サードパーティの IdP

### 2. SP（サービスプロバイダー）

- ユーザーがアクセスするサービス
- IdP からの認証情報を受け取る
- リソースへのアクセスを制御

#### サポートする SP

- **AWS アカウント**: 複数の AWS アカウント
- **AWS アプリケーション**: AWS 管理コンソール
- **外部アプリケーション**: SAML 対応アプリ
- **カスタムアプリケーション**: 独自開発アプリ

## 認証フロー

### 1. 基本的な SSO フロー

1. ユーザーが SP にアクセス
2. SP が IdP にリダイレクト
3. IdP でユーザー認証
4. 認証成功後、SP に戻る
5. SP でリソースにアクセス

### 2. SAML 認証

- Security Assertion Markup Language
- XML ベースの認証プロトコル
- 業界標準の認証方式

## まとめ

IAM Identity Center は、複数の AWS アカウントやアプリケーションへのアクセスを一元管理できる強力なサービスです。適切に設定することで、セキュリティの向上と運用効率の改善を両立できます。外部 IdP との連携により、既存の認証システムとの統合も可能です。
