## 重要なポイント

### WAFの基本原則
- **段階的な導入**: Count → Block の順で実装
- **定期的な見直し**: ログ分析とルール最適化
- **パフォーマンス考慮**: ルール数の最適化

### 保護対象の攻撃
- SQLインジェクション攻撃
- クロスサイトスクリプティング（XSS）
- ボット攻撃
- DDoS攻撃

## 関連サービス

- **CloudFront**: CDNでの保護
- **Application Load Balancer**: ロードバランサーレベルでの保護
- **API Gateway**: APIエンドポイントの保護
