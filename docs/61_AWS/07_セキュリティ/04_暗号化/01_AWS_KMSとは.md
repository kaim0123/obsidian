# AWS KMS とは

## 概要

AWS KMS（Key Management Service）は、暗号化キーの作成と管理を容易にする暗号化鍵の管理サービスです。データの暗号化・復号化に必要な暗号化キーを安全に管理し、AWS サービスやアプリケーションで使用できます。

## 主な機能

### 1. 暗号化鍵の管理サービス

- 暗号化キーの作成・削除・無効化
- キーの使用権限の管理
- キーの使用履歴の監査
- ハードウェアセキュリティモジュール（HSM）での保護

### 2. 統合された暗号化

- AWS サービスとの自動統合
- アプリケーションでの簡単な使用
- 透過的な暗号化・復号化

## キーの種類

### 1. カスタマーマスターキー（CMK）

- ユーザーが作成・管理するキー
- データ暗号化キー（DEK）の暗号化に使用
- キーポリシーでアクセス制御

### 2. AWS 管理キー

- AWS が管理するキー
- 各サービス専用
- ユーザーは直接管理できない

### 3. AWS 所有キー

- AWS が所有・管理するキー
- サービス間での共有
- ユーザーは制御できない

## キーローテーション

### 1. 自動ローテーション

- 定期的なキーの自動更新
- セキュリティの向上
- コンプライアンス要件への対応

### 2. 手動ローテーション

- ユーザーが任意のタイミングで実行
- セキュリティインシデント時の対応
- 細かい制御が可能

### 3. ローテーションの仕組み

- 新しいキーマテリアルの生成
- 既存データの再暗号化
- 古いキーの段階的な削除

## キーマテリアル

### 1. AWS KMS 生成

- AWS が生成・管理
- ハードウェアセキュリティモジュールで保護
- 高いセキュリティレベル

### 2. 外部キーマテリアル

- ユーザーが外部で生成
- より細かい制御が可能
- コンプライアンス要件への対応

## 暗号化の種類

### 1. サーバーサイド暗号化（SSE）

- AWS サービス内での暗号化
- 透過的な暗号化・復号化
- パフォーマンスへの影響が少ない

#### SSE の種類

- **SSE-S3**: S3 が管理するキー
- **SSE-KMS**: KMS が管理するキー
- **SSE-C**: カスタマー提供キー

### 2. クライアントサイド暗号化（CSE）

- アプリケーション側での暗号化
- より高いセキュリティレベル
- 実装の複雑さが増す

## 実際の使用例

### 1. S3 での暗号化

- オブジェクトの暗号化
- バケットポリシーでの制御
- アクセスログの暗号化

### 2. RDS での暗号化

- データベースの暗号化
- スナップショットの暗号化
- バックアップの暗号化

### 3. EBS での暗号化

- ボリュームの暗号化
- スナップショットの暗号化
- パフォーマンスへの影響なし

## キーポリシー

### 1. 基本的な構造

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "Enable IAM User Permissions",
      "Effect": "Allow",
      "Principal": {
        "AWS": "arn:aws:iam::123456789012:root"
      },
      "Action": "kms:*",
      "Resource": "*"
    }
  ]
}
```

### 2. 主要な権限

- **kms:Encrypt**: 暗号化の実行
- **kms:Decrypt**: 復号化の実行
- **kms:GenerateDataKey**: データキーの生成
- **kms:DescribeKey**: キー情報の取得

### 1. アクセス制御

- キーポリシーでの制御
- 条件付きアクセス

### 2. 監査機能

- コンプライアンスレポート

- 複数リージョンでの冗長化

## ベストプラクティス

### 1. キー管理

- 最小権限の原則
- 定期的なキーローテーション
- 不要なキーの削除

### 2. セキュリティ

- 強力なキーポリシー
- アクセスログの監視
- 定期的な監査

### 3. コスト最適化

- 適切なキーの選択
- リクエスト数の最適化
- 不要なキーの削除

## 注意点

### 1. キーの削除

- 削除されたキーは復元不可能
- データの復号化ができなくなる
- 慎重な計画が必要

### 2. パフォーマンス

- 暗号化・復号化のオーバーヘッド
- ネットワークレイテンシー
- リクエスト制限

### 3. 制限事項

- リクエストレート制限
- キー数の制限
- リージョン間の制限

## まとめ

AWS KMS は、クラウド環境での暗号化を簡単かつ安全に実現する重要なサービスです。適切に設定することで、データの機密性と整合性を保護できます。キーの管理とアクセス制御を適切に行うことが、セキュアなシステム構築の鍵となります。
