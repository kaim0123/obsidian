# MOC_クラス設計体系

44_クラス設計・デザインパターン の入口ノート。**クラス（型・オブジェクト）単位で「責務をどう割り当て、どう関係づけ、どんな定石で解くか」**を扱う。骨格は Larman『実践UML』の流れ（GRASP で責務を割り当てる → 原則で確かめる → GoF パターンで解く）。パターンは refactoring.guru と同じ GoF の3分類（生成・構造・振る舞い）、アンチパターンは「コードの臭い → リファクタリング」の形で整理する。

フォルダは **テーマ別**、教材（旧 第01〜08部・全25章）を読む **学習順** は下の「学習順インデックス」で持つ。旧「デザインパターン単体教材」（6本）は 50・60 に統合した。

- ファイル名は各フォルダ内で **読む順に `01_` から連番**。本文には教材の章番号（第N章）を書かず、他ノートへの言及はリンクで行う
- 教材の元の章立て（第1〜25章）は [[010Programming/44_クラス設計・デザインパターン/00_全体像/目次|目次]] と下の学習順インデックスにだけ残す
