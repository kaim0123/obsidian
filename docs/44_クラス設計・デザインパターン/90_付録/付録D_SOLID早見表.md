# 付録D　SOLID 早見表

SOLID 5原則の一覧です。詳細は 40_SOLIDの適用 の各章と [[05_SOLIDの統合と判断]] を参照。

---

## 一覧

| 原則 | 略称 | 一言 | 章 |
|------|------|------|-----|
| 単一責任の原則 | **SRP** | 変化の理由は1つ | [[01_単一責任の原則]] |
| 開放閉鎖の原則 | **OCP** | 拡張に開き変更に閉じる | [[02_開放閉鎖の原則]] |
| リスコフの置換原則 | **LSP** | 子は親の代わりに使える | [[03_リスコフの置換原則]] |
| インターフェース分離の原則 | **ISP** | 使わないメソッドに依存しない | [[04_インターフェース分離の原則]] |
| 依存性逆転の原則 | **DIP** | 抽象に依存する | [[03_インターフェースと抽象化]] |

---

## 違反のサインと対策

| 原則 | 違反のサイン | 対策 |
|------|-------------|------|
| SRP | 5000行クラス、変更理由が複数 | Extract Class |
| OCP | 機能追加のたびに同じ switch を修正 | Strategy / 多態 |
| LSP | 子で親の使い方が壊れる | 継承やめ・合成 |
| ISP | 空実装・未サポート例外 | インターフェース分割 |
| DIP | ドメインが `MySql` を直接 new | Repository + 注入 |

---

## 適用の順序（目安）

```text
  SRP（分割）→ OCP/LSP（拡張と継承）→ ISP/DIP（接続）
```

[[05_SOLIDとの関係]] も参照。
