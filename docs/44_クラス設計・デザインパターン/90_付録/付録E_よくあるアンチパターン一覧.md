# 付録E　よくあるアンチパターン一覧

クラス設計で避けるべきアンチパターンの一覧です。詳細は [[01_アンチパターンとの見分け]] を参照。

---

## 構造系

| アンチパターン | 症状 | 対策 |
|---------------|------|------|
| **God Class / God Object** | 1クラスに全処理 | SRP + Extract Class |
| **スパゲッティ継承** | 深い階層・矛盾する override | 合成 + インターフェース |
| **循環依存** | A→B→A | インターフェース・イベントで切断 |
| **巨大インターフェース** | 10個以上のメソッド | ISP で分割 |

## ドメイン系

| アンチパターン | 症状 | 対策 |
|---------------|------|------|
| **貧血モデル** | エンティティはデータのみ | Move Method でドメインへ |
| **アナミックドメインモデル** | 同上（英語表記） | 同上 |
| **プライミティブ偏愛** | 金額を number のみ | 値オブジェクト（Money） |
| **魔法の数値・文字列** | `status === 3` | 列挙型・定数 |

## 生成・ライフサイクル系

| アンチパターン | 症状 | 対策 |
|---------------|------|------|
| **Singleton 乱用** | テスト困難・グローバル状態 | DI・スコープ限定 |
| **どこでも new** | 具象に散在依存 | Factory + Composition Root |
| **Service Locator** | 依存が隠れる | コンストラクタ注入 |

## 命名・組織系

| アンチパターン | 症状 | 対策 |
|---------------|------|------|
| **Utils / Helper 肥大** | 業務ロジックのゴミ箱 | ドメインクラスへ分配 |
| **Manager 乱立** | 責務不明 | ユビキタス言語で改名 |
| **Data / Info クラス** | 意味のない名前 | ドメイン名に |

---

## 脱出の基本フロー

```text
  1. テストで現状の振る舞いを固定
  2. 最も痛い責務を1つ選ぶ
  3. Extract Class / Move Method
  4. レビューで命名と境界を確認
```
