## 詳しい要約

**テーマ：1 台のサーバーで複数のコンピューターを動かす仮想化**

仮想化とはハードウェアをソフトウェアで模倣し、1 台の物理サーバー上に複数の仮想マシン（VM）を動かす技術である。ハイパーバイザーの役割と 2 つのタイプ、仮想化のメリットを解説するショート動画。

---

### なぜ仮想化するのか

- かつては 1 サーバーに 1 アプリ（メールは Windows、Web は Linux、DB は UNIX で計 3 台）
- サーバーの性能が高く、3 台とも 10% 程度しか使われず無駄が多い
- そこで 3 台分を 1 台にまとめる。これが**仮想化**

### VM とハイパーバイザー

- 中に作られる各マシンを**仮想マシン（VM）**と呼ぶ。VM はソフトウェア上のコンピューターで、実体は**ファイル**にすぎない
- VM ごとに別の OS を動かせ、互いに干渉しない。利用者からは実サーバーと区別がつかない
- VM を動かすソフトウェアが**ハイパーバイザー**。CPU・メモリ・ディスクを切り分けて各 VM に配る（例：メール用 VM に CPU 2 個とメモリを割り当て、OS とアプリを入れれば完成）
- コア数が足りなくても、時間を細かく区切って順番に少しずつ実行することで同時に動いているように見せる

### ハイパーバイザーの 2 タイプ

| タイプ | 設置場所 | 特徴・例 |
|---|---|---|
| **Type 1** | OS なしでハードウェアに直接 | 間に何もないので高速。データセンターの標準 |
| **Type 2** | Windows や Mac の上 | 手元の PC で別 OS を試す **VirtualBox** など |

- ただし境界は曖昧になっており、Linux の一部である **KVM** はどちらとも説明できる

### メリット

- マシン台数が減り、電気代や設置スペースが 1 台分で済む
- VM はファイルなので丸ごと持ち運べ、壊れても別マシンで再起動できる

### まとめ

- 仮想化＝1 つのソフトウェア（ハイパーバイザー）でハードウェアを貸し出す仕組み
- VM はファイルであり、集約・可搬性・復旧のしやすさが利点


**0:00** · How virtualization works: multiple computers running inside a single server. In the past, we only put one application on each server. Windows for mail, Linux for web, and UNIX for the database—three servers total. But servers are so powerful that most of their performance goes to waste. It's like having three boxes running at only 10%capacity. So, we consolidate those three into one. This is virtualization.

**0:23** · It is the technology of mimicking hardware with software. Each machine created inside is called a Virtual Machine, or VM. VMs are software-based computers, and in reality, they are just files. You can run a different OS on each VM, and they don't interfere with one another. From the user's perspective, they are indistinguishable from real servers. The software used to run this is called a hypervisor. It slices up and distributes CPU, memory, and disk space to the VMs. For example, the mail VM gets two CPUs and some memory. Once allocated, you install each OS and app, and you're done.

**0:52** · Even without enough cores, it runs because it divides time into tiny slices. It executes tasks little by little in order, appearing to run simultaneously.

**1:02** · There are two types of hypervisors.

**1:04** · Type 1 is installed directly on hardware without an OS. Since there's nothing in between, it's fast and a standard for data centers. Type 2 is installed on top of Windows or Mac.

**1:13** · VirtualBox, which you use to try another OS on your computer, is this type. However, this boundary is becoming less clear today. KVM is part of Linux and can be explained as either Type 1 or Type 2. The advantage is the reduction in the number of machines.

**1:26** · Electricity costs and space are limited to just one machine. And because VMs are just files, you can carry them around entirely. If one breaks, you just restart it on another machine.

**1:35** · Leasing out hardware through a single piece of software. That is virtualization. That was the true nature of virtualization.
