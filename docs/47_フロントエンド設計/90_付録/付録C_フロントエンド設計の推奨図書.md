## 学習のすすめ方

1. 『フロントエンドの知識地図』で全体の地図を持つ
2. [[00_フロントエンド設計の変遷]] で、各設計思想がどんな課題から生まれたかを押さえる
3. React ドキュメントの状態管理と Feature-Sliced Design / bulletproof-react で、状態とフォルダの置き方を決める
4. GreatFrontEnd の RADIO で、1 つの UI を最初から設計してみる
