# プロセス監視

## プロセスとは

**プロセス（Process）**は、実行中のプログラムのインスタンスです。Linux システムでは、すべての実行中のプログラムはプロセスとして管理され、固有のプロセス ID（PID）が割り当てられます。

## プロセスの基本概念

### プロセス ID（PID）

- 各プロセスに割り当てられる一意の番号
- 1 から始まり、システムの制限まで
- プロセス終了後は再利用される

### 親プロセスと子プロセス

- **親プロセス**: 他のプロセスを生成したプロセス
- **子プロセス**: 親プロセスから生成されたプロセス
- **init プロセス**: PID 1 の特別なプロセス（すべてのプロセスの祖先）

### プロセスの状態

- **実行中（Running）**: CPU を使用中
- **待機中（Waiting）**: リソースの待機中
- **停止中（Stopped）**: 一時停止中
- **ゾンビ（Zombie）**: 終了したが親プロセスが回収していない

## プロセスの表示

### ps コマンド

#### 基本的な使用方法

```bash
# 現在のシェルのプロセスを表示
ps

# すべてのプロセスを表示
ps aux

# 詳細情報付きで表示
ps -ef

# 特定のユーザーのプロセスを表示
ps -u username

# 特定のプロセスを表示
ps -p PID
```

#### ps コマンドの出力項目

```
USER       PID %CPU %MEM    VSZ   RSS TTY      STAT START   TIME COMMAND
root         1  0.0  0.1  19356  1544 ?        Ss   Jan01   0:01 /sbin/init
```

- **USER**: プロセスの所有者
- **PID**: プロセス ID
- **%CPU**: CPU 使用率
- **%MEM**: メモリ使用率
- **VSZ**: 仮想メモリサイズ
- **RSS**: 物理メモリサイズ
- **TTY**: 端末
- **STAT**: プロセス状態
- **START**: 開始時刻
- **TIME**: CPU 使用時間
- **COMMAND**: コマンド名

### top コマンド

```bash
# リアルタイムでプロセスを監視
top

# 特定のユーザーのプロセスのみ表示
top -u username

# 更新間隔を指定
top -d 5

# 特定のプロセスを監視
top -p PID
```

#### top コマンドの操作

- **q**: 終了
- **k**: プロセスを終了
- **r**: 優先度を変更
- **h**: ヘルプを表示
- **1**: CPU 使用率の詳細表示

### htop コマンド

```bash
# より見やすいプロセス監視
htop

# 特定のユーザーのプロセスのみ表示
htop -u username
```

## プロセスの検索

### pgrep コマンド

```bash
# プロセス名で検索
pgrep nginx

# プロセス名とPIDを表示
pgrep -l nginx

# 特定のユーザーのプロセスを検索
pgrep -u username nginx

# 完全一致で検索
pgrep -x nginx
```

### pidof コマンド

```bash
# プロセス名からPIDを取得
pidof nginx

# 複数のプロセスを検索
pidof nginx apache2
```

### pstree コマンド

```bash
# プロセスツリーを表示
pstree

# 特定のプロセスのツリーを表示
pstree -p PID

# ユーザー名を表示
pstree -u
```

## プロセスの制御

### kill コマンド

```bash
# プロセスを終了（SIGTERM）
kill PID

# 強制終了（SIGKILL）
kill -9 PID

# プロセス名で終了
killall nginx

# 特定のシグナルを送信
kill -HUP PID
```

### シグナルの種類

- **SIGTERM (15)**: 正常終了
- **SIGKILL (9)**: 強制終了
- **SIGHUP (1)**: 設定再読み込み
- **SIGINT (2)**: 割り込み（Ctrl+C）
- **SIGSTOP (19)**: 一時停止
- **SIGCONT (18)**: 再開

### nohup コマンド

```bash
# バックグラウンドで実行（ログアウト後も継続）
nohup command &

# 出力をファイルに保存
nohup command > output.log 2>&1 &
```

### jobs コマンド

```bash
# バックグラウンドジョブを表示
jobs

# ジョブをフォアグラウンドに戻す
fg %1

# ジョブをバックグラウンドで再開
bg %1
```

## システムリソースの監視

### free コマンド

```bash
# メモリ使用量を表示
free

# 人間が読みやすい形式で表示
free -h

# 継続的に監視
free -h -s 5
```

### vmstat コマンド

```bash
# システム統計を表示
vmstat

# 5秒間隔で表示
vmstat 5

# 10回表示
vmstat 5 10
```

### iostat コマンド

```bash
# I/O統計を表示
iostat

# 5秒間隔で表示
iostat 5

# 特定のデバイスのみ表示
iostat -x /dev/sda
```

### sar コマンド

```bash
# CPU使用率を表示
sar -u 1 5

# メモリ使用率を表示
sar -r 1 5

# ディスクI/Oを表示
sar -d 1 5
```

## プロセスの優先度

### nice コマンド

```bash
# 優先度を変更して実行
nice -n 10 command

# 優先度を確認
nice -n 0 command
```

### renice コマンド

```bash
# 実行中のプロセスの優先度を変更
renice 10 PID

# 特定のユーザーのプロセスを変更
renice 10 -u username
```

## プロセスの詳細情報

### /proc ファイルシステム

```bash
# プロセスの詳細情報を表示
cat /proc/PID/status

# プロセスのメモリマップを表示
cat /proc/PID/maps

# プロセスの環境変数を表示
cat /proc/PID/environ

# プロセスのコマンドラインを表示
cat /proc/PID/cmdline
```

### lsof コマンド

```bash
# プロセスが開いているファイルを表示
lsof -p PID

# 特定のファイルを使用しているプロセスを表示
lsof /var/log/syslog

# 特定のポートを使用しているプロセスを表示
lsof -i :80
```

## 実用的な監視例

### システム監視スクリプト

```bash
#!/bin/bash
# システム監視スクリプト

echo "=== システム情報 ==="
uptime
echo

echo "=== メモリ使用量 ==="
free -h
echo

echo "=== ディスク使用量 ==="
df -h
echo

echo "=== プロセス一覧（CPU使用率順） ==="
ps aux --sort=-%cpu | head -10
echo

echo "=== プロセス一覧（メモリ使用率順） ==="
ps aux --sort=-%mem | head -10
```

### ログ監視

```bash
# ログファイルを監視
tail -f /var/log/syslog | grep "ERROR"

# 複数のログファイルを監視
tail -f /var/log/syslog /var/log/auth.log
```

### プロセス監視

```bash
# 特定のプロセスを監視
while true; do
    if ! pgrep nginx > /dev/null; then
        echo "Nginx is not running!"
        systemctl start nginx
    fi
    sleep 60
done
```

## まとめ

プロセス監視は、Linux システムの運用において重要な機能です。ps、top、htop などのコマンドを使用して、システムの状態を把握し、問題のあるプロセスを特定・制御できます。適切な監視と制御により、システムの安定性とパフォーマンスを維持できます。定期的な監視と適切なリソース管理により、効率的なシステム運用が可能になります。
