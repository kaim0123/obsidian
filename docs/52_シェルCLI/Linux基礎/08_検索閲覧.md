# 検索閲覧

## 検索閲覧とは

Linux システムでは、**検索閲覧**はファイルやディレクトリ、テキストの内容を効率的に見つけるための重要な機能です。様々なコマンドとツールを使用して、目的の情報を素早く見つけることができます。

## ファイル・ディレクトリの検索

### find コマンド

#### 基本的な使用方法

```bash
# ファイル名で検索
find /path -name "filename"

# 現在のディレクトリ以下で検索
find . -name "*.txt"

# 大文字小文字を区別しない検索
find /path -iname "filename"

# ファイルタイプで検索
find /path -type f  # ファイルのみ
find /path -type d  # ディレクトリのみ
```

#### 高度な検索オプション

```bash
# ファイルサイズで検索
find /path -size +100M    # 100MB以上
find /path -size -1k      # 1KB未満
find /path -size 50M      # ちょうど50MB

# 更新日時で検索
find /path -mtime -7      # 7日以内に更新
find /path -mtime +30     # 30日以上前に更新
find /path -mmin -60      # 60分以内に更新

# 権限で検索
find /path -perm 755      # 権限755のファイル
find /path -perm -u+x     # 所有者に実行権限があるファイル

# 所有者で検索
find /path -user username
find /path -group groupname
```

#### 検索結果の処理

```bash
# 検索結果に対してコマンドを実行
find /path -name "*.txt" -exec ls -l {} \;

# 検索結果を削除
find /path -name "*.tmp" -delete

# 検索結果をファイルに保存
find /path -name "*.log" > logfiles.txt
```

### locate コマンド

#### 基本的な使用方法

```bash
# ファイル名で高速検索
locate filename

# パターンで検索
locate "*.txt"

# 大文字小文字を区別しない検索
locate -i filename

# 検索結果の数を制限
locate -n 10 filename
```

#### データベースの更新

```bash
# データベースを更新
sudo updatedb

# 特定のパスを除外して更新
sudo updatedb --prunepaths="/tmp /var/tmp"
```

### which コマンド

```bash
# コマンドの場所を検索
which ls
which python
which java

# すべての場所を表示
which -a python
```

### whereis コマンド

```bash
# コマンドの場所、マニュアル、ソースを検索
whereis ls
whereis python
whereis -b ls  # バイナリのみ
whereis -m ls  # マニュアルのみ
```

## テキスト内容の検索

### grep コマンド

#### 基本的な使用方法

```bash
# ファイル内で文字列を検索
grep "pattern" filename

# 複数ファイルで検索
grep "pattern" file1 file2

# ディレクトリ内のすべてのファイルで検索
grep -r "pattern" directory/

# 大文字小文字を区別しない検索
grep -i "pattern" filename

# 行番号を表示
grep -n "pattern" filename

# マッチした行の前後を表示
grep -A 3 -B 3 "pattern" filename
```

#### 高度な検索オプション

```bash
# 正規表現を使用
grep -E "pattern1|pattern2" filename

# 単語全体で検索
grep -w "word" filename

# マッチしない行を表示
grep -v "pattern" filename

# マッチしたファイル名のみ表示
grep -l "pattern" *.txt

# マッチした行数だけ表示
grep -c "pattern" filename

# バイナリファイルをスキップ
grep -I "pattern" filename
```

### egrep コマンド

```bash
# 拡張正規表現を使用
egrep "pattern1|pattern2" filename
egrep "pattern{3,5}" filename
```

### fgrep コマンド

```bash
# 固定文字列として検索（正規表現を無効化）
fgrep "pattern" filename
```

## ファイル内容の閲覧

### cat コマンド

```bash
# ファイルの内容を表示
cat filename

# 複数ファイルを連結して表示
cat file1 file2

# 行番号付きで表示
cat -n filename

# 非表示文字を表示
cat -A filename
```

### less コマンド

```bash
# ページ単位でファイルを表示
less filename

# 操作キー
# スペース: 次のページ
# b: 前のページ
# q: 終了
# /: 検索
# n: 次の検索結果
# N: 前の検索結果
# g: ファイルの先頭
# G: ファイルの末尾
```

### more コマンド

```bash
# ページ単位でファイルを表示（lessの簡易版）
more filename
```

### head コマンド

```bash
# ファイルの先頭10行を表示
head filename

# 先頭5行を表示
head -n 5 filename

# 先頭5行を表示（別の記法）
head -5 filename
```

### tail コマンド

```bash
# ファイルの末尾10行を表示
tail filename

# 末尾5行を表示
tail -n 5 filename

# リアルタイムで監視
tail -f filename

# 複数ファイルを監視
tail -f file1 file2
```

## 高度な検索・閲覧

### awk コマンド

```bash
# 特定の列を抽出
awk '{print $1}' filename

# 条件に基づいて行を抽出
awk '$3 > 100' filename

# 区切り文字を指定
awk -F',' '{print $1, $2}' filename
```

### sed コマンド

```bash
# 文字列を置換
sed 's/old/new/g' filename

# 特定の行を表示
sed -n '10,20p' filename

# 特定の行を削除
sed '10,20d' filename
```

### sort コマンド

```bash
# ファイルをソート
sort filename

# 数値でソート
sort -n filename

# 逆順でソート
sort -r filename

# 特定の列でソート
sort -k 2 filename
```

### uniq コマンド

```bash
# 重複行を除去
uniq filename

# 重複行の数を表示
uniq -c filename

# 重複行のみ表示
uniq -d filename
```

## 実用的な検索例

### ログファイルの検索

```bash
# エラーログを検索
grep -i "error" /var/log/syslog

# 特定の日付のログを検索
grep "2024-01-15" /var/log/syslog

# ログファイルを監視
tail -f /var/log/syslog | grep "ERROR"
```

### 設定ファイルの検索

```bash
# 設定ファイル内で特定の設定を検索
grep -r "Listen" /etc/apache2/

# コメント行を除外して検索
grep -v "^#" /etc/ssh/sshd_config
```

### プロセスの検索

```bash
# 実行中のプロセスを検索
ps aux | grep "nginx"

# プロセスIDを取得
pgrep nginx

# プロセス名を取得
pidof nginx
```

### ファイルの検索

```bash
# 大きなファイルを検索
find / -size +100M 2>/dev/null

# 最近更新されたファイルを検索
find . -mtime -1

# 特定の拡張子のファイルを検索
find . -name "*.log" -o -name "*.txt"
```

## 検索の最適化

### インデックスの活用

```bash
# locateデータベースを更新
sudo updatedb

# 特定のパスを除外
sudo updatedb --prunepaths="/tmp /var/tmp"
```

### 検索範囲の限定

```bash
# 特定のディレクトリのみ検索
find /home -name "*.txt"

# 特定のファイルタイプのみ検索
find . -type f -name "*.py"
```

### 並列処理

```bash
# 並列で検索
find . -name "*.txt" | xargs grep "pattern"
```

## まとめ

検索閲覧は、Linux システムでの効率的な情報管理の基盤です。find、grep、locate などのコマンドを適切に使い分けることで、目的の情報を素早く見つけることができます。特に、ログファイルの分析、設定ファイルの確認、システムの監視などの場面で、これらの検索機能は非常に有用です。検索の最適化とインデックスの活用により、より効率的な検索が可能になります。
