# vi と nano の基礎

## テキストエディタとは

Linux システムでは、**テキストエディタ（Text Editor）**は、ファイルの作成・編集を行うための基本的なツールです。vi と nano は、最も一般的に使用されるテキストエディタです。

## vi エディタ

### vi の特徴

- 軽量で高速
- すべての Linux システムに標準搭載
- キーボードのみで操作
- モードベースの操作

### vi のモード

#### コマンドモード（Command Mode）

- デフォルトのモード
- コマンドの入力
- ファイルの保存・終了

#### 挿入モード（Insert Mode）

- テキストの入力・編集
- コマンドモードから切り替え

#### ビジュアルモード（Visual Mode）

- テキストの選択
- コピー・切り取り・貼り付け

### vi の基本操作

#### vi の起動

```bash
# ファイルを開く
vi filename

# 新しいファイルを作成
vi newfile.txt

# 複数ファイルを開く
vi file1 file2 file3
```

#### モードの切り替え

```bash
# 挿入モードに切り替え
i    # カーソル位置に挿入
a    # カーソル位置の後に挿入
o    # 新しい行を作成して挿入
O    # 上の行に新しい行を作成して挿入

# コマンドモードに戻る
Esc
```

#### カーソルの移動

```bash
# 基本移動
h    # 左
j    # 下
k    # 上
l    # 右

# 単語移動
w    # 次の単語の先頭
b    # 前の単語の先頭
e    # 現在の単語の末尾

# 行移動
0    # 行の先頭
$    # 行の末尾
^    # 行の最初の非空白文字

# 画面移動
Ctrl+f    # 次のページ
Ctrl+b    # 前のページ
Ctrl+d    # 半ページ下
Ctrl+u    # 半ページ上
```

#### テキストの削除

```bash
# 文字の削除
x    # カーソル位置の文字を削除
X    # カーソル位置の前の文字を削除

# 単語の削除
dw   # 単語を削除
db   # 前の単語を削除

# 行の削除
dd   # 現在の行を削除
D    # カーソル位置から行末まで削除
```

#### コピー・切り取り・貼り付け

```bash
# コピー
yy   # 現在の行をコピー
yw   # 単語をコピー

# 切り取り
dd   # 現在の行を切り取り
dw   # 単語を切り取り

# 貼り付け
p    # カーソル位置の後に貼り付け
P    # カーソル位置の前に貼り付け
```

#### 検索・置換

```bash
# 検索
/pattern    # 前方検索
?pattern    # 後方検索
n           # 次の検索結果
N           # 前の検索結果

# 置換
:s/old/new/        # 現在の行の最初の一致を置換
:s/old/new/g       # 現在の行のすべての一致を置換
:%s/old/new/g      # ファイル全体の置換
```

#### ファイルの操作

```bash
# 保存
:w          # ファイルを保存
:w filename # 別名で保存

# 終了
:q          # 終了（変更なし）
:q!         # 強制終了（変更を破棄）
:wq         # 保存して終了
:x          # 保存して終了

# その他
:set number # 行番号を表示
:set nonumber # 行番号を非表示
```

## nano エディタ

### nano の特徴

- 初心者に優しい
- 直感的な操作
- ヘルプが表示される
- モードレス

### nano の基本操作

#### nano の起動

```bash
# ファイルを開く
nano filename

# 新しいファイルを作成
nano newfile.txt

# 複数ファイルを開く
nano file1 file2 file3
```

#### 基本的な操作

```bash
# カーソルの移動
Ctrl+f    # 右
Ctrl+b    # 左
Ctrl+n    # 下
Ctrl+p    # 上

# テキストの削除
Ctrl+h    # バックスペース
Ctrl+d    # 文字を削除
Ctrl+k    # 行を削除

# コピー・切り取り・貼り付け
Alt+6     # テキストをコピー
Ctrl+k    # テキストを切り取り
Ctrl+u    # テキストを貼り付け
```

#### 検索・置換

```bash
# 検索
Ctrl+w    # 検索
Ctrl+g    # 次の検索結果

# 置換
Ctrl+\    # 置換
```

#### ファイルの操作

```bash
# 保存
Ctrl+o    # ファイルを保存

# 終了
Ctrl+x    # 終了

# その他
Ctrl+c    # 現在の位置を表示
Alt+g     # 指定行に移動
```

## 実用的な例

### 設定ファイルの編集

#### vi での編集

```bash
# SSH設定ファイルを編集
sudo vi /etc/ssh/sshd_config

# 編集手順
# 1. iキーで挿入モードに切り替え
# 2. テキストを編集
# 3. Escキーでコマンドモードに戻る
# 4. :wqで保存して終了
```

#### nano での編集

```bash
# SSH設定ファイルを編集
sudo nano /etc/ssh/sshd_config

# 編集手順
# 1. 直接テキストを編集
# 2. Ctrl+oで保存
# 3. Ctrl+xで終了
```

### スクリプトの作成

#### vi でのスクリプト作成

```bash
# 新しいスクリプトを作成
vi myscript.sh

# 編集手順
# 1. iキーで挿入モードに切り替え
# 2. スクリプトを入力
# 3. Escキーでコマンドモードに戻る
# 4. :wqで保存して終了
```

#### nano でのスクリプト作成

```bash
# 新しいスクリプトを作成
nano myscript.sh

# 編集手順
# 1. 直接スクリプトを入力
# 2. Ctrl+oで保存
# 3. Ctrl+xで終了
```

## 高度な機能

### vi の高度な機能

#### マクロ

```bash
# マクロの記録
qa    # マクロ'a'の記録開始
# 操作を実行
q     # マクロの記録終了

# マクロの実行
@a    # マクロ'a'を実行
@@    # 最後のマクロを実行
```

#### 複数ファイルの編集

```bash
# 複数ファイルを開く
vi file1 file2 file3

# ファイル間の移動
:n    # 次のファイル
:N    # 前のファイル
:files # ファイル一覧を表示
```

#### 分割表示

```bash
# 水平分割
:split filename

# 垂直分割
:vsplit filename

# 分割間の移動
Ctrl+w w    # 次の分割に移動
Ctrl+w h    # 左の分割に移動
Ctrl+w j    # 下の分割に移動
Ctrl+w k    # 上の分割に移動
Ctrl+w l    # 右の分割に移動
```

### nano の高度な機能

#### 複数ファイルの編集

```bash
# 複数ファイルを開く
nano file1 file2 file3

# ファイル間の移動
Alt+>    # 次のファイル
Alt+<    # 前のファイル
```

#### 分割表示

```bash
# 水平分割
Alt+2    # 水平分割

# 垂直分割
Alt+1    # 垂直分割

# 分割間の移動
Alt+]    # 次の分割に移動
Alt+[    # 前の分割に移動
```

## トラブルシューティング

### 一般的な問題

#### vi での問題

```bash
# 挿入モードから抜けられない
Escキーを押す

# ファイルが保存できない
:w! filename    # 強制保存
:q!             # 強制終了
```

#### nano での問題

```bash
# ファイルが保存できない
Ctrl+o          # 保存
Ctrl+x          # 終了
```

### 設定のカスタマイズ

#### vi の設定

```bash
# .vimrcファイルを作成
vi ~/.vimrc

# 設定例
set number
set autoindent
set tabstop=4
set shiftwidth=4
set expandtab
```

#### nano の設定

```bash
# .nanorcファイルを作成
nano ~/.nanorc

# 設定例
set autoindent
set tabsize 4
set tabstospaces
set mouse
```

## まとめ

vi と nano は、Linux システムでのテキスト編集において重要なツールです。vi は軽量で高速、nano は初心者に優しいという特徴があります。基本的な操作をマスターすることで、効率的なファイル編集が可能になります。特に、設定ファイルの編集、スクリプトの作成、ログファイルの確認などの場面で、これらのエディタは非常に有用です。適切な設定とカスタマイズにより、より効率的な編集作業が可能になります。
