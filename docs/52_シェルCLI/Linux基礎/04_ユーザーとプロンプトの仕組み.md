# ユーザーとプロンプトの仕組み

## ユーザーとは

Linux システムでは、**ユーザー（User）**はシステムにアクセスするためのアカウントです。各ユーザーは固有のユーザー ID（UID）とグループ ID（GID）を持ち、システムリソースへのアクセス権限が管理されます。

## ユーザーの種類

### 1. スーパーユーザー（root）

- ユーザー ID: 0
- システム全体への完全なアクセス権限
- すべてのコマンドを実行可能
- 危険な操作も可能

### 2. システムユーザー

- ユーザー ID: 1-999（通常）
- システムサービス用のアカウント
- ログイン不可（通常）
- 例: `www-data`, `mysql`, `postgres`

### 3. 一般ユーザー

- ユーザー ID: 1000 以上
- 通常の作業用アカウント
- 制限された権限
- ログイン可能

## ユーザー情報の確認

### 現在のユーザー確認

```bash
# 現在のユーザー名を表示
whoami

# 現在のユーザーIDを表示
id

# 詳細なユーザー情報
id -a
```

### ユーザー情報ファイル

```bash
# ユーザー情報を表示
cat /etc/passwd

# パスワード情報（シャドウファイル）
sudo cat /etc/shadow

# グループ情報
cat /etc/group
```

## プロンプトとは

**プロンプト（Prompt）**は、シェルがユーザーの入力を待っている状態を示す表示です。通常、現在のユーザー名、ホスト名、現在のディレクトリなどの情報が表示されます。

## プロンプトの構成要素

### 基本的なプロンプト

```bash
user@hostname:~$
```

### 構成要素の説明

- `user`: 現在のユーザー名
- `@`: 区切り文字
- `hostname`: ホスト名（コンピュータ名）
- `:`: 区切り文字
- `~`: 現在のディレクトリ（~はホームディレクトリ）
- `$`: 一般ユーザーのプロンプト記号
- `#`: root ユーザーのプロンプト記号

## プロンプトのカスタマイズ

### PS1 環境変数

```bash
# 現在のプロンプト設定を確認
echo $PS1

# プロンプトをカスタマイズ
export PS1='\u@\h:\w\$ '

# より詳細なプロンプト
export PS1='[\u@\h \W]\$ '
```

### プロンプト記号の意味

- `\u`: ユーザー名
- `\h`: ホスト名
- `\w`: 現在のディレクトリのフルパス
- `\W`: 現在のディレクトリ名のみ
- `\$`: 一般ユーザーは$、root は#
- `\t`: 現在時刻
- `\d`: 現在の日付

## ホームディレクトリ

### ホームディレクトリとは

- 各ユーザーの個人用ディレクトリ
- 通常は `/home/ユーザー名`
- root ユーザーは `/root`

### ホームディレクトリの操作

```bash
# ホームディレクトリに移動
cd ~
cd $HOME

# ホームディレクトリのパスを表示
echo $HOME
echo ~

# ホームディレクトリの内容を表示
ls ~
ls $HOME
```

## ユーザー切り替え

### su コマンド

```bash
# rootユーザーに切り替え
su -

# 他のユーザーに切り替え
su - username

# 環境変数を保持して切り替え
su username
```

### sudo コマンド

```bash
# 管理者権限でコマンド実行
sudo command

# rootユーザーになる
sudo su -

# 他のユーザーになる
sudo su - username
```

## ユーザー管理

### ユーザーの作成

```bash
# 新しいユーザーを作成
sudo useradd -m -s /bin/bash username

# パスワードを設定
sudo passwd username

# ユーザーをグループに追加
sudo usermod -aG groupname username
```

### ユーザーの削除

```bash
# ユーザーを削除（ホームディレクトリも削除）
sudo userdel -r username

# ユーザーのみ削除（ホームディレクトリは残す）
sudo userdel username
```

## グループ管理

### グループの確認

```bash
# 現在のユーザーのグループ
groups

# 特定のユーザーのグループ
groups username

# グループ情報の詳細
id username
```

### グループの作成・削除

```bash
# 新しいグループを作成
sudo groupadd groupname

# グループを削除
sudo groupdel groupname
```

## セッション管理

### ログイン情報の確認

```bash
# 現在ログインしているユーザー
who

# 詳細なログイン情報
w

# ログイン履歴
last

# 現在のセッション情報
loginctl show-session
```

### セッションの終了

```bash
# 現在のセッションを終了
exit

# 強制終了
logout

# 他のユーザーのセッションを終了
sudo pkill -u username
```

## まとめ

ユーザーとプロンプトは、Linux システムの基本的な概念です。ユーザー管理により、システムのセキュリティとアクセス制御が実現されます。プロンプトは、現在の状態を視覚的に示し、効率的な作業を支援します。これらの理解は、安全で効率的なシステム運用の基盤となります。
