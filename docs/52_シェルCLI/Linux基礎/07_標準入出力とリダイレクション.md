# 標準入出力とリダイレクション

## 標準入出力とは

Linux システムでは、すべてのプロセスが**標準入出力（Standard I/O）**を持っています。これらは、プログラムと外部環境とのデータのやり取りを管理するための仕組みです。

## 標準入出力の種類

### 1. 標準入力（stdin）

- **ファイルディスクリプタ**: 0
- プログラムへの入力データの流れ
- 通常はキーボードからの入力

### 2. 標準出力（stdout）

- **ファイルディスクリプタ**: 1
- プログラムからの出力データの流れ
- 通常は画面（ターミナル）への表示

### 3. 標準エラー出力（stderr）

- **ファイルディスクリプタ**: 2
- エラーメッセージの出力
- 通常は画面（ターミナル）への表示

## リダイレクションとは

**リダイレクション（Redirection）**は、標準入出力の流れを変更する機能です。ファイルや他のコマンドにデータの流れを向けることができます。

## 出力のリダイレクション

### 標準出力のリダイレクション

#### > 演算子（上書き）

```bash
# 標準出力をファイルに保存（上書き）
ls -la > filelist.txt

# コマンドの結果をファイルに保存
date > current_date.txt

# 複数行の出力をファイルに保存
echo "Line 1" > output.txt
echo "Line 2" > output.txt  # 上書きされる
```

#### >> 演算子（追加）

```bash
# 標準出力をファイルに追加
ls -la >> filelist.txt

# 複数行の出力を追加
echo "Line 1" >> output.txt
echo "Line 2" >> output.txt  # 追加される
```

### 標準エラー出力のリダイレクション

#### 2> 演算子

```bash
# エラー出力をファイルに保存
command 2> error.log

# エラー出力を破棄
command 2> /dev/null
```

#### 2>> 演算子

```bash
# エラー出力をファイルに追加
command 2>> error.log
```

### 標準出力と標準エラー出力の同時リダイレクション

#### &> 演算子

```bash
# 標準出力とエラー出力を同じファイルに保存
command &> output.log

# 標準出力とエラー出力を破棄
command &> /dev/null
```

#### 個別にリダイレクション

```bash
# 標準出力とエラー出力を別々のファイルに保存
command > output.log 2> error.log

# 標準出力をファイルに、エラー出力を画面に表示
command > output.log

# 標準出力を画面に、エラー出力をファイルに
command 2> error.log
```

## 入力のリダイレクション

### < 演算子

```bash
# ファイルの内容を標準入力として使用
sort < input.txt

# ファイルの内容をコマンドに渡す
wc -l < data.txt

# 複数行の入力をコマンドに渡す
cat << EOF
Line 1
Line 2
Line 3
EOF
```

### << 演算子（ヒアドキュメント）

```bash
# ヒアドキュメントの使用
cat << EOF > output.txt
This is line 1
This is line 2
This is line 3
EOF
```

## パイプ（Pipe）

### | 演算子

```bash
# コマンドの出力を次のコマンドの入力に渡す
ls -la | grep "txt"

# 複数のコマンドを連結
ps aux | grep "apache" | wc -l

# ソートして重複を除去
sort file.txt | uniq
```

### パイプの例

```bash
# プロセス一覧から特定のプロセスを検索
ps aux | grep "nginx"

# ファイルの行数をカウント
cat file.txt | wc -l

# ログファイルからエラーを抽出
tail -f /var/log/syslog | grep "ERROR"
```

## 高度なリダイレクション

### ファイルディスクリプタの操作

#### 標準出力を標準エラー出力にリダイレクト

```bash
# 標準出力を標準エラー出力に送る
command >&2

# 標準エラー出力を標準出力に送る
command 2>&1
```

#### ファイルディスクリプタの複製

```bash
# 標準出力をファイルに保存し、同時に画面にも表示
command | tee output.txt

# 標準出力とエラー出力を両方保存
command 2>&1 | tee output.log
```

### プロセス置換

#### <() 構文

```bash
# 2つのファイルを比較
diff <(sort file1.txt) <(sort file2.txt)

# コマンドの出力をファイルとして扱う
grep "pattern" <(find . -name "*.txt")
```

## 実用的な例

### ログファイルの処理

```bash
# ログファイルからエラーを抽出してファイルに保存
grep "ERROR" /var/log/syslog > errors.txt

# ログファイルを監視してエラーを表示
tail -f /var/log/syslog | grep "ERROR"

# ログファイルの行数をカウント
wc -l < /var/log/syslog
```

### データの処理

```bash
# ファイルの内容をソートして重複を除去
sort data.txt | uniq > unique_data.txt

# ファイルの行数をカウント
cat file.txt | wc -l

# ファイルの単語数をカウント
cat file.txt | wc -w
```

### システム監視

```bash
# プロセス一覧をファイルに保存
ps aux > processes.txt

# ディスク使用量をファイルに保存
df -h > disk_usage.txt

# メモリ使用量を監視
free -m | grep "Mem"
```

## エラーハンドリング

### エラー出力の処理

```bash
# エラーを無視
command 2>/dev/null

# エラーをログファイルに保存
command 2>> error.log

# エラーと出力を分離
command > output.log 2> error.log
```

### 終了コードの確認

```bash
# 前のコマンドの終了コードを確認
echo $?

# 終了コードに基づく処理
command && echo "Success" || echo "Failed"
```

## まとめ

標準入出力とリダイレクションは、Linux システムでのデータ処理の基盤となる重要な概念です。これらの機能を活用することで、コマンドの出力を効率的に処理し、複雑なデータ処理パイプラインを構築できます。特に、ログファイルの処理、データの変換、システム監視などの場面で、これらの機能は非常に有用です。
