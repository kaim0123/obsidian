# ファイル操作

## ファイルとは

Linux システムでは、**ファイル（File）**はデータを保存するための基本的な単位です。テキストファイル、バイナリファイル、設定ファイルなど、様々な種類のファイルが存在します。

## ファイルの種類

### 1. 通常ファイル（Regular File）

- テキストファイル
- バイナリファイル
- データファイル

### 2. ディレクトリ（Directory）

- ファイルやディレクトリを格納する特殊なファイル
- フォルダのような概念

### 3. シンボリックリンク（Symbolic Link）

- 他のファイルやディレクトリへの参照
- ショートカットのような概念

### 4. デバイスファイル

- ハードウェアデバイスへのアクセス用
- ブロックデバイス、キャラクターデバイス

## 基本的なファイル操作

### ファイルの表示

#### cat コマンド

```bash
# ファイルの内容を表示
cat filename

# 複数ファイルを連結して表示
cat file1 file2

# 行番号付きで表示
cat -n filename
```

#### less コマンド

```bash
# ページ単位でファイルを表示
less filename

# 操作キー
# スペース: 次のページ
# b: 前のページ
# q: 終了
# /: 検索
```

#### head コマンド

```bash
# ファイルの先頭10行を表示
head filename

# 先頭5行を表示
head -n 5 filename
```

#### tail コマンド

```bash
# ファイルの末尾10行を表示
tail filename

# 末尾5行を表示
tail -n 5 filename

# リアルタイムで監視
tail -f filename
```

### ファイルの作成

#### touch コマンド

```bash
# 空のファイルを作成
touch filename

# 複数ファイルを作成
touch file1 file2 file3

# タイムスタンプを更新
touch filename
```

#### echo コマンド

```bash
# ファイルに内容を書き込み
echo "Hello World" > filename

# ファイルに内容を追加
echo "New line" >> filename
```

### ファイルのコピー

#### cp コマンド

```bash
# ファイルをコピー
cp source destination

# 複数ファイルをコピー
cp file1 file2 destination/

# ディレクトリを再帰的にコピー
cp -r source_dir destination_dir

# 詳細情報を表示
cp -v source destination

# 上書き確認
cp -i source destination
```

### ファイルの移動・リネーム

#### mv コマンド

```bash
# ファイルを移動
mv source destination

# ファイル名を変更
mv oldname newname

# 複数ファイルを移動
mv file1 file2 destination/

# 上書き確認
mv -i source destination
```

### ファイルの削除

#### rm コマンド

```bash
# ファイルを削除
rm filename

# 複数ファイルを削除
rm file1 file2 file3

# 確認なしで削除
rm -f filename

# ディレクトリを再帰的に削除
rm -r directory

# 強制削除
rm -rf directory
```

## ファイルの検索

### find コマンド

```bash
# ファイル名で検索
find /path -name "filename"

# 拡張子で検索
find /path -name "*.txt"

# ファイルサイズで検索
find /path -size +100M

# 更新日時で検索
find /path -mtime -7

# ファイルタイプで検索
find /path -type f
```

### locate コマンド

```bash
# ファイル名で高速検索
locate filename

# データベースを更新
sudo updatedb
```

## ファイルの比較

### diff コマンド

```bash
# 2つのファイルを比較
diff file1 file2

# 統一形式で比較
diff -u file1 file2

# サイドバイサイドで比較
diff -y file1 file2
```

### cmp コマンド

```bash
# バイナリファイルを比較
cmp file1 file2
```

## ファイルの圧縮・展開

### gzip/gunzip

```bash
# ファイルを圧縮
gzip filename

# ファイルを展開
gunzip filename.gz
```

### tar コマンド

```bash
# アーカイブを作成
tar -cf archive.tar file1 file2

# アーカイブを展開
tar -xf archive.tar

# gzip圧縮付きでアーカイブ
tar -czf archive.tar.gz directory/

# gzip圧縮付きで展開
tar -xzf archive.tar.gz
```

## ファイルの権限

### 権限の確認

```bash
# ファイルの詳細情報を表示
ls -l filename

# 権限の詳細
stat filename
```

### 権限の変更

```bash
# 所有者に実行権限を追加
chmod u+x filename

# 数値で権限を設定
chmod 755 filename

# 所有者を変更
chown user:group filename
```

## ファイルの属性

### ファイルタイプの確認

```bash
# ファイルタイプを表示
file filename

# 詳細な情報を表示
file -i filename
```

### ファイルサイズの確認

```bash
# ファイルサイズを表示
ls -lh filename

# ディスク使用量を表示
du -h filename

# ディレクトリのサイズ
du -sh directory/
```

## まとめ

ファイル操作は、Linux システムの基本的な操作の一つです。これらのコマンドをマスターすることで、効率的にファイルを管理し、システムを操作できるようになります。特に、ファイルの表示、作成、コピー、移動、削除の基本操作は、日常的な作業で頻繁に使用されるため、しっかりと理解しておくことが重要です。
