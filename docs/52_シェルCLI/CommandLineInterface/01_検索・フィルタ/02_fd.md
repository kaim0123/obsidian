# fd - モダンなファイル検索ツール

## 概要

**fd**は、`find`コマンドのモダンな代替ツールです。Rustで書かれており、**直感的な構文**、**高速な検索**、**賢いデフォルト設定**が特徴です。findの複雑なオプションを覚える必要がなく、シンプルにファイルを見つけることができます。

### fdの特徴

- **シンプルな構文**: `fd パターン` だけで検索できる
- **高速**: 並列処理による高速なディレクトリ走査
- **スマートなデフォルト**: `.gitignore`を尊重、隠しファイルをスキップ
- **カラー出力**: ファイルタイプに応じた色分け表示
- **正規表現サポート**: デフォルトで正規表現が使える
- **Unicode対応**: 日本語ファイル名も問題なく検索

## インストール

```bash
# macOS（Homebrew）
brew install fd

# Ubuntu / Debian
sudo apt install fd-find
# ※ コマンド名は fdfind になる場合がある。エイリアスを設定:
# alias fd='fdfind'

# Arch Linux
pacman -S fd

# Windows（Scoop）
scoop install fd

# Windows（Chocolatey）
choco install fd

# Cargo（Rust）
cargo install fd-find
```

バージョン確認:

```bash
fd --version
```

## 基本的な使い方

### パターンによる検索

```bash
# ファイル名に "test" を含むファイルを検索
fd test

# 現在のディレクトリ以下すべてが対象（デフォルト）
# 大文字小文字は自動判定（スマートケース）

# 特定のディレクトリを検索
fd test src/

# 完全一致ではなく部分一致（デフォルト）
fd mod
# → module.ts, data_model.py, README.md など
```

### パターンなしで全ファイル一覧

```bash
# すべてのファイルを一覧表示（lsの再帰版のように使える）
fd

# 特定のディレクトリ配下の全ファイル
fd . src/
```

## よく使うオプション

### ファイルタイプの絞り込み

| オプション | 説明 | 例 |
|-----------|------|-----|
| `-e EXT` | 拡張子で絞り込み | `fd -e py` |
| `-t f` | ファイルのみ | `fd -t f` |
| `-t d` | ディレクトリのみ | `fd -t d` |
| `-t l` | シンボリックリンクのみ | `fd -t l` |
| `-t x` | 実行可能ファイルのみ | `fd -t x` |
| `-t e` | 空のファイル/ディレクトリ | `fd -t e` |

```bash
# Pythonファイルのみ検索
fd -e py

# 複数の拡張子を指定
fd -e js -e ts -e tsx

# ディレクトリのみ検索
fd -t d node_modules

# 拡張子 + パターンの組み合わせ
fd -e md readme
```

### 検索範囲の制御

| オプション | 説明 | 例 |
|-----------|------|-----|
| `-d N` / `--max-depth N` | 最大深度を指定 | `fd -d 2` |
| `--min-depth N` | 最小深度を指定 | `fd --min-depth 2` |
| `-H` / `--hidden` | 隠しファイルも検索 | `fd -H .bashrc` |
| `-I` / `--no-ignore` | .gitignoreを無視 | `fd -I node_modules` |
| `-u` | 隠しファイル + ignore無視 | `fd -u` |
| `-E PATTERN` / `--exclude` | パターンを除外 | `fd -E node_modules` |

```bash
# 深さ1（直下のファイルのみ）
fd -d 1

# 隠しファイルを含めて検索
fd -H .env

# node_modules を除外して検索
fd -E node_modules -E dist -e ts

# 複数の除外パターン
fd -E '*.min.js' -E '*.map' -e js
```

### 時間による絞り込み

```bash
# 最近1日以内に変更されたファイル
fd --changed-within 1d

# 1週間以内に変更されたPythonファイル
fd -e py --changed-within 1w

# 30分以内に変更されたファイル
fd --changed-within 30m

# 1ヶ月以上前に変更されたファイル
fd --changed-before 1month
```

### サイズによる絞り込み

```bash
# 1MB以上のファイル
fd --size +1m

# 100KB未満のファイル
fd --size -100k

# 空のファイル
fd -t e
```

### 出力の制御

```bash
# フルパスで表示
fd -a test

# null区切りで出力（xargsの-0オプションと組み合わせ）
fd -0 -e py

# カラー出力を無効化
fd --color never

# 1つだけ見つかったら終了
fd -1 "pattern"
```

## 正規表現によるファイル検索

fdはデフォルトで**正規表現**をサポートしています:

```bash
# 数字で始まるファイル
fd '^\d'

# test_ で始まる Python ファイル
fd '^test_' -e py

# v1, v2, v3 ... のパターン
fd 'v\d+' -e md

# アンダースコアを含むファイル（ただしキャメルケースのものは除外）
fd '_[a-z]'

# 日付形式のファイル名（YYYY-MM-DD）
fd '\d{4}-\d{2}-\d{2}'
```

### リテラル検索（正規表現を無効化）

```bash
# -F / --fixed-strings で正規表現を無効化
fd -F "file[1].txt"
fd -F "config.yaml"
```

### 大文字・小文字の制御

```bash
# 大文字小文字を無視（デフォルトはスマートケース）
fd -i "readme"

# 大文字小文字を区別
fd -s "README"
```

## コマンドの実行（-x / -X）

fdの強力な機能の一つが、検索結果に対してコマンドを実行する機能です:

### -x（各ファイルに対して個別実行）

```bash
# 見つかったファイルを個別に処理
fd -e py -x wc -l     # 各Pythonファイルの行数を表示

# プレースホルダーの使用
# {} = フルパス
# {.} = 拡張子なしのパス
# {/} = ファイル名のみ
# {//} = ディレクトリパスのみ
# {/.} = 拡張子なしのファイル名

# .jpg を .png にリネーム
fd -e jpg -x mv {} {.}.png

# 各ファイルの情報を表示
fd -e log -x echo "File: {/}, Dir: {//}"
```

### -X（すべてのファイルを一括で渡す）

```bash
# すべてのマッチを一度にコマンドに渡す
fd -e py -X wc -l      # 全Pythonファイルの行数を一括表示

# 見つかったファイルを一括削除（注意！）
fd -e tmp -X rm

# 見つかったファイルをtar.gzに固める
fd -e log -X tar czf logs.tar.gz
```

## findとの比較

### 基本操作の比較

```bash
# ファイル名で検索
find . -name "*.py"              →  fd -e py
find . -iname "*test*"           →  fd -i test

# ディレクトリのみ
find . -type d -name "src"       →  fd -t d src

# 深さ制限
find . -maxdepth 2 -name "*.js"  →  fd -d 2 -e js

# 空のファイル
find . -empty                    →  fd -t e

# 最近変更されたファイル
find . -mtime -1                 →  fd --changed-within 1d

# コマンド実行
find . -name "*.py" -exec wc -l {} \;   →  fd -e py -x wc -l
find . -name "*.py" -exec wc -l {} +    →  fd -e py -X wc -l
```

### 比較表

| 特徴 | find | fd |
|------|------|----|
| 構文 | 複雑（`-name`, `-type` 等） | シンプル（`fd パターン`） |
| 速度 | 普通 | 高速（並列処理） |
| .gitignore | 非対応 | 自動尊重 |
| 隠しファイル | デフォルトで含む | デフォルトでスキップ |
| カラー出力 | なし | あり |
| 正規表現 | `-regex`オプション | デフォルト |
| Unicode | 限定的 | 完全対応 |
| 可搬性 | どこでもある | インストール必要 |

## 他のコマンドとの組み合わせ

### fd + xargs

```bash
# 見つかったファイルをgrepで検索
fd -e py | xargs grep "import"

# null区切りで安全に処理（ファイル名にスペースがある場合）
fd -0 -e py | xargs -0 grep "import"
```

### fd + fzf

```bash
# fzfでインタラクティブにファイルを選択
fd -t f | fzf

# fzfで選択したファイルをエディタで開く
fd -t f | fzf | xargs code

# fzfのデフォルトコマンドにfdを設定
export FZF_DEFAULT_COMMAND='fd --type f --hidden --follow --exclude .git'
```

### fd + rg

```bash
# fdでファイルを見つけて、rgで中身を検索
fd -e py -X rg "def main"

# 特定のディレクトリ構造のファイルのみrgで検索
fd -e ts --search-path src/components | xargs rg "useState"
```

### fd + bat

```bash
# 見つかったファイルの中身をbatで表示
fd -e md -x bat {}

# fzfのプレビューにbatを使用
fd -t f | fzf --preview 'bat --color=always {}'
```

## 実践的な使用例

```bash
# プロジェクト内の設定ファイルを一覧
fd -e yaml -e yml -e json -e toml -e ini

# 大きなファイルを見つける（10MB以上）
fd --size +10m

# 古いログファイルを見つける（30日以上前）
fd -e log --changed-before 30d

# テストファイルを探す
fd 'test|spec' -e ts -e js

# node_modules 以外の package.json を探す
fd -E node_modules package.json

# Dockerfileを探す
fd -g 'Dockerfile*'

# 空のディレクトリを探す
fd -t e -t d

# 特定のパターンのファイルを一括リネーム
fd -e txt -x mv {} {.}.md

# 最近1時間以内に変更されたソースファイル
fd -e ts -e tsx --changed-within 1h

# バックアップファイル（.bak, ~）を探す
fd -H '(\.bak$|~$)'
```

---

## まとめ

- **fd**はfindの直感的で高速な代替ツール
- `fd パターン`のシンプルな構文で、findの複雑なオプションから解放される
- `-e`（拡張子）、`-t`（タイプ）、`-d`（深さ）の3つが基本
- `-x` / `-X`でコマンド実行もfindより簡潔
- fzf、rg、batなど他のモダンツールとの相性が抜群
