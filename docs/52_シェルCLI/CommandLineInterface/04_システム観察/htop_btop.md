# htop / btop - システムモニタリング

## 概要

**htop**と**btop**は、システムのCPU、メモリ、プロセスの状態をリアルタイムで監視するためのインタラクティブなツールです。従来の`top`コマンドを大幅に改良し、より見やすく操作しやすくなっています。

### なぜプロセス監視が必要か

- **高負荷プロセスの特定**: CPUやメモリを大量に消費しているプロセスを見つける
- **メモリリークの発見**: メモリ使用量が時間とともに増加しているプロセスを特定
- **システムの健全性確認**: 全体的なリソース使用状況を把握
- **プロセスの管理**: 不要なプロセスの停止（kill）

---

## top（従来のツール）

### topとは

**top**はほぼすべてのUnix/Linuxシステムにプリインストールされているプロセスモニターです。

```bash
# topの起動
top

# 基本的な操作
# q: 終了
# k: プロセスをkill
# M: メモリ順にソート
# P: CPU順にソート
# 1: 各CPUコアの個別表示
```

topは機能的には十分ですが、操作性や視認性の面でhtop/btopに大きく劣ります。

---

## htop

### htopとは

**htop**は、topの改良版として開発されたインタラクティブなプロセスビューアです。カラー表示、マウス操作、プロセスのツリー表示など、多くの改善がなされています。

### インストール

```bash
# macOS（Homebrew）
brew install htop

# Ubuntu / Debian
sudo apt install htop

# Arch Linux
pacman -S htop

# Windows（WSL内で使用）
sudo apt install htop
```

### 画面構成

htopの画面は大きく3つの部分に分かれています:

```
┌─────────────────────────────────────────────┐
│ CPU [||||||||||||      45%]  Mem [||||||  3.2G/16G] │  ← ヘッダー（リソース使用状況）
│ CPU [||||||           28%]  Swp [|       0.5G/8G]  │
├─────────────────────────────────────────────┤
│  PID USER    PRI NI  VIRT   RES   SHR S CPU% MEM% │  ← プロセスリスト
│  1234 user   20  0  1.2G  256M  64M  S 12.5  1.6  │
│  5678 root   20  0  512M  128M  32M  S  8.3  0.8  │
│  ...                                                │
├─────────────────────────────────────────────┤
│ F1Help F2Setup F3Search F4Filter F5Tree F6Sort ... │  ← フッター（操作ガイド）
└─────────────────────────────────────────────┘
```

#### ヘッダー部分

- **CPUバー**: 各CPUコアの使用率をバーで表示。色分けは:
  - 緑: ユーザープロセス
  - 赤: カーネルプロセス
  - 青: 優先度の低いプロセス
- **Memバー**: メモリ使用量
- **Swpバー**: スワップ使用量

#### プロセスリスト

| 列 | 説明 |
|----|------|
| PID | プロセスID |
| USER | 実行ユーザー |
| PRI | 優先度 |
| NI | Nice値 |
| VIRT | 仮想メモリ |
| RES | 物理メモリ |
| SHR | 共有メモリ |
| S | 状態（S:スリープ、R:実行中、Z:ゾンビ） |
| CPU% | CPU使用率 |
| MEM% | メモリ使用率 |
| TIME+ | CPU使用時間 |
| Command | コマンド名 |

### 操作方法

#### 基本操作

| キー | 動作 |
|------|------|
| `↑` / `↓` | プロセスの選択 |
| `q` / `F10` | 終了 |
| `Space` | プロセスにタグ付け（複数選択） |
| `Enter` | プロセスの詳細を展開 |

#### ソート

| キー | 動作 |
|------|------|
| `F6` / `>` | ソート列の選択 |
| `P` | CPU使用率でソート |
| `M` | メモリ使用率でソート |
| `T` | CPU時間でソート |
| `I` | ソート順を反転 |

#### 検索・フィルタ

| キー | 動作 |
|------|------|
| `F3` / `/` | プロセス名で検索 |
| `F4` / `\` | プロセス名でフィルタ（マッチしないものを非表示） |

#### プロセスの管理

| キー | 動作 |
|------|------|
| `F9` / `k` | プロセスにシグナルを送信（kill） |
| `F7` / `]` | Nice値を下げる（優先度を上げる） |
| `F8` / `[` | Nice値を上げる（優先度を下げる） |

#### 表示の切り替え

| キー | 動作 |
|------|------|
| `F5` / `t` | ツリー表示の切り替え |
| `H` | ユーザースレッドの表示/非表示 |
| `K` | カーネルスレッドの表示/非表示 |
| `u` | 特定ユーザーのプロセスだけ表示 |
| `F2` | セットアップ画面（カスタマイズ） |

### カスタマイズ（F2 Setup）

`F2`キーで以下の設定が可能:

- **Meters**: ヘッダーに表示するメーター（CPU、メモリ、Load Average、Uptimeなど）
- **Display Options**: 表示オプション（ツリー表示、スレッド表示など）
- **Colors**: カラースキーム
- **Columns**: プロセスリストに表示する列

## btop

### btopとは

**btop++**は、htopの次世代版とも言える高機能なシステムモニターです。CPU、メモリ、ディスク、ネットワーク、GPUの情報を美しいUIで一覧表示します。

### インストール

```bash
# macOS（Homebrew）
brew install btop

# Ubuntu / Debian
sudo apt install btop

# Arch Linux
pacman -S btop

# snap
sudo snap install btop
```

### btopの特徴

htopと比較したbtopの追加機能:

- **ネットワーク監視**: アップロード/ダウンロード速度のリアルタイムグラフ
- **ディスクI/O監視**: ディスクの読み書き速度
- **GPU監視**: GPU使用率、温度、メモリ（対応GPU）
- **美しいUI**: ボックスレイアウトとグラフによる視覚的表示
- **マウス操作**: マウスクリックでの操作対応
- **テーマ**: 複数のカラーテーマ

### 画面構成

btopの画面は複数のボックスで構成されています:

```
┌── CPU ────────────────────┐ ┌── Memory ─────────────┐
│ ▂▃▅▆▇█▇▆▅▃▂▁  45.2%     │ │ Used: 8.2G / 16G      │
│ CPU1 ████████░░ 80%       │ │ Cached: 4.1G          │
│ CPU2 ████░░░░░░ 40%       │ │ Swap: 0.5G / 8G       │
│ ...                       │ │ ▃▅▆█▇▅▃▂▁             │
├── Process List ───────────┤ ├── Network ─────────────┤
│ PID  Name      CPU%  MEM% │ │ ↑ Upload:   1.2 MB/s  │
│ 1234 chrome    25.0  4.2  │ │ ↓ Download: 5.4 MB/s  │
│ 5678 node      12.3  2.1  │ │ ▂▃▅▇█▇▅▃              │
│ ...                       │ ├── Disk ─────────────── │
│                           │ │ /dev/sda: R:50 W:120   │
└───────────────────────────┘ └─────────────────────── ┘
```

### 操作方法

| キー | 動作 |
|------|------|
| `h` | ヘルプ |
| `q` | 終了 |
| `Esc` | メニューを閉じる / 前の画面に戻る |
| `↑` / `↓` | プロセスの選択 |
| `Enter` | プロセスの詳細を表示 |
| `f` | プロセスのフィルタ |
| `/` | プロセスの検索 |
| `t` | シグナル送信（kill） |
| `Tab` | ボックス間の移動 |
| `+` / `-` | ソート列の変更 |
| `e` | ツリー表示の切り替え |
| `m` | メモリの表示単位切り替え |
| `1` | 各CPUコアの個別表示 |

### テーマの変更

btopは複数のカラーテーマを内蔵しています:

```bash
# テーマの選択（btop内で M キーを押す）
# または設定ファイルで指定
# ~/.config/btop/btop.conf
```

## top vs htop vs btop 比較

| 特徴 | top | htop | btop |
|------|-----|------|------|
| プリインストール | ほぼ全環境 | いいえ | いいえ |
| カラー表示 | 限定的 | あり | あり（美しい） |
| マウス操作 | なし | あり | あり |
| ツリー表示 | なし | あり | あり |
| プロセスフィルタ | なし | あり | あり |
| ネットワーク監視 | なし | なし | あり |
| ディスクI/O | なし | なし | あり |
| GPU監視 | なし | なし | あり |
| カスタマイズ性 | 低い | 高い | 高い |
| リソース消費 | 最小 | 小 | 中 |

### 選び方

- **サーバー管理者**: htop（軽量で十分な機能、多くのサーバーにインストール済み）
- **開発者（ローカル）**: btop（ネットワークやディスクI/Oも一目で確認できる）
- **最小環境**: top（追加インストール不要）

## 実践的な使用例

### 高負荷プロセスの特定

```bash
# htopをCPU使用率順で起動
htop --sort-key=PERCENT_CPU

# btopを起動してCPU使用率で確認
btop
# → プロセスリストで自動的にCPU順でソート
```

### 特定ユーザーのプロセス監視

```bash
# htop: 特定ユーザーのプロセスだけ表示
htop -u username

# htop内で u キーを押してユーザーを選択
```

### 特定プロセスの監視

```bash
# htop: 特定のPIDを監視
htop -p 1234,5678

# 起動後に F4 でフィルタ入力
# "node" と入力すると node プロセスだけ表示
```

### メモリリークの調査

```bash
# htopでメモリ順にソート（M キー）
# RES列（物理メモリ使用量）が時間とともに増加しているプロセスを確認

# 特定プロセスのメモリ推移をwatch で監視
watch -n 1 'ps -p 1234 -o rss,vsz,pid,command'
```

### ゾンビプロセスの確認

```bash
# htop内で Status が Z のプロセスを検索
# F3 で検索、または F4 でフィルタ

# コマンドラインで確認
ps aux | awk '$8 == "Z" {print}'
```

---

## まとめ

- **top**: どこでも使えるシステムの基本ツール。最小限だが十分
- **htop**: topの大幅改良版。カラー表示、マウス操作、ツリー表示が便利
- **btop**: 次世代のシステムモニター。ネットワーク、ディスクI/O、GPUも一画面で監視
- 日常的な開発にはhtopかbtop、サーバーの緊急対応にはtopを使えるようにしておく
