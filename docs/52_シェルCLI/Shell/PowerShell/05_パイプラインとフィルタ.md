# パイプラインとフィルタ — `Where-Object` / `Select-Object` / `ForEach-Object`

## この文書のねらい

PowerShell のパイプラインは **オブジェクトを次のコマンドに流す仕組み**（→ `PowerShell基礎.md`）。
流れてきたオブジェクトを **絞る・選ぶ・加工する** ために使う 3 つの基本コマンドがこれ：

- `Where-Object` — **条件で絞り込む**（フィルタ）
- `Select-Object` — **プロパティ・件数を選ぶ**（射影）
- `ForEach-Object` — **各要素に処理を適用する**（ループ）

この 3 つを使いこなせれば、PowerShell の日常作業の 8 割はカバーできる。

---

## 1. まず全体像：3 つの役割の違い

```
[オブジェクト列]
      │
  Where-Object  ←  条件に合うものだけ通す
      │
  Select-Object ←  必要な「列」や「件数」を選ぶ
      │
  ForEach-Object ← 残ったものに対して何かする
      │
  最終出力
```

- Where → **絞り込み（行を減らす）**
- Select → **プロパティ選択（列を減らす）・件数制限**
- ForEach → **各要素への処理（変換・副作用）**

SQL でいうと：
- `Where-Object` ≒ `WHERE`
- `Select-Object` ≒ `SELECT` `TOP/LIMIT`
- `ForEach-Object` ≒ ループ処理

---

## 2. `Where-Object` — 条件で絞る

### 2-1. 基本形

```powershell
Get-Process | Where-Object { $_.CPU -gt 100 }
```

- `{ ... }` の中で条件を書く
- `$_` は「流れてきた現在のオブジェクト」

### 2-2. 比較演算子（bash / Python と違うので注意！）

| 演算子       | 意味           | 例                                   |
|--------------|----------------|--------------------------------------|
| `-eq`        | 等しい         | `$_.Name -eq "chrome"`               |
| `-ne`        | 等しくない     | `$_.Status -ne "Running"`            |
| `-gt` / `-lt` | より大 / より小 | `$_.Length -gt 1MB`                |
| `-ge` / `-le` | 以上 / 以下    | `$_.CPU -ge 50`                      |
| `-like`      | ワイルドカード | `$_.Name -like "chrom*"`             |
| `-match`     | 正規表現       | `$_.Name -match '^chrome\d*$'`       |
| `-contains`  | 配列に含む     | `@("a","b") -contains $_.X`          |
| `-in`        | 配列の中に入るか | `$_.X -in @("a","b")`              |

> **注意**：PowerShell では `==` ではなく **`-eq`** を使う。これは PowerShell に慣れる最初の壁の一つ。

### 2-3. 複数条件

```powershell
Get-Process |
  Where-Object { $_.CPU -gt 100 -and $_.WorkingSet -gt 500MB }
```

- `-and` / `-or` / `-not`
- `-not` は `!` でも書ける

### 2-4. 省略形（PowerShell 3 以降）

`{ }` を使わずに直接書ける簡易構文：

```powershell
Get-Process | Where-Object CPU -gt 100
Get-Service | Where-Object Status -eq "Running"
```

シンプルな 1 条件ならこちらのほうが読みやすい。

### 2-5. エイリアス

`Where-Object` には `where` / `?` のエイリアスがある。対話では短く書けて便利：

```powershell
Get-Process | ? { $_.CPU -gt 100 }
```

ただし **スクリプトには正式名で書く** のが推奨（可読性）。

## 3. `Select-Object` — 列と件数を選ぶ

### 3-1. プロパティを絞る

```powershell
Get-Process | Select-Object Name, Id, CPU
```

- 指定したプロパティだけを持つ **新しいオブジェクト** が作られる
- 表示が見やすくなり、以降のパイプも軽くなる

### 3-2. 件数で絞る

```powershell
Get-Process | Sort-Object CPU -Descending | Select-Object -First 5
Get-Content big.log | Select-Object -Last 20
```

- `-First N` / `-Last N`
- `-Skip N` で頭を捨てる
- `-Unique` で重複排除

### 3-3. 計算プロパティ（その場で新しい列を作る）

```powershell
Get-ChildItem |
  Select-Object Name, @{ Name = "SizeKB"; Expression = { [math]::Round($_.Length / 1KB, 1) } }
```

- `@{ Name = "..."; Expression = { ... } }` の形
- `Name` は列名、`Expression` は計算式

### 3-4. `-ExpandProperty` — プロパティの値そのものを取り出す

```powershell
Get-Process | Select-Object -ExpandProperty Name
```

- オブジェクトではなく **文字列そのもの** が 1 列で出てくる
- 次のコマンドが文字列を期待しているとき（ファイルに書く、配列に入れる）に便利

---

## 4. `ForEach-Object` — 各要素に処理を適用する

### 4-1. 基本形

```powershell
1..5 | ForEach-Object { "$_ 番目" }
```

出力：
```
1 番目
2 番目
3 番目
4 番目
5 番目
```

- `{ ... }` の中が要素ごとに実行される
- `$_` は現在の要素

### 4-2. 副作用のある処理（変換・書き出し）

```powershell
Get-ChildItem *.txt | ForEach-Object {
    $new = $_.Name -replace ' ', '_'
    Rename-Item $_.FullName $new
}
```

- ファイル名の空白をアンダースコアに置換してリネーム

### 4-3. エイリアス

`ForEach-Object` には `foreach` / `%` のエイリアスがある：

```powershell
1..5 | % { $_ * 2 }   # 対話では便利
```

> **混同注意**：`foreach` は **文** の `foreach` ループと **エイリアス** の `ForEach-Object` の両方の意味がある。スクリプトでは紛らわしいので正式名 `ForEach-Object` 推奨。

### 4-4. `-Begin` / `-Process` / `-End`

```powershell
Get-Process | ForEach-Object `
    -Begin   { $total = 0 } `
    -Process { $total += $_.WorkingSet } `
    -End     { "$total bytes" }
```

- `-Begin`：最初の 1 回だけ
- `-Process`：各要素ごと
- `-End`：最後の 1 回だけ
- 集計に使える

### 4-5. 並列実行（PowerShell 7 以降）

```powershell
1..10 | ForEach-Object -Parallel {
    "item $_"
    Start-Sleep -Seconds 1
} -ThrottleLimit 5
```

- 並行実行できる（重要：**5.1 には無い**）
- `$using:変数` で外の変数を渡す

## 5. 典型パターン集

### 5-1. ログから ERROR 行だけ数える

```powershell
Get-Content app.log |
  Where-Object { $_ -match 'ERROR' } |
  Measure-Object |
  Select-Object -ExpandProperty Count
```

### 5-2. 大きなファイル Top 10

```powershell
Get-ChildItem -Recurse -File |
  Sort-Object Length -Descending |
  Select-Object -First 10 Name, @{ Name = "MB"; Expression = { [math]::Round($_.Length / 1MB, 1) } }
```

### 5-3. 名前に "test" を含むプロセスを全停止

```powershell
Get-Process |
  Where-Object { $_.Name -like '*test*' } |
  Stop-Process -WhatIf        # まず WhatIf で確認
```

`-WhatIf` を外すと実行。破壊的操作の前に必ず予行を。

### 5-4. CSV の加工

```powershell
Import-Csv users.csv |
  Where-Object { $_.Age -gt 30 } |
  Select-Object Name, Age, @{ Name = "Seniority"; Expression = { [int]$_.Age - 20 } } |
  Export-Csv users_out.csv -NoTypeInformation -Encoding UTF8
```

## 6. 3 つの使い分けチートシート

| やりたいこと                          | 使うコマンド          |
|---------------------------------------|-----------------------|
| 条件に合うものだけに絞りたい          | `Where-Object`        |
| 表示する列を減らしたい                | `Select-Object`       |
| 最初の 10 件だけほしい                | `Select-Object -First 10` |
| 重複を消したい                        | `Select-Object -Unique` |
| 値だけを取り出して次のコマンドに渡す  | `Select-Object -ExpandProperty` |
| 1 件ずつ何か処理したい                | `ForEach-Object`      |
| 合計・平均を取りたい                  | `Measure-Object`      |
| 並べ替えたい                          | `Sort-Object`         |

---

## 7. つまずきやすいポイント

| 症状                                           | 原因・対処                                           |
|------------------------------------------------|------------------------------------------------------|
| `$_.` と打っても補完が効かない                 | `Where-Object { ... }` の中でないと効かない          |
| `==` で比較するとエラー                        | PowerShell は `-eq`                                  |
| パイプで `Format-Table` 後に `Where-Object`    | `Format-*` は末端専用。Where より後に書く           |
| 配列に文字列を入れたつもりがオブジェクト       | `Select-Object -ExpandProperty` で値だけに           |
| `ForEach-Object -Parallel` が動かない          | PowerShell 5.1 では未対応。7 以降                    |
| `-like 'abc*'` と `-match '^abc'` どっち？     | ワイルドカードなら `-like`、正規表現なら `-match`    |

---

## 8. まとめ

- **Where** で絞る → **Select** で削る → **ForEach** で処理する、の順が基本
- 比較演算子は `-eq`, `-gt` など **ハイフン式**
- 対話では `?` / `%` のエイリアス、スクリプトでは正式名
- `$_` はパイプライン内での「現在の 1 件」
- 破壊的なチェーンは `-WhatIf` で事前確認

この 3 コマンドを「呼吸のように」扱えるようになると、PowerShell は **小さなツールを組み立てるための非常に強力な言語** になる。
