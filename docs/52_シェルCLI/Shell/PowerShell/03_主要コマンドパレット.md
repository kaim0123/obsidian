# 主要コマンド（コマンドレット） — 動詞-名詞 の命名規則

## この文書のねらい

PowerShell のコマンドは **「動詞-名詞」** の形で名前がついている。
この規則を知っていると、**初見のコマンドでも意味が推測でき**、**必要なコマンドを検索で見つけやすくなる**。

「何百もあるコマンドを一つずつ覚える」のではなく、**動詞と名詞のパターンで理解する** のが PowerShell 攻略の近道。

---

## 1. 命名規則のしくみ

```
Get-Process
└┬┘ └───┬───┘
動詞    名詞
```

- **動詞**：何をするか（取得・変更・作成・削除…）
- **名詞**：何に対して（プロセス・ファイル・サービス…）
- 動詞は **承認された動詞リスト** からのみ選ばれる → 機械的に予測可能

```powershell
Get-Verb            # 公式に承認された動詞一覧が出る
```

---

## 2. 必ず覚える 4 つの動詞（CRUD）

| 動詞       | 意味             | 例                                       |
|------------|------------------|------------------------------------------|
| **Get-**   | 取得する（読み） | `Get-Process` `Get-ChildItem` `Get-Date` |
| **Set-**   | 設定する（変更） | `Set-Location` `Set-Content`             |
| **New-**   | 新しく作る       | `New-Item` `New-Object`                  |
| **Remove-** | 削除する         | `Remove-Item` `Remove-Variable`          |

**合言葉**：
- **Get = 読み取り専用で安全**（まず Get から試す）
- **Set / New / Remove は変更が起きる**（`-WhatIf` をつけて試せる）

### `-WhatIf` で予行演習

```powershell
Remove-Item *.log -WhatIf
```

「**もし実行したら何が起きるか**」だけ表示する魔法のスイッチ。
`Remove-*` `Stop-*` など破壊的なコマンドを試すときの保険。

---

## 3. よく使う動詞（中級）

| 動詞       | 意味             | 例                                       |
|------------|------------------|------------------------------------------|
| **Start-** | 開始する         | `Start-Process` `Start-Service`          |
| **Stop-**  | 止める           | `Stop-Process` `Stop-Service`            |
| **Restart-** | 再起動する     | `Restart-Service` `Restart-Computer`     |
| **Test-**  | 条件チェック     | `Test-Path` `Test-Connection`            |
| **Invoke-** | 実行する       | `Invoke-RestMethod` `Invoke-Expression`  |
| **Import-** / **Export-** | 取込/書出 | `Import-Csv` `Export-Csv`           |
| **ConvertTo-** / **ConvertFrom-** | 形式変換 | `ConvertTo-Json` `ConvertFrom-Json` |
| **Select-** | 選ぶ           | `Select-Object` `Select-String`          |
| **Where-** | 絞り込む         | `Where-Object`                           |
| **Sort-**  | 並べ替える       | `Sort-Object`                            |
| **Measure-** | 集計する       | `Measure-Object`                         |
| **Write-** | 出力する         | `Write-Host` `Write-Output` `Write-Error` |
| **Read-**  | 入力を読む       | `Read-Host`                              |

## 4. シーン別・最初に覚える 20 個

### 4-1. ファイルとディレクトリ

```powershell
Get-ChildItem           # ls / dir 相当：ファイル一覧
Set-Location            # cd 相当：移動
Get-Location            # pwd 相当：現在地
Copy-Item               # cp 相当
Move-Item               # mv 相当
Remove-Item             # rm 相当
New-Item                # ファイル/フォルダを作る
Get-Content             # cat 相当：中身を読む
Set-Content             # 上書き保存（置換）
Add-Content             # 追記
```

### 4-2. プロセスとサービス

```powershell
Get-Process             # 動いているプロセス一覧
Stop-Process            # プロセスを止める
Get-Service             # サービス一覧
Restart-Service         # サービス再起動
```

### 4-3. データ操作・整形

```powershell
Where-Object            # 条件で絞る
Select-Object           # 列を選ぶ・件数を絞る
Sort-Object             # 並べ替え
ForEach-Object          # 各要素に処理
Measure-Object          # 集計
```

### 4-4. 調べる（探索）

```powershell
Get-Command             # コマンドの存在を調べる
Get-Help                # ヘルプを見る
Get-Member              # オブジェクトの中身を調べる
```

## 5. 名前を思い出せないときの探し方

### 5-1. 動詞で探す

```powershell
Get-Command -Verb Get            # Get- で始まるコマンドをすべて
Get-Command -Verb Set,New        # 複数指定も可
```

### 5-2. 名詞で探す

```powershell
Get-Command -Noun Process        # Process に関わるコマンドをすべて
Get-Command -Noun *Item*         # ワイルドカードもOK
```

### 5-3. 部分一致で探す

```powershell
Get-Command *network*            # 名前に network を含むコマンド
```

> **Tip**：`Get-Command` を覚えれば、「PowerShell で◯◯するコマンドあるかな？」が自力で調べられる。

## 6. エイリアス（省略形）との関係

PowerShell には bash ユーザー向けに **エイリアス** が用意されている。

| エイリアス | 実体            |
|-----------|------------------|
| `ls`      | `Get-ChildItem`  |
| `cat`     | `Get-Content`    |
| `cp`      | `Copy-Item`      |
| `rm`      | `Remove-Item`    |
| `pwd`     | `Get-Location`   |
| `cd`      | `Set-Location`   |

対話で打つときは短いエイリアスが便利。
ただし **スクリプトに書くときは正式名（動詞-名詞）** を推奨。

理由：
- エイリアスは環境によって書き換えられていることがある（可搬性が落ちる）
- コードレビューで他人が読むとき、正式名のほうが意味が明らか
- PSScriptAnalyzer などの静的解析ルールでも警告される

→ 詳しくは `エイリアス.md`

## 7. パラメータの読み方

```powershell
Get-ChildItem -Path C:\ -Recurse -Filter "*.log"
```

- `-Path`, `-Recurse`, `-Filter` が **パラメータ**
- `-Recurse` のように値を取らないものは **スイッチ**
- パラメータ名は省略できる場合がある（位置パラメータ）が、**省略しないほうが読みやすい**

**共通パラメータ**（ほぼ全コマンドに使える）：

| パラメータ     | 用途                                         |
|---------------|----------------------------------------------|
| `-WhatIf`     | 実行せずに「何が起きるか」だけ表示           |
| `-Confirm`    | 実行前に Yes/No を聞く                       |
| `-Verbose`    | 詳細ログを出す                               |
| `-ErrorAction` | エラー時の動作（Stop / SilentlyContinue 等） |
| `-OutVariable` | 結果を変数にも入れる                         |

## 8. 承認された動詞の主要カテゴリ

`Get-Verb` で出る動詞は **意味ごとに分類** されている。代表だけ抜粋：

### 8-1. Common（共通操作）
`Add` / `Clear` / `Copy` / `Get` / `Move` / `New` / `Remove` / `Set` / `Show` / `Hide`

### 8-2. Data（データ操作）
`Convert` / `ConvertTo` / `ConvertFrom` / `Export` / `Import` / `Group` / `Join` / `Merge` / `Select` / `Sort` / `Update`

### 8-3. Diagnostic（診断）
`Debug` / `Measure` / `Ping` / `Resolve` / `Test` / `Trace`

### 8-4. Lifecycle（状態遷移）
`Complete` / `Disable` / `Enable` / `Install` / `Invoke` / `Register` / `Restart` / `Resume` / `Start` / `Stop` / `Suspend` / `Uninstall` / `Wait`

### 8-5. Communications（通信）
`Connect` / `Disconnect` / `Read` / `Receive` / `Send` / `Write`

**自作の関数にも、この動詞を使う**のが PowerShell 流儀。

```powershell
function Get-MyReport { ... }   # OK
function Fetch-MyReport { ... } # 警告（非承認動詞）
```

---

## 9. 最短で使いこなすためのコツ

1. **迷ったら `Get-`** から試す（壊れない）
2. **破壊的操作は `-WhatIf`** で予行演習
3. **`Get-Command` と `Get-Help`** で自力で調べる習慣
4. **正式名で書く**（対話はエイリアス OK、スクリプトはフルネーム）
5. **パイプで `Get-Member`** してオブジェクトの中身を確認する

この 5 つが身についたら、知らないコマンドに出会っても **自力で解決** できるようになる。
