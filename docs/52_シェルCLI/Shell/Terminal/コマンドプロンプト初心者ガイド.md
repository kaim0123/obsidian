## コマンドプロンプトとは

**コマンドプロンプト**（Command Prompt、略してcmd）は、Windowsに標準搭載されているコマンドラインインターフェースです。マウスを使わずにキーボードだけでコンピュータを操作できます。

### なぜコマンドプロンプトを学ぶのか？
- **高速操作**: マウス操作より素早く作業できる
- **自動化**: バッチファイルで作業を自動化できる
- **システム管理**: 高度なシステム設定が可能
- **プログラミング基礎**: 開発環境の理解に役立つ

---

## 起動方法

### 方法1: スタートメニューから
1. スタートボタンをクリック
2. 「cmd」と入力
3. 「コマンドプロンプト」をクリック

### 方法2: ファイル名を指定して実行
1. `Windows + R` キーを押す
2. 「cmd」と入力
3. Enterキーを押す

### 方法3: エクスプローラーから
1. エクスプローラーで任意のフォルダを開く
2. アドレスバーに「cmd」と入力
3. Enterキーを押す

## 基本的な画面構成

```
C:\Users\ユーザー名>
```

### 各部分の説明
- `C:\Users\ユーザー名`: 現在のディレクトリ（フォルダ）のパス
- `>`: プロンプト（コマンド入力待ち状態を示す）
- カーソル: ここにコマンドを入力する

### 重要なキー操作
- **Enter**: コマンドを実行
- **↑/↓**: コマンド履歴の移動
- **Tab**: ファイル名の自動補完
- **Ctrl + C**: 実行中のコマンドを中断

## 基本コマンド

### 1. ヘルプの表示
```cmd
help
```
利用可能なコマンド一覧が表示されます。

### 2. 特定コマンドのヘルプ
```cmd
help コマンド名
```
例：
```cmd
help dir
```

### 3. 現在の時刻表示
```cmd
time
```

### 4. 現在の日付表示
```cmd
date
```

### 5. コマンド履歴の表示
```cmd
doskey /history
```

## ディレクトリ操作

### 現在のディレクトリを確認
```cmd
cd
```
または
```cmd
echo %cd%
```

### ディレクトリ一覧の表示
```cmd
dir
```

### ディレクトリの移動
```cmd
cd ディレクトリ名
```

#### 例
```cmd
# デスクトップに移動
cd Desktop

# 親ディレクトリに移動
cd ..

# ルートディレクトリに移動
cd \

# 特定のパスに移動
cd C:\Users\ユーザー名\Documents
```

### 新しいディレクトリの作成
```cmd
mkdir ディレクトリ名
```
または
```cmd
md ディレクトリ名
```

### ディレクトリの削除
```cmd
rmdir ディレクトリ名
```
または
```cmd
rd ディレクトリ名
```

## ファイル操作

### ファイル一覧の表示
```cmd
dir
```

### 詳細情報付きで表示
```cmd
dir /w
```

### 隠しファイルも表示
```cmd
dir /a
```

### ファイルのコピー
```cmd
copy 元ファイル コピー先
```

#### 例
```cmd
copy file1.txt file2.txt
copy file1.txt C:\backup\
```

### ファイルの移動・リネーム
```cmd
move 元ファイル 移動先
```

#### 例
```cmd
move oldname.txt newname.txt
move file.txt C:\backup\
```

### ファイルの削除
```cmd
del ファイル名
```

#### 例
```cmd
del file.txt
del *.txt
```

### ファイルの内容表示
```cmd
type ファイル名
```

### ファイルの検索
```cmd
dir ファイル名 /s
```

## 実践練習

### 練習1: 基本的なディレクトリ操作
```cmd
# 1. 現在のディレクトリを確認
cd

# 2. ディレクトリ一覧を表示
dir

# 3. 新しいフォルダを作成
mkdir practice

# 4. 作成したフォルダに移動
cd practice

# 5. 現在のディレクトリを確認
cd
```

### 練習2: ファイル操作
```cmd
# 1. テキストファイルを作成（メモ帳で）
notepad test.txt

# 2. ファイルの内容を表示
type test.txt

# 3. ファイルをコピー
copy test.txt test_copy.txt

# 4. ファイル一覧を確認
dir

# 5. コピーファイルを削除
del test_copy.txt
```

### 練習3: パスの操作
```cmd
# 1. デスクトップに移動
cd Desktop

# 2. 親ディレクトリに戻る
cd ..

# 3. ドキュメントフォルダに移動
cd Documents

# 4. ルートディレクトリに移動
cd \

# 5. 元のディレクトリに戻る
cd C:\Users\ユーザー名
```

## よくあるエラーと対処法

### 1. 「指定されたファイルが見つかりません」
```
指定されたファイルが見つかりません。
```
**原因**: ファイル名やパスが間違っている
**対処法**: 
- ファイル名を正確に入力
- `dir`でファイル一覧を確認
- パスが正しいか確認

### 2. 「アクセスが拒否されました」
```
アクセスが拒否されました。
```
**原因**: 管理者権限が必要な操作
**対処法**: 
- 管理者としてコマンドプロンプトを実行
- 別のディレクトリで試す

### 3. 「ディレクトリ名が無効です」
```
ディレクトリ名が無効です。
```
**原因**: 存在しないディレクトリに移動しようとしている
**対処法**: 
- `dir`でディレクトリ一覧を確認
- 正しいディレクトリ名を入力

### 4. コマンドが認識されない
```
'コマンド名' は、内部コマンドまたは外部コマンド、
操作可能なプログラムまたはバッチ ファイルとして認識されていません。
```
**原因**: コマンド名のスペルミス
**対処法**: 
- コマンド名を正確に入力
- `help`で利用可能なコマンドを確認

## 便利なテクニック

### 1. タブ補完
ファイル名やディレクトリ名の途中まで入力してTabキーを押すと、自動補完されます。

### 2. コマンド履歴
↑キーで以前のコマンドを呼び出せます。

### 3. ワイルドカード
```cmd
# すべてのテキストファイルを表示
dir *.txt

# 特定の文字で始まるファイルを表示
dir a*

# 特定の文字を含むファイルを表示
dir *test*
```

### 4. パイプとリダイレクト
```cmd
# 結果をファイルに保存
dir > filelist.txt

# 結果を追加でファイルに保存
dir >> filelist.txt

# ファイルの内容を表示
type filelist.txt
```

## バッチファイルの基礎

### 簡単なバッチファイルの作成
```cmd
# バッチファイルを作成
notepad mybatch.bat
```

### バッチファイルの内容例
```batch
@echo off
echo バッチファイルを実行中...
dir
echo 実行完了
pause
```

### バッチファイルの実行
```cmd
mybatch.bat
```

## 次のステップ

### 1. より高度なコマンドを学習
- `findstr`: ファイル内の文字列検索
- `xcopy`: ディレクトリのコピー
- `robocopy`: 高機能なファイルコピー

### 2. バッチファイルの作成
- 複数のコマンドを組み合わせたスクリプト
- 条件分岐やループの使用

### 3. システム管理コマンド
- `systeminfo`: システム情報の表示
- `tasklist`: 実行中のプロセス一覧
- `netstat`: ネットワーク接続状況

### 4. PowerShellへの移行
コマンドプロンプトに慣れたら、より高機能なPowerShellの学習を始めましょう。

## まとめ

### 学習のポイント
1. **毎日少しずつ**: 継続的な練習が重要
2. **エラーを恐れない**: エラーから学ぶことが多い
3. **実際に使う**: 理論だけでなく実践を重視
4. **ヘルプを活用**: `help`コマンドを積極的に使用

次のステップとして、PowerShellやGit Bashの学習に進むことをお勧めします！
