## コマンドプロンプト クイックリファレンス

### 基本操作
| 操作 | コマンド | 説明 |
|------|----------|------|
| 現在のディレクトリ確認 | `cd` | 現在のディレクトリパスを表示 |
| ディレクトリ一覧 | `dir` | ファイル・フォルダ一覧を表示 |
| ディレクトリ移動 | `cd パス` | 指定したディレクトリに移動 |
| 親ディレクトリに移動 | `cd ..` | 一つ上のディレクトリに移動 |
| ルートディレクトリに移動 | `cd \` | ルートディレクトリに移動 |

### ファイル・ディレクトリ操作
| 操作 | コマンド | 説明 |
|------|----------|------|
| ディレクトリ作成 | `mkdir 名前` | 新しいディレクトリを作成 |
| ディレクトリ削除 | `rmdir 名前` | 空のディレクトリを削除 |
| ファイルコピー | `copy 元 先` | ファイルをコピー |
| ファイル移動 | `move 元 先` | ファイルを移動・リネーム |
| ファイル削除 | `del ファイル名` | ファイルを削除 |
| ファイル内容表示 | `type ファイル名` | ファイルの内容を表示 |

### システム情報
| 操作 | コマンド | 説明 |
|------|----------|------|
| システム情報 | `systeminfo` | システムの詳細情報を表示 |
| プロセス一覧 | `tasklist` | 実行中のプロセス一覧 |
| ネットワーク接続 | `netstat` | ネットワーク接続状況 |
| 現在の時刻 | `time` | 現在の時刻を表示 |
| 現在の日付 | `date` | 現在の日付を表示 |

### 便利なオプション
| コマンド | オプション | 説明 |
|----------|------------|------|
| `dir` | `/w` | 横並びで表示 |
| `dir` | `/a` | 隠しファイルも表示 |
| `dir` | `/s` | サブディレクトリも検索 |
| `copy` | `/y` | 上書き確認なし |

## PowerShell クイックリファレンス

### 基本操作
| 操作 | コマンドレット | エイリアス | 説明 |
|------|----------------|------------|------|
| 現在のディレクトリ確認 | `Get-Location` | `pwd` | 現在のディレクトリパスを表示 |
| ディレクトリ一覧 | `Get-ChildItem` | `ls`, `dir` | ファイル・フォルダ一覧を表示 |
| ディレクトリ移動 | `Set-Location` | `cd` | 指定したディレクトリに移動 |
| ディレクトリ作成 | `New-Item -ItemType Directory` | `mkdir` | 新しいディレクトリを作成 |
| ディレクトリ削除 | `Remove-Item` | `rmdir` | ディレクトリを削除 |

### ファイル操作
| 操作 | コマンドレット | エイリアス | 説明 |
|------|----------------|------------|------|
| ファイルコピー | `Copy-Item` | `cp` | ファイルをコピー |
| ファイル移動 | `Move-Item` | `mv` | ファイルを移動・リネーム |
| ファイル削除 | `Remove-Item` | `rm` | ファイルを削除 |
| ファイル内容表示 | `Get-Content` | `cat` | ファイルの内容を表示 |
| ファイル内容書き込み | `Set-Content` | - | ファイルに内容を書き込み |

### システム管理
| 操作 | コマンドレット | 説明 |
|------|----------------|------|
| プロセス一覧 | `Get-Process` | 実行中のプロセス一覧 |
| サービス一覧 | `Get-Service` | サービス一覧 |
| システム情報 | `Get-ComputerInfo` | システムの詳細情報 |
| ネットワーク接続 | `Get-NetTCPConnection` | ネットワーク接続状況 |

### オブジェクト操作
| 操作 | コマンドレット | 説明 |
|------|----------------|------|
| オブジェクト選択 | `Select-Object` | 特定のプロパティを選択 |
| オブジェクトフィルタ | `Where-Object` | 条件でフィルタリング |
| オブジェクト並び替え | `Sort-Object` | オブジェクトを並び替え |
| オブジェクトグループ化 | `Group-Object` | オブジェクトをグループ化 |

### パイプライン
| 記号 | 説明 | 例 |
|------|------|-----|
| `|` | パイプライン | `Get-Process | Sort-Object CPU` |
| `>` | 出力をファイルに保存 | `Get-Process > processes.txt` |
| `>>` | 出力をファイルに追加 | `Get-Process >> processes.txt` |

## トラブルシューティング

### よくあるエラーと対処法

#### 1. コマンドが見つからない
**エラー**: `'コマンド名' は、内部コマンドまたは外部コマンドとして認識されていません。`
**対処法**: 
- コマンド名のスペルを確認
- パスが正しく設定されているか確認
- 必要なソフトウェアがインストールされているか確認

#### 2. アクセスが拒否されました
**エラー**: `アクセスが拒否されました。`
**対処法**: 
- 管理者権限でターミナルを実行
- ファイルの権限を確認
- 別のディレクトリで試す

#### 3. ファイルが見つかりません
**エラー**: `指定されたファイルが見つかりません。`
**対処法**: 
- ファイル名のスペルを確認
- パスが正しいか確認
- ファイルが存在するか確認

#### 4. ディレクトリが無効です
**エラー**: `ディレクトリ名が無効です。`
**対処法**: 
- ディレクトリ名のスペルを確認
- ディレクトリが存在するか確認
- パスが正しいか確認

### デバッグのコツ

#### 1. エラーメッセージを読む
- エラーメッセージには問題の手がかりが含まれている
- 英語のエラーメッセージも理解できるようになる

#### 2. 段階的に実行する
- 複雑なコマンドは段階的に実行する
- 各段階で結果を確認する

#### 3. ヘルプを活用する
- `help`コマンド（コマンドプロンプト）
- `Get-Help`コマンドレット（PowerShell）
- `man`コマンド（Git Bash）

#### 4. ログを確認する
- コマンドの実行結果を記録する
- エラーが発生した場合の状況を記録する

## まとめ

このクイックリファレンスは、各ターミナルの基本的な操作を素早く参照するためのものです。実際の操作では、このリファレンスを参考にしながら、段階的に学習を進めてください。

### 重要なポイント
1. **基本操作をマスターする**: ディレクトリ移動、ファイル操作など
2. **エラーに慣れる**: エラーから学ぶことが多い
3. **実践を重視する**: 理論だけでなく実際に操作する
4. **継続的に学習する**: 定期的に新しいコマンドを覚える

ターミナル操作は現代の開発者にとって必須のスキルです。このリファレンスを活用して、効率的に学習を進めてください！
