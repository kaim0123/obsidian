## コマンドプロンプト練習問題

### 初級問題

#### 問題1: 基本的なディレクトリ操作
以下の操作を順番に実行してください：
1. 現在のディレクトリを確認する
2. ディレクトリ一覧を表示する
3. 「cmd_practice」という名前のフォルダを作成する
4. 作成したフォルダに移動する
5. 現在のディレクトリを確認する

#### 問題2: ファイル操作
以下の操作を順番に実行してください：
1. メモ帳で「hello.txt」というファイルを作成し、「Hello Command Prompt!」と入力して保存する
2. ファイルの内容を表示する
3. ファイルを「hello_copy.txt」にコピーする
4. ファイル一覧を表示して確認する
5. コピーファイルを削除する

#### 問題3: パス操作
以下の操作を順番に実行してください：
1. デスクトップに移動する
2. 親ディレクトリに戻る
3. ドキュメントフォルダに移動する
4. ルートディレクトリ（C:\）に移動する
5. 元のディレクトリに戻る

### 中級問題

#### 問題4: バッチファイルの作成
以下の内容のバッチファイルを作成してください：
- 現在の日付と時刻を表示
- 現在のディレクトリを表示
- ディレクトリ一覧を表示
- 「バッチファイル実行完了」というメッセージを表示
- 実行を一時停止

#### 問題5: ワイルドカードの使用
以下の操作を実行してください：
1. 複数のテキストファイル（.txt）を作成する
2. すべてのテキストファイルを一覧表示する
3. 特定の文字で始まるファイルのみを表示する
4. ファイル一覧をテキストファイルに保存する

## 総合練習問題

### 問題1: ファイル管理システムの構築
以下の要件を満たすシステムを構築してください：

#### コマンドプロンプト版
1. 「file_system」フォルダを作成
2. その中に「documents」「images」「scripts」の3つのサブフォルダを作成
3. 各フォルダに適切なサンプルファイルを作成
4. ファイル一覧を「file_list.txt」に保存
5. バッチファイルで上記の操作を自動化

#### PowerShell版
1. 「file_system」フォルダを作成
2. その中に「documents」「images」「scripts」の3つのサブフォルダを作成
3. 各フォルダに適切なサンプルファイルを作成
4. ファイル一覧を「file_list.txt」に保存
5. PowerShellスクリプトで上記の操作を自動化

#### Git Bash版
1. 「file_system」フォルダを作成
2. その中に「documents」「images」「scripts」の3つのサブフォルダを作成
3. 各フォルダに適切なサンプルファイルを作成
4. ファイル一覧を「file_list.txt」に保存
5. シェルスクリプトで上記の操作を自動化

### 問題2: ログ分析システム
以下の要件を満たすシステムを構築してください：

#### 要件
1. ログファイルを作成（複数のエントリを含む）
2. ログファイルから特定の情報を抽出
3. 抽出した情報を新しいファイルに保存
4. 統計情報を表示

#### 各ターミナルでの実装
- **コマンドプロンプト**: `findstr`コマンドを使用
- **PowerShell**: `Select-String`コマンドレットを使用

### 問題3: バックアップシステム

#### 要件

## 解答例

### コマンドプロンプト解答例

#### 問題1の解答
```cmd
cd
dir
mkdir cmd_practice
cd cmd_practice
cd
```

#### 問題2の解答
```cmd
notepad hello.txt
type hello.txt
copy hello.txt hello_copy.txt
dir
del hello_copy.txt
```

#### 問題4の解答（バッチファイル）
```batch
@echo off
echo 現在の日付と時刻:
date /t
time /t
echo.
echo 現在のディレクトリ:
cd
echo.
echo ディレクトリ一覧:
dir
echo.
echo バッチファイル実行完了
pause
```

### PowerShell解答例

#### 問題1の解答
```powershell
Get-Location
Get-ChildItem
New-Item -ItemType Directory -Name "powershell_practice"
Set-Location "powershell_practice"
Get-Location
```

#### 問題2の解答
```powershell
Get-Process
Get-Process | Format-List
Get-Process | Where-Object {$_.Name -like "*notepad*"}
Get-Process | Sort-Object CPU -Descending
Get-Process | Sort-Object CPU -Descending | Select-Object -First 5
```

#### 問題5の解答（PowerShellスクリプト）
```powershell
param(
    [string]$UserName = "Guest"
)

Write-Host "こんにちは、$UserName さん！"
Write-Host "現在の日付と時刻: $(Get-Date)"
Write-Host "現在のディレクトリ: $(Get-Location)"
Write-Host "プロセス一覧（上位5つ）:"
Get-Process | Select-Object -First 5 | Format-Table Name, Id, CPU
```

### Git Bash解答例

#### 問題1の解答
```bash
pwd
ls
mkdir gitbash_practice
cd gitbash_practice
pwd
```

#### 問題2の解答
```bash
echo "Hello Git Bash!" > test.txt
cat test.txt
cp test.txt test_copy.txt
ls -la
rm test_copy.txt
```

#### 問題4の解答（シェルスクリプト）
```bash
#!/bin/bash

echo "現在の日付と時刻: $(date)"
echo "現在のディレクトリ: $(pwd)"
echo "ファイル一覧:"
ls -la

read -p "あなたの名前を入力してください: " name
echo "こんにちは、$name さん！"
```

## 学習のポイント

### 1. 段階的な学習
- 初級問題から順番に取り組む
- 各ターミナルの特徴を理解する
- 実際にコマンドを入力して練習する

### 2. 実践的な応用
- 総合練習問題で実用的なスキルを身につける
- 自分のプロジェクトでターミナルを使用する
- エラーに遭遇したら対処法を学習する

### 3. 継続的な学習
- 毎日少しずつ練習する
- 新しいコマンドや機能を積極的に学習する
- 他の学習者と情報交換する

### 4. 記録と振り返り
- 学習した内容を記録する
- 定期的に振り返りを行う
- 苦手な部分を重点的に練習する
