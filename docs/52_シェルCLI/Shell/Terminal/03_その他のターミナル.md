# その他のターミナル — Alacritty / WezTerm など選択肢

## この文書のねらい

Windows Terminal（→ `Windows_Terminal.md`）は標準的だが、**唯一の選択肢ではない**。
「もっと速いのが欲しい」「macOS / Linux でも同じ設定を使いたい」「GPU 描画の軽快さが欲しい」といったニーズに応える、**第三勢力のターミナル** がいくつかある。

この文書では、代表的な選択肢の **性格・強み・乗り換えの目安** を整理する。

> **おさらい**：ターミナル（窓）とシェル（中身）は別。一覧から知りたい → `00_ターミナルとシェル入門.md`。ここで扱うのはすべて「窓」側（→ `01_ターミナルとシェルの違い.md`）。

---

## 1. 一言で性格分け

| ターミナル          | 性格                                                           |
|---------------------|---------------------------------------------------------------|
| **Windows Terminal** | 標準。Windows 前提なら第一候補                                |
| **Alacritty**       | 最速・最小主義。GPU 描画、機能は意図的に削ぎ落とす            |
| **WezTerm**         | 多機能・Lua 設定・クロスプラットフォーム                      |
| **iTerm2**          | macOS 専用の老舗。タブ・分割・検索などフル装備                |
| **Kitty**           | Linux / macOS 向け。GPU 描画で機能も豊富                       |
| **Warp**            | 現代的 UX + AI 機能。新興・独自路線                           |
| **Hyper**           | Electron 製、Web 技術でプラグインが書ける（重めだが自由）     |
| **MinTTY**          | Cygwin / Git Bash に付属。Windows 向け軽量                     |

---

## 2. Alacritty — 最速・ミニマリスト

### 2-1. 特徴

- **GPU 描画（OpenGL）** で描画が極めて軽い
- Rust 製。起動も速く、重い出力（長いログ）でも止まらない
- 設定は TOML ファイル 1 枚。**タブもペイン分割も無い**
- マウスサポートは最小限

### 2-2. 向いている人

- キー操作で完結できる人（tmux / zellij 併用前提）
- 「色・フォント・キーだけ決まれば十分」というミニマリスト
- 1 日中大量のログを流し続ける人

### 2-3. 向いていない人

- マルチタブ・ペイン分割を **ターミナル側に求める** 人
- GUI でプロファイル切替したい人
- 絵文字や複雑な装飾を多用する人

### 2-4. 設定例（`alacritty.toml`）

```toml
[font]
size = 12.0
[font.normal]
family = "Cascadia Code"

[window]
opacity = 0.9

[colors.primary]
background = "#1E1E2E"
foreground = "#CDD6F4"
```

---

## 3. WezTerm — 多機能オールラウンダー

### 3-1. 特徴

- **GPU 描画 + タブ + ペイン分割 + 設定スクリプト可能**
- Rust 製
- **Lua** で設定を書く（プログラマブル）
- Windows / macOS / Linux で **同じ設定ファイルが使える**
- 画像表示（iTerm2 image protocol / Sixel）対応

### 3-2. 向いている人

- 1 つの設定ファイルを **複数 OS で共有** したい
- GUI の便利さ（タブ・検索・分割）も欲しいし、速さも欲しい
- 設定をコードとして書きたい（`wezterm.lua`）

### 3-3. 設定例（`~/.wezterm.lua`）

```lua
local wezterm = require 'wezterm'
return {
  font = wezterm.font 'Cascadia Code',
  font_size = 11.0,
  color_scheme = 'Tokyo Night',
  window_background_opacity = 0.9,
  hide_tab_bar_if_only_one_tab = true,
  keys = {
    { key = 'd', mods = 'CTRL|SHIFT', action = wezterm.action.SplitHorizontal{} },
  },
}
```

### 3-4. Windows Terminal との比較

| 観点                | Windows Terminal | WezTerm                |
|---------------------|-------------------|------------------------|
| クロスプラットフォーム | Windows のみ    | Win / Mac / Linux      |
| 設定形式           | JSON              | Lua（ロジックも書ける） |
| GPU 描画           | あり              | あり                   |
| WSL/SSH 統合       | 優秀              | 普通（プロファイル可）  |
| 画像表示           | 限定的            | Sixel / iTerm2 対応     |

---

## 4. iTerm2 — macOS の定番

- macOS 専用。**ターミナル（macOS 標準）の上位互換**
- 検索・分割・プロファイル・トリガー（正規表現で色付け・アクション）
- 画像表示・自動プロファイル切替・Shell Integration が強力
- macOS しか使わないなら **まず試すべき**

ただし WezTerm や Warp が普及したことで相対的優位は縮小。

---

## 5. Kitty — Linux / macOS の高機能派

- GPU 描画、豊富な機能、設定テキスト 1 枚
- **kitten** という内蔵サブコマンドで画像表示・差分・SSH 越しの機能を提供
- 画像表示プロトコル（Kitty graphics protocol）が他ツールにも採用されつつある
- Windows 未対応

---

## 6. Warp — 新世代 + AI

- **ターミナルの UX を再発明** するコンセプト
- コマンドを **ブロック単位** で表示、マウス編集可能
- 組み込み AI：コマンド補完、自然言語 → シェルコマンド
- **クラウドアカウントが絡む**ので、業務で使う場合は情報の取り扱いに注意
- 最近 Windows ベータも出た

### 向いている人

- AI サポートで学習しながら進めたい人
- 「黒い画面」に慣れていない初心者〜中級者
- 個人開発者

### 向いていない人

- 機密性の高い業務（ログが外部に出ないか要確認）
- 素のターミナルの透明性を重視する人

---

## 7. Hyper — Web 技術で作られたターミナル

- **Electron 製**（= Chromium ベース）
- プラグインが JS / CSS で書ける、見た目を派手にできる
- 機能はコミュニティプラグイン依存
- **動作が重め**（ネイティブ系と比べると）

「気軽に遊べる」「テーマを凝りたい」には向くが、仕事のメインに据えるのは要検討。

---

## 8. MinTTY — 軽量・Windows 向け

- Cygwin / MSYS2 / Git for Windows に付属
- **Git Bash の「窓」**はこれ
- 単機能で軽量、UTF-8 対応、日本語もそこそこ扱える
- 最近は Windows Terminal に譲る立ち位置

---

## 9. 選び方の指針

### 9-1. 「何を優先するか」で決める

| 優先したいもの              | 推奨                              |
|-----------------------------|-----------------------------------|
| Windows に最適・標準        | **Windows Terminal**              |
| 速さ・最小主義              | **Alacritty**                     |
| クロスプラットフォーム・多機能 | **WezTerm**                    |
| macOS 専用で成熟            | **iTerm2**                        |
| Linux / macOS で高機能      | **Kitty**                         |
| AI 補助・モダン UX          | **Warp**                          |
| 自由にカスタマイズ          | **Hyper**                         |

### 9-2. tmux / zellij 前提ならどれでも同じ？

Alacritty / Kitty のように **タブを持たない** ターミナルは、
`tmux` や `zellij` を併用するとタブ・分割が手に入る。
設定の分離になり、**ターミナルを乗り換えても tmux 設定はそのまま** というメリットがある。

### 9-3. 「とりあえず試す」手順

1. 今使っているのが Windows Terminal なら **WezTerm** を試す（クロスプラットフォーム化できる）
2. 重い作業で遅さを感じるなら **Alacritty** を試す（軽さを実感）
3. macOS なら **iTerm2 → WezTerm or Warp** の順に体験
4. 合わなければ戻すのは簡単。設定ファイルだけ取っておく

## 10. 共通の評価軸

ターミナルを選ぶときのチェック項目：

- **描画速度**：`yes` コマンドを長時間流して引っかかりがないか
- **日本語表示**：全角半角混じりのテキストで桁ズレしないか
- **絵文字・Nerd Font**：プロンプトアイコンが崩れないか
- **IME 連携**：日本語入力時の下線がまっすぐ出るか
- **コピペの挙動**：選択だけでコピー？ 複数行が改行付きで貼れる？
- **検索**：`Ctrl+F` で出力から検索できるか
- **プロファイル切替**：シェルの切替が速いか
- **設定の共有**：テキストファイル 1 枚で済むか、Git で管理できるか

---

## 11. まとめ

- **Windows Terminal** が Windows のスタンダード
- 速さなら **Alacritty**、多機能・クロスプラットフォームなら **WezTerm**
- macOS は **iTerm2** が老舗、近年は **WezTerm / Warp** も有力
- タブ・分割を **tmux / zellij** に委ねる流派もある（ターミナル本体を軽くできる）
- 一度 **設定ファイルを dotfiles 化** すれば、乗り換えコストは小さい

ターミナルは **毎日 8 時間触る道具**。15 分の比較検討が年単位で効いてくる。
