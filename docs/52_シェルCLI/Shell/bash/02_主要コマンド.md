# 主要コマンド — ls / cd / grep / find / awk / sed

## この文書のねらい

bash 上で **日常的に使うコマンドの 9 割** はごく限られた数。
ここではその中核になる 10 数個を、**初心者がそのまま写して動かせる** 実例とともに整理する。

「すべてのオプションを覚える」必要はない。**これが読めれば `man` や `--help` で残りを自力で追える**、の境界を目指す。

---

## 1. ディレクトリ移動・確認

### 1-1. `pwd` — いまどこ？

```bash
pwd
# → /home/alice/dev/project
```

- **Print Working Directory** の略
- 迷ったらまず `pwd`

### 1-2. `cd` — 移動する

```bash
cd /var/log         # 絶対パス
cd ..                # 親ディレクトリへ
cd ~                  # ホーム
cd -                  # 直前の場所に戻る（地味に便利）
```

### 1-3. `ls` — 一覧を見る

```bash
ls                  # 普通に
ls -l               # 詳細（権限・サイズ・更新日）
ls -la              # 隠しファイル（ドット始まり）も含む
ls -lh              # サイズを人間が読める形に
ls -lt              # 更新時刻でソート
ls -S               # サイズでソート
ls *.md             # ワイルドカード
```

**覚える組み合わせ**：`ls -la` / `ls -lh` / `ls -lt`

## 2. ファイル操作

### 2-1. `cp` — コピー

```bash
cp a.txt b.txt              # a を b にコピー
cp a.txt dir/                # ディレクトリに
cp -r srcdir dstdir          # ディレクトリごと（-r 必須）
cp -i a.txt b.txt            # 上書き前に確認
cp -p a.txt b.txt            # パーミッション・タイムスタンプも保持
```

### 2-2. `mv` — 移動 / リネーム

```bash
mv old.txt new.txt          # リネーム
mv file.txt dir/             # 移動
mv -n file.txt dir/          # 既にあれば上書きしない（安全）
```

### 2-3. `rm` — 削除

```bash
rm file.txt                  # ファイル削除
rm -r dir                    # ディレクトリごと（中身ごと）
rm -f file.txt               # 確認せず強制
rm -rf dir                   # ★要注意★ 再帰・強制
```

> **警告**：`rm -rf /` は **システム全消去** につながる。パス指定は絶対に確認してから。
> `rm` にはゴミ箱がない。消したら戻らない。**不安なときは `mv` で待避** するのが手。

### 2-4. `mkdir` / `rmdir` — ディレクトリ操作

```bash
mkdir newdir                # 作成
mkdir -p a/b/c              # 中間ディレクトリも自動作成
rmdir emptydir              # 空のときだけ削除
```

## 3. ファイルの中身を見る

### 3-1. `cat` — 全部出す

```bash
cat file.txt
cat a.txt b.txt > merged.txt   # 結合してリダイレクト
```

### 3-2. `less` — 1 画面ずつ（長いファイル向け）

```bash
less big.log
```

操作：
- **`Space`** : 次のページ
- **`b`** : 前のページ
- **`/検索語`** : 検索（`n` 次、`N` 前）
- **`q`** : 終了

**`less` は `cat | more` より現代的**。ログを読むならこれ。

### 3-3. `head` / `tail` — 先頭 / 末尾

```bash
head file.txt               # 先頭 10 行
head -n 5 file.txt          # 先頭 5 行
tail file.txt               # 末尾 10 行
tail -f /var/log/app.log    # リアルタイム追従（重要）
```

`tail -f` はログ監視の定番。

### 3-4. `wc` — 行数・単語数

```bash
wc file.txt                 # 行・単語・バイト
wc -l file.txt              # 行数だけ
```

## 4. 検索系：`grep` と `find`

### 4-1. `grep` — 中身を検索

```bash
grep 'ERROR' app.log                # ファイル内で検索
grep -i 'error' app.log             # 大文字小文字を区別しない
grep -n 'TODO' main.c               # 行番号付き
grep -r 'TODO' src/                 # ディレクトリを再帰
grep -v 'DEBUG' app.log             # マッチしない行（反転）
grep -E '(ERROR|WARN)' app.log      # 拡張正規表現
grep -c 'ERROR' app.log             # 件数だけ
```

**覚える組み合わせ**：`grep -rn 'TODO' .` / `grep -iE '...'`

最近は `ripgrep`（`rg`）のほうが速くて使いやすい。迷ったらそれでもよい。

### 4-2. `find` — ファイルを探す

```bash
find . -name '*.log'                      # 名前で検索
find . -type f -name '*.md'               # ファイルだけ
find . -type d -name 'node_modules'       # ディレクトリだけ
find . -size +10M                          # 10MB 超
find . -mtime -1                           # 1 日以内に変更
find . -name '*.pyc' -delete               # 見つけて削除
find . -name '*.log' -exec rm {} \;        # 各ファイルにコマンドを実行
```

- `.` は検索開始ディレクトリ
- `{}` はヒットしたファイル名、`\;` は `-exec` の終了マーカー

**`find | xargs` の定番**：

```bash
find . -name '*.log' -print0 | xargs -0 rm
```

## 5. テキスト加工：`awk` と `sed`

### 5-1. `sed` — 置換・削除・抽出

```bash
sed 's/old/new/' file.txt                # 各行の最初の old を new に
sed 's/old/new/g' file.txt               # 全部
sed -i 's/old/new/g' file.txt            # ファイル直接書き換え（慎重に）
sed -n '10,20p' file.txt                 # 10〜20 行だけ
sed '/^$/d' file.txt                     # 空行削除
```

- **`s/A/B/`** で A を B に置換（スラッシュ以外の区切り文字も使える）
- `g` は「各行で全部」、`i` は大文字小文字無視、両方なら `gi`

### 5-2. `awk` — フィールド処理

テキストを **空白区切りの列** として扱うのが awk の得意技。

```bash
awk '{ print $1 }' file.txt              # 1 列目を出力
awk '{ print $NF }' file.txt             # 最終列
awk -F ',' '{ print $2 }' data.csv       # CSV の 2 列目
awk '$3 > 100' data.txt                  # 3 列目が 100 超の行
awk '{ sum += $1 } END { print sum }'    # 合計
```

- `$1` `$2` ... は列、`$0` は行全体、`$NF` は最終列
- `-F` で区切り文字を変更

### 5-3. 使い分け

| やりたいこと            | 使うコマンド     |
|-------------------------|------------------|
| 1 対 1 の文字列置換     | `sed`            |
| 列（フィールド）操作    | `awk`            |
| 条件マッチ + 集計       | `awk`            |
| ざっくりフィルタリング  | `grep`           |

## 6. よくある合わせ技

### 6-1. ログからエラー件数を日付ごとに集計

```bash
grep ERROR app.log \
  | awk '{ print $1 }' \
  | sort | uniq -c | sort -rn
```

### 6-2. 巨大ファイルから特定パターンだけ抜き出す

```bash
grep -E '^(ERROR|FATAL)' huge.log > issues.log
```

### 6-3. ディレクトリ内の行数合計

```bash
find src/ -name '*.py' -exec cat {} + | wc -l
```

### 6-4. プロセスを grep して kill

```bash
ps aux | grep chrome | grep -v grep | awk '{ print $2 }' | xargs kill
```

（`pkill chrome` のほうが一発で済む）

## 8. 覚え方のコツ

### 8-1. まずは 3 つのオプションで止める

新しいコマンドを覚えるとき、**最頻出のオプション 3 つだけ** を覚える。

- `ls` → `-l` `-a` `-h`
- `grep` → `-r` `-n` `-i`
- `find` → `-name` `-type` `-exec`
- `sort` → `-r` `-n` `-u`

### 8-2. `man` を読む習慣

```bash
man grep
```

- `/pattern` で検索、`q` で終了（`less` と同じ操作）
- 最初は序盤の **SYNOPSIS** と **EXAMPLES** だけ拾い読み

### 8-3. パイプで積み上げる

1 行で全部書こうとせず、**段階的に `| head` で確認しながら** 組み立てると失敗が少ない：

```bash
grep ERROR app.log | head
grep ERROR app.log | awk '{print $1}' | head
grep ERROR app.log | awk '{print $1}' | sort | uniq -c
```

## 9. つまずきやすいポイント

| 症状                                       | 原因・対処                                           |
|--------------------------------------------|------------------------------------------------------|
| `rm -rf` で必要なものも消えた              | 取り返しがつかない。`-i` / `mv` で退避する癖を       |
| `find -exec` の `\;` を忘れる              | コマンド終了マーカー。`-exec rm {} \;`               |
| `grep` が再帰してくれない                  | `-r` が必要                                          |
| `sed -i` でファイルが空に                  | 途中でエラーに。先に `sed '...'` 出力だけ確認する    |
| `awk '{print $2}'` が空白だらけで壊れる    | 区切り文字が予想と違う（タブ？連続空白？）           |
| スペースを含むファイル名で `find | xargs` が壊れる | `-print0 | xargs -0` を使う                  |

---

## 10. まとめ

- 日常作業の中心は **`ls` / `cd` / `cat` / `grep` / `find`**
- `sed` と `awk` は **ストリーム加工の二大巨頭**。sed = 置換、awk = 列処理
- まずは各コマンドの **3 オプション** を覚える
- **パイプで繋いで積み上げる**のが bash の醍醐味
- 破壊的操作（`rm -rf`, `sed -i`）は **必ず予行確認**
