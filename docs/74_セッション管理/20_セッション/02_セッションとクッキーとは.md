# セッションとクッキーとは

セッションとクッキーは、Webアプリケーションでユーザーの状態を管理する仕組みです。この章では、これらの概念について初心者向けに解説します。

## 📖 セッションとクッキーとは何か

**クッキー（Cookie）**は、ブラウザに保存される小さなデータです。  
**セッション（Session）**は、サーバー側で管理される一時的なデータです。

### 日常生活での例え

- **クッキー**: 会員カード（ブラウザに保存される）
- **セッション**: レストランのテーブル番号（サーバーで管理される）

## 🍪 クッキー（Cookie）

### クッキーとは

クッキーは、サーバーがブラウザに送信し、ブラウザが保存する小さなデータです。

### クッキーの特徴

- **ブラウザに保存される**
- **サーバーに自動的に送信される**
- **有効期限を設定できる**
- **ドメインごとに管理される**

### クッキーの使用例

#### サーバー側での設定

```javascript
const express = require('express');
const app = express();

// クッキーを設定
app.get('/set-cookie', (req, res) => {
  res.cookie('username', 'yamada', {
    maxAge: 24 * 60 * 60 * 1000, // 24時間
    httpOnly: true, // JavaScriptからアクセス不可（セキュリティ）
    secure: true, // HTTPSのみ
    sameSite: 'strict' // CSRF攻撃対策
  });
  res.send('クッキーを設定しました');
});

// クッキーを読み取る
app.get('/get-cookie', (req, res) => {
  const username = req.cookies.username;
  res.json({ username });
});

// クッキーを削除
app.get('/delete-cookie', (req, res) => {
  res.clearCookie('username');
  res.send('クッキーを削除しました');
});
```

#### クライアント側での操作

```javascript
// クッキーを設定（JavaScript）
document.cookie = 'username=yamada; max-age=86400; path=/';

// クッキーを読み取る
function getCookie(name) {
  const value = `; ${document.cookie}`;
  const parts = value.split(`; ${name}=`);
  if (parts.length === 2) {
    return parts.pop().split(';').shift();
  }
}

const username = getCookie('username');
console.log(username);
```

### クッキーの用途

1. **ログイン状態の保持**
2. **ユーザー設定の保存**
3. **ショッピングカートの管理**
4. **トラッキング（広告など）**

## 🔐 セッション（Session）

### セッションとは

セッションは、サーバー側で管理される一時的なデータです。

### セッションの特徴

- **サーバー側で管理される**
- **セッションIDで識別される**
- **セキュリティが高い**
- **サーバーのメモリやデータベースに保存される**

### セッションの使用例

```javascript
const express = require('express');
const session = require('express-session');
const app = express();

// セッションの設定
app.use(session({
  secret: 'your-secret-key',
  resave: false,
  saveUninitialized: false,
  cookie: {
    secure: true, // HTTPSのみ
    httpOnly: true,
    maxAge: 24 * 60 * 60 * 1000 // 24時間
  }
}));

// ログイン処理
app.post('/login', (req, res) => {
  const { username, password } = req.body;
  
  // 認証処理（簡略化）
  if (username === 'yamada' && password === 'password123') {
    // セッションにユーザー情報を保存
    req.session.user = {
      id: 1,
      username: 'yamada',
      email: 'yamada@example.com'
    };
    res.json({ message: 'ログイン成功' });
  } else {
    res.status(401).json({ error: '認証に失敗しました' });
  }
});

// セッションからユーザー情報を取得
app.get('/profile', (req, res) => {
  if (req.session.user) {
    res.json({ user: req.session.user });
  } else {
    res.status(401).json({ error: 'ログインが必要です' });
  }
});

// ログアウト処理
app.post('/logout', (req, res) => {
  req.session.destroy((err) => {
    if (err) {
      return res.status(500).json({ error: 'ログアウトに失敗しました' });
    }
    res.json({ message: 'ログアウトしました' });
  });
});
```

## 🔄 クッキーとセッションの違い

| 項目 | クッキー | セッション |
|------|---------|-----------|
| **保存場所** | ブラウザ | サーバー |
| **サイズ制限** | 約4KB | 制限なし |
| **セキュリティ** | 低い（JavaScriptからアクセス可能） | 高い（サーバー側のみ） |
| **有効期限** | 設定可能 | 設定可能 |
| **用途** | ユーザー設定、トラッキング | ログイン状態、機密情報 |

## 💡 実践例：ログイン機能

### セッションを使ったログイン

```javascript
const express = require('express');
const session = require('express-session');
const app = express();

app.use(express.json());
app.use(session({
  secret: 'secret-key',
  resave: false,
  saveUninitialized: false,
  cookie: { secure: true, httpOnly: true, maxAge: 24 * 60 * 60 * 1000 }
}));

// ログイン
app.post('/api/login', (req, res) => {
  const { username, password } = req.body;
  
  // 認証処理
  if (authenticate(username, password)) {
    req.session.userId = getUserId(username);
    res.json({ message: 'ログイン成功' });
  } else {
    res.status(401).json({ error: '認証に失敗しました' });
  }
});

// 認証が必要なエンドポイント
app.get('/api/profile', (req, res) => {
  if (!req.session.userId) {
    return res.status(401).json({ error: 'ログインが必要です' });
  }
  
  const user = getUserById(req.session.userId);
  res.json(user);
});

// ログアウト
app.post('/api/logout', (req, res) => {
  req.session.destroy();
  res.json({ message: 'ログアウトしました' });
});
```

## ⚠️ セキュリティの注意点

### 1. HttpOnlyフラグ

JavaScriptからアクセスできないようにする。

```javascript
res.cookie('sessionId', sessionId, {
  httpOnly: true // JavaScriptからアクセス不可
});
```

### 2. Secureフラグ

HTTPS接続でのみ送信されるようにする。

```javascript
res.cookie('sessionId', sessionId, {
  secure: true // HTTPSのみ
});
```

### 3. SameSite属性

CSRF攻撃を防ぐ。

```javascript
res.cookie('sessionId', sessionId, {
  sameSite: 'strict' // 同一サイトからのみ送信
});
```

### 4. セッションの有効期限

適切な有効期限を設定する。

```javascript
app.use(session({
  cookie: {
    maxAge: 24 * 60 * 60 * 1000 // 24時間
  }
}));
```

## 🎯 まとめ

- **クッキー**は、ブラウザに保存される小さなデータ
- **セッション**は、サーバー側で管理される一時的なデータ
- **ログイン状態**の管理に使われる
- **セキュリティ**を考慮した設定が重要
- **HttpOnly、Secure、SameSite**などのフラグを適切に設定する
