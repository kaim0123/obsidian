# クッキーとは

クッキー（Cookie）は、Webアプリケーションでユーザーの状態を管理するための重要な仕組みです。この章では、クッキーの概念と使い方について初心者向けに詳しく解説します。

## 📖 クッキーとは何か

**クッキー（Cookie）**は、サーバーがブラウザに送信し、ブラウザが保存する小さなデータです。次回同じサイトにアクセスしたときに、ブラウザが自動的にサーバーに送信します。

### 日常生活での例え

クッキーは、「会員カード」のようなものです。

- **会員カード**: 店で発行され、次回来店時に提示する
- **クッキー**: サーバーが発行し、次回アクセス時に自動的に送信される

会員カードを見れば、あなたが会員であることが分かるように、クッキーを見れば、サーバーはあなたが誰であるかを識別できます。

## 🍪 クッキーの特徴

### 1. ブラウザに保存される

クッキーは、ユーザーのブラウザに保存されます。

```
サーバー → ブラウザ: Set-Cookieヘッダーでクッキーを送信
ブラウザ: クッキーを保存
次回アクセス時: ブラウザが自動的にクッキーを送信
```

### 2. 自動的に送信される

ブラウザは、同じドメインへのリクエストに自動的にクッキーを含めます。

```javascript
// サーバーがクッキーを設定
Set-Cookie: sessionId=abc123; Path=/; HttpOnly

// 次回のリクエストで自動的に送信
Cookie: sessionId=abc123
```

### 3. ドメインごとに管理される

クッキーは、設定されたドメインでのみ送信されます。

```
example.com で設定されたクッキー
  → example.com へのリクエストでのみ送信
  → other.com へのリクエストでは送信されない
```

### 4. サイズ制限がある

1つのクッキーは約4KBまで、1つのドメインあたり約20個まで保存できます。

## 💻 クッキーの使い方

### サーバー側での設定（Express.js）

```javascript
const express = require('express');
const cookieParser = require('cookie-parser');
const app = express();

app.use(cookieParser());

// クッキーを設定
app.get('/set-cookie', (req, res) => {
  res.cookie('username', 'yamada', {
    maxAge: 24 * 60 * 60 * 1000, // 24時間（ミリ秒）
    httpOnly: true, // JavaScriptからアクセス不可
    secure: true, // HTTPSのみ
    sameSite: 'strict' // CSRF攻撃対策
  });
  res.send('クッキーを設定しました');
});

// クッキーを読み取る
app.get('/get-cookie', (req, res) => {
  const username = req.cookies.username;
  res.json({ username: username || 'クッキーがありません' });
});

// クッキーを削除
app.get('/delete-cookie', (req, res) => {
  res.clearCookie('username');
  res.send('クッキーを削除しました');
});
```

### クライアント側での操作（JavaScript）

```javascript
// クッキーを設定
document.cookie = 'username=yamada; max-age=86400; path=/';

// クッキーを読み取る
function getCookie(name) {
  const value = `; ${document.cookie}`;
  const parts = value.split(`; ${name}=`);
  if (parts.length === 2) {
    return parts.pop().split(';').shift();
  }
  return null;
}

// 使用例
const username = getCookie('username');
console.log(username); // 'yamada'

// クッキーを削除（有効期限を過去に設定）
function deleteCookie(name) {
  document.cookie = `${name}=; max-age=0; path=/`;
}

deleteCookie('username');
```

## 🔐 クッキーの属性

### 1. maxAge / expires（有効期限）

クッキーの有効期限を設定します。

```javascript
// maxAge（ミリ秒）
res.cookie('username', 'yamada', {
  maxAge: 24 * 60 * 60 * 1000 // 24時間
});

// expires（日付）
res.cookie('username', 'yamada', {
  expires: new Date(Date.now() + 24 * 60 * 60 * 1000) // 24時間後
});
```

### 2. path（パス）

クッキーを送信するパスを指定します。

```javascript
res.cookie('username', 'yamada', {
  path: '/admin' // /admin以下のパスでのみ送信
});
```

### 3. domain（ドメイン）

クッキーを送信するドメインを指定します。

```javascript
res.cookie('username', 'yamada', {
  domain: '.example.com' // example.comとそのサブドメインで送信
});
```

### 4. httpOnly（JavaScriptからのアクセス制限）

JavaScriptからアクセスできないようにします。セキュリティのため重要です。

```javascript
res.cookie('sessionId', 'abc123', {
  httpOnly: true // JavaScriptからアクセス不可（XSS攻撃対策）
});
```

### 5. secure（HTTPSのみ）

HTTPS接続でのみ送信されるようにします。

```javascript
res.cookie('sessionId', 'abc123', {
  secure: true // HTTPSのみ送信
});
```

### 6. sameSite（CSRF攻撃対策）

クロスサイトリクエストでの送信を制御します。

```javascript
res.cookie('sessionId', 'abc123', {
  sameSite: 'strict' // 同一サイトからのみ送信
  // 'lax': GETリクエストのみクロスサイトで送信
  // 'none': すべてのクロスサイトリクエストで送信（secure必須）
});
```

## 🎯 クッキーの用途

### 1. ログイン状態の保持

```javascript
// ログイン成功時にセッションIDをクッキーに保存
app.post('/api/login', async (req, res) => {
  const { username, password } = req.body;
  
  // 認証処理
  if (await authenticate(username, password)) {
    const sessionId = generateSessionId();
    
    // セッションIDをクッキーに保存
    res.cookie('sessionId', sessionId, {
      httpOnly: true,
      secure: true,
      sameSite: 'strict',
      maxAge: 24 * 60 * 60 * 1000 // 24時間
    });
    
    res.json({ message: 'ログイン成功' });
  } else {
    res.status(401).json({ error: '認証に失敗しました' });
  }
});
```

### 2. ユーザー設定の保存

```javascript
// ユーザーの言語設定を保存
app.post('/api/settings/language', (req, res) => {
  const { language } = req.body;
  
  res.cookie('language', language, {
    maxAge: 365 * 24 * 60 * 60 * 1000, // 1年間
    httpOnly: false // クライアント側でも読み取り可能
  });
  
  res.json({ message: '言語設定を保存しました' });
});
```

### 3. ショッピングカートの管理

```javascript
// ショッピングカートの内容を保存
app.post('/api/cart/add', (req, res) => {
  const { productId, quantity } = req.body;
  
  // 既存のカートを取得
  const cart = JSON.parse(req.cookies.cart || '[]');
  
  // 商品を追加
  cart.push({ productId, quantity });
  
  // クッキーに保存
  res.cookie('cart', JSON.stringify(cart), {
    maxAge: 7 * 24 * 60 * 60 * 1000, // 7日間
    httpOnly: false
  });
  
  res.json({ message: 'カートに追加しました' });
});
```

### 4. トラッキング（分析）

```javascript
// ユーザーの訪問を追跡
app.use((req, res, next) => {
  if (!req.cookies.visitorId) {
    const visitorId = generateVisitorId();
    res.cookie('visitorId', visitorId, {
      maxAge: 365 * 24 * 60 * 60 * 1000, // 1年間
      httpOnly: false
    });
  }
  next();
});
```

## ⚠️ クッキーのセキュリティ

### 1. 機密情報を保存しない

```javascript
// ❌ 間違い（パスワードをクッキーに保存）
res.cookie('password', userPassword); // 危険！

// ✅ 正しい（セッションIDのみ保存）
res.cookie('sessionId', sessionId, {
  httpOnly: true,
  secure: true
});
```

### 2. HttpOnlyフラグの使用

```javascript
// ❌ 間違い（JavaScriptからアクセス可能）
res.cookie('sessionId', sessionId); // XSS攻撃のリスク

// ✅ 正しい（JavaScriptからアクセス不可）
res.cookie('sessionId', sessionId, {
  httpOnly: true // XSS攻撃から保護
});
```

### 3. Secureフラグの使用

```javascript
// ❌ 間違い（HTTPでも送信される）
res.cookie('sessionId', sessionId); // 盗聴のリスク

// ✅ 正しい（HTTPSのみ送信）
res.cookie('sessionId', sessionId, {
  secure: true // HTTPSのみ送信
});
```

### 4. SameSite属性の使用

```javascript
// ❌ 間違い（CSRF攻撃のリスク）
res.cookie('sessionId', sessionId);

// ✅ 正しい（CSRF攻撃から保護）
res.cookie('sessionId', sessionId, {
  sameSite: 'strict' // 同一サイトからのみ送信
});
```

## 🔄 クッキーとセッションの違い

| 項目 | クッキー | セッション |
|------|---------|-----------|
| **保存場所** | ブラウザ | サーバー |
| **サイズ制限** | 約4KB | 制限なし |
| **セキュリティ** | 低い（JavaScriptからアクセス可能） | 高い（サーバー側のみ） |
| **有効期限** | 設定可能 | 設定可能 |
| **用途** | ユーザー設定、トラッキング | ログイン状態、機密情報 |

## 💡 実践例：ログイン機能

### セッションIDをクッキーに保存

```javascript
const express = require('express');
const session = require('express-session');
const app = express();

// セッションの設定（セッションIDはクッキーに保存される）
app.use(session({
  secret: 'your-secret-key',
  resave: false,
  saveUninitialized: false,
  cookie: {
    secure: true, // HTTPSのみ
    httpOnly: true, // JavaScriptからアクセス不可
    maxAge: 24 * 60 * 60 * 1000, // 24時間
    sameSite: 'strict' // CSRF攻撃対策
  }
}));

// ログイン
app.post('/api/login', (req, res) => {
  const { username, password } = req.body;
  
  if (authenticate(username, password)) {
    // セッションにユーザー情報を保存
    req.session.userId = getUserId(username);
    res.json({ message: 'ログイン成功' });
  } else {
    res.status(401).json({ error: '認証に失敗しました' });
  }
});

// 認証が必要なエンドポイント
app.get('/api/profile', (req, res) => {
  if (!req.session.userId) {
    return res.status(401).json({ error: 'ログインが必要です' });
  }
  
  const user = getUserById(req.session.userId);
  res.json(user);
});
```

## 🍪 クッキーの種類

### 1. セッションクッキー

ブラウザを閉じると削除されるクッキー。

```javascript
// maxAgeやexpiresを設定しない
res.cookie('sessionId', 'abc123', {
  httpOnly: true
});
```

### 2. 永続クッキー

有効期限が設定されているクッキー。

```javascript
// maxAgeを設定
res.cookie('username', 'yamada', {
  maxAge: 365 * 24 * 60 * 60 * 1000 // 1年間
});
```

### 3. サードパーティクッキー

別のドメインから設定されるクッキー（トラッキングなどに使用）。

```javascript
// example.com から other.com のクッキーを設定
// 現在、多くのブラウザでブロックされている
```

## 🔍 クッキーの確認方法

### ブラウザの開発者ツール

1. **Chrome/Edge**: F12 → Application → Cookies
2. **Firefox**: F12 → Storage → Cookies
3. **Safari**: 開発メニュー → Webインスペクタ → Storage → Cookies

### JavaScriptで確認

```javascript
// すべてのクッキーを表示
console.log(document.cookie);

// 特定のクッキーを取得
function getCookie(name) {
  const value = `; ${document.cookie}`;
  const parts = value.split(`; ${name}=`);
  if (parts.length === 2) {
    return parts.pop().split(';').shift();
  }
  return null;
}

console.log(getCookie('username'));
```

## ⚠️ よくある間違いと注意点

### 1. 機密情報をクッキーに保存

```javascript
// ❌ 間違い
res.cookie('password', userPassword);
res.cookie('creditCard', cardNumber);

// ✅ 正しい
res.cookie('sessionId', sessionId, {
  httpOnly: true,
  secure: true
});
// 機密情報はサーバー側のセッションに保存
```

### 2. HttpOnlyを設定しない

```javascript
// ❌ 間違い（XSS攻撃のリスク）
res.cookie('sessionId', sessionId);

// ✅ 正しい
res.cookie('sessionId', sessionId, {
  httpOnly: true // JavaScriptからアクセス不可
});
```

### 3. Secureを設定しない（本番環境）

```javascript
// ❌ 間違い（HTTPで送信される）
res.cookie('sessionId', sessionId, {
  httpOnly: true
});

// ✅ 正しい（HTTPSのみ送信）
res.cookie('sessionId', sessionId, {
  httpOnly: true,
  secure: true // 本番環境では必須
});
```

### 4. SameSiteを設定しない

```javascript
// ❌ 間違い（CSRF攻撃のリスク）
res.cookie('sessionId', sessionId, {
  httpOnly: true,
  secure: true
});

// ✅ 正しい（CSRF攻撃から保護）
res.cookie('sessionId', sessionId, {
  httpOnly: true,
  secure: true,
  sameSite: 'strict' // CSRF攻撃対策
});
```

## 🎯 まとめ

- **クッキー**は、ブラウザに保存される小さなデータ
- **自動的に送信**されるため、ログイン状態の保持などに便利
- **セキュリティ**を考慮した設定が重要
- **HttpOnly、Secure、SameSite**などのフラグを適切に設定する
- **機密情報は保存しない**（セッションIDのみ）
- **サイズ制限**がある（約4KB）
