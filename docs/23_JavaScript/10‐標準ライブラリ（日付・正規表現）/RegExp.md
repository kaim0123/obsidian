# RegExp（正規表現）

## 正規表現とは

**正規表現（Regular Expression, RegExp）** は、「文字列のパターン」を表す小さな言語です。電話番号のフォーマット、メールアドレスっぽい文字列、日付の形式…などを検出・抽出・置換するのに使います。

「謎の記号列」に見えますが、少しずつ読めるようになります。

## 作り方

JavaScript では2通りの書き方があります。

```js
// (1) リテラル
const re1 = /hello/;
const re2 = /^\d{4}-\d{2}-\d{2}$/;

// (2) コンストラクタ（動的に組み立てる）
const keyword = "hello";
const re3 = new RegExp(keyword, "i");
```

リテラルは簡潔で読みやすい。動的に組み立てるときだけ `new RegExp` を使います。

## フラグ（オプション）

末尾や第2引数で指定します。

- `g` … グローバル（全てマッチ）
- `i` … 大文字小文字を無視
- `m` … 複数行モード（`^` / `$` が各行頭/末にマッチ）
- `s` … `.` が改行にもマッチ
- `u` … Unicode モード（サロゲートペア対応）
- `y` … sticky（lastIndex から開始）
- `d` … マッチ位置情報を返す

```js
/hello/gi; // 大文字小文字無視＋全マッチ
```

Unicode まわりをちゃんと扱うなら `u` フラグ推奨。

## 文字クラス（何にマッチするか）

| パターン | 意味 |
|---|---|
| `a` | 文字 a |
| `.` | 任意の1文字（改行除く、`s`で改行も） |
| `\d` | 数字（0-9） |
| `\D` | 数字以外 |
| `\w` | 英数字+アンダースコア |
| `\W` | それ以外 |
| `\s` | 空白（スペース・タブ・改行） |
| `\S` | 空白以外 |
| `[abc]` | a, b, c のどれか |
| `[^abc]` | それ以外 |
| `[a-z]` | a から z の範囲 |
| `[0-9a-zA-Z]` | 英数字 |
| `\b` | 単語境界 |
| `\B` | 単語境界でない |

## アンカー（位置）

- `^` … 先頭
- `$` … 末尾
- `\b` … 単語境界

```js
/^hello/.test("hello world"); // true
/world$/.test("hello world"); // true
```

## 繰り返し（量指定子）

| パターン | 意味 |
|---|---|
| `*` | 0回以上 |
| `+` | 1回以上 |
| `?` | 0回または1回（省略可） |
| `{3}` | ちょうど3回 |
| `{3,}` | 3回以上 |
| `{2,5}` | 2〜5回 |

```js
/a+/       // "a", "aa", "aaa"...
/\d{3,4}/  // 数字3〜4桁
```

### 貪欲とレイジー

量指定子の後ろに `?` を付けると、できるだけ **少なく** マッチするようになります。

```js
"<b>bold</b>".match(/<.+>/)[0];  // "<b>bold</b>"（貪欲）
"<b>bold</b>".match(/<.+?>/)[0]; // "<b>"（レイジー）
```

## グループと選択

### グループ

```js
/(abc)+/    // "abc", "abcabc", "abcabcabc"
```

### 選択（or）

```js
/cat|dog|bird/
```

### 名前付きグループ

```js
const m = "2026-04-22".match(/(?<year>\d{4})-(?<month>\d{2})-(?<day>\d{2})/);
console.log(m.groups.year);  // "2026"
```

非常に読みやすいので積極的に使うと良い。

### 非キャプチャグループ

```js
/(?:abc)+/  // キャプチャしないグループ
```

## lookahead / lookbehind（前後読み）

「後ろにこの文字列がある」「前にこれがある」などの条件。

- `(?=...)` … 肯定先読み（後ろにあること）
- `(?!...)` … 否定先読み
- `(?<=...)` … 肯定後読み
- `(?<!...)` … 否定後読み

```js
// 数字の後ろに "円" があるものだけ抽出
"100円 / 200$".match(/\d+(?=円)/); // ["100"]

// "abc" の直前の "a" を除く
```

## 主なメソッド

### RegExp 側

```js
/hello/i.test("Hello world"); // true（真偽判定）
/(\d+)/.exec("abc 123 def");  // ["123", "123", index:4, ...]
```

`exec` は g フラグありで繰り返し呼ぶと、次のマッチに進みます。

```js
const re = /\d+/g;
let m;
while ((m = re.exec("1 2 3"))) {
  console.log(m[0]); // "1", "2", "3"
}
```

### String 側（こちらのほうが使いやすい）

```js
"2026-04-22".match(/\d+/g);         // ["2026","04","22"]
"abc abc".matchAll(/(\w)b/g);       // イテレータ
"abc".search(/b/);                   // 1（位置）
"aaa".replace(/a/g, "b");            // "bbb"
"aaa".replaceAll("a", "b");          // "bbb"
"a,b;c".split(/[,;]/);               // ["a","b","c"]
```

### replace の関数引数

マッチに応じて置換文字列を動的に変える。

```js
"hello world".replace(/\w+/g, (m) => m.toUpperCase());
// "HELLO WORLD"
```

### 置換で参照する

- `$&` … マッチ全体
- `$1`, `$2`, … … キャプチャ
- `$<name>` … 名前付きグループ

```js
"2026-04-22".replace(/(\d{4})-(\d{2})-(\d{2})/, "$3/$2/$1");
// "22/04/2026"
```

## よくあるパターン

```js
// メールっぽい（ざっくり）
/^[^\s@]+@[^\s@]+\.[^\s@]+$/

// URL（簡易）
/^https?:\/\/[^\s]+$/

// 日本の郵便番号
/^\d{3}-?\d{4}$/

// 日付 YYYY-MM-DD
/^\d{4}-\d{2}-\d{2}$/

// 数字だけ
/^\d+$/

// 半角英数
/^[a-zA-Z0-9]+$/
```

## よくある落とし穴

### 1. エスケープ

`.` や `?` などの記号は特別な意味を持ちます。文字通りマッチしたいなら `\.` のようにエスケープ。

```js
/example.com/.test("exampleXcom"); // true！（. は任意1文字）
/example\.com/.test("example.com"); // true
```

### 2. new RegExp のエスケープ

文字列で作ると `\` が2重になる。

```js
new RegExp("\\d+"); // /\d+/
```

テンプレートから作るなら、まずユーザ入力をエスケープする。

```js
function escapeRE(s) {
  return s.replace(/[.*+?^${}()|[\]\\]/g, "\\$&");
}
new RegExp(escapeRE("example.com"));
```

### 3. g フラグと lastIndex

```js
const re = /\d+/g;
re.test("123"); // true（lastIndex が進む）
re.test("123"); // false！
```

`g` 付きの `test`/`exec` は状態を持つので再利用に注意。

### 4. 貪欲マッチの事故

```js
"<p>hi</p><p>bye</p>".match(/<p>.*<\/p>/);
// ["<p>hi</p><p>bye</p>"]（まとめてマッチ）
```

レイジー `.*?` を使うか、`[^<]*` のようにクラスで限定。

### 5. HTML のパースには使わない

正規表現は HTML のような「ネストする構造」を正確に扱えません。DOM パーサを使うのが正解。

## まとめ

- 正規表現は文字列パターンのミニ言語
- リテラル `/pattern/flags` が基本。動的なら `new RegExp`
- `test`, `match`, `replace`, `split` が日常的に使う
- `g`/`i`/`u` フラグと、`^`/`$`/`\b`/`\d`/量指定子をまず押さえる
- 先読み・後読み、名前付きグループは表現力が一気に上がる
- 落とし穴：エスケープ、貪欲マッチ、lastIndex

最初は「コピペして必要な部分だけ変える」で十分です。使っているうちに自然と読めるようになります。
