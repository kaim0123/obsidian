# 配列の重複削除

## 定番：Set を使う

プリミティブの配列なら、これ1行で終わりです。

```js
const unique = [...new Set([1, 2, 2, 3, 3, 3])]; // [1, 2, 3]
```

Set は重複を許さないコレクションなので、配列を Set に入れて戻すだけで重複が消えます。文字列、数値、真偽値、null、undefined いずれも対応。

```js
[...new Set(["a", "b", "a", "c"])]; // ["a", "b", "c"]
[...new Set([true, false, true])];  // [true, false]
```

## filter + indexOf 版

Set が使えない昔の環境や、「書き方で意図を見せたい」場面で。

```js
const unique = arr.filter((v, i) => arr.indexOf(v) === i);
```

**仕組み**：`indexOf` は最初に見つけた位置を返す。「今の位置と最初の位置が一致」する要素だけ残す＝重複の最初だけが残る。

計算量は O(n²) なので、配列が大きいと遅い。Set 版のほうが圧倒的に速い。

## オブジェクトの重複を消す

`Set` はオブジェクトを **参照比較** します。中身が同じでも別オブジェクトなら別物扱い。

```js
const arr = [{ id: 1 }, { id: 1 }, { id: 2 }];
[...new Set(arr)]; // [{id:1},{id:1},{id:2}]（消えない）
```

### id などのキーで重複を消す

```js
function uniqBy(arr, key) {
  const seen = new Set();
  return arr.filter((item) => {
    const k = item[key];
    if (seen.has(k)) return false;
    seen.add(k);
    return true;
  });
}

uniqBy([{ id: 1 }, { id: 1 }, { id: 2 }], "id");
// [{id:1},{id:2}]
```

### Map を使うシンプルな書き方

```js
const unique = [...new Map(arr.map((x) => [x.id, x])).values()];
```

**仕組み**：`[id, x]` のペアで Map を作ると、同じ id は後の値で上書きされる。`.values()` で値だけ取り出す。

後の要素を優先したいときに特に便利。先勝ち（最初の要素を残したい）ならちょっと工夫が必要。

```js
function uniqFirst(arr, keyFn) {
  const map = new Map();
  for (const x of arr) {
    const k = keyFn(x);
    if (!map.has(k)) map.set(k, x); // 既にあれば上書きしない
  }
  return [...map.values()];
}
```

## 関数で比較キーを作る

```js
function uniqBy(arr, keyFn) {
  const seen = new Set();
  return arr.filter((x) => {
    const k = keyFn(x);
    if (seen.has(k)) return false;
    seen.add(k);
    return true;
  });
}

uniqBy([{ name: "太郎", age: 20 }, { name: "太郎", age: 30 }], (u) => u.name);
// [{ name: "太郎", age: 20 }]
```

複合キーは文字列化でOK：

```js
uniqBy(items, (x) => `${x.category}-${x.name}`);
```

## 完全一致（全プロパティ）で重複を消す

単純には `JSON.stringify` をキーにする。

```js
const unique = [...new Map(arr.map((x) => [JSON.stringify(x), x])).values()];
```

**注意**：プロパティ順が同じである前提。順序がバラバラだと別物扱いになる。

順序を揃えたいなら：

```js
const normalize = (o) => JSON.stringify(Object.fromEntries(Object.entries(o).sort()));
```

## 大文字小文字を区別しない

```js
const unique = [...new Set(arr.map((s) => s.toLowerCase()))];
// 元の大小を保ちたいなら uniqBy
const unique2 = uniqBy(arr, (s) => s.toLowerCase());
```

## 連続する重複だけを消す（ランレングス）

```js
function dedupConsecutive(arr) {
  return arr.filter((v, i) => i === 0 || v !== arr[i - 1]);
}

dedupConsecutive([1, 1, 2, 2, 2, 3, 1, 1]); // [1, 2, 3, 1]
```

並び順を保ったまま「ダブり押し」を消すような用途。

## NaN と undefined の扱い

`Set` は NaN を等しいものとして扱います（稀な特例）。

```js
[...new Set([NaN, NaN, 1, 1])]; // [NaN, 1]
```

`indexOf` は NaN を見つけられないので、NaN 混じりの配列は `includes` や Set を使う。

## パフォーマンスの目安

| 方法 | 計算量 | 速さ |
|---|---|---|
| `new Set` → spread | O(n) | ◎ |
| `Map` を使う | O(n) | ◎ |
| `filter + indexOf` | O(n²) | △ |
| `JSON.stringify` キー | O(n) だが定数係数大 | ○ |

1000要素以下なら何を使っても体感変わりませんが、10,000超なら Set/Map 一択です。

## ライブラリ

```js
import uniq from "lodash.uniq";
import uniqBy from "lodash.uniqby";

uniq([1, 2, 2, 3]);
uniqBy([{id:1},{id:1}], "id");
```

## まとめ

- **プリミティブ**：`[...new Set(arr)]` の1行
- **オブジェクト＋キー指定**：`new Map(arr.map(x => [x.id, x])).values()`
- **関数キー**：`uniqBy(arr, fn)` を自作
- **完全一致**：`JSON.stringify` をキーに
- 巨大配列は `filter+indexOf` ではなく Set/Map で

「重複を消す」はよくある需要なので、`[...new Set(arr)]` は完全に暗記しておくと便利。オブジェクト相手なら `uniqBy` パターンが万能です。
