# 配列のシャッフル

## シャッフルとは

配列の要素を **ランダムな順に並べ替える** こと。カードをシャッフルするイメージです。

クイズの問題順、BGMの再生順、ガチャの結果表示など、ランダム順が必要なあらゆる場面で使います。

## よくある失敗例：sort + random

ネットでよく見かけますが、これは **偏りが出る実装** で避けるべき。

```js
// NG：偏る
const bad = [1, 2, 3, 4, 5].sort(() => Math.random() - 0.5);
```

`sort` は比較の一貫性（「A<B, B<C なら A<C」）を前提にしています。ランダムに -0.5 や +0.5 を返すと、この前提が壊れ、**実装依存で偏ったシャッフル** になります。

## 正しい実装：Fisher-Yates アルゴリズム

統計的に均等にシャッフルされる、古典的かつ実用的な方法。

```js
function shuffle(arr) {
  const a = [...arr]; // 元を変えないようにコピー
  for (let i = a.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    [a[i], a[j]] = [a[j], a[i]]; // 交換
  }
  return a;
}

shuffle([1, 2, 3, 4, 5]); // 例: [3, 1, 5, 2, 4]
```

### アルゴリズムの流れ

1. 配列を末尾から見る（`i` が n-1 → 0 に減る）
2. 0〜i のランダムな位置 `j` を選ぶ
3. 位置 i と j を交換
4. 繰り返し

これで **全ての並びが等確率で現れる** ことが数学的に保証されています。

### 破壊版（元を変えてもいい場合）

```js
function shuffleInPlace(arr) {
  for (let i = arr.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    [arr[i], arr[j]] = [arr[j], arr[i]];
  }
  return arr;
}
```

`[...arr]` が不要な分、少し高速。

## 暗号学的に安全なシャッフル

`Math.random` は予測可能な擬似乱数なので、**セキュリティ用途や公平性が必要なガチャ** には不向き。その場合は `crypto.getRandomValues` を使います。

```js
function secureShuffle(arr) {
  const a = [...arr];
  const buf = new Uint32Array(a.length);
  crypto.getRandomValues(buf);

  for (let i = a.length - 1; i > 0; i--) {
    const j = buf[i] % (i + 1); // 厳密にはバイアスが出るので注意
    [a[i], a[j]] = [a[j], a[i]];
  }
  return a;
}
```

※ `% (i+1)` は小さな範囲だとわずかにバイアスが出ます。完全に均等を求めるなら「棄却サンプリング」が必要ですが、普通の用途なら上記で OK。

## ランダムに1つ取り出す（シャッフル不要の場合）

単に「ランダムに1つだけ欲しい」なら：

```js
function pickOne(arr) {
  return arr[Math.floor(Math.random() * arr.length)];
}
```

複数ランダムに選ぶ：

```js
function pickMany(arr, n) {
  return shuffle(arr).slice(0, n);
}
```

## ランダムな整数を取りたい

```js
// a以上b未満
function randInt(a, b) {
  return Math.floor(Math.random() * (b - a)) + a;
}

// a以上b以下
function randIntInclusive(a, b) {
  return Math.floor(Math.random() * (b - a + 1)) + a;
}

randInt(1, 7); // 1〜6
randIntInclusive(1, 6); // 1〜6
```

## シャッフルのバリエーション

### 一部だけシャッフル

```js
// 最初の3つだけシャッフル
const arr = [1, 2, 3, 4, 5];
const first3 = shuffle(arr.slice(0, 3));
const result = [...first3, ...arr.slice(3)];
```

### シード固定（再現可能なランダム）

`Math.random` はシードが固定できません。テストや「昨日と同じ順番」が必要なら、擬似乱数生成を自作します。

```js
function mulberry32(seed) {
  return function () {
    let t = (seed += 0x6D2B79F5);
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

function shuffleWithSeed(arr, seed) {
  const rand = mulberry32(seed);
  const a = [...arr];
  for (let i = a.length - 1; i > 0; i--) {
    const j = Math.floor(rand() * (i + 1));
    [a[i], a[j]] = [a[j], a[i]];
  }
  return a;
}

shuffleWithSeed([1,2,3,4,5], 42); // 毎回同じ並び
```

再現可能なデモ、テスト、ゲームのリプレイ機能などに使えます。

## 落とし穴

### 1. sort で済ませようとする

前述のとおり偏ります。絶対に避ける。

### 2. 元の配列を変えて混乱

破壊版を使うと、渡した配列が書き換わってバグります。レシピとしては **非破壊版を基本** にすると安全。

### 3. セキュリティ要件を見落とす

ガチャや抽選など「公平性」が問われる場面では、`Math.random` は避け、サーバ側 + 暗号的乱数で実装。

## まとめ

- シャッフルは **Fisher-Yates** が定番かつ正しい
- `sort(() => Math.random() - 0.5)` は偏るので使わない
- セキュリティ重視なら `crypto.getRandomValues` + サーバ側処理
- 再現可能ランダムが必要なら擬似乱数を自作
- 1つだけなら `arr[Math.floor(Math.random() * arr.length)]`

「シャッフルしたい」と思ったら、まず Fisher-Yates のテンプレを貼る、くらいの感覚で OK です。
