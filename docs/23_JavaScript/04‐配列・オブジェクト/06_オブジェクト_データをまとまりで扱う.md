## 06-1. オブジェクトの基本（プロパティ、ドット / ブラケット）

### オブジェクトとは

オブジェクトは**「名前（キー）と値のペア」をまとめたデータ構造**です。

```javascript
const user = {
  name: "太郎",
  age: 20,
  isStudent: true,
};
```

### プロパティへのアクセス

```javascript
// ドット記法（基本はこちら）
console.log(user.name);  // → "太郎"
console.log(user.age);   // → 20

// ブラケット記法（キーが動的なとき）
console.log(user["name"]);  // → "太郎"

const key = "age";
console.log(user[key]);     // → 20（変数でキーを指定）
```

**使い分け**：
- 通常 → ドット記法 `user.name`
- キーが変数・特殊文字を含む → ブラケット記法 `user[key]`

### プロパティの追加・変更・削除

```javascript
const user = { name: "太郎" };

// 追加
user.age = 20;
console.log(user);  // → { name: "太郎", age: 20 }

// 変更
user.name = "花子";
console.log(user);  // → { name: "花子", age: 20 }

// 削除
delete user.age;
console.log(user);  // → { name: "花子" }
```

### プロパティの存在確認

```javascript
const user = { name: "太郎", age: 20 };

// in 演算子
console.log("name" in user);   // → true
console.log("email" in user);  // → false

// hasOwnProperty
console.log(user.hasOwnProperty("name"));  // → true
```

### オブジェクトの繰り返し

```javascript
const user = { name: "太郎", age: 20, city: "東京" };

// キーの一覧
console.log(Object.keys(user));    // → ["name", "age", "city"]

// 値の一覧
console.log(Object.values(user));  // → ["太郎", 20, "東京"]

// キーと値のペア
console.log(Object.entries(user)); // → [["name","太郎"], ["age",20], ["city","東京"]]

// for...of で繰り返す
for (const [key, value] of Object.entries(user)) {
  console.log(`${key}: ${value}`);
}
// → name: 太郎
// → age: 20
// → city: 東京
```

## 06-2. 分割代入（object destructuring）

### 基本の分割代入

オブジェクトのプロパティを**個別の変数に取り出す**構文です。

```javascript
const user = { name: "太郎", age: 20, city: "東京" };

// 従来の書き方
const name = user.name;
const age = user.age;

// 分割代入（同じことを1行で）
const { name, age, city } = user;
console.log(name);  // → "太郎"
console.log(age);   // → 20
console.log(city);  // → "東京"
```

### 別名をつける

```javascript
const user = { name: "太郎" };

const { name: userName } = user;
console.log(userName);  // → "太郎"
// console.log(name);   // → ReferenceError（name は定義されない）
```

### デフォルト値

```javascript
const user = { name: "太郎" };

const { name, age = 0, role = "user" } = user;
console.log(name);  // → "太郎"
console.log(age);   // → 0（プロパティがないのでデフォルト値）
console.log(role);  // → "user"
```

### ネストした分割代入

```javascript
const user = {
  name: "太郎",
  address: {
    city: "東京",
    zip: "100-0001",
  },
};

const { name, address: { city } } = user;
console.log(city);  // → "東京"
```

### 関数の引数での分割代入

```javascript
// ❌ 引数でいちいちアクセス
function greet(user) {
  console.log(`${user.name}さん（${user.age}歳）`);
}

// ✅ 引数で分割代入
function greet({ name, age }) {
  console.log(`${name}さん（${age}歳）`);
}

greet({ name: "太郎", age: 20 });
// → 太郎さん（20歳）
```

## 06-3. 省略記法とスプレッド（...）

### プロパティの省略記法

変数名とキー名が同じとき、省略できます。

```javascript
const name = "太郎";
const age = 20;

// ❌ 冗長
const user = { name: name, age: age };

// ✅ 省略記法
const user2 = { name, age };
console.log(user2);  // → { name: "太郎", age: 20 }
```

### メソッドの省略記法

```javascript
// ❌ 冗長
const obj = {
  greet: function() {
    return "Hello";
  }
};

// ✅ 省略記法
const obj2 = {
  greet() {
    return "Hello";
  }
};
```

### スプレッド構文（...）

オブジェクトを展開・コピー・マージするのに使います。

```javascript
// コピー
const original = { a: 1, b: 2 };
const copy = { ...original };
console.log(copy);  // → { a: 1, b: 2 }

// マージ
const defaults = { color: "red", size: "M", weight: 100 };
const custom = { color: "blue", size: "L" };
const result = { ...defaults, ...custom };
console.log(result);  // → { color: "blue", size: "L", weight: 100 }
// 後から書いたものが上書きする

// プロパティを追加してコピー
const user = { name: "太郎" };
const userWithAge = { ...user, age: 20 };
console.log(userWithAge);  // → { name: "太郎", age: 20 }

// プロパティを上書きしてコピー
const updated = { ...user, name: "花子" };
console.log(updated);  // → { name: "花子" }
console.log(user);     // → { name: "太郎" }（元は変わらない）
```

### rest構文（残りを集める）

```javascript
const { name, ...rest } = { name: "太郎", age: 20, city: "東京" };
console.log(name);  // → "太郎"
console.log(rest);  // → { age: 20, city: "東京" }
```

## 06-4. Optional chaining / Nullish coalescing

### Optional chaining（`?.`）

プロパティが存在しないかもしれないとき、エラーを出さずに `undefined` を返します。

```javascript
const user = {
  name: "太郎",
  address: {
    city: "東京",
  },
};

// ❌ ネストが深いとエラーの可能性
// console.log(user.company.name);  // TypeError!

// ✅ Optional chaining
console.log(user.company?.name);  // → undefined（エラーにならない）
console.log(user.address?.city);  // → "東京"
```

```javascript
// 配列やメソッドにも使える
const users = null;
console.log(users?.[0]);         // → undefined
console.log(users?.length);      // → undefined

const obj = {};
console.log(obj.method?.());     // → undefined（メソッドがなくてもエラーにならない）
```

### Nullish coalescing（`??`）

値が `null` または `undefined` のとき、デフォルト値を使います。

```javascript
const name = null;
console.log(name ?? "ゲスト");  // → "ゲスト"

const age = 0;
console.log(age ?? 18);   // → 0（0はnullでもundefinedでもないので、そのまま）
console.log(age || 18);   // → 18（||だと0はfalsyなのでデフォルト値になる！）
```

**`??` と `||` の違い**：

| 値 | `??` の結果 | `||` の結果 |
|-----|-----------|-----------|
| `null` | デフォルト値 | デフォルト値 |
| `undefined` | デフォルト値 | デフォルト値 |
| `0` | **0** | デフォルト値 |
| `""` | **""** | デフォルト値 |
| `false` | **false** | デフォルト値 |

> **ルール：`0` や `""` や `false` を有効な値として扱いたいなら `??` を使う。**

### 組み合わせ

```javascript
const config = {
  database: {
    port: 0,  // 0は有効な値
  },
};

const port = config.database?.port ?? 3306;
console.log(port);  // → 0（?? なので 0 はそのまま使われる）
```

## 06-5. データ構造の設計（形を決める）

### オブジェクトの「形」を考える

データを扱うとき、まず「どういう形で持つか」を考えることが大切です。

```javascript
// ❌ バラバラの変数
let userName1 = "太郎";
let userAge1 = 20;
let userName2 = "花子";
let userAge2 = 25;

// ✅ オブジェクトにまとめる
const users = [
  { name: "太郎", age: 20 },
  { name: "花子", age: 25 },
];
```

### ID をキーにしたオブジェクト（辞書パターン）

```javascript
// 配列：ID で検索するのが遅い
const users = [
  { id: 1, name: "太郎" },
  { id: 2, name: "花子" },
];
const user = users.find(u => u.id === 2);  // 毎回全件探す

// オブジェクト：ID で即座にアクセスできる
const usersById = {
  1: { id: 1, name: "太郎" },
  2: { id: 2, name: "花子" },
};
const user2 = usersById[2];  // 一発で取れる
```

## 06-6. JSON（stringify / parse、保存・通信での定番）

### JSON とは

JSON（JavaScript Object Notation）は、データを**テキスト形式**で表現するフォーマットです。API通信やデータ保存の標準形式。

```json
{
  "name": "太郎",
  "age": 20,
  "hobbies": ["読書", "ゲーム"],
  "address": {
    "city": "東京"
  }
}
```

### JavaScript ↔ JSON の変換

```javascript
// オブジェクト → JSON文字列（stringify）
const user = { name: "太郎", age: 20 };
const json = JSON.stringify(user);
console.log(json);        // → '{"name":"太郎","age":20}'
console.log(typeof json); // → "string"

// 見やすく整形する（第3引数にインデント数）
console.log(JSON.stringify(user, null, 2));
// {
//   "name": "太郎",
//   "age": 20
// }

// JSON文字列 → オブジェクト（parse）
const parsed = JSON.parse(json);
console.log(parsed.name);  // → "太郎"
console.log(typeof parsed); // → "object"
```

### JSON の注意点

```javascript
// JSON にできないもの
JSON.stringify({
  fn: function() {},  // 関数 → 消える
  sym: Symbol("x"),   // Symbol → 消える
  undef: undefined,   // undefined → 消える
  date: new Date(),   // Date → 文字列になる
});
// → '{"date":"2024-01-01T00:00:00.000Z"}'

// 不正なJSONをparseするとエラー
JSON.parse("{ invalid }");  // SyntaxError
```

## 06-7. Map / Set / WeakMap / WeakSet（標準コレクション）

### Map：キーに何でも使えるオブジェクト

```javascript
const map = new Map();

// セット
map.set("name", "太郎");
map.set(42, "数値のキー");
map.set(true, "booleanのキー");

// ゲット
console.log(map.get("name"));  // → "太郎"
console.log(map.get(42));      // → "数値のキー"

// サイズ
console.log(map.size);  // → 3

// 存在確認
console.log(map.has("name"));  // → true

// 削除
map.delete("name");

// 繰り返し
for (const [key, value] of map) {
  console.log(`${key} → ${value}`);
}
```

**Map vs Object の使い分け**：
- キーが文字列/Symbolだけ → 普通のオブジェクト
- キーに数値やオブジェクトを使いたい → Map
- 頻繁にキーの追加・削除がある → Map
- JSONに変換する必要がある → 普通のオブジェクト

### Set：重複しない値のコレクション

```javascript
const set = new Set();

set.add(1);
set.add(2);
set.add(3);
set.add(2);  // 重複は無視される

console.log(set.size);    // → 3
console.log(set.has(2));  // → true

// 配列の重複除去に便利
const arr = [1, 2, 2, 3, 3, 3];
const unique = [...new Set(arr)];
console.log(unique);  // → [1, 2, 3]
```

### WeakMap / WeakSet

キーがオブジェクトだけで、ガベージコレクションの対象になる特殊なコレクション。メモリリークを防ぐのに使います。詳しくは上級者向けなので、「存在を知っている」レベルでOKです。

## 06-8. ディープコピーの考え方（structuredClone / 代替案）

### 浅いコピー（shallow copy）の問題

```javascript
const original = {
  name: "太郎",
  scores: [80, 90, 70],
};

const shallow = { ...original };
shallow.scores.push(100);

console.log(original.scores);  // → [80, 90, 70, 100] ← 元も変わった！
```

スプレッド構文は**1階層目だけ**コピーします。ネストしたオブジェクトや配列は参照のままです。

### structuredClone（深いコピー）

```javascript
const original = {
  name: "太郎",
  scores: [80, 90, 70],
  address: { city: "東京" },
};

const deep = structuredClone(original);
deep.scores.push(100);
deep.address.city = "大阪";

console.log(original.scores);       // → [80, 90, 70]（変わらない！）
console.log(original.address.city); // → "東京"（変わらない！）
```

> `structuredClone` は比較的新しいAPIですが、現在のブラウザとNode.jsで使えます。関数やSymbolはコピーできないので注意。

### JSON を使った代替案

```javascript
const deep2 = JSON.parse(JSON.stringify(original));
```

手軽ですが、`Date`が文字列になる、`undefined`が消える等の制約があります。基本は `structuredClone` を使いましょう。

## よくある間違い

```javascript
// ❌ ネストしたオブジェクトをスプレッドでコピーしたつもり
const copy = { ...original };  // 浅いコピー！ネスト部分は参照のまま

// ❌ for...in でオブジェクトを繰り返す（プロトタイプも含まれる）
for (const key in obj) { ... }
// ✅ Object.keys / Object.entries を使う
for (const [key, value] of Object.entries(obj)) { ... }

// ❌ ?? と || を混同する
const port = config.port || 3000;  // port が 0 だとデフォルト値になる
const port2 = config.port ?? 3000; // port が 0 でもそのまま使われる
```

---

## 重要ポイント

1. オブジェクトは **`{ key: value }` のペア**で構成される
2. **分割代入** `const { name, age } = user` でプロパティを取り出す
3. **スプレッド構文** `{ ...obj }` でコピー・マージ（ただし浅いコピー）
4. **`?.`（Optional chaining）** でネストアクセスのエラーを防ぐ
5. **`??`（Nullish coalescing）** で null/undefined のときだけデフォルト値
6. **`structuredClone`** で深いコピー
7. **Set** で重複除去、**Map** でキーに何でも使えるコレクション

## ミニ課題

**「住所録」プログラムを作ろう**

以下の機能を持つ住所録を作ろう：

```javascript
const addressBook = {
  contacts: [],

  add(contact) { /* 連絡先を追加 */ },
  findByName(name) { /* 名前で検索 */ },
  removeByName(name) { /* 名前で削除（非破壊的に） */ },
  list() { /* 全件表示 */ },
};

addressBook.add({ name: "太郎", phone: "090-1234-5678", city: "東京" });
addressBook.add({ name: "花子", phone: "080-9876-5432", city: "大阪" });

console.log(addressBook.findByName("太郎"));
// → { name: "太郎", phone: "090-1234-5678", city: "東京" }

addressBook.list();
// 全連絡先を表示
```
