## 01-1. 実行のしかた（Console / Node での実行）

### ブラウザの Console で実行する

最も手軽な方法です。ブラウザの開発者ツールを開くだけ。

```javascript
// Console に直接打ち込む
2 + 3
// → 5

"Hello"
// → "Hello"

console.log("こんにちは");
// こんにちは
```

**`console.log()` と直接入力の違い**：

```javascript
// Console に直接打つと「評価結果」が表示される
2 + 3
// → 5（これは評価結果）

// console.log() は「出力」する
console.log(2 + 3);
// 5（これは出力）
// → undefined（console.log自体の戻り値）
```

### HTML ファイルから実行する

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <title>JS練習</title>
</head>
<body>
  <h1>JavaScriptの練習</h1>

  <!-- 方法1: HTMLに直接書く -->
  <script>
    console.log("HTMLから実行！");
  </script>

  <!-- 方法2: 外部ファイルを読み込む（推奨） -->
  <script src="main.js"></script>
</body>
</html>
```

### Node.js で実行する

```bash
# ファイルを作って実行
node main.js

# 対話モード（REPL）で試す
node
> 2 + 3
5
> .exit
```

## 01-2. 値（number / string / boolean / null / undefined）

JavaScriptの値は大きく分けて**プリミティブ（原始的な値）**と**オブジェクト**に分かれます。
この章ではプリミティブを学びます。

### number（数値）

```javascript
// 整数
42
-10
0

// 小数
3.14
-0.5

// 特殊な数値
Infinity       // 無限大
-Infinity      // マイナス無限大
NaN            // Not a Number（数値ではない）
```

```javascript
// NaN の注意点
console.log(0 / 0);          // → NaN
console.log("abc" * 2);      // → NaN
console.log(NaN === NaN);    // → false（NaNは自分自身と等しくない！）
console.log(Number.isNaN(NaN)); // → true（NaNの判定はこれを使う）
```

### string（文字列）

```javascript
// 3種類の書き方
"ダブルクォート"
'シングルクォート'
`バッククォート（テンプレートリテラル）`

// どれを使ってもOK。ただしバッククォートだけ特別な機能がある（後述）
```

```javascript
// 文字列の連結
"Hello" + " " + "World"   // → "Hello World"

// 文字列の長さ
"JavaScript".length        // → 10

// 文字の取り出し
"Hello"[0]                 // → "H"（0から数える！）
"Hello"[4]                 // → "o"
```

### boolean（真偽値）

```javascript
true    // 真（はい）
false   // 偽（いいえ）

// 比較の結果がbooleanになる
3 > 2     // → true
1 === 2   // → false
```

### null と undefined

```javascript
// undefined：「まだ値が入っていない」
let x;
console.log(x);          // → undefined

// null：「意図的に空にした」
let y = null;
console.log(y);          // → null
```

**違いのイメージ**：
- `undefined` = 引き出しを開けたけど何も入っていなかった（勝手にそうなった）
- `null` = 引き出しを空にした（自分でそうした）

### 型の確認：typeof

```javascript
console.log(typeof 42);          // → "number"
console.log(typeof "hello");     // → "string"
console.log(typeof true);        // → "boolean"
console.log(typeof undefined);   // → "undefined"
console.log(typeof null);        // → "object" ← ⚠️ バグ！本当はnullなのに
```

> `typeof null === "object"` は JavaScript の歴史的なバグです。1995年の初期実装のミスがそのまま残っています。null かどうかを調べるには `value === null` を使いましょう。

## 01-3. 演算子（算術 / 比較 / 論理）と真偽

### 算術演算子

```javascript
10 + 3    // → 13  加算
10 - 3    // → 7   減算
10 * 3    // → 30  乗算
10 / 3    // → 3.3333...  除算
10 % 3    // → 1   余り（モジュロ）
2 ** 3    // → 8   べき乗（2の3乗）
```

```javascript
// 複合代入演算子
let count = 0;
count += 1;   // count = count + 1 と同じ → 1
count -= 1;   // count = count - 1 と同じ → 0
count *= 3;   // count = count * 3 と同じ → 0

// インクリメント / デクリメント
let n = 5;
n++;          // n = n + 1 → 6
n--;          // n = n - 1 → 5
```

### 比較演算子

```javascript
// === 厳密等価（型も値も同じ）← これを使う！
1 === 1        // → true
1 === "1"      // → false（型が違う）

// == 抽象等価（型変換してから比較）← 使わない！
1 == "1"       // → true（文字列 "1" を数値に変換してから比較）
0 == false     // → true
"" == false    // → true
null == undefined  // → true
```

> **ルール：常に `===` を使う。`==` は使わない。**
> `==` は暗黙の型変換をするため、予想外の結果になることが多く、バグの温床です。

```javascript
// 大小比較
5 > 3      // → true
5 >= 5     // → true
3 < 5      // → true
3 <= 3     // → true

// 不等価
1 !== 2    // → true
1 !== 1    // → false
```

### 論理演算子

```javascript
// && （AND：両方trueならtrue）
true && true    // → true
true && false   // → false

// || （OR：どちらかtrueならtrue）
true || false   // → true
false || false  // → false

// ! （NOT：反転）
!true           // → false
!false          // → true
```

```javascript
// 実際の使い方
let age = 25;
let hasTicket = true;

// 「20歳以上 かつ チケットを持っている」
if (age >= 20 && hasTicket) {
  console.log("入場できます");
}

// 「学生 または 65歳以上」
let isStudent = false;
if (isStudent || age >= 65) {
  console.log("割引対象です");
}
```

### Truthy と Falsy

JavaScriptでは、boolean以外の値も「真っぽい（truthy）」「偽っぽい（falsy）」と判定されます。

```javascript
// Falsy な値（これだけ覚える！全部で7つ）
false
0
-0
""         // 空文字列
null
undefined
NaN

// 上記以外はすべて Truthy
// 注意：以下はすべて truthy！
"0"        // 文字列の "0"（空でないので truthy）
"false"    // 文字列の "false"（空でないので truthy）
[]         // 空配列（オブジェクトなので truthy）
{}         // 空オブジェクト（オブジェクトなので truthy）
```

```javascript
// if文での活用
let name = "";
if (name) {
  console.log("名前があります");
} else {
  console.log("名前がありません");  // ← こちらが実行される（""はfalsy）
}
```

## 01-4. 文字列（テンプレートリテラル、エスケープ）

### テンプレートリテラル（バッククォート）

```javascript
// 従来の文字列連結
let name = "太郎";
let age = 20;
console.log("私は" + name + "で、" + age + "歳です。");

// テンプレートリテラル（ずっと読みやすい！）
console.log(`私は${name}で、${age}歳です。`);
// → 私は太郎で、20歳です。
```

**`${...}` の中には式を書ける**：

```javascript
let price = 1000;
let tax = 0.1;
console.log(`税込み: ${price * (1 + tax)}円`);
// → 税込み: 1100円

console.log(`3 > 2 は ${3 > 2} です`);
// → 3 > 2 は true です
```

**複数行の文字列**：

```javascript
// 通常の文字列では改行できない（エラーになる）
// let text = "1行目
// 2行目";  // → SyntaxError

// テンプレートリテラルなら改行OK
let text = `1行目
2行目
3行目`;
console.log(text);
// 1行目
// 2行目
// 3行目
```

### エスケープ文字

```javascript
// 特殊な文字を文字列に含めるとき
console.log("He said \"Hello\"");   // → He said "Hello"
console.log('It\'s a pen');         // → It's a pen
console.log("1行目\n2行目");         // → 改行される
console.log("タブ\tタブ");           // → タブ文字が入る
console.log("バックスラッシュ: \\"); // → バックスラッシュ: \
```

## 01-5. 型変換（暗黙 / 明示）と「なぜバグるか」

### 暗黙の型変換（自動で変換される）

JavaScriptは型が違う値を演算すると、**勝手に型を変換する**ことがあります。
これが多くのバグの原因になります。

```javascript
// 文字列 + 数値 → 文字列に連結（数値が文字列に変換される）
"3" + 2       // → "32"（足し算ではなく文字列連結！）
"10" + 5      // → "105"

// 文字列 - 数値 → 数値に変換して計算
"10" - 5      // → 5
"3" * 2       // → 6

// つまり + だけ特殊（文字列連結を優先する）
```

```javascript
// もっとびっくりする例
true + 1      // → 2（true は 1 に変換）
false + 1     // → 1（false は 0 に変換）
"" - 1        // → -1（"" は 0 に変換）
null + 1      // → 1（null は 0 に変換）
undefined + 1 // → NaN（undefined は NaN に変換）
```

### 明示的な型変換（自分で変換する）

```javascript
// 文字列 → 数値
Number("42")      // → 42
Number("3.14")    // → 3.14
Number("")        // → 0
Number("abc")     // → NaN（変換できない）
Number(true)      // → 1
Number(false)     // → 0

// parseInt / parseFloat（先頭から数値を読む）
parseInt("42px")     // → 42（先頭の数値部分だけ読む）
parseInt("abc")      // → NaN
parseFloat("3.14em") // → 3.14

// 数値 → 文字列
String(42)        // → "42"
(42).toString()   // → "42"

// 何でも → boolean
Boolean(0)        // → false
Boolean("")       // → false
Boolean(null)     // → false
Boolean(1)        // → true
Boolean("hello")  // → true
```

### なぜバグるか：実際の例

```javascript
// フォームから取得した値は常に文字列
let input = "5";      // ユーザーが入力した値

// そのまま足すと文字列連結になる！
let result = input + 3;
console.log(result);   // → "53"（期待は 8）

// 正しくは数値に変換してから計算する
let result2 = Number(input) + 3;
console.log(result2);  // → 8
```

## 01-6. 例外（try / catch）とエラーの基本

### エラーが起きるとプログラムが止まる

```javascript
console.log("処理1");
console.log("処理2");
undefinedFunction();       // ← ここでエラー！
console.log("処理3");     // ← 実行されない
```

### try / catch でエラーをキャッチする

```javascript
console.log("処理1");

try {
  // エラーが起きるかもしれない処理
  undefinedFunction();
} catch (error) {
  // エラーが起きたときの処理
  console.log("エラーが発生しました:", error.message);
}

console.log("処理3");  // ← 実行される！
```

出力：
```
処理1
エラーが発生しました: undefinedFunction is not defined
処理3
```

### finally：必ず実行される

```javascript
try {
  console.log("試行中...");
  throw new Error("意図的なエラー");
} catch (error) {
  console.log("エラー:", error.message);
} finally {
  console.log("これは必ず実行される");
}
// 試行中...
// エラー: 意図的なエラー
// これは必ず実行される
```

### エラーを投げる（throw）

```javascript
function divide(a, b) {
  if (b === 0) {
    throw new Error("0で割ることはできません");
  }
  return a / b;
}

try {
  console.log(divide(10, 2));  // → 5
  console.log(divide(10, 0));  // → エラーが投げられる
} catch (error) {
  console.log(error.message);  // → 0で割ることはできません
}
```

> **今の段階では**：try/catch は「エラーでプログラムが止まるのを防ぐ仕組み」と覚えておけばOKです。詳しい使い方は後の章で学びます。

## よくある間違い

```javascript
// ❌ == を使ってしまう
if (x == 0) { ... }
// ✅ === を使う
if (x === 0) { ... }

// ❌ 文字列と数値の足し算を意図せずやる
let total = "100" + 50;  // "10050" になる
// ✅ 数値に変換してから
let total = Number("100") + 50;  // 150

// ❌ console.log のカッコ忘れ
console.log "hello";  // SyntaxError
// ✅ カッコで囲む
console.log("hello");

// ❌ typeof null が "null" だと思っている
if (typeof value === "null") { ... }  // 動かない
// ✅ null は直接比較
if (value === null) { ... }
```

---

## 重要ポイント

1. JavaScriptの値は **number / string / boolean / null / undefined** の5つのプリミティブが基本
2. 比較は必ず **`===`（厳密等価）** を使う。`==` は使わない
3. **テンプレートリテラル** `` `${変数}` `` を使えば文字列の組み立てが楽
4. `+` 演算子は文字列と数値で挙動が変わる。**型を意識する**
5. **Falsy な値**は 7つだけ：`false, 0, -0, "", null, undefined, NaN`
6. エラーが起きても止まらないようにするには **try / catch** を使う
