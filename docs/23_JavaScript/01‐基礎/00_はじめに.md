## 00-1. JavaScriptとは（何ができる／どこで動く）

### JavaScriptってそもそも何？

JavaScriptは**Webページに動きをつけるために生まれたプログラミング言語**です。
1995年にNetscape社のブレンダン・アイクが、わずか10日で最初のバージョンを作ったと言われています。

最初はブラウザの中だけで動く小さな言語でしたが、今では：

- **ブラウザ**（Chrome, Firefox, Safari, Edgeなど）で動くフロントエンド
- **サーバー**（Node.js）で動くバックエンド
- **モバイルアプリ**（React Native など）
- **デスクトップアプリ**（Electron など）
- **IoT・組み込み**

と、あらゆる場所で使われる「世界で最も広く使われている言語の一つ」になりました。

### 具体的に何ができるの？

```
【ブラウザ側（フロントエンド）】
- ボタンをクリックしたら画面が変わる
- フォームに入力した内容をチェックする
- サーバーからデータを取ってきて表示する（API通信）
- アニメーションやインタラクティブな演出

【サーバー側（バックエンド / Node.js）】
- Webサーバーを作る
- データベースを操作する
- ファイルを読み書きする
- コマンドラインツールを作る
```

### JavaScriptの特徴

| 特徴 | 説明 |
|------|------|
| **動的型付け** | 変数に型を宣言しなくていい（楽だが、バグの原因にもなる） |
| **インタプリタ型** | コンパイル不要。書いたらすぐ実行できる |
| **シングルスレッド** | 基本的に一度に一つのことしかしない（でも非同期で工夫する） |
| **プロトタイプベース** | クラスベースとは少し違うオブジェクト指向 |
| **第一級関数** | 関数を変数に入れたり、引数に渡したりできる |

## 00-2. 学習の進め方（教材の読み方・練習のやり方）

### 基本ルール：「読む → 手を動かす → 小さく作る → 直す」

プログラミングの学習で一番大事なのは**手を動かすこと**です。

```
❌ ダメな学習法
   教材を読む → わかった気になる → 次の章へ → 忘れる

✅ よい学習法
   教材を読む → 自分で書いてみる → エラーを直す → 少し変えてみる
```

### この教材の各章の構成

各章は以下の構成になっています：

1. **この章で学ぶこと** ― 何を学ぶかの概要
2. **解説と例** ― コード例つきの説明
3. **よくある間違い** ― 初心者がハマるポイント
4. **重要ポイント** ― 絶対に覚えてほしいこと
5. **練習問題** ― 理解を確認する問題
6. **ミニ課題** ― 自分で作ってみる小さな課題

### 学習のコツ

- **写経（しゃきょう）をしよう**：コードをコピペせず、自分の手で打ち込む。タイプミスでエラーが出るのも学習のうち
- **エラーを恐れない**：エラーは「ここが違うよ」という親切なメッセージ。エラーが出ないと学べない
- **少しずつ変えてみる**：サンプルコードを動かしたら、数値や文字列を変えて「どうなるかな？」と実験する
- **1日15分でもいい**：毎日少しずつ触るのが大事。一気に8時間やるより、毎日30分を2週間のほうが身につく

## 00-3. 開発環境（VS Code / ブラウザ / Node.js / npm）

### 必要なもの

#### 1. ブラウザ（Google Chrome推奨）

すでにパソコンに入っているはずです。Chrome の「開発者ツール」（DevTools）を使うので、Chromeを推奨します。

**開発者ツールの開き方**：
- Windows: `F12` または `Ctrl + Shift + I`
- Mac: `Cmd + Option + I`

開くと「Console」タブがあります。ここに直接JavaScriptを打ち込んで実行できます。

```javascript
// Consoleに打ち込んでみよう
console.log("Hello, World!");
// → Hello, World!

1 + 2
// → 3

"こんにちは".length
// → 5
```

#### 2. Visual Studio Code（VS Code）

Microsoftが作った無料のコードエディタです。プログラマーの間で最も人気があります。

**インストール**：公式サイトからダウンロードしてインストールする。

**おすすめの初期設定**：
- 日本語化：拡張機能「Japanese Language Pack」をインストール
- 自動保存：設定で「Auto Save」を「afterDelay」に変更
- フォントサイズ：見やすい大きさに調整（16px前後がおすすめ）

**最低限覚えるショートカット**：

| 操作 | Windows | Mac |
|------|---------|-----|
| ファイル保存 | `Ctrl + S` | `Cmd + S` |
| ターミナル表示 | `` Ctrl + ` `` | `` Cmd + ` `` |
| コメントアウト | `Ctrl + /` | `Cmd + /` |
| 検索 | `Ctrl + F` | `Cmd + F` |

#### 3. Node.js

JavaScriptをブラウザの外（パソコン上）で実行するための環境です。

**インストール**：公式サイトから「LTS版」をダウンロードしてインストールする。

**確認方法**（ターミナルで実行）：
```bash
node --version
# v20.x.x のように表示されればOK

npm --version
# 10.x.x のように表示されればOK
```

**Node.jsでの実行方法**：
```bash
# ファイルを作って実行
echo 'console.log("Hello from Node!")' > hello.js
node hello.js
# → Hello from Node!
```

#### 4. npm（Node Package Manager）

Node.jsと一緒にインストールされるパッケージ管理ツールです。
他の人が作ったライブラリ（便利な道具）をダウンロードして使えます。
詳しくは11章で学びます。

### フォルダ構成の例

学習用に以下のようなフォルダを作っておくと便利です：

```
js-study/
├── 01-basics/
│   ├── hello.js
│   └── values.js
├── 02-variables/
│   └── scope.js
├── ...
└── index.html    ← ブラウザで試すとき用
```

## 00-4. つまずきポイント集（エラーの読み方、調べ方）

### エラーメッセージの読み方

エラーが出たら、まず**落ち着いて読む**ことが大事です。

エラーメッセージは基本的にこの構造です：

```
エラーの種類: エラーの内容
    at ファイル名:行番号:列番号
```

例：
```
ReferenceError: myVariable is not defined
    at hello.js:3:1
```

これは「hello.js の 3行目で、`myVariable` という変数が定義されていません」という意味です。

### よく見るエラーの種類

| エラー名 | 意味 | よくある原因 |
|----------|------|-------------|
| `SyntaxError` | 文法エラー | カッコの閉じ忘れ、スペルミス |
| `ReferenceError` | 未定義の変数 | 変数名のタイプミス、宣言前に使った |
| `TypeError` | 型の不一致 | nullやundefinedに対してメソッドを呼んだ |
| `RangeError` | 範囲外 | 無限再帰、不正な配列長 |

### エラーの例と対処

```javascript
// SyntaxError: カッコの閉じ忘れ
console.log("hello"
// → SyntaxError: missing ) after argument list
// 対処: ) を追加する → console.log("hello")

// ReferenceError: 変数名のタイプミス
let message = "こんにちは";
console.log(mesage);  // s が一つ足りない
// → ReferenceError: mesage is not defined
// 対処: 正しいスペルに直す → console.log(message)

// TypeError: undefinedにアクセス
let user = undefined;
console.log(user.name);
// → TypeError: Cannot read properties of undefined (reading 'name')
// 対処: userが存在するかチェックする
```

### 調べ方のコツ

1. **エラーメッセージをそのまま検索する**
   - 「TypeError: Cannot read properties of undefined」で検索
   - 英語のままのほうが情報が多い

2. **MDN Web Docs を使う**
   - JavaScriptの公式リファレンス
   - 「MDN Array map」のように「MDN + 知りたいこと」で検索

3. **小さく切り分ける**
   - 長いコードでエラーが出たら、一部をコメントアウトして「どこが原因か」を絞り込む
   - `console.log()` を入れて、変数の中身を確認する

4. **質問するときは**
   - 「動きません」ではなく「こういうコードを書いて、こういう結果を期待したが、こういうエラーが出た」と書く

## よくある間違い

- **VS Codeで書いたのにブラウザで動かない** → HTMLファイルから `<script>` タグで読み込んでいるか確認
- **Node.jsで実行したのにDOMが使えない** → Node.jsにはDOMがない。DOM操作はブラウザ専用
- **`console.log` のスペルミス** → `consolee.log` や `console.lgo` になっていないか確認
- **ファイルを保存し忘れている** → 変更が反映されないときはまず保存を確認（VS Codeのタブに白丸●が出ていたら未保存）

---

## 重要ポイント

1. JavaScriptは**ブラウザでもサーバーでも動く**汎用的な言語
2. 学習は**「読む→書く→試す→直す」の繰り返し**が最も効果的
3. エラーは**敵ではなく味方**。「ここが違うよ」と教えてくれている
4. 開発環境は**VS Code + Chrome + Node.js**があればOK
5. わからないことは**MDN Web Docs**で調べる習慣をつける

## 練習問題

1. ブラウザの開発者ツール（Console）を開いて、以下を実行してみよう：
   - `1 + 1`
   - `"Hello" + " World"`
   - `console.log("私の名前はJavaScriptです")`

2. VS Codeで `hello.js` というファイルを作り、以下を書いて Node.js で実行してみよう：
   ```javascript
   console.log("Hello from VS Code!");
   console.log(1 + 2 + 3);
   ```

3. わざとエラーを出してみよう。以下のコードをそれぞれ実行して、どんなエラーが出るか確認しよう：
   ```javascript
   // (a) 存在しない変数を使う
   console.log(abc);

   // (b) カッコを閉じない
   console.log("hello"

   // (c) undefinedのプロパティにアクセス
   let x = undefined;
   console.log(x.name);
   ```

年齢：（あなたの年齢）
好きな食べ物：（好きな食べ物）
