# クエリ文字列の操作

## クエリ文字列とは

URL の `?` から後ろの部分。

```
https://example.com/search?q=javascript&lang=ja&page=2
                            ↑ここからがクエリ文字列
```

キー=値のペアを `&` で連結した形式。Web アプリでは「検索語」「フィルター」「ページ番号」などを URL に載せるのによく使われます。

## 現代の標準：URLSearchParams

昔は自作や正規表現で扱っていましたが、今は標準 API の **URLSearchParams** が決定版です。

### 文字列からパース

```js
const params = new URLSearchParams("q=javascript&lang=ja&page=2");

params.get("q");        // "javascript"
params.get("lang");     // "ja"
params.get("missing");  // null
params.has("q");        // true
```

### 全部取得

```js
for (const [key, value] of params) {
  console.log(key, value);
}

params.toString(); // "q=javascript&lang=ja&page=2"
```

### 追加・変更・削除

```js
params.set("page", "3");   // 上書き
params.append("tag", "js"); // 追加（同じキー複数 OK）
params.delete("lang");
params.sort();              // キーでソート
```

### 同じキーの複数値

```js
const p = new URLSearchParams("tag=js&tag=ts");
p.getAll("tag"); // ["js", "ts"]
```

`tag[]=js&tag[]=ts` のような PHP 流の記法もある。サーバの仕様に合わせる。

## URL から直接取り出す

現在のページ URL から取り出すなら `location.search` を渡します。

```js
const params = new URLSearchParams(location.search);
const page = Number(params.get("page")) || 1;
```

あるいは URL オブジェクト経由。

```js
const url = new URL("https://example.com/path?q=abc&p=2");
url.searchParams.get("q"); // "abc"
url.searchParams.set("p", "3");
console.log(url.toString()); // "https://example.com/path?q=abc&p=3"
```

`URL` と `URLSearchParams` をセットで使うのが王道。

## オブジェクトからクエリ文字列を作る

```js
const params = new URLSearchParams({
  q: "javascript",
  lang: "ja",
  page: 2,
});
console.log(params.toString()); // "q=javascript&lang=ja&page=2"
```

配列キーは自前で回す必要あり。

```js
const p = new URLSearchParams();
["js", "ts"].forEach((t) => p.append("tag", t));
// "tag=js&tag=ts"
```

## ネストしたオブジェクト

URLSearchParams はフラットな key=value のみ対応。階層構造（`filter[price][gte]=100` など）を扱うならライブラリを検討。

- **qs**（定番）
- **query-string**
- **fast-querystring**

```js
import qs from "qs";
qs.stringify({ filter: { price: { gte: 100 } } });
// "filter[price][gte]=100"
qs.parse("filter[price][gte]=100");
// { filter: { price: { gte: "100" } } }
```

## エンコード／デコード

URLSearchParams は自動でエンコードします。

```js
const p = new URLSearchParams({ q: "こんにちは & Hello" });
p.toString(); // "q=%E3%81%93%E3%82%93%E3%81%AB%E3%81%A1%E3%81%AF+%26+Hello"
```

手動でやるなら：

```js
encodeURIComponent("こんにちは");   // "%E3%81%93%E3%82%93..."
decodeURIComponent("%E3%81%93%E3%82%93..."); // "こんにちは"
```

**注意**：URLSearchParams はスペースを `+` に変換します（`application/x-www-form-urlencoded` の仕様）。一方 `encodeURIComponent` は `%20`。サーバ側がどちらを期待しているか確認する。

## URL を変えずに更新する（SPA 向け）

ページ遷移せず URL だけ書き換える場合：

```js
const params = new URLSearchParams(location.search);
params.set("page", "3");
history.pushState(null, "", `?${params.toString()}`);
// または replaceState（履歴を増やさない）
history.replaceState(null, "", `?${params.toString()}`);
```

Next.js や React Router などフレームワークでは、提供される API を使うのが普通。

## 実例：検索フォーム

```js
const form = document.querySelector("form");
form.addEventListener("submit", (e) => {
  e.preventDefault();
  const data = new FormData(form);
  const params = new URLSearchParams(data);
  location.search = params.toString();
});
```

FormData がそのまま URLSearchParams に渡せる（文字列フィールドのみ）。

## 実例：fetch でクエリを付ける

```js
const params = new URLSearchParams({ q: "JS", page: 1 });
const res = await fetch(`/api/search?${params}`);
```

`params` はそのまま文字列化されます。

## URL クラスの便利機能

```js
const url = new URL("https://example.com:8080/path/page?q=abc#top");

url.protocol; // "https:"
url.hostname; // "example.com"
url.port;     // "8080"
url.pathname; // "/path/page"
url.search;   // "?q=abc"
url.hash;     // "#top"
url.origin;   // "https://example.com:8080"
```

相対 URL を基準 URL と組み合わせる：

```js
new URL("/news", "https://example.com/").toString();
// "https://example.com/news"
```

API エンドポイントの組み立てに便利。

## よくある落とし穴

### 1. 同じキーが上書きされない

```js
const p = new URLSearchParams("a=1&a=2");
p.get("a"); // "1"（最初の1つだけ）
p.getAll("a"); // ["1", "2"]
```

### 2. 空文字とキーなし

```js
const p = new URLSearchParams("a=");
p.get("a"); // ""（空文字）
p.has("a"); // true
```

### 3. Number() はしない

```js
const page = params.get("page"); // "1"（文字列！）
const n = Number(page) || 1;     // 明示的に変換
```

## まとめ

- **`URLSearchParams`** が現代標準、まずこれを覚える
- `URL` オブジェクトと組み合わせて強力
- 階層構造が必要なら `qs` などのライブラリ
- SPA の URL 書き換えは `history.pushState` / `replaceState`
- 値は文字列で返ってくるので、数値に変換する

クエリ文字列を自作正規表現でパースしていた時代は終わりました。標準 API でスッキリ書きましょう。
