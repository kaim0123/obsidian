## 13-1. プロトタイプのイメージ

### プロトタイプとは

JavaScriptのオブジェクトは、別のオブジェクトを**「お手本」として参照する**仕組みを持っています。これが「プロトタイプ」です。

```javascript
const animal = {
  speak() {
    console.log(`${this.name}が鳴きます`);
  },
};

const dog = Object.create(animal);  // animal をプロトタイプにして作る
dog.name = "ポチ";
dog.speak();  // → "ポチが鳴きます"
```

**イメージ**：自分が知らないことを聞かれたら、先輩（プロトタイプ）に聞きに行く。

```
dog → "speak を知ってる？" → 自分にはない → animal（先輩）を見に行く → あった！
```

### なぜ知る必要があるのか

class構文（次のセクション）を使えば直接プロトタイプを触ることは少ないですが、以下の理由で基本を知っておくと役立ちます：

- エラーメッセージの理解（「... is not a function」等）
- `instanceof` の挙動の理解
- ライブラリのコードを読むとき

## 13-2. class の基本（constructor / method）

### class の書き方

```javascript
class User {
  // コンストラクタ（初期化）
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }

  // メソッド
  greet() {
    return `こんにちは、${this.name}です（${this.age}歳）`;
  }

  // ゲッター
  get isAdult() {
    return this.age >= 18;
  }
}

// インスタンスの作成
const user = new User("太郎", 20);
console.log(user.greet());    // → "こんにちは、太郎です（20歳）"
console.log(user.isAdult);    // → true（ゲッターはプロパティのようにアクセス）
```

### プロパティの初期化

```javascript
class Counter {
  count = 0;  // フィールド宣言（初期値）

  increment() {
    this.count++;
  }

  decrement() {
    this.count--;
  }

  getCount() {
    return this.count;
  }
}

const counter = new Counter();
counter.increment();
counter.increment();
console.log(counter.getCount());  // → 2
```

### プライベートフィールド（#）

```javascript
class BankAccount {
  #balance;  // プライベート（外部からアクセスできない）

  constructor(initialBalance) {
    this.#balance = initialBalance;
  }

  deposit(amount) {
    if (amount <= 0) throw new Error("正の金額を入力してください");
    this.#balance += amount;
  }

  withdraw(amount) {
    if (amount > this.#balance) throw new Error("残高不足");
    this.#balance -= amount;
  }

  get balance() {
    return this.#balance;
  }
}

const account = new BankAccount(1000);
account.deposit(500);
console.log(account.balance);    // → 1500
// console.log(account.#balance); // → SyntaxError（外部からアクセス不可）
```

### static メソッド

```javascript
class MathHelper {
  static add(a, b) {
    return a + b;
  }

  static random(min, max) {
    return Math.floor(Math.random() * (max - min + 1)) + min;
  }
}

// インスタンスを作らずに呼べる
console.log(MathHelper.add(2, 3));      // → 5
console.log(MathHelper.random(1, 10));  // → 1〜10のランダム
```

### 継承（extends）

```javascript
class Animal {
  constructor(name) {
    this.name = name;
  }

  speak() {
    console.log(`${this.name}が鳴きます`);
  }
}

class Dog extends Animal {
  constructor(name, breed) {
    super(name);  // 親のコンストラクタを呼ぶ（必須）
    this.breed = breed;
  }

  speak() {
    console.log(`${this.name}（${this.breed}）: ワン！`);
  }

  fetch(item) {
    console.log(`${this.name}が${item}を取ってきた！`);
  }
}

const dog = new Dog("ポチ", "柴犬");
dog.speak();        // → "ポチ（柴犬）: ワン！"
dog.fetch("ボール"); // → "ポチがボールを取ってきた！"
```

## 13-3. 継承より合成（使いどころ）

### 継承の問題点

```javascript
// ❌ 継承が深くなると理解しにくい
class Entity { }
class LivingThing extends Entity { }
class Animal extends LivingThing { }
class Mammal extends Animal { }
class Dog extends Mammal { }
// Dog のメソッドがどこから来ているか追いにくい

// ❌ 複数の機能を継承したいとき困る（JSは単一継承）
// 「泳げる犬」は SwimmableAnimal? SwimmableDog?
```

### 合成（composition）で解決

```javascript
// 機能を関数として切り出す
const canSwim = (obj) => ({
  swim() {
    console.log(`${obj.name}が泳ぎます`);
  },
});

const canFly = (obj) => ({
  fly() {
    console.log(`${obj.name}が飛びます`);
  },
});

// 必要な機能を組み合わせる
function createDuck(name) {
  const duck = { name };
  return {
    ...duck,
    ...canSwim(duck),
    ...canFly(duck),
    quack() {
      console.log(`${name}: ガーガー`);
    },
  };
}

const duck = createDuck("ドナルド");
duck.swim();   // → "ドナルドが泳ぎます"
duck.fly();    // → "ドナルドが飛びます"
duck.quack();  // → "ドナルド: ガーガー"
```

### いつ class を使い、いつ合成を使うか

```
class が向いているとき：
  - 明確な「is-a」関係がある（Dog is an Animal）
  - 状態（プロパティ）と振る舞い（メソッド）をまとめたい
  - インスタンスを複数作る必要がある

合成が向いているとき：
  - 複数の独立した機能を組み合わせたい
  - 継承階層が2段以上になりそうなとき
  - 柔軟に機能を付け替えたいとき
```

## 13-4. 「状態」と「振る舞い」を分ける

### データと処理を分離する

```javascript
// ❌ すべてを1つのクラスに詰め込む
class UserManager {
  constructor() {
    this.users = [];
  }
  addUser(user) { ... }
  removeUser(id) { ... }
  findUser(id) { ... }
  renderUserList() { ... }     // ← 表示もここ？
  saveToDatabase() { ... }     // ← 保存もここ？
  sendEmail(userId) { ... }    // ← メール送信もここ？
}

// ✅ 責務ごとに分ける
// データ（状態）
const state = {
  users: [],
};

// 操作（振る舞い）
function addUser(state, user) {
  return { ...state, users: [...state.users, user] };
}

function findUser(state, id) {
  return state.users.find(u => u.id === id);
}

// 表示は別の関数
function renderUserList(users) { ... }

// 保存も別
function saveUsers(users) { ... }
```

### この考え方が大事な理由

1. **テストしやすい**：純粋な関数は入力と出力だけでテストできる
2. **再利用しやすい**：表示と無関係なロジックは、別の画面でも使える
3. **理解しやすい**：「データ」「ロジック」「表示」が分かれていると、変更箇所が明確

## 13-5. プロトタイプチェーン（"なぜ動くか"の補助線）

### プロトタイプチェーンの仕組み

```javascript
class Animal {
  speak() {
    return "...";
  }
}

class Dog extends Animal {
  bark() {
    return "ワン！";
  }
}

const dog = new Dog();
```

`dog.speak()` が呼ばれるとき：
```
dog → Dog.prototype を見る → speak がない
    → Animal.prototype を見る → speak がある！ → 実行
```

```javascript
// チェーンを確認する
console.log(dog instanceof Dog);     // → true
console.log(dog instanceof Animal);  // → true
console.log(dog instanceof Object);  // → true（すべてのオブジェクトの祖先）
```

### Object.prototype

すべてのオブジェクトは最終的に `Object.prototype` に行き着きます。

```javascript
const obj = {};
obj.toString();      // Object.prototype の toString()
obj.hasOwnProperty("x");  // Object.prototype の hasOwnProperty()
```

### プロトタイプチェーンの図

```
dog
  ↓ __proto__
Dog.prototype
  ↓ __proto__
Animal.prototype
  ↓ __proto__
Object.prototype
  ↓ __proto__
null（終端）
```

> **今の段階では**：classを使えば自動的にプロトタイプチェーンが組まれます。「メソッドが見つかるまで親をたどる仕組みがある」と覚えておけばOKです。

## よくある間違い

```javascript
// ❌ constructorでsuper()を呼び忘れる
class Dog extends Animal {
  constructor(name) {
    // super(name) がない！
    this.name = name;  // ReferenceError
  }
}

// ❌ 継承を使いすぎて深い階層を作る
class A {}
class B extends A {}
class C extends B {}
class D extends C {}  // ← どこまで遡ればいい？

// ❌ classを使うべきでないところで使う
class StringUtils {
  static capitalize(str) { ... }
  static truncate(str, len) { ... }
}
// → これは普通の関数のexportで十分
export function capitalize(str) { ... }
export function truncate(str, len) { ... }
```

---

## 重要ポイント

1. **プロトタイプ**：オブジェクトが「先輩」を参照する仕組み
2. **class**は`constructor`で初期化、メソッドで振る舞いを定義
3. **`#`プレフィックス**でプライベートフィールドを作れる
4. **継承は2段まで**。深くなるなら合成（composition）を検討
5. **状態と振る舞いを分離**すると、テスト・再利用がしやすくなる
6. class はあくまで**プロトタイプの糖衣構文**

## ミニ課題

**「ショッピングカート」をclassで作ろう**

```javascript
class Cart {
  // items はプライベート
  // addItem(name, price, quantity)
  // removeItem(name)
  // getTotal()
  // getItemCount()
  // list() → 全商品を表示
}

const cart = new Cart();
cart.addItem("りんご", 150, 3);
cart.addItem("バナナ", 100, 2);
cart.list();
// りんご x3 = ¥450
// バナナ x2 = ¥200
console.log(`合計: ¥${cart.getTotal()}`);  // → 合計: ¥650
```
