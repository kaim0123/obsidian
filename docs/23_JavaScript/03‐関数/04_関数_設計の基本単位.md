## 04-1. 関数宣言 / 関数式 / アロー関数

### 関数とは

関数は**処理をまとめて名前をつけたもの**です。何度でも呼び出せます。

```javascript
// 「挨拶する」という処理をまとめた
function greet(name) {
  return `こんにちは、${name}さん！`;
}

console.log(greet("太郎"));  // → こんにちは、太郎さん！
console.log(greet("花子"));  // → こんにちは、花子さん！
```

### 関数宣言（function declaration）

```javascript
function add(a, b) {
  return a + b;
}

console.log(add(2, 3));  // → 5
```

特徴：**巻き上げ（hoisting）**される。宣言より前の行でも呼び出せる。

```javascript
// 宣言より前に呼べる
console.log(add(2, 3));  // → 5（エラーにならない）

function add(a, b) {
  return a + b;
}
```

### 関数式（function expression）

```javascript
const add = function(a, b) {
  return a + b;
};

console.log(add(2, 3));  // → 5
```

特徴：巻き上げされない。宣言前に呼ぶとエラー。

### アロー関数（arrow function）

```javascript
const add = (a, b) => {
  return a + b;
};

// 本体が1行なら { } と return を省略できる
const add2 = (a, b) => a + b;

// 引数が1つなら ( ) も省略できる
const double = n => n * 2;

console.log(add(2, 3));     // → 5
console.log(double(4));     // → 8
```

### どれを使えばいいの？

```
基本ルール：
- 普通の関数 → アロー関数を使う（const fn = () => { ... }）
- コールバック（関数を渡すとき）→ アロー関数
- メソッド（オブジェクトの中の関数）→ 状況による（this の問題。後述）
```

```javascript
// ✅ アロー関数の実際の使い方
const numbers = [1, 2, 3, 4, 5];

// map にアロー関数を渡す
const doubled = numbers.map(n => n * 2);
console.log(doubled);  // → [2, 4, 6, 8, 10]

// filter にアロー関数を渡す
const evens = numbers.filter(n => n % 2 === 0);
console.log(evens);    // → [2, 4]
```

## 04-2. 引数・戻り値（デフォルト、可変長、分割代入）

### 基本の引数と戻り値

```javascript
function greet(name) {      // name が引数
  return `Hello, ${name}`;  // return で値を返す
}

let result = greet("太郎"); // "太郎" を渡す
console.log(result);        // → Hello, 太郎
```

### return がないと undefined

```javascript
function sayHello(name) {
  console.log(`Hello, ${name}`);
  // return がない
}

let result = sayHello("太郎");
// Hello, 太郎  ← console.log の出力
console.log(result);  // → undefined（return がないので）
```

### デフォルト引数

```javascript
function greet(name = "ゲスト") {
  return `こんにちは、${name}さん`;
}

console.log(greet("太郎"));  // → こんにちは、太郎さん
console.log(greet());        // → こんにちは、ゲストさん（デフォルト値が使われる）
```

### 可変長引数（rest パラメータ）

```javascript
function sum(...numbers) {
  let total = 0;
  for (const n of numbers) {
    total += n;
  }
  return total;
}

console.log(sum(1, 2, 3));       // → 6
console.log(sum(1, 2, 3, 4, 5)); // → 15
```

`...numbers` で「残りの引数をすべて配列として受け取る」ことができます。

### 引数での分割代入

```javascript
// オブジェクトを受け取って、必要なプロパティだけ取り出す
function printUser({ name, age }) {
  console.log(`${name}（${age}歳）`);
}

let user = { name: "太郎", age: 20, email: "taro@example.com" };
printUser(user);  // → 太郎（20歳）
```

```javascript
// デフォルト値との組み合わせ
function createUser({ name, age = 0, role = "user" } = {}) {
  return { name, age, role };
}

console.log(createUser({ name: "太郎" }));
// → { name: "太郎", age: 0, role: "user" }
```

## 04-3. スコープとクロージャ（「関数が覚える」）

### 関数スコープの復習

```javascript
function outer() {
  let x = 10;  // outer の中で宣言

  function inner() {
    console.log(x);  // 外側の x にアクセスできる
  }

  inner();  // → 10
}

outer();
```

### クロージャとは

クロージャとは、**関数が「自分が作られた場所の変数」を覚えている仕組み**です。

```javascript
function createCounter() {
  let count = 0;  // この変数が「覚えられる」

  return function() {
    count++;
    return count;
  };
}

const counter = createCounter();
console.log(counter());  // → 1
console.log(counter());  // → 2
console.log(counter());  // → 3
```

`createCounter()` が終わっても、返された関数は `count` を覚えています。

**イメージ**：関数が「生まれた部屋の鍵」を持っている。部屋を出ても、鍵を使って元の部屋に戻れる。

### クロージャの実用例

```javascript
// 特定の値を固定する関数を作る
function createMultiplier(factor) {
  return (number) => number * factor;
}

const double = createMultiplier(2);
const triple = createMultiplier(3);

console.log(double(5));   // → 10
console.log(triple(5));   // → 15
```

```javascript
// プライベート変数（外部から直接触れない値）
function createWallet(initialBalance) {
  let balance = initialBalance;

  return {
    deposit(amount) {
      balance += amount;
      return balance;
    },
    withdraw(amount) {
      if (amount > balance) return "残高不足";
      balance -= amount;
      return balance;
    },
    getBalance() {
      return balance;
    }
  };
}

const wallet = createWallet(1000);
console.log(wallet.getBalance());  // → 1000
console.log(wallet.deposit(500));  // → 1500
console.log(wallet.withdraw(200)); // → 1300
// wallet.balance にはアクセスできない（プライベート）
```

## 04-4. 高階関数の入口（関数を渡す）

### 高階関数とは

**関数を引数として受け取る関数**、または**関数を返す関数**を「高階関数」と言います。

JavaScriptでは関数も「値」なので、変数に入れたり、引数に渡したりできます。

```javascript
// 関数を変数に入れる
const sayHello = () => console.log("Hello!");
sayHello();  // → Hello!

// 関数を引数に渡す
function doTwice(fn) {
  fn();
  fn();
}

doTwice(sayHello);
// → Hello!
// → Hello!
```

### コールバック関数

「後で呼び出す関数」をコールバック関数と言います。

```javascript
// setTimeout: 指定時間後に関数を呼ぶ
setTimeout(() => {
  console.log("3秒後に表示");
}, 3000);

// 配列のメソッドに渡す関数もコールバック
const numbers = [1, 2, 3, 4, 5];

numbers.forEach((num) => {
  console.log(num * 10);
});
// → 10, 20, 30, 40, 50
```

### 自分で高階関数を作る

```javascript
// 配列の各要素に処理を適用して新しい配列を返す
function myMap(arr, transform) {
  const result = [];
  for (const item of arr) {
    result.push(transform(item));
  }
  return result;
}

const prices = [100, 200, 300];
const withTax = myMap(prices, price => price * 1.1);
console.log(withTax);  // → [110, 220, 330]
```

## 04-5. this 入門（まずは「困らない」理解）

### this とは

`this` は**「この関数を呼んだオブジェクト」**を指すキーワードです。

```javascript
const user = {
  name: "太郎",
  greet() {
    console.log(`こんにちは、${this.name}です`);
  }
};

user.greet();  // → こんにちは、太郎です
// this は user を指している
```

### this の罠：アロー関数と通常関数の違い

```javascript
const user = {
  name: "太郎",
  friends: ["花子", "次郎"],

  // ❌ アロー関数を使うと this がおかしくなる
  showFriendsBad: () => {
    console.log(this.name);  // → undefined（thisがuserを指さない）
  },

  // ✅ 通常の関数（メソッド短縮記法）なら OK
  showFriendsGood() {
    console.log(this.name);  // → 太郎
  }
};
```

### 今の段階で覚えること

```
1. オブジェクトのメソッドでは this = そのオブジェクト
2. メソッドにはアロー関数を使わない（通常の関数を使う）
3. コールバック関数にはアロー関数を使う（thisの問題を避けられる）
```

```javascript
const user = {
  name: "太郎",
  friends: ["花子", "次郎"],

  showFriends() {
    // ✅ コールバックにアロー関数を使えば、外側のthisを引き継ぐ
    this.friends.forEach((friend) => {
      console.log(`${this.name}の友達: ${friend}`);
    });
  }
};

user.showFriends();
// → 太郎の友達: 花子
// → 太郎の友達: 次郎
```

> `this` の挙動は JavaScript の中でも最も複雑なテーマの一つです。今は上記の3つのルールを覚えれば大丈夫です。

## よくある間違い

```javascript
// ❌ return を忘れる
function add(a, b) {
  a + b;  // return がない！
}
console.log(add(2, 3));  // → undefined

// ❌ アロー関数でオブジェクトを返すとき { } を () で囲まない
const getUser = () => { name: "太郎" };  // ← ブロックと解釈される
console.log(getUser());  // → undefined

const getUser2 = () => ({ name: "太郎" });  // ✅ () で囲む
console.log(getUser2());  // → { name: "太郎" }

// ❌ 引数の数が合わない（エラーにならないので気づきにくい）
function greet(name, age) {
  console.log(`${name}は${age}歳`);
}
greet("太郎");  // → 太郎はundefined歳（エラーにならない！）
```

---

## 重要ポイント

1. 関数の書き方は3つ。基本は**アロー関数**を使う
2. **return** を忘れると `undefined` が返る
3. **デフォルト引数**で引数が省略されたときの値を指定できる
4. **クロージャ**：関数は作られた場所の変数を覚えている
5. **高階関数**：関数を引数に渡す / 関数を返す
6. **`this`**：オブジェクトのメソッドでは通常関数、コールバックではアロー関数

## 練習問題

1. 以下の関数を3つの書き方（関数宣言・関数式・アロー関数）で書こう：
   - 2つの数値を受け取り、大きい方を返す関数 `max`

2. クロージャを使って、呼ぶたびに「前回の値 + 今回の値」を返す関数 `accumulate` を作ろう：
   ```javascript
   const acc = accumulate();
   console.log(acc(5));   // → 5
   console.log(acc(3));   // → 8（5 + 3）
   console.log(acc(10));  // → 18（8 + 10）
   ```

3. 配列と関数を受け取り、配列の各要素に関数を適用した結果を表示する `applyAndPrint` を作ろう：
   ```javascript
   applyAndPrint([1, 2, 3], n => n ** 2);
   // → 1
   // → 4
   // → 9
   ```

## ミニ課題

**「関数電卓」を作ろう**

四則演算の関数をオブジェクトにまとめた電卓を作ろう。

```javascript
const calculator = {
  add: ...,
  subtract: ...,
  multiply: ...,
  divide: ...,
  calculate(a, operator, b) {
    // operator に応じて適切な関数を呼ぶ
  }
};

console.log(calculator.calculate(10, "add", 3));       // → 13
console.log(calculator.calculate(10, "subtract", 3));  // → 7
console.log(calculator.calculate(10, "multiply", 3));  // → 30
console.log(calculator.calculate(10, "divide", 3));    // → 3.333...
console.log(calculator.calculate(10, "divide", 0));    // → "0で割れません"
```
