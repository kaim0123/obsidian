# MOC_バックエンド体系

34_Backend の入口ノート。**サーバーサイドのアプリケーションが、リクエストを受けてから応答を返すまでの内部の仕組みと実装**を扱う。roadmap.sh Backend などの主要カリキュラムの中核トピック（HTTP処理・構造・データアクセス・キャッシュ・非同期・外部連携・エラー処理・スケーリング）をそのまま分野にしている。

## フォルダ構成と運用ルール

| フォルダ | 役割 |
|---|---|
| 00_全体像 | 本MOC・バックエンドの責務マップ |
| 10_サーバーとHTTP処理 | ルーティング・ミドルウェア・リクエストのライフサイクル |
| 20_アプリケーション構造 | レイヤー（Controller/Service/Repository）・DI・設定管理・ディレクトリ設計 |
| 30_データアクセス | ORMの使い方・トランザクション・N+1・コネクションプール・マイグレーション運用 |
| 40_キャッシュ | アプリ内キャッシュ・Redis・HTTPキャッシュ・無効化戦略 |
| 50_非同期・メッセージング | ジョブキュー・スケジューラ・イベント駆動・Webhook受信 |
| 60_外部連携 | 外部APIの呼び出し・リトライ・タイムアウト・冪等性 |
| 70_エラー処理・ロギング | 例外設計・エラーレスポンス・構造化ログ・監視との接続 |
| 80_信頼性・スケーラビリティ | レート制限・負荷分散・水平スケール・ヘルスチェック・グレースフルシャットダウン |
| 90_実装リファレンス | 言語・FW・製品ごとの書き方（Express・Prisma・PostgreSQL …） |

- 10〜80 は **FWに依存しない概念**を書く。特定のFWや製品の書き方は 90 に置き、ここから相互にリンクする
- FWの連載教材は分けず、90 の中で連載の順番のまま保管する
- 次のテーマは兄弟フォルダが本拠地。34 には「バックエンドへの組み込み方」だけを書く

| テーマ | 本拠地 |
