## 詳しい要約

**テーマ：PostgreSQL の基礎から、Node.js（Express）+ pg で CRUD の REST API を作るまで**

PostgreSQL がどんな RDBMS かを説明したあと、SQL Shell（psql）でデータベースとテーブルを作ってデータを入れ、Node.js / Express サーバーと `pg` モジュールで連携して、取得・追加・削除・更新の API を Postman で叩くところまでをハンズオンで解説する入門動画。

---

### PostgreSQL と RDB の基本

- PostgreSQL は **RDBMS**（リレーショナル・データベース管理システム）。DB はデータを入れる箱、MS はその管理システム。
- RDB は Excel のような **テーブル** でデータを管理し、複数のテーブルを共通のキーで結合して関係づける（正規化・主キー・外部キー・トランザクションなどの知識が関わるが本動画では扱わない）。
- RDB には MySQL・Oracle なども、SQL を使わない **NoSQL** には MongoDB・Redis・DynamoDB・Cloud Firestore などがある。
- 簡単なアプリなら NoSQL、大規模で堅牢性・保守運用が求められるならデータベース設計から必要な RDB、という使い分けを提案。

### 構成と準備

- サーバー：Node.js + **Express**、クライアント：**Postman**、DB：PostgreSQL。
- `npm init -y` → `express`・`nodemon`・`pg` をインストールし、ポート 5000 でサーバーを起動。
- PostgreSQL を公式サイトからインストール（設定したパスワードを控える）。付属の **SQL Shell（psql）** で操作する。

### psql での操作

- `\l`：データベース一覧、`CREATE DATABASE users;`：DB 作成、`\c users`：DB に接続、`\dt`：テーブル一覧。
- `CREATE TABLE users (id SERIAL PRIMARY KEY, name VARCHAR(255), email VARCHAR(255), age INT);`（SERIAL で連番、PRIMARY KEY で主キー）。
- `INSERT INTO users (name, email, age) VALUES (...), (...);` で挿入、`SELECT * FROM users;` で全件取得。

### Node.js から接続して API を作る

- `db.js` で `pg` の **Pool** を作成（user・host・database・password・port 5432）してエクスポート。
- `app.use(express.json())` を設定。`pool.query(SQL, [値], callback)` で SQL を実行し、結果は `results.rows`。
- `$1`, `$2` は第1・第2引数を差し込む **プレースホルダ**。

| API | メソッド・パス | SQL / 処理 |
| --- | --- | --- |
| 全ユーザー取得 | GET `/users` | `SELECT * FROM users` |
| 特定ユーザー取得 | GET `/users/:id` | `SELECT * FROM users WHERE id = $1`（id は `req.params`） |
| ユーザー追加 | POST `/users` | 同じ email があればエラー、なければ `INSERT ... VALUES ($1, $2, $3)` → 201 |
| ユーザー削除 | DELETE `/users/:id` | 存在確認してから `DELETE FROM users WHERE id = $1` |
| ユーザー更新 | PUT `/users/:id` | 存在確認してから `UPDATE users SET name = $1 WHERE id = $2` |

- 実演中のミス：重複チェック後に `return` を書かなかったため、エラーを返したあとも INSERT が実行され、「Cannot set headers after they are sent」も発生した。**レスポンスを返したら return で処理を止める** 必要がある。
- POST・DELETE・PUT はブラウザから送れないので Postman で Body（raw / JSON）を指定してリクエストする。

### まとめ

- RDB はテーブルとその関係でデータを管理し、操作には SQL が必須（主要な構文は使いながら覚えればよい）。
- Node.js からは `pg` の Pool と `pool.query` + プレースホルダで SQL を実行して API を組み立てる。
- 追加・削除・更新の前に存在チェックを入れ、エラー時は return で処理を止める。
