# テンプレートエンジン

テンプレートエンジンを使うと、HTMLを動的に生成できます。Express.jsではEJS, Pug, Handlebarsなどがよく使われます。

## 主なテンプレートエンジン
- **EJS**: HTMLに近い記法で学習コストが低い
- **Pug**: インデントベースで簡潔な記法
- **Handlebars**: Mustache系で柔軟な構文

## 導入例（EJS）
```sh
npm install ejs
```
```js
app.set('view engine', 'ejs');
app.get('/', (req, res) => {
  res.render('index', { title: 'トップページ' });
});
```

## レイアウト・パーシャルの活用
- 共通ヘッダーやフッターをパーシャル化
- レイアウトファイルで全体構造を管理

## ベストプラクティス
- ロジックはテンプレートに書きすぎない
- データはコントローラー側で整形
- テンプレートの再利用性を高める
