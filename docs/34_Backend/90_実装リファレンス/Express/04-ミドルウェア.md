# ミドルウェア

ミドルウェアは、リクエストとレスポンスの間に共通処理を挟む仕組みです。

## 仕組みと使い方
- ミドルウェア関数は`(req, res, next)`の形
- `app.use()`で全体適用、`app.get()`等で個別適用

```js
app.use((req, res, next) => {
  console.log('全リクエストで実行');
  next();
});
```

## 公式・サードパーティ製
- 例: `express.json()`（JSONパース）、`morgan`（ログ）、`cors`（CORS対応）

## カスタムミドルウェア
- 独自の認証・ロギング・バリデーションなど

## 利用例
- ログ記録、認証、エラーハンドリング、静的ファイル配信

## ベストプラクティス
- 共通処理はミドルウェア化
- 順序に注意（認証→ルーティング→エラー処理など）
- 再利用性を意識
