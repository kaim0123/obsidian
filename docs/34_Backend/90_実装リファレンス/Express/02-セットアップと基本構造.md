# Express.jsのセットアップと基本構造

## インストール手順
1. Node.jsをインストール（公式サイトからダウンロード）
2. プロジェクトフォルダを作成し、`npm init -y`で初期化
3. Express.jsをインストール
   ```sh
   npm install express
   ```

## 最小構成のサンプル
```js
const express = require('express');
const app = express();

app.get('/', (req, res) => {
  res.send('Hello, Express!');
});

app.listen(3000, () => {
  console.log('サーバーが起動しました');
});
```

## ディレクトリ構成例
```
my-express-app/
├─ node_modules/
├─ public/
├─ routes/
├─ views/
├─ app.js
├─ package.json
```
- `public/` … 静的ファイル（画像・CSS等）
- `routes/` … ルーティング定義
- `views/` … テンプレートエンジン用ファイル
- `app.js` … メインアプリケーション

## package.jsonのポイント
- `scripts`で`nodemon`等を使うと開発効率UP
- 依存パッケージの管理

## 開発時のTips
- `nodemon`で自動再起動
  ```sh
  npm install --save-dev nodemon
  npx nodemon app.js
  ```
- `.env`で環境変数管理
- `express-generator`で雛形作成も可能
