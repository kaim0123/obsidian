# リクエストとレスポンス

Express.jsでは、リクエスト（req）とレスポンス（res）オブジェクトを使って、クライアントとのやり取りを行います。

## reqオブジェクトの主なプロパティ
- `req.params` … ルートパラメータ
- `req.query` … クエリパラメータ
- `req.body` … POSTデータ（`express.json()`等のミドルウェアが必要）
- `req.headers` … リクエストヘッダー

## resオブジェクトの主なメソッド
- `res.send()` … テキストやHTMLを送信
- `res.json()` … JSONデータを送信
- `res.status()` … ステータスコードを設定
- `res.redirect()` … リダイレクト
- `res.sendFile()` … ファイル送信

## データ送信の例
```js
app.get('/text', (req, res) => {
  res.send('テキストレスポンス');
});
app.get('/json', (req, res) => {
  res.json({ message: 'JSONレスポンス' });
});
```

## ベストプラクティス
- 適切なステータスコードを返す
- エラー時は`res.status(400).json({ error: '...' })`のように返す
- JSON APIでは`res.json()`を推奨
