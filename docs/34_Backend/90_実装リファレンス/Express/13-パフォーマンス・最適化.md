## パフォーマンス最適化の基本
- レスポンス速度や同時接続数を向上させる工夫
- コードの無駄を減らし、効率的な処理を心がける

---

## キャッシュ戦略
- レスポンスキャッシュ（例：`res.set('Cache-Control', 'public, max-age=300')`）
- メモリキャッシュ（例：node-cache, Redis）

---

## 負荷分散
- 複数プロセス（Node.jsのclusterモジュール）
- 外部ロードバランサー（Nginx, AWS ELBなど）

---

## ベンチマーク・モニタリング
- Apache Bench, autocannon, Artilleryなどで負荷テスト
- pm2やNew Relicで稼働監視

## Express.jsでの実践例
```js
// レスポンスキャッシュ
app.get('/api/data', (req, res) => {
  res.set('Cache-Control', 'public, max-age=300');
  res.json({ data: 'キャッシュされるデータ' });
});

// clusterによるマルチプロセス
const cluster = require('cluster');
const os = require('os');
if (cluster.isMaster) {
  for (let i = 0; i < os.cpus().length; i++) {
    cluster.fork();
  }
} else {
  // 通常のExpressサーバー起動
}
```
