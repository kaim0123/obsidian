# ルーティング

Express.jsでは、URLごとに処理を振り分ける「ルーティング」が非常に重要です。

## 基本構文
```js
app.get('/path', (req, res) => {
  res.send('GETリクエストに対応');
});
app.post('/path', (req, res) => {
  res.send('POSTリクエストに対応');
});
```

## パラメータ付きルート
```js
app.get('/users/:id', (req, res) => {
  res.send(`ユーザーID: ${req.params.id}`);
});
```

## 動的ルーティング
- ワイルドカード（*）や正規表現も利用可能
- 例: `app.get('/files/*', ...)`

## ルートの分割
- `express.Router()`を使ってルートをモジュール化
```js
const router = require('express').Router();
router.get('/items', ...);
module.exports = router;
```

## ベストプラクティス
- ルートごとにファイル分割
- RESTfulな設計を意識
- ルートの階層構造を整理
