# タイムアウトとキャンセル

> **ひとことで言うと**：`fetch` は放っておくと**いつまでも待つ**。`AbortSignal` という「中止ボタン」を渡しておき、時間切れ（タイムアウト）や不要になったとき（画面を閉じた・検索語が変わった）に押す。

## たとえ話で理解する

電話で問い合わせて保留音が流れ続けているとき、

- 「5分待ってつながらなければ切る」 → **タイムアウト**
- 「もう自分で解決したから切る」 → **キャンセル**

どちらも同じ「電話を切る」操作。Web では `AbortController`（切るボタン）と `AbortSignal`（受話器につないだ線）で表す。

## 基本の書き方

### キャンセル：AbortController

```ts
const controller = new AbortController();
fetch("/api/search?q=ab", { signal: controller.signal });

controller.abort(); // → fetch は AbortError で reject
```

### タイムアウト：AbortSignal.timeout()

```ts
try {
  await fetch("/api/report", { signal: AbortSignal.timeout(10_000) });
} catch (e) {
  if (e instanceof DOMException && e.name === "TimeoutError") { /* 時間切れ */ }
  if (e instanceof DOMException && e.name === "AbortError")   { /* 手動キャンセル */ }
}
```

### 両方：AbortSignal.any()

「10秒で時間切れ」かつ「画面を閉じたら中止」を同時に効かせる。

```ts
const signal = AbortSignal.any([userSignal, AbortSignal.timeout(10_000)]);
await fetch(url, { signal });
```

`AbortSignal.timeout` / `AbortSignal.any` は主要ブラウザと Node.js 20+ で使える。

## ライブラリでの指定

| 道具 | タイムアウト | キャンセル |
|---|---|---|
| fetch | `AbortSignal.timeout(ms)` | `signal` |
| ky v2 | `timeout`（1回あたり・既定10秒）、`totalTimeout`（リトライ込みの合計） | `signal` |
| Axios | `timeout`（ms・既定0＝無制限） | `signal`（`CancelToken` は非推奨） |

**リトライと組み合わせるときの落とし穴**：1回10秒 × リトライ3回＋待ち時間だと、ユーザーは40秒以上待たされる。ky v2 の `totalTimeout` のように「全体の上限」も決めておく。

## よく使う場面

| 場面 | やること |
|---|---|
| 検索ボックスの入力ごとに通信 | 前の通信を abort してから新しいのを送る（古い結果が後から届いて上書きする競合を防ぐ） |
| React の `useEffect` で取得 | クリーンアップ関数で `controller.abort()` |
| TanStack Query | `queryFn: ({ signal }) => getUser(id, signal)` と渡すだけで、不要になったとき自動で中止してくれる |
| 重いダウンロード | 「キャンセル」ボタンに `abort()` をつなぐ |

## 注意点

- abort しても**サーバー側の処理は止まらない**ことが多い。POST を途中で中止しても、注文は作られているかもしれない
- タイムアウトの値は「ユーザーが待てる時間」と「サーバーの処理時間（p99）」の両方から決める
- `AbortError` はユーザーに見せるエラーではない。ログや通知から除外する
