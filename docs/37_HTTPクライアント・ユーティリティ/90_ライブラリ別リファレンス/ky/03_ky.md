# ky（カイ）

> **ひとことで言うと**：ky は fetch の上に「4xx/5xx で例外」「リトライ」「タイムアウト」「フック」「JSONの近道」を足した約5KBのラッパー。fetch を知っていればそのまま使え、2026年の新規プロジェクトでは第一候補になりやすい。

## 基本情報

- 作者：Sindre Sorhus
- 現行：**v2**（2026年リリース。v2.1 が最新）。**Node.js 22+ が必要**。古い Node なら v1 のまま使う
- 動く場所：ブラウザ、Node.js、Deno、Bun（どこでも fetch が動けば動く）

## 基本の使い方

```ts
import ky from "ky";

const user = await ky.get("https://api.example.com/users/42").json<User>();

await ky.post("https://api.example.com/users", { json: { name: "Taro" } });
// json オプションで JSON.stringify と Content-Type を自動でやってくれる

const list = await ky.get("https://api.example.com/users", {
  searchParams: { page: 2 },
}).json<User[]>();
```

## 共通クライアントを作る

```ts
export const api = ky.create({
  prefix: "https://api.example.com/v1", // v1 の prefixUrl から改名
  timeout: 10_000,        // 1回あたり（既定 10秒）
  totalTimeout: 30_000,   // リトライ込みの合計（v2 で追加）
  retry: { limit: 2 },
  hooks: {
    beforeRequest: [
      ({ request }) => request.headers.set("Authorization", `Bearer ${getAccessToken()}`),
    ],
  },
});

// 設定を引き継いで一部だけ変える
const adminApi = api.extend({ headers: { "X-Role": "admin" } });
```

## エラー

```ts
import { HTTPError, NetworkError, TimeoutError } from "ky";

try {
  await api.get("users/42").json();
} catch (e) {
  if (e instanceof HTTPError) {
    e.response.status;
    e.data;          // v2：パース済みのエラーボディ（await 不要）
  } else if (e instanceof TimeoutError) { /* 時間切れ */ }
  else if (e instanceof NetworkError) { /* v2：DNS失敗・接続拒否など */ }
}
```

## スキーマ検証（v2）

Zod・Valibot など Standard Schema 準拠のスキーマを `.json()` に渡すと、検証済み・型付きで返る。

```ts
const user = await api.get("users/42").json(userSchema);
```

## v1 → v2 の主な変更

| 項目 | v1 | v2 |
|---|---|---|
| 接頭URL | `prefixUrl`（先頭 `/` 禁止） | `prefix`（先頭 `/` 可）＋標準的に解決する `baseUrl` |
| フックの引数 | `(request, options, …)` | 状態オブジェクト1つ `{ request, options, retryCount, … }` |
| `beforeError` | `HTTPError` のときだけ | すべてのエラーで呼ばれる |
| 自動リトライ | 広め | 本物のネットワーク障害に限定（`NetworkError`） |
| 全体タイムアウト | なし | `totalTimeout` |
| 空レスポンス | — | `.json()` は空・204 で例外 |
| `searchParams` | 置き換え | 既存のクエリとマージ |
| 新フック | — | `init`（最初に動く） |

## Axios・fetch との違い

- fetch との差：4xx/5xx で例外、リトライ、タイムアウト、フック、`json` 近道
- Axios との差：8分の1ほどのサイズ。`Request`/`Response` など標準の型をそのまま使う。アップロード進捗の表示は Axios（`onUploadProgress`）のほうが実績がある
