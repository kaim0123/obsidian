## 🚀 使い方

### 初心者の方

1. **まず読む**: [02-専門用語集.md](02-専門用語集.md) - わからない用語を調べる
2. **基本を学ぶ**: [01-基本操作とショートカット.md](01-基本操作とショートカット.md)
3. **拡張機能を入れる**: [03-拡張機能.md](03-拡張機能.md)
4. **拡張機能を設定する**: [09-拡張機能の設定と管理.md](09-拡張機能の設定と管理.md)
5. **実務で使う機能**: [06-実務でよく使う機能.md](06-実務でよく使う機能.md)

### 経験者の方

必要なセクションを参照してください。各ファイルは独立しているので、必要な部分だけ読めます。

### 実務で使う方

以下の順序で読むことを推奨します：

1. [01-基本操作とショートカット.md](01-基本操作とショートカット.md) - ショートカットキーを覚える
2. [03-拡張機能.md](03-拡張機能.md) - 推奨拡張機能をインストール
3. [09-拡張機能の設定と管理.md](09-拡張機能の設定と管理.md) - 拡張機能の設定と管理
4. [06-実務でよく使う機能.md](06-実務でよく使う機能.md) - マルチカーソル、検索・置換等
5. [04-Git統合.md](04-Git統合.md) - Gitの効率的な使い方
6. [05-デバッグ機能.md](05-デバッグ機能.md) - デバッグの効率化
7. [07-設定とカスタマイズ.md](07-設定とカスタマイズ.md) - 環境構築

## 📖 各ファイルの特徴

- **初心者向け解説**: 専門用語に「用語解説」を追加
- **実務重視**: 実務でよく使う機能を優先的に解説
- **使用頻度表示**: ショートカットキーに使用頻度（★）を表示
- **実践例**: コード例や使用例を豊富に掲載
- **トラブルシューティング**: よくある問題と解決方法を解説

1. **実際に使ってみる**: 読んだ内容をすぐにVSCodeで試す
