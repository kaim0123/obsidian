## 設定ファイル

VSCodeの設定は、JSON形式のファイルで管理されます。

### 設定の種類

- **ユーザー設定**: すべてのプロジェクトに適用される設定
- **ワークスペース設定**: 現在のプロジェクトのみに適用される設定

### 設定を開く方法

- **方法1**: `Ctrl + ,`（設定UI）
- **方法2**: `Ctrl + Shift + P` → 「Preferences: Open User Settings (JSON)」（JSON形式）

**用語解説**:
- **ワークスペース**: プロジェクトのフォルダやファイルをまとめて管理する単位
- **JSON**: データを表現する形式。設定ファイルによく使われます。

## 実務でよく変更する設定

### settings.jsonの例

```json
{
  // ===== エディタ設定 =====
  "editor.fontSize": 14,
  "editor.fontFamily": "Consolas, 'Courier New', monospace",
  "editor.tabSize": 2,
  "editor.insertSpaces": true,
  "editor.formatOnSave": true,
  "editor.codeActionsOnSave": {
    "source.fixAll.eslint": true
  },
  "editor.wordWrap": "on",
  "editor.minimap.enabled": true,
  "editor.suggestSelection": "first",
  
  // ===== ファイル設定 =====
  "files.autoSave": "afterDelay",
  "files.autoSaveDelay": 1000,
  "files.exclude": {
    "**/.git": true,
    "**/.DS_Store": true,
    "**/node_modules": true,
    "**/.vscode": false
  },
  "files.encoding": "utf8",
  "files.eol": "\n",
  
  // ===== 検索設定 =====
  "search.exclude": {
    "**/node_modules": true,
    "**/dist": true,
    "**/build": true,
    "**/.git": true
  },
  "search.useIgnoreFiles": true,
  
  // ===== ターミナル設定 =====
  "terminal.integrated.defaultProfile.windows": "PowerShell",
  "terminal.integrated.fontSize": 12,
  "terminal.integrated.cursorBlinking": true,
  
  // ===== その他 =====
  "workbench.colorTheme": "Dark+",
  "workbench.iconTheme": "material-icon-theme"
}
```

### 各設定の説明

#### エディタ設定

- **`editor.fontSize`**: フォントサイズ（デフォルト: 14）
- **`editor.fontFamily`**: フォント（等幅フォントを推奨）
- **`editor.tabSize`**: タブのサイズ（スペース数、デフォルト: 4）
- **`editor.insertSpaces`**: タブをスペースに変換（`true`推奨）
- **`editor.formatOnSave`**: 保存時に自動フォーマット（`true`推奨）
- **`editor.codeActionsOnSave`**: 保存時に実行するアクション（ESLintの自動修正等）
- **`editor.wordWrap`**: 行の折り返し（`"on"`で有効化）
- **`editor.minimap.enabled`**: ミニマップの表示（`true`で有効化）
- **`editor.suggestSelection`**: 補完候補の選択方法（`"first"`で最初の候補を選択）

**用語解説**:
- **フォーマット**: コードの見た目を整えること
- **ミニマップ**: エディタの右側に表示される、コード全体の縮小図

#### ファイル設定

- **`files.autoSave`**: 自動保存の設定
  - `"off"`: 無効
  - `"afterDelay"`: 一定時間後に自動保存
  - `"onFocusChange"`: フォーカスが外れた時に自動保存
- **`files.autoSaveDelay`**: 自動保存の遅延時間（ミリ秒、デフォルト: 1000）
- **`files.exclude`**: エクスプローラーで非表示にするファイル・フォルダ
- **`files.encoding`**: ファイルの文字コード（`"utf8"`推奨）
- **`files.eol`**: 改行コード（`"\n"`はLF、`"\r\n"`はCRLF）

**用語解説**:
- **文字コード**: 文字をコンピューターが理解できる形式に変換する方法。UTF-8が最も一般的です。
- **改行コード**: 改行を表す文字。WindowsはCRLF、Mac/LinuxはLFを使います。

#### 検索設定

- **`search.exclude`**: 検索対象から除外するファイル・フォルダ
- **`search.useIgnoreFiles`**: `.gitignore`等の設定ファイルを検索除外に使用

**用語解説**:
- **`.gitignore`**: Gitで管理しないファイルを指定するファイル

#### ターミナル設定

- **`terminal.integrated.defaultProfile.windows`**: Windowsのデフォルトシェル（PowerShell、コマンドプロンプト等）
- **`terminal.integrated.fontSize`**: ターミナルのフォントサイズ
- **`terminal.integrated.cursorBlinking`**: カーソルの点滅（`true`で有効化）

## キーボードショートカットのカスタマイズ

よく使うコマンドにショートカットキーを割り当てることができます。

### ショートカット設定を開く

- **ショートカット**: `Ctrl + K` → `Ctrl + S`
- **または**: `Ctrl + Shift + P` → 「Preferences: Open Keyboard Shortcuts」

### ショートカットの変更

1. コマンドを検索
2. 変更したいショートカットをダブルクリック
3. 新しいキーの組み合わせを入力
4. Enterキーで確定

### よくカスタマイズされるショートカット

- **フォーマット**: `Shift + Alt + F`（デフォルト）→ `Ctrl + Shift + F`など
- **ターミナルの表示/非表示**: `Ctrl + @`（デフォルト）→ `Ctrl + `` `など
- **コマンドパレット**: `Ctrl + Shift + P`（デフォルト、変更する人は少ない）

## テーマ

VSCodeの見た目を変更できます。

### テーマを変更

- **ショートカット**: `Ctrl + K` → `Ctrl + T`
- **または**: `Ctrl + Shift + P` → 「Preferences: Color Theme」

### 人気のテーマ

- **Dark+**: VSCodeのデフォルト（ダーク）
- **Light+**: VSCodeのデフォルト（ライト）
- **One Dark Pro**: 人気のダークテーマ
- **Material Theme**: Material Design風のテーマ
- **Monokai**: シンプルなダークテーマ

### テーマのインストール

1. 拡張機能パネル（`Ctrl + Shift + X`）を開く
2. テーマ名で検索
3. 「インストール」をクリック
4. `Ctrl + K` → `Ctrl + T`でテーマを選択

### アイコンテーマ

ファイルのアイコンを変更できます。

- **Material Icon Theme**: 人気のアイコンテーマ
- **VSCode Icons**: シンプルなアイコンテーマ

**設定方法**:
1. 拡張機能でアイコンテーマをインストール
2. `Ctrl + Shift + P` → 「Preferences: File Icon Theme」
3. テーマを選択

## フォント設定

コードを見やすくするために、等幅フォントを使うことを推奨します。

### 推奨フォント

- **Consolas**: Windowsに標準搭載
- **Courier New**: 多くのOSに標準搭載
- **Fira Code**: リガチャ（文字の結合）に対応
- **Source Code Pro**: Adobe製の等幅フォント
- **JetBrains Mono**: JetBrains製の等幅フォント

### フォントの設定

```json
{
  "editor.fontFamily": "Consolas, 'Courier New', monospace",
  "editor.fontSize": 14,
  "editor.fontLigatures": true
}
```

**説明**:
- **`editor.fontFamily`**: フォント名をカンマ区切りで指定（左から優先）
- **`editor.fontSize`**: フォントサイズ
- **`editor.fontLigatures`**: リガチャを有効化（`true`の場合）

**用語解説**:
- **等幅フォント**: すべての文字が同じ幅のフォント。コードを見やすくするために重要です。
- **リガチャ**: 複数の文字を1つの記号のように表示する機能（例: `->`が`→`のように表示される）

## ワークスペース設定

プロジェクトごとに設定を保存できます。

### ワークスペース設定ファイル

プロジェクトのルートに`.vscode/settings.json`を作成します。

**例**:
```json
{
  "editor.tabSize": 2,
  "editor.formatOnSave": true,
  "files.exclude": {
    "**/node_modules": true,
    "**/dist": true
  }
}
```

### ワークスペース設定のメリット

- **プロジェクトごとに設定**: チームで同じ設定を共有できる
- **Gitで管理**: `.vscode`フォルダをGitで管理すれば、チーム全員が同じ設定を使える

**注意**: `.vscode`フォルダをGitで管理する場合は、個人の設定（ユーザー設定）は含めないようにしましょう。

## 設定のバックアップ

設定をバックアップして、他のPCでも同じ環境を再現できます。

### 方法1: Settings Sync（推奨）

1. `Ctrl + Shift + P` → 「Settings Sync: Turn On...」
2. GitHubまたはMicrosoftアカウントでログイン
3. 設定が自動で同期される

### 方法2: 手動でエクスポート

1. 設定ファイルの場所を確認
   - Windows: `%APPDATA%\Code\User\settings.json`
   - Mac: `~/Library/Application Support/Code/User/settings.json`
   - Linux: `~/.config/Code/User/settings.json`
2. ファイルをコピーして保存

## まとめ

VSCodeをカスタマイズすることで、自分に合った開発環境を構築できます。

**推奨設定**:
1. **フォント**: 等幅フォントを使用
2. **自動保存**: `"afterDelay"`で有効化
3. **自動フォーマット**: 保存時に自動フォーマット
4. **テーマ**: 目に優しいダークテーマ
5. **検索除外**: `node_modules`等を除外
