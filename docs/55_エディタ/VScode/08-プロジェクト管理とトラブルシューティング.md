## プロジェクト管理

### プロジェクトとは

**プロジェクト**は、1つのアプリやプログラムを作るためのファイル群です。通常は1つのフォルダにまとめられます。

**用語解説**:
- **プロジェクト**: 1つのアプリやプログラムを作るためのファイル群。Webサイト、ゲーム、アプリなど。

### プロジェクトの開き方

1. **フォルダを開く**: `Ctrl + K` → `Ctrl + O`
2. **最近開いたフォルダ**: `Ctrl + R`
3. **ワークスペースを開く**: 「ファイル」→「ワークスペースを開く」

---

## ワークスペース

**ワークスペース**は、複数のフォルダを1つのワークスペースにまとめて管理する機能です。

### ワークスペースの作成

1. 「ファイル」→「ワークスペースにフォルダを追加」
2. フォルダを選択
3. 必要に応じて追加のフォルダを追加
4. ワークスペースを保存: `Ctrl + K` → `S`

### ワークスペースファイル

ワークスペースは`.code-workspace`ファイルに保存されます。

**例**:
```json
{
  "folders": [
    {
      "path": "frontend"
    },
    {
      "path": "backend"
    }
  ],
  "settings": {
    "editor.tabSize": 2
  }
}
```

### ワークスペースのメリット

- **複数フォルダを管理**: フロントエンドとバックエンドを同時に開ける
- **設定の共有**: ワークスペース全体に設定を適用
- **検索範囲の拡大**: 複数フォルダを横断して検索

**用語解説**:
- **ワークスペース**: プロジェクトのフォルダやファイルをまとめて管理する単位。複数のフォルダを1つのワークスペースにまとめることも可能です。

## .vscodeフォルダ

プロジェクト固有の設定を保存するフォルダです。

### .vscodeフォルダの構成

```
プロジェクト/
  .vscode/
    settings.json      # ワークスペース設定
    launch.json        # デバッグ設定
    tasks.json         # タスク設定
    extensions.json    # 推奨拡張機能
```

### settings.json

ワークスペース固有の設定を保存します。

**例**:
```json
{
  "editor.tabSize": 2,
  "editor.formatOnSave": true,
  "files.exclude": {
    "**/node_modules": true,
    "**/dist": true
  }
}
```

### launch.json

デバッグの設定を保存します。詳細は「[デバッグ機能](05-デバッグ機能.md)」を参照してください。

### tasks.json

ビルドやテストなどのタスクを定義します。詳細は「[タスクの設定](#タスクの設定)」を参照してください。

### extensions.json

プロジェクトで推奨する拡張機能を指定します。

**例**:
```json
{
  "recommendations": [
    "esbenp.prettier-vscode",
    "dbaeumer.vscode-eslint",
    "ms-python.python"
  ]
}
```

**効果**: プロジェクトを開いた時に、推奨拡張機能がインストールされていない場合、通知が表示されます。

## タスクの設定

**タスク**は、ビルドやテストなどをVSCodeから実行する機能です。

### タスクの作成

1. `Ctrl + Shift + P` → 「Tasks: Configure Task」
2. 「タスクのテンプレートから作成」を選択
3. テンプレートを選択（npm、TypeScript等）
4. タスクを定義

### tasks.jsonの例

#### npmスクリプトの例

```json
{
  "version": "2.0.0",
  "tasks": [
    {
      "type": "npm",
      "script": "build",
      "problemMatcher": [],
      "label": "npm: build",
      "group": {
        "kind": "build",
        "isDefault": true
      }
    },
    {
      "type": "npm",
      "script": "test",
      "problemMatcher": [],
      "label": "npm: test"
    }
  ]
}
```

**説明**:
- **`type`**: タスクの種類（`npm`、`shell`等）
- **`script`**: 実行するスクリプト名
- **`label`**: タスクの表示名
- **`group`**: タスクのグループ（`build`、`test`等）
- **`isDefault`**: デフォルトタスクに設定（`Ctrl + Shift + B`で実行）

#### シェルコマンドの例

```json
{
  "version": "2.0.0",
  "tasks": [
    {
      "label": "Python: 実行",
      "type": "shell",
      "command": "python",
      "args": ["${file}"],
      "problemMatcher": []
    }
  ]
}
```

**説明**:
- **`command`**: 実行するコマンド
- **`args`**: コマンドの引数
- **`${file}`**: 現在開いているファイルのパス

### タスクの実行

- **方法1**: `Ctrl + Shift + P` → 「Tasks: Run Task」→ タスクを選択
- **方法2**: `Ctrl + Shift + B`（ビルドタスクの場合）

**用語解説**:
- **ビルド**: ソースコードを実行可能な形式に変換すること
- **タスク**: ビルドやテストなどをVSCodeから実行する機能

## トラブルシューティング

よくある問題と解決方法を紹介します。

### 1. 拡張機能が動作しない

**症状**: 拡張機能をインストールしたが、機能が使えない

**解決方法**:
1. VSCodeを再起動
2. 拡張機能を無効化→再有効化
3. 拡張機能を再インストール
4. 拡張機能の設定を確認

### 2. フォーマットが効かない

**症状**: コードをフォーマットしようとしても何も起こらない

**解決方法**:
1. フォーマッターがインストールされているか確認（Prettier、ESLint等）
2. デフォルトフォーマッターを設定: `Ctrl + Shift + P` → 「Format Document With...」
3. 設定で「Editor: Format On Save」が有効か確認
4. ファイルの言語モードが正しいか確認（右下の言語名をクリック）

### 3. Gitが認識されない

**症状**: ソース管理パネルにGitの変更が表示されない

**解決方法**:
1. Gitがインストールされているか確認: ターミナルで `git --version`
2. Gitがインストールされていない場合: [Git公式サイト](https://git-scm.com/)からインストール
3. パスが通っているか確認: ターミナルで `git` コマンドが実行できるか
4. リポジトリが初期化されているか確認: `.git`フォルダが存在するか

### 4. ターミナルが開かない

**症状**: ターミナルを開こうとしても開かない

**解決方法**:
1. `Ctrl + Shift + @`でターミナルを開く
2. 設定でデフォルトシェルを確認: `Ctrl + ,` → 「terminal.integrated.defaultProfile」
3. シェルが正しくインストールされているか確認

### 5. パフォーマンスが遅い

**症状**: VSCodeの動作が遅い、フリーズする

**解決方法**:
1. **拡張機能を確認**: 不要な拡張機能を無効化
2. **大きなファイルを閉じる**: 大きなファイル（数MB以上）を開いていないか確認
3. **検索除外を設定**: `files.watcherExclude`で監視対象を除外
   ```json
   {
     "files.watcherExclude": {
       "**/node_modules/**": true,
       "**/dist/**": true,
       "**/.git/**": true
     }
   }
   ```
4. **VSCodeを再起動**: メモリリークの可能性がある場合
5. **PCのリソースを確認**: メモリやCPUの使用率を確認

### 6. 補完が効かない

**症状**: コード補完（IntelliSense）が表示されない

**解決方法**:
1. 言語モードが正しいか確認（右下の言語名をクリック）
2. 必要な拡張機能がインストールされているか確認
3. 設定で補完が無効化されていないか確認: `Ctrl + ,` → 「suggest」で検索
4. VSCodeを再起動

### 7. ファイルが保存できない

**症状**: ファイルを保存しようとしても保存されない

**解決方法**:
1. ファイルの権限を確認: 書き込み権限があるか
2. ディスクの容量を確認: ディスクが満杯でないか
3. ファイルが他のプログラムで開かれていないか確認
4. 別の場所に保存してみる

### 8. 日本語が文字化けする

**症状**: 日本語が正しく表示されない

**解決方法**:
1. ファイルの文字コードを確認: 右下の文字コードをクリック
2. 文字コードを変更: 「エンコード付きで保存」→ 「UTF-8」を選択
3. 設定でデフォルトの文字コードを設定:
   ```json
   {
     "files.encoding": "utf8"
   }
   ```

### 9. ショートカットキーが効かない

**症状**: ショートカットキーを押しても何も起こらない

**解決方法**:
1. 他のアプリケーションと競合していないか確認
2. ショートカットキーの設定を確認: `Ctrl + K` → `Ctrl + S`
3. キーボードの設定を確認（OS側の設定）

### 10. 拡張機能の競合

**症状**: 複数の拡張機能が競合してエラーが発生する

**解決方法**:
1. 拡張機能を1つずつ無効化して、原因を特定
2. 競合する拡張機能の設定を調整
3. 代替の拡張機能を探す

## ログの確認

問題が解決しない場合、ログを確認して原因を特定できます。

### 開発者ツール

- **ショートカット**: `Ctrl + Shift + I`
- **機能**: ブラウザの開発者ツールのような画面が開く
- **用途**: エラーメッセージやコンソールログを確認

### 出力パネル

- **ショートカット**: `Ctrl + Shift + U`
- **機能**: 各種ログを表示
- **用途**: 拡張機能のログ、ターミナルの出力等を確認

**使い方**:
1. `Ctrl + Shift + U`で出力パネルを開く
2. ドロップダウンからログの種類を選択（拡張機能、Git等）
3. エラーメッセージを確認
