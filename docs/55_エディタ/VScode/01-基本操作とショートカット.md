## 基本操作

### フォルダを開く

実務では、プロジェクト単位でフォルダを開くことが推奨されます。

- **方法1**: `Ctrl + K` → `Ctrl + O`（フォルダを開く）
- **方法2**: メニューバーから「ファイル」→「フォルダーを開く」
- **方法3**: ドラッグ&ドロップでフォルダをVSCodeにドロップ

**補足**: 初めて開くフォルダでは、「作成者を信頼しますか？」という警告が表示されることがあります。これは、悪意のあるプログラムの実行を防ぐためのものです。信頼できるフォルダであれば、「はい」を選択してください。

### ファイルの作成・編集

- **新規ファイル**: `Ctrl + N`
- **ファイルを開く**: `Ctrl + O`
- **保存**: `Ctrl + S`
- **すべて保存**: `Ctrl + K` → `S`
- **名前を付けて保存**: `Ctrl + Shift + S`

### エクスプローラー

エクスプローラーは、プロジェクト内のファイルやフォルダを表示・管理するパネルです。

- **表示/非表示**: `Ctrl + Shift + E`
- **ファイル検索**: `Ctrl + P`（クイックオープン）
- **シンボル検索**: `Ctrl + Shift + O`（ファイル内）、`Ctrl + T`（ワークスペース全体）

**用語解説**:
- **シンボル**: 関数名、変数名、クラス名などの識別子のこと。シンボル検索を使うと、コード内の関数や変数に素早く移動できます。

### ターミナル

ターミナルは、コマンドを入力して実行する画面です。プログラマーがよく使う機能です。

- **ターミナルを開く**: `Ctrl + @`（バッククォート）または `Ctrl + Shift + @`
- **新しいターミナル**: `Ctrl + Shift + @`
- **ターミナルを分割**: `Ctrl + Shift + 5`
- **ターミナルを閉じる**: `Ctrl + Shift + W`

**補足**: ターミナルでは、ファイルの操作やプログラムの実行など、様々な作業ができます。

## ショートカットキー（実務で必須）

ショートカットキーを覚えると、マウスを使わずに素早く操作できるようになり、作業効率が大幅に向上します。

### 編集系

| ショートカット | 機能 | 使用頻度 | 解説 |
|--------------|------|---------|------|
| `Ctrl + X` | 行を切り取り（選択なしの場合） | ★★★★★ | 行全体を選択せずに切り取り可能 |
| `Ctrl + C` | 行をコピー（選択なしの場合） | ★★★★★ | 行全体を選択せずにコピー可能 |
| `Alt + ↑/↓` | 行を上下に移動 | ★★★★☆ | コードの順序を変更する時に便利 |
| `Shift + Alt + ↑/↓` | 行を上下にコピー | ★★★★☆ | 似たコードを書く時に便利 |
| `Ctrl + Shift + K` | 行を削除 | ★★★★★ | 行全体を選択せずに削除可能 |
| `Ctrl + Enter` | 下に新しい行を挿入 | ★★★★☆ | カーソル位置に関係なく下に挿入 |
| `Ctrl + Shift + Enter` | 上に新しい行を挿入 | ★★★☆☆ | カーソル位置に関係なく上に挿入 |
| `Ctrl + /` | 行コメントの切り替え | ★★★★★ | コードを一時的に無効化する時に便利 |
| `Shift + Alt + A` | ブロックコメントの切り替え | ★★★☆☆ | 複数行を一度にコメント化 |

**用語解説**:
- **コメント**: コードに書くメモ。プログラムの実行には影響しません。`//`で始まる行コメントと、`/* */`で囲むブロックコメントがあります。

### カーソル・選択系

| ショートカット | 機能 | 使用頻度 | 解説 |
|--------------|------|---------|------|
| `Ctrl + D` | 次の一致を選択（マルチカーソル） | ★★★★★ | 同じ文字列を複数選択して同時編集 |
| `Ctrl + Shift + L` | すべての一致を選択 | ★★★★☆ | ファイル内の同じ文字列をすべて選択 |
| `Alt + Click` | マルチカーソルを追加 | ★★★★☆ | クリックした位置にカーソルを追加 |
| `Ctrl + Alt + ↑/↓` | 上下にカーソルを追加 | ★★★★☆ | 複数行を同時に編集 |
| `Ctrl + U` | カーソル操作を元に戻す | ★★★☆☆ | マルチカーソルを1つずつ戻す |
| `Shift + Alt + I` | 選択範囲の各行の末尾にカーソルを追加 | ★★★☆☆ | 複数行の末尾を同時編集 |
| `Ctrl + Shift + →/←` | 単語単位で選択を拡張 | ★★★★☆ | 単語全体を選択する時に便利 |

**用語解説**:
- **マルチカーソル**: 複数の場所に同時にカーソルを置く機能。同じ文字列を複数箇所で同時に編集できます。

### 検索・置換

| ショートカット | 機能 | 使用頻度 | 解説 |
|--------------|------|---------|------|
| `Ctrl + F` | ファイル内検索 | ★★★★★ | 現在開いているファイル内で検索 |
| `Ctrl + H` | ファイル内置換 | ★★★★★ | 現在開いているファイル内で置換 |
| `Ctrl + Shift + F` | ワークスペース全体で検索 | ★★★★★ | プロジェクト全体で検索 |
| `Ctrl + Shift + H` | ワークスペース全体で置換 | ★★★★☆ | プロジェクト全体で置換 |
| `F3` / `Shift + F3` | 次の/前の検索結果へ | ★★★★☆ | 検索結果を順番に移動 |
| `Alt + Enter` | 検索結果をすべて選択 | ★★★☆☆ | 検索結果をすべてマルチカーソルで選択 |

**補足**: 検索パネルで正規表現を使うこともできます。詳細は「[実務でよく使う機能](06-実務でよく使う機能.md)」を参照してください。

### ナビゲーション

| ショートカット | 機能 | 使用頻度 | 解説 |
|--------------|------|---------|------|
| `Ctrl + P` | クイックオープン（ファイル検索） | ★★★★★ | ファイル名で素早くファイルを開く |
| `Ctrl + T` | シンボル検索（ワークスペース全体） | ★★★★☆ | プロジェクト全体の関数・変数を検索 |
| `Ctrl + Shift + O` | シンボル検索（ファイル内） | ★★★★☆ | 現在のファイル内の関数・変数を検索 |
| `Ctrl + G` | 行番号にジャンプ | ★★★☆☆ | 特定の行番号に移動 |
| `F12` | 定義へ移動 | ★★★★★ | 関数や変数の定義場所に移動 |
| `Alt + F12` | 定義をプレビュー | ★★★★☆ | 定義を別ウィンドウで確認 |
| `Shift + F12` | 参照を表示 | ★★★★☆ | その関数や変数が使われている場所を表示 |
| `Ctrl + -` | 前に戻る | ★★★★☆ | 前のカーソル位置に戻る |
| `Ctrl + Shift + -` | 次に進む | ★★★★☆ | 次のカーソル位置に進む |

**用語解説**:
- **定義**: 関数や変数が最初に定義された場所
- **参照**: その関数や変数が使われている場所

### 表示・パネル

| ショートカット | 機能 | 使用頻度 | 解説 |
|--------------|------|---------|------|
| `Ctrl + B` | サイドバーの表示/非表示 | ★★★★☆ | 左側のパネルを表示/非表示 |
| `Ctrl + J` | パネル（ターミナル等）の表示/非表示 | ★★★★☆ | 下部のパネルを表示/非表示 |
| `Ctrl + Shift + E` | エクスプローラー | ★★★★☆ | ファイル一覧を表示 |
| `Ctrl + Shift + G` | ソース管理 | ★★★★☆ | Gitの変更を表示 |
| `Ctrl + Shift + D` | 実行とデバッグ | ★★★☆☆ | デバッグ機能を表示 |
| `Ctrl + Shift + X` | 拡張機能 | ★★★☆☆ | 拡張機能の管理画面を表示 |
| `Ctrl + ,` | 設定を開く | ★★★☆☆ | VSCodeの設定を開く |
| `Ctrl + K` → `Ctrl + S` | キーボードショートカット | ★★☆☆☆ | ショートカットキーの設定を開く |

### コマンドパレット

| ショートカット | 機能 | 使用頻度 | 解説 |
|--------------|------|---------|------|
| `Ctrl + Shift + P` | コマンドパレットを開く | ★★★★★ | VSCodeの機能を検索して実行 |
| `Ctrl + K` → `Ctrl + S` | キーボードショートカット設定 | ★★☆☆☆ | ショートカットキーの設定を開く |

**用語解説**:
- **コマンドパレット**: VSCodeの機能を検索して実行できるメニュー。メニューを覚えなくても、機能名を検索して実行できます。

### ウィンドウ・タブ

| ショートカット | 機能 | 使用頻度 | 解説 |
|--------------|------|---------|------|
| `Ctrl + W` | タブを閉じる | ★★★★★ | 現在開いているファイルを閉じる |
| `Ctrl + K` → `W` | すべてのタブを閉じる | ★★★☆☆ | 開いているすべてのファイルを閉じる |
| `Ctrl + Shift + T` | 閉じたタブを再度開く | ★★★★☆ | 誤って閉じたファイルを復元 |
| `Ctrl + Tab` | 次のタブに移動 | ★★★★☆ | 開いているファイルを順番に切り替え |
| `Ctrl + PageUp/PageDown` | タブを切り替え | ★★★☆☆ | タブを切り替える別の方法 |
| `Ctrl + K` → `Ctrl + ←/→` | エディタグループを切り替え | ★★★☆☆ | 分割したエディタを切り替え |

## ショートカットキーの覚え方

1. **よく使うものから覚える**: 編集系（`Ctrl + X`、`Ctrl + C`、`Ctrl + V`）と検索系（`Ctrl + F`、`Ctrl + P`）は最優先
2. **実際に使ってみる**: 覚えたショートカットを実際に使って体に覚えさせる
3. **段階的に覚える**: 一度に全部覚えようとせず、1週間で5個ずつなど目標を立てる
4. **コマンドパレットを活用**: 覚えていない機能は`Ctrl + Shift + P`で検索
