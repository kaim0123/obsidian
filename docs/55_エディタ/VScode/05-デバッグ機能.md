## デバッグとは

**デバッグ（Debug）**は、プログラムのバグ（エラー）を見つけて修正することです。プログラマーの重要な作業の一つで、VSCodeのデバッグ機能を使うと、効率的にバグを見つけることができます。

### デバッグでできること

- **プログラムの実行を一時停止**: 特定の地点で実行を止める
- **変数の値を確認**: 実行中の変数の値を確認
- **1行ずつ実行**: プログラムを1行ずつ実行して動作を確認
- **エラーの原因を特定**: どこで問題が発生しているかを特定

### 用語解説

- **ブレークポイント（Breakpoint）**: プログラムの実行を一時停止する地点
- **ステップ実行（Step Execution）**: プログラムを1行ずつ実行すること
- **変数パネル（Variables Panel）**: デバッグ中に現在の変数の値を表示するパネル
- **コールスタック（Call Stack）**: 関数の呼び出し履歴
- **ログ（Log）**: プログラムの実行記録

## 基本的な使い方

### 1. デバッグパネルを開く

- **ショートカット**: `Ctrl + Shift + D`
- **場所**: 左側のアクティビティバーから「実行とデバッグ」アイコンをクリック

### 2. ブレークポイントを設定

プログラムを一時停止したい行の、行番号の左をクリックします。

- 赤い丸（●）が表示されれば設定完了
- もう一度クリックすると解除

**例**: 変数の値を確認したい行にブレークポイントを設定

### 3. デバッグを開始

1. デバッグパネルの上部で「実行とデバッグの開始」をクリック
2. または `F5` キーを押す
3. 環境を選択（Node.js、Python、Chrome等）

### 4. プログラムが一時停止

ブレークポイントに到達すると、プログラムが一時停止します。

- 黄色の行: 現在実行中の行
- 変数パネル: 現在の変数の値が表示される
- コールスタック: 関数の呼び出し履歴が表示される

## デバッグコントロール

プログラムの実行を制御するボタンやショートカットです。

| ショートカット | ボタン | 機能 | 解説 |
|--------------|--------|------|------|
| `F5` | ▶️ | デバッグ開始/続行 | プログラムを実行、または一時停止から再開 |
| `F9` | ● | ブレークポイントの切り替え | 現在の行にブレークポイントを設定/解除 |
| `F10` | ⏭️ | ステップオーバー | 現在の行を実行し、次の行へ（関数の中には入らない） |
| `F11` | ⬇️ | ステップイン | 現在の行を実行し、関数の中に入る |
| `Shift + F11` | ⬆️ | ステップアウト | 現在の関数から出る |
| `Shift + F5` | ⏹️ | デバッグ停止 | デバッグを終了 |
| `Ctrl + Shift + F5` | 🔄 | 再起動 | デバッグを再起動 |

### 各操作の使い分け

- **ステップオーバー（F10）**: 関数の呼び出しを1つの処理として扱う。関数の中身は見ない
- **ステップイン（F11）**: 関数の中に入って、中身を詳しく見る
- **ステップアウト（Shift + F11）**: 現在の関数から出て、呼び出し元に戻る

**例**:
```javascript
function greet(name) {
  console.log("こんにちは、" + name);
}

greet("太郎");  // この行でF10を押すと、greet関数の中には入らない
                // F11を押すと、greet関数の中に入る
```

## ブレークポイントの設定

### 通常のブレークポイント

行番号の左をクリックして設定。プログラムがその行に到達すると一時停止します。

### 条件付きブレークポイント

特定の条件が満たされた時だけ一時停止します。

1. ブレークポイントを右クリック
2. 「条件を編集」を選択
3. 条件を入力（例: `i > 10`）

**使用例**: ループで10回目以降だけ一時停止したい場合

### ログポイント

プログラムを止めずに、ログを出力します。

1. ブレークポイントを右クリック
2. 「ログポイントを追加」を選択
3. ログメッセージを入力（例: `変数iの値は {i}`）

**用語解説**:
- **ログ**: プログラムの実行記録。`console.log()`で出力するメッセージもログです。

## 変数の確認

### 変数パネル

デバッグ中、左側の「変数」パネルに現在のスコープの変数が表示されます。

- **ローカル**: 現在の関数内の変数
- **グローバル**: プログラム全体で使える変数

### ウォッチ

特定の式の値を監視します。

1. 「ウォッチ」パネルで「+」をクリック
2. 監視したい式を入力（例: `i * 2`、`array.length`）
3. 実行中、その式の値が常に表示される

**使用例**: ループで計算結果を監視したい場合

### インライン表示

変数にマウスをホバーすると、その値が表示されます。

- コードを見ながら変数の値を確認できる
- 変数パネルを見なくても値がわかる

## launch.jsonの設定

デバッグの設定を保存するファイルです。プロジェクトごとに設定を保存できます。

### 作成方法

1. デバッグパネルを開く
2. 「launch.json ファイルを作成します」をクリック
3. 環境を選択（Node.js、Python等）
4. 設定ファイルが作成される

### 設定例（Node.js）

```json
{
  "version": "0.2.0",
  "configurations": [
    {
      "type": "node",
      "request": "launch",
      "name": "Launch Program",
      "program": "${workspaceFolder}/index.js",
      "console": "integratedTerminal"
    }
  ]
}
```

### 設定項目の説明

- **type**: デバッグの種類（node、python等）
- **request**: launch（起動）またはattach（既存プロセスに接続）
- **name**: デバッグ設定の名前（表示名）
- **program**: 実行するファイルのパス
- **console**: コンソールの種類（integratedTerminal、internalConsole等）

**用語解説**:
- **ワークスペース**: プロジェクトのフォルダやファイルをまとめて管理する単位
- **${workspaceFolder}**: ワークスペースのフォルダパスを表す変数

## 言語別の設定例

### Python

```json
{
  "version": "0.2.0",
  "configurations": [
    {
      "name": "Python: 現在のファイル",
      "type": "python",
      "request": "launch",
      "program": "${file}",
      "console": "integratedTerminal"
    }
  ]
}
```

### JavaScript/Node.js

```json
{
  "version": "0.2.0",
  "configurations": [
    {
      "type": "node",
      "request": "launch",
      "name": "Launch Program",
      "program": "${workspaceFolder}/index.js",
      "args": ["arg1", "arg2"]
    }
  ]
}
```

### Chrome（Web開発）

```json
{
  "version": "0.2.0",
  "configurations": [
    {
      "type": "chrome",
      "request": "launch",
      "name": "Launch Chrome",
      "url": "http://localhost:3000",
      "webRoot": "${workspaceFolder}"
    }
  ]
}
```

## デバッグの実践例

### 例1: 変数の値を確認

```javascript
function calculateTotal(items) {
  let total = 0;
  for (let i = 0; i < items.length; i++) {
    total += items[i].price;  // ここにブレークポイントを設定
  }
  return total;
}
```

1. `total += items[i].price;`の行にブレークポイントを設定
2. `F5`でデバッグ開始
3. 変数パネルで`total`、`i`、`items[i]`の値を確認
4. `F10`で次のループへ進む

### 例2: 関数の動作を確認

```javascript
function processData(data) {
  const result = data.map(item => item * 2);  // ここにブレークポイント
  return result.filter(item => item > 10);
}
```

1. `const result = ...`の行にブレークポイントを設定
2. `F5`でデバッグ開始
3. `F11`で`map`関数の中に入る（可能な場合）
4. 変数パネルで`data`と`result`の値を確認

## トラブルシューティング

### デバッグが開始できない

- **確認**: 実行するファイルが正しいか
- **確認**: 必要な拡張機能がインストールされているか（Python、Node.js等）
- **解決**: launch.jsonの設定を確認

### ブレークポイントで止まらない

- **確認**: ブレークポイントが有効か（赤い丸が表示されているか）
- **確認**: その行が実際に実行されているか
- **解決**: 条件付きブレークポイントの条件を確認

### 変数が表示されない

- **確認**: その変数が現在のスコープにあるか
- **確認**: 変数が定義されているか
- **解決**: スコープを確認（ローカル、グローバル）

## まとめ

デバッグ機能を使うことで、プログラムの動作を詳しく確認でき、バグを効率的に見つけることができます。

**覚えておくべきこと**:
1. **ブレークポイント**: プログラムを一時停止する地点
2. **ステップ実行**: 1行ずつ実行して動作を確認
3. **変数パネル**: 実行中の変数の値を確認
4. **F5、F10、F11**: よく使うショートカット
