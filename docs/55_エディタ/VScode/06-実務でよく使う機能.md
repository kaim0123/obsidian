## マルチカーソル編集

**マルチカーソル**は、複数の場所に同時にカーソルを置いて、同じ編集を一度に行う機能です。

### 基本的な使い方

#### 1. `Ctrl + D` - 次の一致を選択

同じ文字列を順番に選択して、複数箇所を同時編集できます。

**使用例**: 変数名を一括変更
```javascript
// 変更前
let userName = "太郎";
let userName = "花子";
let userName = "次郎";

// Ctrl + D を3回押して3箇所を選択
// その後、userName を user_name に変更
```

**手順**:
1. `userName`の1つ目を選択
2. `Ctrl + D`を押す（2箇所目が選択される）
3. さらに`Ctrl + D`を押す（3箇所目が選択される）
4. すべての`userName`が選択された状態で編集

#### 2. `Alt + Click` - クリックした位置にカーソルを追加

マウスでクリックした位置にカーソルを追加します。

**使用例**: 複数行の先頭に文字を追加
```javascript
// 変更前
太郎
花子
次郎

// Alt + Click で各行の先頭にカーソルを追加
// その後、「名前: 」を入力
```

#### 3. `Ctrl + Alt + ↑/↓` - 上下の行にカーソルを追加

現在のカーソル位置の上下の行にカーソルを追加します。

**使用例**: 複数行を同時に編集
```javascript
// 変更前
const item1 = "apple";
const item2 = "banana";
const item3 = "cherry";

// item1の行にカーソルを置き、Ctrl + Alt + ↓ を2回
// 3行すべてにカーソルが追加される
// その後、const を let に変更
```

#### 4. `Shift + Alt + I` - 選択範囲の各行の末尾にカーソルを追加

選択した範囲の各行の末尾にカーソルを追加します。

**使用例**: 複数行の末尾にセミコロンを追加
```javascript
// 変更前
const a = 1
const b = 2
const c = 3

// 3行を選択して Shift + Alt + I
// 各行の末尾にカーソルが追加される
// その後、セミコロンを入力
```

### マルチカーソルの解除

- `Esc`キーを押す
- または、`Ctrl + U`でカーソルを1つずつ戻す

**用語解説**:
- **マルチカーソル**: 複数の場所に同時にカーソルを置く機能。同じ文字列を複数箇所で同時に編集できます。

## 検索と置換（高度な使い方）

### 正規表現を使った置換

**正規表現（Regular Expression / Regex）**を使うと、複雑なパターンで検索・置換できます。

#### 正規表現モードの有効化

1. `Ctrl + H`で置換パネルを開く
2. 「.*」アイコンをクリックして正規表現モードを有効化
3. 正規表現で検索・置換

#### よく使う正規表現パターン

| パターン | 意味 | 例 |
|---------|------|-----|
| `\d` | 数字1文字 | `0`、`1`、`9` |
| `\d+` | 1つ以上の数字 | `123`、`45` |
| `\w` | 英数字とアンダースコア | `a`、`1`、`_` |
| `\w+` | 1つ以上の英数字 | `hello`、`user123` |
| `\s` | 空白文字 | スペース、タブ |
| `.` | 任意の1文字 | `a`、`1`、`@` |
| `.*` | 任意の文字列 | `hello`、`123abc` |
| `^` | 行の先頭 | 行の最初 |
| `$` | 行の末尾 | 行の最後 |
| `()` | グループ化 | 後で参照できる |
| `$1`、`$2` | グループの参照 | 置換で使う |

#### 実践例

**例1: 関数をアロー関数に変換**

```javascript
// 検索: function (\w+)\(
// 置換: const $1 = (
```

**説明**:
- `function`: 文字列「function」に一致
- ` `: スペース
- `(\w+)`: 関数名をキャプチャ（グループ1）
- `\(`: 開き括弧（`(`は特殊文字なので`\`でエスケープ）

**例2: コメントを削除**

```javascript
// 検索: //.*$
// 置換: （空）
```

**説明**:
- `//`: 文字列「//」に一致
- `.*`: 任意の文字列
- `$`: 行の末尾

**例3: 変数名を一括変更**

```javascript
// 検索: \buserName\b
// 置換: user_name
```

**説明**:
- `\b`: 単語の境界（単語の途中にマッチしないようにする）
- `userName`: 文字列「userName」に一致

**用語解説**:
- **正規表現**: 文字列のパターンを表現する記法。検索・置換で複雑なパターンを指定できます。

### ファイル全体での検索・置換

- **`Ctrl + Shift + F`**: ワークスペース全体で検索
- **`Ctrl + Shift + H`**: ワークスペース全体で置換

**機能**:
- ファイルタイプでフィルタリング可能（例: `*.js`のみ）
- フォルダを除外可能（例: `node_modules`を除外）
- 大文字・小文字を区別するか選択可能

## スニペット

**スニペット**は、よく使うコードの断片を登録しておく機能です。短い文字列を入力すると、長いコードが自動入力されます。

### スニペットの作成

1. `Ctrl + Shift + P`でコマンドパレットを開く
2. 「スニペット: スニペットファイルを構成する」を選択
3. 言語を選択（例: JavaScript、Python）
4. スニペットを定義

### スニペットの書き方

```json
{
  "Console log": {
    "prefix": "clog",
    "body": [
      "console.log('$1');"
    ],
    "description": "Console log"
  }
}
```

**説明**:
- **prefix**: 入力する短い文字列（例: `clog`）
- **body**: 実際に挿入されるコード
- **description**: 説明文
- **$1、$2**: カーソル位置（タブで移動）

### 実践例

#### JavaScriptの例

```json
{
  "Arrow Function": {
    "prefix": "af",
    "body": [
      "const ${1:functionName} = (${2:params}) => {",
      "  $3",
      "};"
    ],
    "description": "Arrow function"
  },
  "Try Catch": {
    "prefix": "try",
    "body": [
      "try {",
      "  $1",
      "} catch (error) {",
      "  console.error(error);",
      "}"
    ],
    "description": "Try catch block"
  }
}
```

**使い方**:
1. `af`と入力してEnter
2. アロー関数のコードが挿入される
3. `$1`の位置（関数名）にカーソルが移動
4. 関数名を入力してTabキーで次の位置へ

**用語解説**:
- **スニペット**: よく使うコードの断片を登録しておく機能。短い文字列を入力すると、長いコードが自動入力されます。

## コードフォーマット

コードの見た目を整える（フォーマット）機能です。

### 手動フォーマット

- **ショートカット**: `Shift + Alt + F`
- **機能**: 現在のファイルをフォーマット

### 保存時自動フォーマット

保存時に自動でフォーマットする設定：

1. `Ctrl + ,`で設定を開く
2. 「format on save」で検索
3. 「Editor: Format On Save」にチェック
4. 「Editor: Default Formatter」でフォーマッターを選択（例: Prettier）

**用語解説**:
- **フォーマット**: コードの見た目を整えること。インデントを統一したり、改行を調整したりします。

## インポートの整理

### 未使用のインポートを削除

1. `Ctrl + Shift + P`でコマンドパレットを開く
2. 「Organize Imports」を選択
3. 未使用のインポートが自動で削除される

### 自動インポート

TypeScript/JavaScriptで、使用した関数を自動でインポート：

1. 関数名を入力
2. 補完候補から選択
3. 自動でインポート文が追加される

**用語解説**:
- **インポート**: 他のファイルのコードを使えるようにすること。

## ファイルの比較

2つのファイルの違いを確認できます。

### 方法1: エクスプローラーから

1. エクスプローラーでファイルを右クリック
2. 「選択項目と比較」を選択
3. 比較するファイルを選択

### 方法2: コマンドパレットから

1. `Ctrl + Shift + P`でコマンドパレットを開く
2. 「File: Compare Active File With...」を選択
3. 比較するファイルを選択

**表示**:
- 左側: 現在のファイル
- 右側: 比較するファイル
- 緑色: 追加された行
- 赤色: 削除された行

## 統合ターミナル

VSCode内でターミナルを使えます。

### 基本的な操作

- **ターミナルを開く**: `Ctrl + @`（バッククォート）
- **新しいターミナル**: `Ctrl + Shift + @`
- **ターミナルを分割**: `Ctrl + Shift + 5`
- **ターミナルを閉じる**: `Ctrl + Shift + W`

### 複数ターミナル

- **追加**: `Ctrl + Shift + @`で追加
- **切り替え**: `Ctrl + PageUp/PageDown`
- **種類を変更**: ターミナル右上の「+」横の「▼」から選択

**使用例**:
- 1つ目: サーバーを起動
- 2つ目: テストを実行
- 3つ目: Git操作

**用語解説**:
- **ターミナル**: コマンドを入力して実行する画面。プログラマーがよく使う機能です。

## クイックオープン

ファイル名で素早くファイルを開く機能です。

### 基本的な使い方

- **ショートカット**: `Ctrl + P`
- **機能**: ファイル名で検索して開く

### 高度な使い方

- **行番号で開く**: `Ctrl + P` → ファイル名 → `:` → 行番号（例: `index.js:25`）
- **シンボルで開く**: `Ctrl + P` → `@` → シンボル名（例: `@functionName`）
- **複数ファイル**: `Ctrl + P`で複数のファイルを選択して開く

**用語解説**:
- **シンボル**: 関数名、変数名、クラス名などの識別子のこと。
