## 概要

### Cursorとは

**Cursor**は、VS Codeをベースに開発されたAIコードエディタです。ChatGPTやClaudeなどのAIを統合しており、エディタ内で直接AIアシスタントと対話しながらコーディングができます。

**主な特徴**:
- VS Codeの拡張機能やテーマと高い互換性
- AIによるコード補完・生成・修正支援
- コードベースのインデックス化（最大1万ファイル）
- プライバシーモード対応

### KIROとは

**KIRO**は、Amazonが開発したAI統合開発環境（IDE）です。仕様駆動型の開発をサポートし、自然言語で要件を記述すると、AIが自動でコード、テスト、ドキュメントを生成します。

**主な特徴**:
- 仕様駆動型開発のサポート
- AWSとの高い親和性
- AIエージェントによる自動化
- チーム開発向け機能

**用語解説**:
- **仕様駆動型開発**: 要件定義からコード生成までをAIが自動化する開発手法
- **AIエージェント**: ユーザーの意図を理解して自動で作業を実行するAIプログラム

## Cursorの特徴と使い方

### VS Codeからの移行

CursorはVS Codeをベースにしているため、VS Codeの知識やショートカットキーがそのまま使えます。

- **設定の互換性**: VS Codeの設定ファイル（`settings.json`）をそのまま使用可能
- **拡張機能**: VS Codeの拡張機能の多くが利用可能
- **ショートカットキー**: VS Codeと同じショートカットキーが使える

### AI機能の使い方

#### 1. AIチャット（`Ctrl + L`）

エディタ内でAIアシスタントと対話できます。

- **使い方**: `Ctrl + L`を押すと、AIチャットパネルが開きます
- **機能**: コードの説明、バグ修正、コード生成などを依頼できます

**使用例**:
```
ユーザー: この関数をTypeScriptに変換してください
AI: [TypeScriptコードを生成]
```

#### 2. インライン編集（`Ctrl + K`）

コードを直接編集する指示をAIに出すことができます。

- **使い方**: コードを選択して`Ctrl + K`を押すと、編集指示を入力できます
- **機能**: 選択したコードを、指示に従ってAIが自動編集します

**使用例**:
- 選択したコードに対して「エラーハンドリングを追加してください」と指示
- AIが自動でエラーハンドリングを追加したコードを生成

#### 3. コード補完

AIが文脈を理解して、より適切なコード補完を提案します。

- **自動補完**: 入力中に自動でコード提案が表示されます
- **Tabで受け入れ**: `Tab`キーで提案を受け入れます

#### 4. コードベースのインデックス化

プロジェクト全体のコードをAIが理解して、より適切な提案を行います。

- **最大1万ファイル**: プロジェクト内の最大1万ファイルをインデックス化
- **広い文脈の理解**: プロジェクト全体の構造を考慮したコード提案

#### 5. Composer機能（`Ctrl + I`）

複数ファイルにまたがる変更を一度に指示できます。

- **使い方**: `Ctrl + I`でComposerを開き、変更指示を入力
- **機能**: 複数ファイルを同時に編集・生成できます

**使用例**:
```
ユーザー: ユーザー認証機能を追加してください
AI: [認証関連の複数ファイルを自動生成・編集]
```

### プライバシーモード

機密情報を含むコードを扱う際に便利な機能です。

- **機能**: コードがリモートに保存されません
- **使い方**: 設定でプライバシーモードを有効化

### Cursor特有のショートカットキー

| ショートカット | 機能 | 使用頻度 |
|--------------|------|---------|
| `Ctrl + L` | AIチャットを開く | ★★★★★ |
| `Ctrl + K` | インライン編集 | ★★★★☆ |
| `Ctrl + I` | Composerを開く | ★★★★☆ |
| `Ctrl + Shift + L` | コードベース全体を参照してチャット | ★★★☆☆ |

### Cursorの実務での活用例

1. **コードレビュー**: AIにコードレビューを依頼して、改善点を提案してもらう
2. **リファクタリング**: 「この関数をリファクタリングしてください」と指示
3. **ドキュメント生成**: コードから自動でコメントやドキュメントを生成
4. **バグ修正**: エラーメッセージをAIに説明してもらい、修正方法を提案してもらう
5. **テストコード生成**: 関数を選択して「テストコードを生成してください」と指示

## KIROの特徴と使い方

### 仕様駆動型開発

KIROは、仕様書を書くとAIが自動でコード、テスト、ドキュメントを生成する仕様駆動型開発をサポートします。

#### 1. 仕様書の記述

自然言語で要件を記述します。

**例**:
```
機能: ユーザー登録
- メールアドレスとパスワードでユーザーを登録
- メールアドレスの重複チェック
- パスワードは8文字以上
```

#### 2. AIによる自動生成

仕様書から以下を自動生成:
- **コード**: 実装コード
- **テスト**: テストコード
- **ドキュメント**: APIドキュメントなど

### AWSとの統合

KIROはAWSサービスとの親和性が高く、AWS環境での開発に最適化されています。

- **デプロイ**: AWSサービスへのデプロイが容易
- **統合**: AWSの各種サービスとの連携が簡単

### AIエージェント機能

KIROのAIエージェントは、開発プロセスを自動化します。

#### グローバルステアリング

開発全体の方向性をAIが理解して、一貫性のある開発を支援します。

#### シーケンシャルフック

開発プロセスの各段階で、自動的に適切な処理を実行します。

### MCPサーバーサポート

バージョン0.5.0から、リモートのMCPサーバーをサポートしています。

- **機能**: 外部ツールやサービスとの連携が可能
- **用途**: データベース接続、API連携など

**用語解説**:
- **MCPサーバー**: Model Context Protocolサーバー。AIエージェントが外部サービスと連携するためのプロトコル

### チーム開発向け機能

KIROは、チーム開発をサポートする機能が充実しています。

- **仕様書の共有**: チーム全体で仕様書を共有
- **進捗管理**: 開発の進捗を可視化
- **コードレビュー**: 自動コードレビュー機能

### 互換性

#### Cursor

- **VS Codeとの互換性**: ★★★★★

  - ショートカットキーが同じ

#### KIRO

- **VS Codeとの互換性**: ★★★☆☆
  - 基本的な機能は類似
  - 拡張機能の互換性は限定的
  - 独自の機能が多い

## 使い分けのガイド

### VS Codeを選ぶべき場合

- ✅ 拡張機能の豊富さを重視する
- ✅ カスタマイズ性を重視する
- ✅ 軽量で高速な動作を求める
- ✅ AI機能は不要、または拡張機能で対応する
- ✅ 幅広い開発環境に対応したい

### Cursorを選ぶべき場合

- ✅ AIを活用した効率的なコーディングをしたい
- ✅ VS Codeの知識を活用したい
- ✅ コードレビューやリファクタリングをAIに任せたい
- ✅ 既存のVS Code環境から移行したい
- ✅ 個人開発や小規模チーム開発

### KIROを選ぶべき場合

- ✅ 仕様駆動型開発を行いたい
- ✅ AWS環境で開発している
- ✅ チーム開発で仕様書の共有が重要
- ✅ 要件定義からコード生成までを自動化したい
- ✅ 企業向けの開発プロセスを重視する

### 移行のポイント

#### VS CodeからCursorへ

1. **設定の移行**: VS Codeの設定ファイルをそのままコピー可能
2. **拡張機能**: ほぼそのまま使用可能
3. **学習コスト**: ほぼゼロ（AI機能だけ覚えればOK）

#### VS CodeからKIROへ

1. **概念の理解**: 仕様駆動型開発の概念を理解する必要がある
2. **ワークフロー**: 従来のワークフローから変更が必要
3. **学習コスト**: やや高い（新しい開発手法を学ぶ必要がある）

## 実務での活用シナリオ

### Cursorの活用例

#### シナリオ1: コードレビュー

```markdown
1. コードを選択
2. Ctrl + L でAIチャットを開く
3. 「このコードをレビューしてください」と入力
4. AIが改善点を提案
5. 提案を参考に修正
```

#### シナリオ2: リファクタリング

```markdown
1. リファクタリングしたい関数を選択
2. Ctrl + K でインライン編集
3. 「この関数をリファクタリングして、エラーハンドリングを追加してください」と入力
4. AIが修正したコードを提案
5. Tab で受け入れ
```

#### シナリオ3: テストコード生成

```markdown
1. テストを書きたい関数を選択
2. Ctrl + L でAIチャットを開く
3. 「この関数のテストコードを書いてください」と入力
4. AIがテストコードを生成
5. テストファイルにコピー
```

### KIROの活用例

#### シナリオ1: 仕様書からコード生成

```markdown
1. 仕様書を記述（自然言語）
2. AIがコード、テスト、ドキュメントを自動生成
3. 生成されたコードを確認・修正
4. AWSにデプロイ
```

#### シナリオ2: チーム開発

```markdown
1. チームで仕様書を共有
2. 各メンバーが分担して実装
3. AIエージェントが自動でコードレビュー
4. 進捗を可視化
```

## まとめ

### 各エディタの強み

- **VS Code**: 汎用性と拡張性が高い、業界標準
- **Cursor**: AI機能が充実、VS Codeからの移行が容易
- **KIRO**: 仕様駆動型開発、AWS統合、チーム開発向け

### 推奨される選択

1. **初心者**: VS Codeから始める
2. **AIを活用したい**: Cursorがおすすめ
3. **仕様駆動型開発**: KIROがおすすめ
4. **既存プロジェクト**: VS Codeを継続
5. **新規プロジェクト**: 要件に応じて選択

### 併用も可能

実際には、プロジェクトや用途に応じて複数のエディタを併用することも可能です。

- **VS Code**: メインエディタとして使用
- **Cursor**: AI機能が必要な時だけ使用
- **KIRO**: AWS開発や仕様駆動型開発の時だけ使用
