# 拡張機能の設定と管理

各拡張機能の推奨設定（settings.json）、パフォーマンス最適化、管理方法、トラブルシューティングをまとめたガイドです。拡張機能の一覧は [拡張機能カタログ](03-拡張機能.md) を参照してください。

---

## settings.json での設定方法

拡張機能の設定は 3 つの方法で変更できる。

1. **GUI**: 拡張機能パネルで拡張機能を選択 → 歯車アイコン → 「拡張機能の設定」
2. **設定画面**: `Ctrl + ,` → 拡張機能名で検索
3. **直接編集**: `settings.json` に記述（最も柔軟）

**用語解説**:
- **settings.json**: VSCode の設定を保存する JSON 形式のファイル。`Ctrl + Shift + P` → 「Preferences: Open User Settings (JSON)」で開ける。

## Lint / Format の設定

### Biome（Prettier + ESLint の代替を使う場合）

```json
{
  "editor.defaultFormatter": "biomejs.biome",
  "editor.formatOnSave": true,
  "editor.codeActionsOnSave": {
    "source.organizeImports.biome": "explicit",
    "quickfix.biome": "explicit"
  },
  "[javascript]": {
    "editor.defaultFormatter": "biomejs.biome"
  },
  "[typescript]": {
    "editor.defaultFormatter": "biomejs.biome"
  },
  "[javascriptreact]": {
    "editor.defaultFormatter": "biomejs.biome"
  },
  "[typescriptreact]": {
    "editor.defaultFormatter": "biomejs.biome"
  },
  "[json]": {
    "editor.defaultFormatter": "biomejs.biome"
  }
}
```

**プロジェクト設定（biome.json）**:
```json
{
  "$schema": "https://biomejs.dev/schemas/1.9.0/schema.json",
  "organizeImports": {
    "enabled": true
  },
  "formatter": {
    "indentStyle": "tab",
    "lineWidth": 100
  },
  "linter": {
    "enabled": true,
    "rules": {
      "recommended": true
    }
  }
}
```

### Prettier（従来構成を使う場合）

```json
{
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "editor.formatOnSave": true,
  "[javascript]": {
    "editor.defaultFormatter": "esbenp.prettier-vscode",
    "editor.formatOnSave": true
  },
  "[typescript]": {
    "editor.defaultFormatter": "esbenp.prettier-vscode",
    "editor.formatOnSave": true
  },
  "[json]": {
    "editor.defaultFormatter": "esbenp.prettier-vscode"
  },
  "prettier.singleQuote": true,
  "prettier.trailingComma": "es5",
  "prettier.tabWidth": 2,
  "prettier.semi": true,
  "prettier.printWidth": 80,
  "prettier.arrowParens": "avoid"
}
```

**プロジェクト設定（.prettierrc）**:
```json
{
  "singleQuote": true,
  "trailingComma": "es5",
  "tabWidth": 2,
  "semi": true
}
```

**除外設定（.prettierignore）**:
```
node_modules
dist
build
*.min.js
```

### ESLint（Biome 未使用時）

```json
{
  "eslint.enable": true,
  "editor.codeActionsOnSave": {
    "source.fixAll.eslint": true
  },
  "eslint.validate": [
    "javascript",
    "javascriptreact",
    "typescript",
    "typescriptreact"
  ],
  "eslint.format.enable": true
}
```

**プロジェクト設定（.eslintrc.json）**:
```json
{
  "extends": ["eslint:recommended"],
  "env": {
    "browser": true,
    "node": true,
    "es2021": true
  },
  "rules": {
    "no-console": "warn",
    "no-unused-vars": "error"
  }
}
```

## Git 連携の設定

### GitLens

```json
{
  "gitlens.codeLens.enabled": true,
  "gitlens.currentLine.enabled": true,
  "gitlens.hovers.enabled": true,
  "gitlens.statusBar.enabled": true,
  "gitlens.currentLine.format": "${author} ${agoOrDate}",
  "gitlens.codeLens.scopes": ["document", "containers", "blocks"],
  "gitlens.advanced.fileHistoryFollowsRenames": true,
  "gitlens.advanced.caching.enabled": true
}
```

**実務での活用**:
- **コードレビュー**: 各行の変更履歴を確認
- **責任の追跡**: 誰がいつ変更したかを確認
- **ブランチ比較**: ブランチ間の差分を視覚的に確認

**用語解説**:
- **コードレンズ**: コードの上に表示される情報（関数の参照数、最後に変更した人等）

## エラー表示の設定

### Error Lens

```json
{
  "errorLens.enabled": true,
  "errorLens.enabledDiagnosticLevels": ["error", "warning"],
  "errorLens.followCursor": "allLines",
  "errorLens.gutterIconsEnabled": true,
  "errorLens.messageTemplate": "$message"
}
```

**パフォーマンス重視のカスタマイズ**:
```json
{
  "errorLens.followCursor": "activeLine",
  "errorLens.enabledDiagnosticLevels": ["error"],
  "errorLens.messageTemplate": "$severity $message ($source)"
}
```

### Astro

```json
{
  "[astro]": {
    "editor.defaultFormatter": "astro-build.astro-vscode"
  }
}
```

### Tailwind CSS IntelliSense

```json
{
  "tailwindCSS.includeLanguages": {
    "astro": "html"
  },
  "tailwindCSS.experimental.classRegex": [
    ["class\\s*=\\s*\"([^\"]*)\""]
  ]

```

**補足**: Astro ファイルでも補完を有効にするには `includeLanguages` の設定が必要。

## チーム開発での設定共有

### `.vscode/settings.json`

プロジェクトのルートに `.vscode/settings.json` を配置すると、チーム全体で同じ設定を共有できる。

### `.editorconfig`

EditorConfig 拡張機能を使い、エディタ間で共通の設定を適用する。

```ini
root = true

[*]
charset = utf-8
end_of_line = lf
insert_final_newline = true
indent_style = space
indent_size = 2

[*.md]
trim_trailing_whitespace = false
```

## パフォーマンス最適化

### パフォーマンスに影響しやすい拡張機能

- **GitLens**: 大量のファイルがある場合、初期化に時間がかかる
- **Error Lens**: 多くのエラーがある場合、表示が遅くなる
- **IntelliSense 系**: 大きなプロジェクトでは補完が遅くなる

### 最適化の設定

```json
{
  "gitlens.codeLens.enabled": false,
  "gitlens.currentLine.enabled": true,
  "errorLens.followCursor": "activeLine",
  "files.watcherExclude": {
    "**/node_modules/**": true,
    "**/dist/**": true,
    "**/build/**": true,
    "**/.git/**": true
  },
  "search.exclude": {
    "**/node_modules": true,
    "**/dist": true,
    "**/build": true
  }
}
```

## 拡張機能の管理

### 無効化・有効化

1. `Ctrl + Shift + X` で拡張機能パネルを開く
2. 拡張機能を選択
3. 「無効にする」/「有効にする」をクリック

**推奨**: 使用していない拡張機能は定期的に無効化またはアンインストール。

### バックアップと同期

**Settings Sync（推奨）**:
1. `Ctrl + Shift + P` → 「Settings Sync: Turn On...」
2. GitHub または Microsoft アカウントでログイン
3. 拡張機能リスト・設定が自動同期される

### 更新

- **自動更新**: デフォルトで有効
- **手動更新**: 拡張機能パネルで「更新」をクリック

## トラブルシューティング

### 拡張機能が動作しない

1. VSCode を再起動
2. 拡張機能を無効化 → 再有効化
3. 拡張機能を再インストール
4. 拡張機能の設定を確認
5. ログを確認: `Ctrl + Shift + U` → 拡張機能名を選択

### 拡張機能の競合

複数の拡張機能が競合してエラーが発生する場合：

1. 拡張機能を 1 つずつ無効化して原因を特定
2. 競合する拡張機能の設定を調整
3. 代替の拡張機能を探す

**よくある競合例**:
- **Prettier と ESLint**: `"editor.defaultFormatter"` で Prettier を指定し、ESLint は保存時の自動修正のみ使用
- **Prettier / ESLint と Biome**: Biome を使う場合は Prettier と ESLint を無効化

### 設定が反映されない

1. VSCode を再起動
2. `settings.json` の構文エラーを確認
3. ワークスペース設定とユーザー設定の競合を確認（ワークスペース設定が優先される）
