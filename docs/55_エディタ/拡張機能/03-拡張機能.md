# 拡張機能カタログ

VSCode / Cursor に導入すべき拡張機能を、カテゴリ別にまとめたリファレンスです。

---

## 拡張機能とは

**拡張機能（Extension）**は、VSCode に機能を追加するプラグインです。無料でインストールでき、開発効率を大幅に向上させます。

### インストール方法

1. `Ctrl + Shift + X` で拡張機能パネルを開く
2. 検索ボックスに拡張機能名を入力
3. 「インストール」をクリック
4. 必要に応じて VSCode を再起動

---

## Lint / Format

コードの品質チェックと自動整形を行う拡張機能。プロジェクトに合わせてどちらかを選択する。

### Biome（biomejs.biome）

Prettier + ESLint の代替として登場したオールインワンツール。Rust 製で高速。

- **用途**: Lint と Format を 1 つのツールで実行
- **対応言語**: JavaScript、TypeScript、JSX/TSX、JSON、CSS
- **特徴**:
  - 設定ファイルが `biome.json` 1 つにまとまる
  - Prettier 互換のフォーマットルール
  - ESLint 互換のリントルール（200 以上）
  - ESLint + Prettier より数十倍高速
- **注意**: Biome を使う場合、Prettier と ESLint は不要。競合を避けるため無効化すること

### Prettier - Code formatter（esbenp.prettier-vscode）

コードを自動でフォーマット（整形）する拡張機能。広く普及しており情報が豊富。

- **用途**: コードスタイルの統一、読みやすいコードの維持
- **対応言語**: JavaScript、TypeScript、HTML、CSS、JSON、Markdown 等
- **特徴**:
  - `.prettierrc` でプロジェクト単位の設定が可能
  - 保存時に自動フォーマット

**用語解説**:
- **フォーマット**: コードの見た目を整えること。インデントを統一したり、改行を調整したりする。

### ESLint（dbaeumer.vscode-eslint）

JavaScript / TypeScript のコード品質をチェックする拡張機能。

- **用途**: バグの早期発見、コーディング規約の遵守
- **特徴**:
  - 未使用の変数を警告
  - エラーの可能性を指摘
  - `.eslintrc.json` でルールをカスタマイズ

**用語解説**:
- **リント（Lint）**: コードの品質をチェックすること。バグを防ぐために使う。

## Git 連携

### GitLens（eamodio.gitlens）

Git の履歴や変更を視覚的に表示する拡張機能。

- **用途**: コードレビュー、変更履歴の確認
- **主な機能**:
  - 各行に最後に変更した人と日時を表示
  - ファイルの変更履歴をグラフで表示
  - ブランチの比較

**用語解説**:
- **Git**: ファイルの変更履歴を管理するシステム。
- **コードレビュー**: 他の人が書いたコードを確認して、問題がないかチェックすること。

## エラー表示

### Error Lens（usernamehw.errorlens）

エラー・警告をコード行のインラインに直接表示する。

- **用途**: エラーをすぐに確認できる
- **特徴**: 通常は「問題」パネルを開く必要があるが、行の右側にリアルタイム表示される

### Pretty TypeScript Errors（yoavbls.pretty-ts-errors）

TypeScript のエラーメッセージを人間が読みやすい形式に変換する。

- **用途**: 長い型エラーを構造化して表示
- **特徴**:
  - ジェネリクスやユニオン型のエラーを見やすく整形
  - 型の差分をハイライト表示
  - 不一致箇所が一目でわかる
- **設定不要**: インストールするだけで有効化

## フレームワーク・言語サポート

### Astro（astro-build.astro-vscode）

`.astro` ファイルの言語サポート。Astro フレームワークで開発するために必須。

- **主な機能**:
  - シンタックスハイライト
  - コード補完（HTML、CSS、JavaScript/TypeScript）
  - コンポーネントの型チェック
  - Frontmatter（`---` ブロック）の TypeScript サポート
  - Go to Definition / Find References

**用語解説**:
- **Frontmatter**: `.astro` ファイルの先頭にある `---` で囲まれた領域。サーバーサイドで実行される TypeScript を記述する。

### Tailwind CSS IntelliSense（bradlc.vscode-tailwindcss）

Tailwind CSS のクラス名補完と情報表示。

- **主な機能**:
  - クラス名のオートコンプリート（`bg-` と入力すると候補を表示）
  - ホバーで実際の CSS プロパティをプレビュー
  - 存在しないクラス名を警告
  - `tailwind.config.js` のカスタム設定にも対応

### Python（ms-python.python）+ Pylance

Microsoft 公式の Python 言語サポート。

- **機能**: コード補完、デバッグ、リント、型チェック、インポートの整理
- **補足**: Pylance は Python 拡張機能と一緒にインストールされることが多い

**用語解説**:
- **型チェック**: 変数の型（文字列、数値など）が正しく使われているかチェックすること。

### Extension Pack for Java

Microsoft 公式の Java 開発パック。

- **機能**: コード補完、デバッグ、Maven/Gradle サポート

### C/C++（ms-vscode.cpptools）

Microsoft 公式の C/C++ 言語サポート。

- **機能**: コード補完、デバッグ、IntelliSense

## HTML / XML 編集

### Auto Rename Tag（formulahendry.auto-rename-tag）

HTML/XML タグの開始・終了タグを同時にリネームする。

- **用途**: HTML/JSX/XML 編集時の効率化
- **使用例**: `<div>` を `<section>` に変更すると、自動で `</div>` も `</section>` に変更される

**用語解説**:
- **タグ**: HTML や XML で使われる、要素を囲む記号。`<div>` が開始タグ、`</div>` が終了タグ。

## 開発支援ツール

### GitHub Actions（github.vscode-github-actions）

GitHub Actions ワークフローファイル（`.github/workflows/*.yml`）の編集サポート。

- **主な機能**:
  - ワークフロー YAML のシンタックスハイライト
  - アクション名・入力パラメータの補完
  - ワークフロー構文のバリデーション
  - ワークフロー実行状況の確認（サイドバー）
- **設定不要**: インストールするだけで有効化

### Path Intellisense（christian-kohler.path-intellisense）

ファイルパスの補完機能。パスのタイプミスを防げる。

### Todo Tree（Gruntfuggly.todo-tree）

TODO コメントを一覧表示。コード内に `// TODO: ログイン機能を追加` と書くと、サイドバーに一覧表示される。

### Thunder Client / REST Client

API をテストする拡張機能。Web API の動作確認に使う。

**用語解説**:
- **API**: プログラム同士が通信するための仕組み。

### Live Server（ritwickdey.LiveServer）

ローカルサーバーを起動する拡張機能。HTML ファイルを右クリック → 「Open with Live Server」で使用。

**用語解説**:
- **ローカルサーバー**: 自分の PC 上で動くサーバー。Web 開発時のプレビューに使う。

## 見た目・可読性

### Material Icon Theme（PKief.material-icon-theme）

ファイルアイコンを美しく表示するテーマ。ファイルの種類を視覚的に識別しやすくなる。

### indent-rainbow（oderwat.indent-rainbow）

インデントを色分けして表示。コードの階層構造を視覚的に理解できる。

**用語解説**:
- **インデント**: コードの行頭に付ける空白（字下げ）。コードの構造を視覚的に表現する。

## `.vscode/extensions.json` でチームに共有

プロジェクトのルートに以下のファイルを配置すると、チームメンバーがプロジェクトを開いたときに推奨拡張機能のインストールを促せる。

**Astro + Tailwind 構成の例**:
```json
{
  "recommendations": [
    "biomejs.biome",
    "astro-build.astro-vscode",
    "bradlc.vscode-tailwindcss",
    "yoavbls.pretty-ts-errors",
    "usernamehw.errorlens",
    "github.vscode-github-actions"
  ]
}
```

**汎用的な構成の例**:
```json
{
  "recommendations": [
    "esbenp.prettier-vscode",
    "dbaeumer.vscode-eslint",
    "eamodio.gitlens",
    "usernamehw.errorlens",
    "formulahendry.auto-rename-tag"
  ]
}
```

## Cursor での補足

Cursor は VSCode のフォークであるため、上記の拡張機能はすべてそのまま利用できる。Cursor 固有の AI 機能（Tab 補完、Cmd+K、Chat）とこれらの拡張機能は競合しない。
