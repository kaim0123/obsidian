# Cursorの設定と使い方

Cursorは、VS CodeをベースにしたAI統合エディタです。この章では、Cursorの効果的な設定方法と使い方について解説します。

## 📖 Cursorとは

Cursorは、ChatGPTやClaudeなどのAIを統合したコードエディタです。エディタ内で直接AIアシスタントと対話しながらコーディングができます。

**主な特徴**:
- VS Codeの拡張機能やテーマと高い互換性
- AIによるコード補完・生成・修正支援
- コードベースのインデックス化（最大1万ファイル）
- プライバシーモード対応

## 1. 基本設定

### 設定ファイルの場所

- **Windows**: `%APPDATA%\Cursor\User\settings.json`
- **macOS**: `~/Library/Application Support/Cursor/User/settings.json`
- **Linux**: `~/.config/Cursor/User/settings.json`

### 推奨設定

```json
{
  // AI補完の設定
  "cursor.cpp.disabledLanguages": [],
  "cursor.general.enableAutoImport": true,
  
  // コード補完の設定
  "cursor.chat.model": "gpt-4",  // または "claude-3-opus"
  "cursor.chat.maxTokens": 4000,
  
  // プライバシー設定（機密情報がある場合は true）
  "cursor.general.enablePrivacyMode": false,
  
  // インデックス設定
  "cursor.index.maxFiles": 10000,
  "cursor.index.ignorePatterns": [
    "**/node_modules/**",
    "**/.git/**",
    "**/dist/**",
    "**/build/**",
    "**/.next/**",
    "**/coverage/**"
  ],
  
  // コードベース参照の設定
  "cursor.chat.enableCodebaseIndexing": true,
  
  // ショートカット設定
  "cursor.chat.shortcut": "ctrl+l",
  "cursor.composer.shortcut": "ctrl+i",
  
  // 自動補完の設定
  "cursor.general.enableAutoCompletions": true,
  "cursor.general.enableCodeActions": true
}
```

### 設定項目の説明

#### AI補完の設定

- `cursor.cpp.disabledLanguages`: AI補完を無効化する言語を指定
- `cursor.general.enableAutoImport`: 自動インポートを有効化

#### コード補完の設定

- `cursor.chat.model`: 使用するAIモデル（"gpt-4" または "claude-3-opus"）
- `cursor.chat.maxTokens`: 最大トークン数（応答の長さを制御）

#### プライバシー設定

- `cursor.general.enablePrivacyMode`: プライバシーモードを有効化（機密情報を含むコードを扱う際は `true` に設定）

#### インデックス設定

- `cursor.index.maxFiles`: インデックス化する最大ファイル数
- `cursor.index.ignorePatterns`: インデックス化から除外するパターン

## 2. プロジェクト固有の設定

### .cursorrules ファイル

プロジェクトのルートに `.cursorrules` ファイルを作成することで、プロジェクト固有のルールを設定できます。このファイルは、AIがコードを生成する際のガイドラインとして機能します。

### .cursorrules の例

```markdown
# .cursorrules

## プロジェクトの概要
このプロジェクトは、Node.js + Express.js + MySQLを使用したWebアプリケーションです。

## アーキテクチャ
- MVCパターンに従う
- モデル層にHTMLを含めない
- コントローラーは薄く保つ
- ビジネスロジックはモデルに配置

## コーディング規約
- JavaScript: ES6+を使用
- 命名規則: キャメルケース（変数・関数）、パスカルケース（クラス）
- インデント: 2スペース
- セミコロン: 使用する

## セキュリティ
- SQLインジェクション対策: プリペアドステートメントを使用
- XSS対策: エスケープ処理を実装
- 機密情報: 環境変数を使用
- CSRF対策: CSRFトークンの検証

## エラーハンドリング
- try-catchブロックを使用
- 適切なHTTPステータスコードを返す
- エラーログを記録
- ユーザーに分かりやすいエラーメッセージを返す

## テスト
- 単体テストを必ず書く
- テストカバレッジ80%以上を目標
- Jestを使用

## コード品質
- DRY原則に従う
- 関数は単一責任の原則に従う
- 適切なコメントを追加
```

### .cursorrules の効果

`.cursorrules` ファイルを設定することで、以下の効果が得られます：

1. **一貫性の向上**: プロジェクト全体で一貫したコードスタイル
2. **ミスの防止**: よくあるミス（MVC違反、セキュリティ対策の不足など）を防ぐ
3. **効率の向上**: 毎回同じ指示を繰り返す必要がなくなる

## 3. Cursorの効果的な使い方

### 1. AIチャット（`Ctrl + L`）

エディタ内でAIアシスタントと対話できます。

#### 良いプロンプト例

```
「この関数をリファクタリングしてください。DRY原則に従い、エラーハンドリングを追加してください。」

「このコードのセキュリティ脆弱性をチェックし、改善案を提示してください。
特にSQLインジェクション、XSS、CSRF対策を確認してください。」

「MVCパターンに従って、このコードを適切な層に分離してください。
モデル層にHTMLが含まれていないか確認してください。」
```

### 2. インライン編集（`Ctrl + K`）

コードを選択して `Ctrl + K` を押し、具体的な指示を入力します。

#### 良い指示例

- 「エラーハンドリングを追加してください。try-catchブロックを使用し、適切なHTTPステータスコードを返してください。」
- 「この関数をTypeScriptに変換してください」
- 「コメントを追加してください。各関数の目的とパラメータを説明してください。」
- 「テストコードを生成してください。Jestを使用し、正常系と異常系の両方をテストしてください。」

### 3. Composer（`Ctrl + I`）

複数ファイルにまたがる変更を一度に指示できます。

#### 良いプロンプト例

```
ユーザー認証機能を追加してください。以下のファイルを作成・修正してください:

- models/User.js: ユーザーモデル
  - データベース操作
  - パスワードハッシュ化（bcrypt）
  - バリデーション

- controllers/auth_controller.js: 認証コントローラー
  - ログイン処理
  - 登録処理
  - トークン検証

- routes/auth.js: 認証ルート
  - POST /api/auth/login
  - POST /api/auth/register
  - GET /api/auth/verify

- middleware/auth.js: 認証ミドルウェア
  - JWTトークンの検証

要件:
- MVCパターンに従う
- セキュリティベストプラクティスを適用
- エラーハンドリングを含める
- テストコードを含める
```

### 4. コードベース全体を参照（`Ctrl + Shift + L`）

コードベース全体を参照してチャットできます。

#### 良いプロンプト例

```
「このプロジェクトの既存の認証実装を参考に、新しい認証機能を追加してください。
既存のコードスタイルとアーキテクチャパターンに従ってください。」
```

## 4. よくあるミスを防ぐ設定

### MVC違反を防ぐ

`.cursorrules` に以下を追加：

```markdown
## アーキテクチャ
- MVCパターンに厳密に従う
- モデル層にHTMLを含めない
- ビュー層にビジネスロジックを含めない
- コントローラー層に過度なロジックを含めない
```

### セキュリティ対策を含める

`.cursorrules` に以下を追加：

```markdown
## セキュリティ
- SQLインジェクション対策: プリペアドステートメントを使用
- XSS対策: エスケープ処理を実装
- CSRF対策: CSRFトークンの検証
- 機密情報: 環境変数を使用
- 認証・認可: 適切に実装
```

### エラーハンドリングを含める

`.cursorrules` に以下を追加：

```markdown
## エラーハンドリング
- すべての非同期処理をtry-catchブロックで囲む
- 適切なHTTPステータスコードを返す
- エラーログを記録
- ユーザーに分かりやすいエラーメッセージを返す
```

## 5. セキュリティ設定

### プライバシーモード

機密情報を含むコードを扱う際は、プライバシーモードを有効化します。

```json
{
  "cursor.general.enablePrivacyMode": true
}
```

プライバシーモードを有効にすると、コードがリモートに保存されません。

### 機密情報の保護

1. **環境変数の使用**: 機密情報は環境変数に保存
2. **`.gitignore`の設定**: 機密情報を含むファイルを除外
3. **プライバシーモードの活用**: 機密情報を含むコードを扱う際は有効化
4. **コードレビュー**: 生成されたコードに機密情報が含まれていないか確認

## 🎯 まとめ

Cursorを効果的に使用するためには、以下の点が重要です：

1. **適切な設定**: 基本設定とプロジェクト固有の設定（`.cursorrules`）を行う
2. **効果的なプロンプト**: 具体的で明確なプロンプトを書く
3. **機能の活用**: AIチャット、インライン編集、Composerを適切に使い分ける
4. **セキュリティ**: プライバシーモードを適切に設定
5. **ミスの防止**: `.cursorrules`でよくあるミスを防ぐ設定を含める

適切に設定し、効果的に使用することで、開発効率を大幅に向上させることができます。
