# 解説HTML 作成ルール

Claude で作るときは スキル `md-to-explainer-html`（`.claude/skills/md-to-explainer-html/`）が同じルールで作業する。詳しい部品の書き方・テンプレートはスキル側を正とする。

## 置き場・ファイル名
- `public/<章フォルダ名>/` 直下（例：`public/74_セッション管理/`）。docs と同じ章フォルダ名にする
- 目次：`00-0_目次.html`、全体像：`00-1_<章テーマ>の全体像.html`
- 各ページ：`<フォルダ番号>-<通し番号>_<タイトル>.html`（例：`20-1_XSSの基本.html`）
- ファイル名の数字順＝読む順
- ファイル名の先頭に「解説_」は付けない。空白は使わない
- 1ページ＝1テーマ（ノート1〜数本）

## パス
`public/<章>/` 直下に置くので、1階層上がるだけ。

| 参照先 | 書き方 |
|---|---|
| 共通CSS / JS | `../_解説HTML/style.css`、`../_解説HTML/script.js` |
| 同じ章のページ | `10-1_Cookieの仕組み.html` |
| 他の章のページ | `../72_Web脆弱性対策/20-1_XSSの基本.html` |

## 見た目
- CSS・JS は共通ファイルを読み込む（ページに書かない）
- 色・フォントのテーマは `node scripts/apply-explainer-theme.mjs` が当てる（`scripts/explainer-theme/workbench.css` が正）。ページや style.css に手で色を書かない
- 骨組みは下の「テンプレート」をコピー。クラス名は style.css にあるものだけ使う
- サイトへの依存（`/_site/…` など）は書かない。全体ナビはサイトが配信時に差し込む

## 内容
- 初心者向け、です・ます調
- 元ノートの内容は削らない。ノートにない内容は最小限
- 専門用語は初出で一言説明
- hero の直後に「ひとことで言うと」（`callout key`）
- h2 は番号付き。最後は「まとめ」「理解度チェック」「参考資料」
- 図は流れ・位置関係を示す箇所だけ（インラインSVG、1ページ0〜3枚、`d-*` クラスを使う）
- それ以外は文章・表・コード比較（危険な例／安全な例）
- 他の章と重なる内容は書き直さずリンク

## 目次ページ
- フォルダごとにページ一覧＋1行説明
- おすすめの読む順
- 最後に関連するフォルダ（他の章の目次へのリンク）

## 前後ページ送り
- ファイル名の数字順でつなぐ。ページを足したら前後のページと目次も直す

## 確認
- `node .claude/skills/md-to-explainer-html/scripts/check.mjs public/<章>` でエラー0件にする（リンク切れ・未定義クラス・必須見出し・ページ送り・目次への載せ漏れ）
- `npm run dev` でブラウザ表示し、図の崩れを確認

## テンプレート
```html
<!doctype html>
<html lang="ja">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>ページタイトル｜章テーマ解説</title>
<link rel="stylesheet" href="../_解説HTML/style.css">
</head>
<body>
<header class="topbar">
  <div class="topbar-inner">
    <a class="site" href="00-0_目次.html">章テーマ解説</a>
    <span class="crumb"><a href="00-0_目次.html">目次</a> › 20 フォルダ名 › ページタイトル</span>
    <button class="toc-btn" type="button">目次</button>
  </div>
</header>
<div class="layout">
  <nav class="toc" id="toc"><p class="toc-title">このページの目次</p><ol id="toc-list"></ol></nav>
  <main>
    <div class="hero">
      <span class="eyebrow">20 フォルダ名</span>
      <h1>ページタイトル</h1>
      <p class="lead">リード文</p>
      <p class="meta">もとにしたノート：20_フォルダ名/01_ノート名</p>
    </div>

    <div class="callout key">
      <p class="callout-title">ひとことで言うと</p>
      <p>結論</p>
    </div>

    <h2 id="sec-1"><span class="num">1.</span>見出し</h2>
    <p>本文</p>

    <h2><span class="num">N.</span>まとめ</h2>
    <h2><span class="num">N.</span>理解度チェック</h2>
    <details><summary>Q1. 問題</summary><div class="body"><p>答え</p></div></details>
    <h2 id="sources">参考資料</h2>
    <ul class="sources"><li>…</li></ul>

    <nav class="pager" aria-label="ページ移動">
      <a class="prev" href="前.html"><span class="lbl">← 前のページ</span>前のタイトル</a>
      <a class="idx" href="00-0_目次.html">目次</a>
      <a class="next" href="次.html"><span class="lbl">次のページ →</span>次のタイトル</a>
    </nav>
  </main>
</div>
<script src="../_解説HTML/script.js"></script>
</body>
</html>
```
