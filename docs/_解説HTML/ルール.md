# 解説HTML 作成ルール

## 置き場・ファイル名
- `<テーマフォルダ>/00_全体像/` 直下
- 目次：`00-0_目次.html`
- 各ページ：`<フォルダ番号>-<通し番号>_<タイトル>.html`（例：`20-1_XSS.html`）
- ファイル名の先頭に「解説_」は付けない（置き場の 00_全体像 で解説ページと分かるため）
- 1ページ＝1テーマ（ノート1〜数本）

## 見た目
- ライトモードのみ。シンプルに
- CSS・JS は共通ファイルを読み込む（ページに書かない）
  - `<link rel="stylesheet" href="../../_解説HTML/style.css">`
  - `<script src="../../_解説HTML/script.js"></script>`
- 骨組みは下の「テンプレート」をコピー。クラス名は style.css にあるものだけ使う

## 内容
- 初心者向け、です・ます調
- 元ノートの内容は削らない。ノートにない内容は最小限
- 専門用語は初出で一言説明
- h2 は番号付き。最後は「まとめ」「理解度チェック」「参考資料」
- 図は流れ・位置関係を示す箇所だけ（インラインSVG、1ページ0〜3枚、`d-*` クラスを使う）
- それ以外は文章・表・コード比較（危険な例／安全な例）
- 他のフォルダ（71〜75）と重なる内容は書き直さずリンク

## 目次ページ
- フォルダごとにページ一覧＋1行説明
- おすすめの読む順

## 確認
- ブラウザで表示し、図の崩れ・リンク切れを確認

## テンプレート
```html
<!doctype html>
<html lang="ja">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>ページタイトル｜サイト名</title>
<link rel="stylesheet" href="../../_解説HTML/style.css">
</head>
<body>
<header class="topbar">
  <div class="topbar-inner">
    <a class="site" href="00-0_目次.html">サイト名</a>
    <span class="crumb"><a href="00-0_目次.html">目次</a> › 20 フォルダ名 › ページタイトル</span>
    <button class="toc-btn" type="button">目次</button>
  </div>
</header>
<div class="layout">
  <nav class="toc" id="toc"><p class="toc-title">このページの目次</p><ol id="toc-list"></ol></nav>
  <main>
    <div class="hero">
      <span class="eyebrow">20 フォルダ名</span>
      <h1>ページタイトル</h1>
      <p class="lead">リード文</p>
      <p class="meta">もとにしたノート：20_フォルダ名/01_ノート名</p>
    </div>

    <h2><span class="num">1.</span>見出し</h2>
    <p>本文</p>

    <h2><span class="num">N.</span>まとめ</h2>
    <h2><span class="num">N.</span>理解度チェック</h2>
    <details><summary>Q1. 問題</summary><div class="body"><p>答え</p></div></details>
    <h2>参考資料</h2>
    <ul class="sources"><li>…</li></ul>

    <nav class="pager">
      <a class="prev" href="前.html"><span class="lbl">← 前のページ</span>前のタイトル</a>
      <a class="idx" href="00-0_目次.html">目次</a>
      <a class="next" href="次.html"><span class="lbl">次のページ →</span>次のタイトル</a>
    </nav>
  </main>
</div>
<script src="../../_解説HTML/script.js"></script>
</body>
</html>
```
