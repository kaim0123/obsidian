# モジュールの使い方

## はじめに

前の章では、エラーハンドリング（try-except）を学びました。

この章では、**モジュールの使い方**を学びます。モジュールを使うと、コードを整理して再利用できるようになります。

## モジュールとは

### 簡単に言うと

**モジュール**とは、**関数や変数をまとめたファイル**のことです。

### モジュールのメリット

- ✅ **コードの整理**：関連する機能をまとめられる
- ✅ **再利用**：一度書いたコードを何度も使える
- ✅ **保守性**：変更が簡単になる

## モジュールの作成

### 簡単なモジュールの例

`math_utils.py` というファイルを作成します：

```python
# math_utils.py

def add(a, b):
    """2つの数を足す"""
    return a + b

def subtract(a, b):
    """2つの数を引く"""
    return a - b

def multiply(a, b):
    """2つの数を掛ける"""
    return a * b

def divide(a, b):
    """2つの数を割る"""
    if b == 0:
        return "ゼロで割ることはできません"
    return a / b
```

## モジュールのインポート

### import文

モジュールをインポート（読み込む）するには、`import`文を使います。

```python
import math_utils

result = math_utils.add(10, 5)
print(result)  # 15
```

### from ... import ...

特定の関数だけをインポートできます。

```python
from math_utils import add, subtract

result = add(10, 5)
print(result)  # 15

result = subtract(10, 5)
print(result)  # 5
```

### from ... import ... as ...

別名を付けてインポートできます。

```python
from math_utils import add as plus

result = plus(10, 5)
print(result)  # 15
```

### import ... as ...

モジュール全体に別名を付けられます。

```python
import math_utils as mu

result = mu.add(10, 5)
print(result)  # 15
```

## 標準ライブラリ

### 標準ライブラリとは

Pythonには、**標準ライブラリ**という、最初から使えるモジュールがたくさんあります。

### よく使う標準ライブラリ

#### math：数学関数

```python
import math

# 円周率
print(math.pi)  # 3.141592653589793

# 平方根
print(math.sqrt(16))  # 4.0

# 切り上げ
print(math.ceil(3.7))  # 4

# 切り捨て
print(math.floor(3.7))  # 3
```

#### datetime：日時処理

```python
from datetime import datetime, timedelta

# 現在の日時
now = datetime.now()
print(now)  # 2024-01-01 12:00:00.123456

# 日時のフォーマット
formatted = now.strftime("%Y-%m-%d %H:%M:%S")
print(formatted)  # 2024-01-01 12:00:00

# 日時の加算
future = now + timedelta(days=7)
print(future)  # 2024-01-08 12:00:00.123456
```

#### random：乱数

```python
import random

# 0から9までの乱数
number = random.randint(0, 9)
print(number)

# リストからランダムに選択
fruits = ["りんご", "バナナ", "オレンジ"]
fruit = random.choice(fruits)
print(fruit)

# リストをシャッフル
numbers = [1, 2, 3, 4, 5]
random.shuffle(numbers)
print(numbers)
```

#### os：オペレーティングシステム

```python
import os

# 現在のディレクトリ
current_dir = os.getcwd()
print(current_dir)

# ファイルが存在するかチェック
if os.path.exists("test.txt"):
    print("ファイルが存在します")

# パスを結合
file_path = os.path.join("data", "test.txt")
print(file_path)
```

#### json：JSON処理

```python
import json

# 辞書をJSON文字列に変換
data = {"name": "太郎", "age": 25}
json_string = json.dumps(data)
print(json_string)  # {"name": "\u592a\u90ce", "age": 25}

# JSON文字列を辞書に変換
parsed = json.loads(json_string)
print(parsed)  # {'name': '太郎', 'age': 25}
```

## パッケージ

### パッケージとは

**パッケージ**とは、**複数のモジュールをまとめたもの**です。

### パッケージの構造

```
my_package/
    __init__.py
    module1.py
    module2.py
    subpackage/
        __init__.py
        module3.py
```

### パッケージのインポート

```python
# パッケージ全体をインポート
import my_package

# パッケージ内のモジュールをインポート
from my_package import module1

# サブパッケージをインポート
from my_package.subpackage import module3
```

## 実用的な例

### 例1：ユーティリティモジュール

`utils.py` を作成：

```python
# utils.py

def format_name(first, last):
    """名前を整形"""
    return f"{last} {first}".title()

def calculate_age(birth_year):
    """年齢を計算"""
    from datetime import datetime
    current_year = datetime.now().year
    return current_year - birth_year

def is_valid_email(email):
    """メールアドレスを検証"""
    return "@" in email and "." in email
```

使用例：

```python
from utils import format_name, calculate_age, is_valid_email

name = format_name("taro", "yamada")
print(name)  # Yamada Taro

age = calculate_age(1990)
print(age)  # 34

if is_valid_email("user@example.com"):
    print("有効なメールアドレスです")
```

### 例2：データ処理モジュール

`data_processor.py` を作成：

```python
# data_processor.py

def calculate_average(numbers):
    """平均を計算"""
    if not numbers:
        return 0
    return sum(numbers) / len(numbers)

def find_max(numbers):
    """最大値を取得"""
    if not numbers:
        return None
    return max(numbers)

def find_min(numbers):
    """最小値を取得"""
    if not numbers:
        return None
    return min(numbers)
```

使用例：

```python
from data_processor import calculate_average, find_max, find_min

scores = [80, 90, 70, 85, 95]
print(f"平均: {calculate_average(scores)}")
print(f"最高点: {find_max(scores)}")
print(f"最低点: {find_min(scores)}")
```

## よくあるエラー

### エラー1：モジュールが見つからない

**エラーメッセージ：**
```
ModuleNotFoundError: No module named 'math_utils'
```

**原因：**
- モジュールファイルが存在しない
- パスが間違っている

**解決方法：**
1. モジュールファイルが同じディレクトリにあるか確認
2. ファイル名が正しいか確認

### エラー2：循環インポート

**問題：**
```python
# module1.py
import module2

# module2.py
import module1  # 循環インポート
```

**解決方法：**
- モジュールの依存関係を見直す
- 必要な時だけインポートする

## 練習問題

### 問題1：モジュールを作成する

`calculator.py` というモジュールを作成して、四則演算の関数を定義してください。

**ヒント：**
```python
# calculator.py
def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

def multiply(a, b):
    return a * b

def divide(a, b):
    if b == 0:
        return "ゼロで割ることはできません"
    return a / b
```

### 問題2：モジュールをインポートする

作成した `calculator.py` をインポートして、計算を実行してください。

**ヒント：**
```python
import calculator

result = calculator.add(10, 5)
print(result)  # 15
```

import random

numbers = [random.randint(1, 100) for _ in range(5)]
