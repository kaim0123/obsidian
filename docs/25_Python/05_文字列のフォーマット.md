# 文字列のフォーマット

## はじめに

前の章では、文字列操作の詳細を学びました。

この章では、**文字列のフォーマット**を学びます。変数の値を文字列に埋め込んで、美しく表示できるようになります。

## 文字列フォーマットの方法

Pythonには、文字列をフォーマットする方法がいくつかあります。

### 1. %演算子（古い方法）

```python
name = "太郎"
age = 25
text = "私の名前は%sです。年齢は%d歳です。" % (name, age)
print(text)  # 私の名前は太郎です。年齢は25歳です。
```

**フォーマット指定子：**
- `%s`：文字列
- `%d`：整数
- `%f`：浮動小数点数

### 2. format()メソッド

```python
name = "太郎"
age = 25
text = "私の名前は{}です。年齢は{}歳です。".format(name, age)
print(text)  # 私の名前は太郎です。年齢は25歳です。
```

### 3. f-string（推奨）

```python
name = "太郎"
age = 25
text = f"私の名前は{name}です。年齢は{age}歳です。"
print(text)  # 私の名前は太郎です。年齢は25歳です。
```

**f-stringがおすすめ**：読みやすく、書きやすいです。

## f-stringの詳細

### 基本的な使い方

```python
name = "太郎"
age = 25

# 変数を埋め込む
text = f"私の名前は{name}です。年齢は{age}歳です。"
print(text)
```

### 式を埋め込む

```python
a = 10
b = 20

# 計算結果を埋め込む
text = f"{a} + {b} = {a + b}"
print(text)  # 10 + 20 = 30
```

### 関数呼び出しを埋め込む

```python
name = "太郎"

# メソッドを呼び出す
text = f"名前は{name.upper()}です"
print(text)  # 名前は太郎です
```

## 数値のフォーマット

### 小数点の桁数を指定

```python
pi = 3.14159265

# 小数点以下2桁
text = f"円周率は{pi:.2f}です"
print(text)  # 円周率は3.14です

# 小数点以下4桁
text = f"円周率は{pi:.4f}です"
print(text)  # 円周率は3.1416です
```

### 整数の桁数を指定

```python
number = 42

# 5桁で表示（足りない分は0で埋める）
text = f"番号は{number:05d}です"
print(text)  # 番号は00042です
```

### カンマ区切り

```python
price = 1000000

# カンマ区切りで表示
text = f"価格は{price:,}円です"
print(text)  # 価格は1,000,000円です
```

### パーセント表示

```python
rate = 0.15

# パーセントで表示
text = f"税率は{rate:.1%}です"
print(text)  # 税率は15.0%です
```

## 文字列の配置

### 左揃え

```python
name = "太郎"

# 10文字分の幅で左揃え
text = f"|{name:<10}|"
print(text)  # |太郎        |
```

### 右揃え

```python
name = "太郎"

# 10文字分の幅で右揃え
text = f"|{name:>10}|"
print(text)  # |        太郎|
```

### 中央揃え

```python
name = "太郎"

# 10文字分の幅で中央揃え
text = f"|{name:^10}|"
print(text)  # |    太郎    |
```

### 埋め文字を指定

```python
name = "太郎"

# 0で埋める
text = f"|{name:0>10}|"
print(text)  # |00000000太郎|

# *で埋める
text = f"|{name:*^10}|"
print(text)  # |***太郎****|
```

## 実用的な例

### 例1：レシートの表示

```python
def print_receipt(items):
    total = 0
    print("=" * 30)
    print("レシート")
    print("=" * 30)
    
    for item, price in items:
        print(f"{item:20} {price:>6,}円")
        total += price
    
    print("-" * 30)
    print(f"{'合計':20} {total:>6,}円")
    print("=" * 30)

items = [("りんご", 100), ("バナナ", 150), ("オレンジ", 120)]
print_receipt(items)
```

実行結果：
```
==============================
レシート
==============================
りんご                   100円
バナナ                   150円
オレンジ                 120円
------------------------------
合計                     370円
==============================
```

### 例2：成績表の表示

```python
def print_grades(students):
    print(f"{'名前':<10} {'点数':>6} {'評価':>6}")
    print("-" * 24)
    
    for name, score in students:
        if score >= 90:
            grade = "優秀"
        elif score >= 70:
            grade = "合格"
        else:
            grade = "不合格"
        
        print(f"{name:<10} {score:>6} {grade:>6}")

students = [("太郎", 85), ("花子", 92), ("次郎", 65)]
print_grades(students)
```

実行結果：
```
名前         点数   評価
------------------------
太郎           85   合格
花子           92   優秀
次郎           65 不合格
```

### 例3：進捗バーの表示

```python
def show_progress(current, total):
    percentage = (current / total) * 100
    bar_length = 20
    filled = int(bar_length * current / total)
    bar = "=" * filled + "-" * (bar_length - filled)
    
    print(f"[{bar}] {percentage:.1f}% ({current}/{total})")

show_progress(7, 10)
```

実行結果：
```
[==============------] 70.0% (7/10)
```

## 複雑なフォーマット

### 条件付きフォーマット

```python
age = 20

# 条件に応じて表示を変える
text = f"年齢は{age}歳で、{'大人' if age >= 18 else '子供'}です"
print(text)  # 年齢は20歳で、大人です
```

### 辞書を使ったフォーマット

```python
person = {"name": "太郎", "age": 25}

# 辞書の値を直接使う
text = f"名前は{person['name']}で、年齢は{person['age']}歳です"
print(text)
```

### リストを使ったフォーマット

```python
scores = [80, 90, 70]

# リストの要素を使う
text = f"点数は{scores[0]}、{scores[1]}、{scores[2]}です"
print(text)
```

## よくあるエラー

### エラー1：f-stringのfを忘れる

**問題：**
```python
name = "太郎"
text = "私の名前は{name}です"  # fがない
print(text)  # 私の名前は{name}です（そのまま表示される）
```

**解決方法：**
```python
name = "太郎"
text = f"私の名前は{name}です"  # fを付ける
print(text)  # 私の名前は太郎です
```

### エラー2：引用符の使い方

**問題：**
```python
name = "太郎"
# text = f"私の名前は"{name}"です"  # エラー
```

**解決方法：**
```python
name = "太郎"
# 方法1：異なる引用符を使う
text = f'私の名前は"{name}"です'

# 方法2：エスケープする
text = f"私の名前は\"{name}\"です"
```
