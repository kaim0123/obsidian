# タプルとセット

## はじめに

前の章では、辞書（dict）を学びました。

この章では、**タプルとセット**を学びます。これで、Pythonの主要なデータ構造を全て学びます。

## タプル（tuple）とは

### 簡単に言うと

**タプル**とは、**変更できないリスト**のようなものです。

### リストとの違い

| 特徴 | リスト | タプル |
|------|--------|--------|
| **変更可能** | ✅ 可能 | ❌ 不可能 |
| **書き方** | `[1, 2, 3]` | `(1, 2, 3)` |
| **用途** | 変更が必要なデータ | 変更不要なデータ |

### 基本的な書き方

```python
# タプルの作成
coordinates = (10, 20)
colors = ("赤", "青", "緑")

# 括弧は省略可能
coordinates = 10, 20
```

### タプルの特徴

#### 1. 変更できない（イミュータブル）

```python
coordinates = (10, 20)
# coordinates[0] = 30  # エラー！変更できない
```

#### 2. 要素へのアクセスは可能

```python
coordinates = (10, 20)
print(coordinates[0])  # 10
print(coordinates[1])  # 20
```

#### 3. スライスも可能

```python
colors = ("赤", "青", "緑", "黄", "紫")
print(colors[1:3])  # ("青", "緑")
```

### タプルの使いどころ

#### 1. 座標

```python
point = (10, 20)
print(f"X座標: {point[0]}, Y座標: {point[1]}")
```

#### 2. RGBカラー

```python
red = (255, 0, 0)
green = (0, 255, 0)
blue = (0, 0, 255)
```

#### 3. 関数の戻り値（複数の値を返す）

```python
def get_name_and_age():
    return "太郎", 25

name, age = get_name_and_age()
print(name)  # 太郎
print(age)   # 25
```

### タプルの操作

#### count()：要素の個数を数える

```python
numbers = (1, 2, 2, 3, 2, 4)
count = numbers.count(2)
print(count)  # 3
```

#### index()：要素のインデックスを取得

```python
colors = ("赤", "青", "緑")
index = colors.index("青")
print(index)  # 1
```

#### len()：要素の個数を取得

```python
colors = ("赤", "青", "緑")
print(len(colors))  # 3
```

## セット（set）とは

### 簡単に言うと

**セット**とは、**重複のない要素の集合**です。

### リストとの違い

| 特徴 | リスト | セット |
|------|--------|--------|
| **重複** | ✅ 可能 | ❌ 不可能 |
| **順序** | ✅ 保持される | ❌ 保持されない |
| **書き方** | `[1, 2, 3]` | `{1, 2, 3}` |

### 基本的な書き方

```python
# セットの作成
fruits = {"りんご", "バナナ", "オレンジ"}

# 空のセット（注意：{}は辞書になる）
empty_set = set()
```

### セットの特徴

#### 1. 重複が自動的に削除される

```python
numbers = {1, 2, 2, 3, 3, 4}
print(numbers)  # {1, 2, 3, 4}（重複が削除される）
```

#### 2. 順序が保証されない

```python
fruits = {"りんご", "バナナ", "オレンジ"}
print(fruits)  # 順序は保証されない
```

### セットの操作

#### add()：要素を追加

```python
fruits = {"りんご", "バナナ"}
fruits.add("オレンジ")
print(fruits)  # {"りんご", "バナナ", "オレンジ"}
```

#### remove()：要素を削除

```python
fruits = {"りんご", "バナナ", "オレンジ"}
fruits.remove("バナナ")
print(fruits)  # {"りんご", "オレンジ"}
```

#### discard()：要素を削除（エラーにならない）

```python
fruits = {"りんご", "バナナ", "オレンジ"}
fruits.discard("ぶどう")  # 存在しなくてもエラーにならない
```

#### clear()：全ての要素を削除

```python
fruits = {"りんご", "バナナ", "オレンジ"}
fruits.clear()
print(fruits)  # set()
```

### セットの集合演算

#### union()（または `|`）：和集合

```python
set1 = {1, 2, 3}
set2 = {3, 4, 5}

# 方法1
union = set1.union(set2)
print(union)  # {1, 2, 3, 4, 5}

# 方法2
union = set1 | set2
print(union)  # {1, 2, 3, 4, 5}
```

#### intersection()（または `&`）：積集合

```python
set1 = {1, 2, 3}
set2 = {3, 4, 5}

# 方法1
intersection = set1.intersection(set2)
print(intersection)  # {3}

# 方法2
intersection = set1 & set2
print(intersection)  # {3}
```

#### difference()（または `-`）：差集合

```python
set1 = {1, 2, 3}
set2 = {3, 4, 5}

# 方法1
difference = set1.difference(set2)
print(difference)  # {1, 2}

# 方法2
difference = set1 - set2
print(difference)  # {1, 2}
```

#### symmetric_difference()（または `^`）：対称差集合

```python
set1 = {1, 2, 3}
set2 = {3, 4, 5}

# 方法1
sym_diff = set1.symmetric_difference(set2)
print(sym_diff)  # {1, 2, 4, 5}

# 方法2
sym_diff = set1 ^ set2
print(sym_diff)  # {1, 2, 4, 5}
```

### セットの便利なメソッド

#### in：要素が含まれているかチェック

```python
fruits = {"りんご", "バナナ", "オレンジ"}
if "りんご" in fruits:
    print("りんごがあります")
```

#### issubset()：部分集合かチェック

```python
set1 = {1, 2}
set2 = {1, 2, 3, 4}

print(set1.issubset(set2))  # True
```

#### issuperset()：上位集合かチェック

```python
set1 = {1, 2, 3, 4}
set2 = {1, 2}

print(set1.issuperset(set2))  # True
```

## 実用的な例

### 例1：タプルで座標を管理

```python
# 複数の点の座標
points = [(0, 0), (10, 20), (30, 40)]

for point in points:
    x, y = point
    print(f"X: {x}, Y: {y}")
```

### 例2：セットで重複を削除

```python
# リストから重複を削除
numbers = [1, 2, 2, 3, 3, 4, 5, 5]
unique_numbers = list(set(numbers))
print(unique_numbers)  # [1, 2, 3, 4, 5]
```

### 例3：セットで共通の要素を見つける

```python
# 2つのリストの共通要素
list1 = [1, 2, 3, 4, 5]
list2 = [4, 5, 6, 7, 8]

set1 = set(list1)
set2 = set(list2)

common = set1 & set2
print(common)  # {4, 5}
```

### 例4：セットで購読者を管理

```python
# 2つのニュースレターの購読者
newsletter1 = {"太郎", "花子", "次郎"}
newsletter2 = {"花子", "次郎", "三郎"}

# 両方購読している人
both = newsletter1 & newsletter2
print("両方購読：", both)  # {"花子", "次郎"}

# どちらか一方だけ購読している人
only_one = newsletter1 ^ newsletter2
print("どちらか一方：", only_one)  # {"太郎", "三郎"}
```

## データ構造の使い分け

### どのデータ構造を使うべきか

| データ構造 | 使いどころ |
|-----------|-----------|
| **リスト** | 順序が重要、変更が必要、重複OK |
| **辞書** | キーと値のペア、検索が速い |
| **タプル** | 変更不要、座標やRGBなど |
| **セット** | 重複を避けたい、集合演算が必要 |

### 例：学生の成績管理

```python
# リスト：学生の名前（順序が重要）
students = ["太郎", "花子", "次郎"]

# 辞書：学生の成績（キーで検索）
scores = {
    "太郎": 85,
    "花子": 90,
    "次郎": 80
}

# タプル：各学生の情報（変更不要）
student_info = ("太郎", 20, "東京")

# セット：合格した学生（重複なし）
passed = {"太郎", "花子"}
```

## よくあるエラー

### エラー1：タプルを変更しようとする

**エラーメッセージ：**
```
TypeError: 'tuple' object does not support item assignment
```

**原因：**
- タプルは変更できない

**解決方法：**
```python
# タプルは変更できないので、リストを使う
coordinates = [10, 20]
coordinates[0] = 30  # OK
```

### エラー2：空のセットを作成する

**問題：**
```python
empty = {}  # これは辞書になる！
```

**解決方法：**
```python
empty = set()  # 正しい
```

## 練習問題

### 問題1：タプルで座標を管理

3つの点の座標をタプルで管理して、それぞれの座標を表示してください。

**ヒント：**
```python
points = [(0, 0), (10, 20), (30, 40)]
for point in points:
    x, y = point
    print(f"X: {x}, Y: {y}")
```

### 問題2：セットで重複を削除

リスト `[1, 2, 2, 3, 3, 4, 5, 5]` から重複を削除してください。

**ヒント：**
```python
numbers = [1, 2, 2, 3, 3, 4, 5, 5]
unique = list(set(numbers))
print(unique)
```

### 問題3：セットの集合演算

2つのセット `{1, 2, 3, 4}` と `{3, 4, 5, 6}` の和集合、積集合、差集合を計算してください。

**ヒント：**
```python
set1 = {1, 2, 3, 4}
set2 = {3, 4, 5, 6}

print("和集合：", set1 | set2)
print("積集合：", set1 & set2)
print("差集合：", set1 - set2)
```

## まとめ

### 学んだこと

1. ✅ **タプル**：変更できないリスト、座標やRGBなどに使う
2. ✅ **セット**：重複のない要素の集合、集合演算ができる
3. ✅ **データ構造の使い分け**：用途に応じて適切なデータ構造を選ぶ

### Pythonの主要なデータ構造

- ✅ **リスト**：順序が重要、変更可能
- ✅ **辞書**：キーと値のペア
- ✅ **タプル**：変更不可
- ✅ **セット**：重複なし、集合演算
