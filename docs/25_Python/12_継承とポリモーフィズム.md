# 継承とポリモーフィズム

## はじめに

前の章では、クラスとオブジェクトを学びました。

この章では、**継承とポリモーフィズム**を学びます。オブジェクト指向プログラミングの重要な概念を理解できるようになります。

## 継承とは

### 簡単に言うと

**継承**とは、**既存のクラスを基に新しいクラスを作る**ことです。

### 具体例で理解する

#### 例：動物

- **基底クラス（親クラス）**：動物（「食べる」「寝る」などの共通の機能）
- **派生クラス（子クラス）**：犬、猫（動物の機能を引き継ぎ、独自の機能を追加）

## 継承の基本

### 基本的な書き方

```python
class 親クラス:
    # 親クラスの定義
    pass

class 子クラス(親クラス):
    # 子クラスの定義
    pass
```

### 具体例：動物クラス

```python
class Animal:
    def __init__(self, name):
        self.name = name
    
    def eat(self):
        print(f"{self.name}が食べています")
    
    def sleep(self):
        print(f"{self.name}が寝ています")

class Dog(Animal):
    def bark(self):
        print(f"{self.name}がワンワンと鳴いています")

class Cat(Animal):
    def meow(self):
        print(f"{self.name}がニャーニャーと鳴いています")
```

### 使用例

```python
dog = Dog("ポチ")
dog.eat()    # ポチが食べています（親クラスのメソッド）
dog.sleep()  # ポチが寝ています（親クラスのメソッド）
dog.bark()   # ポチがワンワンと鳴いています（子クラスのメソッド）

cat = Cat("タマ")
cat.eat()   # タマが食べています
cat.meow()  # タマがニャーニャーと鳴いています
```

## メソッドのオーバーライド

### オーバーライドとは

**オーバーライド**とは、**親クラスのメソッドを子クラスで再定義する**ことです。

### 具体例

```python
class Animal:
    def __init__(self, name):
        self.name = name
    
    def make_sound(self):
        print(f"{self.name}が音を出しています")

class Dog(Animal):
    def make_sound(self):  # 親クラスのメソッドをオーバーライド
        print(f"{self.name}がワンワンと鳴いています")

class Cat(Animal):
    def make_sound(self):  # 親クラスのメソッドをオーバーライド
        print(f"{self.name}がニャーニャーと鳴いています")
```

### 使用例

```python
dog = Dog("ポチ")
dog.make_sound()  # ポチがワンワンと鳴いています

cat = Cat("タマ")
cat.make_sound()  # タマがニャーニャーと鳴いています
```

## super()の使い方

### super()とは

**super()**は、**親クラスのメソッドを呼び出す**時に使います。

### 具体例

```python
class Animal:
    def __init__(self, name):
        self.name = name
        print(f"動物 {self.name} が作成されました")

class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)  # 親クラスの__init__を呼び出す
        self.breed = breed
        print(f"犬種: {self.breed}")

dog = Dog("ポチ", "柴犬")
# 動物 ポチ が作成されました
# 犬種: 柴犬
```

## ポリモーフィズムとは

### 簡単に言うと

**ポリモーフィズム**とは、**同じメソッド名で異なる動作をする**ことです。

### 具体例

```python
class Animal:
    def make_sound(self):
        pass

class Dog(Animal):
    def make_sound(self):
        print("ワンワン")

class Cat(Animal):
    def make_sound(self):
        print("ニャーニャー")

class Bird(Animal):
    def make_sound(self):
        print("チュンチュン")

# ポリモーフィズムの例
animals = [Dog("ポチ"), Cat("タマ"), Bird("ピヨ")]
for animal in animals:
    animal.make_sound()  # 同じメソッド名で異なる動作
```

実行結果：
```
ワンワン
ニャーニャー
チュンチュン
```

## 実用的な例

### 例1：図形クラス

```python
class Shape:
    def area(self):
        """面積を計算（抽象メソッド）"""
        raise NotImplementedError("サブクラスで実装してください")
    
    def perimeter(self):
        """周囲の長さを計算（抽象メソッド）"""
        raise NotImplementedError("サブクラスで実装してください")

class Rectangle(Shape):
    def __init__(self, width, height):
        self.width = width
        self.height = height
    
    def area(self):
        return self.width * self.height
    
    def perimeter(self):
        return 2 * (self.width + self.height)

class Circle(Shape):
    def __init__(self, radius):
        self.radius = radius
    
    def area(self):
        import math
        return math.pi * self.radius ** 2
    
    def perimeter(self):
        import math
        return 2 * math.pi * self.radius

# ポリモーフィズムの例
shapes = [
    Rectangle(5, 3),
    Circle(4),
    Rectangle(2, 2)
]

for shape in shapes:
    print(f"面積: {shape.area():.2f}, 周囲: {shape.perimeter():.2f}")
```

### 例2：従業員クラス

```python
class Employee:
    def __init__(self, name, salary):
        self.name = name
        self.salary = salary
    
    def calculate_bonus(self):
        """ボーナスを計算"""
        return self.salary * 0.1

class Manager(Employee):
    def calculate_bonus(self):  # オーバーライド
        """マネージャーのボーナス（通常の2倍）"""
        return self.salary * 0.2

class Developer(Employee):
    def calculate_bonus(self):  # オーバーライド
        """開発者のボーナス（通常の1.5倍）"""
        return self.salary * 0.15

# ポリモーフィズムの例
employees = [
    Employee("太郎", 500000),
    Manager("花子", 800000),
    Developer("次郎", 600000)
]

for emp in employees:
    bonus = emp.calculate_bonus()
    print(f"{emp.name}: ボーナス {bonus:,.0f}円")
```

## isinstance()とissubclass()

### isinstance()：型チェック

```python
class Animal:
    pass

class Dog(Animal):
    pass

dog = Dog()

print(isinstance(dog, Dog))    # True
print(isinstance(dog, Animal)) # True（継承関係）
print(isinstance(dog, str))    # False
```

### issubclass()：継承関係のチェック

```python
class Animal:
    pass

class Dog(Animal):
    pass

print(issubclass(Dog, Animal))  # True
print(issubclass(Animal, Dog))   # False
```

## 多重継承

### 多重継承とは

**多重継承**とは、**複数の親クラスから継承する**ことです。

### 具体例

```python
class Flyable:
    def fly(self):
        print("飛んでいます")

class Swimmable:
    def swim(self):
        print("泳いでいます")

class Duck(Flyable, Swimmable):
    def quack(self):
        print("ガーガー")

duck = Duck()
duck.fly()   # 飛んでいます
duck.swim()  # 泳いでいます
duck.quack() # ガーガー
```

**注意**：多重継承は複雑になることがあるので、慎重に使う必要があります。

## よくあるエラー

### エラー1：親クラスのメソッドを呼び出せない

**問題：**
```python
class Animal:
    def __init__(self, name):
        self.name = name

class Dog(Animal):
    def __init__(self, name, breed):
        # 親クラスの__init__を呼び出していない
        self.breed = breed
```

**解決方法：**
```python
class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)  # 親クラスの__init__を呼び出す
        self.breed = breed
```

## 練習問題

### 問題1：車クラスの継承

車クラスを継承して、電気自動車クラスを作成してください。

**ヒント：**
```python
class Car:
    def __init__(self, brand, model):
        self.brand = brand
        self.model = model
        self.fuel = 100
    
    def drive(self):
        if self.fuel > 0:
            self.fuel -= 10
            print(f"{self.brand} {self.model}が走っています")
        else:
            print("燃料がありません")

class ElectricCar(Car):
    def __init__(self, brand, model, battery):
        super().__init__(brand, model)
        self.battery = battery
    
    def drive(self):  # オーバーライド
        if self.battery > 0:
            self.battery -= 5
            print(f"{self.brand} {self.model}が静かに走っています")
        else:
            print("バッテリーがありません")
```
