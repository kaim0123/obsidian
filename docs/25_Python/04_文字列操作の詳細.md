# 文字列操作の詳細

## はじめに

前の章では、タプルとセットを学びました。

この章では、**文字列操作の詳細**を学びます。文字列をより効果的に扱えるようになります。

## 文字列の基本操作

### 文字列の連結

#### +演算子

```python
first_name = "太郎"
last_name = "山田"
full_name = last_name + first_name
print(full_name)  # 山田太郎
```

#### join()メソッド

```python
words = ["こんにちは", "世界"]
sentence = " ".join(words)
print(sentence)  # こんにちは 世界
```

### 文字列の繰り返し

```python
word = "Hello"
repeated = word * 3
print(repeated)  # HelloHelloHello
```

## 文字列の検索と置換

### find()：文字列を検索

```python
text = "こんにちは、世界"
index = text.find("世界")
print(index)  # 6
```

### replace()：文字列を置換

```python
text = "こんにちは、世界"
new_text = text.replace("世界", "Python")
print(new_text)  # こんにちは、Python
```

### in：文字列が含まれているかチェック

```python
text = "こんにちは、世界"
if "世界" in text:
    print("「世界」が含まれています")
```

### startswith()：文字列で始まるかチェック

```python
text = "こんにちは、世界"
if text.startswith("こんにちは"):
    print("「こんにちは」で始まります")
```

### endswith()：文字列で終わるかチェック

```python
text = "こんにちは、世界"
if text.endswith("世界"):
    print("「世界」で終わります")
```

## 文字列の分割と結合

### split()：文字列を分割

```python
text = "りんご,バナナ,オレンジ"
fruits = text.split(",")
print(fruits)  # ["りんご", "バナナ", "オレンジ"]
```

### splitlines()：改行で分割

```python
text = "りんご\nバナナ\nオレンジ"
fruits = text.splitlines()
print(fruits)  # ["りんご", "バナナ", "オレンジ"]
```

### join()：文字列を結合

```python
fruits = ["りんご", "バナナ", "オレンジ"]
text = ",".join(fruits)
print(text)  # りんご,バナナ,オレンジ
```

## 文字列の変換

### upper()：大文字に変換

```python
text = "hello"
uppercase = text.upper()
print(uppercase)  # HELLO
```

### lower()：小文字に変換

```python
text = "HELLO"
lowercase = text.lower()
print(lowercase)  # hello
```

### capitalize()：最初の文字を大文字に

```python
text = "hello"
capitalized = text.capitalize()
print(capitalized)  # Hello
```

### title()：各単語の最初を大文字に

```python
text = "hello world"
titled = text.title()
print(titled)  # Hello World
```

### strip()：前後の空白を削除

```python
text = "  hello  "
stripped = text.strip()
print(stripped)  # hello
```

### lstrip()：左側の空白を削除

```python
text = "  hello"
left_stripped = text.lstrip()
print(left_stripped)  # hello
```

### rstrip()：右側の空白を削除

```python
text = "hello  "
right_stripped = text.rstrip()
print(right_stripped)  # hello
```

## 文字列の情報取得

### len()：文字列の長さ

```python
text = "こんにちは"
length = len(text)
print(length)  # 5
```

### count()：文字列の出現回数

```python
text = "hello world"
count = text.count("l")
print(count)  # 3
```

### isdigit()：数字かチェック

```python
text1 = "123"
text2 = "abc"

print(text1.isdigit())  # True
print(text2.isdigit())  # False
```

### isalpha()：アルファベットかチェック

```python
text1 = "hello"
text2 = "123"

print(text1.isalpha())  # True
print(text2.isalpha())  # False
```

### isalnum()：英数字かチェック

```python
text1 = "hello123"
text2 = "hello world"

print(text1.isalnum())  # True
print(text2.isalnum())  # False（スペースがある）
```

## 文字列のスライス

### 基本的なスライス

```python
text = "こんにちは、世界"

# インデックス2から5まで
print(text[2:5])  # にちは

# 最初から5まで
print(text[:5])  # こんにちは

# 5から最後まで
print(text[5:])  # 、世界

# 最後の2文字
print(text[-2:])  # 世界
```

### ステップを指定

```python
text = "こんにちは、世界"

# 1文字おきに取得
print(text[::2])  # こには世
```

## 実用的な例

### 例1：メールアドレスの検証

```python
def is_valid_email(email):
    if "@" in email and "." in email:
        parts = email.split("@")
        if len(parts) == 2:
            return True
    return False

email = "user@example.com"
if is_valid_email(email):
    print("有効なメールアドレスです")
else:
    print("無効なメールアドレスです")
```

### 例2：CSVデータの処理

```python
csv_data = "名前,年齢,都市\n太郎,25,東京\n花子,30,大阪"

lines = csv_data.splitlines()
for line in lines[1:]:  # ヘッダーをスキップ
    parts = line.split(",")
    name, age, city = parts
    print(f"{name}さんは{age}歳で{city}に住んでいます")
```

### 例3：文字列の整形

```python
def format_name(first, last):
    # 最初の文字を大文字に、残りを小文字に
    first = first.capitalize()
    last = last.capitalize()
    return f"{last} {first}"

name = format_name("taro", "yamada")
print(name)  # Yamada Taro
```

### 例4：パスワードの強度チェック

```python
def check_password_strength(password):
    if len(password) < 8:
        return "短すぎます（8文字以上）"
    
    if not any(c.isdigit() for c in password):
        return "数字が含まれていません"
    
    if not any(c.isalpha() for c in password):
        return "アルファベットが含まれていません"
    
    return "強力なパスワードです"

password = "Password123"
result = check_password_strength(password)
print(result)
```

## よくあるエラー

### エラー1：文字列と数字を連結

**エラーメッセージ：**
```
TypeError: can only concatenate str (not "int") to str
```

**原因：**
- 文字列と数字を直接連結しようとしている

**解決方法：**
```python
age = 25
# text = "年齢は" + age + "歳です"  # エラー

text = "年齢は" + str(age) + "歳です"  # 正しい
# または
text = f"年齢は{age}歳です"  # f-string（次の章で説明）
```

### エラー2：文字列を変更しようとする

**注意：**
- 文字列は変更できません（イミュータブル）

**解決方法：**
```python
text = "hello"
# text[0] = "H"  # エラー

new_text = "H" + text[1:]  # 新しい文字列を作成
print(new_text)  # Hello
```

## 練習問題

文字列 `"こんにちは、世界"` を `"こんにちは、Python"` に置換してください。

**ヒント：**
```python
text = "こんにちは、世界"
new_text = text.replace("世界", "Python")
print(new_text)
```

文字列 `"りんご,バナナ,オレンジ"` をカンマで分割して、各要素を表示してください。

```python
text = "りんご,バナナ,オレンジ"
fruits = text.split(",")
for fruit in fruits:
    print(fruit)
```

```python
text = "  hello world  "
cleaned = text.strip().title()

```
