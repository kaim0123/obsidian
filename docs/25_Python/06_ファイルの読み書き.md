# ファイルの読み書き

## はじめに

前の章では、文字列のフォーマットを学びました。

この章では、**ファイルの読み書き**を学びます。データをファイルに保存したり、ファイルから読み込んだりできるようになります。

## ファイル操作の基本

### ファイルを開く

ファイルを操作するには、まず**ファイルを開く**必要があります。

```python
file = open("ファイル名", "モード")
```

### ファイルモード

| モード | 説明 |
|--------|------|
| `"r"` | 読み込み（デフォルト） |
| `"w"` | 書き込み（既存のファイルは上書き） |
| `"a"` | 追記（既存のファイルの末尾に追加） |
| `"x"` | 新規作成（既存のファイルがあるとエラー） |

### ファイルを閉じる

ファイルを使い終わったら、**必ず閉じる**必要があります。

```python
file = open("test.txt", "r")
# ファイルを使う
file.close()
```

## ファイルの読み込み

### read()：ファイル全体を読み込む

```python
file = open("test.txt", "r", encoding="utf-8")
content = file.read()
print(content)
file.close()
```

### readline()：1行ずつ読み込む

```python
file = open("test.txt", "r", encoding="utf-8")
line1 = file.readline()
line2 = file.readline()
print(line1)
print(line2)
file.close()
```

### readlines()：全ての行をリストで読み込む

```python
file = open("test.txt", "r", encoding="utf-8")
lines = file.readlines()
for line in lines:
    print(line.strip())  # strip()で改行を削除
file.close()
```

### for文で1行ずつ読み込む（推奨）

```python
file = open("test.txt", "r", encoding="utf-8")
for line in file:
    print(line.strip())
file.close()
```

## ファイルの書き込み

### write()：文字列を書き込む

```python
file = open("output.txt", "w", encoding="utf-8")
file.write("こんにちは、世界！\n")
file.write("これは2行目です\n")
file.close()
```

### writelines()：リストを書き込む

```python
lines = ["1行目\n", "2行目\n", "3行目\n"]
file = open("output.txt", "w", encoding="utf-8")
file.writelines(lines)
file.close()
```

## with文（推奨）

### with文とは

**with文**を使うと、ファイルを自動的に閉じてくれます。

```python
with open("test.txt", "r", encoding="utf-8") as file:
    content = file.read()
    print(content)
# ファイルは自動的に閉じられる
```

**メリット：**
- ファイルを閉じるのを忘れない
- エラーが発生しても確実に閉じられる

### with文の例

#### 読み込み

```python
with open("test.txt", "r", encoding="utf-8") as file:
    for line in file:
        print(line.strip())
```

#### 書き込み

```python
with open("output.txt", "w", encoding="utf-8") as file:
    file.write("こんにちは、世界！\n")
    file.write("これは2行目です\n")
```

## 実用的な例

### 例1：メモ帳アプリ

```python
def save_note(filename, content):
    """メモをファイルに保存"""
    with open(filename, "w", encoding="utf-8") as file:
        file.write(content)
    print("メモを保存しました")

def load_note(filename):
    """メモをファイルから読み込む"""
    try:
        with open(filename, "r", encoding="utf-8") as file:
            content = file.read()
        return content
    except FileNotFoundError:
        return "ファイルが見つかりません"

# 使用例
save_note("memo.txt", "これはテストメモです")
content = load_note("memo.txt")
print(content)
```

### 例2：ログファイルの記録

```python
def log_message(message):
    """ログメッセージをファイルに記録"""
    from datetime import datetime
    timestamp = datetime.now().strftime("%Y-%m-%d %H:%M:%S")
    
    with open("log.txt", "a", encoding="utf-8") as file:
        file.write(f"[{timestamp}] {message}\n")

# 使用例
log_message("アプリケーションが起動しました")
log_message("ユーザーがログインしました")
log_message("エラーが発生しました")
```

### 例3：設定ファイルの読み書き

```python
def save_settings(settings):
    """設定をファイルに保存"""
    with open("settings.txt", "w", encoding="utf-8") as file:
        for key, value in settings.items():
            file.write(f"{key}={value}\n")

def load_settings():
    """設定をファイルから読み込む"""
    settings = {}
    try:
        with open("settings.txt", "r", encoding="utf-8") as file:
            for line in file:
                line = line.strip()
                if "=" in line:
                    key, value = line.split("=", 1)
                    settings[key] = value
    except FileNotFoundError:
        pass
    return settings

# 使用例
settings = {"theme": "dark", "language": "ja", "font_size": "14"}
save_settings(settings)

loaded_settings = load_settings()
print(loaded_settings)
```

## ファイルパス

### 相対パスと絶対パス

#### 相対パス

現在のディレクトリからの相対的なパス

```python
# 同じディレクトリ
with open("test.txt", "r", encoding="utf-8") as file:
    pass

# サブディレクトリ
with open("data/test.txt", "r", encoding="utf-8") as file:
    pass

# 親ディレクトリ
with open("../test.txt", "r", encoding="utf-8") as file:
    pass
```

#### 絶対パス

完全なパス

```python
# Windows
with open("C:\\Users\\Username\\Documents\\test.txt", "r", encoding="utf-8") as file:
    pass

# Mac/Linux
with open("/Users/username/Documents/test.txt", "r", encoding="utf-8") as file:
    pass
```

### os.pathモジュールを使う

```python
import os

# パスを結合
file_path = os.path.join("data", "test.txt")
print(file_path)  # data\test.txt (Windows) または data/test.txt (Mac/Linux)

# ファイルが存在するかチェック
if os.path.exists(file_path):
    print("ファイルが存在します")
```

## よくあるエラー

### エラー1：ファイルが見つからない

**エラーメッセージ：**
```
FileNotFoundError: [Errno 2] No such file or directory: 'test.txt'
```

**原因：**
- ファイルが存在しない
- パスが間違っている

**解決方法：**
```python
import os

file_path = "test.txt"
if os.path.exists(file_path):
    with open(file_path, "r", encoding="utf-8") as file:
        content = file.read()
else:
    print("ファイルが見つかりません")
```

### エラー2：文字化け

**原因：**
- エンコーディングが間違っている

**解決方法：**
```python
# エンコーディングを指定
with open("test.txt", "r", encoding="utf-8") as file:
    content = file.read()
```

### エラー3：ファイルを閉じ忘れる

**問題：**
```python
file = open("test.txt", "r")
content = file.read()
# close()を忘れると、ファイルが開いたままになる
```

**解決方法：**
```python
# with文を使う（推奨）
with open("test.txt", "r", encoding="utf-8") as file:
    content = file.read()
```

## 練習問題

### 問題1：ファイルに書き込む

「こんにちは、世界！」という文字列を `hello.txt` に書き込んでください。

**ヒント：**
```python
with open("hello.txt", "w", encoding="utf-8") as file:
    file.write("こんにちは、世界！\n")
```

### 問題2：ファイルから読み込む

`hello.txt` から内容を読み込んで、表示してください。

**ヒント：**
```python
with open("hello.txt", "r", encoding="utf-8") as file:
    content = file.read()
    print(content)
```

### 問題3：複数行を書き込む

3行のメッセージをファイルに書き込んでください。

**ヒント：**
```python
lines = ["1行目\n", "2行目\n", "3行目\n"]
with open("output.txt", "w", encoding="utf-8") as file:
    file.writelines(lines)
```

## まとめ

### 学んだこと

1. ✅ **ファイルを開く**：`open()`
2. ✅ **ファイルモード**：`"r"`（読み込み）、`"w"`（書き込み）、`"a"`（追記）
3. ✅ **ファイルの読み込み**：`read()`、`readline()`、`readlines()`、for文
4. ✅ **ファイルの書き込み**：`write()`、`writelines()`
5. ✅ **with文**：ファイルを自動的に閉じる（推奨）
6. ✅ **ファイルパス**：相対パス、絶対パス

### 重要なポイント

- ✅ **必ずファイルを閉じる**：with文を使うと自動的に閉じられる
- ✅ **エンコーディングを指定**：`encoding="utf-8"` を指定する
- ✅ **エラーハンドリング**：ファイルが存在しない場合を考慮する
