## 標準ライブラリとは

### 標準ライブラリとは

**標準ライブラリ**とは、Pythonに標準で含まれている、**すぐに使えるモジュールの集合**です。

### 標準ライブラリのメリット

- ✅ **追加インストール不要**：Pythonをインストールすれば使える
- ✅ **豊富な機能**：様々な用途に対応
- ✅ **信頼性が高い**：Python公式が提供

## よく使う標準ライブラリ

### collections：高度なデータ構造

#### Counter：要素の個数を数える

```python
from collections import Counter

fruits = ["りんご", "バナナ", "りんご", "オレンジ", "バナナ", "りんご"]
counter = Counter(fruits)
print(counter)  # Counter({'りんご': 3, 'バナナ': 2, 'オレンジ': 1})

# 最も多い要素
print(counter.most_common(1))  # [('りんご', 3)]
```

#### defaultdict：デフォルト値を持つ辞書

```python
from collections import defaultdict

# デフォルト値が0の辞書
scores = defaultdict(int)
scores["太郎"] += 10
scores["花子"] += 20
print(scores)  # defaultdict(<class 'int'>, {'太郎': 10, '花子': 20})
```

### itertools：イテレータツール

#### combinations：組み合わせ

```python
from itertools import combinations

items = ["A", "B", "C"]
combs = list(combinations(items, 2))
print(combs)  # [('A', 'B'), ('A', 'C'), ('B', 'C')]
```

#### permutations：順列

```python
from itertools import permutations

items = ["A", "B", "C"]
perms = list(permutations(items, 2))
print(perms)  # [('A', 'B'), ('A', 'C'), ('B', 'A'), ('B', 'C'), ('C', 'A'), ('C', 'B')]
```

### re：正規表現

#### 文字列の検索

```python
import re

text = "私の電話番号は090-1234-5678です"
pattern = r"\d{3}-\d{4}-\d{4}"
match = re.search(pattern, text)
if match:
    print(match.group())  # 090-1234-5678
```

#### 文字列の置換

```python
import re

text = "私の電話番号は090-1234-5678です"
pattern = r"\d{3}-\d{4}-\d{4}"
replaced = re.sub(pattern, "***-****-****", text)
print(replaced)  # 私の電話番号は***-****-****です
```

### pathlib：パス操作

#### パスの操作

```python
from pathlib import Path

# パスを作成
file_path = Path("data") / "test.txt"
print(file_path)  # data\test.txt

# ファイルが存在するかチェック
if file_path.exists():
    print("ファイルが存在します")

# ファイル名を取得
print(file_path.name)  # test.txt

# 拡張子を取得
print(file_path.suffix)  # .txt
```

### urllib：URL操作

#### ウェブページを取得

```python
from urllib.request import urlopen

try:
    with urlopen("https://www.example.com") as response:
        content = response.read().decode("utf-8")
        print(content[:100])  # 最初の100文字を表示
except Exception as e:
    print(f"エラー: {e}")
```

## 実用的な例

### 例1：ログの記録（logging）

```python
import logging

# ログの設定
logging.basicConfig(
    level=logging.INFO,
    format='%(asctime)s - %(levelname)s - %(message)s',
    filename='app.log'
)

# ログを記録
logging.info("アプリケーションが起動しました")
logging.warning("警告メッセージ")
logging.error("エラーメッセージ")
```

### 例2：設定ファイルの読み込み（configparser）

```python
import configparser

# 設定ファイルを作成
config = configparser.ConfigParser()
config['DEFAULT'] = {
    'language': 'ja',
    'theme': 'dark'
}
config['USER'] = {
    'name': '太郎',
    'age': '25'
}

with open('config.ini', 'w', encoding='utf-8') as f:
    config.write(f)

# 設定ファイルを読み込む
config = configparser.ConfigParser()
config.read('config.ini', encoding='utf-8')

print(config['USER']['name'])  # 太郎
print(config['DEFAULT']['language'])  # ja
```

### 例3：データの圧縮（zipfile）

```python
import zipfile

# ZIPファイルを作成
with zipfile.ZipFile('archive.zip', 'w') as zipf:
    zipf.write('file1.txt')
    zipf.write('file2.txt')

# ZIPファイルを展開
with zipfile.ZipFile('archive.zip', 'r') as zipf:
    zipf.extractall('extracted')
```

### 例4：時間の計測（time）

```python
import time

# 処理時間を計測
start = time.time()

# 何らかの処理
time.sleep(1)  # 1秒待つ

end = time.time()
elapsed = end - start
print(f"処理時間: {elapsed:.2f}秒")
```

## よくあるエラー

### エラー1：モジュールが見つからない

**エラーメッセージ：**
```
ModuleNotFoundError: No module named 'xxx'
```

**原因：**
- モジュール名が間違っている
- 標準ライブラリではない（外部ライブラリが必要）

**解決方法：**
- モジュール名を確認
- 標準ライブラリの一覧を確認

### エラー2：インポートエラー

**エラーメッセージ：**
```
ImportError: cannot import name 'xxx' from 'yyy'
```

**原因：**
- 関数名やクラス名が間違っている

**解決方法：**
- 公式ドキュメントで正しい名前を確認

## 練習問題

### 問題1：Counterを使う

リスト `[1, 2, 2, 3, 3, 3, 4, 4, 4, 4]` の各要素の個数を数えてください。

**ヒント：**
```python
from collections import Counter

numbers = [1, 2, 2, 3, 3, 3, 4, 4, 4, 4]
counter = Counter(numbers)
print(counter)
```

### 問題2：正規表現で電話番号を検索

文字列から電話番号（090-1234-5678形式）を検索してください。

**ヒント：**
```python
import re

text = "私の電話番号は090-1234-5678です"
pattern = r"\d{3}-\d{4}-\d{4}"
match = re.search(pattern, text)

    print(match.group())
```

### 問題3：処理時間を計測

リストのソート処理の時間を計測してください。

**ヒント：**
```python
import time
import random

numbers = [random.randint(1, 1000) for _ in range(10000)]

start = time.time()
numbers.sort()
end = time.time()

print(f"処理時間: {end - start:.4f}秒")
```
