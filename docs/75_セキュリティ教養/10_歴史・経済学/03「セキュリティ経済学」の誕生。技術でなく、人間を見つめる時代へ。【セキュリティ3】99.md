## 詳しい要約

### シリーズの位置づけ

「**情報セキュリティ**」シリーズ**第3回・最終回**（全3回）。前2回の「守る側の不利」「Microsoftの改善」「PEBKAC（人間問題）」を受け、**セキュリティ経済学**という新学問を中心に、希望と限界を語る締めくくり。参照書『情報セキュリティの敗北史』の流れに沿う。

### 冒頭：豚のダンス vs セキュリティ

プリンストン大学の**エドワード・フェルテン**教授の格言：「豚のダンスとセキュリティのどちらかを選ばせられたら、ユーザーは常に**豚のダンス**を選ぶだろう」。

- セキュリティは**必要感が薄く優先順位が低い**。
- ほとんど利得のないエンタメの方を選んでしまう——失敗例えとして有名だが、情報セキュリティ分野では流通している。

### 前2回のおさらい

1. セキュリティは構造的に**めちゃくちゃ難しい**（攻撃者の非対称的優位、OSの巨大化）。
2. Microsoftが**意識改革＋技術改善**でOSの穴をかなり塞いだ。
3. しかし最大の問題は**PEBKAC**（椅子とキーボードの間＝人間）。
4. コンピューターサイエンスだけでは解決できない → **セキュリティ経済学**（2000年頃〜）の登場。

### セキュリティ経済学の誕生：オークランド会議と車中の雑談

- **2000年頃**、**オークランド会議**（セキュリティ研究者の集まり）の出席者2人が、レストランで「**なぜ人はウイルス対策ソフトを購入しないのか**」と雑談。
- アイデアが良すぎて**会議に出ず**、駐車場で車を止めたまま話し続けた——ファインマンがホテルのバーで画期的なアイデアを思いついた話の類。
- この雑談が後の論文につながり、**セキュリティ経済学**が動き始める。2002年に第1回ワークショップ。

### コモンズの悲劇：ユーザーはバカではない

従来のセキュリティ研究者：「対策しろ、バカなユーザーだ」。

セキュリティ経済学の視点：**十分合理的なプレイヤーが、十分合理的な決断の結果、セキュアでない選択をしている**。

- **コモンズの悲劇**の「共有地」＝**インターネット**。
- 2000年代のウイルス感染時、自分のPCのデータが消えるのではなく、**スパムメールの発信基地**や**DDoS攻撃の踏み台**になる——被害は**自分ではなく他者・全体**に及ぶ。
- **チフのメアリー**的：自覚症状なく周囲に感染を広げる。自分の不利益は微々たるものだが、共有地（インターネット）へのダメージは大きい。
- 羊飼いの比喩：1頭増やすメリットは自分に、草の枯渇コストは全体に分散 → 合理的にウイルス対策を怠る。
- 結論：**「ジョニーは暗号化できない」のではなく「ジョニーは合理的だから暗号化しない」**。

### ハーバート・サイモンと「関心」の消費

ノーベル経済学賞受賞者**ハーバート・サイモン**：**関心（attention）は資産であり、消費するもの**。

- 1番安いスーパーで買わないのは、調べるコストの方が大きいから——**合理的**。
- 楽天スーパーセールを追いかける人も、関心を投資して得している側。
- セキュリティを諦めるのも同様に合理的かもしれない → **インセンティブを踏まえていない従来の研究者の方が、人間理解が足りなかった**可能性。

### 外部不経済とプロバイダーによる取り締まり

経済学の用語：**外部不経済**（市場の失敗の一種）。

- 川を汚しても企業が責任を取らない → **4大公害** → **公害対策基本法**（政府が市場の外から介入）。
- ウイルス対策ソフト問題への応用：**プロバイダー**（NTT、ソネット等）が通信を取りまとめている → 感染・スパム送信・DDoS加担が分かれば、**一時停止・罰金・隔離**などのインセンティブを設計できるのでは、という提案。
- **インセンティブ設計**が経済学からのアイデア。ただし**理論段階が多く、実際にはあまり実行されていない**——法整備が必要かもしれない。

### 信頼性保証会社の逆説（2002年ワークショップ）

「このサイトは安全です」と**信頼性を保証する営利企業**（投資信託の格付け会社のようなもの）が当時存在。

- インターネットの大規模サイトのうち悪意のあるサイトは約**2%**。
- 「信頼性保証済み」サイト群の中の悪意サイトの割合は？ → 正解 **5%**（ランダムより**危ない**）。
- **猫の落下統計**と同型の**選択バイアス**：怪しいサイトほど信頼性保証を**頼みに来る**（2階から落ちた猫は病院に連れてこないが、8階から落ちた無傷の猫は連れてくる → 高層ほど怪我が少ないという誤った統計）。
- セキュリティ経済学の役割：**一見常識的な施策が本当に効くか、統計で検証する** → 意味ある施策と意味ない施策が浮き彫りになる。

### リスク恒常性（Risk Homeostasis）

行動経済学の話（パラシュートの話）。

- スカイダイビングで**自動開伞装置**（一定高度で予備パラシュートが開く）を導入。
- **パラシュートが開かずに死んだ人数**は減ったが、**それ以外の死因**が増え、**死者数トータルはほぼ横ばい**。
- 安全だと思うと**リスクの高い行動**を取るようになる（ジェットコースターで手を離す等）。
- 保険に入ると事故が増える、という話も同系。
- 情報セキュリティへの示唆：安全なソフト・VPNを導入しても、**油断してスパムメールを開く**可能性。**Surfsharkも銀の弾丸ではない**——契約しても警戒心を忘れないこと。

### その他の行動経済学エピソード（触れのみ）

- **イスラエルの保育園**：遅刻罰金 → 遅刻が増えた（金を払えば遅れていい）。
- **コブラの報奨金**：自ら繁殖させて報奨金目的のブリーダーが発生。
- **6種類のジャム**：選択肢が多いと**決定麻痺**——満足度は少ない方が高い。

### シリーズ総括：敗北史の中の希望

| テーマ | 内容 |
|--------|------|
| 歴史 | 基本的に**絶望の歴史**——守るのが難しすぎる |
| 希望 | **人類が蓄積した別学問**（経済学・心理学）の知見を借りる |
| 現状 | セキュリティ経済学は**20年経ってもまだ発展途上**、実行段階に移せていない部分が多い |
| 古い思考 | 「技術で全部解決できる」という考えの人がまだ多い（著者の指摘） |
| ムーアの法則 | **人の考えは20年ではアップデートされない**——技術は指数関数的に進むが、セキュリティのこの手の問題はそう解決しない |
| アルゴリズムの限界 | スパムフィルター等は有効だが、**ソーシャルエンジニアリング**（チョコでパスワード聞く等）はアルゴリズムでは止められない |
| 方向性 | **ルールデザイン**——人により良い行動を取らせるインセンティブ設計 |

### 第3回・シリーズの締め

1. 技術的問題だと思っていたものが、実は**人間の行動を制約する経済学の問題**だった。
2. ユーザーはバカではなく**合理的**——だからインセンティブ設計が必要。
3. 意味のある施策・意味のない施策を**統計で見極める**のがセキュリティ経済学。
4. 安全対策を入れても**リスク恒常性**で油断しないこと。
5. 完全な勝利ではないが、**別分野の英知**に頼る余地がある——それが3回にわたる「パンドラの箱」の希望。
