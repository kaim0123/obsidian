## 詳しい要約

### エピソードの位置づけ

前回に続く**ランサムウェア第2回**。前回は「ガーファ株と同じく**スケーラビリティのあるビジネスモデル**が流行を生んだ」という話。今回はその裏側——**複数の利害関係者が絡む関連産業**と、**全員の利益が一致する闇の構造**——を解剖する。参照の中心は**『ランサムウェア追跡チーム』**（はみ出し者が挑むサイバー犯罪との知られざる戦い）。

### ランサムウェア業界の「洗練」

ビジネスモデルが成熟すると起きる典型現象として、**客単価の引き上げ**と**関連産業の発生**が挙げられる。

- **客単価**：かつては個人相手に平均**300ドル**（数万円）程度。2024年には平均**273万ドル**（約5億円）規模へ。**角川**も約**4.7億円**支払いと報じられた。
- **ターゲットのシフト**：個人から**企業（BtoB）**へ。YouTubeコンサルが個人5000円/時から企業10万円/時へ移行するのと同型の構造。
- **関連産業**：保険・事前防御・**復旧支援**などが立ち上がる。YouTube界隈の音声編集・サムネデザイナー・SNSスクール（ヒーローズ等）に相当するエコシステム。

### 関連産業の三層

1. **サイバー保険**：攻撃で事業停止した際の**損害補填**が中心。最近は**身代金そのものは保証外**となるケースが増えている。
2. **事前防御・監視**：ランサムウェア侵入を防ぐ・検知するセキュリティ業者（警備会社的な存在）。
3. **復旧支援業者**：「我々の技術で復旧します。まずご連絡を」と客を集める。**身代金より高額**（2〜3倍）を請求することもざらだが、企業はそれでも払う。

### なぜ身代金を直接払わず、復旧業者に払うのか

- **レピュテーションリスク**：身代金支払いは「犯罪者への資金提供」「反社会的勢力への供与」と同視され、世論・警察（FBI等）から**払うな**と強く止められる。
- **二次被害**：身代金を払った病院などが患者情報流出で**患者から訴えられる**——本当の加害者（ロシアのマフィア等）は特定・訴追できないのに、**手前の被害者が叩かれる**地獄構造。
- **保険会社の利害**：業務停止が続くと**1日あたり数億円**の損失。相対的に身代金の方が安いので払いたいが、世論が許さない。
- **復旧業者という「出口」**：「身代金は払っていない。復旧業者に依頼しただけ」という**言い訳が立つ**。世論のプレッシャーのせいで、身代金の数倍でも復旧業者に流れる。

### パチンコ三店方式との類似

パチンコの**三店方式**——玉を直接現金化できず、景品→近くの「たまたま」買い取り業者で現金化——と構造が酷似する。

- 企業は**直接身代金を払えない**（社会的・法的圧力）。
- 復旧業者が仲介することで、表の金が**こっそり裏（犯罪者）へ流れる**——**逆マネーロンダリング**（表→裏への資金移送）。
- 「たまたまそういう店があるだけ」という言い訳も、病院の前に薬局があるのと同じで、**狙って作られた構造**。

### 全員の利害が一致する「美しい」ビジネスモデル

紹介されたステークホルダー**全員の利益が一致**している点が核心。

| 主体 | 利害 |
|------|------|
| **被害企業** | 一刻も早く立ち直りたい |
| **保険会社** | 長期の業務停止より身代金の方が安い → 払いたい |
| **世論・警察** | 身代金を直接払うな |
| **復旧支援業者** | 高値を吹っかけても払ってもらえる |

**中抜きモデル**：復旧業者が「5億で復旧します」と請求し、うち5億を身代金として犯罪者に払い、**10億を懐に入れる**。全員ハッピーに見える。

**さらに悪質なモデル（推測）**：復旧業者自らランサムウェアを開発・仕掛け、復号鍵を握った上で「身代金の3倍で復旧します」と営業。**価格決定権**を握れるため、身代金相場を釣り上げれば復旧料も比例して跳ね上がる（3倍レバレッジ）。保険会社に仕掛ければ**保険の実績**にもできる——**ワンストップ**の極致。

### 復旧支援業者の倫理的問題

- **偽善**：「身代金は払いません」と看板を掲げながら**裏で払っている**ケースが多い。「自社技術で復旧」と嘘をつく。**犯罪者の方が潔い**という辛辣な指摘。
- **システム上の必然**：それが儲かる構造なら、必ず**やる人が出る**。必ずしも全員が悪意満々とは限らない——「社会貢献している」と信じて働く人もいる。
- **犯人より悪い？**：ランサムウェアを仕掛けた犯人より、**表向き善人の復旧業者**の方が問題視される側面がある、というタイトルの含意。

### 正当な復旧支援業者の役割

悪徳ばかりではなく、**実際に機能する業者**も存在する。

1. **技術的復旧**：本当に解除できるものはその場で解除。
2. **交渉代行（ネゴシエーター）**：誘拐事件の交渉人と同様、**犯人との交渉は特殊技能**。素人が「なんだこの犯罪者名」調のメールを書くと交渉決裂。プロは「いつもお世話になっております、今回も○○が担当します」と**常連クライアント**のように入る。
3. **交渉の効果**：大企業を**ビジネス相手**として扱うと犯人側も喜び、**値引き交渉**がスムーズに進む（5億→3億等）。**下から行く**方が結果的に社会のためになる、という逆説。
4. **エスカレーション**：支払ったのに復旧されない場合、ランサムウェア組織内の**親分**にチクると対応が動く。
5. **指名依頼**：交渉がスムーズすぎて、犯人側から**特定の交渉人を指名**するケースも。

ただし**結局は金を払っている**点は変わらず、「犯人をのさばらせる一員では」というモヤモヤは残る。

### 業界の成熟と悪徳の駆逐

スタートアップ界隈と同様、**盛り上がり期に無双が乱立→成熟とともに淘汰**が進んでいる。

- **自作自演の罠**：詳しい人がランサム業者のふりをして「被害に遭いました」と相談。業者が「直します」と言いながら**裏で身代金を払っていた**ことが判明する事例が多数。
- **嘘つき業者の駆逐**：こうした業者は倫理問題で**淘汰**されつつある。
- **理想**：交渉代行は**本当にどうしようもない時**の最終手段。それ以前に**復旧可能なシステムの開発**を進めるべき。

### 誘拐との比較とランサムウェアの優位性

歴史上**誘拐**も似た構造（身代金→批判）。しかし誘拐は**失敗して殺害・逮捕されるリスク**があった。ランサムウェアは**リスクが極めて低く**、だからここまで巨大化した。

### 解決策の議論（とその限界）

- **ダークウェブ破壊**：1つ潰しても**別のが生まれる**。Whistleblower的な「ダークウェブ破壊ヒーロー」は非現実的。
- **インターネット停止・発電停止・江戸時代回帰**：技術が一度生まれれば**個人間で再び繋がる**ため、根本解決にならない——茶番として扱われるが、問題の難しさを示す。

### まとめ

ランサムウェアは犯罪でありながら、**巨大な市場**ゆえに極端に洗練されたビジネスモデルが成立する。パチンコ三店方式のように**表と裏をつなぐ中間業者**が存在し、**被害者・保険・世論・復旧業者の利害が奇妙に一致**する。資本主義の歪み——シリコンバレーも三店方式も同型——が、**裏の社会でも表と同じことが起きている**という気づきで締める。
