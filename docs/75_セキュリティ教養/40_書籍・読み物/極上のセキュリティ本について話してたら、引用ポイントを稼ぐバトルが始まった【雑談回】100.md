## 詳しい要約

### エピソードの位置づけ

「**情報セキュリティ**」シリーズ（#97〜#99）終了後の**雑談回・第100回**。本編の余談ではなく、シリーズの中心参照書**『情報セキュリティの敗北史』**（副題：脆弱性はどこから来たのか）への称賛と、番組ならではの**「引用ポイント稼ぎ」**ネタが大半を占める回。著者**種本**（本書中の「セキュリティ柱」）のレトリックの巧みさが、台本構成すら圧倒した。

### なぜこの本を「鬼おもろ本」と呼ぶのか

ゆるコンピュータ科学ラジオでは通常、台本用に**高速スキャン読み**することも多いが、本作は**一文字ずつ味わう**価値があると判断し、久しぶりにじっくり通読した。

**本のスペック**：

| 項目 | 内容 |
|------|------|
| 正味本文 | 約300ページ |
| 参考文献・注釈 | **約100ページ**（奥付まで）。第3章だけで注釈200数十個 |
| 参考文献番号 | 30〜32番までナンバリング |
| 発売 | **2日で重版**、各種アワード受賞 |
| 著者 | 世界的投資銀行幹部（ロンドン・ロイヤル）、収支（CFA）取得 |
| 共著者 | システムエンジニア経歴後、米国大学でMBA |

### デザイン・編集の巧みさ

編集者目線での評価も高い。

- **帯**：ビスマルクの「**愚者は経験に学び、賢者は歴史に学ぶ**」——ITリテラシー本ありがちな「21世紀のビジネスマン必読」系ではなく、骨のある引き
- **表紙**：科学模様、余白をしっかり取ったデザイン。明朝体は**要所に2種類だけ**使うなど、地味だが緻密
- **タイトル**：原題 `History of Information Security in the Computer Age` から**『情報セキュリティの敗北史』**へ——副題「コンピューター時代の情報セキュリティ史」より圧倒的に引きが強い改題

### レトリックの名文・名エピソード

#### ハッカーの二重生活

> セキュリティ企業に勤務していたハッカーたちにとっては、夜は脆弱性に関する情報を研究して公開し、日中は自分たちが作った攻撃方法に対するシグネチャなどの防御策を書くという不利な状況が生まれた。**密偵が同時に森番を務め、放火犯が同時に消防士を務めていた**わけである。

#### Penetrate & Patch → Patch and Pray

侵入テストして脆弱性を見つけパッチを当てる**Penetrate & Patch**が、いつしか**Patch and Pray**（パッチを当てて祈る）に変わった——P&P党員を踏むインジャ。

#### その他の秀逸な記述

- **Oracle**創業者が「システムはアンブレイカブル（破られない）」と豪語→大惨事。**3億ドルでハワイの島を買っていた**とさらっと書く
- **ビル・ゲイツ**は大学時代にハッキングして捕まった経験があり、セキュリティの大切さを身に沁みて理解していた
- 同ゲイツが2004年に「**パスワードは死んだ**」と宣言→著者が「これ以上の間違いはなかった」と容赦なくいじる
- 当時のインターネットで野晒しにされた**「Internet Exploder（インターネット爆破するもの）」**等のフレーズを余すところなく収集

### ハッカー文化の不思議さ

- **動機**：違法行為だが、多くは**自分の力を示したい**（ヤンキー文化に近い）。NASAサーバーをハックした、等の自慢
- **表と裏**：「ハッキングやったぜ」とは言えないが、「**この脆弱性を発見しました**」は猛アピール——犯罪自慢の代わりに**こっそりオファー**が来る文化もあった
- **『誰が音楽をただにしたい』**との比較：インターネットが閉じた空間だった頃、発売前CDの流出は「クール」と見られた。今の感覚では理解しにくいが、**30人だけの秘密基地**の中ではヒーローになれる感覚があった

### 詐欺の「知的」な手法（本からの引用）

#### ナイジェリア送金詐欺——なぜ毎回「ナイジェリア」なのか

ABテストの結果ではない。**マーケティング**の発想。

- 「ナイジェリアの王子」等、**定型的な国名・文面**にしておく
- ググればすぐ「詐欺の定型文」と分かる→**賢い人は早めに離脱**
- やり取りコストがかかる前に振り落とし、**本当に引っかかる人だけ**が返信する
- 中途半端に賢い人を引っかけない方が、詐欺師にとって効率的

#### 野球予言詐欺

1600人に半分ずつ「明日巨人が勝つ」「明日中日が勝つ」と送り、当たった方だけに次の予言を送る——**2の累乗**で絞り込み、最後に100人程度が「この人は予言者だ」と錯覚する手口。

### 引用ポイント・バトル（番組ネタ）

本の素晴らしさを語るうち、**日常会話に文学・哲学を引用して「ポイント」を稼ぐ**という番組内ゲームに発展。

| 引用 | 状況・ポイント |
|------|--------------|
| **ゴーゴリ→ドストエフスキー**「一体どうして椅子を壊すんですか。皆さん、国家の損失になるじゃありませんか」 | 友達が肘掛けを壊した時に使えば**2ポイント**（ゴーゴリ1＋ドストエフスキー1）。水野さんは3年間椅子を壊してくれるのを待っていたが未遂 |
| **ダ・ヴィンチ**「食欲がないのに食べると健康を害するように、欲求がないのに学習すると記憶を損う」 | 言語学回の福田先生の後に使えば良かった——**放送後に気づき、逃した引用** |
| **ブルータリズム（建築家タウト）**「日光東照宮を見て——**最も建築の堕落だ**」 | 観光の定番引用。**1ポイント** |
| **サルトル**「**名前とは記述の束である**」 | 名刺交換時に「水野と申します」→「名前とは記述の束である」で**1ポイント** |
| **エカダンピ** | 仏教系。師に弟子入りを断られ、**片腕を切り落として**決意を示す——響きは可愛いが意味は過激 |
| **バーナード・ショー**「ある職業を極めた人なら誰でもその職業に対して**懐疑的**になる」 | 種本が情報セキュリティに懐疑的になった例として本から引用。種本の種本への孫引き |

**引用の心得**（堀本流）：カフカ『変身』の「目が覚めると巨大な毒虫に」は**クリシェで最悪**。「全く早起きというやつは、いつも人間を薄馬にしてしまう」等、**誰も引用していない箇所**を狙う。

### VALUE BOOKS コラボ：ゆるコンピュータ科学ラジオ書店

本作があまりに良かったため、**VALUE BOOKS**とコラボ。

- **200冊を仕入れ**（倉庫を圧迫中）

- 動画公開頃には**オリジナルデザインの特設サイト**も完成予定
- 書店利益は番組側に（「VALUE BOOKSの脆弱性かもしれない」と自虐）
- 他にも『誰が音楽をただにしたい』『アルゴリズムとデータ構造』等を並べる予定

紙の本として**約3000円**だが、インテリアとしても成立する品質——**開きっぱなしにしたくなる本**。

### まとめ

『情報セキュリティの敗北史』は、**レトリック・参考文献の量・面白センサー・デザイン**すべてが秀逸な「極上のセキュリティ本」。セキュリティシリーズの締めくくりとして、本の中身紹介に加え引用バトル・書店PRまで展開した雑談回。本編で扱ったテーマ（ハッカー文化、詐欺の合理、Penetrate & Patch、ビル・ゲイツ等）の**「種本版」エッセンス**が詰まっている。
