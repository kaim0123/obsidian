# MOC_分散システム体系

68_分散システム の入口ノート。**複数のマシンが協調して 1 つのシステムとして動くときの仕組みと難しさ**を扱う。DDIA（Designing Data-Intensive Applications 第2版）の Part II（複製・分割・トランザクション・分散の難しさ・一貫性と合意）に、キュー・分散キャッシュ・障害耐性パターンを加えている。61〜69 全体の地図は [[MOC_運用領域マップ]]。
