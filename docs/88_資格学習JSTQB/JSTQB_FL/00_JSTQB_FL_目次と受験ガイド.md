# JSTQB FL（Foundation Level）教材 目次と受験ガイド

## 受験ガイド

### JSTQB FL とは
- **正式名称**: JSTQB認定テスト技術者資格 Foundation Level
- **国際資格**: ISTQB（International Software Testing Qualifications Board）の日本版
- **対象者**: ソフトウェアテストに関わるすべての人（開発者・QA・PM など）
- **前提条件**: なし（誰でも受験可能）

### 試験概要
| 項目 | 内容 |
|------|------|
| 問題数 | 40問（4択の選択式） |
| 試験時間 | 60分（非英語圏は+25%で75分の場合あり） |
| 合格ライン | 65%（26問/40問 正解） |
| 受験料 | 22,000円（税込） |
| 出題範囲 | JSTQB FL シラバス v4.0（2024年〜） |
| 結果通知 | 試験後約3〜4週間 |

### 開催スケジュール・申し込み方法
- **開催頻度**: 年2回（例年 **2月頃** と **8月頃**）
- **申し込み先**: [JSTQB公式サイト](http://jstqb.jp/)
- **申し込み期間**: 試験日の約2〜3ヶ月前に公式サイトで告知
- **試験会場**: 全国の主要都市（CBT方式の場合はテストセンター）
- **流れ**:
  1. 公式サイトで試験日程を確認
  2. 申し込み期間内にWeb申込
  3. 受験料を支払い
  4. 受験票を受け取り
  5. 試験日に会場で受験

### おすすめの問題集・学習リソース

#### 無料のオンライン問題集
- **[テス友（Qbook）](https://www.qbook.jp/info-testomo/)** — 最もおすすめ
  - JSTQB公認の無料学習アプリ（Web / iOS / Android対応）
  - 「章別」「間違えた問題」「ランダム」の3パターンで出題
  - 弱点分析機能付き、シラバスへのリンクもあり
  - Qbookへの無料登録で利用可能
- **[無料de試験](http://newtokyo.westus2.cloudapp.azure.com/shiken/jstqbTop.htm)**
  - アカウント登録不要で何度でも受験可能
  - 300問以上を収録（シラバス2018ベース）
- **[Udemy「JSTQB-FL試験対策 問題集（300問）」](https://www.udemy.com/course/jstqb-fl-300/)**（有料）
  - セール時に1,500〜2,000円程度で購入可能
  - 模擬試験形式＋LO別の重点対策問題

#### おすすめの書籍
- **[ソフトウェアテスト教科書 JSTQB Foundation 第5版（翔泳社）](https://www.shoeisha.co.jp/book/detail/9784798186061)**
  - シラバス2023対応の定番書
  - シラバスの内容をわかりやすく解説＋練習問題＋模擬試験1回分収録
  - 用語の丁寧な解説が特徴
- **[徹底攻略 JSTQB Foundation 教科書&問題集（インプレス）](https://book.impress.co.jp/books/1124101026)**
  - シラバス2023対応版あり
  - 各章末の演習問題＋模擬問題収録

### 推奨する学習ステップ
合格者の多くが実践している方法:
1. **シラバス or 参考書をざっと1周流し読み**（全体像を掴む）
2. 本教材の各章を順番に学習する
3. **テス友をひたすら解く**（通勤中などスキマ時間で）
4. **間違えた箇所のシラバス・参考書を再読** → 3に戻ってループ
5. 本番1〜2週前に**模擬試験を時間を計って解く**（40問を75分以内）

#### 学習期間の目安
- 平日1〜2時間、休日3〜4時間で **約1ヶ月** が目安
- テスト経験者なら2〜3週間でも合格可能

### 取得するメリット
- ソフトウェアテストの**国際標準の知識**が身につく
- 開発者としても**品質意識**が向上する
- テスト関連の**共通言語**でコミュニケーションできる
- 転職・キャリアアップに活用できる

### 学習のポイント
- **用語の正確な理解**が最重要（シラバスの定義をそのまま覚える）
- 「テストの7原則」は必ず出題される
- テスト技法（同値分割・境界値分析・デシジョンテーブル・状態遷移）は計算問題も出る
- シラバスの「学習の目的（LO）」に沿って出題される
- テス友で間違えた問題を繰り返すのが最も効率的
