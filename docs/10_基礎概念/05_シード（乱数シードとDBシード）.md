# シード（乱数シードとDBシード）

プログラミングで「シード（seed ＝ 種）」と言うとき、指しているものは主に**2種類**あります。どちらも「最初に与えるもの」という意味で「種」と呼ばれますが、中身はまったく別の概念です。このノートは、どちらのシードかを見分けて本編へ進むための案内です。

| | 乱数シード | DBシード |
|---|---|---|
| 英語 | random seed | seed data / seeding |
| 何か | 乱数生成器に最初に渡す**数値** | DB に最初から入れておく**データ**（とその投入スクリプト） |
| 目的 | 乱数の結果を**再現できる**ようにする | 開発・テスト・本番を**決まった初期状態**から始める |
| 出てくる場所 | テスト、機械学習、ゲーム、シミュレーション | バックエンド、ORM、マイグレーション、E2E テスト |
| 例 | `random.seed(42)`、`faker.seed(123)` | `prisma db seed`、`rails db:seed` |
| 本編 | [[擬似乱数と乱数シード]] | [[06_シードデータ]] |

## どちらのシードか見分ける

周りに出てくる単語で見分けられます。

- **乱数シード**の可能性が高い：`random`、`rand`、`Math.random`、「再現性」、「シード値」、`42`、機械学習、シャッフル、flaky、Minecraft
- **DBシード**の可能性が高い：`db`、`seeds.rb`、`seeder`、`seed.ts`、マイグレーション、初期データ、マスタデータ、ダミーデータ、`npm run seed`

迷ったら「**数値を1つ渡しているか**（→乱数シード）」「**レコードを作っているか**（→DBシード）」で判断できます。

### 両方が同時に出てくる場面
faker でダミーデータを作って DB に入れるシードスクリプトでは、両方が出てきます。

```typescript
faker.seed(123);                           // ← 乱数シード（毎回同じダミーデータにする）
const users = Array.from({ length: 100 }, () => ({ name: faker.person.fullName() }));
await prisma.user.createMany({ data: users }); // ← このスクリプト全体が DB シード
```
