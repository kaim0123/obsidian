# 制御構造

## 制御構造とは
プログラムの**実行の流れを制御する構文**のことです。上から順に実行するだけでなく、条件で分岐したり、処理を繰り返したりできます。

## 3つの基本構造

### 1. 順次（Sequence）
上から順に実行。

### 2. 選択（Selection / 分岐）
条件によって処理を分ける。

### 3. 反復（Iteration / ループ）
同じ処理を繰り返す。

この3つを組み合わせれば**あらゆるアルゴリズム**が書けることが知られています（構造化定理）。

## 条件分岐

### if / else
```javascript
if (score >= 90) {
  console.log("A");
} else if (score >= 70) {
  console.log("B");
} else {
  console.log("C");
}
```

### switch / case
値が多数の分岐に向く。
```javascript
switch (day) {
  case "Mon": console.log("月"); break;
  case "Tue": console.log("火"); break;
  default:    console.log("その他");
}
```

### 三項演算子（条件式）
```javascript
const label = score >= 60 ? "合格" : "不合格";
```

### パターンマッチ（現代的な分岐）
Rust、Scala、最近のPython、C#などで使える強力な分岐。
```rust
match value {
    0      => println!("zero"),
    1..=9  => println!("digit"),
    _      => println!("other"),
}
```

## ループ

### forループ
回数が決まっているとき。
```javascript
for (let i = 0; i < 10; i++) {
  console.log(i);
}
```

### whileループ
条件が真の間繰り返す。
```javascript
while (!done) {
  done = tryOnce();
}
```

### do-whileループ
**少なくとも1回**は実行される。
```javascript
do {
  input = prompt("入力");
} while (!isValid(input));
```

### for-of / for-in / foreach
コレクションを走査。
```javascript
for (const item of items) { ... }      // 値
for (const key in obj)    { ... }      // キー
items.forEach(item => ...);            // メソッド版
```

## ループの制御

### break
ループを抜ける。
```javascript
for (const n of nums) {
  if (n < 0) break;   // 負の数が出たら終了
}
```

### continue
次の反復へジャンプ。
```javascript
for (const n of nums) {
  if (n % 2 === 0) continue;  // 偶数はスキップ
  console.log(n);
}
```

### ラベル付きループ
ネストした内側から特定のループを抜けたい時。
```javascript
outer:
for (const row of grid) {
  for (const cell of row) {
    if (cell === null) break outer;
  }
}
```

## 無限ループとその抜け方
```javascript
while (true) {
  const msg = queue.receive();
  if (msg === "quit") break;
  handle(msg);
}
```
常駐処理やイベントループで使います。明示的な終了条件が必要。

## 早期リターン
分岐のネストを減らすテクニック。関数の先頭で条件を弾く。
```javascript
function process(user) {
  if (!user) return;         // ガード節
  if (!user.active) return;
  // 本処理
}
```

## 関数型スタイルのループ
配列操作で`for`を書かずに宣言的に書く。
```javascript
const evens   = nums.filter(n => n % 2 === 0);
const doubled = nums.map(n => n * 2);
const sum     = nums.reduce((a, b) => a + b, 0);
```

## 再帰
関数が**自分自身を呼び出す**。木構造の探索や分割統治に向く。
```javascript
function factorial(n) {
  if (n <= 1) return 1;     // 基底条件
  return n * factorial(n - 1);
}
```
基底条件を忘れるとスタックオーバーフローになります。

## 例外による制御（補足）
`try / catch / finally` で例外ベースのフロー制御。詳細は例外処理の章で。

## 構造化プログラミングのコツ

### ネストを浅く保つ
```javascript
// ❌ ネストが深い
if (a) { if (b) { if (c) { ... } } }

// ✅ 早期リターン
if (!a) return;
if (!b) return;
if (!c) return;
...
```

### goto的な飛び越えを避ける
多くの現代言語は `goto` を廃止／非推奨。`break` / `continue` / 例外で十分。

## 言語ごとの違い（ざっくり）
- **Python**: インデントがブロックを示す。`match` は3.10〜
- **Go**: `while` 無し、`for` で全部書く
- **Rust**: `loop`, `while`, `for` + 強力な `match`
- **JavaScript**: `for...of` / `for...in` の使い分けに注意

## まとめ
- **順次・選択・反復**が制御構造の3本柱
- 分岐は `if` / `switch` / パターンマッチ
- ループは `for` / `while` / `for-each`、制御は `break` / `continue`
- 宣言的スタイル（map/filter/reduce）や再帰も選択肢
- **ネストは浅く、早期リターンで可読性を保つ**
