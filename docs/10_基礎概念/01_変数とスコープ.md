# 変数とスコープ

## 変数とは
値に**名前を付けて参照できるようにした箱**のことです。プログラム内で同じ値を何度も使ったり、計算結果を保持するために利用します。

```javascript
let name = "Alice";     // 変数nameに "Alice" を格納
console.log(name);      // "Alice"
```

## 変数の宣言と代入

### 宣言
変数を「これから使う」と言語処理系に知らせる行為。

### 初期化
宣言と同時に値を入れること。

### 代入
既存の変数に新しい値を入れること。

```javascript
let x;         // 宣言
x = 10;        // 代入
let y = 20;    // 宣言＋初期化
```

## 変数の種類

### ミュータブル（可変）
値を変更できる変数。
```javascript
let count = 0;
count = count + 1;  // OK
```

### イミュータブル（不変）/ 定数
一度決めたら変えられない変数。
```javascript
const PI = 3.14;
// PI = 3.15;  // エラー
```

### 各言語での定数宣言
- **JavaScript**: `const`
- **Java**: `final`
- **Rust**: `let` (既定で不変、可変は `let mut`)
- **Python**: 慣習上 `UPPER_CASE`（言語的には強制なし）

## スコープとは
変数が**有効な範囲**のこと。スコープを外れるとその名前では参照できません。

### 代表的なスコープ
1. **グローバルスコープ**: プログラム全体
2. **関数スコープ**: 関数内だけ
3. **ブロックスコープ**: `{ }` の中だけ
4. **モジュールスコープ**: 1ファイル内

## ブロックスコープの例
```javascript
function example() {
  if (true) {
    let inside = "hello";
    console.log(inside);  // OK
  }
  console.log(inside);   // エラー: 外からは見えない
}
```

## スコープチェーン
内側から外側へ順に変数を探す仕組み。

```javascript
const a = 1;
function outer() {
  const b = 2;
  function inner() {
    const c = 3;
    console.log(a, b, c);  // 1 2 3
  }
  inner();
}
```
`inner` は自分 → `outer` → グローバル、と探しに行きます。

## 変数の寿命（ライフタイム）
変数がメモリ上に存在する期間。
- ローカル変数: 関数の実行中だけ
- グローバル変数: プログラム終了まで
- クロージャ: 参照している限り生き続ける

## シャドーイング
内側のスコープで**外側と同じ名前**の変数を宣言すること。

```javascript
let x = 10;
function f() {
  let x = 20;  // 外側のxを隠す
  console.log(x);  // 20
}
console.log(x);  // 10
```

## 巻き上げ（ホイスティング）
JavaScript特有の挙動。`var` 宣言や関数宣言は**スコープの先頭に巻き上げられる**。
```javascript
console.log(v);  // undefined（エラーにならない）
var v = 1;
```
`let` / `const` はTDZ（一時的死角）で参照エラーになります。

## 命名規則（一般論）
- 意味が伝わる名前（`count` > `c`）
- 短すぎず長すぎず
- **camelCase**（JS, Java, Swift）
- **snake_case**（Python, Ruby, Rust）
- 定数は `UPPER_SNAKE_CASE`

## よくあるバグ

### 1. スコープ外で使おうとする
```javascript
for (let i = 0; i < 3; i++) { /* ... */ }
console.log(i);  // エラー
```

### 2. 意図せぬ上書き
同名のグローバル変数を関数内で再利用してしまう。

### 3. 変数の使い回し
別の意味の値を同じ変数に入れる → 可読性が落ちる。

## ベストプラクティス
- **使う直前で宣言**（スコープを最小に）
- **既定は `const`**、変更が必要な時だけ `let`
- グローバル変数は極力使わない
- シャドーイングは避ける

## まとめ
- 変数は**値に名前を付けた箱**
- **スコープ**は変数が使える範囲、内→外と探す
- `const` を基本に、変更が必要な時のみ `let`
- 寿命・命名・シャドーイングを意識するとバグが減る
