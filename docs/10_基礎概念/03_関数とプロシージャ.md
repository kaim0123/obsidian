# 関数とプロシージャ

## 関数とは
入力（引数）を受け取り、処理を行って**結果を返す**ひとまとまりのコードです。同じ処理をまとめて再利用できます。

```javascript
function square(x) {
  return x * x;
}

console.log(square(4));  // 16
```

## プロシージャとの違い
- **関数（function）**: 値を返す
- **プロシージャ（procedure）**: 副作用を行うが値は返さない（Pascalなどに存在）

現代言語では区別が曖昧で、戻り値がない関数（`void`）=プロシージャと扱われることが多いです。

## 関数の構成要素
1. **名前**: 呼び出すための識別子
2. **仮引数（パラメータ）**: 入力を受ける変数
3. **本体**: 実行される処理
4. **戻り値**: 結果として返す値

```javascript
function greet(name) {       // 名前: greet, 仮引数: name
  return `Hello, ${name}!`;  // 戻り値
}

greet("Alice");              // 実引数: "Alice"
```

## 関数を使うメリット
- **再利用**: 同じ処理を何度も書かなくていい
- **抽象化**: 複雑な処理に名前を付けて隠蔽
- **テストしやすい**: 単体でテストできる
- **可読性向上**: 意図が名前で伝わる

## 引数の渡し方

### 値渡し（Pass by Value）
値がコピーされる。関数内で変更しても外に影響しない。
```c
void f(int x) { x = 99; }
int a = 1;
f(a);    // a は 1 のまま
```

### 参照渡し（Pass by Reference）
変数そのものを渡す。関数内の変更が外にも反映。
```cpp
void f(int& x) { x = 99; }
int a = 1;
f(a);    // a は 99 に
```

### 言語ごとの実態
- **JavaScript/Python**: プリミティブは値渡し、オブジェクトは「参照の値渡し」
- **Java**: すべて値渡し（参照型は参照がコピーされる）
- **Rust**: 所有権と借用で明示的

## 様々な引数

### デフォルト引数
```javascript
function greet(name = "anon") { return `Hi, ${name}`; }
greet();       // "Hi, anon"
greet("Bob");  // "Hi, Bob"
```

### 可変長引数
```javascript
function sum(...nums) {
  return nums.reduce((a, b) => a + b, 0);
}
sum(1, 2, 3, 4);  // 10
```

### キーワード引数（Python等）
```python
def connect(host, port=80, ssl=False):
    ...
connect("example.com", ssl=True)
```

## 戻り値

### 単一の値
```javascript
function add(a, b) { return a + b; }
```

### 複数の値
- タプル（Python, Rust, Go）
- オブジェクト・配列（JS）
```javascript
function minMax(arr) {
  return { min: Math.min(...arr), max: Math.max(...arr) };
}
const { min, max } = minMax([3, 1, 4]);
```

### 値を返さない
`void`、`null`、`undefined`、`None` など。副作用のみ。

## 第一級関数
関数を**値として扱える**特徴。現代言語のほぼすべてが対応。
```javascript
const greet = function(name) { return `Hi ${name}`; };
const list  = [greet];
list[0]("Alice");
```

## 高階関数
関数を**引数で受け取る／戻り値で返す**関数。
```javascript
// 引数として受け取る
[1, 2, 3].map(x => x * 2);  // [2, 4, 6]

// 戻り値として返す
function makeAdder(n) {
  return x => x + n;
}
const add5 = makeAdder(5);
add5(3);  // 8
```

## 無名関数・アロー関数・ラムダ
名前を付けずその場で定義する関数。
```javascript
// JS
const double = x => x * 2;

// Python
double = lambda x: x * 2

// Java
x -> x * 2
```

## クロージャ
関数が**定義時のスコープの変数を覚えている**仕組み。
```javascript
function counter() {
  let count = 0;
  return () => ++count;
}
const c = counter();
c();  // 1
c();  // 2
```

## 純粋関数と副作用

### 純粋関数
- 同じ入力に対して必ず同じ出力
- 外部の状態を変えない（副作用なし）
```javascript
const add = (a, b) => a + b;
```

### 副作用のある関数
```javascript
function save(user) {
  db.insert(user);   // DB変更
  logger.log(user);  // ログ出力
}
```

純粋関数はテスト・並行処理に強い。ただし実用的なコードは副作用が必要。

## 再帰関数
自分自身を呼び出す関数。基底条件が必須。
```javascript
function fib(n) {
  if (n < 2) return n;      // 基底条件
  return fib(n - 1) + fib(n - 2);
}
```

### 末尾再帰最適化
末尾で自分を呼ぶ形式なら、ループに変換してスタック消費を抑えられる（言語による）。

## メソッド vs 関数
- **関数**: 独立した処理
- **メソッド**: オブジェクトに属する関数（`this` や `self` を持つ）
```python
class Dog:
    def bark(self):  # メソッド
        print("Woof")

def hello():         # 関数
    print("Hi")
```

## 関数設計のベストプラクティス

### 単一責任
1つの関数は1つの仕事だけ。

### 短く保つ
目安: 1画面（20〜40行）に収める。

### 名前で意図を伝える
```javascript
// ❌
function proc(x) { ... }

// ✅
function calculateTax(amount) { ... }
```

### 引数は少なく
3〜4個を超えたらオブジェクト化を検討。

### 副作用を明確に
名前で示す（`saveUser`, `fetchData`）。

## まとめ
- 関数は**入力を受け取り結果を返す**再利用可能な処理単位
- 第一級関数・高階関数・クロージャは現代言語の基本
- **純粋関数**はテスト・並行処理で強い
- **単一責任・短い・明瞭な名前**を意識すると品質が上がる
