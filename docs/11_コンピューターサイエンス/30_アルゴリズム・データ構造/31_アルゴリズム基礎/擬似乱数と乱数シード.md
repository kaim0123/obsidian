# 擬似乱数と乱数シード

**乱数シード（random seed）**とは、擬似乱数生成器に**最初に渡す値**のことです。同じシードを渡すと、毎回まったく同じ乱数列が出てきます。この性質を理解するには、まず「コンピューターの乱数は計算で作られている」ことを知る必要があります。

> DB に初期データを入れる「DBシード」は別の概念です → [[06_シードデータ]]

---

## 1. コンピューターの乱数は「計算」で作られる

コンピューターは決まった手順しか実行できないので、本当の意味でのデタラメな数は作れません。そこで、**計算式で「乱数っぽく見える数列」を作ります**。

- **擬似乱数（pseudo-random number）**：計算で作った、乱数のように見える数
- **擬似乱数生成器（PRNG, Pseudo-Random Number Generator）**：擬似乱数を作る仕組み

PRNG は「今の状態」から「次の数」と「次の状態」を計算する装置です。

```
シード → [計算] → 数1 → [計算] → 数2 → [計算] → 数3 → …
```

この**一番最初の状態を決める値がシード**です。シードは「種」という意味で、ここから乱数列が「育つ」イメージから名付けられています。

### 1.1 一番簡単な PRNG：線形合同法
昔からある方法に**線形合同法（LCG）**があります。

```
次の状態 = (a × 今の状態 + c) mod m
```

```javascript
function createLCG(seed) {
  let state = seed;
  return function next() {
    state = (1103515245 * state + 12345) % 2 ** 31;
    return state / 2 ** 31; // 0以上1未満にする
  };
}

const rand = createLCG(42);
rand(); // 毎回同じ値
rand(); // 毎回同じ値（1回目とは違う）
```

計算式が決まっているので、**シードが同じなら結果も必ず同じ**になるのが分かります。

現在の言語では、LCG より統計的な品質が高い **メルセンヌ・ツイスタ**（Python の `random`）や **xorshift 系**（多くのブラウザの `Math.random`）、**PCG**（NumPy）などが使われています。

---

## 2. 同じシードなら、同じ乱数列になる

これが乱数シードの一番大事な性質です。

```python
import random

random.seed(42)
print(random.randint(1, 100), random.randint(1, 100))  # 例: 82 15

random.seed(42)
print(random.randint(1, 100), random.randint(1, 100))  # また 82 15（同じ）
```

シードを指定しないと、多くの言語では**現在時刻や OS のエントロピー（キー入力のタイミングなど、予測できない値）**をシードとして自動で使います。そのため、普段は実行するたびに違う結果になります。

---

## 3. 何に使うか

| 用途 | シードを固定する理由 |
|---|---|
| **テスト** | ランダムな値を使うテストが、たまにだけ落ちる（flaky）のを防ぐ。落ちたときに同じ状況を再現できる |
| **機械学習** | 重みの初期値やデータ分割を固定し、実験結果を再現・比較できるようにする |
| **ゲーム** | 同じシードから同じマップを作る（Minecraft の「シード値」はこれ） |
| **シミュレーション** | 条件を1つだけ変えて比較したいときに、それ以外のランダム要素をそろえる |
| **ダミーデータ生成** | faker などで毎回同じダミーデータを作り、画面確認やテストを安定させる |

ゲームの例がわかりやすいです。マップ全体を保存しなくても、**シード値という数値1つ**を保存すれば、同じ世界を何度でも作り直せます。

## 4. 言語ごとの書き方

```python
# Python
import random
random.seed(42)

import numpy as np
rng = np.random.default_rng(42)   # 推奨: 生成器オブジェクトごとにシードを持たせる
rng.integers(1, 100)
```

```javascript
// JavaScript: Math.random() にはシードを指定できない
// 再現性が必要なら seedrandom などのライブラリを使う
import seedrandom from "seedrandom";
const rng = seedrandom("42");
rng(); // 毎回同じ値
```

```typescript
// テストデータ生成ライブラリ @faker-js/faker
import { faker } from "@faker-js/faker";
faker.seed(123); // 以降の生成データが毎回同じになる
faker.person.fullName();
```

## 5. 注意点

### 5.1 セキュリティ用途に使わない
擬似乱数は計算で作っているので、**シードが分かれば以降の乱数はすべて予測できます**。時刻をシードにしている場合、時刻を推測されるだけで破られることもあります。

パスワード、トークン、セッション ID などには、**暗号学的に安全な乱数生成器（CSPRNG）**を使います。

| 言語 | 普通の乱数（予測されうる） | 安全な乱数 |
|---|---|---|
| JavaScript | `Math.random()` | `crypto.getRandomValues()`、`crypto.randomUUID()` |
| Python | `random` | `secrets` |
| Node.js | `Math.random()` | `crypto.randomBytes()` |

### 5.2 グローバルなシードはほかのコードに影響する
`random.seed()` はプロセス全体の状態を変えます。ライブラリの中で呼ぶと、そのライブラリを使う側の乱数まで固定されてしまいます。できれば**生成器オブジェクトを作って、その中にシードを閉じ込めます**（NumPy の `default_rng` など）。

### 5.3 テストでは「固定する」か「記録する」か
シードを固定すると再現性は上がりますが、いつも同じ値しか試しません。もう1つのやり方は、**ランダムなシードで実行し、失敗したときにそのシードをログに出す**方法です。プロパティベーステストのツール（fast-check、Hypothesis など）はこれを自動でやってくれます。

---

## 6. まとめ

- コンピューターの乱数は**計算で作る擬似乱数**
- **シード**は擬似乱数生成器の最初の状態を決める値
- **同じシードなら同じ乱数列**になるので、テスト・機械学習・ゲームで**再現性**のために使う
- 予測できてしまうので、**セキュリティ用途には CSPRNG を使う**
- シードはグローバルに設定するより、**生成器オブジェクトに閉じ込める**
