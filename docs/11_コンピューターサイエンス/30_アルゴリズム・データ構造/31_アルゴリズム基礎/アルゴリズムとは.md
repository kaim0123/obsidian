# アルゴリズムとは

## アルゴリズムの定義
問題を解決するための「手順」や「やり方」のことです。料理のレシピのように、ステップバイステップで目的を達成する方法を示します。

## 日常生活のアルゴリズム

### 例1: カップラーメンの作り方
```
1. カップのフタを開ける
2. お湯を線まで注ぐ
3. 3分待つ
4. フタを開けて食べる
```

### 例2: 目的地への行き方
```
1. 現在地を確認
2. 地図で目的地を探す
3. 最短ルートを選ぶ
4. そのルートで移動する
```

## プログラミングのアルゴリズム

### 例1: 最大値を見つける
```javascript
function findMax(numbers) {
  // 1. 最初の要素を暫定の最大値とする
  let max = numbers[0];

  // 2. 残りの要素を順に確認
  for (let i = 1; i < numbers.length; i++) {
    // 3. 現在の最大値より大きければ更新
    if (numbers[i] > max) {
      max = numbers[i];
    }
  }

  // 4. 最大値を返す
  return max;
}

console.log(findMax([3, 7, 2, 9, 1]));  // 9
```

### 例2: 合計を計算
```javascript
function sum(numbers) {
  // 1. 合計を0で初期化
  let total = 0;

  // 2. すべての要素を足していく
  for (let num of numbers) {
    total += num;
  }

  // 3. 合計を返す
  return total;
}

console.log(sum([1, 2, 3, 4, 5]));  // 15
```

## 良いアルゴリズムの条件

### 1. 正確性
正しい結果を返す

### 2. 効率性
速く動作する（時間計算量が小さい）
少ないメモリで動く（空間計算量が小さい）

### 3. 可読性
他の人が読んで理解できる

### 4. 保守性
後から修正や改善がしやすい

## アルゴリズムの比較

### 問題: 1〜100の合計を求める

#### 方法1: ループで足す
```javascript
function sumLoop() {
  let total = 0;
  for (let i = 1; i <= 100; i++) {
    total += i;
  }
  return total;
}
// 計算回数: 100回
```

#### 方法2: 数学の公式を使う
```javascript
function sumFormula() {
  const n = 100;
  return (n * (n + 1)) / 2;
}
// 計算回数: 3回（掛け算、足し算、割り算）
```

どちらも答えは5050ですが、方法2の方が圧倒的に速いです！

## アルゴリズムの分類

### 探索アルゴリズム
データから目的の値を見つける
- 線形探索（順番に探す）
- 二分探索（半分ずつ絞り込む）

### ソートアルゴリズム
データを並べ替える
- バブルソート
- クイックソート
- マージソート

### 再帰アルゴリズム
関数が自分自身を呼び出す
- 階乗の計算
- フィボナッチ数列
- 木構造の探索

## 実践例

### 偶数だけを抽出
```javascript
function filterEven(numbers) {
  const result = [];
  for (let num of numbers) {
    if (num % 2 === 0) {
      result.push(num);
    }
  }
  return result;
}

console.log(filterEven([1, 2, 3, 4, 5, 6]));  // [2, 4, 6]
```

### 文字列を反転
```javascript
function reverse(str) {
  let result = "";
  for (let i = str.length - 1; i >= 0; i--) {
    result += str[i];
  }
  return result;
}

console.log(reverse("hello"));  // "olleh"
```

### 重複を除去
```javascript
function removeDuplicates(arr) {
  const result = [];
  for (let item of arr) {
    if (!result.includes(item)) {
      result.push(item);
    }
  }
  return result;
}

console.log(removeDuplicates([1, 2, 2, 3, 3, 3, 4]));  // [1, 2, 3, 4]

// より効率的な方法（Set を使う）
function removeDuplicatesFast(arr) {
  return [...new Set(arr)];
}
```

## アルゴリズムを学ぶ意義

1. **問題解決能力の向上**
   - 複雑な問題を小さく分解できる
   - 効率的な解決策を考えられる

2. **コードの品質向上**
   - 速く動くプログラムが書ける
   - メモリ効率の良いコードが書ける

3. **技術面接対策**
   - 多くの企業がアルゴリズムの知識を求める
   - コーディング試験で必要

4. **プログラミング思考の基礎**
   - どの言語でも応用できる
   - 新しい技術の理解が早くなる

## アルゴリズムの学び方

### 1. 基本を理解する
- 配列、リスト、木、グラフなどのデータ構造
- 探索、ソート、再帰などの基本アルゴリズム

### 2. 実際に書いてみる
- 自分の手で実装する
- エラーを恐れない

### 3. 時間計算量を意識する
- どれくらい時間がかかるか考える
- より効率的な方法を探す

### 4. 問題を解く
- LeetCode、AtCoder などの競技プログラミングサイト
- 毎日少しずつ続ける

## まとめ

- **アルゴリズム**は問題解決の手順
- **正確性**と**効率性**が重要
- 同じ問題でも**複数のアルゴリズム**がある
- **基本を理解**して、**実践**することが大切
- アルゴリズムは**プログラミングの基礎**
