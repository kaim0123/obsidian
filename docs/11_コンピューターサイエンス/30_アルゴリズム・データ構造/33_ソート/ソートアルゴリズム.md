# ソートアルゴリズム

## ソートとは

データを特定の順序（昇順・降順）に並べ替えることです。

### 重要性
- データの検索が速くなる
- データの可視化が容易になる
- アルゴリズムの基礎を学べる

---

## バブルソート（Bubble Sort）

隣り合う要素を比較して交換を繰り返すシンプルなアルゴリズムです。

### アルゴリズム
1. 隣り合う要素を比較
2. 順序が逆なら交換
3. これを配列の最後まで繰り返す
4. 最大値が末尾に移動（泡のように浮かぶ）

### 実装
```javascript
function bubbleSort(arr) {
  const n = arr.length;

  for (let i = 0; i < n - 1; i++) {
    for (let j = 0; j < n - 1 - i; j++) {
      if (arr[j] > arr[j + 1]) {
        // 交換
        [arr[j], arr[j + 1]] = [arr[j + 1], arr[j]];
      }
    }
  }

  return arr;
}

console.log(bubbleSort([5, 3, 8, 4, 2]));  // [2, 3, 4, 5, 8]
```

### 時間計算量
- **最良**: O(n)（既にソート済み）
- **平均**: O(n²)
- **最悪**: O(n²)

### 特徴
- **シンプル**で理解しやすい
- **遅い**（大きなデータには不向き）
- **安定ソート**（同じ値の順序が保たれる）

---

## 選択ソート（Selection Sort）

最小値を見つけて先頭に移動させることを繰り返すアルゴリズムです。

### アルゴリズム
1. 未ソート部分から最小値を見つける
2. 先頭と交換
3. ソート済み部分を1つ増やす
4. 繰り返す

### 実装
```javascript
function selectionSort(arr) {
  const n = arr.length;

  for (let i = 0; i < n - 1; i++) {
    let minIndex = i;

    // 最小値を探す
    for (let j = i + 1; j < n; j++) {
      if (arr[j] < arr[minIndex]) {
        minIndex = j;
      }
    }

    // 交換
    if (minIndex !== i) {
      [arr[i], arr[minIndex]] = [arr[minIndex], arr[i]];
    }
  }

  return arr;
}

console.log(selectionSort([5, 3, 8, 4, 2]));  // [2, 3, 4, 5, 8]
```

### 時間計算量
- **すべて**: O(n²)

### 特徴
- 交換回数が少ない
- **不安定ソート**

---

## 挿入ソート（Insertion Sort）

カードを整列するように、要素を適切な位置に挿入するアルゴリズムです。

### アルゴリズム
1. 2番目の要素から開始
2. ソート済み部分と比較
3. 適切な位置に挿入
4. 繰り返す

### 実装
```javascript
function insertionSort(arr) {
  const n = arr.length;

  for (let i = 1; i < n; i++) {
    const key = arr[i];
    let j = i - 1;

    // keyより大きい要素を右にシフト
    while (j >= 0 && arr[j] > key) {
      arr[j + 1] = arr[j];
      j--;
    }

    arr[j + 1] = key;
  }

  return arr;
}

console.log(insertionSort([5, 3, 8, 4, 2]));  // [2, 3, 4, 5, 8]
```

### 時間計算量
- **最良**: O(n)（既にソート済み）
- **平均**: O(n²)
- **最悪**: O(n²)

### 特徴
- **小さなデータ**や**ほぼソート済み**に効率的
- **安定ソート**
- **オンラインアルゴリズム**（データが来たら逐次ソート可能）

---

## マージソート（Merge Sort）

分割統治法を使った効率的なソートアルゴリズムです。

### アルゴリズム
1. 配列を半分に分割
2. 再帰的に各部分をソート
3. ソート済みの部分をマージ

### 実装
```javascript
function mergeSort(arr) {
  if (arr.length <= 1) {
    return arr;
  }

  const mid = Math.floor(arr.length / 2);
  const left = mergeSort(arr.slice(0, mid));
  const right = mergeSort(arr.slice(mid));

  return merge(left, right);
}

function merge(left, right) {
  const result = [];
  let i = 0, j = 0;

  while (i < left.length && j < right.length) {
    if (left[i] <= right[j]) {
      result.push(left[i]);
      i++;
    } else {
      result.push(right[j]);
      j++;
    }
  }

  return result.concat(left.slice(i)).concat(right.slice(j));
}

console.log(mergeSort([5, 3, 8, 4, 2]));  // [2, 3, 4, 5, 8]
```

### 時間計算量
- **すべて**: O(n log n)

### 特徴
- **高速**で安定
- **追加メモリ**が必要
- **安定ソート**

---

## クイックソート（Quick Sort）

ピボットを基準に分割してソートする効率的なアルゴリズムです。

### アルゴリズム
1. ピボット（基準値）を選ぶ
2. ピボットより小さい要素を左、大きい要素を右に分ける
3. 左右を再帰的にソート

### 実装
```javascript
function quickSort(arr) {
  if (arr.length <= 1) {
    return arr;
  }

  const pivot = arr[Math.floor(arr.length / 2)];
  const left = arr.filter(x => x < pivot);
  const middle = arr.filter(x => x === pivot);
  const right = arr.filter(x => x > pivot);

  return [...quickSort(left), ...middle, ...quickSort(right)];
}

console.log(quickSort([5, 3, 8, 4, 2]));  // [2, 3, 4, 5, 8]
```

### 時間計算量
- **最良/平均**: O(n log n)
- **最悪**: O(n²)（既にソート済みの場合）

### 特徴
- **平均的に最速**
- **追加メモリ少ない**
- **不安定ソート**

## JavaScriptの組み込みソート

```javascript
const arr = [5, 3, 8, 4, 2];

// デフォルト（文字列として比較）
arr.sort();
console.log(arr);  // [2, 3, 4, 5, 8]

// 数値として比較（昇順）
arr.sort((a, b) => a - b);
console.log(arr);  // [2, 3, 4, 5, 8]

// 降順
arr.sort((a, b) => b - a);
console.log(arr);  // [8, 5, 4, 3, 2]

// オブジェクトの配列
const users = [
  { name: "太郎", age: 25 },
  { name: "花子", age: 20 },
  { name: "次郎", age: 30 }
];

// 年齢でソート
users.sort((a, b) => a.age - b.age);
```

## ソートアルゴリズムの比較

| アルゴリズム | 時間計算量（平均） | 時間計算量（最悪） | 空間計算量 | 安定性 |
|------------|------------------|------------------|-----------|--------|
| バブルソート | O(n²) | O(n²) | O(1) | 安定 |
| 選択ソート | O(n²) | O(n²) | O(1) | 不安定 |
| 挿入ソート | O(n²) | O(n²) | O(1) | 安定 |
| マージソート | O(n log n) | O(n log n) | O(n) | 安定 |
| クイックソート | O(n log n) | O(n²) | O(log n) | 不安定 |

---

## 使い分けのポイント

### 小さなデータ（n < 50）
- **挿入ソート**が高速

### 大きなデータ
- **クイックソート**（平均的に最速）
- **マージソート**（最悪でも O(n log n)）

### 安定性が必要
- **マージソート**
- **挿入ソート**

### メモリが限られている
- **クイックソート**
- **挿入ソート**

### 実務では
- **JavaScriptの組み込みソート**を使う
  - 内部で最適化されたアルゴリズムが使われる
  - V8（Chrome）では Timsort（マージソート + 挿入ソート）

---

## まとめ

- **ソート**はデータを並べ替える基本操作
- **O(n²)**: バブル、選択、挿入（シンプル、遅い）
- **O(n log n)**: マージ、クイック（複雑、速い）
- **実務では組み込みソート**を使う
- アルゴリズムの学習には最適な題材
