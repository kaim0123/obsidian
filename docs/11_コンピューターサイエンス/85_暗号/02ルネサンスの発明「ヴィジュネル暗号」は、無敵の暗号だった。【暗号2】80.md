## 要約

**暗号シリーズ第2回の位置づけ**

前回までの流れ（シーザー暗号→単一換字式暗号→頻度分析→宗教・写本研究での着想）を踏まえ、「頻度分析の壁をどう超えるか」をクイズ形式で探る回。最終的に**ヴィジュネル暗号**へ着地し、解読法は次回へ持ち越す。

**前回の宿題——水野の暗号案**

「鍵を複雑な関数にしてアルファベットを数値化し演算する」（RSA的な発想）、50音体系への置き換え、2〜3文字の並びで置き換える（コード／n-gram）、単語単位の置き換えなど、複数のアイデアが一度に混ざった状態。堀本は「ヴィジュネルですやん」系の台本分岐を用意していたが、想定外のミックスで台無しに——それでも**ホモフォニック換字式**や**多アルファベット（1対多）**の要素が、後の議論と重なる。

**ホモフォニック換字式暗号——頻度を薄めるが破られる**

頻度分析の弱点は「Eが多すぎる」こと。対策として、Eを11種類の記号に分散させ、各文字の出現率をおおよそ1%に均す発想（**ホモフォニック換字式暗号**）。一見完璧に見えるが、**連鎖（ビグラム）**で崩れる。例：Qの次はほぼU、Queenのような語では「Qの直後の記号」から手がかりが残る（Wikipediaの「Qの後にU以外が来る単語一覧」のような言語ネタ）。記号を増やしても、**置き換え後の並び**を長文で見れば、頻度の高い文字から順に潰せる。

さらに運用上の問題：1文字を3文字にばらすと、復号時に「どこで区切るか」が多義的になる（ABCが一語か、AとBCか）。分かち書き情報を数字列で持つ案も、暗号の中に暗号を入れる複雑さと実用性の問題で却下方向。

**単一換字式の本質的限界：1対1**

ここまでの暗号は**単一換字式（単一アルファベット置換）**——暗号文の1記号は、常に同じ平文1文字に戻る**1対1**の対応。Eを12種類に分けても、結局は「どれもE」という1対他の世界だった。

**ヴィジュネル暗号——1対多で「無敵」**

**ブレーズ・ド・ヴィジュネル**（ルネサンス期）が考案。**鍵**はずらし量の数字列（例：7, 14, 19を繰り返す）。平文の**何文字目か**によって、同じ文字でも別の暗号文になる——1文字目のAと2文字目のAは別の記号へ。**1対多**の対応のため、頻度分析が使えない。ホモフォニックの連鎖問題も、位置が変わることでかわす。

**体験：QUEEN → XIXLB**

鍵 `7, 14, 19`（デモ用に短縮）。Q→7ずらし、U→14ずらし、E→19ずらし……結果 **XIXLB**。同じ **X** がQとIを表し、平文の2つの **E** が **X** と **AO** に別々になる。表記の慣習：平文は小文字、暗号文は大文字（暗号解読の文脈での相場）。

鍵の伝達：数字羅列の代わりに、アルファベット順で7番目・14番目・19番目の文字を並べた単語——例えば **「hot」** と言うだけで鍵が伝わる。シェイクスピア一節を鍵にすれば覚えやすく運用も楽——ただし存在しない綴りの数字は使えない、という軽い制約あり。

**強いが普及しなかった理由**

暗号化・復号とも手間がかかり、当時は広くは使われなかった。それでも「絶対にバレたくない」用途では使われた。**メアリー・ステュアート**（スコットランド女王）の処刑譚：暗号化した暗殺計画の手紙が解読され、裁判で罪に問われ処刑——皮肉にも、ヴィジュネル暗号が提案されたのはほぼ同時期で、「これを知っていれば」という歴史のアイロニーとして触れられる。用途は王の軍令、奇襲の指令など、奪読されると困る手紙全般。暗号には人間ドラマが詰まっている、という『暗号解読』のトーンにも通じる話。

**解読のヒント（次回予告）**

ソーシャルエンジニアリングや鍵の奪取（ツーリングが難破船から暗号表を奪う話など）も現実の手段だが、ヴィジュネルは**紙とペンだけ**で解ける。水野の「定型フレーズから当てる」案は、ラマヌジャン逸話に例えられ**属人的すぎて却下**。

人類で初めて解いたのは**チャールズ・バベッジ**（チューリングではない）。電子コンピュータ以前の「コンピューターの父」が、特殊装置ではなく紙ペンで閃いた。**縦に積んで引いていく**ような数字の操作は、エニグマ解読でチューリングらが試した方法に近い——次回、クイズ形式で解説予定。視聴者にもコメント欄で仮説を募る。
