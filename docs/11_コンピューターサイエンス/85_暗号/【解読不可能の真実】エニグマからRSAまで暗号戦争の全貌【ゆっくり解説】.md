## 詳しい要約

本動画は、霊夢が降臨堂で見つけた **暗号で書かれた本** をきっかけに、古代のスキュタレーから現代の **ポスト量子暗号・量子鍵配送** まで、暗号技術の歴史を一気通貫で解説する。「歴史を知るのみが真実にたどり着ける」というヒントに沿い、**暗号と解読の攻防** がコンピュータ科学の発展とどう結びついてきたかを霊夢と魔理沙の対話形式で辿る。

### 古代〜中世——置換暗号とその弱点

| 暗号 | 時代・人物 | 仕組み | 弱点 |
|------|-----------|--------|------|
| **スキュタレー** | 紀元前、スパルタ | 棒に革紐を巻き、縦に文字を書いてから紐を外す **転置式暗号** | 棒の太さが分かれば解読可能 |
| **カエサル暗号** | 紀元前1世紀、ユリウス・カエサル | アルファベットを **3文字ずつずらす** 単一置換 | アルファベットは26文字しかないため **全パターン試行（ブルートフォース）** で必ず解ける |
| **ROT13** | 現代のネタバレ防止など | 13文字ずらすカエサル暗号の一種。2回適用で元に戻る | 暗号としては脆弱 |

### 頻度分析——暗号解読の革命（9世紀）

アラビアの数学者 **アル＝キンディ** が **頻度分析** を発明した。

- 言語には文字の出現頻度の偏りがある（英語では **E が約12.7%** で最多）。
- 暗号文で最も多い文字を **E の暗号化結果** と推定し、ずらし量を特定できる。
- 英語では **THE** などの頻出語パターンも手がかりになる。
- 単純な置換暗号はこれで一掃された。

### 多表式暗号——頻度分析への対抗（15〜19世紀）

| 暗号 | 人物・時代 | 仕組み | 解読法 |
|------|-----------|--------|--------|
| **アルベルティ暗号** | 15世紀、レオナルド・バッティスタ・アルベルティ（「暗号の父」） | 文字ごとに **異なる置換表** を使い分ける **多表式暗号** | 頻度分析が無効化される |
| **ヴィジュネル暗号** | 16世紀、ブレーズ・ド・ヴィジュネール | キーワード（例：`KEY`）の各文字に応じてずらし量を変え、キーワードを繰り返す | **300年間** 解読不可能とされたが、19世紀に **カシスキー試験法** で周期（キーワード長）を特定し、各位置で頻度分析が可能に |

### 機械暗号の時代——エニグマと第2次世界大戦（20世紀）

**1918年**、ドイツのアルトゥール・シェルビウスが **エニグマ** を発明した。

| 項目 | 内容 |
|------|------|
| **構造** | 電気機械式暗号機。タイプライター風の入力で、**ローター**（26接点の円盤）が回転しながら文字を置換 |
| **強度** | 標準型は **3つのローター** が異なる速度で回転。設定の組み合わせは **約1京5900兆通り** 以上 |
| **ポーランドの突破** | **1932年**、マリアン・レフスキが数学的分析と **ボンバ**（機械的総当たり装置）で解読に成功 |
| **チューリングの改良** | イギリス・ブレッチリー・パークで **チューリング・ボンバ** を開発。電気機械式コンピュータの先駆とも言える |
| **限界** | ドイツ軍は暗号を継続強化。**海軍用4ローター・エニグマ** は特に困難だったが、暗号書の入手や通信パターン分析で解読を継続 |
| **影響** | 戦争を **2年以上短縮** したとされるが、解読事実は **戦後30年間秘密** に。戦後もエニグマを使い続けた国があり、イギリスは余剰機を同盟国に販売していた |

### コンピュータ時代——DES と公開鍵暗号の革命（1970年代）

#### DES（Data Encryption Standard, 1976年）

| 項目 | 内容 |
|------|------|
| **仕様** | 64ビットのデータを **56ビット鍵** で暗号化（約 **7京通り** の鍵空間） |
| **NSA の関与** | 開発に **NSA（米国家安全保障局）** が関与。バックドア（抜け道）の疑いが生じた |
| **革命的な点** | **アルゴリズムを公開** したこと——**ケルクホフスの原理**（安全性は鍵の秘密にのみ依存すべき）の実践。公開により世界中の研究者が弱点を検証し、安全性が高まる |

#### 公開鍵暗号（1976年〜）

| 項目 | 内容 |
|------|------|
| **従来の共通鍵暗号** | 暗号化と復号に **同じ鍵** を使う。事前に安全な方法で鍵を共有する **鍵配送問題** があった |
| **ディフィー＝ヘルマン（1976年）** | **公開鍵**（誰でも暗号化可能）と **秘密鍵**（復号は本人のみ）を分離。南京錠の比喩——錠は公開、鍵は秘密 |
| **RSA（1977年）** | リベスト・シャミア・アデルマンが開発。**素数分解の困難性** を利用——掛け算は容易だが、大きな数（200桁など）の素因数分解は現行コンピュータでも極めて困難。**HTTPS** などインターネットセキュリティの基盤 |

### 量子コンピュータの脅威とポスト量子暗号（21世紀）

| 項目 | 内容 |
|------|------|
| **量子コンピュータ** | **量子ビット** の重ね合わせにより、従来コンピュータとは根本的に異なる並列計算が可能 |
| **ショアのアルゴリズム（1994年）** | 量子コンピュータで **素数分解を高速化** する手法。十分な性能の量子マシンがあれば **RSA は破られる** |
| **現状** | 2019年に Google が量子超越性を発表したが、**実用的な暗号解読にはまだ性能不足**。10〜20年後は未知数 |
| **ポスト量子暗号** | 量子コンピュータでも解読困難な新方式の研究。**格子暗号**（高次元空間の最短ベクトル問題）、多変数多項式暗号、ハッシュベース署名など |
| **NIST 標準化（2024年）** | 米国国立標準技術研究所が **6年かけて評価** し、ポスト量子暗号の標準化を完了 |

---

### 量子暗号・最新技術

| 技術 | 内容 |
|------|------|
| **量子鍵配送（QKD）** | 量子力学の **観測による状態変化** を利用。盗聴されると量子状態が変わり、受信者が検出可能——理論上は絶対安全だが、光ファイバーの距離制限や装置コストが課題 |
| **墨子号（2017年）** | 中国が量子通信衛星で北京〜ウィーン間の量子暗号通信に成功。地上100kmの限界を宇宙経由で克服 |
| **準同型暗号（2009年）** | クレイグ・ゲントリーが完全準同型暗号を実現。**暗号化したまま計算** が可能——クラウドで中身を見せずに処理できる。計算コストは大きく実用化は途上 |
| **その他** | ブロックチェーン、ゼロ知識証明、動画暗号なども注目分野 |

### 理論上絶対安全な暗号——ワンタイムパッド

- メッセージと **同じ長さの乱数** を使い、**1度しか使えない** 鍵で暗号化する方式。
- **理論的に絶対安全** だが、鍵の配送・管理が現実的でないため実用には向かない。

---

### 暗号の歴史から得られる教訓

1. **完璧な秘密は存在しない**——エニグマも DES も「解読不可能」と思われたが、いずれも破られた。
2. **暗号の強度は時代と共に変わる**——コンピュータの進化（や量子コンピュータ）で、かつて安全だった方式が一瞬で脆弱になる。
3. **暗号は攻撃と防御の永遠の攻防**——新しい暗号が生まれれば新しい解読法も生まれるが、それがコンピュータ科学の進歩を促してきた。
4. **暗号はプライバシーと自由の盾**——独裁下でも自由な通信を可能にする一方、犯罪者にも利用される **両面性** は永遠の課題。

---

### 視聴者への実践的アドバイス

- **弱いパスワード**（`123456`、名前＋数字など）は真っ先に試される。
- **長いパスフレーズ** を使う（例：「私は毎朝6時に起きて東方を遊ぶ」→ `WAM6OKTO` のように変換）。
- **パスワードマネージャー** で複雑なパスワードを管理し、覚えるのはマスターパスワードだけにする。
- **2要素認証（2FA）** を必ず有効にする。
- 暗号の歴史が示すように、**常に最新のセキュリティ対策** を心がけることが重要。
