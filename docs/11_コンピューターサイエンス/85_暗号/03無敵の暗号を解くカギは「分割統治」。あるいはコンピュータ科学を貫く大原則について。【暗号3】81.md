## 要約

**暗号シリーズ第3回の位置づけ**

前回の**ヴィジュネル暗号**（位置ごとにずらし量が変わる多アルファベット暗号）の**解読法**を、クイズ形式でたどる回。結論は **divide and conquer（分割統治）**——電子コンピュータ以前の19世紀、**チャールズ・バベッジ**が紙とペンで見出した手法。全4回のうち第3回。次回（最終回）はRSA・現代暗号などを駆け足で扱う予定。

**前回の宿題と水野の思考**

「周期さえ分かれば総当たりや頻度でいけるのでは」——**分割して統治せよ**という方向性は7割正解（「7割バベッジ」）。ただし周期の特定方法は寝る前には至らず。単語当て（THE、ZAなど）や、ずらし量を一括で戻すシーザー的アプローチでは、ヴィジュネル全体には効かない。

**バベッジとは誰か**

**19世紀**のイギリスの数学者・発明家。チューリングやノイマン（20世紀）より前の「コンピューターの父」の一人。真空管や半導体なしに**歯車の計算機**（差分機関・解析機関）を設計したが、予算打ち切りで完成せず。広い意味ではそろばん・アンティキテラ機械・パスカル計算機も「コンピュータ」。**郵便料金の全国統一**（距離比例より事務コストが重い、という分析）など、ひらめき型の実務改革でも知られる。逸話：大道芸人嫌いで追放運動→家を囲んで爆音演奏される、など（コンピュータ史の本編は別回へ）。

**解読の核心：周期を特定してから分割する**

ヴィジュネルは、鍵の**周期**（例：7, 14, 19の3つを繰り返すなら周期3）が分かれば、実質**複数の単一換字式（シーザー）暗号の束**になる。

**ステップ1——周期の推定（カシスキー的な発想）**

長い暗号文では、**同じ平文の単語**（the、queen など）が、鍵の位相が偶然揃った位置では**同じ暗号文列**になる。見た目はバラバラでも、十分な長さ＋短い鍵（例：20文字の鍵で1000文字）なら、繰り返しは起こりうる。

手順：同じと思われる暗号文列を複数見つけ、**その間の文字数**をすべて数える → 間隔のリストの**公約数**が周期の候補（例：21文字間と49文字間 → 公約数7 → 周期7の可能性）。単語の意味ではなく**算数**で攻めるのがポイント。

**ステップ2——分割統治＋各列への頻度分析**

周期が7なら、暗号文を**7列に縦に積む**（1, 8, 15…列目／2, 9, 16…列目……）。各列はずらし量が一定なので、それぞれ**単なるシーザー暗号**。

ここで決定的な飛躍：**単語や英文として読もうとしない**。列ごとに抜き出した文字列だけに**頻度分析**をかける（Eが最多、など）。26文字の頻度表を当てはめ、列ごとに復号 → 横に並べ直せば平文。第1回の頻度分析の知識があっても、「まず分割する」発想がなければヴィジュネルには届かない——言語好きほど「あり得る綴り」「単語当て」に寄りがちで、この飛躍は難しい、という対比が強調される。

**「無敵」だった理由と限界**

- **繰り返し鍵**が弱点。鍵を暗号文と同じ長さの**真にランダムな列**にすれば原理的には解けない（ワンタイムパッド）が、鍵を届ける労力＝内容を届ける労力になり、実用では意味が薄い。**鍵は短く、秘密に伝えやすく**ある必要がある。
- 鍵伝達の工夫：数字 `7,14,19` → **「hot」**（H=7番目、O=14番目…）、シェイクスピア一節、**May I have a large container of coffee?**（文字数で円周率）のような覚えやすい英文、**書籍暗号**（宣言文の何単語目か、など）——いずれも歴史上試されているが、本質的弱点（周期・繰り返し）の回避にはなりにくい。
- 水野案（文中の `?` で周期変更、コーヒー文でサイン、など）は**小細工**——ルイ15世の「大暗号」のような無意味文字挿入・消去規則も、地道な除去で後世解読された。**改良は積み重ねだが、本質的アイデアで破られる**という史観。

**コンピュータ科学との接続**

バベッジの解法は、問題を小さな同型問題に**分割**し、それぞれ解いて**統合**する——現代のアルゴリズム設計でも中心の **divide and conquer**。電子計算機以前から、この原則が暗号解読に現れている、という回のメッセージ。

**雑談・次回予告**

暗号解読の歴史の多くは言語学者の領域だったが、バベッジは**言語学的当て推量ではなくアルゴリズム**で突破した例。堀本の学生時代の暗号日記（コード＝単語置換、饅頭→小説家デビュー願望など）のネタ、大小文字混在の自作暗号への挑戦状も。最終回でRSA・エニグマなど現代〜未来の暗号へ。
