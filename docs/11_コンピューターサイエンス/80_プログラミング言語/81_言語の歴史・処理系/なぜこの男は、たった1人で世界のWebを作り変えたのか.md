## 詳しい要約

**テーマ：ブレンダン・アイクと JavaScript の 30 年**

1995 年に 10 日間で作られた JavaScript と、その作者ブレンダン・アイクの物語。追い詰められた Netscape の事情から生まれ、妥協の傷（typeof null など）を抱えつつ、命名・Microsoft との争い・ECMA 標準化・Netscape 消滅を経て世界の Web の 98% 以上で動く言語になった経緯と、アイクのその後（Mozilla CEO 辞任、Brave 創業）を 5 章で辿る。

---

### 序章

- JavaScript は世界の Web サイトの **98% 以上** で動く
- 1995 年 5 月 6 日〜15 日の **10 日間**、1 人の男が Netscape のオフィスで書き上げた（Java は 5 年、Rust は安定版まで約 7 年）

### 第1章 なぜ10日で作らなきゃいけなかったのか

- 1995 年の Web はボタンを押しても何も起きない「紙のパンフレットの展示」のような場所だった
- Netscape Navigator のマーク・アンドリーセンは Web が「読むもの」で終わらないと信じていた
- Windows 95 に **Internet Explorer を同梱** しようとする Microsoft の脅威 → ブラウザ内でプログラムが動く世界を先に作らないと会社が終わる
- JavaScript は「作りたかった」からではなく **追い詰められた状況** から生まれた

### 第2章 ブレンダン・アイクという男

- 1961 年生まれ。サンタクララ大学で数学と CS、イリノイ大学で修士号
- Silicon Graphics で 7 年間 OS・ネットワークのコード、MicroUnity でマイクロカーネルや DSP、GCC の移植も → **コンピューターのほぼ全レイヤーを実務で経験**
- 「10 日で作った」は事実だが「10 日だけで作れた」わけではなく、下に 10 年の蓄積がある
- 1995 年 4 月、34 歳で Netscape に入社。口説き文句は「ブラウザに **Scheme** を入れよう」だった

### 第3章 10日間で何が起きたのか

- 入社数週間後、役員から「Scheme はダメだ。Sun と組むことになった。**Java に似た言語** を 10 日で作れ」（Navigator 2.0 ベータに間に合わせるため）。社内コードネームは Mocha
- **見た目は Java**（波括弧・セミコロン）、**中身は Scheme**（関数を値として扱える、クロージャ）、**オブジェクトの仕組みは Self** から借りた混ぜ合わせ
- 本人いわく「Java の可愛い弟でなければならなかった」
- 妥協の例：GC を入れる時間がなく後付け → セキュリティホールの原因に
- **typeof null が "object" を返すバグ**：世界中のサイトが依存した後で、直すと Web が壊れるため手遅れに
- 突貫工事の傷は、Web が大きくなるほど直せなくなる

### 第4章 生まれた瞬間から潜り抜けた嵐

- 9 月のベータでは **LiveScript**、12 月に **JavaScript** へ改名。理由は **マーケティング**（Sun の Java が話題の中心で、対 Microsoft で手を組んでいた）。本人も後に認めている
- 1996 年 8 月、Microsoft が IE 3.0 にリバースエンジニアリングした **JScript** を搭載。微妙な違いのせいで開発者はブラウザごとの分岐を大量に書くことに
- 1996 年 11 月、Netscape が **ECMA** に標準化を依頼 → 1997 年 6 月 **ECMAScript** として最初の標準（ES6 などの ES の由来。JavaScript はブランド名、ECMAScript は仕様名）
- 互換性問題はその後 10 年近く続く
- 1998 年、力尽きた Netscape がブラウザのソースコードを公開 → **Mozilla** プロジェクト（アイクも立ち上げに参加）
- 1999 年 AOL が Netscape を買収、2003 年にブラウザ事業を閉鎖 → **Mozilla Foundation** 設立、Firefox へ

### 第5章 作った男が、作った世界を壊しに戻る

- アイクは長く Firefox の技術的中心人物。2005 年 CTO、2014 年 3 月 24 日に **Mozilla CEO** 就任
- 2008 年にカリフォルニア州のある住民投票へ 1,000 ドルを寄付していたことが問題化。署名 5 万人超、OkCupid が Firefox ユーザーに別ブラウザを推奨する事態に → **わずか 11 日後の 4 月 3 日に辞任**
- 2015 年 **Brave Software** 創業、2016 年に広告とトラッカーを最初からブロックする **Brave ブラウザ** をリリース
- JavaScript や Cookie を作った側の人間が、それを使った **トラッキング広告モデル** を批判。独自の暗号資産 **BAT** で、広告を見たユーザー自身が報酬を得る仕組みも導入
- 結論：彼は 1 人で Web を作り替えたわけではない。10 日で書いたのは「種」で、それを Microsoft との競争、Sun との提携、ECMA 標準化、Mozilla の仲間、世界中の開発者が育てた。だが種がなければ何も始まらなかった

### まとめ

- JavaScript は Microsoft に追い詰められた Netscape の事情から、10 日間で「見た目 Java・中身 Scheme・オブジェクトは Self」として生まれた
- 名前はマーケティング由来、typeof null などの妥協は互換性のため今も残る
- JScript との分裂 → ECMAScript 標準化、Netscape → Mozilla → Firefox という流れ
- アイクは Mozilla CEO を 11 日で辞任し、今は Brave でプライバシー重視の Web を目指している
