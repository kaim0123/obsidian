#コンピュータ

## 詳しい要約

**プログラミング言語** は、人間がコンピュータに指示を出すための **「橋渡し」** である。本動画は **1940 年代の機械語** から **アセンブリ・FORTRAN・COBOL・BASIC・C 言語・オブジェクト指向・Java・C#・Python・Ruby・JavaScript** まで、約 **80 年** にわたる進化を時系列でたどり、各言語が **どの時代の課題を解決したか** を初心者向けに解説する。歴史を知ることで、現代のテクノロジーが **なぜ今の形になったのか** を理解できる。

### なぜプログラミング言語の歴史を知るのか

- 現代のテクノロジー（Web・スマホ・AI・クラウド）は、すべて **プログラミング言語の積み重ね** の上に成り立っている。
- 各言語は **独立して生まれたわけではなく**、前の言語の知恵を受け継ぎながら進化してきた。
- 結局のところ、プログラミング言語の役割は **人間とコンピュータの橋渡し** —— この本質は時代が変わっても変わらない。

### 黎明期：機械語とアセンブリ（1940 年代）

- **機械語**：コンピュータが直接実行できる **0 と 1（数字の羅列）** のみでプログラムを書く方式。1940 年代から使用。
- **アセンブリ言語（1949 年）**：機械語命令を **`MOV`・`ADD`** などの **ニーモニック（記号）** に置き換え、人間が少し理解しやすくした。
- ただしアセンブリも **まだハードウェアに近く難しい** —— より抽象度の高い言語への需要が生まれる。

### コンパイラの登場：FORTRAN（1954 年）

- **FORTRAN**（**FOR**mula **TRAN**slation＝数式翻訳）= IBM が **1954 年** に開発。
- **科学者・エンジニアが普段使う数式** をほぼそのままプログラムに書ける——画期的な高水準言語。
- **コンパイラ**：人間が書いたプログラムを **機械語に変換するソフトウェア**。これにより人間は理解しやすい形でプログラムを書けるようになった。
- FORTRAN コンパイラの性能が優秀で、**手書きの機械語と同等の実行効率** を達成——高水準言語の実用性を証明した。

### ビジネス向け：COBOL（1958 年）

- **COBOL**（**CO**mmon **B**usiness **O**riented **L**anguage＝共通ビジネス指向言語）。
- **英語の文章のように読める** 文法——経理・人事など **非エンジニアでも書ける** 設計。
- 例：`MULTIPLY PRICE BY QUANTITY GIVING TOTAL` のような記述。
- **信頼性が高く大量データ処理に強い** ため、**今も世界中の基幹系**（銀行 ATM、航空会社予約システムなど）で稼働中。

### 初心者の扉：BASIC と REPL（1964 年）

- **BASIC**（**B**eginner's **A**ll-purpose **S**ymbolic **I**nstruction **C**ode）= ダートマス大学が **プログラミング未経験の学生** 向けに開発。
- **行番号を使った単純な構文** と **対話的な実行環境** が特徴。
- **REPL**（**R**ead **E**val **P**rint **L**oop＝読む・評価する・表示する・繰り返す）の先駆け——プログラムを書いて **即座に結果を確認** できる環境。
  - 例：Python の対話環境で `1+2` と入力すればすぐ `3` と表示される。
  - **学習・実験・デバッグ** に最適。Python・JavaScript・Ruby・Rust など現代の言語でも REPL が標準装備。
- BASIC の考え方は後の言語に **大きな影響** を与えた。

### 革命：C 言語と UNIX（1970 年代）

- **デニス・リッチー**（ベル研究所）が開発した **C 言語** は「本当の革命」。
- **高水準言語なのに低レベルの制御も可能** —— 人間にも分かりやすく、かつコンピュータの細かい部分まで制御できる。
- **UNIX オペレーティングシステム** が C 言語で書き直されたことで、**異なるコンピュータへの移植** が劇的に容易になった（それ以前 OS は専用の機械語で書かれることが多かった）。

### パラダイムの転換：オブジェクト指向（1980 年代）

- **オブジェクト指向プログラミング（OOP）**：プログラムを **部品化して再利用しやすくする** 考え方。
  - 例：「霊夢」という **クラス** を作れば、巫女・赤白の服（特徴）やお祓い・無双封印（できること）を **まとめて扱える**。
- 代表的な言語：
  - **C++** —— C 言語の機能を保ちながら OOP を実現。今も **ゲームエンジン** や高速処理が必要なソフトで使用。
  - **Objective-C** —— Apple 系開発で長く使われた。

### Java 時代：Write Once, Run Anywhere（1990 年代）

- **Java**（サン・マイクロシステムズ）= 1990 年代の主役。**Write Once, Run Anywhere**（一度書けばどこでも動く）がキャッチフレーズ。
- **JVM**（Java Virtual Machine＝Java 仮想マシン）の仕組み：
  1. Java プログラムは **バイトコード**（JVM 専用の中間言語）にコンパイルされる。
  2. バイトコードは **特定の CPU や OS に依存しない** 形式——これが WORA の核心。
  3. JVM が **4 つの主要機能** を提供：
     - バイトコードの **解釈と実行**
     - **メモリ管理とガベージコレクション**（使わなくなったデータを自動削除）
     - **セキュリティ管理**
     - **マルチスレッド処理**
- **Windows・Mac・Linux** すべてで同じ Java プログラムが動作——インターネット普及とともに **大規模企業システム** で広く採用。

### Microsoft の回答：C# / .NET

- **C# / .NET** = Microsoft が **Java に対抗** するために 1990 年代後半に開発、**2002 年** に初版リリース。
- **.NET フレームワーク**：様々なプログラミング言語を統合できる **プラットフォーム**。**C#** が中心的な言語。
- **主な用途**：Windows アプリ、ゲーム開発（Unity）、Web 開発、企業システム。**Xbox ゲーム** やビジネス向け Web アプリで強い。
- **Java との違い**：型の扱いや言語機能に若干の差。**Windows 環境により最適化** されているが、近年は **オープンソース化** しクロスプラットフォーム対応も進展。

### 人間に優しい言語の時代（2000 年代〜）

| 言語 | 開発者 | 特徴 | 主な用途 |
|------|--------|------|---------|
| **Python** | グイド・ヴァン・ロッサム | **読みやすさ** を最重視。インデントでブロックを表現、英語っぽい文法 | **データ分析・AI 開発** |
| **Ruby** | 松本行弘（日本人） | **プログラマーの生産性と幸せ** を目指して設計 | **Web 開発**（Ruby on Rails） |
| **JavaScript** | ブレンダン・エイヒ | 当初は **ブラウザ上の簡単なスクリプト** だったが、今や **フロントエンド開発の標準**。**Node.js** によりサーバーサイドでも使用可能 | **Web 全般**（フロント・バックエンド） |

### 未来の言語

- **AI・クラウド** の発展により、新しいニーズに応える言語が増えている。
  - **Rust** —— **高速で安全** なシステムプログラミング言語。
  - **Kotlin** —— **Java をモダンにした** JVM 言語。
- ただし **基本的な考え方は変わらない** —— 人間とコンピュータの橋渡しという役割は不変。先人の知恵は受け継がれ続ける。

### キーワード一覧

| キーワード | 意味 |
|-----------|------|
| **機械語** | コンピュータが直接理解できる 0 と 1 の数字列 |
| **アセンブリ言語** | 機械語を人間が理解しやすい記号（ニーモニック）に変換した言語 |
| **コンパイラ** | 高水準言語のプログラムを機械語に変換するソフトウェア |
| **高水準言語** | 人間が理解しやすい形でプログラムを書ける言語（FORTRAN、C、Python など） |
| **REPL** | Read-Eval-Print-Loop。対話的にコードを入力し即座に結果を確認できる環境 |
| **オブジェクト指向** | プログラムを部品（オブジェクト）として設計し、再利用しやすくする考え方 |
| **JVM** | Java Virtual Machine。バイトコードを解釈・実行し、OS 非依存の実行環境を提供 |
| **ガベージコレクション** | 使わなくなったメモリを自動的に回収する仕組み |
| **Write Once, Run Anywhere** | Java のスローガン。一度書いたプログラムをどの OS でも動かせる |

### まとめ

- プログラミング言語の歴史は **コンピュータと人間の関係を深めてきた** 80 年の物語。
- **機械語 → アセンブリ → FORTRAN → COBOL → BASIC → C 言語 → オブジェクト指向 → Java → Python・Ruby・JavaScript** と、それぞれが **時代ごとの課題**（効率・ビジネス・教育・移植性・再利用・クロスプラットフォーム・読みやすさ）を解決してきた。
- 未来の言語も **より便利・安全・効率的** になっていくだろうが、**橋渡し** という本質は変わらない。
- 歴史を知ることで、今の技術が **より面白く** 感じられ、これからの進化も **楽しみ** になる。
