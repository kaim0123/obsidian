## 詳しい要約

**テーマ：C# の誕生と進化、そして双子の VB.NET との運命の分かれ目**

C# は Microsoft と Sun Microsystems の Java をめぐる法廷闘争の敗北から生まれ、LINQ・async/await・Unity を通じて世界の主要言語に育った。同時に生まれた VB.NET は進化で後れを取り、2023 年に「新構文を追加しない」と決定された。言語の運命は技術の優劣だけでなく、開発元の戦略と「進化し続けるかどうか」で決まる、というのが結論。

---

### 第1章 Java との決裂から始まった C# の誕生

- 1990 年代後半、Java は「**Write Once, Run Anywhere**」で爆発的に普及。
- Microsoft は独自の Java 仮想マシンを Windows に組み込み、**Windows 専用の独自拡張**を加え始めた。
- これに Sun Microsystems が激怒して法廷闘争に。Microsoft は **2000 万ドル以上の和解金**を払い、独自拡張をやめることになった。
- そこで「自分たちで最高の言語を作る」と判断。Borland から引き抜いた **アンダース・ヘルスバーグ**（Turbo Pascal・Delphi の生みの親、のちに TypeScript も設計）に開発を任せた。
- 1999 年にコードネーム **COOL**（C-like Object Oriented Language）で開始、2000 年に C# として発表。名前は C++ の「++」をさらに重ねて「#」に見立てたもの。
- 単なる Java のコピーではなく、**Java・C++・Delphi の長所を取り込んだ**言語として設計された。

### 第2章 C# が起こした「革命」

- **LINQ**（C# 3.0）：データベースへの問い合わせを C# の文法の中で書けるようにした。
- **async/await**（C# 5.0）：非同期処理を同期処理と同じくらいシンプルに書ける仕組み。後に JavaScript・Python・Rust などにも採用され、事実上の世界標準になった。
- 他言語の良いところ取りで生まれた C# が、**他言語に影響を与える側**に回った。
- **Unity**（2005 年登場のゲームエンジン）が C# を主要言語に採用し、ゲーム開発者に一気に広がった（ポケモン GO も Unity）。

### 第3章 VB.NET との「運命分岐」

- VB.NET は Visual Basic を .NET Framework 向けに作り直したもの。2002 年に C# と一緒にリリースされ、**同じ実行環境・同じライブラリ**で同じことができる「双子」だった。
- 違いは文法の思想：VB.NET は `If ... Else`、`For ... Next` など**自然な英語に近い書き方**、C# は C や Java に近い**波かっこ・セミコロン**の世界。
- 2000 年代前半は VB6 からの流れで **VB.NET のほうがシェアが大きかった**。日本でも銀行の内部ツールや製造業の生産管理など、VB 系システムが今も多く稼働している。
- しかし C# はジェネリクス・LINQ・ラムダ式・async/await・パターンマッチングと毎年のように進化。VB.NET にも同じ機能は入ったが**常に C# より遅れ**、.NET Core の初期は C# と F# だけがサポートされ VB.NET は後回しにされた。

### 第4章 2023 年の「決定」

- 2023 年 2 月、Microsoft は .NET の 3 言語の方針を発表：**C# は最先端であり続けるために進化**、**VB.NET は新しい言語構文を追加せず安定性を重視**。
- 業界は「開発言語としての役割は終わった」と受け止めた。保守・改修案件は残るが、新規案件はほぼゼロ。COBOL と同じ道を歩み始めている。
- VB.NET のエンジニアや言語自体に問題があったわけではなく、**Microsoft が C# に全力を注ぐと決めただけ**。コミュニティからは反発も多かったが、判断は変わらなかった。
- 教訓：言語を選ぶときは、今人気かどうかだけでなく**開発元がどれだけ本気で投資しているか**を見る必要がある。

### 第5章 C# の「次の 25 年」

- C# は今もバージョンを重ね、Stack Overflow 調査でも世界 5 番目に使われる言語として安定している。
- 2016 年、Microsoft は Windows 専用だったフレームワークを**オープンソース化・クロスプラットフォーム化**（.NET Core）し、Linux や macOS でも動くようにした。**Xamarin 買収**で iOS・Android アプリも作れるようになった。
- 皮肉にも、Java に対抗して生まれた C# が Java のスローガン「Write Once, Run Anywhere」を実現し始めている。
- ヘルスバーグは **Turbo Pascal → Delphi → C# → TypeScript** と 40 年にわたり言語を設計してきた。TypeScript には C# の DNA が流れている。

### まとめ

- C# は Java をめぐる法廷闘争の敗北から生まれ、LINQ・async/await・Unity で主要言語に成長した。
- 双子の VB.NET は進化速度の差で格差が開き、2023 年に事実上の進化終了が決まった。
- 言語の命運は開発元の戦略で決まることがあり、**進化を止めた瞬間にレガシーへの道が始まる**。
