## 詳しい要約

**テーマ：「玩具」と呼ばれた JavaScript の黒歴史と復活**

今や最も使われている JavaScript も、かつては「まともなエンジニアは使わない玩具」だった。10 日間での誕生、カオスな仕様、ブラウザ戦争という黒歴史を経て、V8 と Node.js で評価が一転した。奇妙な仕様にはたいてい歴史的な理由がある。

---

### 誕生の黒歴史：10 日で作られた言語

- 1995 年、**Netscape** がブラウザで動く言語を求め、**ブレンダン・アイク**に作らせた。期間はわずか **10 日**（Microsoft との競争で焦っていた）
- アイクは **Scheme** に影響を受けた関数型の言語を作りたかったが、上から「**Java に似せろ**」と言われ、見た目も名前も Java 風に
- Java とはまったく違う言語なのに、今も「Java と JavaScript は同じですか？」という混乱を生んでいる

### カオスな仕様（10 日で急いだ結果）

| 例 | 挙動 | 問題 |
|---|---|---|
| `==` | 型を自動変換して比較（`"1" == 1` が true） | バグの温床 → 今は `===` を使えと言われる |
| `typeof null` | `"object"` を返す | バグだが直すと既存コードが壊れるため放置（バグが仕様に） |
| `NaN === NaN` | false | 自分自身と等しくない唯一の値 |
| `"11" + 1` / `"11" - 1` | `"111"` / `10` | 足し算は文字列結合、引き算は数値計算で一貫性がない |

### ブラウザ戦争という暗黒時代

- 1990 年代後半〜2000 年代前半、Netscape と Internet Explorer がそれぞれ**独自機能**を追加
- 同じコードがブラウザによって動いたり動かなかったりし、両対応のために**二重にコード**を書く必要があった
- 2000 年代前半の JavaScript は「玩具」「素人の言語」とサーバーサイドのエンジニアから見下されていた

### 復活の転機

- **2008 年**：Google が Chrome を発表。高速な **V8** エンジンで実行速度が劇的に向上
- **2009 年**：**Node.js** 登場でサーバーサイドでも動くようになり、フロントエンドもバックエンドも同じ言語で書けるように → 評価が一転

### まとめ

- 10 日で作られ黒歴史だらけの言語が、今は世界で一番使われている
- 「なぜこんな仕様なのか」と思ったら、たいてい歴史に理由がある
