## 詳しい要約

**テーマ：Javaが嫌われ続けながら生き残る理由と「Jabol論」の検証**

Javaは20年以上前から「終わる」と言われながら、銀行・保険・官公庁のシステムを支え続けている。嫌われる原因は、冗長な書き味やアプレット時代の悪印象、そして何よりOracleの訴訟・課金への不信にある。「JavaはCOBOLの再来（Jabol）」という指摘は構造としては一理あるが、Javaは半年ごとに進化しており言語単体で見れば当たらない、という話。

---

### 第1章 冗長で迷惑で危険 ― 言語そのものへの不満

- 1995年、Sun Microsystems の **ジェームズ・ゴスリン** が開発。「Write Once, Run Anywhere」（JVMさえあればどこでも動く）は当時革命的
- **冗長性**：1行出力するのにクラス定義と main メソッド宣言が必要（Pythonなら1行）。Spring の `AbstractSingletonProxyFactoryBean` のような長いクラス名はJava文化を象徴するジョークに
- **アプレット時代のトラウマ**：頻繁な更新通知（Askツールバーの同梱チェックまで）、脆弱性の温床で、2013年1月には US-CERT がブラウザのJavaプラグイン無効化を勧告
- 不人気の土台は言語仕様の欠陥というより、書き味と時代の印象の蓄積

### 第2章 本丸はOracle ― 訴訟と従業員数課金

- 2010年、Oracle が Sun を74億ドルで買収
- **停滞**：Java 6（2006年）から Java 7（2011年）まで5年間メジャーアップデートなし（スマホとクラウドで業界が最も動いた時期）
- **訴訟**：2010年、OracleがAndroidのJava API無断利用でGoogleを提訴（請求最大約90億ドル）。2021年4月、米最高裁がGoogleの利用をフェアユースと認め、11年の争いが決着
- **課金**：2019年1月、Java 8 の商用アップデートを有償化。2023年1月、Java SE ライセンスが **全従業員数課金** に（999人以下で1人月15ドル、Javaを触らない経理や営業の分まで）
- Gartner試算でコストは2〜5倍、調査ではOracle Javaユーザーの9割が脱Oracleを検討（ドイツでは95%）
- 嫌われているのはJavaという言語というより、**Oracleという管理人**

### 第3章 Jabol論 ― JavaはCOBOLの再来なのか

- COBOL（1959年生まれ）は推定8000億行が稼働し、誰も新規では選ばないが消せない
- Javaも同じ道：メガバンクの勘定系周辺、保険の契約管理、官公庁システムなどに2000年代の巨大Java資産が動き続け、SIer案件は保守・改修ばかり
- 2019年の Google I/O で **Android は Kotlin ファースト** を宣言 → 攻めの領域から撤退し守りの領域に残る
- 若手が選ばない → 求人が保守案件ばかり → さらにCOBOL化、という循環。Jabol論は悪口というより「成功した言語だけが辿る構造」の指摘

### 第4章 反論 ― 半年ごとに進化する古株

- 2017年の **Java 9** からリリースが **6か月ごとの固定サイクル** に（Pythonの年1回より速い）
- Java 16 で **record 型**（定型文の山だったデータクラスが数行に）、2023年9月の Java 21 で **Project Loom の仮想スレッド** が正式導入（数百万の並行処理を軽量に）
- Oracle課金にも出口：**OpenJDK** と Eclipse Temurin・Amazon Corretto などの無料ディストリビューション。脱Oracle組もJavaを捨てず、Oracle以外のJavaへ移っている
- COBOLは書ける人が減り言語の進化も止まったが、Javaは開発が活発で開発者人口は1000万人規模 → Jabol論は言語単体で見れば当たっていない

### 最終章 「嫌われる言語」とは何なのか

- 嫌われる言語の常連（Java・PHP・JavaScript）の共通点は **世界で最も使われている** こと。使う人がいない言語は嫌われようがない＝憎まれ口の総量は普及の証明
- キャリアの視点：COBOLエンジニアは人材枯渇で単価が上がり続けている。Javaも巨大資産が何十年も動き続けるので、読める人の価値は下がらない
- 「流行に張る戦略」と「残るものに張る戦略」がある。嫌われているからやめる、は判断として浅いかもしれない

### まとめ

- Java嫌いの正体は、冗長さ・アプレットの悪印象と、Oracleの停滞・訴訟・従業員数課金への不信
- Jabol論は構造としては当たる面があるが、半年ごとのリリースや OpenJDK により言語自体は活発に進化している
- 「嫌われる」は「大量に使われている」の裏返しで、残る技術に張るキャリア戦略もある
