## 詳しい要約

本動画は、**世界史・日本史の流れ** と **コンピュータ・プログラミング言語の発展** を並行してたどる、約 50 分の総合解説である。単に言語を年代順に並べるのではなく、**通信技術の進歩**、**戦争と冷戦**、**企業間の競争**、**インターネットとスマートフォンの普及** といった社会背景と結びつけて、各言語が **なぜ・いつ・どの文脈で生まれたか** を説明する。なお、動画説明欄にあるとおり **誤情報を含む旧版** であり、訂正版作成予定である点に留意すること。

### 動画の構成と主旨

- 江戸時代の日本文化から始まり、ヨーロッパの産業革命・植民地時代、両世界大戦、冷戦、PC 革命、Web 時代、スマホ時代、AI 時代までを一気通貫で扱う。
- **低水準言語**（機械語・アセンブリに近いもの）と **高水準言語**（人間が理解しやすいもの）の対比を軸に、言語の「世代」も説明する。
- 最終メッセージは、「言語は目的のための **道具** にすぎない。好きな言語の歴史を振り返ってみよう」というもの。

### コンピュータ誕生以前（17〜19 世紀）

| 年代 | 出来事 | プログラミングとの関係 |
|------|--------|----------------------|
| **1642 年頃** | フランスのパスカルが **パスカリーヌ** を発明 | 現存する最古の計算機。父の税務業務向け。プログラミングと不可分の系譜の起点 |
| **1837 年頃** | チャールズ・バベッジが **解析機関（アナリティカル・エンジン）** を構想 | 穿孔カードで演算を制御する設計。コンピュータの原型 |
| **1840 年代** | **エイダ・ラブレス** が解析機関の解説書を執筆 | 穿孔カードによる演算手順を記述。**世界初のプログラマ** とされる（当時は言語も実機も未完成） |

- この時代、まだ **プログラミング言語は存在しない**。解析機関も完成せず、プログラマだけが先に誕生した、という皮肉な状況が語られる。
- 通信面では、電信・電話の発明が後のコンピュータネットワークと深く結びつく。**ベル研究所**（グラハム・ベル由来）と **IBM**（穿孔カード・国勢調査処理から成長）が、ハードとソフト両面で後世に大きな役割を果たす。

### 第二次世界大戦とコンピュータの実用化

- **エニグマ暗号** の解読に向け、イギリスの **アラン・チューリング** が **チューリングマシン** を構想——現代コンピュータの理論的基盤。
- 終戦後、アメリカで爆弾の軌道計算などにコンピュータ開発が進み、**ジョン・フォン・ノイマン** が関与。
- **1946 年**、世界初のプログラム可能な汎用電子計算機 **ENIAC** が発表。当時は一室に収まらない巨大装置。
- **トランジスタ** の発明（ショックレーほか、ベル研究所）によりコンピュータは小型化し、やがてスマートフォン・スマートウォッチへとつながる。

### 高水準言語の黎明期（1950〜60 年代）

| 言語 | 年代 | 開発者・背景 | 特徴 |
|------|------|-------------|------|
| **Plankalkül** | 1940 年代（WWII 中） | ドイツ・コンラート・ツーゼ | 初の高水準言語とされるが、戦時の情報統制で普及せず |
| **FORTRAN** | **1954 年** | IBM・ジョン・バクサス | 科学技術計算向け。長年改良され現役 |
| **ALGOL 58 → ALGOL 60** | 1958〜60 年 | 欧州の研究者 | `begin`〜`end`、`if`・`for` による構造化プログラミングの源流 |
| **Lisp** | 1958 年頃 | アメリカの数学者 | 数式記法由来。時代の流行に左右されず論理で進化 |
| **COBOL** | 1959 年頃 | グレース・ホッパーほか | 英語に近い自然な記述。ビジネス向け |
| **RPG** | 1960 年代 | IBM | 人間の言語に極めて近い記述。第 4 世代言語の先駆けと位置づけ |

- 第 1 世代＝機械語、第 2 世代＝アセンブリ、第 3 世代＝FORTRAN・COBOL など、という世代区分も紹介される。
- **第 1 次 AI ブーム** が起こるが、FORTRAN は学生には難しすぎたため、**BASIC**（ダートマス大学）が教育向けに開発される。
- **PL/I** は COBOL と FORTRAN の両方の役割を担う万能言語として設計。**Simula**（ノルウェー、ALGOL 由来）はシミュレーション言語として登場。

### 冷戦・宇宙開発と C 言語の時代（1960〜70 年代）

- **1969 年** アポロ 11 号の月面着陸。宇宙船は信頼性重視で低性能コンピュータを搭載——月面着陸と言語史は直接関係薄い、という注も入る。
- スイスの **Pascal**（ALGOL 由来）が誕生。300 年前のパスカリーヌの名を受け継ぐ、シンプルで汎用的な言語。
- アメリカでは軍事協力のため **ARPANET**（インターネットの起源）が東西を結ぶ。
- ベル研究所の **ケン・トンプソン** が英国の BCPL を参考に **B 言語** を作成し、**デニス・リッチィ** が改良して **C 言語** が誕生。
- **UNIX** との強い結びつきにより、多くの企業が UNIX に依存し **C の覇権** につながる。ただし C はすぐに有名にならず、当時のキーボードでは `{}` などの記号入力が難しかった、という逸話も紹介される。
- **オブジェクト指向** の思想が登場。**Prolog**（AI・言語処理）、**ML**（数学的証明）もこの時期に開発。
- **ビル・ゲイツ**（Microsoft 設立）と **スティーブ・ジョブズ**（Apple Computer 設立）が西海岸で活躍し、パーソナルコンピュータ時代の幕が開ける。

### パソコン革命とオブジェクト指向言語（1970〜80 年代）

- IBM が PC 市場に参入し、交渉がまとまらず **マイクロソフトに OS 開発を依頼**——後の Windows 帝国への布石。
- フランスの **Ada** 言語が軍事・各種分野で採用（4 色チーム競争の緑チームが勝利、というエピソード）。
- 大学間ネットワーク **CSNET**・**BITNET**（米国）、**EUnet**（欧州）が形成される。
- ベル研究所の **ビャーネ・ストロヴストルップ** が C にオブジェクト指向機能を追加し **C++** が誕生。
- **ブラッド・コックス** は C を改変せず、Smalltalk に C を統合する **Objective-C** を開発。C++ と Objective-C は互いに干渉しない拡張のため、**Objective-C++** として併用可能。
- **MATLAB**（スタンフォード大学・クレーブ・モラー）が商用化。**第 2 次 AI ブーム** が世界的に到来。
- **Eiffel**（ベルトラン・メイヤー）がオブジェクト指向を体系化。GUI 時代の到来で **Macintosh** と **Windows** が競合。
- Apple は Pascal 系を **Object Pascal** へと発展させるが、開発環境名と言語名の混同で混乱が生じる（後述）。

### インターネット・Web 時代（1990 年代）

- **Perl**（ラリー・ウォール）が C で難処理を事前に用意し、**書いてすぐ動かせる** スクリプト言語として普及——**インタプリタ言語** の台頭。
- **Python**（シンプルさ重視）、**Visual Basic** → **VBA** も登場。
- フィンランドの **リーナス・トーバルズ** が **Linux** を独自手法で開発し、オープンソースとして配布——IT 世界全体に衝撃。
- **HTML**（ティム・バーナーズ＝リー）が Web の基盤技術として普及。特許を取らず誰でも自由に使える設計。
- ニュージーランドの **R 言語**（S 言語の模倣）、ブラジルの **Lua**（ゲームエンジン連携）も開発。
- 商用インターネットが認可され、**Yahoo**・**Amazon** など Web サービスが急増。
- **第 1 次ブラウザ戦争**：Netscape Navigator vs Internet Explorer（Windows 95 同梱）。
- **Java** と **JVM**（サン・マイクロシステムズ・ジェームズ・ゴスリン）——機種ごとにコードを書き分ける必要がなくなる。**Java アプレット** でブラウザ上実行も可能に。
- Microsoft は **JScript**（IE 向け）を開発。ECMA による **ECMAScript** 標準化も進むが、IE の市場支配で Netscape は敗退。
- **Flash**（マクロメディア→Adobe）が Web リッチコンテンツの主流に。
- 日本発の **Ruby**（まつもとゆきひろ）——Perl・Python と同系統だが「コーディングを楽しく」する設計と徹底したオブジェクト指向が特徴。LAMP の **P** に加えられる（**P**erl、**P**ython、**P**HP に続く **P** 言語）。
- **PHP/FI**（ラスマス・ラードフ）が Web 特化言語として登場。**LAMP**（Linux + Apache + MySQL + PHP）環境が完成し、ライセンス料なしで Web サービスを構築可能に。
- **Delphi** と **Object Pascal** の名称混乱：Delphi 専用言語として一時「Delphi 言語」と呼ばれたが、現在は再び **Object Pascal** と呼ばれる。

### 2000 年代：Y2K、C#、フレームワーク、第 2 次ブラウザ戦争

- **Y2K 問題**（2000 年問題）：年の 2 桁表記による誤動作の懸念。エンジニアの努力で大事故は回避。
- **D 言語**（C の後継候補）、**C#**（Microsoft・アンダース・ヘルスバーグ。C++++ の流れから C# と命名）が登場。
- **Groovy**・**Scala** など JVM 上で動く言語が増加。
- **Ruby on Rails**（デンマーク・デビッド・ハネイソン）がスタートアップに人気。**Django**（Python、オランダ）も Web 開発フレームワークとして台頭。
- **Unity** ゲームエンジン（当初は C#・UnityScript・JavaScript・Boo から選択可能だったが、9 年後 **C# のみ** に統一）。
- **Google** の高品質検索と **Google Maps** の Ajax 技術が JavaScript の可能性を再評価させ、サーバー側の **Python** 人気も上昇。
- **第 2 次ブラウザ戦争**：IE の脆弱性と開発停滞を機に、Firefox・Safari・Chrome などが参戦。
- **iPhone（2007）** → OS X ベースの iPhone OS → **iOS**。開発言語は **Objective-C**。
- **Android**（Linux ベース、開発言語は Java）。Facebook・Twitter のネイティブアプリ化で Objective-C と Java の需要が増加。
- **Node.js**（ライアン・ダール、V8 エンジンをブラウザ外で実行）——JavaScript がサーバー側にも進出。**MongoDB**・**Express**・**jQuery** など周辺技術も登場。
- **Go**（ロブ・パイク・ケン・トンプソン・ロバート・グリーズマー、Google）——C++ への不満から生まれた。
- **Dart**（Google）など **AltJS**（JavaScript を避けたい層向け）が登場するが、評価は分かれる。

### 2010 年代：クラウド、TypeScript、Rust、AI 第 3 波

- **Kotlin**（JetBrains）、**Ceylon**（Red Hat）、**Laravel**（PHP 向けフレームワーク）などが登場。
- **Chrome** が全環境に展開され、**第 2 次ブラウザ戦争の勝者** が決定。
- **TypeScript**（アンダース・ヘルスバーグ）が控えめな AltJS として成長。**React** と **JSX** の組み合わせで **MERN スタック**（MongoDB + Express + React + Node.js）が完成——**JavaScript だけで Web アプリを作る** 環境が整う。
- **クラウドコンピューティング**（AWS・Azure・Google Cloud）と **Docker** により、個人がサーバーを用意する必要が減少。**マイクロサービス** の潮流で **Go** と **Spring Boot**（Java）が好まれる。
- **Swift**（Apple、Chris Lattner 設計）が Objective-C に代わる iOS 開発言語に。**Rust 1.0**（Mozilla）が C/C++ の更新に挑戦。**Zig** も Rust と競合する形で開発開始。
- **ECMAScript 2015**（ES6）で JavaScript 本体が大幅進化。CoffeeScript や Dart の採用は減少し、**TypeScript** だけが伸び続ける。
- **第 3 次 AI ブーム**：チェス・オセロで AI が人間に勝利。画像認識がスマホに搭載可能に。**Python** が AI 開発のデファクトスタンダードに。R 言語から Python へのシフトも進行。
- **ポケモン GO**（Niantic・任天堂・ポケモン）が AR/VR への関心を一気に高め、**Unity** が再注目される。**Flutter**（Google、Dart 採用）もクロスプラットフォーム開発の選択肢に。
- **Kotlin** が Android の Java 後継に選ばれる（Swift との統一構想もあったが、Java 開発者を置き去りにしない方針が優先）。
- Oracle による Java 有料化の噂など、Java の立ち位置が揺らぐ。**Julia 1.0**（2018）が AI ブームで注目を集めるが、Python からの乗り換えにはまだ時間がかかる可能性。
- **量子コンピュータ** 研究（IBM の Qiskit、Google の Cirq）が次の技術革命の候補に。

### 2020 年代：コロナ、ChatGPT、Mojo

- **新型コロナ** によるリモートワーク普及で、副業としてプログラミングを始める人が急増。**Python** が学習・実用の第一選択になりやすい。
- **ChatGPT**（2022〜）の性能向上により、文章要約から **コード生成** まで実用段階に。プログラミング言語との親和性が話題に。
- **Mojo**（Chris Lattner）が AI 開発向けの新言語として登場——**第 3 次 AI ブーム** が「AI 開発戦争」のフェーズに入ったとされる。
- 今後 C・Java・Python のような「巨大言語」がまた現れるかは不明だが、**言語はあくまで目的のための道具** である、という結論で締めくくられる。
