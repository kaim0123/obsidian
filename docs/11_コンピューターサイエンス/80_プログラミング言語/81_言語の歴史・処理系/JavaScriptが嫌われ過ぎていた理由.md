## 詳しい要約

**テーマ：世界一嫌われ、世界一使われる言語 JavaScript の 30 年**

JavaScript は「嫌いな言語」の常連でありながら、Stack Overflow 2025 年開発者調査で使用率 66% の首位。10 日間の突貫開発に始まり、玩具扱い・ブラウザ分裂・仕様の欠陥で嫌われたが、jQuery・V8・Node.js で基盤の座に就いた。今も嫌われるのは、憎しみの標的がエコシステムに移ったことと、Web では「選べない言語」だからだと論じる。

---

### 第 1 章：10 日間で作られた言語

- 1995 年 5 月、ブラウザ市場の 8 割を握っていた **Netscape** に入社した 33 歳の **ブレンダン・アイク**に「ブラウザで動く簡単なスクリプト言語を**10 日**で作れ」という指令
- 1995 年 12 月の Navigator 2.0 搭載が先に決まっており、逆算するとそれしか時間がなかった。ほぼ不眠で心臓部を書き上げた
- 名前は Mocha → LiveScript → 正式発表直前に **JavaScript** へ改名。Sun と提携していた Netscape が、当時最大の流行語 Java の「弟分」に見せる**マーケティング**のため
- 以来 30 年、「Java と JavaScript はメロンとメロンパンくらい違う」と説明し続けることに

### 第 2 章：玩具・危険物・分裂の三重苦

- 最初の 10 年の嫌われ方は言語より**使われ方**。90 年代後半の用途はマウスカーソルを追うアニメーションや勝手に開くポップアップ広告
- セキュリティ面でも危険物扱いで、スクリプトをオフにするのが上級者のたしなみとされた
- Netscape と Microsoft の覇権争いで、Microsoft は互換実装 **JScript** を独自に作成 → ブラウザ判定をして処理を 2 通り書く「同じものを 2 回作る仕事」
- 1997 年に **ECMAScript** として標準化されたが実装の分裂は止まらず、2000 年代前半まで「まともなソフトウェアを書く言語」とは思われていなかった

### 第 3 章：仕様そのものへの憎しみ

- `==` の比較：空文字列と `0` は等しい、`0` と `"0"` も等しいのに、空文字列と `"0"` は等しくない。型を勝手に変換して比べるため一貫性がない → 実務の鉄則は「**`===` を使え**」
- `typeof null` が `"object"` を返すのは最初の実装のバグがそのまま仕様として固定されたもので、直すと既存コードが壊れるため 30 年直せていない（**後方互換の呪い**）
- 2012 年、ゲイリー・バーンハートの 4 分間のライトニングトーク「**Wat**」が奇妙な挙動（空配列 + 空配列 = 空文字列など）を実演し、JavaScript 嘲笑文化の決定版に
- 2008 年、ダグラス・クロックフォードの『**JavaScript: The Good Parts**』は良い部分だけで約 170 ページ。「悪い部分を避ければ美しい言語」という主張が風向きを変えた

### 第 4 章：王座への 3 段ロケット

| 年 | 出来事 | 効果 |
|---|---|---|
| 2006 | ジョン・レシグの **jQuery** | ブラウザ差異をライブラリで吸収し「2 回作る仕事」を終わらせた |
| 2008 | Google の **V8** エンジン（Chrome） | 実行速度が桁違いに向上し「遅い玩具」の前提が崩れた |
| 2009 | ライアン・ダールの **Node.js** | サーバーでも動き、フロントとサーバーを同じ言語で書けるように |

- 2007 年のジェフ・アトウッドの予言「JavaScript で書けるアプリはいずれ必ず JavaScript で書かれる（Atwood の法則）」は的中し、VS Code や Slack も JavaScript 技術で動く
- 言語側も **ES2015** でクラス・モジュール・変数宣言を改善、2012 年には Microsoft のアンダース・ヘルスバーグが **TypeScript** を作り型がない弱点に蓋をした → 仕様レベルの悪口はかなり解決済み

### 最終章：それでも嫌われ続ける理由

- 憎しみの標的が言語から**エコシステム**へ移動
  - 2016 年の **left-pad 事件**：文字列の左を埋めるだけの 11 行のパッケージが作者の抗議で削除され、世界中のビルドが連鎖的に止まった
  - React・Vue・Svelte やビルドツールの主役が数年ごとに交代し、「**JavaScript 疲れ**」という言葉が生まれた
- 構造的な理由：ブラウザで動く言語が実質これしかなく、Web に関わる全員が**強制的に触る**。Python や Rust は好きな人が選んで使うので悪口を言う母数が小さい → 使用率 1 位と嫌われ度 1 位の両立は**独占の代償**
- アイクは後年「自分がやらなければもっとひどい何かがブラウザに乗っていた」と振り返る。完璧を目指して 2 年かけていたら席は他に奪われていた — 速さと不完全さがセットで歴史を作った

### まとめ

- 嫌われる理由は時代ごとに変化：初期は使われ方とブラウザ分裂、次に仕様の欠陥、今はエコシステムの騒がしさ
- jQuery・V8・Node.js の 3 段ロケットで玩具から基盤へ成り上がった
- 嫌われている数は使われている数の裏返し。Web で「選べない言語」であることが両方を生んでいる
