# UNIX・Linux・Windows

> **この章を読むと分かること**
> - 「UNIX」「Linux」「macOS」「Android」「iOS」… これらすべてが親戚関係にある衝撃
> - UNIXは **ゲームを動かしたいから生まれた** という意外な真相
> - GNU と Linux の関係（「GNU's Not Unix」のダジャレ）
> - Windows 95 がなぜ「OSなのに発売日に深夜行列」を作ったのか
> - 「UNIX 哲学」のラーメン二郎との奇妙な共通点

---

## はじめに — あなたのスマホにも UNIX の血が流れている

驚くかもしれませんが、今使っているスマホやMacの中には、**1969年に生まれたUNIXの血** が流れています。

```
        UNIX（1969年、AT&Tベル研究所）
              │
   ┌──────────┼──────────┐
   ↓          ↓          ↓
[BSD系]    [System V系]  [Linux系]
   │          │          │
   ↓          ↓          ↓
macOS      AIX、HP-UX   Linuxサーバー
iPhone                  Android
                        ChromeOS
```

世界の主要OSのうち、**Windows以外はほぼ全て UNIXの系譜** です。1人のプログラマーが暇つぶしで作ったゲーム用OSが、半世紀後に世界を支配するなんて、誰が予想したでしょうか。

## 1. UNIXの誕生 — ゲームから始まった革命

### 1-1. 1969年、ベル研究所での暇つぶし

UNIXのきっかけは **「ゲームを動かしたい」** という、信じられないほど些細な動機でした。

```
1965年   Multicsという巨大なOSプロジェクト
        ↓ 複雑すぎて開発難航
        ↓ ベル研は撤退
1969年   ケン・トンプソン、暇つぶしで
        「Space Travel（宇宙戦）」というゲームを作りたい
        ↓ でも動かすOSがない
        ↓ じゃあ自分で作るか
8月    PDP-7上で最初のUNIXが動作！
```

### 1-2. 名前の由来は実は「ダジャレ」

> **Multics**（複数ユーザーOS）→ **マルチ**（複数）
> **UNICS**（単一ユーザーOS）→ **ユニ**（単一）
> 
> Multicsの「マルチ」をもじって「ユニ」にした **ダジャレ**。
> 発音しやすく **UNIX** に改名。

つまり、**現代社会の基盤たる UNIX の名前はダジャレから始まった** わけです。

### 1-3. 革新的な3つの特徴

初期 UNIX には、当時としては革新的な3つの特徴がありました。

**① 階層ファイルシステム（ディレクトリ）**

それまでファイルは平らに並ぶだけでした。UNIXは **フォルダ（ディレクトリ）で階層的に整理** する仕組みを導入。

```
/
├── home/
│   ├── alice/
│   │   └── document.txt
│   └── bob/
└── etc/
    └── config
```

今では当たり前ですが、これがなければファイル整理は地獄でした。

**② パイプ（`|`）— 小さなプログラムを組み合わせる**

UNIX の最大の発明とも言える機能。プログラムの出力を別のプログラムの入力につなげます。

```
cat file.txt | grep "error" | sort | head -10
        ↓        ↓           ↓        ↓
   ファイルを   "error"を    並べ替え  上位10件
   表示       含む行抽出
```

複雑なことを **小さな単機能プログラムの組み合わせ** で実現する。これが UNIX 哲学の核心です。

**③ すべてはテキスト**

設定ファイルもログも、すべて **テキスト形式**。人間も読めるし、プログラムで処理しやすい。

## 2. C言語と移植性 — UNIX 普及の最大の鍵

### 2-1. アセンブリからC言語への大胆な書き直し

初期 UNIX はアセンブリ言語で書かれていました。問題は **特定のCPU専用** だったこと。

```
PDP-7のアセンブリで書かれたUNIX
     ↓ 1973年、衝撃の決断
動いているOSを丸ごとC言語で書き直す！
     ↓
コンパイラさえあれば、どのコンピュータでも動く
     ↓
移植性（ポータビリティ）の獲得
```

これは前例のない大冒険でした。「動いているOSを、別の言語で書き直す」なんて、普通は怖くてできません。

### 2-2. AT&Tと独占禁止法 — 大学に格安で配った理由

AT&Tは独占禁止法により **コンピュータ事業ができない** 縛りがありました。そこで UNIX を：

- **大学に格安で**
- **ソースコード付きで** 提供

学生・研究者が自由に改変できる環境が整い、技術革新が爆発的に進みました。**規制が結果的にオープン化を促した** という皮肉な歴史。

## 3. UNIX戦争とPOSIX — 「同じUNIXなのに動かない」問題

### 3-1. 各社が独自拡張で分裂

```
1980年代の混沌
       ↓
AT&T System V    BSD      SunOS    AIX(IBM)   HP-UX
   │              │         │         │          │
   各社が独自に機能を追加
       ↓
「同じUNIXなのに互換性がない」状態に
```

プログラムの移植が困難になり、業界全体が混乱しました。これが **UNIX戦争**。

### 3-2. POSIX — 互換性の橋

1980年代後半、IEEE（電気電子技術者協会）が **POSIX**（Portable Operating System Interface）標準を制定。

```
POSIX = UNIX系OSの共通インターフェース
        ↓
完全統一ではないが、基本的な互換性を確保
        ↓
プログラムの移植が容易になった
```

> **比喩**：方言ではあるが、共通語で会話できるようになった

これにより UNIX、Linux、macOS など UNIX 系OSは「**POSIXファミリー**」として互いに似た動きをします。

## 4. UNIX、Linux、macOS、BSDの関係 — 一族の家系図

「UNIX と Linux って同じ？」「macOS は UNIX？」 — よくある混乱を整理します。

### 4-1. 家系図

```
                  UNIX (1969、AT&T)
                      │
        ┌─────────────┴─────────────┐
        ↓                           ↓
    [System V]                  [BSD]
   （AT&T商用版）            （バークレー大）
        │                       │
        ↓                       ↓
   AIX、HP-UX等            FreeBSD、NetBSD
                                │
                                ↓
                          macOS（Apple）
                          iOS
                          
                     ＼
                      ↓ 思想的に影響
                   Linux (1991、リーナス)
                      │
                      ↓
                  Android、Ubuntu、
                  Red Hat等
```

### 4-2. 厳密に言うと

- **「Linux は UNIX」は厳密には間違い**。LinuxはUNIXのソースコードを使っていません。
- 正確には **「Linux は UNIX系 / UNIX ライク OS」**。
- **macOS は UNIX**（公式認定済み）。BSDの直系。
- **POSIXに準拠する** 3つのOSファミリー：UNIX、Linux、BSD。

### 4-3. ラーメン屋で例えると

| OS | ラーメン屋の例え |
|----|--------------|
| **UNIX** | 元祖ラーメン店 |
| **BSD** | 元祖から暖簾分けした支店 |
| **Linux** | 元祖に憧れて独立した、別流派の人気店 |

## 5. GNU と Linux — フリーソフトウェア革命

### 5-1. リチャード・ストールマンとプリンター事件

1980年代、企業がソフトウェアを **商品** として扱い始め、ソースコードを公開しなくなりました。

> **事件**：MIT人工知能研究所のプリンターが故障したとき、以前ならソースを直せたのに、新しいプロプライエタリ・ソフトウェアでは **直せなくなった**。

天才ハッカー **リチャード・ストールマン** はこれに激怒。

> 「このままじゃ、ユーザーがソフトウェアを制御できなくなる。
> ソフトウェアにユーザーが制御される時代になってしまう」

### 5-2. GNUプロジェクトの宣言（1983年）

1983年9月27日、ストールマンは歴史的な宣言をします。

> **UNIXと互換性のある、完全にフリーなOSを作る**

これが **GNUプロジェクト**。

### 5-3. 「GNU's Not Unix」というダジャレ

GNUは「**GNU's Not Unix**」の再帰的な略です。

```
G  =  GNU's
N  =  Not
U  =  Unix

展開すると：
GNU's Not Unix = (GNU's Not Unix)'s Not Unix
            = ((GNU's Not Unix)'s Not Unix)'s Not Unix
            = ... 無限ループ
```

「UNIXじゃないよ」と再帰的に主張するハッカーのジョーク。プログラマー文化の象徴です。

### 5-4. GNU の悩み — カーネルが完成しない

ストールマンは GNU で UNIX に必要なツール群（コンパイラ、エディタ、シェル等）を作りましたが、**最後の1ピースである「カーネル」が完成しなかった**。

そこに登場するのが…

## 6. Linux — 21歳の学生が世界を変えた

### 6-1. 1991年、ヘルシンキ大学のリーナス

**リーナス・トーバルズ**、21歳。フィンランド・ヘルシンキ大学の学生。

```
背景：
  - 教育用UNIX「Minix」を使っていた
  - 自分の386 PCの機能をフル活用したいが、Minixは制限が多い
        ↓
  「自分でOSのカーネルを作るか」
        ↓
1991年8月25日、有名な投稿：
  「Hello everybody out there using minix -
   I'm doing a (free) operating system 
   (just a hobby, won't be big and professional like gnu)」
        ↓
  Linux誕生
```

### 6-2. GNU + Linux = 完全なOS

GNU には **ツール群** はあったが **カーネル** がなかった。Linuxには **カーネル** はあったが **ツール群** がなかった。

```
GNU（ツール群） + Linux（カーネル） = GNU/Linux（完全なOS）
```

実は **「Linux」と呼ばれているOSの多くは、厳密には「GNU/Linux」** です。

### 6-3. オープンソース革命

Linux の革命性は、技術だけでなく **開発モデル** にもありました。

| 従来の開発モデル | Linuxの開発モデル |
|--------|--------|
| 企業内で機密管理 | 世界中の開発者が参加 |
| 数人〜数十人 | 数千人〜数万人 |
| トップダウン | ボトムアップ、合意形成 |
| クローズド | オープンソース |

> **エリック・レイモンドの言葉**：「Given enough eyeballs, all bugs are shallow」
> （目玉が十分多ければ、どんなバグも浅くなる）

### 6-4. なぜマスコットがペンギンなのか

Linuxのマスコットはペンギン「**Tux**」。理由はなんと…

> リーナスがオーストラリアの動物園でペンギンに**噛まれた**。それが印象的だったから。

意外な理由で世界的に有名なマスコットが決まりました。

### 6-5. Linuxはどこにいるのか

「Linuxはマニアのもの」と思いがちですが、実は **世界を支配しています**：

| 場所 | Linuxの存在 |
|------|----------|
| **スマートフォン** | Android（世界スマホシェア約7割） |
| **Webサーバー** | 大半がLinux |
| **クラウド（AWS、GCP）** | 中はLinux |
| **スーパーコンピュータ** | TOP500の100% |
| **家電・IoT** | 多くがLinux |
| **デスクトップ** | ← ここだけ少数派 |

## 7. Windows — もう1つの巨人

### 7-1. MS-DOS時代

1980年代前半のパソコンは **MS-DOS** が主流でした。

```
画面：真っ黒、白い文字だけ
操作：すべてキーボードで命令

ファイル削除：
> del file.txt
```

マウスもアイコンもなく、コマンドを覚える必要がありました。

### 7-2. Windows 1.0 〜 3.1（1985〜1993）

1985年、Microsoft が **Windows 1.0** を発売。MS-DOS上で動く GUIシェルでした。

しかし大して売れず、3.0、3.1と改良を重ねて少しずつ普及。「**Windows = MS-DOSの上のおまけ**」というイメージでした。

### 7-3. Windows 95 — 「OSなのに深夜行列」事件（1995年）

1995年8月、**Windows 95** が発売。発売日には **秋葉原で深夜から行列** ができる社会現象に。

> **OS（基本ソフト）に行列ができるという異常事態**。
> ゲームソフトでも、人気ガジェットでもなく、**OS** に。

なぜそんなことが起きたのか？ 技術的に革命的だったからです。

**① 32ビット化**

[[02-CPUとアーキテクチャとは|CPU章]] で触れた32ビット化を本格採用。メモリ管理が大幅進化。

**② TCP/IP標準搭載**

```
それまで：インターネット接続には別途ソフトのインストールが必要
Windows 95：標準で TCP/IP 搭載
        ↓
家庭から簡単にインターネット接続できるように
        ↓
「インターネット元年」の触媒になる
```

**③ DirectX**

```
ゲーム開発：それまで各社のハードに合わせて個別対応必要
DirectX：Microsoftが統一インターフェースを提供
        ↓
ゲーム開発が劇的に楽に
        ↓
Windowsゲーム市場の爆発
```

**④ スタートメニューとタスクバー**

今では当たり前の「スタートボタン」「タスクバー」の誕生。直感的なGUIが完成しました。

**⑤ プラグアンドプレイ**

USB機器を差せば自動認識（今でいうPnP）の元祖。

### 7-4. 「日本のPC-98を滅ぼした黒船」

実は Windows 95 は日本市場で **ガラパゴス王者の PC-98 を滅ぼした黒船** でもありました。
詳しくは [[04-PCとGUIとは|歴史04-PCとGUI]] 参照。

### 7-5. Windows のその後

```
Windows 95
   ↓
Windows 98, ME（不安定でも普及）
   ↓
Windows XP（2001）— 大ヒット、長寿命
   ↓
Vista（2006）— 不評
   ↓
Windows 7（2009）— 大ヒット
   ↓
Windows 8（2013）— タッチ向けで不評
   ↓
Windows 10（2015）— 安定
   ↓
Windows 11（2021）
```

歴史的に「**奇数バージョンが大ヒット、偶数（Vista, 8）が不評**」というジンクスも。

## 8. UNIX哲学 — ラーメン二郎との奇妙な共通点

### 8-1. 「分かりやすさ」を捨てる思想

現代の OS は **「ユーザーに分かりやすく」** が基本理念です。Windows、macOSは、初心者でも触れるように作られています。

しかし UNIX の始まりに据えられた思想は真逆でした。

> **「何をしているのかわからないのなら、ここにいるべきではない」**
> （『UNIXという考え方』より）

**自己責任・事前学習を前提とした逆張りの設計**。これが UNIX哲学です。

### 8-2. ラーメン二郎との共通点

意外なたとえですが、UNIXの厳しさは **ラーメン二郎** と酷似しています。

| | UNIX | ラーメン二郎 |
|---|---|---|
| 初心者への配慮 | なし | なし |
| 学習コスト | 高い | 高い |
| 専門用語 | コマンド | コール（ニンニク・ヤサイ等） |
| 失敗すると | 操作不能 | 食べきれず残す |
| 通の人にとって | 最高 | 最高 |
| 大衆向け版 | macOS、Windows | カップ麺、通販 |

両者の共通点は「**尖った思想だからこそ、ハマる人には深く刺さる**」こと。傑作はだいたい万人ウケしません。

### 8-3. 「対話拒否」 — UNIXは対話型UIを嫌う

二郎の「ニンニク入れますか？」は一見対話型ですが、実態は **コマンド入力のプロンプト** です（UNIXの `$` マークと同じ）。

> **対話型UIの問題**：
> - 「何をしたいですか？」と毎回聞かれる
> - 1つずつ選択肢を絞っていく → 時間がかかる
> - 話している間 **拘束される**（他のことができない）

UNIX哲学はこれを嫌い、**一発でコマンドを打ち込む** スタイルを選びました。慣れた人にとっては圧倒的に速いのです。

### 8-4. UNIX 哲学の主な原則

> **1つのことをうまくやれ**
> **テキストで通信せよ**（プログラム間のデータ交換）
> **小さなツールを組み合わせよ**

これらの原則は、現代のソフトウェア設計の根幹をなしています。マイクロサービス、Unix風のCLIツール（git、Docker等）— すべてこの思想の延長線です。

## 9. シェルの進化 — UNIXからzshまで

「シェル」とはOSのコマンドを受け付ける窓口のこと。UNIX以来の進化を簡単に：

| シェル | 年 | 特徴 |
|--------|----|----|
| **sh**（Bourne shell） | 1977 | UNIX標準、シンプル |
| **csh**（C shell） | 1978 | C言語ライクな構文 |
| **bash** | 1989 | sh互換 + 機能拡張、Linux標準 |
| **zsh** | 1990 | 高機能、macOS標準（2019〜） |
| **fish** | 2005 | ユーザーフレンドリー、補完が強力 |

現代のターミナルでよく使われるのは **bash** と **zsh**。プログラマーの日常ツールです。

## 10. この章のまとめ

### 大きな構図

```
1969  UNIX誕生（暇つぶしから）
   ↓ C言語で書き直して移植性を獲得
1970s 大学に格安で配布、爆発的普及
   ↓
1980s UNIX戦争、POSIXで標準化
   ↓
1983  GNU プロジェクト（ストールマン）
1991  Linux カーネル（リーナス）
   ↓ GNU + Linux で完全なOSが完成
2000s スマホ時代へ
   ↓
現在  Linux系（Android）+ UNIX系（iOS）が世界のスマホを支配
      Windowsは別系統で生き残る
```

### 大切なポイント

1. **UNIXは「ゲームを動かしたい」から生まれた**
   小さな動機が、結果として世界を変える。

2. **「Linux」と呼ばれているもののほとんどは GNU/Linux**
   ツール群（GNU）とカーネル（Linux）の組み合わせ。

3. **オープンソースは「目玉の力」**
   世界中の開発者が見ているから、バグが浅くなる。

4. **Windows 95 は OS の革命だった**
   32ビット化、TCP/IP、DirectX。OSなのに行列ができた。

5. **UNIX哲学は「分かる人にだけ分かれ」のスタンス**
   万人受けを捨てたからこそ、本物が生まれた。
