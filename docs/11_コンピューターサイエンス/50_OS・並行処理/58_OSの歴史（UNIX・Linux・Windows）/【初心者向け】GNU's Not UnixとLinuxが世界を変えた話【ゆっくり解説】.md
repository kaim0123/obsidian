## 詳しい要約

本動画は、霊夢が日常で目にする **GNU** という文字をきっかけに、**リチャード・ストールマン（RMS）** が始めた GNU プロジェクトと、それが **Linux カーネル** と結びついて現代のインターネット・スマホを支えるまでの歴史を解説する。核心は **「フリー＝無料ではなく自由」** という理念と、**コピーレフト（GPL）** によってその自由が永続的に守られてきた、ということ。

### GNU とは何か

| 項目 | 内容 |
|------|------|
| **読み方** | **グニュー**（`G` + `new`）。「ぐぬ」ではない |
| **正式名称** | **GNU's Not Unix**——「GNU は Unix ではない」 |
| **再帰的頭字語** | GNU の中に GNU's Not Unix が入り、さらにその中に GNU が……と **無限に展開できる** プログラマーのジョーク（再帰的頭字語） |
| **目的** | Unix と互換性のある **完全にフリーなオペレーティングシステム** を一から作る |

---

### 背景——ハッカー文化からプロプライエタリ時代へ

| 時代 | 状況 |
|------|------|
| **1970〜80年代前半** | ソフトウェアは研究者同士で **ソースコードを自由に共有・改良** する文化が主流。MIT 人工知能研究所の **リチャード・ストールマン** がその中心にいた |
| **ハッカー** | 本来は **技術を探求する優秀なプログラマー** のこと（悪意ある侵入者とは別） |
| **1980年代** | 企業がソフトウェアを **商品化**。ソースコード非公開・改造禁止の **プロプライエタリ（所有権）ソフトウェア** の時代が到来 |
| **きっかけ** | MIT のプリンター故障時、以前は自分でソフトを修正できたが、プロプライエタリ化でソースが見えず直せなくなった——**「ユーザーがソフトを制御できなくなる」** 危機をストールマンが痛感 |

---

### GNU プロジェクトの始まり（1983年）

**1983年9月27日**、ストールマンが歴史的宣言を行い、GNU プロジェクトが始動した。

#### フリーソフトウェアの「4つの自由」

> **Free as in freedom, not as in free beer.**（無料ビールのフリーではなく、自由のフリー）

| 番号 | 自由 | 内容 |
|------|------|------|
| **第0** | 実行の自由 | どんな目的でもプログラムを **実行** できる |
| **第1** | 研究・改造の自由 | 動作を **研究・改造** できる（ソースコードへのアクセスが前提） |
| **第2** | 再配布の自由 | **コピーを再配布** できる |
| **第3** | 改良版配布の自由 | **改良版を配布** できる |

- **1985年**：**FSF（Free Software Foundation / フリーソフトウェア財団）** を設立し、4つの自由を制度的に守る体制を構築。

---

### GPL——コピーレフトという革命（1989年）

**GNU GPL（General Public License）** は、著作権法を **逆手に取った** ライセンス。

| 概念 | 内容 |
|------|------|
| **通常の著作権** | 自由を **制限** する |
| **GPL** | 著作権を使って自由を **保護** する |
| **コピーレフト** | GPL ソフトを改造・配布する場合、**改造版も同じ GPL で公開** しなければならない。自由が **感染（伝播）** していく仕組み |
| **効果** | フリーソフトウェアが **プロプライエタリに取り込まれる** のを防ぐ |

---

### GNU の開発とカーネル問題

ストールマンは **1984年に MIT を辞め**、GNU に専念した。

| ソフトウェア | 内容 |
|-------------|------|
| **Emacs**（1984年頃） | テキストエディタ。大ヒットし **40年以上現役**。みんなで改良し続けられるフリーソフトの強みを体現 |
| **GCC** | **GNU Compiler Collection**。プログラムを機械語に翻訳するコンパイラ。今も世界中で使用 |
| **その他** | シェル、各種ユーティリティなど、OS を構成する **ツール群** を10年近くかけて開発 |

#### Hurd カーネルの苦戦

- OS の心臓部である **カーネル** が完成しないまま **1990年代** に入った。
- GNU プロジェクトは **Hurd** という **マイクロカーネル** を採用したが、設計が野心的すぎて開発が停滞。
- この時期、GNU プロジェクトは **失敗したのではないか** と思われた。

---

### Linux の登場と GNU/Linux の誕生（1991年）

| 項目 | 内容 |
|------|------|
| **1991年8月25日** | フィンランドの大学生 **リーナス・トーバルズ**（21歳）が「趣味で OS を作っている。興味ある人は？」とネットに投稿 |
| **Linux カーネル** | 最初から **GPL ライセンス** を採用。カーネル単体では何もできない |
| **組み合わせ** | GNU が10年かけて作った **コンパイラ・エディタ・シェル・ユーティリティ** と Linux カーネルを合体 |
| **誕生** | **1992年頃**、**GNU/Linux システム** が完成 |

#### 名称問題

- 正確には **GNU/Linux** と呼ぶべきだが、**Linux** の方が短く覚えやすく普及。
- 実際のシステムの **大部分は GNU のソフトウェア** で構成され、カーネルだけが Linux。
- ストールマンは今も **GNU/Linux** と呼ぶよう訴え続けている。

---

### 普及と影響

| 分野 | 状況 |
|------|------|
| **1990年代〜** | サーバー、ワークステーション、スーパーコンピューターなどで急速に普及 |
| **スマートフォン** | **Android** は Linux カーネルと GNU ツールの一部を使用——日常のスマホにも GNU が入っている可能性 |
| **その他** | Web サーバーの大半、ルーター、家電製品など **あらゆる場所** に存在 |

---

### フリーソフトウェア vs オープンソース

| 項目 | フリーソフトウェア | オープンソース |
|------|------------------|--------------|
| **提唱** | ストールマン、FSF | **1998年**、エリック・レイモンドらが **オープンソース** という言葉を提唱 |
| **重視点** | **自由という理念** | **実用性・開発手法の優位性** |
| **ストールマンの姿勢** | 「フリーソフトウェア」という言葉にこだわり、理念を忘れないよう訴え続ける |

#### 思想の広がり——コモンズ

- **みんなで共有する資産** という考え方を広めた。
- **Wikipedia**——みんなで知識を共有・育てる GNU 的発想。
- **Creative Commons ライセンス** も GPL の影響を受けている。

---

### 現代の課題と進化（2000年代〜2025年）

| 課題 | 対応 |
|------|------|
| **クラウドコンピューティング** | サーバー側のソフトは配布されないため GPL の自由が適用されにくい → **AGPL**（ネットワーク経由のサービス提供時もソース公開を義務化） |
| **ティボ化（Tivoization）** | ハードウェアで自由を制限する問題 → **GPLv3**（2007年）で対応 |
| **Hurd カーネル** | 今も開発継続中（遅いが）。**完全な GNU/Hurd システム** という夢は諦められていない |

#### 主要な GNU ソフトウェア（現役）

GNU Coreutils、GNU Bash、GCC、Emacs、GNOME、GNU Octave など、数えきれないほどのソフトが世界中で稼働。

---

### 批判と評価

- **批判**：理想主義すぎる、実用性を無視している、ストールマン自身の言動が物議を醸した、など。
- **評価**：GNU プロジェクトがなければ、今の **インターネットもスマホも全く違う形** になっていた可能性がある。**デジタル時代の自由の定義** を変えた。

---

### まとめ——GNU の歴史を一言で

1. **1983年**：ストールマンがソフトウェアの自由を守るため GNU プロジェクトを開始。4つの自由と GPL を生み出した。
2. **フリー＝無料ではなく自由**。
3. **約10年** かけてツール群を構築したがカーネルで苦戦 → **Linux** が登場し GNU/Linux が完成。
4. 現在は **スマホからサーバーまで** あらゆる場所で使用。
5. GNU の理念は技術を超えて **Wikipedia や Creative Commons** にも影響。
6. **40年以上** 続き、クラウド時代の自由をどう守るかという新しい挑戦も続いている。
