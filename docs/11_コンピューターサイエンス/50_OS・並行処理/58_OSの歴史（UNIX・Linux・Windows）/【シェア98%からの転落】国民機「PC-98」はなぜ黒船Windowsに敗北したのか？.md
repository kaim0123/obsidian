## 詳しい要約

**テーマ：国内シェア9割の「国民機」PC-98 が、DOS/V と Windows 95 という「黒船」に敗れた理由**

1980年代後半、NEC の PC-9801 シリーズは国内パソコン市場で90%超のシェアを握った（タイトルの「98%」は語呂合わせで、実際は約90%）。日本語処理と上位互換性で市場を制したが、独自規格ゆえの高コスト体質と世界標準からの孤立が敗因となり、1990年の DOS/V、1995年の Windows 95 によってわずか数年でシェアを失った。ガラパゴス化の教訓を読み解く。

---

### PC-98 の強み

- 1982年登場の16ビット機。CPU は Intel 8086、価格29万8000円。
- **日本語処理の圧倒的優位**：IBM PC など海外機は漢字表示が貧弱だったが、PC-98 は16×16ドットの**漢字ROMを標準搭載**し、実用的なビジネス文書を作れる唯一の選択肢だった。
- **上位互換性の徹底**：1982年のソフトが1990年代のマシンでも動き、ソフト資産が無駄にならなかった。
- ビジネス・教育・ゲーム（信長の野望、三國志、ときめきメモリアルなど）で標準に。640×400の高解像度も当時は圧倒的。

### 世界標準からの孤立

- 世界では1981年登場の **IBM PC とその互換機**が標準に。設計が公開された**オープンアーキテクチャ**で、台湾や米国のメーカーも互換機を作れた。
- 競争で価格が下がり、1990年代初頭には PC 互換機が10万円前後、PC-98 は20〜30万円台と2倍以上。PC-98 はパーツ・拡張カードも独自規格で高コスト体質から抜け出せなかった。
- 世界市場は日本の10〜20倍の規模で、ソフトメーカーは世界向けを優先。

### 第1の黒船：DOS/V（1990年）

- 1990年10月、IBM が **DOS/V** を発表。PC 互換機で日本語を表示できる MS-DOS。
- 漢字ROM というハードウェアに頼らず、フォントをハードディスクに置いて**ソフトウェアで日本語を表示**する発想。安い PC 互換機で日本語が使えるようになり、PC-98 最大の強みが消えた。
- PC-98 が25万円の時代に DOS/V 機は15万円程度。初期は日本語表示が不完全でソフトも少なく様子見が多かったが、NEC は一時的なブームと見誤った。
- 1993年ごろには 486・Pentium の投入と値下がりで DOS/V 機の性能が急向上。

### 第2の黒船：Windows 95（1995年）

- 1995年11月23日、Windows 95 日本語版発売。
- **GUI**（スタートボタン、デスクトップ、ドラッグ＆ドロップ）で、コマンド入力が必要な MS-DOS から劇的に使いやすくなった。
- PC-98 版 Windows 95 もあったが、性能と価格で敗北：PC 互換機は Pentium 75MHz で約15万円、PC-98 は i486DX2 66MHz で20万円以上。
- Windows 95 は32ビット OS で互換機の性能を引き出せた一方、PC-98 は16ビット時代の設計を引きずっていた（独自の Cバスや FM/PCM 音源のサウンドボード PC-9801-86 などはマニアには懐かしい存在）。
- Photoshop や Office、ゲームが Windows 95 版で続々登場し、互換機の方が速く動く。
- シェアは約90% → 1997年に50%割れ → 1999年に20%台。**2003年に生産終了**、21年の歴史に幕。

### 教訓と遺産

- 日本市場への最適化は1980年代には正しい戦略だったが、インターネット・Windows・半導体の急進化によるグローバル化の波に対応できなかった。
- NEC は1997年に PC 互換機「PC98-NX」を出したが、PC-98 の看板を掲げた互換機は従来ユーザーには裏切りと映った。
- PC-98 末期（1996〜1998年）には**東方 Project** の旧作5作品がすべて PC-98 用に作られ、制約の中で独特の魅力を生んだ。PC-98 は日本のパソコン文化とクリエイター・エンジニアを育てた。

### まとめ

- **市場の独占は未来を保証しない**（シェア9割でも負けた）。
- **互換性の維持はコストを伴う**（レガシーが技術革新の足かせに）。
- **閉じた市場は開かれた標準に勝てない**（物量と多様性で圧倒される）。Android と iOS、EV の規格競争、AI 開発競争にも通じる。
