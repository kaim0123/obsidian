## 詳しい要約

本動画は、**1995 年 11 月 23 日** に発売された **Windows 95** が、なぜ OS の箱を買うために **秋葉原で深夜の大行列** ができるほどの社会現象になったのかを、**32 ビット化・TCP/IP 標準搭載・DirectX・PC-98 終焉** といった技術的側面から解説する。単なるバージョンアップではなく、**PC の使い方そのものが変わる瞬間** に立ち会うために人々が並んだ——iPhone 初代のような感覚だが、それを **技術が本物で裏打ちしていた** ことが核心である。

### Windows 95 とは

- **Windows 95**＝Microsoft が 1995 年に発売した **32 ビット GUI オペレーティングシステム**。Windows 3.1 の後継。
- 単なる OS 更新ではなく、**プリエンプティブマルチタスク・長いファイル名・スタートボタン・タスクバー・右クリック・TCP/IP 標準搭載・DirectX** など、現代の PC 体験の基礎を一気に確立した **プラットフォーム転換点**。
- 日本では **PC-98 独自路線の終焉** と **世界標準 PC 文化への合流** のトリガーにもなった。

### 社会現象としての Windows 95

| 要素 | 内容 |
|------|------|
| **発売日** | 1995 年 11 月 23 日 |
| **現象** | 秋葉原のショップで **深夜から大行列**——OS の箱を買うために並ぶのは滅多にない |
| **本質** | ソフトウェアの箱を買いに来たのではなく、**「これからの PC がどう変わるか」** を先に手に入れに来た |
| **3 種類の購入者** | ① **SE（義務）**——社内 PC 環境が時代遅れになる焦り ② **自作 PC ユーザー（熱狂）**——32 ビットネイティブ時代の到来 ③ **一般の人（雰囲気）**——「インターネットってやつでしょ」というふわっとした期待 |

---

### 第 1 期：Windows 3.1 の限界——変化の「入り口」

#### DOS 上の 16 ビット GUI

- **Windows 3.1** は **16 ビットベース** で、**DOS（黒い画面）の上に乗っかって動く** GUI だった。
- Windows がフリーズすると **DOS 含めて全体が道連れ** で死ぬ——基礎工事が本物ではなかった。

#### 協調型マルチタスク（Cooperative Multitasking）

- アプリが **「次の人どうぞ」** と譲らないと他のアプリが動けない。
- 意地悪なアプリが独占すると **画面全体が凍りつく**——会議のプレゼン中に Excel が固まって再起動しかない、という地獄が日常だった。

#### 8.3 形式のファイル名

- DOS 時代のルール：**ファイル名 8 文字・拡張子 3 文字** まで（例：`企画1.doc`）。
- 仕事用の意味のある名前がつけられず、**暗号のようなファイル名** で管理——「分かる人の道具」だった PC の象徴。

---

### 第 2 期：Windows 95 のコア技術——OS が「本物の土台」に

#### 32 ビット + プリエンプティブマルチタスク

- **32 ビットアプリ** が本格的に動く環境に。
- **プリエンプティブマルチタスク**：OS 側が **「そろそろ交代しろ」** と強制的に切り替え——1 つのアプリが固まっても **他は動き続け、OS 全体は生き残る**。
- 今では当たり前だが、**ここからそうなった**。

#### 長いファイル名（Long Filename）

- 8.3 制限が撤廃。**`仕事用紙_1995年企画案.doc`** のような名前が使えるように。
- **フォルダーを自分で整理する文化** が一般人にも広がり、PC が **「分かる人の道具」から「普通の人の道具」** に近づいた。

#### スタートボタン・タスクバー・右クリック

| UI 要素 | 設計思想 | 影響 |
|---------|----------|------|
| **スタートボタン** | 初心者は電源を入れた後 **どこを押せばいいか迷う**——**全ての入り口を 1 箇所に集める**。「迷ったらスタート」 | 情報設計として革命的。機能を増やすのではなく **入り口を 1 個にした** |
| **タスクバー** | 画面下部の帯に **今開いているアプリが全部並ぶ** | 3.1 ではウィンドウが重なると発掘が必要だったが、**マルチタスクが目に見える形** に |
| **右クリック** | 対象の上で右クリックすると **その対象に関連する操作一覧** が出る | **説明書を読まなくても操作できる世界**——「とりあえず右クリック」が 30 年経った今も健在 |

---

### 第 3 期：マーケティング——技術を売らず「気分」を売った

- Microsoft は **ローリング・ストーンズの「Start Me Up」** を当時としては破格の使用料で購入。
- 深夜のテレビで **潜在意識や自動車の CM に混ざって** ギターリフが流れる——家電売り場の BGM かと思った人も多かった。
- CM の内容：**スペックを一切説明しない**。画面が起動してスタートボタンが光り、**「さあ、どこへ行きたい」** というメッセージだけ。
- **技術を買わせるのではなく「こういう気分になれる」を売った**——しかし CM が約束した体験の変化を **技術がちゃんと裏打ちしていた**（嘘のイメージ広告ではなかった）。

---

### 第 4 期：TCP/IP 標準搭載——インターネット前夜の「扉」

#### イメージと実態のズレ

- **1995 年の日本** ではまだ **ほとんどの人がインターネットにつながっていなかった**。
- 雑誌の表紙や家電量販店のポップに **「インターネット」** の文字は踊るが、**説明できる人間がほとんどいない**——言葉だけが先に走った時代。

#### パソコン通信との対比

- **ニフティサーブ・PC-VAN** などの **パソコン通信ユーザー** は、専用ネットワークの中で十分豊かな世界を享受。
- インターネットが話題になると **「わざわざ乗り換える必要あるのか」** という感覚も——慣れ親しんだ世界を捨て、ゼロから覚え直すことへの躊躇。

#### TCP/IP 標準搭載の意味

- **TCP/IP**（インターネット通信の基本的な約束ごと）が **OS に最初から入る** ようになった。
- Windows 3.1 では **Winsock スタックを買って入れる** かプロバイダーソフトで設定する必要があり、**インターネットは詳しい人のもの** だった。
- Windows 95 で **「繋ごうと思えば繋げる状態」** にハードルが下がった。
- **ダイヤルアップ設定ウィザード** が OS に入り、モデム・プロバイダー契約・時間課金などの壁は残るが、**「不可能」から「難しいけど自分でもできるかもしれない」** へ——一般人が初めて挑戦できる入り口ができた。
- 技術的事実であると同時に、**「この OS はインターネットを前提にしている」** という Microsoft の宣言でもあった。

---

### 第 5 期：PC-98 終焉——日本独自の「ガラパゴス」から世界標準へ

#### PC-98 とは

- **1995 年以前の日本** のパソコン市場は世界と **全然違う形**——**NEC の PC-98 シリーズ** が市場の下半数を占め、ビジネスでも家庭でも **「パソコン＝PC-98」** の時代。
- **BIOS・テキスト表示・グラフィック仕様** すべて NEC 独自設計——**世界標準とは別の企画** で動いていた。
- PC-98 用ソフトは PC-98 でしか動かない。ドス V マシンのソフトは動かない——**完全に別の世界**（日本だけのガラパゴス）。

#### Windows 95 がもたらした転換

- **GUI が前提** になったことで、PC-98 が得意としていた **日本語テキストの独自表示** の優位性が消えた。
- 美しい PC-98 のテキスト画面が **突然「古い画面」** に見え始めた——**強みが一矢で弱み** に。
- **「PC-98 かドス V か」ではなく「Windows が動くかどうか」** が基準に。ドス V マシンの方が安ければ **安い方を選ぶ** 人間が増える。
- **1990 年代後半から PC-98 のシェアは急落**。NEC は最終的に **ドス V 互換機市場に参入し、独自路線を畳んだ**——自分たちが作り上げた世界を自分で畳んだ。
- 一方で、**日本をガラパゴスの古藤から世界標準の PC 文化に引き戻した** とも言える。

#### 日本の仕事現場への直撃

- 当時の日本オフィス：**文書＝ワープロ専用機、表計算＝別ソフト、プレゼン＝また別**——1 つの資料を作るのに **機械を渡り歩く** のが普通。
- **Windows 95 + Office セット販売** で Word・Excel・PowerPoint が仕事の標準セットに——**1 台の PC で資料作成から表計算まで完結**。
- **TrueType フォント** で **画面で見た通りに印刷（WYSIWYG）** される状態に——当時は画面と印刷が一致しないのが普通で、明朝体とゴシック体が綺麗に出るだけで感動した記録が残る。
- **PC-98・ワープロ専用機の消滅、オフィスの標準化**——OS の話が **日本の働き方の話** になった。

---

### 第 6 期：DirectX——PC ゲーム革命の最後のピース

#### DOS 直起動の地獄

- Windows 95 以前、**PC ゲームは DOS から直接起動** していた——Windows を経由しない。
- ゲームは **ハードウェアを直接叩く** 必要があり（サウンドカードのメモリアドレス指定、グラフィックチップへの直接命令）、**メーカーごとに全部違う**。
- 起動前に **`config.sys` / `autoexec.bat`** を手で書き換え、再起動して音が出なければまた書き換え——**深夜に何度も繰り返す** のが当時のあるある。
- Windows 上でゲームを動かすと **OS が間に入って遅延** するため、速度が命のゲームには致命的——**ゲームは DOS から起動が常識**。

#### DirectX の登場

- **DirectX**＝ゲームとハードウェアの間の **共通の翻訳仕組み**。
- ゲーム側は「音を出せ」「画面に描け」と DirectX に命令し、DirectX が各ハードウェアに合わせて翻訳——**ゲーム側はハードの違いを気にしなくていい**。
- **DirectDraw（画面）・DirectSound（音）・DirectInput（入力）** に役割分担。
- **Windows でゲームをする選択肢が初めて現実的** に——「DOS じゃないとゲームにならなかった」のに **Windows でも遊べる** ように。
- 後の **Direct3D** へと発展し、**3D アクセラレータ時代・GPU 競争** の土台に——**今の PC ゲームがあるのは Windows 95 が土台を作ったから** とも言える。

---

### まとめ：なぜ社会現象になったのか

| 変化 | 内容 |
|------|------|
| **32 ビット土台** | プリエンプティブマルチタスク、本物の OS 基盤 |
| **ファイル名の自由化** | 長いファイル名、一般人の PC 管理文化 |
| **UI 革命** | スタートボタン、タスクバー、右クリック——30 年経っても健在 |
| **TCP/IP 標準搭載** | インターネットへの扉、詳しい人のものから一般人の入口へ |
| **PC-98 終焉** | 日本独自路線の終わり、世界標準への合流、オフィス標準化 |
| **DirectX** | DOS ゲーム地獄の終焉、PC を仕事も遊びも担う総合プラットフォームに |

- **これらが 1 度に来た**——1 つ 1 つは来る変化でも、**全部同時に来たから「今が変わる瞬間」** になった。
- **技術だけでも、デザインだけでも、マーケティングだけでも届かなかった。全部が揃っていた**——どれか 1 個欠けていたら深夜の行列にはならなかった。
- 行列に並んだ人々は **OS の箱を買いに来たのではなく、これからの自分の生活がどんな画面になるのかを確かめに来た**——**未来の UI を先に手に入れに来た**。
- **「よくわからないけどなんか変わるらしい」** と感じた一般の人が、**「PC は自分には関係ない」から「自分にもできるかもしれない」** と思えた瞬間——それが一番大きな変化だったかもしれない。
- Windows 95 は **終わった OS の話ではなく、今の話でもある**——スタートボタン、右クリック、タスクバーは現代の Windows にもスマートフォンにも繋がっている。
