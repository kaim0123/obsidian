## 詳しい要約

**テーマ：Windowsサーバーが「インターネットの土台」という戦場でLinuxに負けた理由**

Windowsサーバーは社内サーバーでは今も強いが、インターネットに公開される表側のサーバーではLinuxに圧倒された。勝敗を分けたのは性能ではなく「広がり方」で、無料のOS（Linux）と無料のWebサーバー（Apache）の組み合わせ、無人運用との相性、中身を自由にいじれることが差を生んだ。

---

### 第1章 二つのサーバーの世界

- サーバーの居場所は **会社の中（社内）** と **インターネット（表側）** の2つ
- 社内：社員のID管理、ファイル共有、社内システム。社内PCが全部Windowsなら、同じMicrosoft製品で揃えるとつなぎ目が滑らかで、1000人規模の設定を1箇所から管理できる
- 表側：2026年3月の調査で、OSが判明しているサイトのうち **Linux約60.9%、Windows 9.0%**。人気上位サイトに絞るとさらに差が開く
- ポイント：Windowsが負けたのは表側（インターネット）の世界

### 第2章 無料が商品を駆逐した日

- 1990年代半ば、誰もがホームページを持ちたがった時代。Webサーバーの選択肢の一つがMicrosoft製品だった
- その横に現れたのが **Apache**：世界中のボランティアが作り無料で配布。落ちにくく、中身を自由に改変でき、高価な専用機も不要
- 1995年にはApacheが世界で最も使われるWebサーバーに
- 当時サイトを作っていたのは学生・研究者・個人などお金のない人たちで、無料の道具から広がった
- Apacheが最も快適に動く相手が無料OSの **Linux**。サイト立ち上げのソフト代が丸ごと0円になり、当時の常識を覆した

### 第3章 数字で見る今の圧倒的な差

- クラウド（Amazon・Microsoft・Googleの3社が大半）で借りられているサーバーの中身は **Linuxが約92%**
- Microsoft自身のクラウド **Azure** 上でもLinuxの方がWindowsより多い。Microsoftは意地を張らず、Linuxを自社クラウドで受け入れる商売を選んだ（拒めば顧客ごと他社クラウドへ逃げるため）
- スーパーコンピューター上位500台は2017年末以降 **すべてLinux**
- MicrosoftのWebサーバー **IIS** の使用率は約5%まで低下
- ポイント：ネット・クラウド・スパコンという表側の世界はほぼすべてLinuxが土台

### 第4章 差がついた3つの理由

1. **お金（ライセンス料）**：数百〜数千台並べるネットの世界では、1台ごとのライセンス料が台数分膨らむ。Linuxなら何台増やしてもOS代は0。急なアクセス増で「1時間だけ100台増やす」ような場面でも気軽に増やせる
2. **性格の違い**：Windowsは人が画面の前でマウス操作する前提で生まれた。ネットのサーバーはデータセンターで無人のまま何ヶ月も動く。Linuxは画面なしで文字の命令だけで操作でき、数百台に一斉に命令を配れる。またWindowsは長く **更新のたびの再起動** という癖があり、止まらないことが命のネットでは重い弱点だった
3. **中身を自由にいじれること**：Linuxは設計図（ソースコード）が公開され、無駄を削って用途に合わせ調整できる。Windowsは非公開で、用意された形のまま使うしかない

### 第5章 開かれたものの強さ

- これは「Windowsサーバーがダメな製品だった」という話ではない。社内のID管理やルールの一括配布ではWindowsの方が素直で、社内利用を含めれば今も大きなシェアを持つ
- 勝敗を分けたのは技術の高さではなく **広がり方**：「売って届ける道」（商品）と「配って広がる道」（無料・設計図公開で世界中の技術者が使い・直し・広げる）
- エンジニアへの教訓：技術選定で性能だけを見がちだが、世界の土台になるかは **誰でも触れるか・中が見えるか・みんなで育てられるか** という「開かれているか」で決まる。「閉じた優秀さより開かれた普通さ」
- 近年のMicrosoftはLinux向けソフトを自ら作り、設計図を公開する側に回った。負けから相手の強さの理由を学んで取り入れた姿勢は、エンジニアにもそのまま使える

### まとめ

- Windowsの負けは全面敗北ではなく「インターネットの土台」という一つの戦場での負け
- 無料のLinux＋Apacheが、ネット普及期に個人・小規模チームから広がって土台を押さえた
- ライセンス料・無人運用との相性・改変の自由の3点が、規模が大きいほど効いた
- 技術が世界の土台になるかは、性能以上に「開かれ方・広がり方」で決まる
