   ↓

## 5. 「OS」と他の章のクロスリファレンス

### 歴史章との関係

OSの章は、歴史章で扱った各時代の **実装の中身** です。

| 歴史章のトピック | OSでの該当 |
|--------|--------|
| ENIAC、ノイマン型 | OSの起源（バッチ処理時代） |
| UNIX誕生（1969） | [[02-UNIX-Linux-Windowsとは|02-UNIX/Linux/Windows]] |
| Windows 95 | [[02-UNIX-Linux-Windowsとは|Windows 95 革命]] |
| Linux / Android | [[02-UNIX-Linux-Windowsとは|Linux 普及史]] |

### ハードウェア章との関係

OSはハードウェアを **管理する** ソフトウェア。両者は密接です。

| ハードウェアの概念 | OSでの対応 |
|--------|--------|
| CPU の判断 | プロセス管理、スケジューラ |
| メモリ | 仮想アドレス空間、メモリ管理 |
| キャッシュ | OSは認識して最適化 |
| 競合状態（race condition） | OSが排他制御で防ぐ |
| 8086互換性 | リアルモードでの起動 |

### CrowdStrike事件は何だったのか

[[03-プロセス・システムコール・ドライバとは|第3節]] で扱った CrowdStrike事件は、**Ring 0 で動くドライバの怖さ** を世界に見せつけた事件でした。

- ハードウェアの特権（Ring 0） × ソフトウェアのバグ ＝ 世界停止
- ドライバ設計のあり方が再考される契機に
- 結果：Rust 言語へのドライバ移行が加速

## 6. 第6章「OS」を読み終えたあなたへ

OS の世界には、ここで扱えなかった魅力的なトピックがまだまだあります。

- **仮想化技術**（VMware、KVM、Xen）

- **マイクロソフトの新しい挑戦**（WSL、Windows on ARM）
- **macOS / iOS の内部**（XNU、Mach、BSD混在）
- **AI と OS の融合**（自律的なリソース管理）

興味があれば、これらの単語で検索を広げてみてください。
