## 要約

**シリーズの位置づけ**

ゆるコンピュータ科学ラジオ「ノイマン」シリーズ **第3回・最終回**（全3回）。前回までの **リアリスト像** を核兵器開発と照らし合わせ、「人間のフリをした悪魔」と呼ばれる理由と **それでも冷酷ではなかった** 側面を描く。コンピュータの功績は駆け足で触れ、**別シリーズ（計算機の歴史）** への布石あり。おまけ回（厳選エピソード雑談）予告。

**冒頭：ゲーム理論の父、ギャンブルは滅法弱い**

- ゲーム理論の創始者なのに **ポーカー等でボロ負け**——考え事（エルゴード理論等）に夢中で集中できない。前回の「考え事しちゃう」系エピソードの延長。

### 第二次世界大戦と原爆開発

**自由主義を守るための行動**

| 行動 | 内容 |
|------|------|
| **亡命支援** | 量子物理学の大物など、ヨーロッパから逃がす活動 |
| **軍人志望** | 陸軍士官試験 **筆記満点・歴代最高得点** → 採用試験が延びた結果 **35歳** になり年齢制限（35歳未満）で不採用 |
| **弾道計算** | 軍内部で大砲の弾道軌道計算等に貢献 |
| **ロサアラモス** | 核兵器開発研究所で **爆縮型（プルトニウム）** の聖地な計算を完成 |

- 軍人になれなかった分、研究者として原爆開発に **大活躍**——マクレイ本も「軍に使う才能ではなかった」と同趣旨。
- 志望動機（堀本の解釈）：**自由主義国側が勝つために貢献する** → 軍人になるのが合理的、というシンプルなロジック。

**広島と長崎の違い**

- **広島（ウラン）**：刺激を与えれば連鎖反応で爆発——比較的単純な **銃型**。
- **長崎（プルトニウム）**：爆縮型——タイミングよく段階的起爆が必要で **技術的に極めて困難**。「無理じゃないか」と言われた設計をノイマンの計算力で完成。

**ゲーム理論的な核戦略**

- 「ヒトラー率いるドイツが先に核を持ったらどうなるか」を分析。
- 損失最小の均衡：**先に核を持ち、相互保有時は互いに打てない状態**——これが **相互確証破壊（MAD）** 的発想の原型（堀本は憶測と前置き）。
- 原爆投下で **概ね戦争終結** するだろうという目論見——案の定そうなった。
- 水素爆弾開発にも **リーダー的役割**（ビキニ環礁実験）。アインシュタイン「原爆で10万人死んだ、水爆はダメ」に対し、ノイマン **「スターリンが持つよりケネディが持つべき」**——一貫したリアリスト論。

**他の科学者との対比**

| 人物 | 兵器開発への姿勢 |
|------|------------------|
| **アインシュタイン** | ルーズベルトへの手紙（開発推進）に署名 → 後に **「人生最大のしくじり」**、アインシュタイン・ラッセル宣言 |
| **フリッツ・ハーバー** | 毒ガス・独逸作戦への寄与 → 妻クララが反対し **自殺** |
| **ノイマン** | **反省しない**。**堂々と** 肯定し続ける——科学者兵器開発者の中で **一番飄々としている** |

- ノイマンから見ればアインシュタインは **時流が読めない理想主義者** に見えた（戦争がなければ揉めなかった可能性）。

**「人間のフリをした悪魔」像**

- 賢い悪役キャラ的——「こうすればよい手段を選ぶ」「私の予想通りだった」。
- しかし内心は **両親の呵責** より **「今正しい選択肢はこれだろう」** という信念に支えられている——徹底したリアリスト。
- 一般人は後から「あれは良くなかった」と振り返るが、ノイマンは **「あの時ベストの行動をした」** と考え続けた。

### 冷酷ではないエピソード：オッペンハイマー

- **オッペンハイマー**：原爆プロジェクトリーダー。実験成功時 **「今や我は死神、世界の破壊者となり」**（バガヴァッド・ギーター）——スタッフは **中二病** ではなく **「手柄独り占めだ」** と不満。
- 原爆後、オッペンハイマーは反省し **水素爆弾反対** → ノイマンと **仲悪し**（同じロサアラモス、スタンス対立）。
- **スパイ容疑** で投獄されそうになった際——ノイマンは **「気に入らんがスパイではない」** と必死で署名し、**投獄を防いだ**。
- **トロッコ問題**：5人 vs 1人 → ノイマンなら **即「切り替えるでしょ」**——プラグマティック。常人の「モヤモヤ」とは対照的。

### コンピュータ：夢想家の夢をリアリストが実現

**ENIACとノイマン型**

- チューリングマシン等は **机上の空論**、ENIACは存在したが **効率悪い・立ち上げが大変**。
- ノイマンは **配線を繋ぎ変えず、入力だけ変えればいろんな計算ができる** 方式を提案——**ノイマン型アーキテクチャ**（現代PCのほぼ全部）。
- 10進数コンピュータ議論に対し **2進数** を推奨。さらに **人間に覚えやすい8進数**（2の3乗まとまり）——現代の **16進数** 表記の思想的原型。

**特許騒動と結果**

- ENIAC改善案を **一般出版** → 元開発者が特許で儲けようとして **訴訟**。
- 判決：**知的財産を認めない** → 誰でも使える → 競争でコンピュータ普及加速——リアリスト的「世界のため」判断。

**批判ポイント**

- 若者のアイデアを **5段階先まで進めて自分の手柄に**——コンピュータでも同型の批判あり。結果的には普及が早まった。

**本編での扱い**

- 3回目にして **約10分で駆け足**——ノイマン生涯にくっつけるには不十分。堀本：**「計算機の歴史（パスカルからノイマンまで）」別シリーズ** を検討。

### 大きな流れ：伝統から実用性へ

- 第二次世界大戦で **世界経済の中心がヨーロッパ→アメリカ** へ。
- ヨーロッパ＝**伝統・文化**、アメリカ＝**プラグマティック・実用**——ノイマン自身もこの移動を体現。
- **「バロックの大伽藍にこもる」** 抽象議論を嫌い、有用なものを好む。
- 人類史・個人史ともに **夢見がちな伝統→現実的・実用的** へのシフト。その中で **最もリアリストな男が生んだ最も現実的な機械＝コンピュータ**。

### 本回の結論と今後

- **原爆の「良かった」とは言わない**——ノイマンが **見ていた景色・考えていたもの** を示し、「冷徹なクソ野郎」は **一面的** という話。
- 頭が良すぎて社交しない偏屈科学者（キャベンディッシュ、カント等）とは違い、**社交・人望** もあった稀有なタイプ。
- 全3回で紹介したやばいエピソードは **約6個／素材200個**——おまけ **「ノイマンウミガメのスープ」** 級の厳選雑談回を予告。
- 水野のフォロー：リアリスト論が **原爆正当化に聞こえる** リスク——本要約でも **評価ではなく視点の説明** である点を明示。
