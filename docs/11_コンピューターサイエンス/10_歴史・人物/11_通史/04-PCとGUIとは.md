# パソコン・GUI・日本のPC市場（1970〜1990年代）

> **この章を読むと分かること**
> - 「GUI」って何？ なぜ革命だったのか

## はじめに — パソコンは「個人のもの」になった

[[02-電子計算機とは|前章]]までで、コンピュータは部屋サイズから机サイズへ縮みました。ここから先、1970年代後半〜1990年代は、コンピュータが **「個人のもの」** になっていく時代です。

そしてこの時代に、現代の PC・Mac・スマホの **形** が決まりました。

```
時代の流れ
1977  Apple II        ← 家庭用コンピュータ革命
1981  IBM PC          ← ビジネス標準、x86アーキテクチャ普及
1982  PC-9801         ← 日本のガラパゴス市場
1984  Macintosh       ← GUI とマウスが個人へ
1995  Windows 95      ← 世界標準が日本にも上陸
2007  iPhone          ← タッチ操作の復活
```

---

## 1. Apple II — 家庭用コンピュータ革命（1977年）

### 1-1. 何が革命的だったか

1977年、Apple は **Apple II** を発売。これが現代の「家庭用パソコン」の起点です。

| 特徴 | 意義 |
|-----|------|
| **カラー表示** | 当時の他機はモノクロが主流 |
| **拡張スロット** | ディスクドライブやプリンターを後から追加可能 |
| **プログラミングが簡単** | ゲーム・教育ソフトが大量に作られた |
| **家庭・学校に普及** | パソコンが「個人や家庭で使うもの」になった |

Apple II の成功で、Apple は世界的なメーカーに飛躍します。

---

## 2. IBM PC と x86 — 業界標準の誕生（1981年）

### 2-1. IBM の参入

家庭用は Apple が席巻したものの、**ビジネス分野** にはまだ大規模に入ってきていません。そこで巨人 **IBM** が動きます。

| 年 | 出来事 |
|----|------|
| 1978 | Intel 8086（16ビット）登場 — 高性能だが高価 |
| 1979 | Intel 8088 登場 — 外部バスを8ビットにしてコストダウン |
| 1981 | **IBM PC** 発売 — 8088 を採用 |

### 2-2. 「設計を公開」した IBM の決断 — オープンアーキテクチャ

IBM は、それまでのような **独占** ではなく、PC の設計を **公開** する戦略を取りました。これによって何が起きたか：

```
IBM が設計を公開
       ↓
他社が「IBM 互換機」を作れるようになる
       ↓
価格競争 → どんどん安くなる
       ↓
Intel x86 アーキテクチャが世界標準になる
       ↓
IBM 自身よりも、Intel と Microsoft が勝者になる
```

これが現代まで続く **「x86 系の PC」** という基本枠組みの始まりです。Apple との競争の構図も、この時点でほぼ確立されました。

---

## 3. Macintosh と GUI 革命（1984年）

### 3-1. GUI とは何か（初心者向け）

**GUI（Graphical User Interface）** とは、**マウスで絵（アイコン）をクリックして操作する** インターフェースのことです。

| 種類 | 操作方法 | 例 |
|-----|--------|-----|
| **CUI（コマンドライン）** | 黒い画面に文字でコマンドを打つ | ハッカー映画でよく見るやつ、`cd`、`ls` など |
| **GUI** | アイコンをマウスでクリック・ドラッグ | Windows、macOS、スマホ |

> **CUI 時代に何かを開くには：**
> ```
> cd C:\Users\Documents
> open report.docx
> ```
> 全部 **文字で覚えて打つ** 必要があった。

GUI の登場は革命でした。**「絵を見てクリックするだけ」** になったことで、専門家でなくても誰でもコンピュータを使えるようになったのです。

### 3-2. Apple Lisa（1983年）と Macintosh（1984年）

GUI の原点は **Xerox PARC**（ゼロックスの研究所）で開発されたものでしたが、Xerox はそれを商品化しませんでした。

そこに目を付けたのが Apple のスティーブ・ジョブズ。Xerox PARC を見学してインスピレーションを得て、Apple は GUI を商品化します。

| 製品 | 年 | 結末 |
|-----|----|----|
| Apple Lisa | 1983 | 1万ドル超 → 高すぎて売れず |
| **Macintosh** | 1984 | 約2,500ドル → 大成功 |

Macintosh は **マウス操作** を一般向けに **初めて普及** させた製品となりました。デザイン・音楽制作などのクリエイティブ分野で熱狂的な支持を得ます。

## 4. PC-98 — 日本だけのガラパゴス市場

### 4-1. 「国民機」PC-9801（1982年）

1982年、NEC が発売した **PC-9801**（通称 PC-98）が、日本の PC 市場を独占します。

| 項目 | スペック・特徴 |
|-----|--------|
| CPU | Intel 8086（16ビット） |
| 価格 | 29万8000円 |
| 強み① | **日本語処理**（漢字ROM標準搭載） |
| 強み② | **上位互換性**（古いソフトが新しい機種で動く） |
| 表示 | 640×400、256色（当時としては圧倒的） |

1980年代後半には **国内シェア90%超え** — ほぼ独占。あらゆる名作ゲーム（信長の野望、三国志、ときめきメモリアル等）が PC-98 上で動き、ビジネスから教育、ゲームまで日本中で「パソコン＝PC-98」でした。

### 4-2. なぜ強かったのか — 日本語処理

当時の海外製パソコン（IBM PC など）は **英語圏向けで漢字表示が非常に貧弱** でした。一方、PC-98 は **16×16ドットの漢字ROM** を標準搭載し、**ビジネス文書が実用的に作れる唯一の選択肢** だったのです。

「日本語を扱える」 — これが鉄壁の参入障壁でした。

### 4-3. なぜ滅んだのか — Windows 95 という黒船

しかし、世界では **IBM PC互換機（Windows 機）** が広がっていました。

```
PC-98の運命
日本市場を独占 = 世界標準から孤立
       ↓
世界では IBM PC互換機 + Windows が標準化
       ↓
1995年 Windows 95 が日本上陸
       ↓
日本語処理を Windows 側が解決 → PC-98 の最大の強みが消滅
       ↓
価格競争で安い互換機に押される
       ↓
PC-98 滅亡
```

PC-98 は **「日本だけで最強」** だったがゆえに、**世界標準と戦えなかった**。これがガラパゴス化の典型例として語り継がれます。

> **教訓**：閉じた市場で強いことは、外から黒船が来たときの **武器にならない**。

## 5. タッチ操作はなぜ「一度負けて」、「また勝った」のか

### 5-1. 衝撃の事実 — タッチ操作の方が先

実は **タッチ操作はマウスより古い** 発明です。

> **1963年、スケッチパッド** — GUI の先駆けとなった論文。**ライトペン**（画面の光を読み取るデバイス）で画面を直接タッチして操作するシステムでした。

**「画面に映ったものを直接触る」** — これは人間にとって最も自然な発想です。子供がタブレットを直感で使えるのも、この自然さの証拠です。

### 5-2. なぜタッチ操作は一度滅んだのか — ゴリラアーム問題

しかし、**長時間使うと手が疲れる** という致命的な問題がありました。

特に当時の PC は大画面。画面の端から端までペンや指で移動し続けると、腕が **パンパン** に。これを **ゴリラアーム** と呼びます。

```
画面の上 ──── ゴミ箱
   ↑              ↑
 ファイル          ここまでドラッグ
                  ↓
            腕が疲れる（ゴリラアーム）
```

### 5-3. マウスの「気持ち悪さ」が解決した

マウスを発明したのは **ダグラス・エンゲルバート**。

> **マウスの本質的な発想**
> 「画面と無関係な場所にあるデバイスを操作して、画面上の矢印を動かす」
> 
> これは直感的に気持ち悪い発想。最初に触った人は「狙いを定めても全然そこに行かない」と戸惑う。

しかし、これによって **手の位置を画面から解放** することができました。手元の小さな動きで画面の隅々まで到達できる — 結果として **疲れない**。

> **気持ち悪い発想こそが、人間を画面から解放する革命だった。**

### 5-4. なぜスマホでタッチが復活したのか

2007年の iPhone 以降、タッチ操作が一気に復活します。なぜか？

**答えは「スマホは小さいから」**。

```
PC：       画面が大きい → 端から端まで指で動かすと疲れる（ゴリラアーム）
スマホ：   画面が小さい → 端から端まで動かしても疲れない
            ↓
さらに、小さいから手に持てる
            ↓
画面が常に目の近くにある（PC のように離れて見ない）
            ↓
タッチが理にかなう
```

つまり、**タッチ操作が優れているからスマホで普及した** のではなく、**スマホが小さいからタッチが向いていた** のです。

> **教訓**：道具と用途は、形と規模の関係で決まる。「優れているもの」が常に勝つわけではない。

## 6. この章のまとめ

### 1970〜1990年代の流れ

| 年 | 出来事 | 意義 |
|----|------|----|
| 1977 | Apple II | 家庭用パソコンの誕生 |
| 1981 | IBM PC | x86 アーキテクチャの世界標準化 |
| 1982 | PC-9801 | 日本市場のガラパゴス支配開始 |
| 1984 | Macintosh | GUI・マウスの個人普及 |
| 1995 | Windows 95 | 世界標準が日本にも到来、PC-98 衰退 |
| 2007 | iPhone | タッチ操作の復活、スマホ時代へ |

### 大きな構図

```
┌─────────────────────────────────────────┐
│  PC・GUI の三大潮流                      │
├─────────────────────────────────────────┤
│  ① Apple路線（独自・GUIプロ向け）        │
│  ② IBM/Windows路線（互換機・標準・量産） │
│  ③ 日本独自路線（PC-98・ガラパゴス）     │
└─────────────────────────────────────────┘
        ↓ 時間
   ① と ② が世界を二分、③ は1995年に滅亡
```

### 大切なポイント

1. **「設計を公開する」勇気が標準を作る**
   IBM PC のオープン化が、Microsoft と Intel を勝者にした。閉じた成功（PC-98、Lisa）は短命に終わりがち。

2. **GUI = 専門家でないと使えなかったコンピュータを「みんなのもの」にした**
   黒い画面と謎のコマンドから、絵を見てクリックする世界へ。

3. **操作方法は「形と用途」で決まる**
   - PC（大きい・固定）→ マウス
   - スマホ（小さい・手に持つ）→ タッチ
   
   「優れた発明」だから勝つのではなく、状況に合うから勝つ。

4. **ガラパゴスの教訓**
   日本市場の最適化が、世界標準から取り残される原因にもなる。今でも繰り返される話。
