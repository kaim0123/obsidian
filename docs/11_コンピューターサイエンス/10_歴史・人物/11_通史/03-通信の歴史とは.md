# 通信の系譜（計算機史と並行する系統）

> **この章を読むと分かること**
> - なぜ「電気通信」が世界を変えたのか

> - 海底ケーブルが江戸時代末期にはもう引かれていた驚き
> - 日本が「通信主権」をめぐって戦った隠れた歴史
> - 日本人が世界中の電話の中身を作っていた話

## はじめに — もう1つの「コンピュータ史」

ここまで（[[01-計算の机械化とは|第1節]]・[[02-電子計算機とは|第2節]]）は「計算機」の歴史を見てきました。しかし現代のコンピュータ／インターネットには、もう1つの大きな源流があります — **通信の歴史** です。

```
       ┌─────────────┐
       │  現代の      │
       │  コンピュータ │
       └──────┬──────┘
              │
   ┌──────────┴──────────┐
   │                      │
[計算機の系譜]          [通信の系譜]
バベッジ → ENIAC        モールス → 電話 → ネット
   │                      │
ノイマン型 ←──────────── 合流 → 今のスマホ
```

この章では、後者の流れを追います。

## 1. 通信の遅さは命に関わる時代

### 1-1. 「8週間遅れ」が最速だった時代

1800年代初頭、世界で最も速い新聞といえばイギリスの **タイムズ紙**。それでも、アフリカで起きた事件が紙面に載るまで **8週間** かかっていました。これがその時代の「最速」です。

他の小さな新聞はもっと遅く、隣町の新聞をパクって翌日掲載する文化があり、ニュースが街から街へ **1日ずつ移動** していた結果、田舎の新聞では **半年前の記事** が「最新」として載っていたという話もあります。

> **当時のニュース伝達**
> 事件発生 → 馬車・船で運ばれる → 数週間〜数か月かけて新聞に → 街から街へゆっくり広がる

人類はずっとこの「8週間遅れの世界」で暮らしていました。これを一気に変えたのが **電気通信** です。

### 1-2. なぜ電気で通信できるはずだと考えたのか

「電気はものすごく速く伝わる」 — これが分かれば、遠くの人にも一瞬で情報を送れるはず。しかし1800年代初頭、誰も電気の速さを正確には知りませんでした。

## 2. 神父の残酷な実験 — 1746年

### 2-1. 200人の修道士を並べて電流を流した男

1746年、パリの修道院でとんでもない実験が行われました。

> **ノレ神父の実験**
> 1. 200人の修道士を **円形** に並べる
> 2. 全員に金属の同線を持たせる
> 3. **何の予告もなしに** 強い電流を流す
> 4. みんなが「ぎゃー！」と叫ぶタイミングを観察する

円の長さは **約1.6km**。最初の人と最後の人が **ほぼ同時** に叫んだら、それは電気が一瞬で伝わった証拠になる、という発想です。

なぜ予告なしかというと、「隣の人がびっくりして叫んだ」のではなく「電流が伝わったから叫んだ」と区別するためです — **実験デザインが意外にも科学的** だったわけです（人としてはサイコパスです）。

### 2-2. 実験結果と意義

実験の結果、修道士たちはほぼ同時に叫び、「**電気はほぼ瞬時に伝わる**」ことが分かりました。

> **現代の知見**：電気はほぼ光の速さ（秒速30万km、1秒で地球を7周半）で伝わる

ちなみにノレ神父は「電気通信したいから」ではなく **単なる好奇心** でこの実験をやりました。それでも結果として、後の電気通信の基礎情報になります。

> **教訓**：愚かさも、サイコパスも、好奇心で動く科学者も、何が後に役立つかは予測できない。

## 3. モールス信号 — 愚か者が世界を変えた話

### 3-1. サミュエル・モールス — ダメ商売人

50年後、**サミュエル・モールス** という男が登場します。彼の経歴は、現代でいう「典型的なダメ起業家ワナビー」でした。

- 美術教育を受けたが、自分で絵を描く代わりに **美術品の偽物を大量生産** して売ろうとした
- ルーブル美術館の絵を1枚のキャンバスに **全部詰め込んで** 「これ1枚で美術館全部見れる」というファスト教養ビジネスを構想
- リサーチ不足で、すでに他人がやっていることを「俺が世界を変える」と思い込みがちな性格

### 3-2. 船旅で聞いた話

ある日、モールスは船旅でノレ神父の実験の話を聞きます。「電気は一瞬で伝わる」と。

**実はこの時点で、電気通信の研究は30年進んでいて、科学者たちは『遠距離だと電流が弱まる』という壁にぶつかり、実用化を諦めかけていました。**

しかし **モールスはそのことを知らなかった** ので、「電気で通信できる！ 俺は天才だ！」と猛進します。船の中でひたすらビジネスアイデアを書き殴り、降りた後もこの話ばかりするようになります。

> **「リサーチ不足が功を奏した」というレアケース**：もし長距離通信の難しさを知っていたら、彼も諦めていた。知らなかったからこそ、信号の設計に集中できた。

### 3-3. モールス信号とは何か（初心者向け）

モールス信号は **トン・ツー** の2種類だけで全ての文字を表す符号です。

```
A = ・−        N = −・
B = −・・・    O = −−−
C = −・−・    ...
（・ = トン、− = ツー）

例：SOS = ・・・ −−− ・・・
```

**なぜトンとツーだけ？** これを理解するには、電気通信の仕組みを知る必要があります。

> **モールス信号が必要な理由**
> 電池に同線をつないで、一方を「つけたり消したり」できるとします。同線を伸ばして遠くの豆電球まで届けると、遠くの人は **豆電球のオン・オフだけ** から情報を読み取れます。
> 
> つまり通信線は **1か0か** という最も単純な信号しか送れない。これで文字を伝えるには「短いオン（トン）」と「長いオン（ツー）」の組み合わせで符号化するしかないわけです。

懐中電灯で離れた友達と通信するときに使うのと同じ仕組みです。光・音・電気、何でも「オン・オフ」さえあればモールス信号で文字が送れます。

### 3-4. モールス信号 vs ライバル — なぜ「1本の線」が勝ったのか

実はモールスにはライバルがいました。**クックとホイートストン** の方式です。

| 方式 | 仕組み | 視認性 | コスト |
|-----|------|------|------|
| **クック・ホイートストン式** | 5本の線で、針が交差する位置から文字を直接読む | ◎（一瞬でわかる） | × 線が5倍必要 |
| **モールス式** | 1本の線で、トン・ツーの組み合わせ | △（熟練必要） | ◎ 線が1本 |

短距離なら見やすい多線式が有利。でも **海底ケーブル** で世界を覆おうとした瞬間、話は変わります。

- 1本でも引くのが大変な海底ケーブル、5倍引くなんて不可能
- 線が増えるほど **故障リスクも倍々**

> **結果**：「世界中をケーブルでつなぐ」という大きな夢を **無謀にも** 持っていたモールスが勝った。

### 3-5. なぜ長距離でも電流が届くのか — リレーの発明

「電流が長距離で弱まる」問題はどう解決されたのか。答えは **リレー** という回路です。

> **リレーの仕組み（初心者向けの例え）**
> 寝ているA君を、0.1の力でつついても起きないとします。でも、0.1で起きる仕組み「目覚まし時計（リレー）」があれば、A君のところに置いておけば、弱った信号でも目覚まし時計が反応して、A君を起こせる（＝1の出力に戻せる）。
> 
> これを途中に何個も置けば、信号は何度でも「リフレッシュ」されて、無限に遠くまで届く。

リレーが発明されてから、電気通信は地球を覆い始めます。

## 4. 海底ケーブル — 江戸時代末期からの大事業

### 4-1. 1858年に大西洋横断ケーブル

驚くべきことに、**1858年** には早くも **大西洋を横断する海底ケーブル** が引かれ、ヨーロッパとアメリカが繋がっていました。

> 日本史で言うと **明治維新（1868年）より10年前**。まだ侍が刀を差して歩いていた時代に、欧米列強は **海底ケーブルで通信** していたのです。

### 4-2. ケーブルの中身

海底ケーブルといっても、中身はシンプルです。

```
   ┌────────────────────┐
   │  保護カバー        │
   │  ┌──────────────┐  │
   │  │  ただの銅線   │  │
   │  └──────────────┘  │
   └────────────────────┘
```

ただし途中に **中継局（リレー）** が必要で、海底ケーブルでは深海に沈める専用の中継器を組み込みます。

### 4-3. クジラと工事の苦労

海底ケーブル工事は当然トラブル続きでした。船で引っ張りながら沈めていく作業中、クジラが現れてパニックになる事件もありました。

> **現代の感覚で言うと**：宇宙エレベーターを19世紀に作っているレベル。

## 5. 日本と海底ケーブル — 知られざる不平等条約

### 5-1. 明治4年に日本初の海底ケーブル

日本初の海底ケーブルが開通したのは **1871年（明治4年）**。これは **日本初の鉄道（横浜〜新橋、明治5年）より前** です。

「鉄道より先に海底ケーブル」というのは直感に反しますが、それだけ世界の通信網が早く動いていたという話です。

### 5-2. なぜ「デンマーク」が日本にケーブルを引いたのか

技術力も資金力もない明治初期の日本は、外国にケーブル敷設を頼みました。その相手が **デンマーク** の会社（**大北電信会社**）です。

なぜデンマーク？ — 当時 **イギリスは世界のケーブルの3分の2を所有** する大国で、各国が「これ以上イギリスにケーブル網を握らせたくない」と警戒していました。

> ロシア「イギリスのケーブルがうちを通るのは嫌だ。でもデンマークなら小国だし、まあいいか」

つまり **デンマークは「敵が少ない小国」だったからこそ** 通信外交で活躍できたのです。

### 5-3. 知られざる「不平等条約」

歴史の教科書に載る不平等条約（関税自主権・治外法権）と同じ時期、**通信版の不平等条約** がありました。

- 大北電信会社が、当初は「日本の **国内通信** まで全部独占したい」と要求
- 明治政府の **寺島宗則**（日本電気通信の父）が「国内通信主権は渡さない」と拒否
- しかし後年、**朝鮮半島での反乱対応** で焦った日本が、しぶしぶ国際通信の独占権を譲渡してしまう

結果、日本〜上海間の通信料は、同じ距離のイギリス〜デンマーク間の **約4倍** という「不平等価格」を払い続けることになりました。

### 5-4. 太平洋ケーブルで脱出 — 1906年

この状況を打破するため、**日本〜アメリカの太平洋横断ケーブル** が構想されます。しかしアメリカの領土内に「日本の陸揚げ局」を作るのは国防上の問題があり、外交交渉が難航しました。

ここで活躍したのが **小村寿太郎**。関税自主権の交渉で有名な、あの小村です。

> **日本史好きへ**：「関税自主権を取り戻したのも、隠れた通信主権を取り戻したのも、両方とも小村寿太郎」と覚えておくと話が一本にまとまります。

1906年、太平洋ケーブル開通。とはいえ完全な独立ではなく、表向きはアメリカの企業（コマーシャル・パシフィック・ケーブル）と組んだ形でしたが、**実は大北電信が株の25%を持っていた** という結末。

それでも徐々に日本は通信主権を取り戻し、現在ではほぼ完全に自立しています。

### 5-5. 福岡北部はなぜ「海底ケーブルの要衝」か

現代の日本でも、海底ケーブルの陸揚げ局は **福岡県北部** に集中しています。理由は地理 — 朝鮮半島に近いからです。

実は **元寇（モンゴル軍襲来）の防衛拠点** も福岡北部の同じ場所。

> **時代が変わっても、地理は変わらない。要衝はいつも同じ場所にある。**
> ケーブルを通して歴史を見ると、地政学が見えてきます。

## 6. 電話の中身は日本人が作った — 音声学と工学の出会い

### 6-1. 電話で「セミの声」が聞こえない理由

豆知識：**電話越しではセミの鳴き声がほとんど聞こえません。**

これは、人間の声の周波数から外れた音は **送らない設計** になっているからです。**通信データを減らすため** に高周波（セミ）や低周波（重低音）はカットされています。

Zoom で甲子園のサイレンの真似をしても声が全部消えるのも同じ理由です。

### 6-2. 電話は遅延に超シビア

電話は **遅延に異常にシビア** なメディアです。0.2秒で「ターン交代」が起きる会話で、1秒遅延すると会話が崩壊します。

そのため電話の歴史は、ある意味 **「データ削減の歴史」** と言えます。いかに少ない情報で「同じ声に聞こえる」ようにするか。

### 6-3. 板倉文忠先生 — 名古屋大学が生んだ世界標準

**1970年頃**、名古屋大学の **板倉文忠先生** が、電話のデータ量を **95%削減**（1/20まで圧縮）する手法を確立しました。

| 技術 | 効果 |
|-----|------|
| **線形予測符号化（LPC）** | 音声の波形を予測モデルで圧縮 |
| 0.02秒（20ms）を1フレームに分割 | 短時間なら声はほぼ一定 |
| 過去8個のサンプルから現在を予測する係数 | 160個の点を **8個の数字** で表現 |

> **直感的にいうと**：1秒分の音声を全部送るのではなく、「過去のパターンから次が予測できる係数」だけを送れば、受信側で復元できる。

この技術が **現代のスマホの電話・ネット電話の世界標準** になっています。あなたが今日電話するたびに、板倉先生のアルゴリズムが動いています。

### 6-4. 音声学と工学の合流 — エモい話

面白いのは、板倉先生は **元々音声学の専門家ではなかった** ことです。手書き文字認識など、統計信号処理の研究者でした。

音声の研究を始めて、統計手法をいろいろ試して、うまくいくモデルにたどり着いて、後から気づきました。

> **「あれ、このモデル『音源（声帯）＋フィルター（口の形）』に対応しているな」**

これは **音声学** で前から知られていた「ソース・フィルター・モデル」と完全に一致します。**工学と音声学が、別々のアプローチで同じ答えにたどり着いた** のです。

```
工学（板倉）  ：データ圧縮 → 統計モデル → ある形に収束
                              ↓
                          一致！
                              ↑
音声学      ：人間の発声 → 声帯と口の構造 → ソース・フィルター・モデル
```

研究の中で最も「エモい」瞬間 — **違う分野が同じ場所で合流する** という体験です。

## 7. この章のまとめ

### 通信の歴史 — 一本の線で

```
1746年  ノレ神父の人体実験     ← 電気の速さを測る
   ↓
1820年代 ボルタ電池の発明       ← 安定した電源
   ↓
1830年代 モールス、信号を考案   ← 1本の線で通信
   ↓
1858年   大西洋横断ケーブル     ← 江戸時代末期に既に世界が繋がる
   ↓
1871年   日本初の海底ケーブル   ← デンマーク企業が敷設
   ↓
1906年   太平洋横断ケーブル     ← 日本がアメリカと繋がる
   ↓
1970年代 板倉先生のLPC          ← 日本人が電話の中身を世界標準に
   ↓
現代     光ファイバー、5G        ← ベースは全部「0と1のオン・オフ」
```

### 大切なポイント

1. **通信もコンピュータと同じく「0/1のオン・オフ」が原点**
   モールス信号も、現代の光ファイバー通信も、根本は同じ「デジタル」の発想。

2. **長距離通信を可能にした2つの鍵**
   - リレー（信号の中継再生）
   - 海底ケーブル敷設の技術

3. **地政学を見ないと通信史は分からない**
   ケーブルがどこを通るか、誰が敷設するかは、その時代の **国際関係そのもの**。

4. **「合流するエモさ」**
   通信の歴史と計算機の歴史は、20世紀後半に1本に合流して、現代の **インターネット** になります（[[05-インターネット以降とは|次々章]] へ）。
