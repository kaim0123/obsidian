# インターネット以降（1990年代〜現代）

> **この章を読むと分かること**
> - インターネットはなぜ「軍事研究から生まれた」のに「自由なネット」なのか
> - ブラウザ戦争で IE と Netscape が何を争ったのか
> - SNS は私たちの社会をどう変えたのか
> - クラウドとAIが現代の何を支えているのか

---

## はじめに — 「人類の合作」としてのインターネット

インターネットは **一人の天才の発明ではありません**。何十人もの研究者、複数の国の機関、思想・失敗・偶然の積み重ねによってできた **人類の合作** です。

そして奇妙な矛盾を抱えています。**軍事研究から生まれたのに、自由の象徴になった。**

なぜそんなことが起きたのか — この章ではその答えを追います。

```
1960年代  冷戦・ARPANET    軍事研究としてのスタート
   ↓
1969年    最初の接続        UCLA からスタンフォードへ「LO」
   ↓
1983年    TCP/IP 採用       インターネットの共通言語
   ↓
1989年    World Wide Web    ティム・バーナーズ＝リーが Web を発明
   ↓
1990年代  ブラウザ戦争      Mosaic → Netscape → IE
   ↓
2000年代  Web 2.0、スマホ   ブロードバンド、iPhone（2007）
   ↓
2010年代  SNS、クラウド     Twitter、Facebook、AWS
   ↓
2020年代  生成AI            ChatGPT
```

## 1. なぜインターネットは「軍事研究」から生まれたのか

### 1-1. 冷戦と「通信が死ぬ」恐怖

1960年代、アメリカとソ連は **核戦争一歩手前** の冷戦状態にありました。1962年のキューバ危機では、人類が核戦争の **13日間** を体験しました。

軍の最大の弱点は **通信** でした。

```
当時の通信網（中央集権型）
                       ↑
                       │攻撃される
                  ┌──[中継拠点]──┐
                  │              │
              [拠点A]          [拠点B]
                  │              │
              [拠点C]          [拠点D]
              
中継拠点を破壊されれば → 通信網全体が機能停止
        ↓
指揮系統が消える → 軍隊として機能不能
```

「攻撃されても確実に報復できる」という確信がなければ、**相互確証破壊（MAD）** の均衡も崩れます。

### 1-2. AT&T に断られた「壊れても生き残る通信」

軍は通信会社の **AT&T** に「核攻撃を受けても生き残る通信網を作れないか」と相談しました。AT&T の答えは「**ノー**」。既存の電話インフラに巨額投資済みで、ビジネスモデルを否定する話には乗れなかったのです。

### 1-3. ポール・バランの「分散ネットワーク」

軍はシンクタンク **RAND** に課題を外注。**ポール・バラン** という研究者が画期的な答えを出します。

> **分散ネットワーク** — 中央拠点を作らず、すべてのノードを対等に網の目状に繋ぐ。

```
3つのネットワーク構造
                                    
中央型             分散型             完全分散型
   ●               ●─●─●            ●─●─●─●
  /│\             /│\               │X│X│
 ●─●─●          ●─●─●              ●─●─●─●
  \│/                                │X│X│
   ●                                 ●─●─●─●

中央を壊すと        強い拠点を壊す      壊す中心がない
全滅              と分断される        最も頑強
```

数学的には **グラフ理論** で分析され、十分な冗長性があれば、たとえ大半のノードが破壊されても通信が維持できる、と証明されました。

しかし AT&T の技術者は「素人が書いた空想」と一蹴。後にインターネットの基礎となる発想は、**最初は誰にも理解されなかった** のです。

### 1-4. パケット交換とは何か（初心者向け）

バランとは別に、イギリスのドナルド・デイビスが似た発想を **独立に** 提案。彼が名付けたのが **パケット交換（Packet Switching）** という言葉です。

> **パケット交換とは**
> データを **小さな塊（パケット）** に分割して、それぞれが **別々の経路** で目的地へ届く。受信側で組み立て直す。

```
従来の電話（回線交換）
A ━━━━━━━━━━━━━━━━━━━━━━ B
       1本の回線を独占
       
パケット交換（インターネット）
A ──┬── 経路① ──┬── B
    ├── 経路② ──┤
    └── 経路③ ──┘
    
複数の経路を使い分け、一部が壊れても別経路を使える
```

これがインターネットの根本原理です。今あなたがこのページを読んでいる通信も、内部では小さなパケットに分割されて、複数経路を経由してあなたの端末に届いています。

## 2. ARPANET — 1969年に最初の接続

### 2-1. 公式な目的は「コンピュータ資源の共有」

**ARPA**（Advanced Research Projects Agency）は1958年、ソ連のスプートニク打ち上げのショックで設立された米国の研究機関です。

その情報処理部門 **IPTO** が ARPANET プロジェクトを進めました。注目すべきは：

> **ARPANET の公式な設立目的は「コンピュータ資源の共有」**
> 「核攻撃対策」は後付けの神話。分散構造を採用した **結果として** 核対策にもなった、というのが正確な順序です。

### 2-2. 最初の4拠点はすべて大学

最初に接続された4拠点：

- UCLA（カリフォルニア大学ロサンゼルス校）
- スタンフォード研究所
- カリフォルニア大学サンタバーバラ校
- ユタ大学

**全て大学・研究所。軍事施設は1つもありません。** 軍の予算で作ったのに、最初から使っていたのは大学の研究者 — この **出資者と利用者のずれ** が、後の「自由化」の原動力になります。

### 2-3. 「LO」 — 人類初のインターネット通信

**1969年10月29日**、UCLA のチャーリー・クラインがスタンフォードへ「login」と送信しました。しかし途中でクラッシュし、届いたのは **「LO」** だけ。

これが人類初の ARPANET 通信として記録された **部分的成功** です。

## 3. オープン文化 — なぜインターネットは「自由」になったのか

### 3-1. 軍の研究なのに秘密にしなかった

通常、軍事研究は機密扱いです。しかし ARPA は「**成果は公開せよ**」という方針を取りました。

加えて、研究者コミュニティには独自の規範がありました。

> **知識はオープンに共有し、誰もが対等に参加できる**

### 3-2. RFC — 「ご意見をお聞きしたい」という謙虚さ

1969年4月、UCLA の大学生スティーブ・クロッカーが最初の **RFC（Request for Comments）** を執筆しました。

| RFC の特徴 | 意味 |
|--------|------|
| Request for Comments | 「意見をお聞きしたい」という謙虚な名前 |
| 「暫定的な提案」 | 権威ある文書ではない、と明記 |
| 誰でも書ける | 大学生でも仕様を提案できる |

インターネットの仕様は、特定企業が独占的に決めるのではなく、このプロセスで決まり続けています。**今も RFC 9000番台** まで続いています。

### 3-3. IETF — 「我々は国王を持たない」

仕様策定組織 **IETF**（Internet Engineering Task Force）のスローガンは衝撃的です。

> **「We reject: kings, presidents, and voting.」**
> （我々は国王も、大統領も、多数決も拒否する）

代わりに **「rough consensus and running code」**（おおよその合意と、動くコード）で物事を決める。誰でも参加し、技術的な根拠で合意を作る。これがインターネットの文化の核です。

## 4. TCP/IP と「インターネット」の誕生

### 4-1. ヴィント・サーフとボブ・カーン

1974年、**ヴィント・サーフ** と **ボブ・カーン** が **TCP/IP** の論文を発表。彼らが「インターネットの父」と呼ばれる所以です。

| プロトコル | 役割 | 例え |
|---------|------|----|
| **IP**（Internet Protocol） | 宛先を決める | 封筒の宛名 |
| **TCP**（Transmission Control Protocol） | 確実な到達を保証 | 内容証明郵便 |

### 4-2. 「特許を取らなかった」決断

サーフは後にこう語っています。

> **「TCP/IP は特許を取らなかった。取っていたらここまで普及しなかった。」**

オープンにすることで、誰もが自由に実装でき、技術は爆発的に広がりました。

1983年1月1日、ARPANET 全体が NCP（旧プロトコル）から TCP/IP に切り替えられました。これを「**Flag Day（旗の日）**」と呼びます。**この日が「インターネット」の正式な誕生日** と言ってもよいでしょう。

## 5. World Wide Web の誕生（1989年）

### 5-1. ティム・バーナーズ＝リー

1989年、CERN（欧州原子核研究機構）の **ティム・バーナーズ＝リー** が **World Wide Web** を発明しました。

```
インターネット ≠ Web
                   
インターネット  ＝ 物理的・論理的な通信網
       Web    ＝ その上で動く「ハイパーリンクされた文書システム」
```

- **HTTP**（通信プロトコル）
- **HTML**（文書の書き方）
- **URL**（住所の付け方）

この3つの組み合わせで、現代の Web が始まりました。

### 5-2. Mosaic — 最初の絵が表示されるブラウザ（1993年）

**Mosaic（モザイク）** は初めて画像を表示できる Web ブラウザでした。

それまで Web ブラウザは **テキストしか表示できなかった**。Mosaic は：

- 画像の表示
- クリックでリンクを開く
- ブックマーク機能

など、今では当たり前の機能を備え、爆発的に普及します。

## 6. Windows 95 と一般家庭への普及（1995年）

### 6-1. なぜ Windows 95 は大事件だったのか

1995年8月、**Windows 95** が発売されます。

| 特徴 | 意味 |
|-----|------|
| 使いやすい GUI | 一般家庭でも使えるレベルに到達 |
| **Internet Explorer 標準搭載** | ブラウザ必須の時代に大きな利点 |
| Plug and Play | 周辺機器を簡単接続 |

CM には Rolling Stones の「Start Me Up」が使われ、Microsoft は宣伝に **3億ドル** を投入。発売日には世界中で長蛇の列ができました。

そして **同じ年に、PC-98 という日本のガラパゴス王者が滅亡** していくのです（→ [[04-PCとGUIとは|04-PCとGUI]] 参照）。

## 7. ブラウザ戦争 — IE vs Netscape（1995〜1999年）

### 7-1. ブラウザの覇権争い

| 年 | Netscape Navigator | Internet Explorer |
|----|------------------|------------------|
| 1994 | 登場、80%のシェアを獲得 | （まだない） |
| 1995 | シェア80% | Windows 95 搭載 |
| 1997 | シェアじりじり減少 | 急成長 |
| 1999 | 衰退 | **市場の大半** を握る |

### 7-2. なぜ Netscape は負けたのか

- Microsoft は IE を **Windows に無料バンドル**
- Netscape は単体販売モデルで対抗できず
- Microsoft は **独占禁止法訴訟** で叩かれるが、市場は IE に流れた

> **教訓**：「最強の OS にバンドルされている」というのは、製品自体の良し悪しを超える力を持つ。これは後の Apple のサファリ、Google のクロームの戦略にも影響しました。

## 8. 2000年代 — ブロードバンドとモバイル革命

### 8-1. ダイヤルアップから光へ

```
1990年代  ダイヤルアップ（56kbps）   写真1枚に数分
   ↓ 100倍
2000年代  ADSL（約8Mbps）
   ↓ 12倍
2000年代後半  光ファイバー（100Mbps+） 動画が普通に見られる
```

これが現代の感覚に近づく分岐点でした。**YouTube（2005年）** や **オンラインゲーム** はブロードバンドなしでは成立しません。

### 8-2. iPhone（2007年） — すべてを変えた製品

| iPhone 以前 | iPhone 以後 |
|-----------|-----------|
| 携帯は通話とメール中心 | 本格的なインターネットを持ち運び |
| 物理キーボード | タッチパネル |
| メーカー専用アプリのみ | App Store で誰でもアプリを配信 |

タッチ操作がスマホで復活した話は [[04-PCとGUIとは|前章]] 参照。

### 8-3. クラウドの誕生 — AWS

**AWS（Amazon Web Services）**（2006年〜）が「クラウドコンピューティング」の概念を一般化しました。

> **クラウドとは何か（初心者向け）**
> 自社でサーバーを買う代わりに、Amazon などの巨大データセンターを **借りる** モデル。必要な時に必要な量だけ使い、使った分だけ払う。

これが現代のスタートアップ文化を支えています。今あなたが使っているサービスのほとんどは、AWS / Google Cloud / Azure のどれかの上で動いています。

## 9. 2010年代 — SNS と AI の時代

### 9-1. SNSが社会を変える

| サービス | 特徴 |
|--------|------|
| **Facebook** | 実名ベースの友人ネットワーク |
| **Twitter（X）** | 短文・リアルタイム・拡散性 |
| **Instagram** | 写真・ビジュアル中心 |
| **TikTok** | 短尺動画＋AIレコメンド |

SNS は単なるコミュニケーションツールを超えて、**社会運動の場** にもなりました。

- **#MeToo**（性被害告発）
- **Black Lives Matter**（人種差別反対）
- アラブの春（民主化運動）

ハッシュタグキャンペーンが、政治と社会を動かす力を持つようになりました。

### 9-2. AIの躍進 — 古典から大規模言語モデルへ

**2010年代** に **ディープラーニング** が大躍進。

| 年 | 出来事 |
|----|------|
| 2012 | ImageNet 画像認識で DNN が圧勝 |
| 2016 | AlphaGo が囲碁世界王者を破る |
| 2017 | Transformer 論文（"Attention is All You Need"） |
| 2022 | ChatGPT 公開、生成AI ブーム |

## 10. この章のまとめ

### 1本の線で

```
1960年代  冷戦の恐怖
            ↓
        分散ネットワークの発想（バラン）
            ↓
1969年   ARPANET（軍予算、しかし大学で運用）
            ↓
        オープン文化（RFC、IETF、TCP/IPの非特許化）
            ↓
1983年   TCP/IP 採用、インターネット誕生
            ↓
1989年   World Wide Web 発明（バーナーズ＝リー）
            ↓
1993年   Mosaic 登場、画像のあるWebへ
            ↓
1995年   Windows 95 + IE、一般家庭への普及
            ↓
2000年代 ブロードバンド + iPhone
            ↓
2010年代 SNS + クラウド + AI
            ↓
現在     生成AI、ポストインターネット時代へ
```

### 大切なポイント

1. **インターネットは「人類の合作」**
   一人の発明ではなく、何十人もの思想・失敗・偶然の積み重ね。

2. **「軍事研究 → 自由なネット」の理屈**
   - 軍は「壊れても生き残る通信」が欲しかった → 中央のない分散構造
   - 研究者は「誰でも参加できるオープンなネット」が欲しかった → オープン文化
   - 両者の **「中央に支配を委ねない」** という点で目的が一致した

3. **オープンが勝つ**
   - TCP/IP の非特許化
   - RFC の謙虚さ
   - Linux、Wikipedia、ブラウザのオープンソース化
   
   閉じた標準（PC-98 や Netscape）よりも、開いた標準が長期的に勝つ傾向。

4. **インフラの世代交代がアプリを生む**
   - ダイヤルアップ → YouTube は不可能
   - ブロードバンド → YouTube が成立
   - スマホ + 4G/5G → TikTok が成立
   
   ハードの限界がソフトを規定する。
