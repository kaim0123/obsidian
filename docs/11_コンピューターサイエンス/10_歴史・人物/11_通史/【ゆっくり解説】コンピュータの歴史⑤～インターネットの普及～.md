## 要約

コンピュータの歴史全7回シリーズの第5回。**2000年代**——インターネットが **本格的に発展** し、**ブロードバンド**・**モバイル革命**・**Web 2.0**・**クラウド** の基盤が整った時代を解説する。ダイヤルアップから光回線への移行、iPhone/Android の登場、CPU・GPU の進化、セキュリティ問題の顕在化、AWS によるクラウド時代の幕開けまでをたどる。

### シリーズの位置づけ

- 前回（1990年代）が「インターネットの始まり」なら、**2000年代** は **インターネットが本格発展** した時代。
- 本回の焦点：**ブロードバンドの普及**、**モバイル革命**、**Web 2.0**。
- 後半には **スマートフォン** や **クラウド** が登場—— **今の時代の基盤** がこの十年で形作られた。

### ブロードバンド革命：ダイヤルアップ → ADSL → 光

- **90年代**：**ダイヤルアップ**（電話回線、ピーポーパーポー接続音）が主流。
  - 最大 **56kbps** —— 写真1枚のダウンロードに **数分** かかることも。
- **2000年代**：**ADSL** が普及。
  - 最大 **約8Mbps** —— ダイヤルアップの **100倍以上**。
- その後 **光ファイバー（FTTH）** も普及—— **100Mbps 以上** が当たり前に。
- 高速化による変化：
  - **YouTube**（2005年）など **動画サイト** の登場—— ブロードバンドがなければ成立しなかった。
  - **オンラインゲーム** の普及。
  - インターネットの **使い方そのもの** が大きく変わった。

### モバイル革命：iPhone と Android

- **2000年代後半** の最大の変化の一つ。
- **2007年**：**iPhone** 発売—— **すべてを変えた** と言っても過言ではない。
  - それまでの携帯は **通話・メール** が中心。
  - iPhone は **本格的なインターネット体験** を持ち運べるようにした。
  - **タッチパネル**、**App Store** によるアプリの簡単ダウンロードが画期的。
- **2008年**：初の **Android スマートフォン** 登場—— **スマートフォン市場** が本格始動。

### 2000年代のハードウェア進化

#### CPU

- **Pentium 4**：クロック周波数が **3GHz 以上** まで到達—— しかし **発熱問題** が大きな課題に。
- **2006年**：**Core 2 Duo（コア2デュオ）** 登場—— 発熱を抑えつつ性能向上。**2コア** 搭載で革命的。
- **AMD Athlon 64**（2003年）：**64ビットプロセッサ** の時代を切り開く。
  - 32ビット：最大 **4GB** メモリ。
  - 64ビット：理論上 **16エクサバイト** まで。

#### グラフィック・メモリ・ストレージ

- **NVIDIA GeForce** と **ATI（後の AMD Radeon）** が性能競争。
  - **2006年** から **DirectX 10** 対応カード—— グラフィックスが一気にリアルに。
  - **Half-Life 2**、**Crysis** など革命的グラフィックのゲーム。
- **メモリ**：2000年代初め **256〜512MB** → 後半 **4〜8GB**。**DDR → DDR2 → DDR3** と転送速度向上。
- **HDD**：数10GB → **1TB 以上** が一般的に。
- **SSD**（2000年代後半）：機械部品なしで **高速・静音** —— 当時は容量小・高価。
- **液晶ディスプレイ**：ブラウン管から急速移行。**2005年頃** から **ワイド液晶** が主流。解像度：**1024×768 → 1280×1024 → 1920×1080（フルHD）**。
- **光学ドライブ**：CD-ROM → **DVD** → **2006年頃 Blu-ray vs HD DVD 規格争い**（**Blu-ray 勝利**、PS3 の採用も大きかった）。

### Web 2.0：誰もが情報を発信する時代

- それまでの Web：**情報を見るだけ**。
- **Web 2.0**：**誰もが情報を発信** できるように。
- 代表例：**Wikipedia**、**Facebook**、**Twitter**、**ブログサービス**。
- **SNS の始まり** でもあった。

### セキュリティ問題の顕在化

- インターネットが生活に不可欠になるにつれ、**セキュリティの重要性** が急増。
- 代表的な脅威：**コンピュータウイルス**、**フィッシング詐欺**、**スパイウェア**。
- 有名事件：
  - **ミレニアムバグ（Y2K）**
  - **ILOVEYOU ウイルス**（2000年）：メール添付ファイルで感染、ファイル破損・勝手なメール送信。**5,000万台以上** に影響。「ILOVEYOU」という件名で興味を引き、当時は **ウイルス対策ソフト未導入** が多く拡大。
- 対策の進展：
  - **ウイルス対策ソフト**、**ファイアウォール**、**スパムフィルタ** の一般化。
  - **Windows XP**（2001年）：当初セキュリティに弱点。**SP2**（2004年）でファイアウォール・自動アップデート強化。
  - **HTTPS** の普及、メールフィルタリング、**ユーザー教育**（怪しいリンクをクリックしない）。
- これらが後の **クラウド時代・スマートデバイス時代** のセキュリティ基盤につながった。

### Google の急成長とクラウドの始まり

- **Google**：検索エンジンから **Gmail**（2004年、**1GB** の破格容量）、**Google マップ** など次々展開。
- **2006年**：**Amazon Web Services（AWS）** 開始—— **クラウドコンピューティング** 時代の本格スタート。
  - それまで：企業が **自前でサーバー購入・運用**（初期投資・管理コスト大）。
  - **AWS**：サーバー・ストレージ・DB などを **オンデマンド** で提供—— **必要な時に必要な分だけ**。
  - **Amazon S3**（ストレージ）、**Amazon EC2**（仮想サーバー）が革命的—— 急なアクセス増にも柔軟対応。**スタートアップ** に特に画期的。
- **2000年代後半**：**Google App Engine**、**Microsoft Azure**（2008年発表）も参入。
- クラウドが注目された背景：**ブロードバンド・光回線** の普及、**データ大容量化**、**Linux・仮想化技術**（オープンソース）の基盤。
- 2000年代のクラウドは **始まりの時代** —— 基礎ができ、**2010年代の爆発的成長** への準備が整った。

### 2000年代の結論

- **インターネット高速化**、**モバイル革命**、**ハードウェア進化** が同時進行。
- CPU **マルチコア化**、グラフィックス **リアル化**、ストレージ **大容量化**。
- 後半は **ノート PC 普及** とともに **省電力・高性能** の両立が進展。
- これらが **2010年代のスマートフォン・タブレット時代** を準備した。
- 次回予告：**2010年代** —— スマートフォン進化、SNS 発展、AI 技術など。
