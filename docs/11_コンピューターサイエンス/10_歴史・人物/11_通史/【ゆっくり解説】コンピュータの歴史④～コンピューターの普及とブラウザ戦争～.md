## 要約

コンピュータの歴史全7回シリーズの第4回。**1990年代**——コンピュータが **一般の人に普及** し、**インターネット** と **Windows** が生活を変え始めた時代を解説する。中心テーマは **Mosaic による Web 革命**、**Windows 95/98** の普及、**ハードウェアの急進化**、そして **IE vs Netscape のブラウザ戦争**。

### シリーズの位置づけ

- 前回（1980年代）の x86 vs Apple から引き続き、**1990年代** を扱う。
- 1990年代はコンピュータが **一般市民の生活** に入り込んだ時代—— 当時は子供だった UP 主も、ここまで世の中を変えるとは思っていなかった。
- 本回の焦点：**インターネットの普及** と **ブラウザ戦争**。

### 1990年代初頭：インターネット普及の始まり

- インターネットの起源は **1960年代の ARPANET** だが、**一般向けに普及し始めたのは1990年代**。
- **1993年**：**Mosaic（モザイク）** 登場—— Web 普及に **決定的な役割**。
  - **初めて画像を表示できる Web ブラウザ**（それまでテキストのみ）。
  - **クリックでリンクを開く**、**ブックマーク** など—— 今では当たり前の機能だが、当時は画期的。
  - 使いやすい UI により、多くの人が **インターネットを使いたくなった**。

### Windows 95：家庭・企業への一気普及（1995年）

- **1995年**：**Windows 95** 発売—— **世界的な大ヒット**。
  - 発売日には **世界中で長蛇の列**。
  - CM に **Rolling Stones「Start Me Up」** を使用した象徴的な宣伝。
  - Microsoft は宣伝に **3億ドル** を投入したと言われる。
- 特徴：
  - **使いやすい GUI** と多数の新機能。
  - **Internet Explorer（IE）が標準搭載** —— ブラウザ必須の時代に **大きな利点**。誰でも簡単にインターネットへアクセス可能に。
- **Microsoft Office**（Word、Excel、PowerPoint）も人気—— **家庭だけでなく企業** にも広く普及。
- この頃から **Microsoft が急成長**。

### Windows 98：インターネット利用の拡大（1998年）

- **1998年**：**Windows 98** 発売。
- 新機能：
  - **USB 対応** の強化。
  - **インターネット機能** の改善。
  - **Plug and Play** —— 周辺機器を簡単に接続できる機能が充実。

### 1990年代のハードウェア進化

#### CPU

- **90年代初め**：**Intel 386 / 486** が主流（数字が大きいほど高性能）。
- **1993年**：**Pentium（ペンティアム）** 登場—— パソコン性能が **劇的に向上**。
  - 初代 Pentium：**66MHz**。
  - 90年代末：**Pentium III** で **600MHz 以上**。

#### メモリ・ストレージ

- **メモリ**：90年代初め **4〜8MB** → 後半 **64〜128MB** が当たり前（現代の GB 規格と比べ **1000倍以上** の進化）。
- **ハードディスク**：90年代初め **約100MB** → 後半 **数GB**。**1MB あたりの価格** が90年代を通じて **1/100以下** に。
- **CD-ROM ドライブ** 普及—— 1枚 **650MB**。音楽だけでなく **ゲーム・ソフトウェア** の配布媒体に。当時としては革命的な容量。

#### グラフィック・ディスプレイ

- **家庭用ゲーム機** の進化：**スーパーファミコン**、**PlayStation**、**Nintendo 64** —— **3D ゲーム** が当たり前に。
  - PlayStation は **CD-ROM 採用** で大容量ゲームを実現。
- **3dfx Voodoo カード** —— **PC 用3D グラフィックス** の先駆け（現代 GPU の先祖）。
- **ブラウン管モニター** が主流→画面大型化・解像度向上。**90年代末** から **液晶モニター** も登場（まだ高価、一般化は2000年代）。

- **90年代はハードウェアが急速に進化した時代** —— その進化が **インターネット・Windows・ゲーム** の発展を可能にした。

### ブラウザ戦争：IE vs Netscape（1995〜1999年）

- **1990年代後半**、**Internet Explorer（IE）** と **Netscape Navigator** の **熾烈な競争**。
- **Netscape Navigator**（1994年登場）：
  - 当初 **圧倒的シェア** —— **1995年時点で約80%**。
  - 個人利用でも **約49ドル** の有料。
- **Microsoft の逆転策**：
  - **Windows 95 に IE を無料バンドル** —— 決定的な **転換点**。
  - IE は急速に改良：**JavaScript 対応**、**ActiveX**、**CSS サポート** 強化—— **すべて無料**。
- Netscape は必死に対抗したが、**シェアを奪われ** 最終的に敗退。
- **後日談**：
  - Netscape は **オープンソースプロジェクト Mozilla** へ。
  - 後に **Mozilla Firefox** として **生まれ変わった** —— 今も使われている。
- **独占禁止法問題**：
  - IE の **無料バンドル** が **不公正な競争** として訴えられた。
  - **2000年代まで続く** Microsoft の独占禁止法違反問題の一因に。

### 1990年代の結論

- **ソフトウェア**（Windows、Office、ブラウザ）と **ハードウェア**（CPU、メモリ、HDD、GPU）が **同時に急進化** した時代。
- 技術の進歩が **インターネット普及・Windows 定着・ゲーム発展** につながり、**私たちの生活を大きく変えた**。
- 次回予告：**2000年代** —— インターネット高速化、モバイル機器の登場など。
