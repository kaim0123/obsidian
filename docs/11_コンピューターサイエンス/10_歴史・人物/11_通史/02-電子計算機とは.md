# 電子計算機の誕生と小型化（1940〜1970年代）

> **この章を読むと分かること**
> - 「真空管」「トランジスタ」「集積回路」って何が違うの？
> - なぜコンピュータは部屋サイズから机サイズに小さくなれたのか
> - 「バグ（bug）」という言葉が文字通り「虫」から来た理由
> - Microsoft や Apple の起源にあたる、パーソナルコンピュータ時代の幕開け

---

## はじめに — 30トンから手のひらサイズまで30年

今、あなたが使っているスマホのチップは数mm角です。でも世界最初の電子コンピュータは **重さ30トン、長さ30メートル** の体育館サイズでした。

この章では、コンピュータがどうやって **「部屋サイズ → 机サイズ → 個人所有」** へと小さくなっていったのか、その歴史を追います。

```
1946年 ENIAC         → 30トン、部屋丸ごと
1965年 PDP-8         → 机の上に置けるサイズ
1970年 Intel 4004    → 1チップに集積
1975年 Altair 8800   → 397ドル、個人で買える
   ↓
今のスマホ・PC
```

---

## 1. ENIAC — 世界初の全電子式計算機（1946年）

### 1-1. ENIAC とは

**ENIAC**（エニアック）は、1946年にアメリカで完成した **世界初の全電子式計算機** です。

| 項目 | スペック |
|-----|--------|
| 全長 | 約30メートル |
| 重さ | 約30トン |
| サイズ感 | 部屋まるごと埋め尽くす |
| 使用部品 | **真空管**（数千本） |
| 開発目的 | 戦争中の **弾道計算・爆弾の軌道計算** |

「全電子式」というのは、**真空管** という電子部品で計算をするという意味です。それ以前のバベッジの計算機は歯車（機械式）でした。

### 1-2. 真空管とは何か（初心者向け）

真空管は、ガラス管の中を真空にして電流の流れを制御する部品です。電球のような見た目をしています。

```
真空管の特徴
 ✓ 計算の「1か0か」を表現できる
 ✗ 大きい（電球サイズ）
 ✗ 発熱が大きい
 ✗ 故障しやすい
 ✗ 数千本必要 → 動かすには冷却＋整備チームが常駐
```

ENIAC が部屋サイズになったのは、この真空管を数千本並べる必要があったからです。

### 1-3. プログラム ＝ 配線という時代

ENIAC は「プログラム可能」でしたが、その方法は現代と全く違いました。

> **プログラムを変えるには…**
> - 数千本のケーブルを差し替える
> - 回路を手動で組み替える
> - スイッチを全部設定し直す
>
> → 1回の変更に **数時間〜数日** かかった

つまり「プログラミング」とは、現代のようにコードを打つ作業ではなく、**物理的な配線作業** だったのです。

詳しくは [[01-計算の机械化とは|前章のノイマン型アーキテクチャの説明]] を参照してください — この問題を解決するために「プログラムをメモリに入れる」という革命的な発想が生まれます。

### 1-4. 知られざる女性プログラマーたち

ENIAC には実は **女性のプログラマー** たちが深く関わっていました。当時の社会では、

- 科学・工学は男性が多かったが、**プログラミングには女性が多く関与**
- 計算は **女性が得意とされる分野** とみなされていた
- 真空管をつなぐ回路図を設計し、物理的に組み立てる **精密作業** が多かった

代表的な人物：

| 名前 | その後の活躍 |
|-----|--------|
| **グレース・ホッパー** | **コンパイラの発明者** として有名に |
| ジーン・ジェニングス・バートイク | ENIAC 6人の女性プログラマーの1人 |
| フランシス・ビルズ | 同上 |
| マリリン・メルツァー | 同上 |

しかし当時は彼女たちの貢献は公式には認められず、長く歴史から隠れていました。今では「**初めてプログラム可能なコンピュータを扱った先駆者**」として再評価されています。

### 1-5. 「バグ（bug）」という言葉の由来

プログラムのエラーを **「バグ（bug）」**、それを取り除くことを **「デバッグ（debug）」** と呼びますよね。

実はこの言葉、本当に **「虫」** から来ています。

> **エピソード**
> ある日コンピュータが故障した。原因を調べると、**蛾（が）** が機械内部に入り込み、真空管をショートさせていた。
> この出来事をきっかけに、機械の不具合を「バグ（虫）」、それを取り除くことを「デバッグ（虫を取り除く）」と呼ぶようになった。

当時はまさに **本物の虫** が原因でコンピュータが止まることがあったわけです。

### 1-6. 「宇宙人と通信している？」という誤解

1950年代、コンピュータが面白い誤解を生みました。

ハーバード大学で、コンピュータがランダムに発する音やパターンが **まるで外国語のように聞こえる** ことがありました。ある研究者が「もしかしてコンピュータが宇宙人と通信しているのでは？」と本気で疑ったそうです。

実際はただの **ランダムノイズ** でしたが、それを宇宙人の言葉に聞こえると感じるくらい、当時の人にとってコンピュータは **神秘的な存在** だったのです。

## 2. 真空管からトランジスタへ — 革命的な小型化

### 2-1. なぜトランジスタが革命だったのか

1960年代に入り、コンピュータ業界に大きな変化が起きます。**トランジスタ** という小型部品が登場したのです。

| 比較項目 | 真空管 | トランジスタ |
|---------|------|----------|
| サイズ | 電球サイズ | 小さな粒 |
| 消費電力 | 大 | 小 |
| 発熱 | 大 | 小 |
| 寿命 | 短い（故障多） | 長い |
| 価格 | 高い | 安い |

> **同じ働き、しかし圧倒的に小さい・安い・壊れにくい**

これで一気にコンピュータの世界が変わります。

### 2-2. 集積回路（IC）への進化

さらにトランジスタを **多数まとめて1つのチップに焼き込む** 技術が生まれます。これが **集積回路（IC: Integrated Circuit）** です。

```
真空管時代：    部品が物理的に大きい
       ↓
トランジスタ：  部品が小さくなる
       ↓
集積回路：      多数のトランジスタを1チップに集積
       ↓
（将来）        スマホサイズへ
```

このサイクルが、その後の **小型化・低価格化・高性能化** の源泉になります。

---

## 3. PDP-8 — ミニコンピュータ革命（1965年）

### 3-1. 机の上に乗るコンピュータ

それまでのコンピュータといえば、IBM のメインフレーム — **部屋1つ分のサイズ、数百万ドル** の代物でした。一般の企業や大学には手が届きません。

そこに登場したのが **DEC**（Digital Equipment Corporation）社の **PDP-8**（1965年）。

| 項目 | PDP-8 のスペック |
|-----|--------------|
| サイズ | 机の上に置ける |
| 価格 | 約15,000ドル（当時としては破格） |
| 性能 | 8ビット、メモリ4KB |
| 採用部品 | トランジスタ |

> **当時の価値感覚**
> 今の基準では「8ビット・4KB」は弱小すぎますが、当時は革命的でした。これでも企業や大学の業務に十分使えたのです。

### 3-2. PDP-8 がもたらしたもの

PDP-8 はただ小さくて安いだけではなく、コンピュータ史に大きな影響を残しました。

1. **コンピュータの普及**：大企業の特権だったコンピュータが、中小企業や大学にも届くようになった
2. **プログラミング教育の促進**：触れる人が増え、プログラマーという職業が広がった
3. **後継機への系譜**：PDP-11、VAX シリーズへと進化し、DEC のシェアが拡大
4. **PC 時代への土台**：「机に置けるコンピュータ」という発想が、後のパーソナルコンピュータに繋がる

> もし PDP-8 がなければ、今のパソコンやスマホの進化は **大幅に遅れていた可能性** があると言われています。

---

## 4. Intel 4004 — 世界初のマイクロプロセッサ（1970年）

### 4-1. 「コンピュータが1チップに」

1970年、**インテル** が世界を変えるチップを発表します。**Intel 4004** — 世界初のマイクロプロセッサです。

```
それまで       コンピュータの「頭脳」部分（CPU）は
              多数の部品を組み合わせて作られていた
       ↓
Intel 4004    たった1チップに CPU の機能を集積
              （プロセッサ・メモリ・I/O 機能を1つに）
```

これによって、コンピュータの「小型化の限界」が一気に下がります。

### 4-2. 最初の用途は意外にも「電卓」

革命的な技術 Intel 4004 の最初の用途は、なんと **電卓** でした。日本の電卓メーカーが Intel に発注した特注品が始まりです。

そこから家庭用電卓に取り入れられ、爆発的に普及していきます。「**高度な技術が、意外なところから身近な製品へ届く**」というパターンの教科書例です。

### 4-3. Intel 8080 — 性能アップ

1972年、Intel は **8ビット** のプロセッサ **Intel 8080** を発表。4004 から大幅に性能が上がり、「これならコンピュータが組める」レベルになりました。

これが次のステージ、**パーソナルコンピュータ** の登場を準備します。

---

## 5. Altair 8800 — パソコン時代の幕開け（1975年）

### 5-1. 個人が買えるコンピュータの誕生

1975年、**MITS** という小さな会社（もともと宇宙開発・測定機器メーカー）が、Intel 8080 を搭載した **Altair 8800** を発売します。

| 項目 | Altair 8800 |
|-----|------------|
| 価格 | **397ドル**（キット）／ 498ドル（完成品） |
| 操作 | 前面の **スイッチとランプ** だけ |
| 販売形式 | 主に **組み立てキット** |
| 用途 | 個人が自宅で使うコンピュータ |

> **「自宅にコンピュータを持つ」未来が、ここから始まった**

### 5-2. ブレイクのきっかけ — 雑誌の表紙

当初 Altair 8800 はあまり注目されていませんでした。状況が変わったのは1975年1月、雑誌 **Popular Electronics** の表紙を飾ったことです。

> 表紙：「世界初のミニコンピュータキット、商用機に匹敵」

これが技術者・エンジニアの間で大反響を呼び、Altair はベストセラーになります。

### 5-3. キット販売が生んだ DIY 文化

Altair 8800 は基本的に **自分で組み立てるキット** でした。初心者にはハードルが高かったのですが、これが意外な効果を生みます。

- **改造可能** という自由度が、新しい技術者文化を生んだ
- 手を動かして学ぶ **DIY 精神** が、現代のテックカルチャーにも影響
- 雑誌、ユーザーグループ、互換機が次々と登場

---

## 6. Microsoft と Apple の原点 — ソフトウェア業界の誕生

### 6-1. ビル・ゲイツとポール・アレン

Altair 8800 のために、**ビル・ゲイツとポール・アレン** という2人の若者が **BASIC 言語** を移植・販売しました。これが Altair の売上を大きく後押しします。

そしてこの経験から生まれたのが、後の **Microsoft** です。

> **ハードを作る会社とは別に、ソフトウェアを売る会社が成り立つ**
> 
> この発想が、現代のソフトウェア業界（Windows、Office、Adobe、ゲーム業界…）の起点になりました。

### 6-2. Apple もここから

Altair 8800 が「個人がコンピュータを持つ」未来を見せたことで、**Apple I**（1976年）、**Apple II**（1977年）が登場します。そして1980年代に **IBM PC** の発表でパソコンは一気に一般家庭へ普及していきます。

> **Altair 8800 がなければ、Apple も Microsoft も IBM PC も、今の形では存在しなかった** と言っても過言ではありません。

## 7. この章のまとめ

### 部品の進化が小型化を生んだ

```
真空管（電球サイズ）
    ↓ 1960年代
トランジスタ（小さな粒）
    ↓ 集積技術の進歩
集積回路 IC（チップに数千〜数百万のトランジスタ）
    ↓
マイクロプロセッサ（1チップに CPU を集積）
    ↓
現代の SoC（System on Chip：スマホの心臓部）
```

### 時代別の到達点

| 年 | 出来事 | 意義 |
|----|------|----|
| 1946 | ENIAC | 世界初の全電子式計算機。30トン、部屋サイズ |
| 1950s | 真空管時代 | バグの語源、宇宙人通信の誤解、女性プログラマー |
| 1960s後半 | トランジスタ普及 | 小型化・低価格化の起点 |
| 1965 | PDP-8 | 机に置けるミニコンピュータ |
| 1970 | Intel 4004 | 世界初のマイクロプロセッサ |
| 1972 | Intel 8080 | パソコンを組める性能のチップ |
| 1975 | Altair 8800 | 397ドルで個人が買えるコンピュータ |

### 大きな流れ

**コンピュータの歴史は「小型化・低価格化・個人化」の歴史です。**

部屋を埋め尽くす機械が30年で個人のデスクに乗るようになり、さらに30年後にはポケットに入るスマホになりました。その鍵はすべて **部品の進化**（真空管 → トランジスタ → IC → マイクロプロセッサ）にあります。
