## 2. それぞれの分野を「歴史」として見ると

### 2-1. 人物編 — 歴史の登場人物を深掘る

[[01-計算の机械化とは|第1節]] で出てきた **チューリング・ノイマン・バベッジ** をもっと深く知りたい人へ。

> **おすすめの順序**
> 1. チューリング①（誤解と実像）
> 2. チューリング②（CSの父）
> 3. チューリング③（チューリングマシン）
> 4. ノイマン①〜③（逸話・学者・核）
> 5. バベッジ①②（既に [[01-計算の机械化とは]] で扱った）

人物編は、技術史というよりも **思想史** の側面が強くなります。

### 2-2. ハードウェア — 原理と CPU 史

第3章は **2本の主線** です。🎙️半導体シリーズで「なぜ動くか」を押さえてから、🎬CPU シリーズで設計と産業史を追うのがおすすめです。

> **原理の主線（🎙️）**
> - 半導体 → トランジスタ → 論理回路 → 二進数 → 浮動小数点
> - 並行：[[まとめ目次#1-2 電子計算機の誕生と小型化（1940〜1970年代）\|第1章 1-5]]（トランジスタ・集積回路の歴史）

> **CPU 史の主線（🎬）** — 統合まとめは [[02-CPUとアーキテクチャとは|02-CPUとアーキテクチャ]]
> - CPU戦争（Z80・6502・弱い8088がIBM PCで勝つ）
> - 8086 と「呪われた互換性の40年」
> - x86-64（AMD が Intel を逆転した話）
> - マルチコア時代と「競合状態」
> - ARM vs x86（Apple Silicon）

> **専用チップ（🎙️・任意）**：GPU → NVIDIA → TPU（第1章 **1-17** と **3-14** で NVIDIA が二度登場）

### 2-3. プログラミング言語史

機械語 → アセンブリ → C → C++ → Java → Python → ... と進化を追う。

> **大きな転換点**
> - **コンパイラの発明** = 機械語から人間の言葉へ
> - **インタプリタの発明** = 即座に試せる開発体験
> - **オブジェクト指向の誕生** = ルネサンス的世界観
> - **関数型の復興** = OOP の限界への対応

[[01-計算の机械化とは|第1節]] の「プログラム＝配線」「stored-program」の話の続きです。

### 2-4. OS の歴史

[[02-電子計算機とは|第2節]]・[[04-PCとGUIとは|第4節]]を補完。

> **大きな流れ**
> - **UNIX**（1969）：シンプルな哲学のOS、現代のすべての元
> - **Linux**（1991）：趣味から世界制覇まで
> - **Windows**（1985〜）：一般家庭への普及
> - **POSIX**：UNIX/Linux/macOS をつなぐ共通規格

PC-98 が滅びた話（[[04-PCとGUIとは]]）の裏側にも、OS の世界の戦いがあります。

### 2-5. ネットワーク史

[[05-インターネット以降とは|第5節]]の続編。

> **キーワード**
> - **プロトコル戦争**：OSI vs TCP/IP（なぜ「完璧な設計」が負けたのか）
> - パケット・ルーティング・冗長性の話
> - URL・ドメイン・HTTP の小ネタ（「451エラー」の由来など）

### 2-6. Web・ブラウザ・検索

[[05-インターネット以降とは|第5節]] のブラウザ戦争を、もっと長期スパンで見る。

> **キーワード**
> - **ブラウザ戦争30年の真実**：IE 滅亡の理由
> - **マークアップ言語**：HTML、TeX、論理と見た目の分離
> - **検索エンジン60年史**：Google が一瞬で答えを出せる理由
> - **PageRank**：論文を読みながら理解する Google の核

### 2-7. データ・文字

[[03-通信の歴史とは|第3節]] でも触れた「日本語処理」「文字化け」を深掘る。

> **キーワード**
> - **文字コードの歴史**：なぜ日本語は壊れるのか
> - **データベースの進化**：60年代の階層型から現代の SQL/NoSQL まで
> - **正規化の皮肉**：「完璧な表」は扱いづらい

### 2-8. 暗号・セキュリティ

> **キーワード**
> - **暗号の歴史**：言語学・数学だけでなく ◯◯（聴いてのお楽しみ）も使う
> - **エニグマからRSAまで**：戦争と数学の物語
> - **セキュリティ敗北史**：「最大の障壁は愚かな人間」
> - **匿名通信 Tor とダークウェブ**：上級編

## 3. 「歴史」の読み方ガイド

### 主線 → 支線の流れがおすすめ

```
時間順（第1節〜第5節）
        ↓
全体の地図ができる
        ↓
興味のある分野を選ぶ
        ↓
分野史で深掘り（第2〜10章の各章）
        ↓
新しい興味が湧いたら別の分野へ
```

### 注意 — 同じ話が複数の章で出てくる

例えば「ARPANET」は [[05-インターネット以降とは|第5節]] でも、第8章のネットワーク史でも、第10章の暗号史でも出てきます。

**同じ事実を「時代の中で」見るか「分野の中で」見るかの違い** です。両方読むと、立体的な理解になります。
