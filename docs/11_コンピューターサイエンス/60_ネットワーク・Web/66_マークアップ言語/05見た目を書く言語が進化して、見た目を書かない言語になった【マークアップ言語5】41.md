## 詳しい要約

**テーマ：マークアップ言語は「見た目を書く言語」から「見た目を書いてはいけない言語」へねじれて進化した**

マークアップ言語シリーズ第5回。「マークアップ言語は論理構造を書くもの」という前回までの主張と、TeX のように見た目を美しく指定する言語もマークアップ言語と呼ばれる矛盾を、歴史から解き明かす。結論は、もともと見た目を指定するための言葉が行き当たりばったりの改良の末に正反対の意味になった「パンダの親指」のような存在であり、技術は設計ではなく修繕の歴史だということ。

---

### 「マークアップ」の本来の意味

- 出版業界では、原稿の余白に**印刷所への指示**を書き込む作業を「マーキングアップ」と呼んでいた（英語圏）
- markup はもともと**組版**（文章のレイアウトを整えること）を指す言葉
- つまり本来のマークアップ言語は**見た目を記述するもの**で、TeX のほうが本義に近い
- 堀元の著書の入稿時にも、編集者から星印や色付きの指示が入った原稿が届いた

### HTML も最初は「誰かの思いつき」

- HTML は CERN の人物が思いつきで作り、他の人が真似して広まった（話者による単純化）
- 参考にしたのは、印刷業界で使われていたマークアップ（組版指示）。ブラウザを印刷所に見立てれば同じやり方が使える
- 当初は見た目を整形するためのものとして設計されたと考えられる
- バージョンを重ねる（1.0 → 2.0 → … → 5）中で、**見た目と論理は分離したほうがよい**という意見が強まり、見た目は **CSS** へ移され、最終的に「HTML に見た目を書くな」という着地点になった

### 名前は変えられず、概念全体に波及

- 一度掲げた技術名は下ろせないため、名前はそのままで中身が乖離した
- 「マークアップ言語全般は論理構造を書くべき」という誤った拡張が起き、XML などにも適用
- 本来見た目を指定する言語だった **TeX でも構造的な書き方が増え**、逆輸入が起きている
- 見出しタグを文字を大きくするために使うのは、歴史的にはむしろ正しい使い方とも言える（Google が論理構造として利用しているだけ）

### 言語学との類似

- 「耳障り」は今は不快な場合にしか使わないとされるが、夏目漱石『こころ』や川端康成は「聞き心地」の意味で使っていた
- 後世の人が意味を固定し、取り締まるようになる現象は言葉の意味変化でも多い

### 生物の進化とパンダの親指

- 技術の変遷は**生物の進化と同じく行き当たりばったり**。例：空へ進出した鳥がペンギンとして海に戻る
- **パンダの親指は指ではなく手首の骨**が突出したもの。竹をつかむのに有利で強化され、指のように見えるようになった
- マークアップ言語も「見た目を指定する言語なのに、論理を指定する言語だと思われている」点でパンダの親指と同じ
- 水野は服飾史も言語と同様に、当時の人の意図や流れを遡れる対象だと指摘

### まとめ：技術は修繕の歴史

- パンダの親指の比喩は岩井克人『ヴェニスの商人の資本論』所収「パンダの親指と経済人類学」から。貨幣も現在の機能から元の形を類推できない、という論
- 引用：「自然とは修繕屋であって建築家ではなかった」
- 技術もパッチを当て続けた結果思わぬ形に着地するもので、HTML や OS も最初から設計されたように見えて実はつぎはぎで発展している
- 不合理に見えるものにも歴史があり、それを紐解けば矛盾の理由がわかる
