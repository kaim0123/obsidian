## 詳しい要約

**「ブラウザは凄腕パワポ職人」**を入口に、堀本さんが水野さんに **マークアップ言語** と **HTML** の世界を初めて紹介する回。開発者が書く「謎の文字列」と、ユーザーが目にする「綺麗なページ」は別物——**見えない構造**に注目することが、このシリーズの出発点。**第2回**（[[02HTMLの真価は「論理と見た目の分離」。みちょぱに違法建築をさせてはいけない【マークアップ言語2】38]]）で「論理と見た目の分離」を深掘り。

### 回の位置づけ

- ゆるコンピューター科学ラジオ **#37**。新シリーズ **「ミズノの知らないマークアップ言語の世界」** 第1回（全5回）。
- 水野さんは IT リテラシーが低めの **「ミズノ」枠**——HTML 略語や拡張子程度しか知らない前提で話す。
- 堀本さんは **Markdown の話はこのシリーズではしない** と宣言（命名が紛らわしいため）。マークダウン記法 ≠ マークアップ言語、という混乱ポイントを最初に潰す。

### 1. ブラウザは「凄腕パワポ職人」

| 比喩 | 内容 |
|------|------|
| **職人** | 各ブラウザ（Chrome、Safari、Edge 等）が HTML を受け取り、一瞬で綺麗なページに仕上げる |
| **激務** | 職場の超優秀パワポ職人のように、常に大量の仕事をこなしている |
| **個性** | HTML という共通フォーマットを、各ブラウザが **それぞれ独立に** 描画する（完全同一ではない） |

冒頭の雑談では、Firefox と Thunderbird（メールクライアント）の取り違え、IE 終了サポートの話など。**ブラウザを「クロームちゃん」等と呼んで慕うべき** という冗談から本編へ。

**余談——某コンサルの先輩**

- 激務で有名なコンサル会社に入った先輩（新卒1年目）の仕事：**ひたすら綺麗なパワポを作る**。
- 「**髪を洗う暇もない**」——ブラウザはその先輩の何十億倍も働いている、という比喩で締める。

---

### 2. マークアップ言語とは何か

**語源と意味**

- **Markup**＝原稿に印（マーク）を付けること。蛍光ペンで強調するイメージに近い。
- **マークダウン（Markdown）** は別物。包含関係として **マークダウン ⊂ マークアップ言語** だが、名前が紛らわしい。

**コンピュータ言語の中での位置**

| 種類 | 例 | HTML の位置 |
|------|-----|-------------|
| **プログラミング言語** | Python、JavaScript 等 | 該当しない |
| **データ記述言語** | HTML、XML 等 | **ここ** |

- エンジニアが「言語」と言うとき、必ずしもプログラミング言語を指さない。
- 「HTML でプログラミングしてる」と言われると違和感があるが、**広い意味でのコンピュータ言語** ではある。
- マークアップ言語＝本文以外に **見出し・強調・構造** などの情報をタグで付与する書式。

---

### 3. HTML——ウェブサイトの「本体」

**基本**

- **HTML**＝**H**yper**T**ext **M**arkup **L**anguage（ハイパーテキスト・マークアップ・言語）。
- 水野さんの理解：ファイル名末尾の `.html` / `.htm` くらい。
- 実際：**あらゆるウェブサイトの本体** がこの書式。ゆる言語学ラジオ公式サイトの HTML を画面共有して実演。

**構造のイメージ**

- `<` `>` で囲まれた **タグ** が並ぶ（大括弧のような見た目）。
- `<head>` / `<body>` など、開始タグと終了タグで **囲む** 規則がある。
- `<header>` / `<footer>` など、英語由来の部品名も（Web 業界発の用語かも、という雑談）。

**誰が HTML を書くか**

- 会社で「HTML で出して」と言われることはあるが、中身を理解せずコピペする人が多い。
- 堀本さんの体感：**1000人に1人** 程度が本当に書ける（水野さんは「10人に1人」派）。
- 中学校・大学の HTML 授業でも、意味を理解せず教授の文字列をコピペするだけ、という **あるある**。

**ブラウザの役割**

```
開発者が書いた HTML（謎の文字列）
        ↓
各ブラウザ（Chrome / Safari / Edge …）が受け取り、描画
        ↓
ユーザーには「綺麗なページ」として表示
```

- ユーザーは HTML を **ほぼ一度も目にしない**。何者か（＝ブラウザ）が仕上げてくれている。
- 文言を `<h2>` 内のテキストなどに書き換えれば、表示も変わる——ただし **閉じタグを壊すと全体が崩れる**。

---

### 4. WYSIWYG じゃない——作る人と見る人で見え方が違う

| | マークアップ言語（HTML） | WYSIWYG（Word 等） |
|--|------------------------|---------------------|
| **編集画面** | タグだらけの文字列 | 完成形に近い見た目 |
| **出力** | ブラウザが別途レンダリング | 書いているもの ≒ 印刷結果 |
| **代表** | HTML | Microsoft Word |

- **WYSIWYG**＝What You See Is What You Get（見ているものがそのまま得られる）。
- マークアップ言語は **WYSIWYG ではない**——開発者の画面と、消費者の画面はまったく別物。
- 水野さんの本音（中学2年で HTML を習った記憶）：「**Word みたいな UI でサクッと作れるサービス** を出してくれ」——それが後の **「目に見えるものがすべてじゃない」** への転換点。

---

### 5. 核心——同じ見た目でも、中身の構造は違う

**2行デモ**

画面上はどちらも「大きい文字」とだけ見える2行。見た目は **ほぼ同一**。

| 行 | HTML の中身 | 意味 |
|----|-------------|------|
| **1行目** | `<h1>大きい文字</h1>` | **見出し**（構造・意味情報） |
| **2行目** | `<div style="font-size:…; font-weight:bold">大きい文字</div>` | **見た目だけ** 大きく太くしている |

- 見た目は同じでも、**内部の論理構造が異なる**。
- 上は「見出しである」という情報、下は「デカ文字・太文字にして」という **装飾指示** だけ。
- これが **マークアップ言語の世界**——**見えない構造** がある。

**土木・道路の比喩**

- 目に見える道路の上だけを見ても、下には **トンネル・斜面・予算** などの設計がある。
- 表面だけでなく **奥の構造まで見る** と、道も Web も楽しくなる——開示（透明性）の話にもつながる。

---

### 6. まとめと次回予告

**この回のメッセージ**

1. ウェブの正体は **HTML というマークアップ言語**。
2. **ブラウザ** が HTML を解釈し、私たちに見やすいページを作ってくれる（パワポ職人）。
3. **見ているもの ≠ 作っているもの**。構造（マークアップ）に目を向けると Web が面白くなる。

**エピソード**

- 堀本さん自作サイトの HTML を **あら探し** しないでほしい（`100vw` で横スクロールバーが出る等、フィードバック殺到中）。
- 次回キーワード：**みちょぱと違法建築** → 第2回で「論理と見た目の分離」・HTML/CSS の本題へ（予告時点の語弊は第2回冒頭で訂正）。
