### 1. HTTPステータスコードの基礎（でんでんさんのお便り）

**HTTPステータスコードとは**

- Web通信では、ブラウザ（クライアント）がサーバーへ「このURLのページを見せて」と**パケット**（郵便小包の比喩）を送り、サーバーが返すパケットの**伝票部分**に数字が載る——それがステータスコード。
- **200**：正常（ページ取得成功）。**404 Not Found**：ページが存在しない。
- 中身の自然言語メッセージを毎回読むより、**全員が共通の数字ラベル**で一発仕分けできるようにするための仕組み。規格は **RFC**（インターネット標準）で定義。

**418 I'm a teapot**

- 「私はティーポットなので返事できません」——**エイプリルフールのジョーク**としてRFCに載った有名コード。伝書鳩プロトコルなど、他にもエンジニアジョーク規格がある。

**451 Unavailable For Legal Reasons（本回の目玉）**

- **法的理由により閲覧不可**のときに使うコード。
- 番号の由来はレイ・ブラッドベリのSF **『華氏451度（Fahrenheit 451）』**。451°Fは本が燃える温度。書物を焼き払う「fireman」が活躍する**反知性主義・言論統制**の世界——「法律のもと見せられない」という意味と皮肉が重なる。
- 日本ではあまり見ないが、**検閲の強い地域**（中国など）ではGoogle・YouTube・TikTok等へアクセスしようとして451が出ることがある、という話。中国政府にとっては「451番＝政府」という印象は好ましくない、というジョークも。

### 2. 枯れた技術・フルスクラッチ・加工JS（レビンさんのお便り）

**レビンさんのプロフィール**

- Twitter **単語博士bot**（フォロワー約10万人）の中の人。エンジニアで、**Ustreamチェッカー**（1億PV級）など多数のプロダクトを持つ。
- 「プログラマの三大美徳」回を視聴し、**ゆる言語学ラジオ公式サイトのコードレビュー**を提案。本人も業務でコードレビュー経験があり、参加を申し出てきた。

**生JSと加工JS**

| 用語 | 意味 | 比喩 |
|------|------|------|
| **生JS（Vanilla JS）** | ライブラリなしの素のJavaScript | 包丁で手切り（指を切るリスクあり） |
| **加工JS** | React・Next.js・TypeScriptなど、JSを拡張・束ねたもの | フードプロセッサーで安全・効率的に処理 |

- 「JS」＝JavaScript。レビンさんは**Rails歴10年以上**、PHP・生JS・React・TypeScript等を書く**フルスクラッチ型**のエンジニア。

**枯れた技術（mature technology）**

- 「枯れた」は**ネガティブではない**。長年使われ、安定性が実証された技術——金融系・防災系で「最新イケてる言語」より**古くて堅実な言語**を選ぶときなどに使う。
- 横井軍平『**技術の水平思考**』（任天堂）の思想と重なる：**最新GPU・最高画質で勝負するのではなく、既にある技術をうまく組み合わせて面白いものを作る**（Wii vs PS3の画質差の例）。堀本さんは復刊本を探したが市場価格が高く購入せず。

**フルスクラッチ（from scratch）**

- 英語 **from scratch**＝ゼロから、最初から。語源は競走の**スタートライン（scratch line）**。
- Web制作の**テンプレート・お役立ちセット**を使わず、**全部自分で組み立てる**スタイルのこと。レビンさんはそのタイプ。

### 3. 「コンピューター」表記論（行きピクシコリアヌスさんのお便り）

**お便りの内容**

- ユーザー名はローマの英雄スキピオ・アフリカヌスをもじった**下ネタ**（本人は真面目に名前の由来を説明）。その後のお便りは普通の内容。
- 小学生のテストで設問「私は（　）」に**コンピューター**（長音付き）と答えて**不正解・罰**になった体験。20年経っても納得いかない、という熱いお便り。

**堀本・水野の見解**

- 堀本さんはかつて**JISに従い「コンピュータ」**（長音なし）に統一していた（動画・番組内表記も）。「超を付けないと素人」とイキっていたが、**近年JISは方針を緩和**し、一般流通の**「コンピューター」表記が優勢**になった。
- エンジニア・サーバーなども同様に、昔は厳密なルールがあったが、今は**実際に使われている書き方に合わせてよい**空気。先生が古いJIS信者だった可能性。現代の子なら最新JISを示せば説明できる、という結論。

### 4. おじさん vs おじいさん（児玉さんのお便り）

- 以前の回で「**おじさん**と**おじいさん**はアクセント位置が違う」という話をした。
- 児玉さんの**亡き祖父**は自分のことを「**おじさん**はね」と呼んでいた。番組を聞いて「本当は**おじいさん**と言っていたのでは」と長年のモヤモヤが解消した、という感動のお便り。
- パネリスト側の議論：血縁のある孫に「おじさんはね」とは普通言わないが、**キャラとしてのお調子者**なら「おじいちゃんに見せてごらん」系はあり得る。真相は「藪の中」で締め。

### 5. 失敗たとえ「山手線より中央線」（セドゥラスさんのお便り）

**背景：神道無双流 杖術（じょうじゅつ）**

- 左手を頭上から腹前へ杖を戻す動作で、**円弧ではなく直線的に**素早く引き寄せるべき、という教え。
- その説明に**「山手線より中央線」**という**決まったたとえ**がある——東京の環状線より都心直結の路線の方が速い、というイメージ。

**問題点**

- 流派内では**全国・海外でも同じ例え**を使う。福岡ではピンとこない。カナダでは先生が英語で山手線・中央線を**前提知識として説明したうえで** Central Line / Yamanote Line と教えていた——一見「失敗たとえ」に見える。

**番組での再解釈**

- 落語の「まんじゅうがこわい」→「ピザがこわい」の**ローカライズ**と対比。愛知に住むと「東京ドーム何個分」も通じにくい、という以前の話とも連動。
- 一方、**宗教的・伝統的な教え**では、キリスト教の「石を投げるな」的な**比喩を現代風に書き換えてはならない**という規範もある。成就の例えが頑ななのは、**教義としての比喩の不変性**を守る美徳かもしれない——カナダの先生は教養と誠実さの表れかも、という意外な結論。
