## 詳しい要約

**テーマ：フォワードプロキシとリバースプロキシの違い**

プロキシとは通信を代理で行うサーバーであり、クライアント側に立つ**フォワードプロキシ**とサーバー群の前に立つ**リバースプロキシ**の 2 種類があることを、それぞれの役割とともに解説するショート動画。

---

### フォワードプロキシ

- 社内ネットワークなどの**出口**に置かれ、クライアントの代わりに外部と通信する
- 接続先サーバーからはプロキシの IP アドレスしか見えない
- 学校や企業で特定サイトへのアクセス制限に使われる
- 設定不要で全員の通信を通す「**透過型プロキシ**」もある
- 閲覧したサイトのログを取ったり、一度取得したページを**キャッシュ**して次回すばやく返したりできる

### リバースプロキシ

- インターネットと**サーバー群の間**に立つ（フォワードプロキシと逆の位置）
- クライアントからは背後のサーバーの IP アドレスが見えず、直接攻撃されにくい。例：**API ゲートウェイ**
- アクセス急増時に複数台へ振り分ける（**ロードバランシング**）
- DDoS 攻撃などのトラフィックをここで止められる
- SSL の復号をまとめて引き受ける
- Cloudflare は世界中にリバースプロキシを配置している。エッジサーバーからロードバランサーまで多段構成になることもある

### まとめ

- フォワードプロキシ＝クライアントの代理（アクセス制限・ログ・キャッシュ）
- リバースプロキシ＝サーバーの代理（隠蔽・負荷分散・DDoS 対策・SSL 終端）
- 日常的に訪れるサイトの多くがこの仕組みの上で動いている
