# IPアドレスとサブネットとゲートウェイ

## IPアドレスとは
ネットワーク上の機器を識別するための**番号（住所）**です。データはこの番号を頼りに宛先まで届けられます。

## IPv4とIPv6

### IPv4
- 32ビットで表現（例: `192.168.1.10`）
- 8ビット区切りを「.」でつないだ4つの数字（各0〜255）
- 約43億個だが枯渇気味

### IPv6
- 128ビットで表現（例: `2001:db8::1`）
- 16進数4桁をコロンで8グループに分割
- 事実上無限のアドレスが確保できる

## IPアドレスの種類

### グローバルIPとプライベートIP
| 種類 | 特徴 | 例 |
|---|---|---|
| グローバルIP | インターネット上で一意 | 203.0.113.5 |
| プライベートIP | LAN内だけで有効 | 192.168.1.10 |

### プライベートIPの範囲
```
10.0.0.0    〜 10.255.255.255
172.16.0.0  〜 172.31.255.255
192.168.0.0 〜 192.168.255.255
```

### 特殊なアドレス
- `127.0.0.1` : ループバック（自分自身）
- `0.0.0.0` : 不特定／全アドレス
- `255.255.255.255` : ブロードキャスト

### 静的IPと動的IP
- **静的**: 固定。サーバーなど
- **動的**: DHCPで自動割当。クライアントPCやスマホなど

## サブネットマスク

### 役割
IPアドレスを「**ネットワーク部**」と「**ホスト部**」に分ける仕組みです。

```
IPアドレス        : 192.168.1.10
サブネットマスク  : 255.255.255.0
─────────────────────────────────
ネットワーク部    : 192.168.1
ホスト部          : .10
```

同じネットワーク部を持つ機器同士は、直接通信できます。

### CIDR表記
```
192.168.1.0/24
```
の `/24` は「上位24ビットがネットワーク部」の意味。サブネットマスク `255.255.255.0` と同じです。

### よく使うCIDR
| CIDR | サブネットマスク | ホスト数 |
|---|---|---|
| /24 | 255.255.255.0 | 254 |
| /25 | 255.255.255.128 | 126 |
| /26 | 255.255.255.192 | 62 |
| /16 | 255.255.0.0 | 65534 |

## サブネット分割（サブネッティング）
大きなネットワークを小さく分けることで、
- セキュリティを向上
- ブロードキャストを抑制
- 管理を効率化
できます。

例: `192.168.1.0/24` を `/25` で2つに分割
```
192.168.1.0/25   →  .1〜.126
192.168.1.128/25 →  .129〜.254
```

## デフォルトゲートウェイ

### 役割
自分のネットワーク外（別のネットワーク）に通信したい時に**出口となる機器**です。一般的にはルーターを指します。

```
[PC 192.168.1.10] → [ルーター 192.168.1.1] → [インターネット]
       └─ ゲートウェイ ─┘
```

### 動作の流れ
1. 宛先IPが同じネットワーク内 → 直接送信
2. 宛先IPが外部 → デフォルトゲートウェイへ転送
3. ルーターがさらに次の経路へ転送

## 実際の設定例（一般家庭の場合）
```
IPアドレス        : 192.168.1.10
サブネットマスク  : 255.255.255.0
デフォルトゲートウェイ: 192.168.1.1  ← 家庭用ルーター
DNSサーバー       : 192.168.1.1 など
```

## 確認コマンド
- Windows: `ipconfig`
- macOS/Linux: `ip a` または `ifconfig`

## まとめ
- IPアドレスは**ネットワーク上の住所**
- **サブネットマスク**でネットワーク部とホスト部を区別
- **CIDR表記**で簡潔に範囲を表せる
- **デフォルトゲートウェイ**は外部ネットワークへの出口
