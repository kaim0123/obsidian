# ルーターとスイッチとハブとNAT

## この章で扱うこと
ネットワーク機器にはそれぞれ役割があります。**ハブ / スイッチ / ルーター**はOSIの階層が異なり、動作単位も違います。NATはルーターでよく使われる**アドレス変換の仕組み**です。

## 階層と動作単位の対応

| 機器 | OSI層 | 扱う情報 | 役割 |
|---|---|---|---|
| ハブ | 1層（物理） | 電気信号 | 全ポートに中継 |
| スイッチ | 2層（データリンク） | MACアドレス | 宛先ポートだけに転送 |
| ルーター | 3層（ネットワーク） | IPアドレス | 異なるネットワーク間を中継 |

## ハブ（Hub）

### 特徴
- 受け取った信号を**全ポートにそのまま流す**（リピーター的）
- 衝突（コリジョン）が起きやすい
- 帯域を全ポートで共有するため遅い

### 現在の位置づけ
ほぼ置き換えられ、現代ではスイッチングハブ（＝スイッチ）が主流。

## スイッチ（L2スイッチ）

### 特徴
- MACアドレステーブルを持ち、**宛先のポートだけに転送**
- 各ポートが独立した帯域を使える
- 同一ネットワーク（LAN）内の通信を効率化

### 動作の流れ
```
① 端末Aからフレーム到着
② 送信元MACを記録（ポート学習）
③ 宛先MACを検索
   - テーブルにあれば → そのポートへ転送
   - 無ければ → 全ポートにブロードキャスト
```

### VLAN
1台のスイッチを論理的に分割して複数ネットワークに見せる機能。セキュリティ・効率化に活用。

### L3スイッチ
ルーティング機能も備えたスイッチ。大規模ネットワークで使われる。

## ルーター（Router）

### 特徴
- **異なるネットワーク間**を接続
- IPアドレスを見て最適な経路を選ぶ（ルーティング）
- 家庭用ルーターはNAT、DHCP、Wi-Fi AP、ファイアウォールを兼ねることが多い

### 動作の流れ
```
① IPパケットを受信
② 宛先IPをルーティングテーブルと照合
③ 一致する経路の次ホップへ転送
```

### ルーティングテーブルの例
```
宛先              次ホップ         インターフェース
0.0.0.0/0    →   203.0.113.1    →  eth0 （デフォルト）
192.168.1.0/24 → 直接接続        →  eth1
```

### ルーティングプロトコル
- **静的ルーティング**: 手動で設定
- **動的ルーティング**: OSPF, RIP, BGPなどで自動更新

## 各機器の比較

| 項目 | ハブ | スイッチ | ルーター |
|---|---|---|---|
| OSI層 | 1 | 2 | 3 |
| 転送単位 | ビット | フレーム | パケット |
| 宛先判断 | なし（全ポート） | MACアドレス | IPアドレス |
| 衝突回避 | × | ○ | ○ |
| ネットワーク分離 | × | △(VLAN) | ○ |

## NAT（Network Address Translation）

### 何をするもの？
**プライベートIPとグローバルIPを変換**する仕組みです。1つのグローバルIPを複数の端末で共有できるため、IPv4アドレス枯渇対策としても不可欠。

### 基本のイメージ
```
[PC 192.168.1.10] ──→ [ルーター(NAT)] ──→ [インターネット]
    プライベートIP        グローバルIP
    192.168.1.10         203.0.113.5
```

## NATの種類

### 静的NAT
1対1で固定的に対応付け。サーバー公開などで使う。
```
192.168.1.10 ⇄ 203.0.113.10 （固定）
```

### 動的NAT
グローバルIPのプール（集合）から空いている1つを動的に割り当てる。

### NAPT / PAT（IPマスカレード）
**IPアドレス + ポート番号**で多対1に変換。**家庭・会社のルーターはほぼこれ**。

```
内部                        外部
192.168.1.10:54321  ⇄  203.0.113.5:60000
192.168.1.11:54322  ⇄  203.0.113.5:60001
192.168.1.12:54323  ⇄  203.0.113.5:60002
```
1つのグローバルIPで複数端末が同時に通信可能。

## NATの動作フロー
```
① PC(192.168.1.10:54321) → ルーター「google.comに接続」
② ルーターが送信元を 203.0.113.5:60000 に書き換え、変換表に記録
③ 応答 → ルーターが変換表を見て PCへ戻す
```

## NATのメリット・デメリット

### メリット
- IPv4アドレスの節約
- 内部構成が外部から見えにくい（簡易的なセキュリティ効果）

### デメリット
- 外部→内部への接続が原則できない（要ポートフォワード）
- P2P通信やVoIPで問題が起きやすい（NAT越えが必要）
- 追跡・デバッグがしにくい

## ポートフォワーディング
外部からサーバーに接続させたい時に使う。
```
外部:203.0.113.5:80 → 内部:192.168.1.100:80
```
家庭用ルーターの設定画面でよく目にする機能。

## その他の関連機器

### アクセスポイント（AP）
Wi-Fi電波を発して有線LANへ橋渡しする装置。

### ロードバランサ（LB）
複数サーバーへの負荷を分散。L4（TCP/UDP）・L7（HTTP）で動作。

### ファイアウォール
通信を許可/拒否するセキュリティ装置。ルーター機能と一体化も多い。

## 家庭用ルーターの中身
一般的な家庭用ルーターは多機能な統合装置:
- **ルーター**（外部接続・NAT）
- **スイッチ**（LANポート）
- **無線AP**（Wi-Fi）
- **DHCPサーバー**（IP配布）
- **簡易ファイアウォール**

## まとめ
- **ハブ → スイッチ → ルーター**の順で扱う階層が高くなる
- スイッチはMAC、ルーターはIPで経路判断
- NATは**プライベートIPとグローバルIPを変換**する仕組み
- 家庭のルーターは**NAPT**で1つのIPを多端末で共有
