# ポート番号とファイアウォール基礎

## ポート番号とは
同じコンピュータ上で動いている**複数のアプリを区別する番号**です。IPアドレスが「マンションの住所」なら、ポート番号は「部屋番号」にあたります。

```
[192.168.1.10]
 ├─ ポート80  → Webサーバー
 ├─ ポート22  → SSHサーバー
 └─ ポート3306→ MySQL
```

## 範囲と分類

| 範囲 | 区分 | 用途 |
|---|---|---|
| 0〜1023 | ウェルノウンポート | HTTP, SSH など標準サービス |
| 1024〜49151 | 登録済みポート | 特定ソフト用に登録されたもの |
| 49152〜65535 | 動的/プライベートポート | クライアント側の一時利用 |

## 代表的なポート番号

| ポート | プロトコル | 用途 |
|---|---|---|
| 20/21 | FTP | ファイル転送 |
| 22 | SSH | 暗号化リモート接続 |
| 25 | SMTP | メール送信 |
| 53 | DNS | 名前解決 |
| 80 | HTTP | Web（平文） |
| 110 | POP3 | メール受信 |
| 143 | IMAP | メール管理 |
| 443 | HTTPS | Web（暗号化） |
| 3306 | MySQL | データベース |
| 3389 | RDP | Windowsリモートデスクトップ |
| 5432 | PostgreSQL | データベース |
| 6379 | Redis | インメモリDB |
| 8080 | HTTP代替 | 開発サーバーなど |

## ポートの動き

### 例: Webアクセス
```
クライアント            サーバー
192.168.1.10:54321  →  203.0.113.5:443
    （動的ポート）        （ウェルノウン）
```
- クライアント側はOSが自動で空きポートを割り当てる
- サーバー側はサービスごとに決まったポートで待ち受け（LISTEN）

### ソケット
**IP + ポート番号**の組を「ソケット」と呼び、通信の端点を一意に識別します。

## よく使うコマンド
- `netstat -an` / `ss -tuln` : 開いているポートを確認
- `lsof -i :80` : ポート80を使っているプロセス
- Windowsの `netstat -ano` + `tasklist /FI "PID eq xxx"`

## ファイアウォールとは
ネットワークの通信を**許可・拒否**するルールに従ってフィルタリングする仕組みです。外部からの攻撃や意図しない通信を防ぐ役割を担います。

### 動作イメージ
```
[外部]
  │
  ▼
[ファイアウォール]  ← ルールで許可/拒否
  │
  ▼
[内部ネットワーク]
```

## ファイアウォールの種類

### パケットフィルタ型
- ヘッダ情報（IP・ポート・プロトコル）で判断
- 高速だがアプリ内容までは見ない

### ステートフルインスペクション型
- 通信の状態（接続中か否か）も記憶して判断
- 戻りの通信を自動で許可できる

### アプリケーションゲートウェイ（WAF等）
- HTTPなどアプリ層の中身まで検査
- SQLインジェクションなどを防ぐ

## ルール設計の基本

### 基本方針
- **デフォルト拒否**: 明示的に許可したもの以外は通さない
- **最小権限**: 必要最小限のポートだけ開ける
- **内向き/外向き**を別々に設計

### 例: Webサーバーの場合
```
許可:
  TCP 22   ← 管理用SSH（特定IPのみ）
  TCP 80   ← HTTP
  TCP 443  ← HTTPS
拒否:
  上記以外すべて
```

## セキュリティグループ（クラウド）
AWSなどクラウドではインスタンスごとに「セキュリティグループ」でファイアウォールを設定します。**インバウンド（入）/ アウトバウンド（出）**それぞれのルールを定義します。

## よくあるトラブル
- **繋がらない**: ポートが閉じている／ファイアウォールで遮断
- **遅い**: 想定外のポートで通信している
- **不要ポート開放**: 攻撃の入口になる

まずは `telnet ホスト ポート` や `nc -zv ホスト ポート` で疎通確認するのが定番です。

## まとめ
- ポート番号はアプリを識別する**部屋番号**
- 有名サービスにはウェルノウンポートが決まっている
- ファイアウォールは通信を**許可/拒否**する関所
- 「**デフォルト拒否＋最小許可**」がセキュリティの基本
