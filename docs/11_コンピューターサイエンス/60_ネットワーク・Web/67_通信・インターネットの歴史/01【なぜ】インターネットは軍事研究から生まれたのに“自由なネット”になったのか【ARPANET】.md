## 要約

「自由の象徴」であるインターネットが、なぜ軍事研究から生まれたのか——その矛盾の正体を、**冷戦**・**分散ネットワーク**・**ARPANET**・**TCP/IP**・**Web** まで一気通貫で解説する動画。インターネットは一人の天才の発明ではなく、**何十人もの思想・失敗・偶然の積み重ね**であり、軍の「壊れても生き残る通信」と研究者の「誰でも参加できるオープンなネット」という**目的は異なる2つの要求**が、**中央に支配を委ねない**という点で融合した結果として生まれた。

### テーマと問い

- インターネットの出発点は**軍事研究**（ARPANET）だが、今や**誰もが使う自由の象徴**になっている——この矛盾こそが本動画の主題。
- 一人の発明者に帰属できない理由：複数の研究者・機関・偶然が重なってできた**人類の合作**。
- 動画の結論：**誰も完全には支配できない**構造と**誰でも参加できる**構造が同時に成り立つこと——だから Wikipedia もモリスワームも AI も同じネット上に存在する。

### 冷戦と「通信が死ぬ」危機（1960年代）

- **1960年代のアメリカ**：冷戦の真っ只中。アメリカとソ連が核兵器を大量保有し、いつ核戦争が始まってもおかしくない状況。
- **1962年キューバ危機**：人類が核戦争の一歩手前まで行ったとされる13日間。
- **相互確証破壊（MAD）**：お互いが核で全滅できる状態にしておけば、どちらも先に打てなくなるという均衡の論理。
- 軍の致命的弱点は**通信**：
  - 当時の通信は**電話中心の中央集権型**——重要な中継拠点が数か所に集中し、そこが破壊されれば通信網全体が機能停止（将棋の「大玉」のような構造）。
  - 通信が死ぬ＝指揮系統が消える＝軍隊として機能不能。
  - MAD が成立するには「攻撃されても必ず報復できる」確信が必要だが、指揮系統破壊で報復命令が出せなくなる。
- **SAGE**（半自動地上環境システム）や軍専用の **AUTODIN** も、設計思想が中央集権型のままでは同じ弱点を抱えていた。
- **AT&T** に「壊れても生き残る通信」を相談したが、既存インフラの根本変更には協力できないと断られた——巨額投資済みのビジネスモデルを否定する話は受け入れられない。

### ポール・バランと分散ネットワーク（RAND）

- アメリカは **RAND（ランド）コーポレーション** に課題を外注——「どうすれば壊されても生き残る通信が作れるか」。
- **ポール・バラン**（RAND）が提案した**分散ネットワーク**：
  - ネットワーク構造を3類型に分類：**中央型**（星型）・**分散型**（複数拠点が束ねる）・**完全分散型**（全拠点が対等につながる網の目）。
  - できる限り**完全分散型**に近い構造を提案——中央がなければ壊す場所もない。
  - **グラフ理論**で分析：十分な冗長性があれば、核攻撃で大半のノードが失われても通信が維持できることを数学的に示した。
  - **1964年**、全11巻の報告書 *On Distributed Communications* にまとめる。
  - AT&T の技術者に「こんなもの動くわけがない」「素人が書いた空想」と一蹴された——後にインターネットの基礎になる発想。
- **ホットポテトルーティング**：パケットを受け取ったノードが即座に次へ転送（暑いジャガイモを早く渡すイメージ）。
- **ストア・アンド・フォワード**：パケットを中継ノードに一旦保存してから次へ転送——混雑時も情報が滞らず届く。

### ドナルド・デイビスとパケット交換（英国・独立発見）

- バランとは別に、イギリスの **ドナルド・デイビス**（NPL＝英国国立物理学研究所）が **1965年** に独立して似た概念を提案。
- 動機は軍事目的ではなく、**高価なコンピューターを効率よく共有したい**という発想から。
- デイビスが名付けた **パケット交換（Packet Switching）** という用語が今も使われる：
  - データを小さなパケットに分割し、それぞれが**別々の経路**で目的地へ届き、着信側で組み立て直す。
  - 従来の電話（**回線交換**）は通話中ずっと回線を2人で独占するのに対し、パケット交換は複数通信が同じ回線を分け合え、一部の経路が壊れても別経路を使える——**効率と耐久性**が根本的に異なる。

### ARPA と思想的源流

- **ARPA**（Advanced Research Projects Agency＝高等研究計画局）：
  - **1957年** ソ連のスプートニク1号打ち上げへのショックを受け、**1958年** に設立。
  - 中の **IPTO**（情報処理技術局）初代長官 **J.C.R. リックライダー** が思想的な源流：
    - **1962年**「**銀河規模コンピューターネットワーク**」構想のメモ——当時数億円の巨大機を全部つないで情報共有する未来像。
    - コンピューターを**武器ではなく人間の知性を拡張する道具**として捉えた。
  - ARPA の特徴：優秀な研究者に多額予算を渡し、**細かい口出しをしない**（成果は出せ、やり方は任せる）。
- **ラリー・ロバーツ** がバランの論文を読み込み、現実のシステムとして組み上げた中心人物。

### ARPANET の神話と真実

- よく言われる神話：「ARPANET は核攻撃対策として作られた」
- **公式な設立目的はコンピューター資源の共有**——核対策はバランの思想の話。
- 正確な順序：分散体制を持つネットワークを選んだ**結果**、核対策にもなった。
- **最初の4拠点**（すべて大学・研究所、軍施設はゼロ）：
  - UCLA、スタンフォード研究所、カリフォルニア大学サンタバーバラ校、ユタ大学
  - 軍の予算で作ったのに、最初から使っていたのは**大学の研究者**——出資者と利用者のずれが後の「自由化」の原動力に。
- **1969年10月29日**、UCLA のチャーリー・クラインがスタンフォードへ「login」と送信——途中でクラッシュし、届いたのは **「LO」** だけ。人類初の ARPANET 通信として記録された部分的成功。
- **IMP**（Interface Message Processor）：BBN が製造したパケット転送専用機——**ルーターの原型**。大型ラック級、当時約8万ドル。

### 早期の利用と「目的と使い方のずれ」

- 接続安定後、研究者は **Telnet**（遠隔操作）・**FTP**（ファイル転送）を使い始める。
- **1971年**、レイ・トムリンソンが**電子メール**を実装——`@` をユーザー名とホスト名の区切りに採用（人の名前に使われない記号を探した結果）。
- メールがトラフィックの大半を占めるようになり、**軍事用ネットワークがほぼメール専用**に——作った目的と実際の使い方が最初からずれていった。
- **1972年**、ロバート・カーンがワシントン学会で ARPANET を一般公開——「概念が現実になった瞬間」。

### オープン文化：RFC と IETF

- 研究者コミュニティの規範：**知識はオープンに共有し、誰もが対等に参加できる**。
- ARPA も「成果は公開せよ」という方針——軍の研究なのに秘密にしなかった。
- **RFC**（Request for Comments）：
  - **1969年4月**、UCLA の大学生スティーブ・クロッカーが最初の RFC を執筆——「暫定的な提案」「権威ある文書ではない」「ご意見をお聞きしたい」という謙虚なスタンス。
  - 今も番号9000超で続く——インターネットの仕様は特定企業が独占決定するのではなく、このプロセスで決まる。
- **IETF**（Internet Engineering Task Force）：「我々は国王を持たない、独裁者を持たない」——誰でも参加しコンセンサスで決める。

### TCP/IP と「旗の日」（1983年）

- 当初は **NCP**（Network Control Protocol）——ARPANET 専用の「閉じた世界の言葉」。
- **1974年**、**ヴィント・サーフ**と**ボブ・カーン**が **TCP** の論文を発表——「インターネットの父」。
  - **IP**：宛先を決める（住所を書く役割）
  - **TCP**：確実な到達を保証（届いたか確認する役割）——当初1つだったが役割分割で柔軟性向上。
  - サーフ：「TCP/IP は特許を取らなかった。取っていたらここまで普及しなかった」——オープンにすることで技術が広がるという確信。
- **DNS**（1983年、ポール・モカペトリス）：エリザベス・フェインレラーが手書きで管理していた `HOSTS.TXT` の限界を解決——階層構造で中央に頼らずスケール。
- **1983年1月1日「フラグデー」**：全通信プロトコルを TCP/IP に一斉統一——古い NCP を切り捨て、新しい旗の元に集まった日。
- **1983年**、軍の通信部分が **MILNET** として切り離され、ARPANET は純粋に研究・学術用に——**制度的にも民間化**の始まり。
- 異なるネットワーク間の接続：**EGP** → 後に **BGP**（ボーダーゲートウェイプロトコル）——インターネットは「ネットワークのネットワーク」。BGP の設定ミスで大規模障害が起きることもあり、「脆弱な要所」とも言われる。

### インターネット誕生の「誕生日」論争

- 1969年（ARPANET 初接続）派、1983年（フラグデー）派、1991年（Web 公開）派など、定義によって「正解」が変わる。
- 本動画は技術的基盤が揃った日という観点で **1983年** を採用。

### 民間化と Web の誕生

- **1990年**、ARPANET は正式終了——インターネットに発展的に解消。バックボーンは **NSFNET**（アメリカ国立科学財団）が担うが、**1980年代は商用利用禁止**。
- **1991年**、スイスの CERN の **ティム・バーナーズ＝リー** が **HTML・HTTP・URL** を設計——世界中の研究者が実験データ・論文を共有するため。
  - 初の Web サイト（1991年8月）は「Web とは何か」を説明する文書——自己言及的。
  - **1993年4月**、CERN が WWW 技術を**永久にロイヤリティフリー**と正式宣言。
- **1993年**、イリノイ大学 NCSA の **マーク・アンドリーセン** らが **モザイク** を公開——画像を文中に埋め込む最初の広域普及ブラウザ。Web トラフィックが1年で数千倍に爆増。
- **1994年**、アンドリーセンが **ネットスケープ** を設立（ブラウザ戦争の話は別動画へ）。
- **1995年**、商用利用禁止ルール廃止＋**Windows 95** 発売——一般家庭への普及が加速。ARPANET 誕生（1969年）から **26年** で家庭の普通の道具に。

### モリスワーム（1988年）——自由の代償

- **1988年11月2日**、コーネル大学のロバート・モリスが書いた**ワーム**が自己増殖しながら拡散。
  - 当時接続されていた約6万台のうち、約1割（6000台）が数時間で感染。
  - sendmail・finger・rsh など複数の脆弱性を組み合わせた攻撃——今も続くセキュリティの基本問題。
  - モリスは「ネットワークの規模を測る実験」と主張したが、感染判定のバグで同一マシンに何度も感染し続け CPU を食い潰した。
  - **コンピューター詐欺乱用法（CFAA）で有罪**——史上初。
- 事件を受け **CERT/CC**（カーネギーメロン大学）設立——脆弱性を隠さず公開して修正する文化の確立。
- インターネットは**「信頼のネットワーク」**（接続されたコンピューターが互いを信頼する前提）として設計されていた——**セキュリティは後付け**。
- 「**インターネットはセキュリティよりも接続性のために作られた**」——自由であることは悪意も自由に入ってくることでもある。

### 矛盾の正体と現代への示唆

- 軍は「壊されても死なないネット」、研究者は「誰でも参加できるオープンなネット」を求めた——目的は別だが、**中央に支配を委ねない**点で一致。
- その融合が「**誰も支配できない**」インターネットの本質的構造を生んだ。
- 皮肉：物理インフラ層ではバランの分散思想が今も生きる一方、サービス層では **Google・Apple** など巨大プラットフォームによる**中央化**が進行——「道路は誰のものでもないが、走る車は特定会社のもの」。
- **ネット中立性**：回線事業者がデータの種類で速度・料金を差別してはいけないという原則——インフラ層の「誰も支配しない」を制度で維持しようとする議論（未決着）。
- **IPv4**（32ビット・約43億アドレス）の枯渇 → **IPv6**（128ビット・約340澗）——設計者は「43億あれば十分」と思っていたが、スマホ・IoT の爆発を予想できなかった。
- **Wikipedia** はバランや初期研究者の思想の直系の子孫——同じネット上に監視・広告も共存する。
