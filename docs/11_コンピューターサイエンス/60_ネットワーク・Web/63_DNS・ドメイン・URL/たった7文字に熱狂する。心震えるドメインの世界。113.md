### 3. 日本語ドメイン（IDN）の幻

- 2010年代前半、**日本語URLがSEOに有利**という噂が一時流行。
- Googleが公式に「そうではない」とガイドラインを出し、一瞬で廃れた。
- **日銀総裁の発言と為替が先に動く**——市場がGoogleの動向を伺う様子に似ている、という比喩。
- 現在はほぼ見かけなくなったが、ドメイン専門メディアは日本語ドメインを **こだわって使い続けている**。

### 4. ドメインの基本

**ドメインとは**

- `note.com` 全体、または `studio.site` の **`studio.site` 部分**（サブドメインの手前2つ）。
- **世界で1個しか存在しない** 識別子。`note` + `.com` の組み合わせで一意に特定できる。
- `.com` など末尾は **トップレベルドメイン（TLD）**。

**なぜ人はこだわるか**

1. **会社の顔**——名刺・手打ちアクセスで意識される（QRコード時代でも）
2. **SEOの傾向**——Googleはドメインごとにランク付けしているわけではないが、`.com` の方が「立派なサイトが多い」という **結果としての優遇** がある
3. **迫力・覚悟**——`note.mu` だと「本気度が足りない」と感じる人もいる

**東京の住所序列とドメイン**

- インターネットは物理から自由なはずなのに、`.com` への引っ越しは **パワーゲーム** に似ている
- ただし物理的な場所に紐づくよりはマシ、という見方もある

### 5. ノートのドメイン物語——`note.mu` → `note.com`

**背景**

- もともと **ピースオブケイク** 社の読み物サイト「ケイクス」が母体。ノートが伸びたので集中。
- 当初は **`note.mu`**（モーリシャス `.mu`＝ミュージック系の遊び心）でスタート。

**変更の2つの理由**

| 理由 | 内容 |
|------|------|
| **実利的（SEO）** | `.mu` はマイナーTLD。`.com` の方が「大手サービス」感が出る |
| **感情的（迫力）** | 社長・加藤貞明氏「**メジャー感・覚悟・迫力が足りない**」 |

**1年がかりの取得劇**（社長＋CXO・深津惇氏が専念）

**`note.jp` の取得——人情交渉**

- 個人が保有。文具系企業ではない。
- 社長と深津氏が **新幹線で地方まで訪問**、ケーキを持参。
- 相手は `@note.jp` のメールアドレスを愛用し断るも、サービスのビジョンで **説得に成功**。
- 推定価格：**100万円台**

**`note.com` の取得——金の交渉**

- 海外の **ドメインバイヤー（転売業者）** が保有。
- 最初 **100万円** で返事が来たが、プロのエージェントが登場。
- **1億7000万円** と吹っかけられる → 深津氏が「いらない」と一度断る。
- 2ヶ月放置後、**8000万円** のオファーなど **延々の値引き交渉**。
- 社会的意義は語らない（値段が上がるため）。**ビジネスライクに徹する**。
- 推定価格：**1000万円台**

**教訓**

- ポール・グレアムの格言：「`marquee.com` が空いていなければ、**会社名を変えなさい**」
- ノートは一般名詞「note」を諦めず、ドメインを買いに行った **骨のある決断**
- **2つ同時に交渉** することで、相手に自分のカードを見せずに済むメリットもある

### 6. Netflix のドメイン諦め話

| 項目 | 内容 |
|------|------|
| **第1希望** | `rent.com`（レンタルDVD事業のため） |
| **断られた理由** | 400万ドル（約数億円）を要求され諦め |

ドメインバイヤーは **クリスマス前に売り切りたい** など、心理を読んだ交渉もある。

### 7. ドメイン取得の実務と文化

**誰でも取れる長いドメイン**

- `水野大.com` のような長い文字列は **空いていて安い**（年間1200円程度）。
- お名前.com 等で空き状況を確認できる。

**堀本さんの持ちドメイン例**

- `magicut.top`——マジックの種実験の造語。安い `.top` を選んだ結果、今は飽きている
- 計20個程度を保有

**投機の話**

- 月面開発競争のように「まだ空いてる土地を取る」感覚
- AirPods発売時に隣の社長が `hearable.com` を取得したが、**ヒアラブル** という言葉が流行らず無駄投資に
- 未来予測は当たっても、**取ったドメインの単語** が外れると意味がない

**流行りスポット化**

- `.io`（入出力のI/O）をつけると「ちょといけてる」時代があった
- 東京の不動産で「このエリアが今いけてる」ように、ドメインにも **流行り刷り** がある

### 8. フィッシング詐欺とドメイン——裏テーマの核心

**なぜドメインを見るべきか**

- 偽サイトは **見た目は本物そっくり** にできるが、**ドメインの偽造はできない**
- 例：`note.com/m` の偽サイトは `note.mu/m` など **ドメイン部分が違う**

**実践的な見分け方**

| パターン | 判断 |
|----------|------|
| **Amazon** | 本物は `amazon.co.jp`。それ以外は疑う |
| **怪しい例** | `xydkfrc.com/m` のようなランダム文字列 |
| **一般則** | 有名Webサービスは `.com` が多い。企業公式は `.co.jp` が多い（Amazonは例外として覚える） |

水野さんはURLをほとんど見ないため、詐欺に釣られやすい——今回の **ITリテラシー底上げ** が目的のひとつ。
