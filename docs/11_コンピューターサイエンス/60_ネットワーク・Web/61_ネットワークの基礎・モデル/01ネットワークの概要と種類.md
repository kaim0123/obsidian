# ネットワークの概要と種類

## ネットワークとは
複数のコンピュータやデバイスをケーブルや電波でつなぎ、データをやり取りできるようにした仕組みです。メール送信、Web閲覧、動画視聴など、現代のIT活動はすべてネットワーク上で動いています。

## 基本モデル
```
[端末A] ──── ネットワーク ──── [端末B]
 送信 →                       ← 受信
```
送信側と受信側がルール（プロトコル）に従ってデータを送受信します。

## ネットワークの種類（規模による分類）

### LAN（Local Area Network）
- 家庭、オフィス、学校など**狭い範囲**のネットワーク
- 速度が速く、管理者が自分たちで構築できる
- 例: 自宅のWi-Fi、会社内のイーサネット

### WAN（Wide Area Network）
- 都市や国をまたぐような**広域ネットワーク**
- 通信事業者（キャリア）の回線を使う
- 例: 本社と支社を結ぶ専用線、インターネット全体

### MAN / CAN / PAN
- **MAN**: 都市規模（Metropolitan）
- **CAN**: 大学のキャンパス内
- **PAN**: Bluetoothなど、身の回りの機器同士

## 構成の種類（関係性による分類）

### クライアント・サーバー型
```
[クライアント] → リクエスト → [サーバー]
                ← レスポンス ←
```
役割が明確に分かれている。Webサイトやメールは基本この形式。

### P2P（Peer to Peer）型
各端末が対等にデータをやり取りする。BitTorrent、一部のビデオ会議などで利用。

## 接続方式

### 有線
- **イーサネット（LANケーブル）**: 安定して高速
- **光ファイバー**: 長距離・超高速

### 無線
- **Wi-Fi**: 一般的な無線LAN
- **Bluetooth**: 近距離、低消費電力
- **モバイル通信（4G/5G）**: 屋外でも使える

## インターネットの位置づけ
世界中のネットワーク同士を接続した「ネットワークのネットワーク」です。TCP/IPという共通プロトコルで動いているため、異なるメーカー・OSの機器でも通信できます。

## 基本用語のミニ辞典
- **ノード**: ネットワークに接続されている機器
- **ホスト**: データを送受信する端末
- **帯域**: 単位時間に送れるデータ量（bps）
- **遅延（レイテンシ）**: データが届くまでの時間

## まとめ
- ネットワーク = 機器をつないでデータをやり取りする仕組み
- 規模で**LAN / WAN**などに分類される
- 構成で**クライアント・サーバー / P2P**に分かれる
- インターネットは世界規模のネットワークの集合体
