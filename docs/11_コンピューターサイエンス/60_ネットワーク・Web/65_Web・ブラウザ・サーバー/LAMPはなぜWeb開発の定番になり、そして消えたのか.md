## 詳しい要約

**テーマ：LAMP という「言葉」の誕生・独占・消滅**

かつて求人票の定番だった LAMP（Linux・Apache・MySQL・PHP）は言葉としてほぼ消えたが、部品は今も全部生きている（W3Techs 2026 年：PHP はサーバーサイド言語の 71.8%）。LAMP を終わらせたのはライバルではなく「サーバー 1 台」という単位の消滅であり、定番が消えるとは負けることではなく「空気になる」ことだ、というのが結論。

---

### 第1章 4 文字は誰が、何のために作ったのか

- 1998 年 12 月、ドイツの雑誌 c't の編集者**ミヒャエル・クンツェ**が記事「Let there be light（光あれ）」で命名。主張は「無料のソフト 4 つで高価な商用パッケージ（Solaris＋Netscape のサーバー＋Oracle）を代替できる」。
- 4 部品は一緒に使う前提で作られていない：
  - Linux：1991 年、フィンランドの学生リーナス・トーバルズの趣味のカーネル
  - Apache：1995 年、NCSA httpd にパッチを当て続けた有志の集まり（a patchy server が名前の由来）
  - MySQL：1995 年、スウェーデンのモンティ・ワイデニウスら
  - PHP：1995 年、カナダのラスマス・ラードフが自分の履歴書ページのアクセス集計用に書いた Personal Home Page
- O'Reilly と MySQL AB が乗り、2001 年に O'Reilly が onlamp.com を立ち上げて普及。**LAMP は技術ではなく、バラバラの部品を 1 つの選択肢に見せる「言葉の発明」**だった。

### 第2章 なぜ 2000 年代の Web を独占できたのか

- 決め手は **mod_php**：PHP を Apache のモジュールとして組み込むと、ファイルを置くだけで動く。デプロイという概念がなく「FTP で上げたら本番」。
- **レンタルサーバー経済**との相性：Apache 1 台に何千契約者を同居でき原価が激減。日本でもさくらインターネットやロリポップが月額数百円で PHP＋MySQL を提供。
- 2002 年の **XAMPP** で学生も自宅で同じ環境を再現。WordPress（2003 年）、MediaWiki を使う Wikipedia（2001 年）も LAMP 上で動く。
- 大企業も追随：2002 年 Yahoo! が独自言語を捨て PHP 採用、2004 年 Facebook も LAMP で誕生。2010 年に Facebook は PHP を C++ に変換する **HipHop** を自作して CPU 使用量を約半分に（乗り換えられなかったのが実情）。
- LAMP を定番にしたのは性能や設計思想ではなく、**置けば動く手軽さとレンタルサーバー業の経済**。

### 第3章 A・M・P が 1 文字ずつ剥がれた

| 文字 | 代替 | 経緯 |
|---|---|---|
| A（Apache） | NGINX | 接続ごとにプロセス／スレッドを割り当てる Apache は 1 万接続超でメモリが尽きる（**C10K 問題**）。2004 年公開の NGINX は少数プロセスで数万接続をさばく。Netcraft では 2019 年 4 月、W3Techs では 2021 年 3 月に逆転。「LEMP」という言葉も |
| M（MySQL） | MariaDB / MongoDB | 2008 年 Sun が MySQL AB を 10 億ドルで買収、2010 年 Oracle が Sun を買収。ワイデニウスは MariaDB をフォーク。2009 年 MongoDB 登場、2013 年に **MEAN**（MongoDB・Express・Angular・Node.js）が提案される |
| P（PHP） | Rails / Django / Node.js | 2004 年 Rails、2005 年 Django、2009 年ライアン・ダールの Node.js でフロントとバックを 1 言語で書けるように |

- LAMP は 1 つの敵に倒されたのではなく、**各文字に別の代替が現れ 4 文字が揃わなくなった**。

### 第4章 名前が消えた本当の原因

- LEMP も MEAN も定着しなかった。消えたのは部品ではなく「**1 台のサーバーに何を入れるか**」という問いそのもの。
- 2006 年 AWS EC2（サーバーの時間貸し）→ 2009 年 RDS（DB は借りるもの）→ 2013 年 Docker（環境はイメージとして配るもの）→ 2014 年 AWS Lambda（請求書からもサーバーが消える）。
- 2015 年、Netlify 創業者マティアス・ビルマンが **JAMstack**（JavaScript・API・Markup）を提唱。スタックの定義からサーバー OS も Web サーバーも DB も抜け落ちた。
- 2026 年のスタックは docker-compose と Terraform の数百行。中で PHP が動いていても 4 文字で呼ぶ意味がない。

### 最終章 部品は全部残っている

- W3Techs 2026 年：PHP 71.8%、Ruby 6.7%、JavaScript 5.9%。WordPress だけで全サイトの 43%。Apache 23.7%、NGINX 32.8%。
- 最大の勝者は L：2000 年頃は Linux 対 Windows Server（Microsoft は Windows・IIS・SQL Server・ASP で対抗）の二択だったが、今その対立を語る人はいない。**勝ちすぎて名前から消えた**。
- 面接の質問も「LAMP の経験は？」から「Laravel や Next.js の経験は？」へ。Laravel（2011 年）の中身は PHP と MySQL で Linux 上で動く。

### まとめ

- LAMP は技術ではなく、無料で本番を作れるという主張のための「言葉」だった。
- 独占の理由は mod_php の手軽さとレンタルサーバーの経済。
- 消えた原因はライバルではなく、クラウド・コンテナ・サーバーレスによる「サーバー 1 台」という単位の消滅。
- 定番の最後の姿は、誰にも名前を呼ばれないほど浸透すること。
