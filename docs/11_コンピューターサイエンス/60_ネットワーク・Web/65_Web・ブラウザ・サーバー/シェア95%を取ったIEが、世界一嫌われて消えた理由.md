## 詳しい要約

**テーマ：シェア 95% の IE が嫌われて消えたのは、独占後に更新を止めたから**

Internet Explorer は技術ではなく「無料化と OS 同梱」という流通で勝ち、シェア 95% に到達した直後に 5 年間開発を止めた。標準無視やセキュリティ欠陥で開発者と利用者に実害を与え続け、Firefox と Chrome の「自動更新」という仕組みに倒された。Chromium 一強の現在にも「独占した後に手を止めると Web 全体を道連れにする」という教訓が刺さる、という話。

---

### 第1章 無料化とOS同梱。流通で勝った最初の覇権争い

- IE は 1995 年 8 月、**Spyglass** から Mosaic のコードをライセンスして作られた（純粋な自社開発ではない）。
- 契約は IE の売上に応じたロイヤリティだったため、Microsoft は IE を**無料配布**し最低保証額だけで済ませた。Spyglass は後に監査を要求し 800 万ドルの和解金で決着。
- 無料の IE で有料の **Netscape Navigator** に正面から対抗し、さらに Windows 95 後期から **OS に同梱**。1998 年にシェアが逆転し、Netscape は AOL に買収されて第 1 次ブラウザ戦争は決着。
- 同梱戦略は米司法省との**独占禁止法裁判**に発展し、2000 年には会社分割命令まで出た（控訴で回避）。この裁判で経営陣は数年間ブラウザどころではなくなった。
- IE の勝利は技術ではなく**流通の勝利**だった。

### 第2章 頂点で開発を止めた5年間

- 2001 年 8 月 IE6 リリース、Windows XP に標準搭載されシェア 95% に。
- 次の **IE7 は 2006 年 10 月**。5 年間メジャーアップデートなし。競争相手が消え、追加投資する経済的理由がなかったため、開発チームは大幅縮小された。
- その間に CSS が成熟し、Ajax が登場し、Google マップが生まれ、Web はページからアプリケーションへ変わったが、95% のユーザーは 2001 年製のエンジンで見ていた。
- 停滞は技術力不足ではなく、**独占が生んだ「更新しない合理性」**の結果。

### 第3章 世界中の開発者に恨まれた技術的罪状

- **標準無視**：CSS ボックスモデルの解釈が W3C 標準と違い、IE だけ横幅の計算結果が変わった。
- **PNG 透過**：IE6 は PNG の半透明を正しく表示できず、背景に灰色が乗った。
- **hasLayout**：IE 内部にだけ存在する謎の概念で、レイアウト崩れの多くの原因に。開発者は意味のない zoom 指定を足して「お祓い」していた。
- 結果、まともなブラウザ向けと IE 専用のハックを**二重に書く**ことになり、IE 専用の**条件付きコメント**まで公式に用意されていた。
- **ActiveX**：Web ページから Windows のネイティブ機能を動かせる仕組みがセキュリティホールとして悪用され、ページを表示しただけでマルウェアに感染する事件が多発。2004 年に US-CERT が別ブラウザの検討を促し、2010 年の Google への攻撃「**オペレーション・オーロラ**」で IE6 の脆弱性が突かれ、ドイツ・フランス政府が IE の利用回避を呼びかけた。
- 嫌われたのは好みの問題ではなく、**標準無視とセキュリティ欠陥という実害**を与え続けたから。

### 第4章 FirefoxとChrome。自動更新の逆襲

- 2004 年 11 月 **Firefox 1.0**（Netscape の残党が起こした Mozilla から誕生）。タブ、ポップアップブロック、拡張機能など IE6 に欠けていたものを全部持ち、数年でシェア 20% 台に。
- 慌てて IE7 を出したが、5 年間ほぼ解散状態だったチームでは追いつけなかった。
- 2008 年 9 月 **Chrome** 登場。本当の発明は速さではなく**自動更新**（約 6 週間ごとに意識しないうちに最新版へ）。
- 一方 IE は OS と運命共同体で、XP を使い続ける企業には IE6 が居続けた。
- 2009 年 YouTube が IE6 サポート終了予告、2010 年に米国のデザイン会社が「IE6 の葬式」を開催し Microsoft から花が届いた。Microsoft 自身も IE6 の利用率低下を呼びかける専用サイトを公開。
- IE を倒したのは個々の新機能ではなく、**自動更新という仕組みの発明**。

### 第5章 Chromium一強はIE6の再来か

- 現在、Chrome 系エンジン **Blink** は派生ブラウザ込みでシェア 7 割超。Edge・Opera・Brave も中身は Chromium。
- 違いは Chromium がオープンソースで更新が止まっていないこと。ただし「Chrome で動けばいい」という空気は 2003 年の「IE で動けばいい」と同じ匂いがする（Safari だけ崩れる話は今も日常的）。
- Microsoft は 2015 年に後継の Edge を独自エンジンで出したが巻き返せず、**2020 年に Chromium ベースへ**作り替えた。
- IE 本体は **2022 年 6 月 15 日**にサポート終了。ただし Edge の IE モードは企業の古い社内システムのため少なくとも 2029 年まで残る予定。
- 最大の教訓：ブラウザは Web という公共インフラの入り口であり、**独占した後に手を止めると Web 全体を道連れにする**。Firefox や Safari が生き残っていることには意味がある。

### まとめ

- IE の勝利は技術ではなく「無料化と OS 同梱」という流通の勝利。
- 独占後の 5 年間の放置と、標準無視・セキュリティ欠陥が嫌われた原因。
- IE を倒したのは Firefox・Chrome が持ち込んだ**自動更新**という仕組み。
- Chromium 一強の今、選択肢が消えた市場で何が起きるかを IE の歴史が示している。
