## 要約

前回（ビジコン・Intel 4004）の続編。1970年代後半〜1980年代前半の **8ビット CPU 戦争**——**Z80** と **6502** が市場を分け合い、技術的には後発・妥協の産物だった **Intel 8088** が **IBM PC** 経由で世界標準になった逆転劇を解説する。ファミコン・Apple・MSX など身近な機種の心臓部から、オープンアーキテクチャ・互換機・**Wintel**・ネットワーク効果までを一気に辿る。核心は「**技術的に強い側が勝つとは限らない**」という市場の法則である。

### 4ビットから8ビットへ：実用 CPU の誕生

- **4004**（1971）は電卓向け **4ビット**。扱えるのは 0〜9 の1桁分。
- **8ビット**になると 0〜255 を一度に処理でき、**ASCII 1文字**も表現可能——電卓から「コンピューターらしい」用途へ。
- **8008**（1972）：8ビット化したがアドレス空間は **16 KB**、多重化バスで速度にも制約。
- **8080**（1974）：トランジスタ約 **6000** 個、アドレス空間 **64 KB**、アドレスバスとデータバスを分離。割り込みも強化され、**汎用コンピュータの心臓**として初めて実用水準に到達。
- **Altair 8800**（1975、MITS）：8080 搭載の組み立てキット（399ドル）。キーボードもゲームもないが「自分専用のコンピューター」として爆発的ヒット。**Gates & Allen** が Altair 向け BASIC を売り出し、**Microsoft の起点**に——CPU 1本がソフトウェア産業まで牽引した。

### Z80：8080 互換で高機能化した対抗馬（1976）

- **Federico Faggin** と **島正利**（4004 設計の中核）が Intel を離れ **Zilog** を設立し、**Z80** を発売。
- **8080 向けプログラムが Z80 で動く**方向の互換性——既存ソフト資産を活かせて普及しやすい。
- 強化点：
  - **インデックスレジスタ（IX/IY）**、**裏レジスタ**（割り込み時に即座に切り替え）
  - 命令数 **78 → 158** に倍増
  - **DRAM リフレッシュの自動化**——外部回路が減り、システム全体のコスト・設計負荷が下がる
- 採用例：**MSX**、NEC **PC-8801**、シャープ **MZ**、英国 **ZX Spectrum** など。当時の主要 OS **CP/M**（8080 系）を引き継げたことも追い風。
- **8ビット時代の大黒柱の一本**。

### 6502：徹底的に削って安くしたもう一方の覇者（1975）

- **MOS Technology**、設計者は **Chuck Peddle**（元 Motorola、6800 開発に関与）。
- 発売当初わずか **25ドル**（当時の 8080 は約 175ドル、**1/7以下**）。Motorola **6800** をベースに余分を削り、製造コストを極限まで下げた。
- 設計思想：汎用レジスタは少ない（アキュムレータ A とインデックス X/Y が主役）が、**ゼロページ**（先頭 256バイトへの高速アクセス）と **13種類のアドレッシングモード**（特にインデックス付き間接）で補う——**ハードウェアの制約をソフトウェアの工夫で乗り越える**。
- トランジスタ約 **3510** 個と少ないのに、クロックあたりの処理効率は高い。**割り込み応答が早い**ためゲーム機・リアルタイム制御向き。
- 採用例：
  - **Apple I / Apple II**（Wozniak は 6800 に親しんでいたが高価で手が出ず、命令セットが近く格安の 6502 を即採用——**25ドルが Apple 誕生を助けた**）
  - **Commodore PET / Commodore 64**（C64 は推定 **1000万台以上**。595ドルで Apple II 系の半額以下、優秀なグラフィック・サウンドチップでゲームも実用も両立）
  - **ファミコン**：**リコー**製カスタム **2A03**（6502 改造版。バイナリ互換だが十進演算モードを省いてコスト削減）
  - 海外では **BBC Micro**、**Atari 2600** など——世界規模で「血」が流れていた。

### 8ビット二強の裏で：Intel の16ビット戦略

- Z80 と 6502 が市場を分け合う間、Intel は **64 KB の壁**を超える **16ビット**へ静かに舵を切る。
- **8086**（1978）：トランジスタ約 **2万9000** 個（4004 の約13倍）。アドレス空間 **20ビット＝最大 1 MB**（64 KB の約16倍）。
- 特徴：
  - **EU（実行）** と **BIU（バス・命令先読み）** の分離——パイプラインの初歩形態。命令を最大6バイト分先読み。
  - **セグメント方式**（CS/DS/SS/ES）：セグメント＋オフセットで20ビットアドレスを生成。同じ物理アドレスに複数の表現があり、後年「プログラミングしにくい」と批判される **苦肉の策（kludge）**。
- **8088**（1979）：内部は8086とほぼ同じだが、**外部データバスを8ビットに絞った廉価版**。16ビットデータを2回に分けて転送するため遅いが、**8ビット時代の周辺チップがそのまま使える**——中身は16ビット・外見は8ビットという妥協が、かえって普及を助けた。
- 後方互換性は後の x86 を貫くキーワード。性能より互換を優先した選択が、半世紀近い覇権を生む。

### IBM PC：なぜ「弱い」8088が選ばれたのか（1981）

- IBM はメインフレームの王者（1980年時点で世界コンピュータ市場の大半）。個人向け PC 市場の急成長に乗り遅れると判断し、社内開発では間に合わないため **外部部品の組み合わせでスピード優先**——コードネーム **プロジェクト・チェス**（開発約1年）。
- CPU 候補には技術的に優秀な **Motorola 68000** もあったが、最終的に **8088** を採用。理由は性能ではなく：
  1. Intel チップ採用の**実績と信頼関係**
  2. **8ビット周辺チップ**と組み合わせられ、部品調達が容易・コスト抑制（68000 は周辺部品が未整備）
  3. Intel がライセンス面で協力的——**セカンドソースとして AMD** にも製造を認め、供給体制が整っていた
- **1981年8月12日** IBM PC 発売：8088 **4.77 MHz**（NTSC カラー信号用 14.318 MHz の1/3）、メモリ最小16 KB〜最大256 KB。
- 真の革命は CPU より **オープンアーキテクチャ**：BIOS 仕様と拡張スロット規格を公開し、他社が互換周辺機器・拡張ボードを作れるようにした。IBM は「大企業の信頼でスタンダードを取る」つもりだった。

### 互換機・MS-DOS・「Intel Inside」の成立

- **Compaq**（1982年末〜）：IBM PC 互換機の先駆け。BIOS は **クリーンルーム開発**（見た人と書く人を分離し、法的に問題のない独自実装）。CPU は同じ 8088、OS は MS-DOS。
- **MS-DOS の起源**：Seattle Computer Products の **86-DOS** を Microsoft が約2.5万ドルでライセンス、後に **5万ドルで著作権ごと買い取り**。IBM には PC-DOS、他社には MS-DOS として提供。**著作権を Microsoft が手元に置いた**契約が決定的——ビジコンが CPU 権利を見逃したのと同型の構造（技術の価値を過小評価した側が機会を逃す）。
- 互換機市場が爆発した結果、市場は IBM だけのものではなくなったが、**CPU はすべて Intel、OS はすべて Microsoft** という構造が固まった。IBM は自分の市場を手放し、Intel が舞台で踊り続けた——**Intel Inside**。
- 互換機の三本柱：**Intel 系 CPU** ＋ **サードパーティ互換 BIOS**（Phoenix、Award、AMI 等）＋ **MS-DOS**。参入コストが下がり、ソフト会社は「互換機向けに書けば世界中に届く」、ユーザーは「どのメーカーでも同じソフト」——**正のスパイラル（ネットワーク効果）**。
- **日本だけ例外**：NEC **PC-9801**（1982）が独自規格で日本標準に。世界が IBM 互換に統一される中、日本は独自路線（崩れるのは Windows 95 以降——別動画）。

### その後の展開と教訓

- **80286**（IBM PC/AT、1984）→ **386**（1985）→ **486**（1989）：x86 命令セット互換を保ちながら進化。現代の Core シリーズも骨格としての互換性は半世紀近く維持（実装は別物）。設計者は当初ここまで長く生き残るとは想像していなかった。
- **Apple** は独自路線：初代 Mac は **Motorola 68000** → PowerPC → **2006年に Intel x86** → 現在は自社設計 **Apple Silicon（ARM）**。
- **Wintel**（Windows + Intel）：1990年代を通じて PC 市場を事実上支配。高性能 CPU と重い OS・ソフトが循環し市場を牽引。
- 構造が崩れ始めたのは **スマートフォン**——スマホ向けは **ARM** が主流で、Intel は成功できなかった。x86 が世界標準だったのは **パソコン市場に限定**され、新市場では別の勝者が生まれた。

### 結論：なぜ“弱い側”が世界を取ったのか

| 勢力 | 強み | 主な土俵 |
|---|---|---|
| **Z80** | ソフト資産・設計の簡便さ | MSX、業務機器、CP/M 系 |
| **6502** | 圧倒的低価格・効率・割り込み応答 | Apple、ファミコン、C64、ゲーム機 |
| **8088** | 周辺エコシステム・供給・互換の積み上げ | IBM PC → 世界の PC 標準 |

- Z80 と 6502 のどちらが技術的に優れていたかは用途次第で答えは出ない。それぞれ自分の土俵を持っていた。
- 最終的に世界標準になったのは、8ビット二強でも 68000 でもなく、**性能では劣るが安く組めて供給が安定した 8088**。IBM のオープン戦略が互換機を呼び込み、**ネットワーク効果**（使う人が多いほどソフトが増え、さらに人が集まる）で固定化された。
- **VHS vs ベータマックス**と同じ構造——技術的優劣だけで勝敗は決まらない。後発が「うちの方が優れている」と主張しても、既存エコシステムを逆転するのは極めて難しい。
- もう一つの教訓：**技術は人と一緒に動く**。Faggin・島が Zilog を作り、Peddle が 6502 を作ったように、設計者が会社を渡り歩くことで技術が伝播する。
- 4004 という小さな電卓チップの思想が、8008・8080 と成長し、Z80・6502 という支流を分けながら、最終的に **IBM PC というダム**に注ぎ込んで世界標準を生んだ。覇権は永遠ではなく、8ビット時代から始まったドラマは形を変えながら今も続いている。
