# GPU・専用チップ — NVIDIA、CUDA、TPU

> **この章を読むと分かること**
> - GPU って結局なに？ CPU と何が違う？
> - なぜ「アホな多数（GPU）」が「賢い1人（CPU）」に勝ったのか
> - なぜ NVIDIA が世界一の企業になったのか（実は GPU 自体は誰でも作れる）
> - Google が作った TPU が「異端すぎる」中身
> - 「汎用 → 専用」へと進む計算機の歴史的逆転

---

## はじめに — 「アホな多数」が「賢い1人」に勝つ話

CPU と GPU は、よく次のように例えられます。

| | **CPU** | **GPU** |
|---|---|---|
| キャラ | 賢い1人 | アホな多数 |
| 仕事 | 判断 + 保存 + 演算 | 保存 + 演算（判断はしない） |
| イメージ | 社長 | 経理部のソルジャー |

> ここで疑問：**「賢い1人」を大量に集めればいいじゃない？**
> 
> 実際、賢い CPU を多数並べる試みもありました（2013年の **Xeon Phi** など）。
> しかし、**アホな多数（GPU）が勝った**。なぜ？

この章ではその謎を解いていきます。

---

## 1. CPU と GPU の根本的な違い

### 1-1. 会社組織の例え

```
┌─────────────────────────────────┐
│  会社（コンピュータ）             │
├─────────────────────────────────┤
│                                 │
│  社長（CPU）                    │
│   ↓ 指示                        │
│   ↓                             │
│  経理部のソルジャー多数（GPU）   │
│   ・指示待ち                    │
│   ・単純作業を一斉に処理         │
│                                 │
└─────────────────────────────────┘
```

| 比較項目 | CPU（社長） | GPU（経理ソルジャー） |
|---------|---------|---------|
| 必須か | **必須**（CPU のないPCは存在しない） | サブ装置（無くてもPCは動く） |
| 役割 | 判断、保存、演算 | 保存、演算のみ |
| 仕事の単位 | 複雑な判断 | 単純作業の繰り返し |
| 人数 | 少（数コア） | **多**（数千コア） |

### 1-2. なぜ GPU は判断しないのか

CPU は **割り込み制御** や **優先順位判断** をしています。

> **CPU の判断の例**：動画を書き出している最中にキーボード入力があった
>
> → 「動画書き出しを一旦止めて、キー入力を先に処理しよう」
> → スムーズな操作感を実現

これを CPU は秒間に何百万回もやっています。

GPU はそういう **複雑な判断はせず**、「言われたことをひたすら計算する」だけです。

---

## 2. なぜ「CPU多数」では勝てなかったのか

### 2-1. 船頭多くして船山に登る

CPU を増やすと、各 CPU は「他の CPU が何を判断しているか」を **常に気にしなければなりません**。

```
CPU-A が考える：「メモリ100番地を書き換えたい」
CPU-B が考える：「メモリ100番地を書き換えたい」
        ↓
両者が独立に判断したら、内容が食い違う！
        ↓
CPU-A：「俺いま100番地書き換えるよ、いい？」
CPU-B：「待って、こっちもだから」
        ↓
こういう調整に膨大なコストがかかる
（キャッシュコヒーレンシを保つ問題）
```

CPU の本来の仕事である「計算」より、**周囲との調整コスト** のほうが大きくなってしまうのです。

> **教訓**：社長が2人いる会社は混乱する。

### 2-2. 衆議院と参議院

これって、実は人間の社会の話とそっくりです。

- 議員が多すぎる議会は何も決められない
- 優秀すぎる人を集めると権力闘争で時間を浪費する（『知性の罠』より）
- 「現場で働きたい人」を無理に管理職にすると、両方ダメになる

> **CPU 多数のアプローチが負けたのも、これと同じ理由でした。**

### 2-3. アホな多数の強み

逆に GPU は判断しないので、調整コストが要りません。

```
社長：「このレシート300枚、計算しといて」
   ↓
ソルジャー300人が、それぞれ1枚ずつ計算
   ↓
判断不要、独立に作業、衝突しない
   ↓
高速完了
```

これが現代の AI 学習（大量の単純な行列計算）に異常に向いていました。

---

## 3. GPU が AI に強い理由

### 3-1. 画像処理＝大量の単純計算

GPU はもともと「Graphics Processing Unit」、つまり **画像処理装置** です。

> 例：画像を明るくする処理
> ```
> 1画素ずつ、赤・緑・青の値を2倍にする
> 1000万画素なら → 1000万個の独立した単純計算
> ```

GPU はこの **「同じ単純計算を大量に並列で」** という仕事に特化しています。

### 3-2. ディープラーニングも同じ構造

ディープラーニング（AI の学習）の本質は、

> **大量の足し算とかけ算の繰り返し**（行列計算）

画像処理用の GPU が AI 学習に転用できる理由がこれです。誰かが「これ AI に使えるじゃん」と気づいて、世界が変わりました。

## 4. NVIDIA はなぜ世界一になれたのか

### 4-1. 実は GPU 自体は誰でも作れる

NVIDIA は **ファブレス企業**（製造を TSMC に委託）です。だとしたら、他社も TSMC に発注すれば同じものが作れそうですよね？

> **答え**：GPU 自体は確かに誰でも作れる。
> でも **「CUDA に対応した GPU」を作れるのは NVIDIA だけ**。

### 4-2. CUDA — ハードウェアを売る会社のソフトウェア

**CUDA** は、GPU に命令を出すための **プログラミング言語＋プラットフォーム** です。

```
通常のプログラミング言語 → CPU 向け
            ↓
GPU は特殊（判断しない、並列実行）
            ↓
GPU 用の別の指示方法が必要 = CUDA
```

業界共通規格として **OpenCL** もありますが、CUDA は NVIDIA の自社規格です。

### 4-3. なぜ CUDA は強いのか

**1. 速い（最適化されている）**

CUDA は NVIDIA の GPU と **密接に結びついた（癒着した）** 設計です。OpenCL のような共通規格は「複数のメーカーに対応する必要がある」ため、特定のハードに最適化できません。

```
CUDA（NVIDIA専用）：
   ハードの細部まで知ったコンパイラで最適化
   ↓
   圧倒的に速い

OpenCL（共通規格）：
   どのハードでも動く必要がある
   ↓
   最適化に限界がある
```

**2. ロックイン（最大の優位性）**

これが本丸です。

```
2007年頃から、NVIDIA は研究機関に GPU を無料・安価で提供
       ↓
研究者が CUDA を使って論文・ライブラリを書く
       ↓
世界中の AI 関連コードが CUDA 前提で蓄積される
       ↓
2012年、ディープラーニング・ブーム
       ↓
「AI やるなら NVIDIA」が既成事実に
       ↓
他社製品を選ぶと「みんなが使うあのライブラリが使えない」
       ↓
誰もが NVIDIA を選ぶ正のスパイラル
```

> **NVIDIA は GPU を売っているように見えて、本質は CUDA エコシステムを売っている**。
> ハードとソフトを一体で設計しているからこそ強い。

### 4-4. 任天堂とは逆の戦略

任天堂は「ハードを安く売って、独占ソフトで儲ける」モデル。NVIDIA は逆です。

```
NVIDIA：「ソフト（CUDA）で客を集め、そのソフトが動くハード（GPU）を高く売る」
```

これが **ハードウェアの逆襲** とも呼ばれる戦略です。

## 5. TPU — Google の「異端」な専用チップ

### 5-1. TPU とは何か

**TPU**（Tensor Processing Unit）は Google が開発した AI 専用チップです。Gemini 3 などの AI 学習にも使われています。

2025年11月、TPU が GPU の代替になりうると報じられ、NVIDIA の時価総額が **約38兆円減少** する事件もありました。

### 5-2. 役割の階層

| | 役割 |
|---|---|
| **CPU** | 判断 + 保存 + 演算（社長） |
| **GPU** | 保存 + 演算（経理ソルジャー） |
| **TPU** | **演算だけ**（脳と記憶を抜いたソルジャー） |

TPU はさらに特化しています。**保存すらしません。**

### 5-3. TPU の核心 — バケツリレー方式

ディープラーニングは大量の **「掛け算 → 合計」** を繰り返します。

```
GPU の方式（300回のメモリ読み書き）
30人に10個ずつ計算を割り当て：
  1. 計算 → メモリに書く
  2. メモリから読む → 計算 → メモリに書く
  3. ...（繰り返し）
   ↓ メモリへの読み書きで電力消費が大きい

TPU の方式（10回のメモリ読み書き）
30人に1個ずつ計算を割り当て：
  1. 計算結果を「隣の人に直接渡す」だけ
  2. 隣も計算して、また隣に渡す
  3. 最後の人だけが結果をメモに書く
   ↓ メモリアクセスを激減
```

### 5-4. なぜこれが「異端」なのか

[[01-半導体と論理回路とは|01-半導体]] のチューリングマシンを思い出してください。あれは **「テープを読み書きする」** のが計算の本質でした。

```
チューリング以来の常識：
  計算とは、記号を読む → 書き換える → 状態を変える の繰り返し
       ↓
ノイマン型コンピュータも、すべて「メモリの読み書き」が前提
       ↓
ところが TPU は…
       ↓
「読み書きしない」設計
電気信号をそのまま隣の回路に渡してしまう
```

これは **コンピュータの根本前提を破った設計** とも言えます。汎用性はほぼゼロですが、**特定のタスク（行列計算）には最強**。

### 5-5. ニューロンに似ている

TPU の「隣のユニットへ電気信号をそのまま渡す」構造は、**人間の脳のニューロン** に似ています。

```
ニューロン：信号を隣のニューロンへ電気的に伝える
       ↓
TPU：信号を隣の演算ユニットへ電気的に伝える
       ↓
偶然なのか、必然なのか
```

人間の脳を模した AI を動かすチップが、**脳の動作原理に似てきている** のは、味わい深い話です。

## 6. 計算機史の逆転 — 汎用から専用へ

### 6-1. 計算機の歴史的な流れ

```
古代〜中世   専用機（そろばん、歯車式計算機）
   ↓
17〜19世紀  パスカル・ライプニッツ・バベッジ（→ [[01歴史/01-計算の机械化]]）
   ↓
1940年代   ENIAC（電子式専用機）
   ↓
1945〜     ノイマン型（汎用機の確立）
   ↓ 60年以上の汎用機時代
2000年代   GPU（半専用）
   ↓
2010年代   TPU など AI 専用チップ
   ↓
将来      ニューロモーフィックチップ、量子コンピュータ
```

### 6-2. 皮肉な歴史の往復

> **人類は長らく「汎用性」を求めてきた。**
> 
> しかし汎用機では解けない問題（「猫の写真を識別する」「自然言語で会話する」など）を解くために、**ディープラーニング** を導入した。
> 
> その結果、**専用計算機のニーズがむしろ増えた**。

汎用 → 専用 → 汎用 → 専用、という振り子。

### 6-3. 「ノイマンボトルネック」への挑戦

[[01-計算の机械化とは|01-計算の机械化]] で触れた **ノイマンボトルネック**（CPU とメモリの分離が遅さの原因）に対して：

| アプローチ | 解決方針 |
|--------|---------|
| **キャッシュ** | メモリへの旅をできるだけ短く（CPU の近くに高速メモリを置く） |
| **GPU** | 数千の単純作業員で物量で押す |
| **TPU** | 「メモリに行かない」設計でボトルネックを回避 |
| **ニューロモーフィック** | 脳のような構造で、根本的にノイマン型から離れる |
| **量子コンピュータ** | 計算モデルそのものが違う |

> **どれも「ノイマン型を完全置換」するわけではなく、得意分野が違う**。
> ノイマン型は当分現役、しかし周辺に専用機が広がっていく時代です。

## 7. この章のまとめ

### 大きな流れ

```
1990s   GPU（画像処理装置として誕生）
   ↓
2000s   NVIDIA が CUDA を投入、研究機関に拡散
   ↓
2007    GPU が AI 学習に転用され始める
   ↓
2012    ディープラーニング・ブーム → GPU 需要爆発
   ↓
2016    Google が TPU を発表（さらに特化）
   ↓
2020s   AI ブーム、NVIDIA が世界一の時価総額
   ↓
2025    TPU が GPU の代替候補に、勢力地図が再変動
```

### 大切なポイント

1. **「アホな多数」が「賢い1人」に勝つことがある**
   判断しなくていい仕事なら、ソルジャーの数が勝つ。

2. **NVIDIA の強さの本質はソフトウェア（CUDA）**
   ハードを売っているように見えて、エコシステムが本丸。

3. **TPU はコンピュータの根本前提を破った**
   「メモリの読み書き」をしない設計。汎用性を捨てて速さを取った。

4. **汎用 → 専用への揺り戻し**
   AI 時代は専用チップが復活する時代。歴史は単純に直線では進まない。

5. **ハードとソフトは一体**
   片方だけ見ても全体は理解できない。
