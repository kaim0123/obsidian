## 詳しい要約

**テーマ：情報量とエントロピーを実際に計算し、「親しくなる＝エントロピーが減る」を理解する**

情報理論シリーズ第3回。情報量の定義「−log₂(確率)」と、その期待値であるエントロピーを、赤ちゃんの性別やくじ引きなどの例で実際に計算する。エントロピーは確率が散らばっているほど大きく、偏るほど小さい。さらに同じ質問でも観測者の前提知識によってエントロピーは変わり、友だちと親しくなることは「友だちという情報源のエントロピーが小さくなること」だと結論づける。

---

### 用語の整理

- 専門用語（自己エントロピー、選択情報量など）は多いが、本動画では「**情報量**」と、その**期待値＝エントロピー**の2つだけを使う。

### 情報量の計算と1ビット

- 定義：**情報量 = −log₂(確率)**。
- いつも晴れの惑星で「晴れ」と知る：確率1 → −log₂1 = **0**（価値ゼロ）。
- 性別がわからない赤ちゃんが男の子だと判明：確率1/2 → −log₂(1/2) = **1**。この単位が**ビット**（1バイト＝8ビット）。
- くじで8人から1人のペアが決まる：確率1/8 → **3ビット**。
- **確率が小さい（レアな）出来事ほど情報量が大きい**。「犬が人を噛んでもニュースにならないが、人が犬を噛めばニュースになる」という定番例もこれ。
- 対数なので、1/1024 の出来事でも10ビット程度と、増え方は穏やか。この定義は0と1で動くコンピューターとの相性が非常に良い。

### エントロピー＝情報量の期待値

- エントロピーは、その情報源から得られる**情報量の期待値**（確率×情報量の総和）。
- 性別が男女1/2ずつの場合：1/2×1 + 1/2×1 = **1ビット**。
- 事前検診で男の子と100%わかっている場合、出産時に「男の子です」と言われても情報量は0 → **エントロピー0**。前提条件があると条件付き確率が1になるため。

### 偏っているとエントロピーは小さい

- 7/8 と 1/8 の場合（8人中1人だけ気が合わない人がいる例）のエントロピーは約**0.54ビット**。
- 均等に散らばる（1/2ずつ）と1、偏るほど小さくなり、極限まで偏ると0。

### 初代ポケモン四天王、誰が好き？

- 堀元さんが四天王（カンナ・シバ・キクコ・ワタル）の誰が好きかを答える、という情報源のエントロピーを考える。
- 堀元さんを全く知らない人：全員1/4 → **2ビット**。
- リスナー：前提情報から「キクコ1/2、カンナ1/4、残り1/8ずつ」と見当をつけられる → 約**1.75ビット**。
- キクコ愛を15分熱弁された編集スタッフ：答えがわかっている → **0ビット**。
- 天気予報でも、予報を作った気象予報士にとっては読み上げられる予報のエントロピーはほぼ0。**同じ情報源でも観測者によってエントロピーは違う**。

### 友だちと親しくなる＝エントロピーが減る

- 付き合いが長くなると「こう聞かれたらこう答えるだろう」と予測でき、条件付き確率の条件が増える → **友だちという情報源のエントロピーが小さくなる**。
- 冒頭の「同じ人とばかり飲むのが嫌」は、エントロピーが0に近づくから、という冗談につながる。
- 観測者次第なので、2人の「客観的なエントロピー」を比べることはできない。飲み会の前に相手の答えを予測しておけば、エントロピーを意識して参加できる。

### まとめ

- 情報量 = −log₂(確率)。レアな出来事ほど大きい。単位はビット。
- エントロピー = 情報量の期待値。確率が散らばるほど大きく、偏るほど小さい。
- エントロピーは観測者の前提知識で変わる。親しくなるとはエントロピーが減ること。
- 次回（最終回）は、なぜ「コミュニケーションの数学的理論」と呼べるのかを扱う予定。
