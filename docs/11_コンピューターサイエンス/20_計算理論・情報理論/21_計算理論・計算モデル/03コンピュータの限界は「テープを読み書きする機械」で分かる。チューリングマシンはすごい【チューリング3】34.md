## 要約

**シリーズの位置づけ**

チューリングシリーズ第3回。前回までの流れ——決定問題（証明可能かを判定する手順があるか）に取り組んだチューリング——を踏まえ、本回は **1936年論文の核心であるチューリングマシン** と、そこから導かれた **「コンピュータの限界」** の先見性を解説。次回（最終回）は功績の **原体験（初恋？）** と人生の結びつき。

### 前回までの復習

- チューリングの本質的仕事 ＝ **アルゴリズムを考えること** → **コンピュータ科学の父**。
- 決定問題：命題が **証明可能かどうかを事前に判定できる手順（マニュアル）** があるか？ という問い。

### チューリングマシン——「無限に長いテープ」から始まる論文

数学論文なのに **いきなり機械の話** から始まる——これが1936年論文の冒頭。

| 要素 | 内容 |
|------|------|
| **テープ** | **無限に長い** 紙テープ。マス目に区切られ、記号（0, 1 等）を読み書き |
| **ヘッド** | テープ上を **左右に移動** しながら記号を読んだり書き換えたり |
| **状態** | マシン内部に **状態 A, B, C…** を保持 |
| **ルール表** | 「状態 A で 0 を読んだら右に移動して 1 を書く」等の **条件分岐** |

- **作る前提ではない**。「こういう仮想マシンがあったと **仮定する**」ための思考実験。
- 言語学の **オートマトン** と論理的に近いが、オートマトンより **表現力が強い**（オートマトンでできることはチューリングマシンでもできる）。
- 大学生のあるある：**「だから何？」** —— ルール4行程度では意味不明。手で実行しても **「だから何？」** のまま。

### 原始的な操作の組み合わせ——半導体シリーズと同じ構造

**ゆるコンピュータ科学ラジオ・半導体シリーズ**（全4回）との接続：

- **トランジスタ**：背中に電流が入れば右→左に流す——**それだけ** の超原始的操作。
- 大量に組み合わせる → 半加算器・全加算器 → **足し算・掛け算** が可能に。
- **チューリングマシン** も同じ：**読む・書く・移動・状態遷移** だけを何十・何百回も組み合わせる。

実演例：

- 状態4つ程度の簡単なルール → 意味不明。
- 状態 **32以上** のルール一覧 → **掛け算**（例：12 × 35）が可能。地獄の量のルール表が必要。
- 2進数の 0/1 で数字を表現し、テープ上に答えが **印字** されるイメージ。

歴史的には **バベッジ**（階差機関・解析機）や **ライプニッツ** も似た発想を持っていたが、チューリングの革新は **手続きを誰にでもわかる形で形式化** した点。

### 論文の真の凄さ——「コンピュータの限界」を示した

「掛け算できる」だけでは **すごくない**。本当の価値は別にある。

**1. できること・できないことを明確に線引き**

- チューリングマシンで **扱える問題のクラス** と **扱えないクラス** を **数学的に厳密に** 定義。
- 「人の心は計算できない」的な **詩的・雰囲気的** な話 **ではない**。論理立てて **スコープを限定** して記述。
- 言語学の文法も **ある程度まで** は扱えるが、それ以上は **「ここまで」と明言** —— 各分野の人が「そうだね」と納得できる整理。

**2. コンピュータがまだ存在しない時代に、限界を予見**

- 1930年代——**電子コンピュータは世の中にない**。
- それでも「**ここまでは確実にできる。ここから先は確実にできない**」と **完全にはっきり** 示した。
- 比喩：空飛ぶ自動車がまだない時代に「**ここまでは運転でいける。ここから先は無理**」と断言するレベルの先見性。

**3. コンピュータの万能性を保証**

- **正しいアルゴリズムが存在する問題** なら、チューリングマシン（＝現代コンピュータ）が **必ず答えを出す**。
- 後世のコンピュータ開発者が **「組み合わせれば何でも解ける」という希望** を持って進める道しるべになった。
- 比喩：「あなたが出願しているのは **女子大** だから、条件を満たせば **受かる** —— 男子大に出願してるわけじゃないから安心して」。

### アルゴリズムで書けない＝コンピュータで扱えない

- **明確な手順（アルゴリズム）で定義できない問題** は、チューリングマシンでも **原理的に扱えない**。
- 恋人との関係や **そのままの株価** など——手順化できないものは計算対象外。
- アルゴリズムトレードは **「前日こう動いた株はこう動く」等のルールに単純化** しているから可能——本来扱えないものを **扱える形に落としている** だけ。

### チューリングの本来の目的——決定問題への回答

万能性の保証は **副産物**。本当にやりたかったこと：

> **「この命題は証明可能か？」を事前に判定するアルゴリズムは存在するか？**

**結論：存在しない。**

| 概念 | 関係 |
|------|------|
| **計算可能（computable）** | チューリングマシンで処理できる |
| **証明可能（provable）** | 決定問題の文脈では **計算可能と同値** |
| **決定問題** | **解けない** —— 判定アルゴリズムはない |

### 停止性問題（Halting Problem）——無限ループは検出できない

論文の核心の一つ。**停止性問題**：

- 与えられたアルゴリズムが **いつか止まるか、永遠に走り続けるか** を判定するアルゴリズムはあるか？
- チューリングの証明：**存在しない**（自己言及パラドックスで矛盾を導く）。

**自己言及の仕組み（簡略）**

- 「止まるか判定するアルゴリズム H」が存在すると **仮定**。
- H に **自分自身** を入力すると矛盾が生じる（止まるなら止まらない、止まらないなら止まる）。
- よって H は **存在し得ない**。

**現代プログラミングへの影響**

- **無限ループ** をプログラムが **書いた時点で検出して教えてくれる** ことは、**原理的に不可能**。
- 「ここ無限ループに入ってますよ」と IDE が教えてくれることは **永遠に実現しない** —— チューリングが1930年代に証明済み。
- ゆるコンピュータ科学ラジオの **「ブラックボックスはお前だ」回** —— ああいう結論を出さざるを得ない状況も、チューリングが **「しょうがない」** と示していた。

### 皮肉な結論

- **コンピュータができないことを示した功績** で、**コンピュータ科学の父** になっている——人生自体も白雪姫のように皮肉めいている。
- 決定問題の答えは **否定的** だが、その **否定的結果自体** が20世紀最重要級の成果。
- 次回（最終回）：功績を生んだ **原体験**（たぶん初恋）と、報われなかった人生の話。
