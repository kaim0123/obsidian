# MOC_コンピューターサイエンス体系

11_コンピューターサイエンス の入口ノート。ACM/IEEE **CS2023** と情報処理学会 **J07-CS** の知識エリアを参考に、**歴史 → 理論 → アルゴリズム → ハードウェア → OS → ネットワーク → データ → 言語 → 暗号 → AI** の分野別に整理している。
学習順に読みたいときは [[まとめ目次]]（2チャンネル横断の学習ロードマップ）から辿る。

- 各分野の下は **番号付きのトピックフォルダ**（例：50_OS → 51_OSの役割・起動, 52_カーネル…）。自分のまとめ・体系ノートも動画・ラジオの回も、内容で振り分ける
- 分野の入口になるマップ（分野別歴史マップ・分野別深掘りマップ）だけは分野フォルダ直下に置く
- 連載シリーズはトピックごとに分かれるので、通しで見たいときは下の「シリーズの所在」を使う
- ノートが少ない分野（85_暗号・99_エッセイ・雑学）はサブフォルダを作らない
- 情報源（ゆっくり情報科学ちゃんねる／ゆるコンピューター科学ラジオ）はフォルダで分けず、各ノートの `author` プロパティで区別する
- 複数分野にまたがるノートは主な1分野に置き、ここからリンクする
- 実務寄りのノートは 010Programming の各実務フォルダへ置く（下記「CS外に置いたノート」）
