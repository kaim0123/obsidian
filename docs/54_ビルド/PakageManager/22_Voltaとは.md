## Voltaとは（Valtaと書かれることもある）

### 概要

- **Volta** は、**Node.js・npm・パッケージマネージャー（yarn / pnpm など）をユーザーごとに固定するためのツール**です。
- `nvm` のような「Node バージョン切り替えツール」の一種ですが、
  - 実行が高速
  - プロジェクトごとにバージョンを自動切り替え
  - グローバルに入れた CLI もまとめて管理
 という特徴があります。

### 何が嬉しいのか

- **プロジェクトごとに Node / npm のバージョンを固定**できる  
  → 「このプロジェクトは Node 18 / npm 10 で動かす」と決めておけば、他のプロジェクトと混ざらない。
- 一度 Volta でツールを入れておけば、**どのフォルダからでも同じバージョンで実行**できる。
- Windows / macOS / Linux で動き、特に **Windows での使いやすさが高い**（`nvm-windows` より安定していると言われることが多い）。

### 基本用語

- **ツール（tool）**：Node / npm / yarn / pnpm などの実行コマンド
- **Pin（ピン留め）**：プロジェクトに対して「このバージョンを使う」と固定すること

### 代表的な使い方イメージ

#### 1. Volta のインストール

（公式インストール方法の一例。実際は公式ドキュメントを参照すること）

```bash
# 例：PowerShell で実行するスクリプト（イメージ）
irm https://get.volta.sh | sh
```

#### 2. Node のインストール

```bash
volta install node@18
```

このコマンドで、

- Node.js 18 系
- それに対応する npm

が Volta 管理下にインストールされ、以後 `node` / `npm` コマンドを打つと Volta 経由で実行されます。

#### 3. プロジェクトごとにバージョンを固定（pin）

```bash
cd my-project
volta pin node@20
volta pin npm@10
```

- プロジェクト直下の `package.json` に、Volta 用の設定が追記されます。
- このプロジェクトに入ると、自動的に Node 20 / npm 10 が使われるようになります。

#### 4. グローバル CLI の管理

```bash
volta install pnpm
volta install yarn
```

- `pnpm` や `yarn` を OS のグローバルではなく **Volta 経由で管理**できます。
- CLI ツールを増やしても、PATH がゴチャゴチャしにくいのが利点です。

### 他ツールとの違い（ざっくり比較）

- **nvm / nvm-windows**
  - シンプルな「Node バージョン切り替え」ツール
  - シェル起動時に読み込むので、やや遅く感じることもある
- **Volta**
  - 実行ファイルのラッパーを PATH に置く方式で**起動が速い**
  - Node だけでなく npm / yarn / pnpm などもまとめて管理
  - プロジェクト単位のピン留めが標準機能として備わっている

### どんなときに使うとよいか

- JavaScript / TypeScript プロジェクトを複数抱えている
- チームで **Node / npm のバージョンを揃えたい**
- Windows 環境で安定した Node バージョン管理を行いたい

という状況では、Volta を標準ツールにしておくとトラブルが減ります。

### まとめ

- **Volta は「Node / npm / パッケージマネージャーのバージョンを、ユーザー単位・プロジェクト単位で安全に固定するツール」**。
- `nvm` よりも
  - パフォーマンス
  - Windows での扱いやすさ
  - プロジェクト単位の管理
に強みがあり、モダンな Node 開発では採用されることが増えてきています。
