# パッケージ管理の基礎

## はじめに

プログラミングでは、他の人が作ったライブラリ（パッケージ）を使うことがよくあります。これらのパッケージを管理する方法を学ぶことは重要です。

この章では、Pythonのパッケージ管理の基礎を学びます。

## パッケージとは

**パッケージ**とは、他の人が作った再利用可能なコードの集まりです。

### 例

- **requests**：HTTPリクエストを簡単に送れる
- **numpy**：数値計算ができる
- **pandas**：データ分析ができる

## pipとは

**pip**は、Pythonのパッケージをインストール・管理するツールです。

### pipの基本的な使い方

#### 1. パッケージのインストール

```bash
pip install パッケージ名
```

**例**：
```bash
pip install requests
```

#### 2. パッケージのアンインストール

```bash
pip uninstall パッケージ名
```

**例**：
```bash
pip uninstall requests
```

#### 3. インストール済みパッケージの確認

```bash
pip list
```

#### 4. パッケージ情報の確認

```bash
pip show パッケージ名
```

**例**：
```bash
pip show requests
```

#### 5. パッケージの更新

```bash
pip install --upgrade パッケージ名
```

**例**：
```bash
pip install --upgrade requests
```

## requirements.txt

プロジェクトで使うパッケージのリストを`requirements.txt`というファイルに書きます。

### requirements.txtの書き方

```
requests==2.31.0
numpy>=1.24.0
pandas~=2.0.0
```

### バージョンの指定方法

- `==2.31.0`：正確にこのバージョン
- `>=1.24.0`：1.24.0以上
- `~=2.0.0`：2.0.0以上、3.0.0未満
- バージョン指定なし：最新版

### requirements.txtからインストール

```bash
pip install -r requirements.txt
```

### requirements.txtを生成

```bash
pip freeze > requirements.txt
```

現在インストールされているパッケージのリストを`requirements.txt`に出力します。

## 仮想環境（Virtual Environment）

### なぜ仮想環境が必要か

異なるプロジェクトで、異なるバージョンのパッケージを使うことがあります。仮想環境を使うと、プロジェクトごとにパッケージを管理できます。

### 仮想環境の作成

```bash
# Python 3.3以降
python -m venv 環境名

# 例
python -m venv myenv
```

### 仮想環境の有効化

**Windows**：
```bash
myenv\Scripts\activate
```

**macOS/Linux**：
```bash
source myenv/bin/activate
```

有効化されると、プロンプトに環境名が表示されます：
```
(myenv) C:\Users\YourName>
```

### 仮想環境の無効化

```bash
deactivate
```

## 実践例

### 例1：新しいプロジェクトを始める

```bash
# 1. プロジェクトフォルダを作成
mkdir my_project
cd my_project

# 2. 仮想環境を作成
python -m venv venv

# 3. 仮想環境を有効化
# Windows
venv\Scripts\activate
# macOS/Linux
source venv/bin/activate

# 4. 必要なパッケージをインストール
pip install requests

# 5. requirements.txtを生成
pip freeze > requirements.txt
```

### 例2：他の人のプロジェクトを使う

```bash
# 1. プロジェクトをダウンロード（例：Gitから）

# 2. 仮想環境を作成
python -m venv venv

# 3. 仮想環境を有効化
venv\Scripts\activate  # Windows
# source venv/bin/activate  # macOS/Linux

# 4. requirements.txtからインストール
pip install -r requirements.txt
```

## よく使うパッケージ

### 1. requests（HTTPリクエスト）

```python
import requests

response = requests.get("https://api.example.com/data")
print(response.json())
```

### 2. numpy（数値計算）

```python
import numpy as np

arr = np.array([1, 2, 3, 4, 5])
print(arr.mean())  # 平均値
```

### 3. pandas（データ分析）

```python
import pandas as pd

df = pd.read_csv("data.csv")
print(df.head())
```

## パッケージの探し方

### 1. PyPI（Python Package Index）

https://pypi.org/

Pythonの公式パッケージリポジトリです。ここからパッケージを検索できます。

### 2. 検索エンジン

「Python [やりたいこと]」で検索すると、適切なパッケージが見つかることが多いです。

**例**：
- 「Python HTTP リクエスト」→ `requests`
- 「Python データ分析」→ `pandas`
- 「Python 画像処理」→ `Pillow`

## トラブルシューティング

### 1. パッケージが見つからない

```bash
# pipを更新
python -m pip install --upgrade pip

# キャッシュをクリア
pip cache purge
```

### 2. 権限エラー

```bash
# ユーザー領域にインストール
pip install --user パッケージ名
```

### 3. バージョン競合

仮想環境を使うことで解決できます。

## まとめ

- `pip`でパッケージをインストール・管理する
- `requirements.txt`でパッケージのリストを管理する
- 仮想環境でプロジェクトごとにパッケージを管理する
- PyPIでパッケージを探す
- よく使うパッケージを覚える

パッケージ管理は、プログラミングの基礎スキルです。しっかりと身につけましょう！
