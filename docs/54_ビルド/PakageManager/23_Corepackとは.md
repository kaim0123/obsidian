## Corepackとは

### 概要

- **Corepack** は、**Node.js に同梱されている「パッケージマネージャー管理ツール」**です。
- `npm` だけでなく、**`yarn` や `pnpm` のバージョンも、プロジェクトごとに固定して実行するための仕組み**を提供します。
- Node.js 16.9 以降で同梱されています（バージョンによって有効 / 無効の違いがありますが、ここでは概念レベルに絞って解説します）。

### 何をしてくれるツールか

- `package.json` に書かれた
  - どのパッケージマネージャー（npm / yarn / pnpm）
  - どのバージョン
を読み取り、そのバージョンを自動的にダウンロードして実行してくれます。

#### イメージ

- `package.json` に「このプロジェクトは pnpm 9 を使う」と書いておく
- 開発者は `pnpm install` などと打つだけ
- Corepack が裏側で「pnpm 9.x を取得して実行」してくれる

これにより、**チーム全員が同じパッケージマネージャーのバージョンを使える**ようになります。

### 基本的な使い方の流れ

#### 1. Corepack を有効化する（必要な場合）

Node のバージョンによっては、明示的に有効化が必要です。

```bash
corepack enable
```

- これにより、`yarn` や `pnpm` コマンドが Corepack 経由で動くようになります。

#### 2. `package.json` にパッケージマネージャーのバージョンを記述

例：pnpm を使う場合

```json
{
  "packageManager": "pnpm@9.0.0"
}
```

例：yarn を使う場合

```json
{
  "packageManager": "yarn@4.1.0"
}
```

#### 3. いつも通りのコマンドを打つ

```bash
pnpm install
pnpm run dev
```

- Corepack が `packageManager` の指定を見て、対応するバージョンの pnpm をダウンロード & 実行します。
- 開発者側は「バージョンを気にせず、同じコマンドを叩くだけ」でよくなります。

### よく使うコマンド例

```bash
# Corepack を有効化
corepack enable

# 特定バージョンの pnpm を準備
corepack prepare pnpm@9.0.0 --activate

# 準備されたバージョンで実行
pnpm install
```

※ 実務では、`package.json` の `packageManager` フィールドと組み合わせて使うことが多いです。

### Corepack と他ツールの関係

- **Volta**
  - Node / npm / yarn / pnpm を**ユーザー単位・プロジェクト単位で管理**するツール
  - Node 本体とは別にインストールする必要がある
- **Corepack**
  - Node に同梱される「パッケージマネージャーランチャー」
  - `package.json` の `packageManager` を見て、「どのパッケージマネージャーをどのバージョンで動かすか」を決める

どちらも「バージョンをそろえる」という目的は同じですが、

- Volta：Node / npm / pnpm / yarn など**開発者環境全体のバージョン管理**
- Corepack：主に **パッケージマネージャーのバージョン固定** をシンプルに行う

という役割の違いがあります。

### どんなときにCorepackが便利か

- Node は素のインストーラーなどで入れていて、**追加ツールを増やしたくない**
- プロジェクトごとに
  - npm / yarn / pnpm のバージョンを固定したい
  - でも npx やグローバル CLI はあまり意識したくない
- チームで「このプロジェクトは pnpm 9 で統一しよう」と決めたい

といった場合に、Corepack を有効化して `packageManager` を書いておくと、**環境差によるトラブルが減ります**。

### まとめ

- **Corepack は Node に同梱された「パッケージマネージャーのバージョン固定ツール」**。
- `package.json` の `packageManager` に
  - どのパッケージマネージャー（npm / yarn / pnpm）
  - どのバージョン
を書くことで、チーム全員の環境で同じバージョンを使わせることができる。
- Volta など他のバージョン管理ツールと組み合わせて使うことも可能だが、まずは
  - 「Node はどう入れるか」
  - 「パッケージマネージャーのバージョンは Corepack で固定するか」
という役割分担を意識しておくと理解しやすいです。
