# 依存関係エラー基礎 - 初心者向け解説

## 依存関係エラーとは？

**依存関係エラー**とは、プロジェクトが使用しているライブラリやパッケージの依存関係（他のパッケージとの関係）に問題があるために発生するエラーです。パッケージが見つからない、バージョンが競合している、循環参照があるなど、様々な原因で発生します。

### 身近な例で理解する

日常生活で例えると：
- **正しい操作**：レシピに必要な材料を全て揃える（材料Aには材料Bが必要、材料Bには材料Cが必要）
- **依存関係エラー**：材料Bが不足している、または材料Aと材料Bのバージョンが合わない

プログラミングでも同じように、パッケージAがパッケージBに依存していて、パッケージBが見つからない、またはバージョンが合わない場合にエラーになります。

## 依存関係エラーの特徴

1. **実行前に検出される**：パッケージをインストールする際にエラーが分かる
2. **環境依存**：インストールされているパッケージによって発生するかどうかが変わる
3. **複雑な問題**：複数のパッケージが絡み合っている場合、原因を特定するのが難しい

## よくある依存関係エラーの種類

### 1. パッケージが見つからない

依存しているパッケージがインストールされていないエラーです。

#### 具体例

```python
# エラー例1: パッケージがインストールされていない
import numpy  # ModuleNotFoundError: No module named 'numpy'

# エラー例2: 依存パッケージがインストールされていない
# package_aがpackage_bに依存しているが、package_bがインストールされていない
import package_a  # ModuleNotFoundError: No module named 'package_b'

# 正しい例1: パッケージをインストール
# pip install numpy

# 正しい例2: requirements.txtを使う
# requirements.txt
# numpy==1.21.0
# pandas==1.3.0
# requests==2.26.0

# pip install -r requirements.txt

# 正しい例3: setup.pyで依存関係を定義
# setup.py
from setuptools import setup, find_packages

setup(
    name="my_package",
    version="1.0.0",
    install_requires=[
        "numpy>=1.20.0",
        "pandas>=1.3.0",
        "requests>=2.26.0",
    ],
)

# pip install .
```

#### 解決方法

- **パッケージをインストール**：`pip install パッケージ名`
- **requirements.txtを使う**：依存関係をファイルで管理
- **setup.pyで依存関係を定義**：パッケージの依存関係を明示

---

### 2. バージョンの競合

複数のパッケージが異なるバージョンの同じパッケージを要求しているエラーです。

#### 具体例

```python
# エラー例1: バージョンの競合
# package_aはnumpy>=1.20.0を要求
# package_bはnumpy<1.20.0を要求
# → 両方を満たすバージョンが存在しない

# エラー例2: インストール時の競合
# pip install package_a package_b
# ERROR: Cannot install package_a and package_b because these package versions have conflicting dependencies.

# 正しい例1: 互換性のあるバージョンを使う
# requirements.txt
# package_a==1.0.0
# package_b==2.0.0
# numpy==1.19.5  # 両方と互換性のあるバージョン

# 正しい例2: バージョン範囲を指定
# setup.py
setup(
    name="my_package",
    install_requires=[
        "numpy>=1.19.0,<2.0.0",  # 1.19.0以上2.0.0未満
        "pandas>=1.3.0,<2.0.0",
    ],
)

# 正しい例3: 依存関係ツリーを確認
# pip install pipdeptree
# pipdeptree  # 依存関係ツリーを表示
```

#### 解決方法

- **互換性のあるバージョンを使う**：全てのパッケージと互換性のあるバージョンを選ぶ
- **バージョン範囲を指定**：`>=1.19.0,<2.0.0` のように範囲を指定
- **依存関係ツリーを確認**：`pipdeptree` で依存関係を可視化

---

### 3. 依存関係の循環参照

パッケージAがパッケージBに依存し、パッケージBがパッケージAに依存しているエラーです。

#### 具体例

```python
# エラー例: 循環参照
# package_a/setup.py
setup(
    name="package_a",
    install_requires=["package_b"],
)

# package_b/setup.py
setup(
    name="package_b",
    install_requires=["package_a"],
)

# → 循環参照が発生する

# 正しい例1: 循環参照を解消
# package_a/setup.py
setup(
    name="package_a",
    install_requires=["package_b"],
)

# package_b/setup.py
setup(
    name="package_b",
    # package_aへの依存を削除
    install_requires=[],
)

# 正しい例2: 共通パッケージを作る
# common_package/setup.py
setup(
    name="common_package",
    install_requires=[],
)

# package_a/setup.py
setup(
    name="package_a",
    install_requires=["common_package", "package_b"],
)

# package_b/setup.py
setup(
    name="package_b",
    install_requires=["common_package"],
)
```

#### 解決方法

- **循環参照を解消**：一方の依存関係を削除
- **共通パッケージを作る**：共通の機能を別パッケージに分離
- **依存関係を再設計**：パッケージの構造を見直す

---

### 4. 互換性の問題

パッケージのバージョンが、使用しているPythonのバージョンや他のパッケージと互換性がないエラーです。

#### 具体例

```python
# エラー例1: Pythonのバージョンが合わない
# package_aはPython 3.8以上を要求
# Python 3.7で実行 → エラー

# エラー例2: パッケージのバージョンが古すぎる
# package_aはnumpy>=1.20.0を要求
# numpy 1.19.0がインストールされている → エラー

# 正しい例1: Pythonのバージョンを確認
import sys

if sys.version_info < (3, 8):
    raise RuntimeError("Python 3.8以上が必要です")

# 正しい例2: パッケージのバージョンを確認
import numpy

if numpy.__version__ < "1.20.0":
    raise RuntimeError("numpy 1.20.0以上が必要です")

# 正しい例3: setup.pyでPythonのバージョンを指定
setup(
    name="my_package",
    python_requires=">=3.8",  # Python 3.8以上が必要
    install_requires=[
        "numpy>=1.20.0",
    ],
)
```

#### 解決方法

- **Pythonのバージョンを確認**：`python --version` で確認
- **パッケージのバージョンを確認**：`pip show パッケージ名` で確認
- **setup.pyでバージョンを指定**：`python_requires` でPythonのバージョンを指定

---

### 5. ロックファイルの不整合

ロックファイル（依存関係の正確なバージョンを記録したファイル）が、実際の環境と一致していないエラーです。

#### 具体例

```bash
# エラー例1: ロックファイルが古い
# Pipfile.lockが古く、新しいパッケージがインストールされている
pipenv install  # Lockfileが古いという警告

# エラー例2: ロックファイルが破損している
# requirements.txtと実際の環境が一致しない
pip install -r requirements.txt  # 競合が発生

# 正しい例1: ロックファイルを再生成
# pipenv
pipenv lock  # ロックファイルを再生成
pipenv install  # ロックファイルに基づいてインストール

# 正しい例2: requirements.txtを更新
pip freeze > requirements.txt  # 現在の環境をrequirements.txtに出力

# 正しい例3: Poetryを使う
poetry lock  # ロックファイルを再生成
poetry install  # ロックファイルに基づいてインストール
```

#### 解決方法

- **ロックファイルを再生成**：`pipenv lock`、`poetry lock` など
- **requirements.txtを更新**：`pip freeze > requirements.txt`
- **バージョン管理**：ロックファイルをGitで管理

---

### 6. オプショナル依存関係の問題

オプショナル（任意）の依存関係が正しくインストールされていないエラーです。

#### 具体例

```python
# エラー例: オプショナル依存関係がインストールされていない
# package_aはpackage_bをオプショナル依存として定義
# しかし、package_bの機能を使おうとするとエラー

# 正しい例1: オプショナル依存関係をインストール
# setup.py
setup(
    name="my_package",
    install_requires=[
        "numpy",
    ],
    extras_require={
        "dev": ["pytest", "black"],  # 開発用の依存関係
        "plot": ["matplotlib"],  # プロット機能用の依存関係
    },
)

# pip install my_package[dev,plot]  # オプショナル依存関係もインストール

# 正しい例2: オプショナル依存関係の存在を確認
try:
    import matplotlib
    HAS_MATPLOTLIB = True
except ImportError:
    HAS_MATPLOTLIB = False

if HAS_MATPLOTLIB:
    import matplotlib.pyplot as plt
    # プロット機能を使う
else:
    print("matplotlibがインストールされていません。プロット機能は使用できません。")
```

#### 解決方法

- **オプショナル依存関係をインストール**：`pip install package[extra]`
- **存在を確認**：オプショナル依存関係の存在を確認してから使う
- **extras_requireを使う**：setup.pyでオプショナル依存関係を定義

## 依存関係エラーを防ぐ方法

### 1. requirements.txtを使う

```txt
# requirements.txt
numpy==1.21.0
pandas==1.3.0
requests==2.26.0
```

```bash
pip install -r requirements.txt
```

### 2. 仮想環境を使う

```bash
# 仮想環境を作成
python -m venv venv

# 仮想環境を有効にする
# Windows
venv\Scripts\activate
# Linux/Mac
source venv/bin/activate

# パッケージをインストール
pip install -r requirements.txt
```

### 3. 依存関係ツリーを確認する

```bash
# pipdeptreeをインストール
pip install pipdeptree

# 依存関係ツリーを表示
pipdeptree

# 特定のパッケージの依存関係を表示
pipdeptree -p numpy
```

### 4. ロックファイルを使う

```bash
# Pipenvを使う
pipenv install
pipenv lock  # ロックファイルを生成

# Poetryを使う
poetry install
poetry lock  # ロックファイルを生成
```

### 5. バージョンを固定する

```txt
# requirements.txt
numpy==1.21.0  # バージョンを固定
pandas==1.3.0
requests==2.26.0
```

## よくある依存関係エラーのチェックリスト

- [ ] パッケージがインストールされているか
- [ ] バージョンが競合していないか
- [ ] 循環参照がないか
- [ ] Pythonのバージョンが合っているか
- [ ] ロックファイルが最新か
- [ ] オプショナル依存関係がインストールされているか
- [ ] 依存関係ツリーを確認したか
- [ ] 仮想環境を使っているか

## まとめ

- **依存関係エラー**は、パッケージの依存関係に問題があるために発生する
- **パッケージが見つからない**場合、`pip install` でインストール
- **バージョンの競合**を解決するために、互換性のあるバージョンを使う
- **循環参照**を解消するために、依存関係を再設計
- **requirements.txt**や**ロックファイル**を使って、依存関係を管理
- **仮想環境**を使って、プロジェクトごとに環境を分離
- **依存関係ツリー**を確認して、問題を特定
