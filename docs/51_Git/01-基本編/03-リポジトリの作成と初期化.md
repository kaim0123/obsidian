# リポジトリの作成と初期化

## 概要

Gitでプロジェクトを管理するには、まず**リポジトリ**（Repository）を作成する必要があります。リポジトリは、プロジェクトの全履歴を保存する場所です。

## リポジトリとは

リポジトリは、プロジェクトのファイルとその変更履歴を保存するデータベースのようなものです。`.git`ディレクトリに、すべての履歴情報が保存されます。

### リポジトリの種類

1. **ローカルリポジトリ**: 開発者のマシン上にあるリポジトリ
2. **リモートリポジトリ**: GitHub、GitLabなどのサーバー上にあるリポジトリ

## 新しいリポジトリの作成

### 方法1: 既存のディレクトリをGitリポジトリにする

既存のプロジェクトディレクトリをGitで管理する場合：

```bash
# プロジェクトディレクトリに移動
cd /path/to/your/project

# Gitリポジトリとして初期化
git init
```

これにより、現在のディレクトリに`.git`ディレクトリが作成され、Gitの管理下に置かれます。

### 方法2: 新しいディレクトリを作成して初期化

```bash
# 新しいディレクトリを作成
mkdir my-project
cd my-project

# Gitリポジトリとして初期化
git init
```

### 方法3: リモートリポジトリからクローン

既存のリモートリポジトリ（GitHubなど）からクローンする場合：

```bash
# HTTPSを使用
git clone https://github.com/username/repository.git

# SSHを使用
git clone git@github.com:username/repository.git

# 特定のディレクトリ名でクローン
git clone https://github.com/username/repository.git my-project
```

## git init の詳細

### 基本的な使い方

```bash
git init
```

### オプション

#### リポジトリ名を指定

```bash
git init my-project
```

これにより、`my-project`というディレクトリが作成され、その中でGitリポジトリが初期化されます。

#### ベアリポジトリの作成

共有サーバー用のリポジトリを作成する場合：

```bash
git init --bare my-project.git
```

ベアリポジトリには作業ディレクトリがなく、履歴のみを保存します。

## .git ディレクトリの構造

`git init`を実行すると、`.git`ディレクトリが作成されます。この中には以下のような重要な情報が保存されます：

```
.git/
├── HEAD              # 現在のブランチへの参照
├── config            # リポジトリ固有の設定
├── description       # リポジトリの説明
├── hooks/            # Gitフックスクリプト
├── info/             # 除外パターンなど
├── objects/          # すべてのオブジェクト（コミット、ツリー、ブロブ）
├── refs/             # ブランチとタグへの参照
│   ├── heads/        # ブランチへの参照
│   └── tags/         # タグへの参照
└── index             # ステージングエリア
```

**注意**: `.git`ディレクトリは通常、直接編集すべきではありません。

## リポジトリの状態確認

### リポジトリが初期化されているか確認

```bash
# .gitディレクトリの存在確認
ls -la .git

# または
git status
```

### リポジトリの設定確認

```bash
# リポジトリ固有の設定を確認
git config --local --list
```

## リポジトリの削除

Gitの管理をやめる場合（`.git`ディレクトリを削除）：

```bash
# 注意: これによりすべての履歴が削除されます
rm -rf .git
```

Windowsの場合：
```powershell
Remove-Item -Recurse -Force .git
```

## 実践例

### 例1: 新しいWebプロジェクトの開始

```bash
# プロジェクトディレクトリを作成
mkdir my-website
cd my-website

# Gitリポジトリを初期化
git init

# 初期ファイルを作成
echo "# My Website" > README.md
echo "node_modules/" > .gitignore

# ファイルを追加
git add README.md .gitignore

# 初回コミット
git commit -m "Initial commit"
```

### 例2: 既存プロジェクトにGitを追加

```bash
# 既存のプロジェクトディレクトリに移動
cd existing-project

# Gitリポジトリを初期化
git init

# .gitignoreファイルを作成（必要に応じて）
echo "node_modules/" > .gitignore
echo ".env" >> .gitignore

# すべてのファイルを追加
git add .

# 初回コミット
git commit -m "Add existing project files"
```

## .gitignore ファイル

リポジトリに含めたくないファイルを指定するには、`.gitignore`ファイルを作成します。

### 基本的な.gitignoreの例

```gitignore
# 依存関係
node_modules/
vendor/

# 環境変数ファイル
.env
.env.local

# ビルド成果物
dist/
build/
*.o
*.exe

# エディタ設定
.vscode/
.idea/
*.swp
*.swo

# OS固有のファイル
.DS_Store
Thumbs.db
```

### .gitignoreのパターン

- `*.log`: すべての.logファイル
- `node_modules/`: node_modulesディレクトリ全体
- `!important.log`: 例外（important.logは除外しない）
- `temp?`: tempで始まる4文字のファイル
- `[abc]`: a、b、cのいずれか1文字

## リモートリポジトリの追加

ローカルリポジトリをリモートリポジトリ（GitHubなど）と連携させる：

```bash
# リモートリポジトリを追加
git remote add origin https://github.com/username/repository.git

# リモートリポジトリの確認
git remote -v
```

## トラブルシューティング

### エラー: "not a git repository"

現在のディレクトリがGitリポジトリではない場合：

```bash
# リポジトリを初期化
git init
```

### エラー: "repository already exists"

既にリポジトリが存在する場合、`.git`ディレクトリを削除してから再初期化：

```bash
rm -rf .git
git init
```
