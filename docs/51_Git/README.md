## 🎯 学習の進め方

### 初心者の方

1. **基本編を順番に読む**: 01-基本編のドキュメントを順番に読み進めてください
2. **実際に試す**: 各章の内容を実際にコマンドを実行して試してください

## 📝 コマンドの表記

このガイドでは、コマンドを以下のように表記しています：

```bash
git command [options] [arguments]
```

- `command`: 必須のコマンド名
- `[options]`: オプション（省略可能）
- `[arguments]`: 引数（省略可能）

実際にコマンドを実行する際は、`[]`を除いて入力してください。

## ⚠️ 注意事項

- **強制プッシュ**: `--force`オプションは共有ブランチでは使用しないでください
- **履歴の書き換え**: 既にプッシュしたコミットの履歴を書き換える際は、チームと相談してください
- **バックアップ**: 重要な変更を行う前に、バックアップを取ることをお勧めします
