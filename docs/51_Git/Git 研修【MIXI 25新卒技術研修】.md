**テーマ：新卒向け Git 研修（基礎・内部構造・GitHub でのチーム開発）**

MIXI の 2025 年度新卒技術研修「Git 研修」の収録動画（約 1 時間 40 分）。Git の基本操作とブランチ、履歴の改変といった基礎編、Git オブジェクトやコミット・reset の仕組みを扱う内部構造編、GitHub を使ったチーム開発のノウハウ編の 3 部構成。資料は「Basic」と「チーム開発と Git / GitHub」の 2 本が SpeakerDeck で公開されている。

---

### 基礎編（0:02:22〜）

1. Git とは
2. Git の基本的な使い方
3. **ブランチ**の使用
4. **歴史の改変**
5. その他便利機能

### 内部構造編（0:40:32〜）

1. **Git オブジェクト**
2. **コミットの仕組み**
3. **reset の仕組み**

### チーム開発と Git / GitHub（1:16:42〜）

- GitHub の機能について
- GitHub を用いたチーム開発のノウハウ

### まとめ

- 操作の習得だけでなく、オブジェクト・コミット・reset といった内部構造まで踏み込む構成
- 最後に GitHub を使ったチーム開発の実践知を扱う
- 資料・動画は勉強会等で自由に使えるが、有料の場での利用や出典の削除・改変は不可
