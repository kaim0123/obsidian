# サプライチェーン攻撃と委託先管理

## はじめに

**サプライチェーン攻撃**とは、狙った組織を直接攻めるのではなく、**取引先・委託先・利用している SaaS やソフトウェア** を足がかりに侵入する攻撃です。IPA「情報セキュリティ10大脅威 2026」組織編では 2 位でした。

### 一言でいうと

> 「**自社が堅くても、つながっている先が弱ければ漏れる**」。しかも 1 か所破られると、つながっている多数の組織に一斉に波及する。

---

## 3つの類型

| 類型 | 内容 | 2026年の例 |
|---|---|---|
| **委託先・取引先経由** | 委託先の PC やネットワークに侵入し、預けたデータや接続経路を悪用する | 第一興商（委託先 PC のマルウェア感染、約872万件のおそれ）、両毛システムズ（伊勢崎市などへ波及） |
| **SaaS・共通基盤経由** | 複数の企業が使う SaaS やクラウド基盤が侵害され、利用企業すべてに被害が出る | i-ask 提供元（大和証券・損保ジャパン・シチズン等）、KDDI のメール基盤（ISP 6社が共有）、ショップサーブ（利用店舗に波及）、IDCF クラウド（495組織） |
| **ソフトウェア経由** | ライブラリや製品のアップデートに悪意あるコードが混ざる、または製品の脆弱性が突かれる | KDDI（第三者製ソフトのゼロデイ）。npm パッケージ乗っ取りなどもこの類型（[[A08_ソフトウェアとデータの整合性の不備]]） |

---

## なぜ防ぎにくいのか

- **見えない**：委託先の中のセキュリティ状況は、外から確かめにくい
- **信頼された経路**：委託先の VPN や API キーは正規の接続なので、攻撃に使われても目立たない
- **通知が遅れる**：委託先が被害に気づいても、委託元への連絡に時間がかかる（両毛システムズでは 43日）
- **規模の差**：委託先の多くは中小企業で、セキュリティにかけられる予算や人員が限られる（ランサムウェア被害の約 6 割は中小企業）

---

## 対策

### 1. 契約で決めておく

| 項目 | 例 |
|---|---|
| インシデントの通知期限 | 「発覚から 24 時間以内に第一報」 |
| 最低限の技術要件 | MFA 必須、パッチ適用 SLA、EDR 導入、ログを一定期間保管 |
| 再委託の制限 | 再委託するときは事前に承認を取る |
| 監査・報告 | 年 1 回のチェックシート、必要に応じて立ち入り監査 |
| 契約終了時のデータ | 削除と、削除したことの証明 |

### 2. 渡すデータと権限を減らす

- 委託先に渡すデータは **業務に必要な項目だけ** にする（[[05_データ最小化]]）。テストには本番データを使わず、マスキングしたものを渡す
- 委託先からの接続は **期間・範囲を限った一時的な権限** にする（[[01_最小権限の原則]]）。保守用 VPN を常時つなぎっぱなしにしない
- API 連携は **スコープを絞った短命トークン** を使い、長期間有効な共有キーを避ける

### 3. SaaS の選定と運用

- SSO・MFA・監査ログの出力・IP 制限ができるかを選定の条件にする
- ISMAP や SOC 2 などの第三者認証を確かめる
- SaaS 側が侵害されたときに **自社のどのデータが影響を受けるか** を一覧にしておく

### 4. 経産省「SCS 評価制度」

経済産業省の **サプライチェーン強化に向けたセキュリティ対策評価制度** は、取引先のセキュリティ対策を ★ で表す任意の制度です。

| レベル | 想定する攻撃 | 評価の方法 |
|---|---|---|
| ★3 | 脆弱性を悪用する一般的な攻撃 | 専門家の確認付き自己評価 |
| ★4 | 供給停止や情報漏洩など、大きな影響を与える攻撃 | 第三者評価 |

申請受付は令和8年度末（2027年1〜3月）ごろの予定です（経産省 FAQ、2026年3月時点）。取引先を評価する物差しとして使えます。

### 5. ソフトウェアサプライチェーン

- **SBOM** で使っているコンポーネントを把握する（[[A06_脆弱で古いコンポーネント]]）
- 依存パッケージのバージョンを固定し、署名や来歴（SLSA）を確かめる

## まとめ

- 2026年は **SaaS・共通基盤** から多数の組織に波及する被害が目立った
- 対策の柱は **契約（通知期限・技術要件）**、**渡すデータと権限の最小化**、**接続経路の管理**
- 経産省の SCS 評価制度（★3/★4）が、取引先を評価する共通の物差しになる見込み
