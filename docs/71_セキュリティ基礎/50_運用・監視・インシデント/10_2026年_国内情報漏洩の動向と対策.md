# 2026年 国内情報漏洩の動向と対策（技術者向けまとめ）

2026年に国内で相次いだ情報漏洩・ランサムウェア被害について、**公表・報道された「システム的な原因」** を整理し、技術者が取るべき対策を関連ノートにつなげるハブノート。

> [!warning] 出典について
> 多くは報道・セキュリティメディア・Qiita などの **二次情報**（2026-10-17 時点）。侵入経路が未公表の事例も多い。数値を引用するときは各社の公式発表・警察庁・IPA の原資料で確認すること。

---

| ランサムウェアの侵入経路 | 有効回答36件中 **VPN機器 18件・リモートデスクトップ 9件**（合わせて約75%）。メール添付は減少 | 同上 |

## 2. 主な事例と報告された原因（2026年夏〜秋）

| 事例 | 規模（報道ベース） | 報告されているシステム的原因 |
|---|---|---|
| KDDI ISP向けメール基盤（@nifty 等6社が共有） | メールアドレス 1,223万件、うちパスワード 762万件 | 第三者製ソフトの **ゼロデイ脆弱性**。5/16 から被害、6/17 把握。解約済みユーザーのデータも残存 |
| アフラック生命 | 約440万人（口座情報 約22万人） | 通常の利用と **同じ形式のアクセス**。**短時間の大量照会を監視・制御する機能が不足**。CPU高負荷で発覚（侵入から15日後） |
| タイムズカー | 約660万アカウント（うち約160万件は免許証等の画像） | 経路は未公表。パスワードは復元不能形式で保存。**変更できない本人確認書類** を保持していた |
| ショップサーブ（Eストアー） | 約885万件 | サーバー上で不正プログラムが実行され購入者情報が外部送信。**発覚まで約72日**。利用店舗へ波及 |
| i-ask 提供元（大和証券・損保ジャパン・シチズン等） | 各社 数万〜20万件 | 問い合わせ管理 **SaaS 提供元** への不正アクセス |
| IDCフロンティア | 495の企業・自治体に影響 | **クラウド基盤そのもの** へのランサムウェア攻撃 |
| 第一興商 | 約872万件（おそれ） | **委託先PCのマルウェア感染** |
| デジタル庁 GSS | 約24.6万件 | VPN の脆弱性が入口。保守担当者アカウントで大量ファイルアクセス |
| 両毛システムズ | 伊勢崎市などに波及 | VPN アカウント悪用からランサムウェアへ。委託元への通知まで43日 |

ほかに skyticket（約1,464万件）、焼肉きんぐ（約1,078万件）、ブックオフ（最大643万件）、EPARK（3,300万レコード）など、会員システムへの不正アクセスが相次いだ。

### 発覚までの期間

被害の大きさは「入られたこと」より **侵入後の動きが続いた時間** と **届いたデータ量** に比例していた。

| 事例 | 侵入〜発覚 |
|---|---|
| アフラック生命 | 15日 |
| ショップサーブ | 約72日 |
| 両毛システムズ（委託元への通知） | 43日 |
| 米国防総省 DMDC（海外） | 約9か月 |

## 4. 対策マップ（優先度順）

| 優先 | 対策 | 詳しくは |
|---|---|---|
| A. 入口を減らす | VPN/FW/ファイル転送製品のパッチ SLA（KEV 掲載は 48〜72h）、EOL の洗い出し、VPN に MFA、RDP 非公開、ASM | [[07_脆弱性管理（境界機器・パッチ運用）]] |
| B. 被害半径を小さくする | 最小権限・セグメント分離・本人確認書類の分離・項目暗号化・保持期間を過ぎたら物理削除 | [[01_最小権限の原則]] / [[05_データ最小化]] |
| C. 正規に見える攻撃を検知 | 1セッションあたりの取得件数・エクスポート量の監視と自動遮断、外向き通信監視、MTTD を KPI に | [[A09_ログとモニタリングの不備]] |
| D. サプライチェーン | 委託先の通知期限・MFA・パッチ SLA を契約に、渡すデータの最小化、SCS 評価制度（★3/★4） | [[09_サプライチェーン攻撃と委託先管理]] |
| E. AI・エージェント | ツールの許可リスト、実行ロールの最小権限、外部入力は信頼しない、外向き通信の制限 | [[08_プロンプトインジェクション]] |
| F. ランサムウェア | イミュータブルで別アカウントのバックアップ、復元テスト、AD 防御、EDR、IR 訓練 | [[08_ランサムウェア対策]] / [[04_DR訓練とRTO・RPO]] |
| G. 事後対応 | 証拠保全、個人情報保護委員会への報告（速報・確報）、段階的な公表 | [[01_インシデント対応の基本フロー]] |

> [!summary] 一言でいうと
> 2026年の教訓は「高度な攻撃への備え」より **既知の穴の放置・データの持ちすぎ・大量取得の見逃し・委託先からの波及** の4点。**侵入をゼロにする設計から、侵入されても届く範囲を小さくし、早く気づく設計へ。**
