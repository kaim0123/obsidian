# SOLID

Robert C. Martin がまとめた、オブジェクト指向設計の 5 つの原則（2000 年ごろ。頭文字の「SOLID」は Michael Feathers が 2004 年ごろに名付けた）。クラスやモジュールを **変更しやすく、理解しやすく** するための指針。

| 原則 | 一言でいうと | ノート |
|---|---|---|
| **S** — 単一責任の原則 | 変更される理由は 1 つだけ | [[01_SRP（単一責任の原則）]] |
| **O** — 開放閉鎖の原則 | 拡張には開き、修正には閉じる | [[02_OCP (開放閉鎖の原則)]] |
| **L** — リスコフの置換原則 | サブクラスは親クラスと置き換えられる | [[03_LSP (リスコフの置換原則)]] |
| **I** — インターフェース分離の原則 | 使わないメソッドに依存させない | [[04_ISP (インターフェース分離の原則)]] |
| **D** — 依存性逆転の原則 | 上位も下位も抽象に依存する | [[05_DIP (依存性逆転の原則)]] |
