# Elements（要素の検査）

## Elementsパネルとは
HTMLとCSSをリアルタイムで確認・編集できるパネルです。ページのレイアウトやスタイルをその場で変更して試すことができます。

## 基本操作

### 要素の選択

#### 方法1: 検査ツール
1. DevToolsの左上にある矢印アイコン（選択ツール）をクリック
2. ページ上の確認したい要素をクリック

#### 方法2: 右クリック
1. ページ上で右クリック
2. 「検証」を選択

#### 方法3: DOMツリーから探す
- Elementsパネル内のHTMLツリーを展開して探す

## HTMLの確認と編集

### HTMLを編集する
1. 要素を右クリック > "Edit as HTML"
2. HTMLを直接編集
3. クリック外で確定

### 属性を編集する
- 属性をダブルクリックして編集
- 新しい属性を追加可能

### 要素を削除する
- 要素を選択して `Delete` キー
- または右クリック > "Delete element"

## CSSスタイルの確認

### Stylesパネル
選択した要素に適用されているCSSが表示されます。

```
element.style         ← インラインスタイル
.class-name          ← クラスセレクタ
#id-name             ← IDセレクタ
div                  ← 要素セレクタ
user agent stylesheet ← ブラウザのデフォルトCSS
```

### スタイルの優先順位
上から優先度が高い順に表示されます。
- 取り消し線：上書きされているスタイル
- 太字：現在適用されているスタイル

## CSSの編集

### スタイルの変更
1. プロパティの値をクリック
2. 新しい値を入力
3. リアルタイムで反映される

### 新しいスタイルを追加
1. `element.style` の中をクリック
2. プロパティと値を入力

```css
color: red;
font-size: 20px;
```

### スタイルの有効/無効
- チェックボックスでオン/オフを切り替え

## Computedパネル

要素に最終的に適用されているスタイルを確認できます。

- すべての計算済みスタイルを表示
- マージンやパディングの値
- 継承されたスタイル

## Box Model（ボックスモデル）

要素のサイズと余白を視覚的に表示します。

```
┌─────────────────┐
│     Margin      │  外側の余白
│  ┌───────────┐  │
│  │  Border   │  │  境界線
│  │ ┌───────┐ │  │
│  │ │Padding│ │  │  内側の余白
│  │ │ ┌───┐ │ │  │
│  │ │ │   │ │ │  │  Content（内容）
│  │ │ └───┘ │ │  │
│  │ └───────┘ │  │
│  └───────────┘  │
└─────────────────┘
```

### 値の編集
- ボックスモデルの値をクリックして編集可能

## 便利な機能

### カラーピッカー
- 色の値をクリックするとカラーピッカーが表示
- スポイトツールでページから色を取得

### クラスの追加/削除
- `.cls` ボタンをクリック
- クラス名を入力して追加
- チェックボックスで有効/無効を切り替え

### 疑似クラスの適用
- `:hov` ボタンをクリック
- `:hover`, `:active`, `:focus` などを強制的に適用

### レスポンシブデザインの確認
1. DevToolsのデバイスツールバーをオン
2. 画面サイズを変更
3. CSSの変化を確認

## 実践例

### 1. 文字色を変更
```css
/* Stylesパネルで */
color: #ff0000;
```

### 2. ボタンのサイズ変更
```css
padding: 20px 40px;
font-size: 18px;
```

### 3. レイアウトの調整
```css
display: flex;
justify-content: center;
align-items: center;
```

## デバッグのコツ

1. **想定と違うスタイルが適用されている時**
   - Stylesパネルで優先順位を確認
   - 取り消し線のスタイルをチェック

2. **要素が表示されない時**
   - `display: none` になっていないか
   - `opacity: 0` や `visibility: hidden` を確認

3. **レイアウトが崩れる時**
   - Box Modelで余白を確認
   - 親要素のスタイルを確認

## 注意事項

- **変更は一時的**: ページをリロードすると元に戻ります
- **本番環境には影響なし**: あくまでブラウザ上での表示のみ
- **実際のコードを変更する**: 確認後、エディタで実装が必要
