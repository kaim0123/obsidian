## 判断基準
- 依存関係: OS/ドライバ/ミドルウェアが必要か
- セキュリティ: 資格情報の扱い/閉域要件/鍵管理
- コストと運用: 常時サーバ/スケール/保守
- 開発速度: 立ち上げの速さ/デバッグ性

## 選択肢と使い分け
- ローカル + サーバーレス（推奨デフォルト）
  - AWS SAM/CDK + Lambda + API Gateway/DynamoDB
- ローカル + コンテナ
  - Docker Compose → 本番は ECS/Fargate へ
- EC2 リモート開発（Cursor/VS Code over SSH/SSM）
  - OS依存/既存資産/一時検証に適
- Cloud9（フルマネージドIDE）
  - 権限/接続/チーム共有が楽

## 接続の優先度
1. SSM Session Manager（鍵不要・監査容易）
2. Systems Manager Port Forwarding（RDP/DBへ踏み台不要）
3. 直接SSH（キーペア/セキュリティグループ管理が必要）
