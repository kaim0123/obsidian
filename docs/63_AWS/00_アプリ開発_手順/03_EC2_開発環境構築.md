## 事前方針
- 可能ならパブリックIP/22番は開けない（SSM優先）
- AMI: Amazon Linux 2023 などの最新
- IAMロール: `AmazonSSMManagedInstanceCore` を付与

## 作成手順（要点）
1. VPC/サブネット（プライベート推奨）
2. EC2 起動（キーペアは不要: SSM接続前提）
3. セキュリティグループ（アウトバウンドのみでも可）
4. SSM エージェント有効（AL2023 はデフォルト）
5. 必要ミドルウェア（git, build-essential, docker 等）

```bash
sudo yum update -y
sudo yum install -y git
# 必要に応じて runtime を追加
```

## リモート開発（Cursor/VS Code）
- SSM経由のポートフォワード → SSH リモート拡張
- 直接SSHの最小要件: 固定グローバルIP制限 + 秘密鍵保護
