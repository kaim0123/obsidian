## ローカルツール
- DynamoDB Local: 単体テスト高速化
- LocalStack: 複数サービスの疑似化（段階導入）
- AWS SAM Accelerate/SST: 反映高速化

## 環境変数/秘密
- `.env` はローカルのみ（Git追跡外）
- 本番は Parameter Store/Secrets Manager

## Cursor でのデバッグ
1. ローカル起動（例: `sam local start-api --debug-port 5890`）
2. デバッガ設定を `localhost:5890` にアタッチ
3. ブレークポイントで変数/ログを確認

### 例: Python アタッチ設定（概念）
```
type: python-attach
host: localhost
port: 5890
```

### DynamoDB Local 起動例（Docker）
```bash
docker run -p 8000:8000 amazon/dynamodb-local
# SDK のエンドポイントを http://127.0.0.1:8000 に
```

## TIPS
- `AWS_PROFILE` と `AWS_REGION` を明示
- Docker リソース不足に注意（メモリ/CPU）
- 依存はロックファイル管理（npm/pip）

## トラブルシューティング
- アタッチできない: firewall/ポート、デバッガ設定のポート番号を確認
- LocalStack で差異: 本番前に最小の統合テストをAWS上でも実行
- Windows で改行/パス問題: スクリプトはWSLやPowerShell対応を意識
