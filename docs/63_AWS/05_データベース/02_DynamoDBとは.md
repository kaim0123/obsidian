# DynamoDB とは

## 概要

DynamoDB は、フルマネージドの NoSQL データベースサービスです。高速で予測可能なパフォーマンスを提供し、シームレスにスケールできる仮想 NoSQL データベースサービスとして、モダンなアプリケーションの構築を支援します。

## 主な機能

### 1. 仮想 NoSQL データベースサービス

- スキーマレスなデータベース
- 高速な読み書き性能
- 自動スケーリング
- フルマネージドサービス

### 2. 高可用性と耐久性

- 99.999999999%（11 個の 9）の耐久性
- マルチ AZ での自動レプリケーション
- 自動バックアップ
- ポイントインタイムリカバリ

## 主要コンポーネント

### 1. テーブル

- データを格納する基本単位
- プライマリキーで一意に識別
- 無制限のスケーリング

### 2. アイテム

- テーブル内の個々のデータ
- 属性（Attribute）の集合
- JSON 形式で表現

### 3. 属性

- アイテムの個々のデータ要素
- 名前と値のペア
- 複数のデータ型をサポート

## プライマリキー

### 1. パーティションキー

- 単一の属性で構成
- データの分散に使用
- 一意性を保証

### 2. 複合プライマリキー

- パーティションキー + ソートキー
- より柔軟なクエリが可能
- 範囲クエリのサポート

## インデックス

### 1. グローバルセカンダリインデックス（GSI）

- テーブル全体に適用
- 異なるパーティションキーでクエリ可能
- テーブルとは独立してスケーリング

#### GSI の特徴

- **柔軟性**: 任意の属性でインデックス作成
- **スケーリング**: テーブルとは独立
- **クエリ**: 効率的なデータアクセス
- **更新**: 最終的整合性

### 2. ローカルセカンダリインデックス（LSI）

- 同じパーティションキー内でのみ有効
- ソートキーの範囲クエリが可能
- テーブルと同じスケーリング

#### LSI の特徴

- **範囲クエリ**: ソートキーの範囲指定
- **強整合性**: 読み取り時の整合性保証
- **制限**: テーブル作成時のみ設定可能
- **パフォーマンス**: 高速な範囲クエリ

## グローバルテーブル

### 1. 機能

- 複数リージョンでの自動レプリケーション
- マルチマスター構成
- 低レイテンシーでの読み書き

### 2. 使用例

- グローバルアプリケーション
- 災害復旧
- データの地理的分散

## キャパシティーモード

### 1. プロビジョニングキャパシティーモード

- 事前にキャパシティーを設定
- 予測可能なパフォーマンス
- コストの予測が可能

#### 特徴

- **RCU**: 読み取りキャパシティーユニット
- **WCU**: 書き込みキャパシティーユニット
- **オートスケーリング**: 自動的なキャパシティー調整
- **予約キャパシティー**: 割引料金

### 2. オンデマンドキャパシティーモード

- 使用量に応じて自動スケーリング
- 事前のキャパシティー設定不要
- 予測困難なワークロードに適している

#### 特徴

- **自動スケーリング**: 需要に応じて自動調整
- **従量課金**: 実際の使用量に基づく料金
- **シンプル**: キャパシティー管理が不要
- **柔軟性**: 急激な負荷変動に対応

## まとめ

DynamoDB は、モダンなアプリケーションに最適化された NoSQL データベースサービスです。自動スケーリング、高可用性、セキュリティ機能により、開発者はアプリケーションロジックに集中できます。適切なデータモデリングとキャパシティー設定により、高性能でコスト効率の良いアプリケーションを構築できます。
