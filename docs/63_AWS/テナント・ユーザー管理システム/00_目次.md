# サーバーレス テナント・ユーザー管理システム - 目次

## 概要
このセクションでは、AWSのサーバーレスアーキテクチャを使用したマルチテナント型のユーザー管理システムの構築方法を学びます。

## システムの特徴
- 🏢 マルチテナント対応（組織ごとのデータ分離）
- 👥 テナント内ユーザー管理
- 🔐 認証・認可（Cognito）
- 📊 ロールベースアクセス制御（RBAC）
- 🚀 完全サーバーレス
- 💰 従量課金で低コスト

## システム構成図
```
クライアント（Webアプリ）
    ↓ HTTPS
CloudFront + S3（静的ホスティング）
    ↓
API Gateway（REST API）
    ↓ Cognito認証
Lambda関数群
    ├→ DynamoDB（テナント・ユーザーデータ）
    ├→ Cognito（認証管理）
    └→ SNS（通知）
```

## 主な機能

### テナント管理
- ✅ テナント作成・更新・削除
- ✅ テナント設定管理
- ✅ テナント情報取得

### ユーザー管理
- ✅ ユーザー登録・更新・削除
- ✅ ユーザー一覧取得
- ✅ ロール・権限管理
- ✅ ユーザー招待機能

### 認証・認可
- ✅ メールアドレス＋パスワード認証
- ✅ JWT トークンベース認証
- ✅ ロールベースアクセス制御
- ✅ テナント間データ分離
