# デプロイ手順

## デプロイの準備

### 1. 事前確認チェックリスト

```
□ AWS CLI がインストールされている
□ SAM CLI がインストールされている
□ AWS認証情報が設定されている
□ S3バケット（SAMデプロイ用）が作成されている
□ すべてのコードがテスト済み
□ 環境変数が設定されている
```

### 2. 必要な権限

デプロイユーザーに以下の権限が必要：

```
- CloudFormation: フルアクセス
- Lambda: フルアクセス
- API Gateway: フルアクセス
- DynamoDB: フルアクセス
- Cognito: フルアクセス
- IAM: ロール作成権限
- S3: デプロイバケットへのアクセス
- CloudWatch Logs: ログ作成権限
```

## CI/CDパイプライン

### GitHub Actionsの設定

```yaml
# .github/workflows/deploy.yml

name: Deploy to AWS

on:
  push:
    branches:
      - main
      - develop

env:
  AWS_REGION: ap-northeast-1
  SAM_CLI_VERSION: 1.100.0

jobs:
  deploy:
    runs-on: ubuntu-latest
    
    steps:
      - name: Checkout code
        uses: actions/checkout@v3
      
      - name: Setup Python
        uses: actions/setup-python@v4
        with:
          python-version: '3.11'
      
      - name: Setup SAM CLI
        uses: aws-actions/setup-sam@v2
        with:
          version: ${{ env.SAM_CLI_VERSION }}
      
      - name: Configure AWS credentials
        uses: aws-actions/configure-aws-credentials@v2
        with:
          aws-access-key-id: ${{ secrets.AWS_ACCESS_KEY_ID }}
          aws-secret-access-key: ${{ secrets.AWS_SECRET_ACCESS_KEY }}
          aws-region: ${{ env.AWS_REGION }}
      
      - name: SAM Build
        run: sam build
      
      - name: SAM Deploy (Dev)
        if: github.ref == 'refs/heads/develop'
        run: sam deploy --config-env default --no-confirm-changeset
      
      - name: SAM Deploy (Prod)
        if: github.ref == 'refs/heads/main'
        run: sam deploy --config-env prod --no-confirm-changeset
      
      - name: Get Stack Outputs
        run: |
          aws cloudformation describe-stacks \
            --stack-name tenant-user-management-${{ github.ref == 'refs/heads/main' && 'prod' || 'dev' }} \
            --query 'Stacks[0].Outputs' \
            --output table
```

## トラブルシューティング

### よくあるエラーと対処法

#### 1. IAM権限エラー
```
Error: User is not authorized to perform: iam:CreateRole
```

**対処法**:
```bash
# IAMロール作成権限を持つユーザーで実行
# または、CAPABILITY_IAMを明示的に指定
sam deploy --capabilities CAPABILITY_IAM
```

#### 2. スタック更新の競合
```
Error: Stack is in UPDATE_IN_PROGRESS state
```

**対処法**:
```bash
# 更新が完了するまで待つ
aws cloudformation wait stack-update-complete \
  --stack-name tenant-user-management-dev
```

#### 3. リソース名の重複
```
Error: Resource already exists
```

**対処法**:
```bash
# 古いスタックを削除
sam delete --stack-name tenant-user-management-dev

# 再デプロイ
sam deploy
```

#### 4. Lambda Layer のビルドエラー
```
Error: Failed to build layer
```

**対処法**:
```bash
# 依存関係を手動でインストール
cd layers/common
pip install -r requirements.txt -t python/
cd ../..

# 再ビルド
sam build
```

## デプロイの確認

### 1. APIエンドポイントのテスト

```bash
# ヘルスチェック（認証不要エンドポイントがある場合）
curl https://xxxxx.execute-api.ap-northeast-1.amazonaws.com/dev/health

# 認証付きリクエスト
curl -H "Authorization: Bearer ${ID_TOKEN}" \
  https://xxxxx.execute-api.ap-northeast-1.amazonaws.com/dev/users
```

### 2. Lambda関数の確認

```bash
# Lambda関数一覧
aws lambda list-functions \
  --query 'Functions[?starts_with(FunctionName, `CreateUser`)].FunctionName'

# 関数の詳細
aws lambda get-function \
  --function-name CreateUser-dev
```

### 3. DynamoDBテーブルの確認

```bash
# テーブル一覧
aws dynamodb list-tables

# テーブルの詳細
aws dynamodb describe-table \
  --table-name TenantUserManagement-dev
```

### 4. Cognitoユーザープールの確認

```bash
# ユーザープール一覧
aws cognito-idp list-user-pools --max-results 10

# ユーザープールの詳細
aws cognito-idp describe-user-pool \
  --user-pool-id ap-northeast-1_XXXXX
```
