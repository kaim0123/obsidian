# グローバルインフラストラクチャ

## 概要

AWS のグローバルインフラストラクチャは、世界中に分散されたデータセンターとネットワークインフラストラクチャで構成されています。これにより、世界中のユーザーに対して低遅延で高可用性のサービスを提供しています。

## インフラストラクチャの構成要素

### 1. リージョン（Region）

- **定義**: 地理的に分離された独立したデータセンター群
- **特徴**: 各リージョンは完全に独立して動作
- **例**: アジアパシフィック（東京）、米国東部（バージニア北部）、欧州（アイルランド）など

### 2. アベイラビリティゾーン（AZ）

- **定義**: リージョン内の独立したデータセンター
- **特徴**: 物理的に分離され、冗長性を提供
- **例**: ap-northeast-1a、ap-northeast-1c、ap-northeast-1d

### 3. エッジロケーション

- **定義**: コンテンツ配信とキャッシュのための拠点
- **特徴**: ユーザーに最も近い場所でコンテンツを配信
- **用途**: CloudFront、Route 53、Lambda@Edge

## 主要リージョン

### アジアパシフィック

- **東京（ap-northeast-1）**: 日本向けサービス
- **大阪（ap-northeast-3）**: 災害復旧用
- **ソウル（ap-northeast-2）**: 韓国向けサービス
- **シンガポール（ap-southeast-1）**: 東南アジア向け
- **シドニー（ap-southeast-2）**: オーストラリア向け

### 北米

- **バージニア北部（us-east-1）**: 主要リージョン
- **オハイオ（us-east-2）**: 東部の冗長性
- **カリフォルニア北部（us-west-1）**: 西部
- **オレゴン（us-west-2）**: 西部の冗長性

### 欧州

- **アイルランド（eu-west-1）**: 欧州主要
- **ロンドン（eu-west-2）**: 英国向け
- **フランクフルト（eu-central-1）**: 中央欧州

## グローバルインフラのメリット

### 1. 低遅延

- ユーザーに最も近いリージョンでサービス提供
- エッジロケーションによる高速コンテンツ配信
- 最適化されたネットワークルーティング

### 2. 高可用性

- 複数リージョンでの冗長構成
- 災害時の自動フェイルオーバー
- 99.99%以上の可用性保証

### 3. コンプライアンス

- 各国のデータ保護法規への対応
- データの地理的制限
- 政府・金融機関向けの専用リージョン

### 4. スケーラビリティ

- 需要に応じた自動スケーリング
- グローバルな負荷分散
- 無制限のリソース拡張

## データの地理的配置

### データレジデンシー

- **定義**: データが物理的に保存される場所
- **重要性**: 法的要件、プライバシー保護
- **制御**: リージョン選択による制御

### データ転送

- **リージョン間**: 有料（一部例外あり）
- **エッジロケーション**: 無料
- **最適化**: データ転送量の最小化

## 災害復旧とビジネス継続性

### マルチリージョン戦略

- **アクティブ-アクティブ**: 複数リージョンで同時稼働
- **アクティブ-パッシブ**: 災害時の切り替え
- **バックアップ**: 定期的なデータ複製

### RTO（復旧時間目標）と RPO（復旧ポイント目標）

- **RTO**: サービス復旧までの時間
- **RPO**: 許容できるデータ損失量
- **AWS**: 分単位での復旧が可能

## まとめ

AWS のグローバルインフラストラクチャは、世界中のユーザーに対して高品質なサービスを提供する基盤です。リージョン、アベイラビリティゾーン、エッジロケーションの組み合わせにより、低遅延、高可用性、スケーラビリティを実現しています。
