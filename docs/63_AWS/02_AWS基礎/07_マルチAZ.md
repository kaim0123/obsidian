# マルチ AZ

## 概要

マルチ AZ（Multi-Availability Zone）は、複数のアベイラビリティゾーンにまたがってリソースを配置し、高可用性と災害耐性を実現する設計パターンです。単一障害点を排除し、ビジネス継続性を確保します。

## マルチ AZ の基本概念

### 1. 冗長性の実現

- **複数 AZ 配置**: 同一リソースを複数の AZ に配置
- **障害の分離**: 一つの AZ の障害が他に影響しない
- **自動フェイルオーバー**: 障害時の自動切り替え

### 2. 高可用性

- **可用性向上**: 99.99%以上の可用性を実現
- **計画停止**: メンテナンス時のサービス継続
- **災害復旧**: 自然災害や停電からの保護

### 3. データ保護

- **同期レプリケーション**: リアルタイムでのデータ複製
- **自動バックアップ**: 複数 AZ でのバックアップ
- **ポイントインタイム復旧**: 任意の時点への復旧

## 主要サービスのマルチ AZ 対応

### 1. Amazon RDS

- **プライマリ/スタンバイ**: 異なる AZ に配置
- **同期レプリケーション**: リアルタイムでのデータ同期
- **自動フェイルオーバー**: 30 秒以内の自動切り替え
- **読み取りレプリカ**: 複数 AZ での読み取り分散

### 2. Amazon EC2

- **インスタンス分散**: 複数 AZ にインスタンスを配置
- **Auto Scaling**: AZ 間での自動スケーリング
- **Elastic Load Balancer**: 複数 AZ での負荷分散
- **EBS ボリューム**: 複数 AZ でのストレージ冗長化

### 3. Amazon ElastiCache

- **プライマリ/レプリカ**: 異なる AZ に配置
- **自動フェイルオーバー**: 障害時の自動切り替え
- **読み取りレプリカ**: 複数 AZ での読み取り分散
- **クラスター**: 複数 AZ でのクラスター構成
