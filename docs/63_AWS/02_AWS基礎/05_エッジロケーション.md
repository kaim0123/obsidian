# エッジロケーション

## 概要

エッジロケーション（Edge Location）は、AWS のグローバルインフラストラクチャの最前線に位置する拠点です。ユーザーに最も近い場所でコンテンツを配信し、低遅延と高パフォーマンスを実現します。

## エッジロケーションの特徴

### 1. 地理的分散

- **世界中に展開**: 200 以上の都市に配置
- **ユーザーに近い**: 主要都市や人口密集地域に設置
- **低遅延**: ユーザーからの物理的距離を最小化

### 2. キャッシュ機能

- **コンテンツキャッシュ**: 静的コンテンツを事前にキャッシュ
- **動的コンテンツ**: 一部の動的コンテンツもキャッシュ可能
- **自動更新**: TTL（Time To Live）に基づく自動更新

### 3. 高速配信

- **CDN 機能**: Content Delivery Network として機能
- **帯域幅最適化**: 効率的な帯域幅利用
- **プロトコル最適化**: HTTP/2、TLS 1.3 などの最新プロトコル対応

## 主要なサービス

### 1. Amazon CloudFront

- **CDN サービス**: グローバルなコンテンツ配信
- **動的コンテンツ**: 動的コンテンツの高速化
- **セキュリティ**: DDoS 保護、WAF 統合
- **カスタマイズ**: カスタムエラーページ、ヘッダー設定

### 2. AWS Lambda@Edge

- **サーバーレス実行**: エッジでのサーバーレス関数実行
- **リアルタイム処理**: リクエスト/レスポンスのリアルタイム処理
- **カスタマイズ**: コンテンツの動的変更
- **A/B テスト**: エッジでの A/B テスト実行

### 3. Amazon Route 53

- **DNS サービス**: グローバル DNS 解決
- **ヘルスチェック**: エンドポイントの監視
- **トラフィックルーティング**: 地理的、重み付け、レイテンシベース
- **ドメイン登録**: ドメイン名の登録・管理

## エッジロケーションの種類

### 1. CloudFront エッジロケーション

- **数**: 400 以上の拠点
- **用途**: 静的コンテンツ配信
- **キャッシュ**: 画像、動画、CSS、JavaScript など
- **更新頻度**: TTL に基づく自動更新

### 2. Regional Edge Cache

- **位置**: リージョンに近い場所
- **用途**: エッジロケーションのキャッシュを補完
- **容量**: より大きなキャッシュ容量
- **更新**: より頻繁なキャッシュ更新

### 3. Origin Shield

- **位置**: オリジンサーバーに近い場所
- **用途**: オリジンサーバーの負荷軽減
- **キャッシュ**: オリジンからのコンテンツをキャッシュ
- **効率**: キャッシュヒット率の向上

## パフォーマンス最適化

### 1. キャッシュ戦略

- **TTL 設定**: 適切なキャッシュ有効期限の設定
- **キャッシュキー**: 効率的なキャッシュキーの設計
- **無効化**: 必要に応じたキャッシュ無効化
- **圧縮**: Gzip/Brotli 圧縮の活用

### 2. コンテンツ最適化

- **画像最適化**: WebP、AVIF 形式の活用
- **動画最適化**: 適応的ビットレートストリーミング
- **CSS/JS 最適化**: ミニファイ、バンドリング
- **HTTP/2**: マルチプレクシングの活用

### 3. セキュリティ

- **HTTPS**: 全トラフィックの暗号化
- **WAF**: Web Application Firewall
- **DDoS 保護**: 分散サービス拒否攻撃からの保護
- **アクセス制御**: 地理的制限、リファラー制限

## 料金体系

### CloudFront 料金

- **データ転送**: 転送量に応じた課金
- **リクエスト**: HTTP/HTTPS リクエスト数
- **無効化**: キャッシュ無効化リクエスト
- **リアルタイムログ**: リアルタイムログ配信

### 最適化のポイント

- **キャッシュヒット率**: 高いキャッシュヒット率の維持
- **圧縮**: データ転送量の削減
- **リージョン選択**: 適切なリージョンの選択
- **無効化の最小化**: 不要な無効化の回避

## ユースケース

### 1. Web サイト配信

- **静的サイト**: HTML、CSS、JavaScript の配信
- **画像配信**: 商品画像、ユーザー画像の配信
- **動画配信**: 動画コンテンツのストリーミング

### 2. API 配信

- **REST API**: API レスポンスのキャッシュ
- **GraphQL**: GraphQL クエリの最適化
- **リアルタイム**: WebSocket 接続の最適化

### 3. モバイルアプリ

- **アプリ配信**: アプリケーションの配信
- **コンテンツ配信**: アプリ内コンテンツの配信
- **プッシュ通知**: プッシュ通知の配信

## まとめ

エッジロケーションは、AWS のグローバルインフラストラクチャの重要な構成要素です。ユーザーに最も近い場所でコンテンツを配信することで、低遅延と高パフォーマンスを実現します。CloudFront、Lambda@Edge、Route 53 などのサービスと組み合わせることで、グローバルなアプリケーションの最適化が可能になります。
