## 重要なポイント

### AWSの基本概念
- **グローバルインフラ**: リージョン、AZ、エッジロケーションの階層構造
- **従量課金**: 使用した分だけ支払う柔軟な料金体系
- **責任共有モデル**: AWSと顧客の責任分担の明確化

### クラウドの利点
- **スケーラビリティ**: 需要に応じたリソースの自動調整
- **コスト効率**: 初期投資不要で運用コストの削減
- **高可用性**: マルチAZ構成による障害耐性
