# VPCの作成とセットアップ

## ステップ1: VPCの作成
1. AWSマネジメントコンソール → VPC → Create VPC
2. 名前タグとIPv4 CIDRブロックを設定
3. 例：`MyVPC` / `10.0.0.0/16`

## ステップ2: サブネットの作成
```bash
# パブリックサブネット（us-east-1a）
名前: PublicSubnet1
CIDR: 10.0.1.0/24
AZ: us-east-1a

# プライベートサブネット（us-east-1b）
名前: PrivateSubnet1
CIDR: 10.0.2.0/24
AZ: us-east-1b
```

## ステップ3: インターネットゲートウェイの作成と接続
1. Internet Gatewayを作成
2. VPCにアタッチ
3. ルートテーブルにルートを追加

## ステップ4: セキュリティグループの設定
```bash
# Webサーバー用セキュリティグループ
インバウンドルール:
- HTTP (80) from 0.0.0.0/0
- HTTPS (443) from 0.0.0.0/0
- SSH (22) from 10.0.0.0/16

# データベース用セキュリティグループ
インバウンドルール:
- MySQL (3306) from 10.0.0.0/16
```

## ネットワーク設定とルーティング

### ルートテーブルの設定例

**パブリックサブネット用ルートテーブル**
```
宛先CIDRブロック    ターゲット
10.0.0.0/16        local
0.0.0.0/0          igw-12345678
```

**プライベートサブネット用ルートテーブル**
```
宛先CIDRブロック    ターゲット
10.0.0.0/16        local
0.0.0.0/0          nat-12345678
```

### VPCピアリング
異なるVPC間でプライベート接続を確立

```bash
# ピアリング接続の作成
1. リクエスターVPC: 10.0.0.0/16
2. アクセプターVPC: 10.1.0.0/16
3. 両方のVPCのルートテーブルにピアリングルートを追加
```
