# IP アドレス

## 概要

IP アドレス（Internet Protocol Address）は、ネットワーク上の機器を一意に識別するための数値です。インターネットやローカルネットワークで、データを正しい宛先に送信するために使用されます。

## IP アドレスの基本構造

### IPv4 アドレス

- **形式**: 4 つの数字をドット（.）で区切った形式
- **例**: 192.168.1.1
- **各数字の範囲**: 0〜255（8 ビット）
- **全体の長さ**: 32 ビット

### オクテット

IP アドレスは 4 つのオクテット（8 ビットずつ）に分かれています：

```
192.168.1.1
│   │   │ │
│   │   │ └─ 第4オクテット（ホスト部分）
│   │   └─── 第3オクテット
│   └─────── 第2オクテット
└─────────── 第1オクテット（ネットワーク部分）
```

## IP アドレスの種類

### 1. プライベート IP アドレス

組織内のローカルネットワークで使用される IP アドレス：

| クラス | 範囲                           | 用途             |
| ------ | ------------------------------ | ---------------- |
| A      | 10.0.0.0 〜 10.255.255.255     | 大規模組織       |
| B      | 172.16.0.0 〜 172.31.255.255   | 中規模組織       |
| C      | 192.168.0.0 〜 192.168.255.255 | 小規模組織・家庭 |

### 2. パブリック IP アドレス

インターネット上で一意に識別される IP アドレス：

- インターネットサービスプロバイダー（ISP）から割り当て
- 世界中で重複しない
- 例: 203.0.113.1

### 3. 特殊な IP アドレス

| IP アドレス     | 用途                     |
| --------------- | ------------------------ |
| 127.0.0.1       | ループバック（自分自身） |
| 0.0.0.0         | デフォルトルート         |
| 255.255.255.255 | ブロードキャスト         |

## IP アドレス範囲の詳細

### クラス別 IP アドレス範囲

#### クラス A（大規模ネットワーク）

- **範囲**: 1.0.0.0 〜 126.255.255.255
- **ネットワーク部**: 8 ビット
- **ホスト部**: 24 ビット
- **利用可能ホスト数**: 16,777,214 台
- **例**: 10.0.0.0/8（プライベート）

#### クラス B（中規模ネットワーク）

- **範囲**: 128.0.0.0 〜 191.255.255.255
- **ネットワーク部**: 16 ビット
- **ホスト部**: 16 ビット
- **利用可能ホスト数**: 65,534 台
- **例**: 172.16.0.0/12（プライベート）

#### クラス C（小規模ネットワーク）

- **範囲**: 192.0.0.0 〜 223.255.255.255
- **ネットワーク部**: 24 ビット
- **ホスト部**: 8 ビット
- **利用可能ホスト数**: 254 台
- **例**: 192.168.0.0/16（プライベート）

### 予約済み IP アドレス範囲

| 範囲           | 用途                     |
| -------------- | ------------------------ |
| 0.0.0.0/8      | ローカルネットワーク     |
| 10.0.0.0/8     | プライベート（クラス A） |
| 127.0.0.0/8    | ループバック             |
| 169.254.0.0/16 | リンクローカル（APIPA）  |
| 172.16.0.0/12  | プライベート（クラス B） |

| 224.0.0.0/4    | マルチキャスト           |
| 240.0.0.0/4    | 実験用・将来使用         |

### AWS での推奨 IP アドレス範囲

#### VPC 設計での考慮事項

| 用途             | 推奨範囲      | 理由                         |
| ---------------- | ------------- | ---------------------------- |
| 小規模環境       | 10.0.0.0/16   | 65,534 台のホストに対応      |
| 中規模環境       | 10.0.0.0/15   | 131,070 台のホストに対応     |
| 大規模環境       | 10.0.0.0/8    | 16,777,214 台のホストに対応  |
| 複数 VPC 接続    | 10.0.0.0/8    | 異なる VPC 間での重複回避    |
| オンプレミス接続 | 172.16.0.0/12 | 既存ネットワークとの重複回避 |

#### サブネット設計例

```
VPC: 10.0.0.0/16
├─ パブリックサブネット: 10.0.1.0/24 (256 IP)
├─ プライベートサブネット: 10.0.2.0/24 (256 IP)
├─ データベースサブネット: 10.0.3.0/24 (256 IP)
└─ 管理サブネット: 10.0.4.0/24 (256 IP)
```

### IP アドレス範囲の計算

#### CIDR 表記による計算

| CIDR | サブネットマスク | 利用可能 IP 数 | 使用可能ホスト数 |
| ---- | ---------------- | -------------- | ---------------- |
| /24  | 255.255.255.0    | 256            | 254              |
| /25  | 255.255.255.128  | 128            | 126              |
| /26  | 255.255.255.192  | 64             | 62               |
| /27  | 255.255.255.224  | 32             | 30               |
| /28  | 255.255.255.240  | 16             | 14               |
| /29  | 255.255.255.248  | 8              | 6                |
| /30  | 255.255.255.252  | 4              | 2                |

#### 計算式

```
利用可能ホスト数 = 2^(32 - CIDR) - 2
```

- **-2 の理由**: ネットワークアドレスとブロードキャストアドレスを除外

## ネットワーク部とホスト部

### 基本概念

IP アドレスは 2 つの部分に分かれます：

- **ネットワーク部**: どのネットワークに属するかを示す
- **ホスト部**: そのネットワーク内の特定の機器を示す

### 例：192.168.1.0/24

```
192.168.1.0/24
│   │   │ │
│   │   │ └─ ホスト部（8ビット）
│   │   └─── ネットワーク部（24ビット）
│   └───────
└───────────
```

## AWS での IP アドレス

### VPC での使用例

```
VPC CIDR: 10.0.0.0/16
├─ パブリックサブネット: 10.0.1.0/24
├─ プライベートサブネット: 10.0.2.0/24
└─ データベースサブネット: 10.0.3.0/24
```

### 利用可能な IP アドレス数

| サブネットマスク | 利用可能 IP 数           | 例             |
| ---------------- | ------------------------ | -------------- |
| /24              | 256 個（254 個使用可能） | 192.168.1.0/24 |
| /25              | 128 個（126 個使用可能） | 192.168.1.0/25 |
| /26              | 64 個（62 個使用可能）   | 192.168.1.0/26 |
| /27              | 32 個（30 個使用可能）   | 192.168.1.0/27 |

## IP アドレスの割り当て

### 静的割り当て

- 手動で IP アドレスを設定
- サーバーやルーターなど固定の機器に使用
- AWS では Elastic IP で実現

### 動的割り当て

- DHCP サーバーが自動で IP アドレスを割り当て
- クライアント PC やモバイル機器に使用
- AWS では VPC 内で自動的に提供

## トラブルシューティング

### よくある問題

1. **IP アドレス重複**: 同じ IP アドレスが複数の機器で使用
2. **サブネット外の通信**: 異なるネットワーク間の通信設定ミス
3. **デフォルトゲートウェイ設定**: 外部ネットワークへの出口設定

### 確認コマンド

```bash
# IPアドレス確認
ipconfig (Windows)
ifconfig (Linux/Mac)

# 接続確認
ping 192.168.1.1
```

## まとめ

IP アドレスはネットワーク通信の基本です。AWS の VPC、サブネット、EC2 インスタンスの設定で直接使用される重要な概念です。プライベートとパブリックの違い、ネットワーク部とホスト部の理解が、AWS のネットワーク設計に不可欠です。
