## 学習の進め方

### 初心者向け
1. **ネットワーク基礎** → 01_基本概念フォルダから開始
2. **VPC基本概念** → 仮想ネットワークの理解
3. **VPCコンポーネント** → サブネット、ルートテーブル等の詳細
4. **VPCセットアップ** → 実際の作成手順

### 中級者向け
5. **VPCセキュリティ** → セキュリティグループ、NACL設定
6. **ELB** → ロードバランシングの仕組み
7. **CloudFront基本概念** → CDNの概要
8. **CloudFront設定** → 実際の設定手順

### 上級者向け
9. **CloudFront実践例** → 静的・動的コンテンツ配信
10. **CloudFrontセキュリティ** → WAF連携、SSL設定
11. **Route53** → DNS設定とルーティングポリシー
12. **接続サービス** → オンプレミスとの連携

### 実践者向け
13. **VPC実践例** → 複雑な構成例とベストプラクティス
14. **実践例** → 実際のアプリケーション構築
