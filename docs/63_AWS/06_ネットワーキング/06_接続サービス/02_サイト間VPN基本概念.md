# サイト間 VPN とは

## 概要

サイト間 VPN は、オンプレミス環境と AWS クラウドを**インターネット経由**で安全に接続するサービスです。IPsec（Internet Protocol Security）を使用して**暗号化されたトンネル**を構築し、オンプレミスのネットワークと VPC を仮想的に 1 つのネットワークとして扱うことができます。

## なぜサイト間 VPN が必要なのか？

### 1. コスト効率

- 専用回線と比較して低コスト
- 既存のインターネット回線を活用
- 初期投資が少ない

### 2. 迅速な導入

- 物理的な回線敷設が不要
- 数時間で接続可能
- 柔軟な設定変更

### 3. セキュリティ

- IPsec による暗号化
- 認証と整合性の保証
- プライベートな通信

## サイト間 VPN の構成要素

### 1. 仮想プライベートゲートウェイ（VGW）

**VPC 側の VPN エンドポイント**

#### 特徴

- VPC にアタッチされる
- 複数の VPN 接続をサポート
- 自動スケーリング

### 2. カスタマーゲートウェイ（CGW）

**オンプレミス側の VPN エンドポイント**

#### 設定項目

- オンプレミスルーターの IP アドレス
- BGP（Border Gateway Protocol）の設定
- ルーティング情報

### 3. VPN 接続

**VGW と CGW 間のトンネル**

#### 特徴

- 2 つのトンネルで冗長化
- 自動フェイルオーバー
- 動的ルーティング（BGP）

## VPN 接続の種類

### 1. 静的ルーティング

**手動でルートを設定**

#### 特徴

- シンプルな設定
- 予測可能なルーティング
- 小規模なネットワークに適している

#### 設定例

```
オンプレミス側：
- 10.0.0.0/16 → AWS VPC
- 0.0.0.0/0 → インターネット

AWS側：
- 192.168.0.0/16 → オンプレミス
```

### 2. 動的ルーティング（BGP）

**自動でルートを学習**

#### 特徴

- 自動的なルート学習
- ネットワークの変更に柔軟に対応
- 大規模なネットワークに適している

#### 設定例

```
オンプレミス側：
- AS番号：65001
- 広告するルート：192.168.0.0/16

AWS側：
- AS番号：64512
- 広告するルート：10.0.0.0/16
```

## 実際の構成例

### 1. 基本的な構成

```
オンプレミス環境
├── ルーター（VPN対応）
├── ファイアウォール
└── サーバー群（192.168.0.0/16）
    ↓
インターネット（IPsecトンネル）
    ↓
AWS VPC
├── 仮想プライベートゲートウェイ
├── プライベートサブネット（10.0.0.0/16）
└── EC2インスタンス
```

### 2. 冗長化構成

```
オンプレミス環境
├── ルーター1（VPN対応）
└── ルーター2（VPN対応）
    ↓
インターネット（2つのIPsecトンネル）
    ↓
AWS VPC
├── 仮想プライベートゲートウェイ
└── プライベートサブネット
```

### 3. マルチサイト構成

```
オンプレミス環境1（東京）
オンプレミス環境2（大阪）
    ↓
インターネット（IPsecトンネル）
    ↓
AWS VPC
├── 仮想プライベートゲートウェイ
└── プライベートサブネット
```

## セキュリティ機能

### 1. IPsec 暗号化

- **ESP（Encapsulating Security Payload）**：データの暗号化
- **AH（Authentication Header）**：データの整合性確認
- **IKE（Internet Key Exchange）**：暗号化キーの交換

### 2. 認証

- **事前共有キー（PSK）**：シンプルな認証
- **証明書認証**：より強固な認証
- **相互認証**：双方向の認証

### 3. 整合性確認

- **HMAC（Hash-based Message Authentication Code）**：データの改ざん検出
- **SHA-1、SHA-256**：ハッシュアルゴリズム
- **MD5**：レガシーなハッシュアルゴリズム

## 料金について

### 1. 仮想プライベートゲートウェイ

### 2. VPN 接続

- **データ転送料金**：$0.05/GB

### 3. カスタマーゲートウェイ

- **時間料金**：無料
- **データ転送料金**：無料

## Direct Connect との比較

| 項目         | サイト間 VPN   | Direct Connect |
| ------------ | -------------- | -------------- |
| コスト       | 低い           | 高い           |
| 導入時間     | 短い（数時間） | 長い（数週間） |
| 帯域幅       | 制限あり       | 高い           |
| レイテンシー | 変動あり       | 一貫して低い   |
| 可用性       | 中程度         | 高い           |
| セキュリティ | 高い           | 非常に高い     |

## まとめ

サイト間 VPN は、オンプレミス環境と AWS クラウドを安全でコスト効率の良い方法で接続するサービスです。専用回線と比較して低コストで迅速に導入できるため、中小規模のネットワークや一時的な接続に特に適しています。
