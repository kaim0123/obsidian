# Direct Connect とは

## 概要

Direct Connect は、オンプレミス環境と AWS クラウドを**専用線**で接続するサービスです。インターネットを経由せずに、**高速で安全な通信**を実現します。企業のデータセンターやオフィスから AWS リソースに直接アクセスできるため、**セキュリティ**と**パフォーマンス**を大幅に向上させることができます。

## なぜ Direct Connect が必要なのか？

### 1. セキュリティの向上

- インターネットを経由しない専用回線
- データの暗号化とプライベートな通信
- コンプライアンス要件の満足

### 2. パフォーマンスの向上

- 一貫した低レイテンシー
- 高い帯域幅の保証
- ネットワークの予測可能性

### 3. コストの削減

- 大量のデータ転送時のコスト削減
- インターネット経由のデータ転送料金の回避
- 長期的なコスト最適化

## Direct Connect の構成要素

### 1. 物理接続

```
オンプレミス環境
    ↓
専用回線（1Gbps、10Gbps、100Gbps）
    ↓
AWS Direct Connectロケーション
    ↓
AWSクラウド
```

### 2. 仮想インターフェイス（Virtual Interface）

- **プライベート仮想インターフェイス**：VPC への直接接続
- **パブリック仮想インターフェイス**：AWS パブリックサービスへの接続
- **Transit 仮想インターフェイス**：Transit Gateway への接続

### 3. カスタマーゲートウェイ（Customer Gateway）

- オンプレミス側のルーター情報を定義
- BGP（Border Gateway Protocol）の設定
- IP アドレスの管理

## Direct Connect の種類

### 1. Direct Connect 専用回線

**物理的な専用回線**を提供

#### 特徴

- 1Gbps、10Gbps、100Gbps の帯域幅
- 物理的な専用回線
- 高い可用性とパフォーマンス

#### 料金

- **1Gbps**：約$0.30/時間
- **10Gbps**：約$2.25/時間
- **100Gbps**：約$22.50/時間

### 2. Direct Connect Hosted Connections

**パートナー経由**での接続

#### 特徴

- パートナーが管理する回線を利用
- より柔軟な帯域幅オプション
- 迅速な導入が可能

#### 帯域幅オプション

- 50Mbps、100Mbps、200Mbps
- 300Mbps、400Mbps，500Mbps
- 1Gbps、2Gbps，5Gbps，10Gbps

## 接続の流れ

### 1. 物理接続の確立

```
1. AWS Direct Connectロケーションを選択
2. 物理的な回線を敷設
3. オンプレミス環境と接続
4. 接続のテストと検証
```

### 2. 仮想インターフェイスの作成

```
1. プライベート仮想インターフェイスの作成
2. VPCへの接続設定
3. BGPの設定
4. ルーティングの確認
```

### 3. ネットワークの設定

```
1. カスタマーゲートウェイの設定
2. ルートテーブルの更新
3. セキュリティグループの設定
4. 接続のテスト
```

## 実際の構成例

### 1. 基本的な構成

```
オンプレミス環境
├── ルーター
├── ファイアウォール
└── サーバー群
    ↓
Direct Connect（1Gbps）
    ↓
AWS Direct Connectロケーション
    ↓
VPC
├── プライベートサブネット
├── パブリックサブネット
└── EC2インスタンス
```

### 2. 冗長化構成

```
オンプレミス環境
    ↓
Direct Connect 1（東京）
Direct Connect 2（大阪）
    ↓
AWS Direct Connectロケーション
    ↓
VPC（マルチAZ構成）
```

### 3. ハイブリッドクラウド構成

```
オンプレミス環境
├── データベースサーバー
├── ファイルサーバー
└── アプリケーションサーバー
    ↓
Direct Connect
    ↓
AWSクラウド
├── EC2インスタンス
├── RDS
├── S3
└── その他のAWSサービス
```

## セキュリティ機能

### 1. プライベート接続

- インターネットを経由しない通信
- データの暗号化
- プライベートなネットワーク環境

### 2. VPC エンドポイント

- AWS サービスへのプライベートアクセス
- インターネットゲートウェイ不要
- セキュリティの向上

### 3. セキュリティグループ

- インスタンスレベルでのアクセス制御
- ポートレベルでの制御
- 動的なルール設定

## パフォーマンスの最適化

### 1. 帯域幅の最適化

- 必要な帯域幅の見積もり
- トラフィックパターンの分析
- 適切な帯域幅の選択

### 2. レイテンシーの最適化

- 地理的に近いロケーションの選択
- ルーティングの最適化
- ネットワークの監視

### 3. 可用性の向上

- 複数の Direct Connect の設定
- 異なるロケーションでの冗長化
- 自動フェイルオーバー

## 料金について

### 1. 物理接続料金

- **1Gbps**：約$0.30/時間（約$216/月）
- **10Gbps**：約$2.25/時間（約$1,620/月）
- **100Gbps**：約$22.50/時間（約$16,200/月）

### 2. データ転送料金

- **最初の 1TB/月**：$0.00/GB
- **1TB-10TB/月**：$0.02/GB
- **10TB-40TB/月**：$0.015/GB
- **40TB-100TB/月**：$0.01/GB

### 3. 仮想インターフェイス料金

- **プライベート仮想インターフェイス**：無料
- **パブリック仮想インターフェイス**：無料
- **Transit 仮想インターフェイス**：無料

## まとめ

Direct Connect は、オンプレミス環境と AWS クラウドを安全で高速な専用回線で接続するサービスです。大量のデータ転送や高いセキュリティ要件がある場合に特に有効で、ハイブリッドクラウド環境の構築に不可欠なサービスです。
