# EC2 実践ガイド

## インスタンス作成手順

### 1. AWSコンソールにログイン
1. AWS Management Consoleにアクセス
2. アカウントでログイン

### 2. EC2ダッシュボードに移動
1. サービス一覧から「EC2」を選択
2. 「インスタンスを起動」ボタンをクリック

### 3. AMIの選択
```
推奨AMI:
- Amazon Linux 2 (無料、AWS最適化)
- Ubuntu Server (人気のLinuxディストリビューション)
- Windows Server (Windows環境が必要な場合)
```

### 4. インスタンスタイプの選択
```
初心者におすすめ:
- t2.micro: 無料利用枠内、学習用
- t3.micro: より高性能、無料利用枠内
- t3.small: 本格運用開始時
```

### 5. インスタンスの詳細設定
- **インスタンス数**: 1（通常）
- **ネットワーク**: デフォルトVPC
- **サブネット**: デフォルトサブネット
- **自動割り当てパブリックIP**: 有効

### 6. ストレージの設定
- **ボリュームタイプ**: gp3（汎用SSD）
- **サイズ**: 8GB（最小）
- **暗号化**: 必要に応じて有効

### 7. セキュリティグループの設定
```
基本的な設定:
- SSH (22): 自分のIPアドレスからのみ
- HTTP (80): 0.0.0.0/0（Webサーバーの場合）
- HTTPS (443): 0.0.0.0/0（Webサーバーの場合）
```

### 8. キーペアの作成・選択
1. 「新しいキーペアを作成」を選択
2. キーペア名を入力
3. 「キーペアを作成」をクリック
4. ダウンロードした.pemファイルを安全に保管

### 9. インスタンスの起動
1. 設定を確認
2. 「インスタンスを起動」をクリック

## セキュリティ設定

### セキュリティグループの設定

#### 基本的なルール
```bash
# SSH接続（管理者用）
Type: SSH
Protocol: TCP
Port: 22
Source: 自分のIPアドレス/32

# HTTP（Webサーバー用）
Type: HTTP
Protocol: TCP
Port: 80
Source: 0.0.0.0/0

# HTTPS（Webサーバー用）
Type: HTTPS
Protocol: TCP
Port: 443
Source: 0.0.0.0/0
```

### キーペアの管理
```bash
# キーペアファイルの権限設定（Linux/Mac）
chmod 400 your-key-pair.pem

# SSH接続
ssh -i your-key-pair.pem ec2-user@your-instance-ip
```

### セキュリティのベストプラクティス
1. **最小権限の原則**: 必要最小限のアクセス権限のみ許可
2. **定期的な更新**: OSとアプリケーションの定期的な更新
3. **ログ監視**: CloudTrailやCloudWatchでアクセスログを監視
4. **バックアップ**: 定期的なスナップショット作成

## よくある質問

### Q1: 初心者はどのインスタンスタイプから始めるべきですか？
**A**: t2.microまたはt3.microから始めることをお勧めします。無料利用枠内で学習でき、基本的なWebサーバーやアプリケーションの動作確認が可能です。

### Q2: インスタンスを停止すると課金は停止しますか？
**A**: インスタンスを「停止」すると、コンピューティング料金は停止しますが、EBSストレージの料金は継続して発生します。「終了」すると、ストレージも削除され課金が停止します。

### Q3: セキュリティグループとネットワークACLの違いは？
**A**: 
- **セキュリティグループ**: インスタンスレベルでのファイアウォール
- **ネットワークACL**: サブネットレベルでのファイアウォール

### Q4: 複数のインスタンスを管理する方法は？
**A**: 
- **Auto Scaling**: 負荷に応じた自動スケーリング
- **Elastic Load Balancer**: トラフィックの分散
- **CloudFormation**: インフラのコード化

### Q5: データの永続化はどうすればよいですか？
**A**: 
- **EBSボリューム**: インスタンスにアタッチする永続ストレージ
- **S3**: オブジェクトストレージ
- **RDS**: マネージドデータベースサービス

### Q6: コストを抑える方法は？
**A**: 
1. 不要なインスタンスの停止・終了
2. 適切なインスタンスタイプの選択
3. リザーブドインスタンスの活用
4. スポットインスタンスの検討
5. 定期的なコスト分析

## まとめ

EC2はAWSの基盤となるサービスで、クラウド上での仮想サーバー管理を可能にします。初心者の方は以下の順序で学習することをお勧めします：

1. **基本概念の理解**: インスタンス、AMI、セキュリティグループ
2. **簡単なインスタンス作成**: t2.microでの学習
3. **セキュリティ設定**: キーペアとセキュリティグループ
4. **モニタリング**: CloudWatchの活用
5. **コスト最適化**: 料金体系の理解と最適化

継続的な学習と実践を通じて、EC2の運用スキルを向上させていきましょう。
