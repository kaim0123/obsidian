# 終了コードと制御構文

## 終了コードとは

**終了コード（Exit Code）**は、コマンドやプログラムが終了する際に返す数値です。この値により、コマンドの実行結果（成功・失敗）を判断し、後続の処理を制御できます。

## 終了コードの基本

### 終了コードの確認

```bash
# 前のコマンドの終了コードを確認
echo $?

# 例
ls /nonexistent
echo $?  # 2（エラー）
```

### 主要な終了コード

- **0**: 成功
- **1**: 一般的なエラー
- **2**: 誤用（misuse）
- **126**: コマンドが実行できない
- **127**: コマンドが見つからない
- **128**: 無効な終了コード
- **130**: Ctrl+C で中断
- **255**: 範囲外の終了コード

## 制御構文

### if 文

#### 基本的な if 文

```bash
if [ condition ]; then
    commands
fi
```

#### if-else 文

```bash
if [ condition ]; then
    commands1
else
    commands2
fi
```

#### if-elif-else 文

```bash
if [ condition1 ]; then
    commands1
elif [ condition2 ]; then
    commands2
else
    commands3
fi
```

### 条件式

#### ファイル・ディレクトリのテスト

```bash
# ファイルが存在するか
if [ -f file.txt ]; then
    echo "File exists"
fi

# ディレクトリが存在するか
if [ -d directory ]; then
    echo "Directory exists"
fi

# ファイルが読み取り可能か
if [ -r file.txt ]; then
    echo "File is readable"
fi

# ファイルが書き込み可能か
if [ -w file.txt ]; then
    echo "File is writable"
fi

# ファイルが実行可能か
if [ -x file.txt ]; then
    echo "File is executable"
fi
```

#### 文字列の比較

```bash
# 文字列が等しいか
if [ "$var1" = "$var2" ]; then
    echo "Strings are equal"
fi

# 文字列が等しくないか
if [ "$var1" != "$var2" ]; then
    echo "Strings are not equal"
fi

# 文字列が空でないか
if [ -n "$var" ]; then
    echo "String is not empty"
fi

# 文字列が空か
if [ -z "$var" ]; then
    echo "String is empty"
fi
```

#### 数値の比較

```bash
# 数値が等しいか
if [ $num1 -eq $num2 ]; then
    echo "Numbers are equal"
fi

# 数値が等しくないか
if [ $num1 -ne $num2 ]; then
    echo "Numbers are not equal"
fi

# 数値が大きいか
if [ $num1 -gt $num2 ]; then
    echo "num1 is greater than num2"
fi

# 数値が小さいか
if [ $num1 -lt $num2 ]; then
    echo "num1 is less than num2"
fi
```

### 論理演算子

#### AND 演算子（&&）

```bash
# 両方の条件が真の場合
if [ condition1 ] && [ condition2 ]; then
    commands
fi

# コマンドの成功を確認
command1 && command2
```

#### OR 演算子（||）

```bash
# どちらかの条件が真の場合
if [ condition1 ] || [ condition2 ]; then
    commands
fi

# コマンドの失敗を確認
command1 || command2
```

#### NOT 演算子（!）

```bash
# 条件が偽の場合
if ! [ condition ]; then
    commands
fi
```

### case 文

```bash
case $variable in
    value1)
        commands1
        ;;
    value2)
        commands2
        ;;
    *)
        default_commands
        ;;
esac
```

#### case 文の例

```bash
#!/bin/bash
read -p "Enter a number (1-3): " num

case $num in
    1)
        echo "You chose option 1"
        ;;
    2)
        echo "You chose option 2"
        ;;
    3)
        echo "You chose option 3"
        ;;
    *)
        echo "Invalid option"
        ;;
esac
```

### for 文

#### 基本的な for 文

```bash
for variable in list; do
    commands
done
```

#### for 文の例

```bash
# ファイルリストを処理
for file in *.txt; do
    echo "Processing: $file"
    cp "$file" backup/
done

# 数値の範囲を処理
for i in {1..5}; do
    echo "Number: $i"
done

# 配列を処理
array=("apple" "banana" "cherry")
for fruit in "${array[@]}"; do
    echo "Fruit: $fruit"
done
```

### while 文

#### 基本的な while 文

```bash
while [ condition ]; do
    commands
done
```

#### while 文の例

```bash
# カウンタを使用
counter=1
while [ $counter -le 5 ]; do
    echo "Counter: $counter"
    counter=$((counter + 1))
done

# ファイルの内容を読み取り
while read line; do
    echo "Line: $line"
done < file.txt

# 無限ループ（Ctrl+Cで終了）
while true; do
    echo "Running..."
    sleep 1
done
```

### until 文

```bash
until [ condition ]; do
    commands
done
```

#### until 文の例

```bash
# 条件が真になるまで実行
counter=1
until [ $counter -gt 5 ]; do
    echo "Counter: $counter"
    counter=$((counter + 1))
done
```

## ループ制御

### break 文

```bash
# ループを終了
for i in {1..10}; do
    if [ $i -eq 5 ]; then
        break
    fi
    echo "Number: $i"
done
```

### continue 文

```bash
# ループの次の反復に進む
for i in {1..10}; do
    if [ $i -eq 5 ]; then
        continue
    fi
    echo "Number: $i"
done
```

## 関数

### 関数の定義

```bash
function_name() {
    commands
}

# または
function function_name {
    commands
}
```

### 関数の例

```bash
# 簡単な関数
greet() {
    echo "Hello, $1!"
}

# 関数の呼び出し
greet "World"

# 戻り値を持つ関数
add() {
    local result=$(( $1 + $2 ))
    return $result
}

# 関数の戻り値を取得
add 5 3
echo "Result: $?"
```

## 実用的な例

### ファイル処理スクリプト

```bash
#!/bin/bash
# ファイル処理スクリプト

# ディレクトリが存在するか確認
if [ ! -d "backup" ]; then
    mkdir backup
    echo "Created backup directory"
fi

# ファイルをバックアップ
for file in *.txt; do
    if [ -f "$file" ]; then
        cp "$file" backup/
        echo "Backed up: $file"
    else
        echo "No .txt files found"
        break
    fi
done
```

### システム監視スクリプト

```bash
#!/bin/bash
# システム監視スクリプト

# プロセスが実行中か確認
check_process() {
    if pgrep "$1" > /dev/null; then
        echo "$1 is running"
        return 0
    else
        echo "$1 is not running"
        return 1
    fi
}

# 複数のプロセスをチェック
processes=("nginx" "apache2" "mysql")

for process in "${processes[@]}"; do
    check_process "$process"
done
```

### ユーザー入力処理スクリプト

```bash
#!/bin/bash
# ユーザー入力処理スクリプト

# メニューを表示
show_menu() {
    echo "1. Option 1"
    echo "2. Option 2"
    echo "3. Option 3"
    echo "4. Exit"
}

# メインループ
while true; do
    show_menu
    read -p "Choose an option: " choice

    case $choice in
        1)
            echo "You chose option 1"
            ;;
        2)
            echo "You chose option 2"
            ;;
        3)
            echo "You chose option 3"
            ;;
        4)
            echo "Goodbye!"
            break
            ;;
        *)
            echo "Invalid option. Please try again."
            ;;
    esac

    echo
done
```

## エラーハンドリング

### エラーの確認

```bash
# コマンドの成功を確認
if command; then
    echo "Command succeeded"
else
    echo "Command failed with exit code: $?"
fi
```

### エラーの処理

```bash
# エラーが発生した場合の処理
command || {
    echo "Error occurred"
    exit 1
}
```

### トラップの使用

```bash
# スクリプト終了時の処理
cleanup() {
    echo "Cleaning up..."
    rm -f temp_file
}

trap cleanup EXIT

# スクリプトの処理
echo "Script running..."
```

## まとめ

終了コードと制御構文は、Linux システムでの効率的なスクリプト作成と自動化の基盤となる重要な概念です。適切な条件分岐とループ制御により、複雑な処理を自動化できます。特に、ファイル処理、システム監視、ユーザー入力処理などの場面で、これらの制御構文は非常に有用です。エラーハンドリングと適切な終了コードの使用により、堅牢で信頼性の高いスクリプトを作成できます。
