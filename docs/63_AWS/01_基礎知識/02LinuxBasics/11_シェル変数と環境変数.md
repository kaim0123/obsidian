# シェル変数と環境変数

## 変数とは

Linux システムでは、**変数（Variable）**はデータを保存するための名前付きの記憶領域です。シェル変数と環境変数の 2 つの種類があり、それぞれ異なる用途とスコープを持ちます。

## シェル変数と環境変数の違い

### シェル変数（Shell Variable）

- 現在のシェルセッション内でのみ有効
- 子プロセスには継承されない
- ローカル変数として機能

### 環境変数（Environment Variable）

- 子プロセスにも継承される
- システム全体で使用可能
- グローバル変数として機能

## 変数の設定

### 基本的な変数設定

```bash
# シェル変数の設定
variable_name="value"

# 環境変数の設定
export variable_name="value"

# 既存のシェル変数を環境変数に変換
export variable_name
```

### 変数の参照

```bash
# 変数の値を表示
echo $variable_name

# 変数の値を表示（波括弧を使用）
echo ${variable_name}

# 変数が未定義の場合のデフォルト値
echo ${variable_name:-"default_value"}
```

## 主要な環境変数

### システム関連

```bash
# ホームディレクトリ
echo $HOME

# 現在のディレクトリ
echo $PWD

# 前のディレクトリ
echo $OLDPWD

# シェルの種類
echo $SHELL

# ユーザー名
echo $USER

# ホスト名
echo $HOSTNAME
```

### パス関連

```bash
# 実行ファイルの検索パス
echo $PATH

# ライブラリの検索パス
echo $LD_LIBRARY_PATH

# マニュアルページの検索パス
echo $MANPATH
```

### 言語・地域設定

```bash
# 言語設定
echo $LANG

# 地域設定
echo $LC_ALL

# 文字エンコーディング
echo $LC_CTYPE
```

## 変数の操作

### 変数の確認

```bash
# すべての環境変数を表示
env

# すべての変数を表示
set

# 特定の変数を確認
echo $variable_name

# 変数が設定されているか確認
if [ -n "$variable_name" ]; then
    echo "Variable is set"
fi
```

### 変数の削除

```bash
# シェル変数を削除
unset variable_name

# 環境変数を削除
unset variable_name
```

### 変数の長さ

```bash
# 変数の文字数を取得
echo ${#variable_name}

# 例
name="Hello"
echo ${#name}  # 5
```

## 文字列操作

### 文字列の切り出し

```bash
# 先頭から指定文字数切り出し
echo ${variable_name:0:5}

# 末尾から指定文字数切り出し
echo ${variable_name: -5}

# 例
path="/home/user/documents/file.txt"
echo ${path:0:10}  # /home/user
echo ${path: -10}  # file.txt
```

### 文字列の置換

```bash
# 最初の一致を置換
echo ${variable_name/old/new}

# すべての一致を置換
echo ${variable_name//old/new}

# 例
text="hello world hello"
echo ${text/hello/hi}    # hi world hello
echo ${text//hello/hi}   # hi world hi
```

### 文字列の削除

```bash
# 先頭から最短一致を削除
echo ${variable_name#pattern}

# 先頭から最長一致を削除
echo ${variable_name##pattern}

# 末尾から最短一致を削除
echo ${variable_name%pattern}

# 末尾から最長一致を削除
echo ${variable_name%%pattern}

# 例
path="/home/user/documents/file.txt"
echo ${path#/}           # home/user/documents/file.txt
echo ${path##*/}         # file.txt
echo ${path%.txt}        # /home/user/documents/file
echo ${path%%.txt}       # /home/user/documents/file
```

## 配列変数

### 配列の定義

```bash
# 配列の定義
array=("element1" "element2" "element3")

# インデックスを指定して定義
array[0]="element1"
array[1]="element2"
array[2]="element3"
```

### 配列の操作

```bash
# 配列の要素を表示
echo ${array[0]}
echo ${array[1]}

# すべての要素を表示
echo ${array[@]}

# 配列の長さを取得
echo ${#array[@]}

# 配列の要素を追加
array+=("element4")

# 配列の要素を削除
unset array[1]
```

## 特殊変数

### 位置パラメータ

```bash
# スクリプトの引数
echo $0    # スクリプト名
echo $1    # 第1引数
echo $2    # 第2引数
echo $@    # すべての引数
echo $#    # 引数の数
```

### その他の特殊変数

```bash
# 最後のコマンドの終了コード
echo $?

# 現在のシェルのプロセスID
echo $$

# 最後のバックグラウンドプロセスのPID
echo $!

# 現在のシェルのオプション
echo $-
```

## 変数のスコープ

### ローカル変数

```bash
# 関数内でのみ有効
function test_function() {
    local local_var="local value"
    echo $local_var
}
```

### グローバル変数

```bash
# スクリプト全体で有効
global_var="global value"

function test_function() {
    echo $global_var
}
```

## 実用的な例

### パスの設定

```bash
# 新しいパスを追加
export PATH="$PATH:/usr/local/bin"

# 複数のパスを追加
export PATH="$PATH:/opt/bin:/usr/local/sbin"
```

### エイリアスの設定

```bash
# エイリアスを設定
alias ll='ls -la'
alias ..='cd ..'
alias grep='grep --color=auto'
```

### プロンプトのカスタマイズ

```bash
# プロンプトをカスタマイズ
export PS1='[\u@\h \W]\$ '

# より詳細なプロンプト
export PS1='[\u@\h \w]\$ '
```

### 言語設定

```bash
# 日本語環境の設定
export LANG=ja_JP.UTF-8
export LC_ALL=ja_JP.UTF-8
```

## 設定ファイル

### 個人設定ファイル

```bash
# Bash設定ファイル
~/.bashrc
~/.bash_profile
~/.bash_aliases

# 設定の読み込み
source ~/.bashrc
. ~/.bashrc
```

### システム設定ファイル

```bash
# システム全体の設定
/etc/environment
/etc/profile
/etc/bash.bashrc
```

## 変数の永続化

### 設定ファイルへの追加

```bash
# .bashrcに追加
echo 'export MY_VARIABLE="value"' >> ~/.bashrc

# .profileに追加
echo 'export PATH="$PATH:/new/path"' >> ~/.profile
```

### 環境変数の確認

```bash
# 現在の環境変数を確認
printenv

# 特定の環境変数を確認
printenv PATH
printenv HOME
```

## まとめ

シェル変数と環境変数は、Linux システムでの設定管理とデータ処理の基盤となる重要な概念です。適切な変数の使用により、効率的なスクリプト作成とシステム設定が可能になります。特に、環境変数はシステム全体に影響するため、慎重に設定・管理することが重要です。変数のスコープと永続化を理解し、適切な設定ファイルを使用することで、効率的なシステム運用が可能になります。
