# コマンドパスを通す仕組み

## コマンドパスとは

**コマンドパス（Command Path）**は、Linux システムでコマンドを実行する際に、そのコマンドの場所を検索するディレクトリのリストです。シェルは、このパスに基づいて実行可能ファイルを探し、見つかった場合に実行します。

## PATH 環境変数

### PATH の確認

```bash
# 現在のPATHを表示
echo $PATH

# PATHの詳細表示
printenv PATH

# PATHの各要素を確認
echo $PATH | tr ':' '\n'
```

### PATH の構造

```bash
# 典型的なPATHの例
/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin

# 各ディレクトリの説明
/usr/local/sbin    # ローカルのシステム管理コマンド
/usr/local/bin     # ローカルのユーザーコマンド
/usr/sbin          # システム管理コマンド
/usr/bin           # ユーザーコマンド
/sbin              # システム管理コマンド
/bin                # 基本的なコマンド
```

## コマンドの検索

### which コマンド

```bash
# コマンドの場所を検索
which ls
which python
which java

# すべての場所を表示
which -a python
which -a java
```

### whereis コマンド

```bash
# コマンドの場所、マニュアル、ソースを検索
whereis ls
whereis python
whereis java

# バイナリのみ表示
whereis -b ls

# マニュアルのみ表示
whereis -m ls
```

### type コマンド

```bash
# コマンドの種類を表示
type ls
type python
type java

# 詳細情報を表示
type -a ls
type -a python
```

## パスの設定

### 一時的な設定

```bash
# 現在のセッションでのみ有効
export PATH="$PATH:/new/path"

# 複数のパスを追加
export PATH="$PATH:/opt/bin:/usr/local/sbin"

# パスの先頭に追加
export PATH="/new/path:$PATH"
```

### 永続的な設定

#### 個人設定ファイル

```bash
# .bashrcに追加
echo 'export PATH="$PATH:/new/path"' >> ~/.bashrc

# .bash_profileに追加
echo 'export PATH="$PATH:/new/path"' >> ~/.bash_profile

# .profileに追加
echo 'export PATH="$PATH:/new/path"' >> ~/.profile
```

#### システム設定ファイル

```bash
# システム全体の設定
sudo nano /etc/environment

# 設定例
PATH="/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin:/new/path"
```

### 設定の適用

```bash
# 設定ファイルを再読み込み
source ~/.bashrc

# または
. ~/.bashrc

# 新しいシェルセッションを開始
bash
```

## 実用的な例

### カスタムスクリプトのパス設定

```bash
# スクリプトディレクトリを作成
mkdir -p ~/bin

# スクリプトを作成
cat > ~/bin/myscript.sh << 'EOF'
#!/bin/bash
echo "Hello from custom script!"
EOF

# 実行権限を付与
chmod +x ~/bin/myscript.sh

# パスに追加
echo 'export PATH="$HOME/bin:$PATH"' >> ~/.bashrc

# 設定を適用
source ~/.bashrc

# スクリプトを実行
myscript.sh
```

### 開発ツールのパス設定

```bash
# Node.jsのパスを追加
export PATH="$PATH:/usr/local/node/bin"

# Pythonのパスを追加
export PATH="$PATH:/usr/local/python/bin"

# Javaのパスを追加
export PATH="$PATH:/usr/local/java/bin"
```

### 複数バージョンの管理

```bash
# 複数のPythonバージョンを管理
export PATH="/usr/local/python3.9/bin:$PATH"
export PATH="/usr/local/python3.8/bin:$PATH"

# 特定のバージョンを優先
export PATH="/usr/local/python3.9/bin:$PATH"
```

## パスの管理

### パスの確認

```bash
# パスの各要素を確認
echo $PATH | tr ':' '\n' | nl

# パスの各要素の存在確認
for dir in $(echo $PATH | tr ':' ' '); do
    if [ -d "$dir" ]; then
        echo "✓ $dir"
    else
        echo "✗ $dir"
    fi
done
```

### パスの整理

```bash
# 重複するパスを除去
export PATH=$(echo $PATH | tr ':' '\n' | sort -u | tr '\n' ':' | sed 's/:$//')

# 存在しないパスを除去
export PATH=$(echo $PATH | tr ':' '\n' | while read dir; do
    [ -d "$dir" ] && echo "$dir"
done | tr '\n' ':' | sed 's/:$//')
```

### パスのバックアップ

```bash
# 現在のPATHをバックアップ
echo "export PATH=\"$PATH\"" > ~/.path_backup

# バックアップから復元
source ~/.path_backup
```

## セキュリティの考慮事項

### パスの順序

```bash
# 安全なパスの順序
export PATH="/usr/local/bin:/usr/bin:/bin:/usr/sbin:/sbin"

# 危険なパスの順序（現在のディレクトリを先頭に）
export PATH=".:$PATH"  # 危険！
```

### パスの検証

```bash
# パスの各要素を検証
validate_path() {
    for dir in $(echo $PATH | tr ':' ' '); do
        if [ ! -d "$dir" ]; then
            echo "Warning: $dir does not exist"
        elif [ ! -r "$dir" ]; then
            echo "Warning: $dir is not readable"
        fi
    done
}

# パスを検証
validate_path
```

## 実用的なスクリプト

### パス管理スクリプト

```bash
#!/bin/bash
# パス管理スクリプト

# パスを追加
add_path() {
    local new_path="$1"
    if [[ ":$PATH:" != *":$new_path:"* ]]; then
        export PATH="$new_path:$PATH"
        echo "Added $new_path to PATH"
    else
        echo "$new_path is already in PATH"
    fi
}

# パスを削除
remove_path() {
    local remove_path="$1"
    export PATH=$(echo $PATH | tr ':' '\n' | grep -v "^$remove_path$" | tr '\n' ':' | sed 's/:$//')
    echo "Removed $remove_path from PATH"
}

# パスを表示
show_path() {
    echo "Current PATH:"
    echo $PATH | tr ':' '\n' | nl
}

# 使用例
# add_path "/usr/local/bin"
# remove_path "/usr/local/bin"
# show_path
```

### パス検証スクリプト

```bash
#!/bin/bash
# パス検証スクリプト

echo "=== PATH Validation ==="
echo

# パスの各要素を検証
for dir in $(echo $PATH | tr ':' ' '); do
    if [ -d "$dir" ]; then
        if [ -r "$dir" ]; then
            echo "✓ $dir"
        else
            echo "✗ $dir (not readable)"
        fi
    else
        echo "✗ $dir (does not exist)"
    fi
done

echo
echo "=== PATH Summary ==="
echo "Total directories: $(echo $PATH | tr ':' '\n' | wc -l)"
echo "Existing directories: $(echo $PATH | tr ':' '\n' | while read dir; do [ -d "$dir" ] && echo "$dir"; done | wc -l)"
echo "Readable directories: $(echo $PATH | tr ':' '\n' | while read dir; do [ -r "$dir" ] && echo "$dir"; done | wc -l)"
```

## まとめ

コマンドパスの仕組みは、Linux システムでの効率的なコマンド実行の基盤となる重要な概念です。適切な PATH 設定により、カスタムスクリプトや開発ツールを簡単に実行できます。特に、パスの順序、セキュリティ、重複の管理などの考慮事項により、安全で効率的なシステム運用が実現できます。定期的なパスの検証と適切な設定により、信頼性の高いシステム運用が可能になります。
