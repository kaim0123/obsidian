# スーパーユーザー

## スーパーユーザーとは

**スーパーユーザー（Super User）**は、Linux システムにおいて最高レベルの権限を持つ特別なユーザーです。通常は`root`という名前で、システム全体への完全なアクセス権限を持ちます。

## root ユーザーの特徴

### 権限

- システム全体への完全なアクセス権限
- すべてのファイルとディレクトリの読み書き・実行
- システム設定の変更
- ユーザーとグループの管理
- システムサービスの制御
- ハードウェアの制御

### 識別

- **ユーザー名**: root
- **ユーザー ID**: 0
- **グループ ID**: 0
- **ホームディレクトリ**: /root

## root ユーザーへの切り替え

### su コマンド

#### 基本的な使用方法

```bash
# rootユーザーに切り替え
su -

# 環境変数を保持して切り替え
su

# パスワードを要求
su -
# パスワードを入力
```

#### su コマンドのオプション

```bash
# 完全な環境で切り替え
su - root

# 特定のコマンドを実行
su -c "command" root

# シェルを指定
su -s /bin/bash root
```

### sudo コマンド

#### 基本的な使用方法

```bash
# 管理者権限でコマンドを実行
sudo command

# rootユーザーになる
sudo su -

# 他のユーザーになる
sudo su - username
```

#### sudo コマンドのオプション

```bash
# 詳細情報を表示
sudo -v

# タイムスタンプを更新
sudo -v

# 特定のユーザーとして実行
sudo -u username command

# 環境変数を保持
sudo -E command
```

## sudo の設定

### sudoers ファイル

```bash
# sudoersファイルを編集
sudo visudo

# sudoersファイルの確認
sudo cat /etc/sudoers
```

### sudoers ファイルの設定例

```bash
# ユーザーにsudo権限を付与
username ALL=(ALL:ALL) ALL

# 特定のコマンドのみ許可
username ALL=(ALL) /usr/bin/apt, /usr/bin/systemctl

# パスワードなしでsudoを許可
username ALL=(ALL) NOPASSWD: ALL

# グループにsudo権限を付与
%sudo ALL=(ALL:ALL) ALL
```

### sudo グループ

```bash
# ユーザーをsudoグループに追加
sudo usermod -aG sudo username

# グループの確認
groups username
```

## セキュリティの考慮事項

### root ユーザーの使用制限

```bash
# rootユーザーでの直接ログインを無効化
sudo nano /etc/ssh/sshd_config
# PermitRootLogin no

# SSH設定を再読み込み
sudo systemctl reload ssh
```

### sudo のベストプラクティス

1. **最小権限の原則**: 必要最小限の権限のみ付与
2. **定期的な監査**: sudo 権限の定期的な確認
3. **ログの監視**: sudo 使用ログの監視
4. **タイムアウト設定**: sudo セッションのタイムアウト

### sudo のタイムアウト設定

```bash
# sudoのタイムアウトを設定
sudo visudo
# Defaults timestamp_timeout=15
```

## 実用的な使用例

### システム管理

```bash
# パッケージのインストール
sudo apt update
sudo apt install package_name

# サービスの制御
sudo systemctl start service_name
sudo systemctl stop service_name
sudo systemctl restart service_name

# ファイルの編集
sudo nano /etc/hosts
sudo vim /etc/ssh/sshd_config
```

### ユーザー管理

```bash
# 新しいユーザーを作成
sudo useradd -m -s /bin/bash newuser

# ユーザーのパスワードを設定
sudo passwd newuser

# ユーザーをグループに追加
sudo usermod -aG groupname username

# ユーザーを削除
sudo userdel -r username
```

### ファイル・ディレクトリの管理

```bash
# 権限の変更
sudo chmod 755 /path/to/directory
sudo chown user:group /path/to/file

# システムファイルの編集
sudo cp /etc/hosts /etc/hosts.backup
sudo nano /etc/hosts
```

### ログの確認

```bash
# システムログの確認
sudo tail -f /var/log/syslog
sudo journalctl -f

# 認証ログの確認
sudo tail -f /var/log/auth.log
```

## トラブルシューティング

### sudo 権限の問題

```bash
# sudo権限の確認
sudo -l

# sudoグループの確認
groups $USER

# sudoersファイルの構文チェック
sudo visudo -c
```

### root パスワードのリセット

```bash
# シングルユーザーモードで起動
# 起動時にGRUBメニューで 'e' を押す
# kernel行の末尾に 'single' を追加
# Ctrl+Xで起動

# rootパスワードをリセット
passwd root

# システムを再起動
reboot
```

### sudo の設定リセット

```bash
# sudoersファイルのバックアップから復元
sudo cp /etc/sudoers.backup /etc/sudoers

# または、visudoで修正
sudo visudo
```

## 監査とログ

### sudo 使用ログの確認

```bash
# sudo使用ログの確認
sudo grep sudo /var/log/auth.log

# 特定のユーザーのsudo使用履歴
sudo grep "username" /var/log/auth.log

# 最近のsudo使用履歴
sudo tail -f /var/log/auth.log | grep sudo
```

### システム監査

```bash
# システム監査ツールの使用
sudo auditctl -l
sudo ausearch -k sudo

# ファイルアクセスの監査
sudo auditctl -w /etc/passwd -p rwxa -k passwd_changes
```

## まとめ

スーパーユーザー（root）は、Linux システムの管理において重要な役割を果たします。適切な権限管理とセキュリティ設定により、安全で効率的なシステム管理が可能になります。特に、sudo コマンドの適切な使用と設定により、最小権限の原則に従った安全なシステム運用が実現できます。定期的な監査とログの監視により、システムのセキュリティを維持できます。
