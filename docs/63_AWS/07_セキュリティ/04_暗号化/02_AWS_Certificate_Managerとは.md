# AWS Certificate Manager とは

## 概要

AWS Certificate Manager（ACM）は、SSL/TLS 証明書をプロビジョニング、管理、デプロイする証明書管理サービスです。HTTPS 通信の暗号化に必要な SSL/TLS 証明書を簡単に取得・管理できます。

## 主な機能

### 1. 証明書管理サービス

- SSL/TLS 証明書の自動発行
- 証明書の自動更新
- 証明書の一元管理
- 証明書の自動デプロイ

### 2. 統合された証明書管理

- AWS サービスとの自動統合
- 手動での証明書インストールが不要
- 証明書の有効期限管理

## 証明書の種類

### 1. パブリック証明書

- 公的な認証局（CA）が発行
- インターネット上で信頼される
- 無料で利用可能

#### サポートする認証局

- **Amazon Trust Services**: AWS の認証局
- **DigiCert**: サードパーティの認証局
- **Let's Encrypt**: 無料の認証局

### 2. プライベート証明書

- 内部認証局が発行
- 組織内でのみ信頼される
- 内部システム用

## 証明書の取得プロセス

### 1. 証明書のリクエスト

- ドメイン名の指定
- 検証方法の選択
- 証明書の種類の選択

### 2. ドメイン検証

- **DNS 検証**: DNS レコードでの検証
- **メール検証**: メールアドレスでの検証
- **HTTP 検証**: HTTP ファイルでの検証

### 3. 証明書の発行

- 検証完了後の自動発行
- 証明書の自動配布
- 有効期限の設定

## 統合サービス

### 1. CloudFront

- CDN での HTTPS 配信
- エッジロケーションでの証明書使用
- グローバルな HTTPS 対応

### 2. Application Load Balancer

- ロードバランサーでの HTTPS 終端
- バックエンドへの HTTP 通信
- 証明書の自動更新

### 3. API Gateway

- RESTful API での HTTPS 対応
- カスタムドメインでの HTTPS
- 証明書の自動管理

### 4. Elastic Beanstalk

- アプリケーションでの HTTPS 対応
- 自動的な証明書の設定
- 環境変数での証明書指定

## 証明書の管理

### 1. 自動更新

- 証明書の有効期限前の自動更新
- 手動での更新作業が不要
- サービス中断の防止

### 2. 証明書の監視

- 有効期限の監視
- 証明書の状態確認
- アラートの設定

### 3. 証明書の削除

- 不要な証明書の削除
- セキュリティの向上
- コストの削減

## まとめ

AWS Certificate Manager は、SSL/TLS 証明書の管理を簡単かつ安全に行える重要なサービスです。無料でパブリック証明書を利用でき、自動更新機能により運用負荷を大幅に軽減できます。AWS サービスとの統合により、HTTPS 通信の実装が簡単になります。
