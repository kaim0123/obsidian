# Amazon GuardDuty

## 概要

Amazon GuardDutyは、AWSクラウド環境における脅威検出サービスです。機械学習、異常検出、統合された脅威インテリジェンスを活用して、AWSアカウント、ワークロード、データに保存されているS3バケットに対する悪意のある活動や不正な動作を継続的に監視します。

## 主な機能

### 1. 脅威検出
- **マルウェア検出**: EC2インスタンスやS3バケット内のマルウェアを検出
- **異常なAPI呼び出し**: 通常とは異なるAPI使用パターンを検出
- **ネットワーク異常**: 疑わしいネットワーク通信を監視
- **データ漏洩の試行**: 不正なデータアクセスや流出を検出

### 2. データソース
- **VPC Flow Logs**: ネットワークトラフィックの分析
- **CloudTrail Event Logs**: API呼び出しの監視
- **DNS Logs**: DNSクエリの分析
- **S3 Access Logs**: S3バケットへのアクセス監視
- **Kubernetes Audit Logs**: EKSクラスターの監査ログ

### 3. 脅威インテリジェンス
- **AWS脅威インテリジェンス**: AWSが収集したグローバルな脅威データ
- **サードパーティフィード**: 外部の脅威インテリジェンスプロバイダーとの連携
- **機械学習ベースの検出**: 行動分析による未知の脅威の検出

## セットアップ手順

### 1. GuardDutyの有効化
```bash
# AWS CLIを使用した有効化
aws guardduty create-detector --enable
```

### 2. データソースの設定
- VPC Flow Logsの有効化
- CloudTrailの設定確認
- DNS Logsの有効化（必要に応じて）

### 3. 通知設定
- SNSトピックの作成
- アラートの設定
- セキュリティチームへの通知設定

## まとめ

Amazon GuardDutyは、AWS環境における包括的なセキュリティ監視を提供する重要なサービスです。機械学習と脅威インテリジェンスを活用して、従来のセキュリティツールでは検出困難な高度な脅威を発見し、組織のセキュリティ体制を強化します。

適切な設定と運用により、クラウド環境のセキュリティリスクを大幅に削減し、インシデント対応の効率化を実現できます。
