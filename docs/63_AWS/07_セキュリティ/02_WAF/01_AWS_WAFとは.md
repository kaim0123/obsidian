# AWS WAF とは

## 概要

AWS WAF（Web Application Firewall）は、ウェブアプリケーションを一般的なウェブエクスプロイトから保護する仮想ウェブアプリケーションファイアーウォールサービスです。CloudFront、Application Load Balancer、API Gateway の前に配置して、悪意のあるトラフィックをフィルタリングします。

## 主な機能

### 1. 仮想ウェブアプリケーションファイアーウォールサービス

- ウェブアプリケーションの保護
- リアルタイムでのトラフィック監視
- カスタマイズ可能なセキュリティルール

### 2. 保護対象の攻撃

- SQL インジェクション攻撃
- クロスサイトスクリプティング（XSS）
- ボット攻撃
- DDoS 攻撃
- 悪意のある IP アドレスからのアクセス

## Web ACL（Web Access Control List）

### 1. 概要

- WAF の中心となる設定コンポーネント
- ルールの集合体
- リクエストの評価と処理を制御

### 2. ルールの種類

- **Allow ルール**: リクエストを許可
- **Block ルール**: リクエストをブロック
- **Count ルール**: リクエストをカウントのみ

### 3. ルールの優先順位

- 数値が小さいほど優先度が高い
- 最初にマッチしたルールが適用される

## 地理的な一致条件

### 1. 機能

- リクエストの発信元国を判定
- 特定の国からのアクセスを制限
- コンプライアンス要件への対応

### 2. 使用例

- 特定の国からのアクセスをブロック
- 国内からのみアクセスを許可
- 地域別のコンテンツ配信

## ステージ（デプロイメント段階）

### 1. 開発段階

- テスト環境でのルール検証
- 誤検知の確認
- パフォーマンスへの影響測定

### 2. 本番段階

- 実際のトラフィックでの保護
- リアルタイムでの監視
- 必要に応じたルール調整

## 主要な保護機能

### 1. AWS 管理ルール

- AWS が提供する事前定義されたルール
- 一般的な攻撃パターンを検出
- 定期的な更新

### 2. カスタムルール

- アプリケーション固有の要件に対応
- 独自の条件設定
- 柔軟な保護戦略

### 3. レート制限

- 特定の IP アドレスからの過度なリクエストを制限
- API の濫用防止
- サーバーリソースの保護

## 統合サービス

### 1. CloudFront

- CDN のエッジロケーションで保護
- グローバルな保護
- 低レイテンシー

### 2. Application Load Balancer

- ロードバランサーレベルでの保護
- アプリケーション層でのフィルタリング
- バックエンドサーバーの保護

### 3. API Gateway

- API エンドポイントの保護
- RESTful API のセキュリティ
- マイクロサービスアーキテクチャでの活用

## 監視とログ

### 1. CloudWatch メトリクス

- ブロックされたリクエスト数
- 許可されたリクエスト数
- ルール別の統計情報

### 2. ログの有効化

- 詳細なリクエスト情報の記録
- セキュリティインシデントの分析
- トラブルシューティング

## 実際の使用例

### 1. EC サイトの保護

- 不正な購入試行の防止
- ボットによる在庫確認の制限
- 決済情報の保護

### 2. 企業 Web サイト

- 悪意のあるスキャンの防止
- 機密情報への不正アクセス防止
- ブランド保護

### 3. API サービス

- API の濫用防止
- レート制限の実装
- 不正なデータアクセスの防止

## 設定のベストプラクティス

### 1. 段階的な導入

- まずは Count ルールでテスト
- 誤検知の確認
- 徐々に Block ルールに移行

### 2. 定期的な見直し

- ログの分析
- ルールの最適化
- 新しい脅威への対応

### 3. パフォーマンスの考慮

- ルール数の最適化
- 複雑な条件の避ける
- キャッシュの活用

## コスト

### 1. 料金体系

- Web ACL の料金
- ルールの料金
- リクエスト数の料金

### 2. コスト最適化

- 必要なルールのみ設定
- 定期的な使用量の確認
- 不要なルールの削除

## まとめ

AWS WAF は、ウェブアプリケーションのセキュリティを大幅に向上させる重要なサービスです。適切に設定することで、様々な攻撃からアプリケーションを保護できます。段階的な導入と定期的な見直しが成功の鍵となります。
