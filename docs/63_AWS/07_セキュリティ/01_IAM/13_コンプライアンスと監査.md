# コンプライアンスと監査

## 概要

このドキュメントでは、IAMのコンプライアンス要件と監査手順について説明します。各種規制要件への対応方法、監査の実施手順、レポート作成方法などを包括的にカバーします。

## 主要なコンプライアンスフレームワーク

### 1. SOC 2 Type II

#### 要件
```
- 可用性（Availability）
- 機密性（Confidentiality）
- 処理の整合性（Processing Integrity）
- プライバシー（Privacy）
- セキュリティ（Security）
```

#### IAMでの対応
```bash
# アクセス制御の実装
aws iam update-account-password-policy \
    --minimum-password-length 12 \
    --require-symbols \
    --require-numbers \
    --require-uppercase-characters \
    --require-lowercase-characters \
    --max-password-age 90 \
    --password-reuse-prevention 5

# MFAの強制
aws iam create-virtual-mfa-device \
    --virtual-mfa-device-name company-mfa \
    --outfile mfa-setup.png \
    --bootstrap-method QRCodePNG
```

#### 監査証跡の確保
```bash
# CloudTrailの設定
aws cloudtrail create-trail \
    --name SOC2AuditTrail \
    --s3-bucket-name soc2-audit-logs \
    --include-global-service-events \
    --is-multi-region-trail \
    --enable-log-file-validation \
    --kms-key-id alias/aws/cloudtrail

# ログの長期保存
aws s3api put-bucket-lifecycle-configuration \
    --bucket soc2-audit-logs \
    --lifecycle-configuration '{
        "Rules": [
            {
                "ID": "ArchiveOldLogs",
                "Status": "Enabled",
                "Transitions": [
                    {
                        "Days": 30,
                        "StorageClass": "STANDARD_IA"
                    },
                    {
                        "Days": 90,
                        "StorageClass": "GLACIER"
                    }
                ]
            }
        ]
    }'
```

### 3. PCI DSS

#### 要件
```
- 強力なアクセス制御
- 定期的なセキュリティテスト
- セキュリティポリシーの維持
- データの保護
```

#### IAMでの対応
```bash
# PCI DSS準拠のパスワードポリシー
aws iam update-account-password-policy \
    --minimum-password-length 16 \
    --require-symbols \
    --require-numbers \
    --require-uppercase-characters \
    --require-lowercase-characters \
    --max-password-age 30 \
    --password-reuse-prevention 10 \
    --hard-expiry

    {
      "Effect": "Allow",

        "s3:GetObject"

        "Bool": {
          "aws:MultiFactorAuthPresent": "true"

        "StringEquals": {

```

#### 監査手順の実行
```bash
# 1. ユーザー管理の監査
aws iam list-users --query 'Users[*].[UserName,CreateDate,PasswordLastUsed]' --output table

# 2. アクセスキーの監査
aws iam list-access-keys --user-name john-doe --query 'AccessKeyMetadata[*].[AccessKeyId,Status,CreateDate]' --output table

# 3. ポリシーの監査
aws iam list-policies --scope Local --query 'Policies[*].[PolicyName,Arn,CreateDate]' --output table

# 4. グループの監査
aws iam list-groups --query 'Groups[*].[GroupName,CreateDate]' --output table

# 5. ロールの監査
aws iam list-roles --query 'Roles[*].[RoleName,CreateDate,MaxSessionDuration]' --output table
```

#### 監査レポートの生成
```python
import boto3
import json
from datetime import datetime

def generate_audit_report():
    iam = boto3.client('iam')
    cloudtrail = boto3.client('cloudtrail')
    
    report = {
        'audit_date': datetime.now().isoformat(),
        'scope': 'IAM Configuration and Access Control',
        'findings': [],
        'recommendations': []
    }
    
    # ユーザー管理の監査
    users = iam.list_users()
    for user in users['Users']:
        # MFAの確認
        mfa_devices = iam.list_mfa_devices(UserName=user['UserName'])
        if not mfa_devices['MFADevices']:
            report['findings'].append({
                'type': 'Security Risk',
                'description': f"User {user['UserName']} does not have MFA enabled",
                'severity': 'High'
            })
        
        # アクセスキーの確認
        access_keys = iam.list_access_keys(UserName=user['UserName'])
        for key in access_keys['AccessKeyMetadata']:
            if key['Status'] == 'Active':
                # アクセスキーの使用状況確認
                last_used = iam.get_access_key_last_used(AccessKeyId=key['AccessKeyId'])
                if 'LastUsedDate' not in last_used['AccessKeyLastUsed']:
                    report['findings'].append({
                        'type': 'Unused Resource',
                        'description': f"Access key {key['AccessKeyId']} has never been used",
                        'severity': 'Medium'
                    })
    
    # 推奨事項の生成
    report['recommendations'] = [
        'Enable MFA for all users',
        'Remove unused access keys',
        'Implement regular access reviews',
        'Enhance monitoring and alerting'
    ]
    
    return report
```

### 2. セキュリティレポート

#### 月次セキュリティレポート
```python
def generate_monthly_security_report():
    iam = boto3.client('iam')
    cloudtrail = boto3.client('cloudtrail')
    
    report = {
        'report_period': '2024-01-01 to 2024-01-31',
        'executive_summary': {
            'total_users': len(iam.list_users()['Users']),
            'mfa_enabled_users': 0,
            'active_access_keys': 0,
            'policy_changes': 0,
            'failed_logins': 0
        },
        'detailed_findings': [],
        'recommendations': []
    }
    
    # MFA有効ユーザーの確認
    users = iam.list_users()
    for user in users['Users']:
        mfa_devices = iam.list_mfa_devices(UserName=user['UserName'])
        if mfa_devices['MFADevices']:
            report['executive_summary']['mfa_enabled_users'] += 1
    
    # アクティブなアクセスキーの確認
    for user in users['Users']:
        access_keys = iam.list_access_keys(UserName=user['UserName'])
        for key in access_keys['AccessKeyMetadata']:
            if key['Status'] == 'Active':
                report['executive_summary']['active_access_keys'] += 1
    
    return report
```
