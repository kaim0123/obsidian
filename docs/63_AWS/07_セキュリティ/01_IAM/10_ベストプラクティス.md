# IAMベストプラクティス

## 概要

IAMのベストプラクティスは、AWS環境のセキュリティを最大化し、運用効率を向上させるための重要な指針です。このドキュメントでは、IAMの設計、実装、運用におけるベストプラクティスを包括的に説明します。

## セキュリティの基本原則

### 1. 最小権限の原則

#### 基本概念
```
原則: ユーザーやロールには、業務に必要最小限の権限のみを付与する
目的: セキュリティリスクの最小化とインシデントの影響範囲の限定
```

#### 実装方法
```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::specific-bucket/specific-folder/*"
    }
  ]
}
```

#### チェックリスト
```
✅ 各ユーザーの業務内容を明確に定義
✅ 必要最小限の権限を特定
✅ 定期的な権限の見直し
✅ 未使用権限の削除
```

### 2. 多要素認証（MFA）の強制

#### MFAの重要性
```
目的: 認証情報の漏洩による不正アクセスを防止
対象: すべてのユーザー（特に管理者権限を持つユーザー）
```

#### 実装方法
```bash
# ユーザーにMFAデバイスを設定
aws iam create-virtual-mfa-device \
    --virtual-mfa-device-name john-doe-mfa \
    --outfile QRCode.png \
    --bootstrap-method QRCodePNG

# MFAデバイスを有効化
aws iam enable-mfa-device \
    --user-name john-doe \
    --serial-number arn:aws:iam::123456789012:mfa/john-doe-mfa \
    --authentication-code1 123456 \
    --authentication-code2 789012
```

#### 条件付きMFA要求
```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": "s3:DeleteObject",
      "Resource": "*",
      "Condition": {
        "Bool": {
          "aws:MultiFactorAuthPresent": "true"
        }
      }
    }
  ]
}
```

import boto3
from datetime import datetime, timedelta

def detect_anomalous_access():
    cloudtrail = boto3.client('cloudtrail')
    
    # 過去24時間のアクセスを分析
    end_time = datetime.now()
    start_time = end_time - timedelta(hours=24)
    
    response = cloudtrail.lookup_events(
        LookupAttributes=[
            {
                'AttributeKey': 'EventName',
                'AttributeValue': 'AssumeRole'
            }
        ],
        StartTime=start_time,
        EndTime=end_time

    # 異常なアクセスパターンを検出
    suspicious_events = []
    for event in response['Events']:
        if is_suspicious_event(event):
            suspicious_events.append(event)
    
    return suspicious_events

### 2. アクセスキーのローテーション

#### 自動ローテーションの実装
```python
import boto3
from datetime import datetime, timedelta

def rotate_access_keys():
    iam = boto3.client('iam')
    
    # 90日以上古いアクセスキーを特定
    cutoff_date = datetime.now() - timedelta(days=90)
    
    users = iam.list_users()
    for user in users['Users']:
        access_keys = iam.list_access_keys(UserName=user['UserName'])
        
        for key in access_keys['AccessKeyMetadata']:
            if key['CreateDate'].replace(tzinfo=None) < cutoff_date:
                # 新しいアクセスキーを作成
                new_key = iam.create_access_key(UserName=user['UserName'])
                
                # 古いアクセスキーを無効化
                iam.update_access_key(
                    UserName=user['UserName'],
                    AccessKeyId=key['AccessKeyId'],
                    Status='Inactive'
                )
                
                # 古いアクセスキーを削除
                iam.delete_access_key(
                    UserName=user['UserName'],
                    AccessKeyId=key['AccessKeyId']
                )
```

### 2. フォレンジック分析

#### ログ分析の実施
```python
import boto3
from datetime import datetime, timedelta

def forensic_analysis(user_name, start_time, end_time):
    cloudtrail = boto3.client('cloudtrail')
    
    # ユーザーのアクティビティを分析
    response = cloudtrail.lookup_events(
        LookupAttributes=[
            {
                'AttributeKey': 'Username',
                'AttributeValue': user_name
            }
        ],
        StartTime=start_time,
        EndTime=end_time
    )
    
    # アクティビティの分析
    activities = []
    for event in response['Events']:
        activities.append({
            'time': event['EventTime'],
            'action': event['EventName'],
            'source_ip': event['SourceIPAddress'],
            'user_agent': event.get('UserAgent', 'N/A')
        })
    
    return activities
```
