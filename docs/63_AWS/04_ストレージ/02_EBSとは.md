# EBS とは

## 概要

EBS（Elastic Block Store）は、EC2 インスタンス用の仮想ブロックストレージサービスです。永続的なストレージボリュームを提供し、データベース、ファイルシステム、アプリケーションのデータ保存などに使用されます。

## 主な機能

### 1. 仮想ブロックストレージサービス

- EC2 インスタンス用の永続ストレージ
- ブロックレベルのストレージ
- 高い可用性と耐久性
- 動的なサイズ変更

### 2. 永続性

- インスタンスの停止後もデータ保持
- スナップショットによるバックアップ
- 複数 AZ でのレプリケーション
- データの保護

## ボリュームタイプ

### 1. 汎用 SSD（gp3）

- バランスの取れた性能
- コスト効率が良い
- 幅広い用途に適している
- 最新の汎用 SSD

#### 汎用 SSD の特徴

- **ベースライン性能**: 3,000 IOPS、125 MiB/s
- **バースト性能**: 最大 16,000 IOPS
- **サイズ**: 1 GiB〜16 TiB
- **料金**: 容量と IOPS に基づく

### 2. 汎用 SSD（gp2）

- 従来の汎用 SSD
- 容量に比例した性能
- 安定した性能
- 広く使用されている

#### gp2 の特徴

- **ベースライン性能**: 容量の 3 倍の IOPS
- **最大性能**: 16,000 IOPS
- **サイズ**: 1 GiB〜16 TiB
- **バースト**: 3,000 IOPS のバースト

### 3. Provisioned IOPS SSD（io2）

- 高 IOPS が必要なアプリケーション
- 予測可能な性能
- 低レイテンシー
- データベースに最適

#### io2 の特徴

- **IOPS**: 100〜64,000 IOPS
- **スループット**: 最大 1,000 MiB/s
- **サイズ**: 4 GiB〜16 TiB
- **耐久性**: 99.999%の可用性

### 4. Provisioned IOPS SSD（io1）

- 従来の高 IOPS SSD
- カスタマイズ可能な性能
- 高いスループット
- エンタープライズ用途

#### io1 の特徴

- **IOPS**: 100〜64,000 IOPS
- **スループット**: 最大 1,000 MiB/s
- **サイズ**: 4 GiB〜16 TiB
- **比率**: IOPS/GB 比率最大 50:1

### 5. スループット最適化 HDD（st1）

- 大容量データの処理
- 高いスループット
- コスト効率が良い
- ビッグデータ分析

#### st1 の特徴

- **スループット**: 最大 500 MiB/s
- **IOPS**: 最大 500 IOPS
- **サイズ**: 500 GiB〜16 TiB
- **用途**: ログ処理、データウェアハウス

### 6. Cold HDD（sc1）

- アクセス頻度の低いデータ
- 最も低いコスト
- 大容量ストレージ
- アーカイブ用途

#### sc1 の特徴

- **スループット**: 最大 250 MiB/s
- **IOPS**: 最大 250 IOPS
- **サイズ**: 500 GiB〜16 TiB
- **用途**: コールドデータ、バックアップ

## まとめ

EBS は、EC2 インスタンスに永続的なストレージを提供する重要なサービスです。様々なボリュームタイプから選択でき、用途に応じて最適な性能とコスト効率を実現できます。適切な設計と管理により、高可用性でセキュアなストレージ環境を構築できます。
