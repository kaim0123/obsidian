# EFS とは

## 概要

EFS（Elastic File System）は、複数の EC2 インスタンスから同時にアクセスできる仮想ファイルストレージサービスです。NFS（Network File System）プロトコルを使用し、共有ファイルシステムとして機能します。

## 主な機能

### 1. 仮想ファイルストレージサービス

- 複数インスタンスからの同時アクセス
- NFS プロトコルのサポート
- 自動スケーリング
- フルマネージドサービス

### 2. 共有ファイルシステム

- 複数の EC2 インスタンスで共有
- 同時読み書きが可能
- 一貫性のあるデータアクセス
- 高可用性

## 主要機能

### 1. マルチアタッチ機能

- 複数の EC2 インスタンスから同時マウント
- 共有ファイルシステム
- 同時読み書き
- 一貫性の保証

#### マルチアタッチの特徴

- **同時アクセス**: 複数インスタンスからの同時アクセス
- **一貫性**: 強整合性の保証
- **スケーラビリティ**: 数千のインスタンスからアクセス可能
- **可用性**: マルチ AZ での冗長化

### 2. スナップショット

- ファイルシステムの時点バックアップ
- 増分バックアップ
- クロスリージョンコピー
- 復旧機能

#### スナップショットの特徴

- **自動バックアップ**: 定期的な自動バックアップ
- **手動バックアップ**: 必要に応じた手動バックアップ
- **増分**: 変更された部分のみバックアップ
- **復旧**: 任意の時点への復旧

### 3. ストレージクラス

- 標準ストレージクラス
- インフリクエントアクセス（IA）
- コスト最適化
- 自動的なクラス変更

#### ストレージクラスの特徴

- **標準**: 頻繁にアクセスされるデータ
- **IA**: アクセス頻度の低いデータ
- **自動移行**: アクセスパターンに基づく自動移行
- **コスト最適化**: 使用量に応じた最適化

### 4. マウントターゲット

- サブネット内でのマウントポイント
- セキュリティグループでの制御
- ネットワークアクセスの管理
- 可用性ゾーンごとの配置

#### マウントターゲットの特徴

- **ネットワークアクセス**: サブネットからのアクセス制御
- **セキュリティ**: セキュリティグループでの制御
- **可用性**: マルチ AZ での冗長化
- **パフォーマンス**: ネットワーク最適化

## パフォーマンスモード

### 1. 汎用パフォーマンス

- 一般的な用途に最適
- 低レイテンシー
- 高い IOPS
- 幅広いワークロードに対応

### 2. 最大 I/O パフォーマンス

- 高スループットが必要な用途
- 高い並列性
- ビッグデータ分析
- メディア処理

## スループットモード

### 1. バーストスループット

- ベースライン性能
- バースト性能
- コスト効率が良い
- 一般的な用途

### 2. プロビジョンドスループット

- 予測可能な性能
- カスタマイズ可能
- 高スループット要件
- エンタープライズ用途

## まとめ

EFS は、複数の EC2 インスタンスから同時にアクセスできる共有ファイルシステムサービスです。NFS プロトコルを使用し、高可用性とスケーラビリティを提供します。適切な設計と設定により、効率的でセキュアな共有ストレージ環境を構築できます。
