# 開発環境セットアップ

## 概要
このガイドでは、サーバーレスアプリケーション開発に必要な環境構築を行います。AI（Cursor）を最大限活用するための設定も含みます。

## 開発環境の選択肢

### オプション1: ローカル開発（推奨初心者向け）
```
メリット:
✅ インターネット接続不要で開発可能
✅ 高速な開発サイクル
✅ コスト不要

デメリット:
⚠️ AWSサービスの完全な再現は困難
⚠️ 環境差異によるバグの可能性
```

### オプション2: EC2開発環境（推奨中級者向け）
```
メリット:
✅ 実際のAWS環境で開発
✅ VPC内のリソースに直接アクセス
✅ Cursorでリモート開発可能
✅ チーム共有が容易

デメリット:
⚠️ EC2の費用が発生（t3.medium程度で月$30〜）
⚠️ 初期セットアップがやや複雑
```

### オプション3: AWS Cloud9（推奨AWS初心者向け）
```
メリット:
✅ ブラウザベース
✅ IAMロールが自動設定
✅ 即座に開発開始可能

デメリット:
⚠️ Cursorは使用不可
⚠️ カスタマイズ性が低い
```

## 前提条件

### 1. AWSアカウント
- AWSアカウントの作成済み
- IAMユーザーまたはIAM Identity Centerユーザーの作成
- 適切な権限の付与

### 2. 必要な権限
```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "lambda:*",
        "apigateway:*",
        "dynamodb:*",
        "rds:*",
        "s3:*",
        "cloudformation:*",
        "iam:*",
        "logs:*",
        "ec2:*"
      ],
      "Resource": "*"
    }
  ]
}
```

**注意**: 本番環境では最小権限の原則に従ってください。

## セットアップ手順

## A. ローカル開発環境のセットアップ

### ステップ1: AWS CLIのインストール

#### Windows
```powershell
# MSIインストーラーをダウンロード
# https://awscli.amazonaws.com/AWSCLIV2.msi

# またはwingetで
winget install Amazon.AWSCLI
```

#### macOS
```bash
# Homebrewで
brew install awscli

# または公式インストーラー
curl "https://awscli.amazonaws.com/AWSCLIV2.pkg" -o "AWSCLIV2.pkg"
sudo installer -pkg AWSCLIV2.pkg -target /
```

#### Linux
```bash
curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o "awscliv2.zip"
unzip awscliv2.zip
sudo ./aws/install
```

#### 確認
```bash
aws --version
# 出力例: aws-cli/2.x.x Python/3.x.x Linux/x86_64
```

### ステップ2: AWS認証情報の設定

#### 方法1: aws configure（シンプル）
```bash
aws configure

# 入力プロンプト:
AWS Access Key ID [None]: AKIAIOSFODNN7EXAMPLE
AWS Secret Access Key [None]: wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY
Default region name [None]: ap-northeast-1
Default output format [None]: json
```

#### 方法2: 認証情報ファイルの直接編集
```bash
# Windows
notepad %USERPROFILE%\.aws\credentials

# macOS/Linux
nano ~/.aws/credentials
```

**credentials ファイル**:
```ini
[default]
aws_access_key_id = AKIAIOSFODNN7EXAMPLE
aws_secret_access_key = wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY

[dev-profile]
aws_access_key_id = AKIAI44QH8DHBEXAMPLE
aws_secret_access_key = je7MtGbClwBF/2Zp9Utk/h3yCo8nvbEXAMPLEKEY
```

**config ファイル**:
```ini
[default]
region = ap-northeast-1
output = json

[profile dev-profile]
region = us-west-2
output = json
```

#### 方法3: IAM Identity Center（SSO）
```bash
aws configure sso

# プロンプトに従って入力
SSO start URL [None]: https://my-sso-portal.awsapps.com/start
SSO Region [None]: ap-northeast-1
```

#### 認証確認

### ステップ6: Cursorの設定

#### Cursor拡張機能
1. AWS Toolkit for Visual Studio Code（Cursorでも動作）

3. Python/Node.js 拡張

#### .cursorrules ファイルの作成
プロジェクトルートに以下を作成:

```yaml
# .cursorrules
rules:
  - name: "AWS SAMプロジェクト"
    pattern: "template.yaml"
    description: "SAMテンプレートのベストプラクティスに従う"
    
  - name: "Lambda関数"
    pattern: "**/*function.py"
    context: |
      - Lambdaハンドラー形式に従う
      - 環境変数を使用する
      - ログを構造化する
      - エラーハンドリングを実装する
```

## B. EC2開発環境のセットアップ（Cursor SSH接続）

### ステップ1: EC2インスタンスの起動

#### 1. AWSマネジメントコンソールから
```
1. EC2 → インスタンスを起動
2. 設定:
   - 名前: serverless-dev-env
   - AMI: Amazon Linux 2023（または Ubuntu 22.04）
   - インスタンスタイプ: t3.medium（2vCPU, 4GB RAM）
   - キーペア: 新規作成または既存選択
   - ネットワーク設定:
     - VPC: デフォルトまたはカスタムVPC
     - パブリックIPの自動割り当て: 有効
     - セキュリティグループ:
       - SSH (22): 自分のIPのみ
   - ストレージ: 30GB gp3
```

#### 2. IAMロールのアタッチ
```
EC2 → インスタンス → アクション → セキュリティ → IAMロールを変更

必要な権限:
- Lambda: フル
- API Gateway: フル
- RDS: フル
- DynamoDB: フル
- S3: フル
- CloudFormation: フル
```

#### IAMロールの作成例
```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "lambda:*",
        "apigateway:*",
        "rds:*",
        "dynamodb:*",
        "s3:*",
        "cloudformation:*",
        "logs:*",
        "ec2:Describe*",
        "iam:PassRole",
        "iam:GetRole"
      ],
      "Resource": "*"
    }
  ]
}
```

### ステップ2: EC2への初期セットアップ

#### SSHで接続
```bash
# Windows（PowerShell）
ssh -i "path\to\your-key.pem" ec2-user@ec2-xx-xx-xx-xx.ap-northeast-1.compute.amazonaws.com

# macOS/Linux
chmod 400 your-key.pem
ssh -i your-key.pem ec2-user@ec2-xx-xx-xx-xx.ap-northeast-1.compute.amazonaws.com
```

#### Amazon Linux 2023の場合
```bash
# システムアップデート
sudo dnf update -y

# 開発ツールのインストール
sudo dnf groupinstall -y "Development Tools"
sudo dnf install -y git vim tmux

# Python 3.11
sudo dnf install -y python3.11 python3.11-pip

# Node.js 18
sudo dnf install -y nodejs npm

# Docker
sudo dnf install -y docker
sudo systemctl start docker
sudo systemctl enable docker
sudo usermod -aG docker ec2-user

# AWS CLI（プリインストール済みだが最新化）
pip3.11 install --upgrade awscli

# SAM CLI
pip3.11 install aws-sam-cli

# ログアウトして再ログイン（Dockerグループ反映）
exit
```

#### Ubuntu 22.04の場合
```bash
# システムアップデート
sudo apt update && sudo apt upgrade -y

# 開発ツール
sudo apt install -y build-essential git vim tmux curl wget

# Python 3.11
sudo apt install -y python3.11 python3.11-venv python3-pip

# Node.js 18
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt install -y nodejs

# Docker
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh
sudo usermod -aG docker ubuntu

# AWS CLI
curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o "awscliv2.zip"
unzip awscliv2.zip
sudo ./aws/install

# SAM CLI
pip3 install aws-sam-cli
```

### ステップ3: CursorでSSH接続設定

#### 1. ローカルのSSH設定
Windows: `C:\Users\YourName\.ssh\config`
macOS/Linux: `~/.ssh/config`

```
Host serverless-dev
    HostName ec2-xx-xx-xx-xx.ap-northeast-1.compute.amazonaws.com
    User ec2-user
    IdentityFile C:\path\to\your-key.pem
    ForwardAgent yes
    ServerAliveInterval 60
    ServerAliveCountMax 3
```

#### 2. Cursorでリモート接続

```
方法1: コマンドパレット
1. Ctrl+Shift+P（Mac: Cmd+Shift+P）
2. "Remote-SSH: Connect to Host..." を選択
3. "serverless-dev" を選択

方法2: 左下のリモートアイコン
1. 左下の「><」アイコンをクリック
2. "Connect to Host..." を選択
3. "serverless-dev" を選択
```

#### 3. リモート環境でのCursor設定

接続後、リモートに拡張機能をインストール:
- Python
- AWS Toolkit
- YAML
- GitLens

### ステップ5: ローカルテスト

#### Lambda関数のローカル実行
```bash
# 関数をローカルで起動
sam local start-api

# 別のターミナルでテスト
curl http://127.0.0.1:3000/hello

# 特定のイベントでテスト

```

#### API Gatewayのローカルエミュレーション


## C. 開発ワークフロー

### 1. 日常的な開発サイクル


```yaml
project_context: |
  これはAWSサーバーレスアプリケーションプロジェクトです。

  - AWS Lambda (Python 3.11)
  - API Gateway (REST API)
```

## E. トラブルシューティング

### よくある問題

#### 1. SAM CLIが動作しない
```bash
# Python環境の確認
which python3
python3 --version

# SAMの再インストール
pip3 uninstall aws-sam-cli
pip3 install aws-sam-cli --user

# パスの確認
echo $PATH
```

#### 2. Dockerが起動しない
```bash
# Windows: Docker Desktopが起動しているか確認

# Linux: サービス起動
sudo systemctl start docker
sudo systemctl status docker
```

#### 3. SSH接続ができない
```bash
# キーのパーミッション
chmod 400 your-key.pem

# セキュリティグループ確認
# 自分のIPからポート22が許可されているか

# 接続テスト
ssh -vvv -i your-key.pem ec2-user@your-ec2-ip
```

#### 4. IAM権限エラー
```bash
# 現在の認証情報を確認
aws sts get-caller-identity

# IAMロール/ポリシーの確認
aws iam get-user
aws iam list-attached-user-policies --user-name YourUser
```
