# CloudTrail とは

## 概要

CloudTrail は、AWS アカウント内で実行された API 呼び出しを記録・追跡する API 動作追跡サービスです。誰が、いつ、どこで、何をしたかを詳細に記録し、セキュリティ監査、コンプライアンス、運用分析を支援します。

## 主な機能

### 1. API 動作追跡サービス

- API 呼び出しの記録
- ユーザーアクティビティの追跡
- リソース変更の記録
- セキュリティ監査の支援

### 2. 包括的なログ記録

- 管理イベントの記録
- データイベントの記録
- インサイトイベントの記録
- カスタムイベントの記録

## イベントの種類

### 1. 管理イベント

- リソースの作成・変更・削除
- 設定の変更
- 権限の変更
- アカウント設定の変更

#### 管理イベントの例

- **EC2**: インスタンスの起動・停止・削除
- **S3**: バケットの作成・削除・設定変更
- **IAM**: ユーザー・ロール・ポリシーの変更
- **RDS**: データベースの作成・削除・設定変更

### 2. データイベント

- データの読み取り・書き込み
- オブジェクトレベルの操作
- データアクセスの記録
- 詳細なアクティビティログ

#### データイベントの例

- **S3**: オブジェクトの読み取り・書き込み・削除
- **Lambda**: 関数の実行
- **DynamoDB**: アイテムの読み取り・書き込み
- **SNS**: メッセージの送信

### 3. インサイトイベント

- 異常なアクティビティの検知
- 機械学習による分析
- セキュリティ脅威の検知
- 自動的なアラート

## S3 ログ保存

### 1. ログファイルの保存

- S3 バケットへの自動保存
- 圧縮されたログファイル
- 定期的なファイル生成
- 長期保存

#### S3 ログ保存の特徴

- **自動保存**: ログの自動的な S3 保存
- **圧縮**: gzip 圧縮による効率的な保存
- **分割**: 時間・サイズによるファイル分割
- **暗号化**: ログファイルの暗号化

### 2. ログファイルの構造

- JSON 形式のログ
- 構造化されたデータ
- 検索可能な形式
- 分析に適した形式

## まとめ

CloudTrail は、AWS 環境の監査とセキュリティを支える重要なサービスです。API 呼び出しの詳細な記録により、セキュリティ監査、コンプライアンス、運用分析を支援します。適切な設定と運用により、セキュアで透明性の高い AWS 環境を構築できます。
