## 重要なポイント

### 監視の基本
- **CloudWatch**: メトリクス、ログ、アラームの統合監視
- **Systems Manager**: インスタンスの管理とパッチ適用
- **X-Ray**: 分散トレーシング（開発者ツール）

### 組織管理
- **Organizations**: マルチアカウント環境の統合管理
- **Control Tower**: ガバナンスの自動化とセキュリティベースライン
- **SCP**: サービス制御ポリシーによる権限制限

### 監査とコンプライアンス
- **CloudTrail**: API呼び出しの完全な監査ログ
- **AWS Config**: 設定の継続的監視とコンプライアンス評価
- **Security Hub**: セキュリティの統合管理
