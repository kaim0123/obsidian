# AWS Config とは

## 概要

AWS Config は、AWS リソースの構成変更を追跡・管理する構成変更追跡管理サービスです。リソースの設定変更を継続的に監視し、コンプライアンスの確保、セキュリティの強化、運用の改善を支援します。

## 主な機能

### 1. 構成変更追跡管理サービス

- リソース構成の継続的監視
- 設定変更の記録
- コンプライアンスの評価
- 構成の履歴管理

### 2. 継続的監視

- リアルタイムでの変更検知
- 自動的な評価
- アラートの生成
- レポートの作成

## 主要コンポーネント

### 1. 設定項目（Configuration Items）

- リソースの詳細情報
- 設定のスナップショット
- メタデータの記録
- 関係性の追跡

#### 設定項目の特徴

- **詳細情報**: リソースの完全な設定
- **メタデータ**: 作成日時、変更日時、タグ
- **関係性**: リソース間の依存関係
- **履歴**: 設定変更の履歴

### 2. 設定スナップショット

- 特定時点での設定状態
- 履歴の保存
- 比較分析
- 復旧の支援

### 3. 設定履歴

- 変更の時系列記録
- 変更前後の比較
- 変更者の追跡
- 変更理由の記録

## ルールと評価

### 1. 管理ルール

- 事前定義されたルール
- AWS が提供するルール
- 一般的なベストプラクティス
- セキュリティ要件

#### 管理ルールの例

- **セキュリティ**: セキュリティグループの設定
- **コンプライアンス**: 暗号化の有効化
- **運用**: タグの必須設定
- **コスト**: 未使用リソースの検知

### 2. カスタムルール

- 組織固有のルール
- ビジネス要件に基づくルール
- Lambda 関数による評価
- 柔軟な評価ロジック

#### カスタムルールの特徴

- **柔軟性**: 任意の評価ロジック
- **統合**: Lambda 関数との統合
- **スケーラビリティ**: 大量リソースの評価
- **カスタマイズ**: 組織要件への対応

### 3. 評価結果

- コンプライアンス状態
- 違反の詳細
- 推奨事項
- 修正手順

## まとめ

AWS Config は、AWS リソースの構成管理を支える重要なサービスです。継続的な監視と評価により、セキュリティの強化、コンプライアンスの確保、運用の改善を実現します。適切な設定と運用により、セキュアでコンプライアントな AWS 環境を構築できます。
