# MOC_テストツール

テストツールの使い方の入口。テスト全体の地図は [[MOC_テスト体系]]。「どのテストをどれだけ書くか」は 81、CI で回す品質ゲートの組み方は 86/60_品質ゲート。

## フォルダ構成

| フォルダ | 役割 | 入口 |
|---|---|---|
| 00_全体像 | ツールの役割分担・比較・構成例 | [[01_テストツールの全体像と選び方]] |
| 10_Vitest | テストランナー（Unit / Integration） | [[00_Vitest_目次]] |
| 20_Playwright | E2E テスト | [[00_Playwright_目次]] |
| 30_Testing-Library | UI コンポーネントをユーザー目線で描画・操作する | [[01_Testing Libraryの考え方とセットアップ]] |
| 40_MSW | HTTP / GraphQL のモック | [[01_MSWの仕組みとセットアップ]] |

新しいツールは `50_<ツール名>` のように番号付きフォルダを足す。

### 本拠地の分担

| テーマ | 本拠地 |
|---|---|
| ツールの使い方・API・設定 | **83_テストツール（ここ）** |
| React での Testing Library 入門・フォームの実例 | 32_React/17_テスト（[[13-2-Testing-Libraryの基本]]、[[13-4-フォーム-非同期のテスト]]） |

| ビジュアル回帰・a11y・Lighthouse の CI 組み込み | 86_QAプロセス/60_品質ゲート |

## ツールの選び方

| やりたいこと | ツール | フォルダ |
|---|---|---|
| 関数・フックのロジックのテスト | Vitest | 10_Vitest |
| コンポーネントを描画して操作するテスト | Vitest + Testing Library | 10 + 30 |
| API を呼ぶ画面のテスト | Vitest + Testing Library + MSW | 10 + 30 + 40 |
| ブラウザを動かす E2E テスト・ビジュアル回帰 | Playwright | 20_Playwright |

詳しい比較（Vitest と Jest、Playwright と Cypress、jsdom と happy-dom）は [[01_テストツールの全体像と選び方]]。
