## Playwright E2Eテストでよく出るエラーと対処メモ

### 1. 存在しない matcher を使ってしまう

- **症状**: `Property 'toHaveCountGreaterThan' not found` などのエラー。
- **原因**: Jest など別ツールの matcher 名をそのまま使ってしまい、Playwright には存在しない。
- **対処**:
  - `locator.count()` を使って数値を取得し、`toBeGreaterThan` などの数値用 matcher で確認する。

```ts
const rows = page.locator('table tbody tr');
const rowCount = await rows.count();
expect(rowCount).toBeGreaterThan(0);
```

---

### 2. データ件数を決め打ちしたテスト（0件の環境で落ちる）

- **症状**: `expect(rowCount).toBeGreaterThan(0)` のようなアサーションが、テスト環境でデータ0件のため失敗する。
- **原因**: 「一覧が表示される」ことを確認したいだけなのに、「1件以上ある」ことまで前提にしている。
- **対処**:
  - 「テーブルが表示されていること」「ヘッダーが表示されていること」など、UI構造にフォーカスしたアサーションにする。

```ts
const table = page.locator('table');
await expect(table).toBeVisible();
```

---

### 3. 画面のカラム名／DOM構造の想定ズレ

- **症状**: `取引先名 カラムが表示されていること` などのメッセージでアサーション失敗。実際の画面には `会社名・代表者名` など別のラベルが表示されている。
- **原因**:
  - 実装側のカラム名や構造（`<thead>` が無く、`role="columnheader"` のみ）が、テストの想定と違っている。
- **対処**:
  - Playwright のスナップショット（`error-context.md`）やブラウザの DevTools で、実際のラベル・ロール属性を確認してから locator を決める。
  - カラムは `getByRole('columnheader', { name: '実際のラベル' })` のように role ベースで取得する。

```ts
const columns = [
  '会社名・代表者名',
  '取引先ID',
  '会社カテゴリ',
  '工事種類',
  'パートナーシップ',
  'レビュー平均',
];

for (const name of columns) {
  await expect(
    page.getByRole('columnheader', { name }),
    `${name} カラムが表示されていること`
  ).toBeVisible({ timeout: 15000 });
}
```

---

### 4. ページングUIが環境によって存在しない／ラベルが違う

- **症状**: 「次へ」ボタンを探して `expect(hasNext).toBeTruthy()` しているテストが `false` になって失敗する。
- **原因**:
  - 環境によっては 1ページしかなく「次へ」が表示されない。
  - ページングUIが数字や矢印アイコンだけで、「次へ」というラベル自体が存在しない。
- **対処**:
  - ラベルに依存しない locator（`next` / `次` / 矢印 など複数パターン）を試す。
  - それでも見つからない場合は、そのテストケースを **スキップ扱い（早期 return）** にして落ちないようにする。

```ts
// 「次へ」相当のページングボタン（ラベルに依存しない）を探す
const nextButton =
  page.getByRole('button', { name: /次|next/i }).first().or(
    page.getByRole('button', { name: /›|»/ }).first()
  );

const hasNext = await nextButton.isVisible().catch(() => false);

// ページング UI が存在しない環境では、このテストは実質スキップ扱いにする
if (!hasNext) {
  console.warn('次ページへのボタンが見つからなかったため、ページングテストをスキップしました。');
  return;
}
```
