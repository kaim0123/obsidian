## 前提知識

- **JavaScript / TypeScript の基礎**（変数、関数、モジュール、Promise 程度）があると理解しやすいです。
- **Node.js** が未導入の場合は、01 章でインストール手順を説明します。
- **npm もしくは pnpm / yarn** の基本操作（`install` / `run`）がわかると進めやすいです。
- 既に **Jest** を使ったことがある人は、API がほぼ互換なので、差分だけを拾い読みする学び方もおすすめです。

---

## 学習の進め方

1. **01 章**で Vitest をインストールし、`npm test` が通る状態まで確認する。
2. **02 章**で最初のテストファイルを書き、「成功」と「失敗」の出力を読み取れるようにする。
3. **03 章**で `expect` の各マッチャーを押さえ、テストが何を保証しているのかを明確にする。
4. **04〜05 章**で「外部依存を持つコード」をテストするためのモック・タイマー操作を習得する。
5. **06 章**でカバレッジを確認し、Vitest UI やブラウザモードの使い勝手を試す。
6. **07〜08 章**で実務に近い設計・CI 運用に広げる。

## Vitest 全体像（イメージ）

```
┌────────────────────────────────────────────┐
│               テストファイル                │
│   *.test.ts / *.spec.ts （describe/it）    │
└────────────────────────────────────────────┘
                    │
                    ▼
┌────────────────────────────────────────────┐
│               Vitest ランナー               │
│   Vite の変換パイプライン（ESM / TS / JSX） │
│   並列ワーカー / ウォッチモード / HMR       │
└────────────────────────────────────────────┘
           │                 │
           ▼                 ▼
   ┌─────────────┐    ┌──────────────┐
   │ node 環境    │    │ jsdom / happy-dom │
   │（デフォルト）│    │ / browser mode    │
   └─────────────┘    └──────────────┘
```

Vitest は **Vite の仕組みをそのまま使う**のが最大の特徴で、TypeScript・ESM・JSX の変換設定を別で持たなくても動きます。
