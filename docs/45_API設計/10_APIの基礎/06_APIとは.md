## 1. APIの定義と役割

API（Application Programming Interface）は、「アプリケーション同士が機能やデータをやりとりするための"窓口"や"約束事"」です。プログラム同士が安全かつ効率的に連携するための"インターフェース"を指します。

- **インターフェース**：利用者（クライアント）が提供者（サーバーやライブラリ）に「どんな機能が、どんな方法で使えるか」を明示する契約
- **カプセル化**：内部実装を隠し、外部からは決められた方法でのみ操作できる

---

## 2. APIの種類と実例

### Web API
- HTTP経由でネットワーク越しにやりとりするAPI
- 例：天気予報アプリが気象データAPIから天気情報を取得
- 例：WebアプリがGoogle Maps APIを使って地図を表示
- 例：ECサイトが決済API（Stripe, PayPal等）で支払い処理

### ライブラリAPI
- プログラム内で関数やクラスを呼び出すAPI
- 例：JavaScriptの`Array.prototype.map()`、Pythonの`os`モジュール

### OS API
- OSの機能（ファイル操作、ネットワーク、プロセス管理など）を利用するためのAPI
- 例：Windows API、POSIX API

---

## 3. APIの設計思想と進化

- **疎結合**：APIを介してやりとりすることで、システム同士が独立して開発・運用できる
- **再利用性**：一度作ったAPIを他のアプリやサービスでも活用できる
- **バージョン管理**：APIの仕様変更時はバージョンを分けて互換性を保つ
- **セキュリティ**：認証・認可・レートリミットなどで安全性を担保

### APIの進化
- Web APIの普及で、外部サービス連携やマイクロサービスアーキテクチャが一般化
- REST、GraphQL、gRPCなど多様なAPI設計手法が登場
- APIファースト開発（API仕様を先に決めてから実装）も主流に

---

APIは現代のソフトウェア開発・サービス連携に不可欠な基盤技術です。
