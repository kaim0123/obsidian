# 付録C　HTTP ステータスコード早見表

Web API でよく使うステータスコードと、選び方の目安です。詳細は [[03_ステータスコード]] を参照。

---

## 2xx　成功

| コード | 名称 | いつ使うか | ボディ |
|--------|------|-----------|--------|
| **200** | OK | GET 成功、PUT/PATCH 成功（更新後リソースを返す） | あり |
| **201** | Created | POST でリソース新規作成成功 | 作成リソース推奨 |
| **204** | No Content | DELETE 成功、更新成功でボディ不要 | なし |

---

## 4xx　クライアントエラー

| コード | 名称 | いつ使うか | 例 |
|--------|------|-----------|-----|
| **400** | Bad Request | JSON 不正、必須欠落、型エラー | 不正な JSON |
| **401** | Unauthorized | 認証情報がない・無効・期限切れ | トークン未送信 |
| **403** | Forbidden | 認証済みだが権限不足 | 他人のリソース削除 |
| **404** | Not Found | リソースが存在しない | `/users/999` |
| **409** | Conflict | 状態競合（重複、同時更新） | メールアドレス重複 |
| **422** | Unprocessable Entity | 形式は正しいがルール違反 | 在庫不足で注文不可 |
| **429** | Too Many Requests | レート制限超過 | 短時間に大量リクエスト |

---

## 5xx　サーバーエラー

| コード | 名称 | いつ使うか | 注意 |
|--------|------|-----------|------|
| **500** | Internal Server Error | 想定外の障害 | 内部詳細を露出しない |
| **502** | Bad Gateway | 上流サービス不良 | ゲートウェイ・BFF で |
| **503** | Service Unavailable | メンテ・過負荷 | `Retry-After` を検討 |

---

## 選び方フロー（簡易）

```text
  リクエスト受信
       │
       ├─ 認証なし／無効 ──→ 401
       ├─ 権限不足 ────────→ 403
       ├─ URL・JSON 形式 NG ─→ 400
       ├─ リソースなし ────→ 404
       ├─ ビジネスルール NG ─→ 422（または 409）
       ├─ 競合 ────────────→ 409
       ├─ レート超過 ──────→ 429
       ├─ 成功（作成） ────→ 201
       ├─ 成功（ボディ不要）→ 204
       ├─ 成功（通常） ────→ 200
       └─ サーバー障害 ────→ 500
```

---

## よくある誤用

| 誤 | 正 |
|----|-----|
| バリデーション失敗に 500 | 400 または 422 |
| 権限不足に 404（隠蔽目的） | 403（ポリシー次第で 404 も可だが一貫して） |
| 一覧が空なのに 404 | 200 + `[]` |
| すべてのエラーに 200 + `{ "success": false }` | HTTP ステータスで結果を伝える |
