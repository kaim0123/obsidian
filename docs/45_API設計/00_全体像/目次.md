# API設計 — 教材目次（初心者向け・ゼロからの全体像）

API設計を**初めて学ぶ人向け**に、HTTP の基礎から REST リソース設計、エラー・認証・運用まで段階的に学べる教科書の章立てです。  
既存ノート（[[00_API設計の概要]]）の **8つの基本テーマ** を土台に、より体系的な**理想のカリキュラム**として整理しています。

> **解説本文**: [[010Programming/45_API設計/00_全体像/00_はじめに|00_はじめに]] から各章へ。2026-09-25 にテーマ別フォルダへ再編（入口は [[MOC_API設計体系]]、章と置き場の対応は MOC の学習順インデックス）。

---

## 学習のすすめ方

1. まず **「API とは何か」** と **HTTP の基本** で通信の仕組みを掴む。
2. 次に **一貫性・REST・HTTP メソッド** で「使いやすい窓口」の形を決める。
3. **エラー・ページネーション・バージョニング・認証** で実務に耐える設計を身につけ、**演習** で手を動かして統合する。

> **前提知識**: Web の基本概念（クライアント・サーバー）と JSON の読み書きができるとスムーズ。設計の階層は [[MOC_ソフトウェア設計体系]] の第1〜2部を読んでいると理解が深まる。

## 設計階層との位置づけ

```text
アーキテクチャ    … 建物全体の構造（システム・サービス・非機能）
    ↓
ソフトウェア設計  … 設計思想とパラダイム（[[MOC_ソフトウェア設計体系]]）
    ↓
モジュール設計    … 部屋の役割分担（[[MOC_モジュール設計体系]]）
    ↓
API設計           … 外部との窓口（本教材）
    ↓
クラス設計        … 家具の配置とつなぎ方（[[010Programming/44_クラス設計・デザインパターン/00_全体像/目次]]）
    ↓
メソッド設計      … 家具の細部（[[010Programming/46_メソッド設計/00_全体像/目次|46_メソッド設計/目次]]）
```

API設計は **「プログラムの外側に向けた契約」** の層であり、モジュールの境界やドメインモデル（[[02_DDDとは]]）と連動しながら、クライアント開発者の体験を決める。
