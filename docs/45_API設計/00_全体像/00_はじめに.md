# API設計 — 教材はじめに

## この教材について

[[010Programming/45_API設計/00_全体像/目次]] に沿った **初心者向け解説** です。29 章 + 付録を、テーマ別の 9 フォルダに分けています。各フォルダには旧トピック別ノートや動画・記事のまとめも並んでいます。

- **対象**: プログラミング基礎はあるが、API 設計を体系的に学んだことがない人
- **目的**: 「使いやすく・長く使える・安全な Web API」を設計できるようになる
- **前提**: Web の基本概念（クライアント・サーバー）と JSON の読み書きができること
- **既存ノートとの関係**: [[00_API設計の概要]] は 8 テーマの要約、本教材はゼロから学ぶ教科書
