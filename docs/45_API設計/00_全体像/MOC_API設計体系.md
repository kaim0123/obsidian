# MOC_API設計体系

45_API設計 の入口ノート。**Web API を「使いやすく・変更しやすく・堅牢に」設計する方法**を扱う。骨格は『Web API: The Good Parts』の流れ（エンドポイント → レスポンス → HTTP を活かす → 変更しやすく → 堅牢に）。そこに Microsoft / Zalando / Google の API ガイドラインの項目（エラー形式・ページネーション・長時間処理・バージョニング）と、roadmap.sh の「API スタイル」（REST / GraphQL / gRPC / Webhook）を加える構成にした。

フォルダは **テーマ別**、教材（旧 教科書/ 第01〜11部・全29章）を読む **学習順** は下の「学習順インデックス」で持つ。旧 `トピック別/` のノートは中身で各フォルダに振り分けた。
