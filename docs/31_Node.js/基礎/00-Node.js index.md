# Node.js & Express 入門

## 目次

### 学習の進め方
この教材は、Node.jsとExpress.jsを使ったWebアプリケーション開発を体系的に学ぶための教科書です。以下の順序で学習することをお勧めします：

1. **Node.jsの基礎** - JavaScriptランタイムの基本概念
2. **開発環境の構築** - Node.jsのインストールとセットアップ
3. **モジュールシステム** - コードの分割と再利用
4. **非同期処理** - コールバック、Promise、async/await
5. **ファイルシステム** - ファイルとディレクトリの操作
6. **HTTPサーバー** - 基本的なWebサーバーの作成
7. **Express.js入門** - Webフレームワークの基本
8. **ルーティング** - URLパスとHTTPメソッドの処理
9. **ミドルウェア** - リクエスト処理の拡張
10. **テンプレートエンジン** - 動的なHTML生成
11. **データベース連携** - MongoDB、MySQLとの連携
12. **実践プロジェクト** - 完全なWebアプリケーションの構築

### 学習のコツ

1. **段階的に学習**: 基礎から応用へと順序立てて学ぶ
2. **実践重視**: 各章の練習問題に取り組む
3. **プロジェクトベース**: 実際のアプリケーションを作りながら学ぶ
4. **エラーハンドリング**: エラーを恐れず、デバッグスキルを身につける
5. **コミュニティ活用**: npmパッケージやStack Overflowを活用

### 開発環境

#### 必要なツール
- **Node.js**: JavaScriptランタイム
- **npm**: パッケージマネージャー
- **VSCode/Cursor**: コードエディター
- **Postman**: APIテストツール
- **MongoDB Compass**: データベース管理ツール

#### 推奨拡張機能
- **Node.js Extension Pack**: Node.js開発サポート
- **ESLint**: コード品質チェック
- **Prettier**: コードフォーマット
- **Thunder Client**: APIテスト
