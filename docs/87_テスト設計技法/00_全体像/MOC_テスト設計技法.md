# MOC_テスト設計技法

テストケースを作る技法の入口。テスト全体の地図は [[MOC_テスト体系]]。分類は ISTQB / JSTQB FL シラバス v4.0 第4章（[[04_テスト分析と設計（テスト技法）]]）に合わせた。

| フォルダ | 技法の考え方 | 主な技法 |
|---|---|---|
| 10_ブラックボックス | 仕様から作る | 同値分割・境界値分析・デシジョンテーブル・状態遷移・ペアワイズ |
| 20_ホワイトボックス | コードの構造から作る | ステートメント（命令）カバレッジ・ブランチ（分岐）カバレッジ |
| 30_経験ベース | 経験と勘から作る | エラー推測・チェックリスト（探索的テストは [[04_探索的テストとリスクベーステスト]]） |
| 40_コラボレーションベース | 関係者と一緒に作る | ユーザーストーリー・受け入れ基準・ATDD / BDD |
