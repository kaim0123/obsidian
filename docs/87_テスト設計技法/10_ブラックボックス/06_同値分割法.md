# 同値分割法（Equivalence Partitioning）

**同値分割法**は、入力や条件を「同値クラス」にグループ化し、各クラスから**代表値1つ**を選んでテストする技法です。テストケース数を減らしつつ、効率的にカバーするために使います。

## 📖 同値分割法とは

**同値クラス（Equivalence Class）**とは、「同じように振る舞う」入力のグループです。同じクラス内の値は、システムが同じように処理すると仮定し、1つの代表値でテストすれば十分とみなします。

## 🎯 目的

- **テストケースの削減**: 全パターンをテストする代わりに、代表値でカバー
- **抜け漏れの防止**: 有効・無効などクラスを漏れなく洗い出す
- **効率的な設計**: 冗長なテストを避ける

## 📊 基本的な手順

```
1. 入力・条件を分析する
2. 有効同値クラスと無効同値クラスを特定する
3. 各クラスから代表値を1つ選ぶ
4. テストケースを作成する
```

## 💡 例1: 年齢入力（1〜120歳）

### 同値クラスの分割

| クラス | 範囲 | 代表値 | 期待結果 |
|--------|------|--------|----------|
| 有効 | 1〜120 | 50 | 正常に受け付け |
| 無効（下限外） | 0以下 | -1, 0 | エラー |
| 無効（上限外） | 121以上 | 121, 999 | エラー |

### テストケース

| No | 入力値 | 期待結果 |
|----|--------|----------|
| 1 | 50 | 正常 |
| 2 | 0 | エラー |
| 3 | -1 | エラー |
| 4 | 121 | エラー |
| 5 | 999 | エラー |

---

## 💡 例2: メールアドレス形式

### 同値クラス

| クラス | 例 | 代表値 |
|--------|-----|--------|
| 有効な形式 | user@example.com | user@example.com |
| @なし | userexample.com | userexample.com |
| ドメインなし | user@ | user@ |
| 空 | (空文字) | "" |
| スペース含む | user @example.com | user @example.com |

---

## 💡 例3: 割引率（会員ランク別）

| ランク | 割引率 | 同値クラス |
|--------|--------|------------|
| ブロンズ | 0% | ランク=ブロンズ |
| シルバー | 5% | ランク=シルバー |
| ゴールド | 10% | ランク=ゴールド |
| 無効 | - | ランク=不正値、未選択 |

各ランクが1つの同値クラス。各クラスから1つのテストケースを設計。

## ⚠️ 注意点

1. **境界は別途テスト**: 同値分割法は「クラス内の代表値」に焦点。境界付近は[[07_境界値分析|境界値分析]]と組み合わせる。
2. **無効クラスを忘れずに**: エラー入力、異常値のクラスも必ず定義する。
3. **複数入力の組み合わせ**: 入力が複数ある場合、クラスの組み合わせが膨らむ。[[09_ペアワイズ法|ペアワイズ法]]と併用を検討。

## 🔗 境界値分析との組み合わせ

同値分割法でクラスを決め、**境界値分析**で各クラスの境界（最小値、最大値、境界の前後）をテストすると、効果が高まります。

```
同値クラス: [1〜120]（有効）
境界値: 0, 1, 120, 121 をテスト
```
