# 境界値分析（Boundary Value Analysis）

**境界値分析**は、入力の**境界**や**境界の前後**にバグが集中しやすいという経験則に基づき、境界付近の値を重点的にテストする技法です。同値分割法とセットで使うことが多いです。

## 📖 境界値分析とは

プログラムでは、`<`, `<=`, `>`, `>=` などの比較で境界を扱うため、境界の取り違え（オフバイワンエラー）が発生しやすいです。境界値分析では、そのようなミスを検出するために境界付近をテストします。

## 🎯 目的

- **オフバイワンエラーの検出**: 境界の「1つ内側・外側」のバグを発見
- **境界ロジックの検証**: 比較演算子の誤りをチェック
- **同値分割の補完**: 同値クラスの境界を明確にテスト

## 📊 基本的な手順

```
1. 入力の有効範囲を特定する
2. 境界値（最小、最大、境界の直前・直後）を特定する
3. 各境界についてテストケースを作成する
```

## 🔢 境界値の選び方（範囲: 最小値〜最大値）

### 2値・3値の境界値

| 種類 | 値 | 説明 |
|------|-----|------|
| 最小値-1 | 境界の外側 | 無効（下限外） |
| 最小値 | 境界上 | 有効の端 |
| 最小値+1 | 境界の内側 | 有効 |
| 最大値-1 | 境界の内側 | 有効 |
| 最大値 | 境界上 | 有効の端 |
| 最大値+1 | 境界の外側 | 無効（上限外） |

### 例: 年齢 1〜120歳

| テスト値 | 期待結果 |
|----------|----------|
| 0 | エラー（最小値-1） |
| 1 | 正常（最小値） |
| 2 | 正常（最小値+1） |
| 119 | 正常（最大値-1） |
| 120 | 正常（最大値） |
| 121 | エラー（最大値+1） |

## 💡 例1: 文字数制限（1〜100文字）

| No | 入力 | 文字数 | 期待結果 |
|----|------|--------|----------|
| 1 | "" | 0 | エラー |
| 2 | "A" | 1 | 正常 |
| 3 | "AB" | 2 | 正常 |
| 4 | 99文字 | 99 | 正常 |
| 5 | 100文字 | 100 | 正常 |
| 6 | 101文字 | 101 | エラー |

---

## 💡 例2: 日付範囲（開始日 ≦ 終了日）

開始日・終了日の境界を考える：

- 開始日 = 終了日（同日）→ 有効
- 開始日 > 終了日 → エラー
- 開始日の前日、終了日の翌日なども検討

---

## 💡 例3: 割引適用（購入額3000円以上で10%OFF）

| 購入額 | 境界 | 期待結果 |
|--------|------|----------|
| 2999 | 境界-1 | 割引なし |
| 3000 | 境界 | 割引適用 |
| 3001 | 境界+1 | 割引適用 |

## 📐 同値分割法との組み合わせ

1. **同値分割法**で有効・無効のクラスを定義
2. **境界値分析**で各クラスの境界をテスト

```
有効クラス: [1, 120]
無効クラス: (-∞, 0], [121, ∞)

境界値: 0, 1, 120, 121
```

## ⚠️ 注意点

1. **開区間と閉区間**: 「以上」「超」「未満」の違いを仕様で確認する。
2. **浮動小数点**: 丸め誤差があるため、境界付近の値選定に注意。
3. **複数入力**: 複数の入力が境界を持つ場合、組み合わせが増える。必要に応じて[[09_ペアワイズ法|ペアワイズ法]]を検討。

## 🎯 境界値分析の種類

| 種類 | 内容 |
|------|------|
| **標準境界値** | 最小-1, 最小, 最小+1, 最大-1, 最大, 最大+1 |
| **頑健性テスト** | 有効範囲外も含めてテスト |
| ** Worst-Case** | 複数変数の境界を同時に変える（ケース数は増加） |
