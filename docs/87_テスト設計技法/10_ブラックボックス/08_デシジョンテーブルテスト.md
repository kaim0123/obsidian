# デシジョンテーブルテスト（Decision Table Testing）

**デシジョンテーブル**は、**条件**と**結果（アクション）**の組み合わせを表形式で整理し、網羅的にテストケースを設計する技法です。複数条件による分岐が複雑な場合に有効です。

## 📖 デシジョンテーブルとは

ビジネスルールが「条件Aかつ条件Bなら結果X」「条件Aかつ条件Bでなければ結果Y」のように複雑な場合、表で整理すると抜け漏れを防げます。

## 🎯 目的

- **複雑な条件分岐の網羅**: 条件と結果の組み合わせを漏れなく扱う
- **仕様の明確化**: 曖昧なルールを表で明確にする
- **テストケースの体系化**: 条件と期待結果の対応を一覧で管理

## 📊 デシジョンテーブルの構成

| 要素 | 説明 |
|------|------|
| **条件スタブ** | 判断に使う条件（Yes/No, 値など） |
| **条件エントリ** | 各条件の値（Y/N, 値） |
| **アクションスタブ** | 実行される処理・結果 |
| **アクションエントリ** | 各ルールで実行するか（X=実行） |

## 💡 例1: ローン審査（簡易版）

**ルール**: 
- 年収300万以上 **かつ** 勤続3年以上 → 承認
- 年収500万以上 **または** 保証人有り → 承認
- それ以外 → 否認

### 条件の整理

| 条件 | C1: 年収300万以上 | C2: 勤続3年以上 | C3: 年収500万以上 | C4: 保証人有り |
|------|-------------------|-----------------|-------------------|----------------|
| ルール1 | Y | Y | - | - | → 承認 |
| ルール2 | N | N | Y | - | → 承認 |
| ルール3 | N | N | N | Y | → 承認 |
| ルール4 | N | N | N | N | → 否認 |

### デシジョンテーブル

| 条件/アクション | R1 | R2 | R3 | R4 |
|-----------------|----|----|----|-----|
| C1: 年収≥300万 | Y | N | N | N |
| C2: 勤続≥3年 | Y | N | N | N |
| C3: 年収≥500万 | - | Y | N | N |
| C4: 保証人有 | - | - | Y | N |
| 承認 | X | X | X | |
| 否認 | | | | X |

---

## 💡 例2: 割引適用

**条件**:
- A: 会員である
- B: 購入額3000円以上
- C: クーポン持有

**ルール**:
- AかつB → 10%割引
- Cあり → さらに500円OFF（併用可）
- AかつBかつC → 10%割引 + 500円OFF

### デシジョンテーブル（簡略）

| | R1 | R2 | R3 | R4 | R5 | R6 | R7 | R8 |
|-|----|----|----|----|----|----|----|-----|
| A: 会員 | Y | Y | Y | Y | N | N | N | N |
| B: ≥3000円 | Y | Y | N | N | Y | Y | N | N |
| C: クーポン | Y | N | Y | N | Y | N | Y | N |
| 10%割引 | X | X | | | | | | |
| 500円OFF | X | | X | | X | | X | |
| 割引なし | | | | X | | X | | X |

---

## 💡 例3: ログインエラー表示

| 条件 | 空のID | 空のPW | 不正なID/PW | ロック中 |
|------|--------|--------|-------------|----------|
| メッセージ | "IDを入力" | "PWを入力" | "認証失敗" | "アカウントロック" |

※ 優先度を決めて、複数該当時の表示ルールを定義する必要あり。

## 📐 作成手順

```
1. 条件をすべて洗い出す
2. 各条件の取り得る値を決める（Y/N、または値）
3. 条件の組み合わせ（ルール）を列挙
4. 各ルールに対するアクション/期待結果を記入
5. 冗長なルールを統合（オプション）
6. 各ルールに対してテストケースを作成
```

## ⚠️ 組み合わせ爆発への対処

条件が増えるとルール数が 2^n で増加します。

| 条件数 | ルール数（全組み合わせ） |
|--------|--------------------------|
| 3 | 8 |
| 5 | 32 |
| 10 | 1024 |

**対処法**:
- **不可能な組み合わせを除外**: 現実にあり得ない組み合わせは削除
- **[[09_ペアワイズ法|ペアワイズ法]]との併用**: 全組み合わせではなく、2因子間の組み合わせをカバー
- **条件のグルーピング**: 関連する条件をまとめて扱う
