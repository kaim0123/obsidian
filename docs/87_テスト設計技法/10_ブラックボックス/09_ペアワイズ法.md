# ペアワイズ法（Pairwise Testing / オールペア法）

**ペアワイズ法**は、複数のパラメータ（因子）の組み合わせをテストする際、**2因子間のすべての組み合わせ**だけをカバーする技法です。組み合わせ爆発を抑えつつ、多くのバグを検出できる経験則に基づいています。

## 📖 ペアワイズ法とは

多くのバグは**2つの因子の組み合わせ**で発生することが多いという経験則があります。3つ以上の因子が同時に影響するバグは相対的に少ないため、2因子間の組み合わせ（ペア）を網羅すれば、テストケース数を大幅に減らしつつ、十分な効果が期待できます。

## 🎯 目的

- **組み合わせ爆発の抑制**: 全組み合わせではなく、ペアの組み合わせのみをテスト
- **効率的なカバレッジ**: 少ないテストケースで多くの組み合わせをカバー
- **リソースの最適化**: 時間・コストを抑えたテスト設計

## 📊 組み合わせ数の比較

### 例: 3因子 × 各3水準

| 因子 | 水準 |
|------|------|
| OS | Windows, Mac, Linux |
| ブラウザ | Chrome, Firefox, Safari |
| 解像度 | 1920×1080, 1366×768, 768×1024 |

- **全組み合わせ**: 3 × 3 × 3 = **27ケース**
- **ペアワイズ**: **9ケース**程度（ツールによる）

## 💡 例1: シンプルなペアワイズ

### 因子と水準

| 因子 | 水準 |
|------|------|
| A | A1, A2, A3 |
| B | B1, B2 |
| C | C1, C2, C3 |

### 全組み合わせ: 18ケース

### ペアワイズ表（例）

| No | A | B | C |
|----|---|---|---|
| 1 | A1 | B1 | C1 |
| 2 | A1 | B2 | C2 |
| 3 | A2 | B1 | C2 |
| 4 | A2 | B2 | C3 |
| 5 | A3 | B1 | C3 |
| 6 | A3 | B2 | C1 |
| 7 | A1 | B1 | C3 |
| 8 | A2 | B1 | C1 |
| 9 | A3 | B2 | C2 |

※ 実際にはツールで生成することが多い

---

## 💡 例2: フォーム入力のテスト

| 因子 | 水準 |
|------|------|
| 入力タイプ | 正常, 空, 不正形式 |
| 文字数 | 最小, 中間, 最大超 |
| 文字種 | 半角, 全角, 混在 |

ペアワイズで9〜15ケース程度に削減可能（全組み合わせは27）。

## 🛠️ ペアワイズ生成ツール

| ツール | 特徴 |
|--------|------|
| **PICT** | Microsoft製、コマンドライン、制約指定可能 |
| **allpairspy** | Pythonライブラリ |
| **pairwise.org** | オンラインツール |
| **Hexawise** | 商用、GUI |

### PICTの使用例

```
# pict_input.txt
OS: Windows, Mac, Linux
Browser: Chrome, Firefox, Safari
Resolution: 1920x1080, 1366x768

# 実行
pict pict_input.txt
```

## 📐 適用の手順

```
1. テスト対象の因子（パラメータ）を特定
2. 各因子の水準（取り得る値）を列挙
3. 不可能な組み合わせがあれば制約を定義
4. ペアワイズツールでテストケースを生成
5. 生成結果をレビューし、必要に応じて追加
```

## ⚠️ 注意点

1. **3因子以上のバグ**: まれに3つ以上の因子が関与するバグは見逃す可能性がある。
2. **制約の設定**: 「A1のときはB2のみ」など、不可能な組み合わせをツールに教える必要がある。
3. **重要な組み合わせ**: ビジネス上重要な組み合わせは、ペアワイズに加えて個別にテストする。

## 🔗 他の技法との関係

| 技法 | ペアワイズとの関係 |
|------|-------------------|
| デシジョンテーブル | 条件が多く、全組み合わせが膨大な場合にペアワイズで削減 |
| 同値分割法 | 各因子の水準を同値クラスで決め、ペアワイズで組み合わせ |
| 状態推移テスト | 状態とイベントの組み合わせにペアワイズを適用する場合も |
