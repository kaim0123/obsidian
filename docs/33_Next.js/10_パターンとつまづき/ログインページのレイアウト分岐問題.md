# ログインページのレイアウト分岐問題

## 1. はじめに

Next.jsで管理画面を実装する際、ログインページにも管理用のヘッダーやサイドバーが表示されてしまうことがあります。本章では、その原因と解決方法について学びます。

---

## 2. 問題の背景

多くの管理画面では、共通レイアウトとしてヘッダーやサイドバーを用意します。たとえば、`app/admin/layout.tsx` で以下のようにレイアウトを定義している場合、すべての管理画面ページで同じレイアウトが適用されます。

```tsx
// 例: レイアウトのイメージ
return (
  <>
    <AdminHeader />
    <EventSidebar />
    {children}
  </>
);
```

このままだと、ログインページ(`/admin/login`)にもヘッダーやサイドバーが表示されてしまい、ログイン画面が見づらくなってしまいます。

---

## 3. 原因の解説

- `usePathname()` などで現在のパスは取得しているものの、パスによる分岐（条件分岐）が実装されていない場合、すべてのページで同じレイアウトが適用されます。
- そのため、ログインページでも管理画面用のレイアウトがそのまま表示されてしまいます。

---

## 4. 解決方法

### 条件付きレンダリングの活用

ログインページではヘッダーやサイドバーを表示しないよう、パスによる条件分岐を追加しましょう。

#### 実装例
```tsx
if (pathname === "/admin/login") {
  return <>{children}</>;
}
return (
  <>
    <AdminHeader />
    <EventSidebar />
    {children}
  </>
);
```

このようにすることで、`/admin/login` の場合はヘッダーやサイドバーを描画せず、ログイン画面のみが表示されるようになります。

---

## 5. 学んだこと・まとめ

- 管理画面のレイアウトは、ページごとに適用範囲を制御することが大切です。
- ログインページなど、特定のページでは共通レイアウトを外すために条件付きレンダリングを活用しましょう。
- React/Next.jsの条件分岐やレイアウトの仕組みを理解することで、柔軟なUI設計が可能になります。
