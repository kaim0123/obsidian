# 並列ルートとインターセプト

少し高度なルーティング機能ですが、**ダッシュボード型 UI** や **「画面遷移せずモーダルだけ開く」**ような体験を作るときに強力です。
最初から完全理解する必要はないので、「こんな機能がある」と把握しておけば十分です。

---

## 1. 並列ルート（Parallel Routes）

**1 つの画面に、複数の独立した「ページ」を同時に表示**できる機能です。
たとえば、ダッシュボードで「左：分析」「右：チーム」を**それぞれ独立して読み込み・遷移**させたいときに使います。

### 書き方：`@` で始まるフォルダ（スロット）

```text
app/
└── dashboard/
    ├── layout.tsx
    ├── page.tsx              ← 通常の children
    ├── @analytics/
    │   ├── page.tsx          ← analytics スロット
    │   ├── loading.tsx
    │   └── error.tsx
    └── @team/
        ├── page.tsx          ← team スロット
        └── loading.tsx
```

`@analytics` や `@team` のような **`@` で始まるフォルダ**は「**スロット**」と呼ばれ、レイアウトの引数として渡されます。

### `layout.tsx` で受ける

```tsx
// app/dashboard/layout.tsx
export default function DashboardLayout({
  children,
  analytics,
  team,
}: {
  children: React.ReactNode;
  analytics: React.ReactNode;
  team: React.ReactNode;
}) {
  return (
    <div className="grid grid-cols-3 gap-4">
      <div>{children}</div>
      <div>{analytics}</div>
      <div>{team}</div>
    </div>
  );
}
```

### 何が嬉しい？

- **独立して loading/error を持てる**：team は読み込み完了、analytics はまだ読み込み中、というのが自然に表現できる
- **独立して遷移できる**：URL を変えなくても、片方だけ違うコンテンツに切り替えられる
- ダッシュボード型 UI、ストリーミング、A/B テストなどに有用

---

## 2. `default.tsx`（並列ルート用のフォールバック）

並列ルートを使う際、**スロットに対応する URL がないとき**にレンダリングされる「待避ページ」が必要です。

```tsx
// app/dashboard/@analytics/default.tsx
export default function Default() {
  return null; // 何も表示しない
}
```

これがないと、URL が一致しない場合に 404 などになる可能性があります。

## 3. インターセプトルート（Intercepting Routes）

**「同じ URL なのに、遷移経路によって違う UI を出す」**という、すごく特殊なことができます。
代表例：**Instagram のフィードで写真をタップするとモーダルで開くが、URL を直接叩くと専用ページで開く**、という挙動。

### 書き方：`(.)`、`(..)`、`(..)(..)`、`(...)`

| 記法 | 意味 |
|------|------|
| `(.)` | 同じ階層をインターセプト |
| `(..)` | 1 つ上の階層をインターセプト |
| `(..)(..)` | 2 つ上 |
| `(...)` | ルートからインターセプト |

### モーダルパターンの例

```text
app/
├── feed/
│   ├── page.tsx                          ← 一覧 "/feed"
│   └── @modal/                           ← 並列スロット
│       ├── default.tsx                   ← 通常時は null
│       └── (..)photo/[id]/
│           └── page.tsx                  ← /photo/:id をインターセプト
└── photo/
    └── [id]/
        └── page.tsx                      ← 直接 /photo/:id にアクセス時の本物
```

#### 動作

- `/feed` 一覧で写真をクリック → `<Link href="/photo/123">`
- 通常なら `/photo/123` のページに遷移するが、**`@modal` スロットがインターセプト**してモーダルとして表示
- URL は `/photo/123` に変わる（共有・リロード可能）
- ブラウザでリロード or URL 直接アクセス → 本物の `app/photo/[id]/page.tsx` が表示される

これにより、**「サクッと見たい」と「ガッツリ見たい」を 1 つの URL で両立**できます。

### layout 側での書き方

```tsx
// app/feed/layout.tsx
export default function FeedLayout({
  children,
  modal,
}: {
  children: React.ReactNode;
  modal: React.ReactNode;
}) {
  return (
    <>
      {children}
      {modal}
    </>
  );
}
```

---

## 4. 使い所のまとめ

| 機能 | 用途 |
|------|------|
| 並列ルート（`@slot`） | ダッシュボード、複数領域の独立ロード/遷移、A/B テスト、認証ゲートで切り替え |
| インターセプト（`(.)`、`(..)`） | モーダル、ライトボックス、スライドオーバー、パーマリンク両対応 |

---

## 5. 注意点（初心者向け）

- **必須機能ではありません**。普通のアプリは並列ルートなしで作れます
- これらを使う前に、まず `layout`/`page`/`loading`/`error` を完全に使いこなせるように
- インターセプトは状態管理（モーダル開閉）が複雑になりがち。まずは普通の遷移で実装してから、必要に応じて
- `default.tsx` の置き忘れによる **404 / Next が落ちる** がよくあるトラブル

---

## 6. つまずきポイント

### Q. 並列ルートを使ったらリロード時に Not Found

→ `default.tsx` が抜けています。各スロットに 1 つずつ置きましょう。

### Q. モーダルでリロードしたら一覧画面が消える

→ `(..)photo/[id]/page.tsx` 単体ではモーダルは出ません。リロード時は本物の `app/photo/[id]/page.tsx` が出るので、そちらも必要。

### Q. `@modal` の存在で URL が変わってしまう

→ `@` 始まりのフォルダは URL に出ません。出るのはインターセプト先のパス。

---

## まとめ

- **並列ルート（`@slot`）**：1 画面に複数のページを並べる、独立して読み込み・遷移
- **インターセプトルート（`(.)` など）**：「経路により違う UI、URL は同じ」を実現
- ダッシュボードや SNS のモーダルで活躍する**強力だが応用機能**
- まずは基本ができてから挑戦すれば OK
