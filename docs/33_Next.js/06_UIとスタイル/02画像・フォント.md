# 画像・フォント（next/image, next/font）

Next.js には**画像とフォントを自動最適化する仕組み**が組み込まれています。
普通の `<img>` や `<link rel="stylesheet">` を書くより、ずっと高速・安全になるので積極的に使いましょう。

---

## 1. `next/image`：画像の自動最適化

`<Image>` コンポーネントを使うだけで、

- 自動 **WebP / AVIF** 変換（容量が半分以下に）
- **画面サイズに合わせた解像度**を配信
- **lazy loading**（画面に入ったときだけ読み込み）
- レイアウトシフト（CLS）防止のため**サイズ確保**
- **CDN キャッシュ**

…が全部自動で行われます。

---

## 2. 基本の使い方

### A. ローカル画像（推奨）

```tsx
import Image from "next/image";
import logo from "@/public/logo.png";

export function Header() {
  return <Image src={logo} alt="ロゴ" />;
}
```

`@/public/` から import すると、画像のサイズ情報を**コンパイル時に取得**してくれて、`width`/`height` を書かなくて済みます。

### B. リモート画像

```tsx
<Image
  src="https://example.com/photo.jpg"
  alt="..."
  width={800}
  height={600}
/>
```

`width`/`height` は**必須**（CLS を防ぐため）。

### リモート画像の許可設定

外部ドメインを使うには `next.config.ts` に登録が必要：

```ts
const nextConfig = {
  images: {
    remotePatterns: [
      { protocol: "https", hostname: "example.com" },
      { protocol: "https", hostname: "*.cloudinary.com" },
    ],
  },
};
```

許可していないドメインは表示されません（セキュリティ）。

## 3. フィルやレスポンシブ

### `fill`：親要素いっぱいに広げる

```tsx
<div style={{ position: "relative", width: "100%", height: 300 }}>
  <Image src="/hero.jpg" alt="" fill style={{ objectFit: "cover" }} />
</div>
```

`fill` を使うときは**親に `position: relative`**を付けるのがコツ。

### `sizes`：画面幅ごとの表示サイズを伝える

```tsx
<Image
  src="/photo.jpg"
  alt=""
  fill
  sizes="(max-width: 768px) 100vw, (max-width: 1200px) 50vw, 33vw"
/>
```

これで Next.js はそれぞれの幅に合わせた最適サイズを配信します。

---

## 4. 優先度・プレースホルダ

### `priority`：above-the-fold（最初に見える領域）の画像

```tsx
<Image src="/hero.jpg" alt="" width={1200} height={600} priority />
```

`priority` を付けた画像は **lazy load されず、すぐ読み込まれます**。LCP（Largest Contentful Paint）改善に効果大。

### `placeholder`：読み込み中のぼかし表示

```tsx
import hero from "@/public/hero.jpg";

<Image src={hero} alt="" placeholder="blur" />
```

ローカル画像なら自動でぼかしプレビューが用意されます。リモートなら自分で用意：

```tsx
<Image
  src="https://..."
  width={800}
  height={600}
  placeholder="blur"
  blurDataURL="data:image/png;base64,..." // 小さな base64 画像
  alt=""
/>
```

## 5. `next/font`：フォントの自動最適化

Web フォント（Google Fonts など）を使うと、**ダウンロード待ちで文字がガクッと変わる（FOUT）**問題が発生しがち。
`next/font` はフォントをビルド時に**自前ホスト化**して、外部リクエストを無くしてくれます。

### Google Fonts を使う

```tsx
// app/layout.tsx
import { Inter, Noto_Sans_JP } from "next/font/google";

const inter = Inter({ subsets: ["latin"] });
const notoJP = Noto_Sans_JP({ subsets: ["latin"], weight: ["400", "700"] });

export default function RootLayout({ children }: any) {
  return (
    <html lang="ja" className={`${inter.className} ${notoJP.className}`}>
      <body>{children}</body>
    </html>
  );
}
```

これだけで、

- フォントが**プロジェクトに同梱**される（外部 CDN ではなく自分のサーバー）
- **FOUT がほぼ消える**
- **CLS（レイアウトシフト）も自動で抑制**

### CSS 変数として定義

```ts
const inter = Inter({
  subsets: ["latin"],
  variable: "--font-inter",
});
```

```tsx
<html className={inter.variable}>
```

```css
/* globals.css */
body { font-family: var(--font-inter), sans-serif; }
```

Tailwind と組み合わせるなら：

```ts
// tailwind.config.ts
theme: {
  extend: {
    fontFamily: { sans: ["var(--font-inter)"] },
  },
},
```

### ローカルフォント

```ts
import localFont from "next/font/local";

const myFont = localFont({
  src: "./fonts/MyFont.woff2",
  display: "swap",
});
```

## 6. 画像最適化のコツ

| やること | 効果 |
|---------|------|
| 全画像で `<Image>` を使う | 容量と表示速度に差 |
| LCP 画像に `priority` を付ける | 初回表示が速くなる |
| `fill` のときは `sizes` を必ず指定 | 過剰な高解像度を配信しない |
| ローカル画像は `import` する | サイズ自動 + ぼかしプレースホルダ |
| アイコンは SVG / Inline で | ラスタ画像より軽い |

### SVG はどう扱う？

`<Image src="/icon.svg">` でも動きますが、SVG は **直接 import して JSX として使う**こともできます。

```tsx
// next.config に SVG ローダ設定が必要
import Logo from "@/public/logo.svg";
<Logo width={40} height={40} />
```

| [Lucide](https://lucide.dev/) | シンプル、tree-shake 対応、人気 |

```tsx
import { Search, User, Settings } from "lucide-react";

<button className="flex items-center gap-2">
  <Search size={16} />
  検索
</button>
```

## 8. 動画・音声

`<video>` `<audio>` は**普通の HTML タグでそのまま OK**。最適化された専用コンポーネントはありません。
大きい動画はストリーミング配信サービス（Cloudflare Stream、Mux 等）を使うのが定石。

## 9. つまずきポイント

### Q. リモート画像が表示されない

→ `next.config.ts` の `remotePatterns` に追加していますか？

### Q. `<Image>` が崩れて表示される

→ `fill` を使っていて親に `position: relative` がない、または `width/height` が指定されていない可能性。

### Q. フォントの読み込みが遅い

→ `<head>` に書く方式（`<link rel="stylesheet">`）から **`next/font`** に切り替えると劇的に改善されます。

### Q. 画像が大きすぎてビルドに時間がかかる

→ 元画像を**最初から適切なサイズ**にしておく。Next.js が縮小はできますが、元データは小さい方が良い。

### Q. `priority` を付けすぎると怒られる

→ `priority` は LCP 候補（ファーストビューの最大画像）に**1〜2 個だけ**付けるのが正解。

### Q. SVG をインライン化したい

→ プラグインが必要：[`@svgr/webpack`](https://react-svgr.com/docs/next/) を導入。

---

## まとめ

- 画像は **`next/image`** を必ず使う（自動 WebP / lazy / CDN）
- 外部ドメインは **`next.config` に登録**が必須
- フォントは **`next/font`** で自動セルフホスト → FOUT/CLS 解消
- LCP 画像には **`priority`**、それ以外は lazy
- アイコンは Lucide / Heroicons など専用ライブラリが楽
