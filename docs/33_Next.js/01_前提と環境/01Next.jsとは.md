# Next.js とは

## ひとことで言うと

**Next.js（ネクストジェイエス）は、React で Web アプリを作るための「フルスタックフレームワーク」**です。

- **React**：ボタンやフォームなど、画面の部品（コンポーネント）を作るためのライブラリ
- **Next.js**：その React を使って、本番運用まで耐える「ちゃんとした Web サイト／Web アプリ」を作るための土台

React 単体だと「画面の見た目」しか作れませんが、Next.js を使うと **ルーティング（URL の管理）／サーバー側の処理／画像最適化／本番ビルド** など、Web サイトに必要な機能が最初から全部揃います。

開発元は **Vercel（バーセル）** という会社で、世界中の有名企業（TikTok、Netflix、Hulu など）でも使われています。

---

## なぜ「React だけ」ではダメなのか

React 単体で作ると、次のような問題に必ずぶつかります。

| やりたいこと | React 単体だと | Next.js だと |
|--------------|----------------|--------------|
| URL ごとに違うページを表示 | 自分でルーターを設定（react-router 等を入れる） | フォルダを作るだけで自動 |
| Google などの検索結果に出したい（SEO） | 工夫しないと中身が空っぽに見える | 標準でサーバーが HTML を生成 |
| API を呼んで初期データを表示 | クライアント側で取得 → 表示が一瞬遅れる | サーバー側で取得して渡せる |
| 画像を最適化したい | 自分で WebP 変換などを実装 | `<Image>` を置くだけ |
| 本番ビルド・デプロイ | webpack 設定などを書く必要 | `next build` 一発 |

つまり、**「React で実用的なサイトを作るときに必要な周辺機能」を全部用意してくれている**のが Next.js です。

## Next.js が得意なこと

### 1. ルーティング（URL とページの対応）

`app/` というフォルダの中に `page.tsx` を置くだけで、その階層がそのまま URL になります。

```text
app/
├── page.tsx                → "/"
├── about/page.tsx          → "/about"
└── blog/[slug]/page.tsx    → "/blog/任意の文字列"
```

### 2. サーバーサイドレンダリング（SSR）

ページにアクセスされたタイミングで、**サーバー側で HTML を作って返します**。
これにより、

- 検索エンジンが内容を読み取れる（SEO に強い）
- 最初の表示が速い
- ユーザーの環境（古いスマホなど）に依存しにくい

というメリットがあります。

### 3. 静的サイト生成（SSG）

ブログのように内容がほぼ変わらないページは、**ビルド時に HTML を作っておいて配信**できます。表示が爆速で、サーバー負荷も低くなります。

### 4. 画像・フォントの自動最適化

- `<Image>`：自動で WebP 変換、サイズ最適化、遅延読み込み
- `<Font>`：Google Fonts などをセルフホストして高速化

### 5. API（バックエンド）も同じプロジェクト内に書ける

「フロント用」と「バックエンド用」でプロジェクトを分けずに、**1 つのリポジトリで API もページも書ける**のが大きな魅力です。

## App Router と Pages Router

Next.js には**2 つのルーティング方式**が共存しています。

| 方式 | フォルダ | 登場時期 | 現状 |
|------|---------|---------|------|
| **App Router** | `app/` | 2023 年〜（Next.js 13） | **これから学ぶならこっち**（推奨） |
| Pages Router | `pages/` | 初期からの伝統的な方式 | 既存プロジェクトで現役。新規は不要 |

このノート群では、原則として **App Router** を扱います。Pages Router は `08_PagesRouter` フォルダで「読めるようになるため」だけ触れます。

---

## バージョン感覚（2026 年時点）

- **Next.js 14（2023 年末）**：App Router が安定版に
- **Next.js 15（2024 年末）**：React 19 対応、`use cache` など登場
- **Next.js 16（2025 年）**：`use cache` 安定、PPR（Partial Prerendering）強化

「最新は最新で覚える」より、まず **App Router の基本概念**を押さえるのが大事です。

## 学習のロードマップ（このノートでの進め方）

1. **環境を整える**（Node.js のインストール、エディタ）
2. **`create-next-app` で雛形を作る**
3. **App Router のフォルダ規約**を覚える（`page.tsx` / `layout.tsx`）
4. **Server Components と Client Components の違い**を理解する
5. **データ取得（`fetch`）とキャッシュ**を学ぶ
6. **Server Actions**（フォーム送信や DB 更新）
7. **デプロイ**して本番公開する

---

## まとめ

- Next.js は **React + 必要な機能全部入りのフレームワーク**
- 単独の React より、**実用的な Web サイトを作るのが圧倒的にラク**
- これから学ぶなら **App Router** 一択
- Vercel が開発しているので、デプロイも極めてスムーズ
