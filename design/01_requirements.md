## 1. 背景と目的

### 1.1 背景
- `docs/` に Obsidian で書いた学習ノート（Markdown 2,346件、フォルダ544個）がある。
- `public/` に、ノートをもとにした解説HTML（117ページ）がある。
- Astro 7 の雛形（`package.json`、`astro.config.mjs`）はあるが、`src/` が空でページが1つもない。そのため `npm run dev` を実行しても何も表示されない。

### 1.2 目的
Obsidian を開かなくても、**ブラウザでノートを読める・たどれる・探せる**ナレッジサイトにする。

### 1.3 成功の基準
1. `npm run dev` で起動し、`http://localhost:4321/` でトップページが表示される。
2. `docs/` のすべての `.md` がページとして表示される（ビルドエラー0件）。
3. ノート内の `[[ウィキリンク]]` をクリックすると、リンク先のノートへ移動できる。
4. `public/` の解説HTMLにサイト内から移動できる。

## 5. 非機能要件

| ID | 分類 | 要件 |
|---|---|---|
| N-01 | 動作環境 | Node.js 22.12 以上（Astro 7 の要件。現在 v22.12.0）、Windows 11 で開発できる |
| N-02 | 起動 | `npm run dev` だけで起動できる。追加のサーバーやDBは使わない |
| N-03 | ビルド | `npm run build` で静的サイト（`dist/`）を出力する。**ノートが1件おかしくてもビルド全体は止めない**（警告を出して続行） |
| N-04 | 性能 | 2,346ページの本番ビルドが5分以内に終わる。各ページは静的HTMLで、JS無しでも本文が読める |
| N-05 | 保守性 | ノートの追加・変更は `docs/` に `.md` を置くだけでサイトに反映される（コード変更不要） |
| N-06 | 互換性 | `docs/` 側のファイルを、サイトのために書き換えない（Obsidian での使い勝手を壊さない） |
| N-07 | 見た目 | **ダークモードのみ**（ライトモードは作らない）。UI は「A ワークベンチ」案（§9）に従う。スマートフォン幅（360px）でも読める |
| N-08 | 日本語 | フォルダ名・ファイル名の日本語をそのままURLに使える |

## 6. 制約・前提

- フレームワークは **Astro 7**（導入済み）を使う。
- ノートの原本は `docs/`、解説HTMLの原本は `public/`。この配置は変えない。
- frontmatter は書き方がそろっていない（有る/無い、`tags` が文字列/配列 など）ため、すべて任意項目として扱う。
- ファイル名（拡張子なし）が重複しているノートが14組ある（例：`00_目次.md`、`01-basics.md`）。
