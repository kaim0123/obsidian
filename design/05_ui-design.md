## 1. コンセプト

**「エディタのように開いて調べる」**

VS Code のような作業画面。左のツリーで「いまどこにいるか」を常に見せ、調べたいノートへ最短でたどり着ける。毎日使う道具として、装飾より情報の密度と速さを優先する。

### 1.1 選んだ理由（3案の比較から）
| 案 | 向いていること | 採用しなかった理由 |
|---|---|---|
| **A ワークベンチ** | 2,300件超を「場所」で把握し、行き来しながら調べる | — |
| B 一冊の本 | 章を最初から順に読む | 調べものには遠回り。フォルダの深さ（最大5階層）を「部・章・節」に当てはめにくい |
| C つながりの地図 | 検索とリンクでたどる | ウィキリンクの約6割が未作成で、関係図がまばらになる。検索機能が前提で、最初のリリースが重くなる |

### 1.2 デザインの原則
1. **現在地を見失わせない**：ツリー・パス表示・ステータスバーの3か所で場所を示す。
2. **本文が主役**：装飾は枠線と背景の濃淡だけ。グラデーション・影・アイコンの多用はしない。
3. **JS が無くても読める**：ツリーの開閉は `<details>`。JS は検索パレットなど後のフェーズの機能だけ。
4. **章ごとの解説HTMLは独立させる**：サイト側から包まず、配信時に「全体へ戻る」リンクだけ足す（§6）。

## 2. 画面レイアウト

### 2.1 骨組み（全ページ共通）

```text
┌──────────────────────────────────────────────────────────────┐
│ Header  [□ Knowledge]      [🔍 ノート・フォルダ・コマンドを検索  Ctrl K]   │ 高さ 56
├───────────────┬────────────────────────────────┬─────────────┤
│ FolderTree    │ (NoteTabs：Phase 4)              │ NoteAside   │
│ 240〜280px    │ PathBar                          │ 220〜260px  │
│               │ 本文（最大 72ch）                │ ノートのみ  │
├───────────────┴────────────────────────────────┴─────────────┤
│ StatusBar                                                     │ 高さ 22
└──────────────────────────────────────────────────────────────┘
```

| 領域 | 幅 | 出るページ |
|---|---|---|
| FolderTree | `flex: 1 1 240px; max-width: 280px` | 全ページ |
| 本文 | `flex: 999 1 560px; min-width: 0` | 全ページ |
| NoteAside | `flex: 1 1 220px; max-width: 260px` | ノートページのみ |

### 2.2 画面ごとの中身
| 画面 | 本文エリアの中身 | ステータスバー |
|---|---|---|
| S-01 トップ | ようこそ欄 → 解説ページ（HTML）のカード → 全フォルダの表（No・分類・フォルダ・ノート数） | `2,343 notes` `544 folders` `117 explainers` ／右端 `未作成リンク N` |
| S-02 フォルダ | フォルダ名 → サブフォルダ一覧 → ノート一覧（名前順・数値順） | `<フォルダ> › サブフォルダ N・ノート N` |
| S-03 ノート | PathBar → h1 → 本文 | `<フォルダ> › 5 / 6` `見出し 3` `リンク 4` ／右端 `Markdown` |

### 2.3 スマホ幅（〜767px）
- 3列は `flex-wrap` で縦に並ぶ：Header → **本文** → NoteAside → FolderTree → StatusBar。
  - 本文を先に読めるよう、DOM 順は「本文 → 右パネル → ツリー」にし、PC 幅では `order` で並べ替える。
- Header の検索欄は1行に収まらなければ2行目に回る。
- 表とコードブロックは枠の中で横スクロール。ページ全体は横スクロールさせない。

## 3. デザイントークン

### 3.1 色（ダーク1セットのみ）

```css
:root {
  color-scheme: dark;
  /* 面 */
  --bg: #14161b;          /* 本文の背景 */
  --surface: #1b1e25;     /* ヘッダー・表の見出し・カード */
  --surface-2: #181b21;   /* ツリー・タブ列 */
  --code-bg: #0f1115;
  --selected: #2a3240;    /* ツリーの現在地 */
  /* 線 */
  --border: #2b2f39;
  --border-soft: #262a33; /* 表の行区切り */
  /* 文字 */
  --text: #e4e6eb;        /* 本文 */
  --text-2: #a3a9b5;      /* 補足 */
  --text-3: #8d94a1;      /* ラベル・パス */
  --text-4: #6f7684;      /* 件数・未作成リンク（補助表示のみ） */
  /* 強調 */
  --accent: #7cb7ec;      /* リンク */
  --accent-hover: #a8d0f5;
  --status-bg: #2a5b86;
  --status-text: #e8f1fa;
  /* Callout */
  --good: #7fd3a2;   --good-soft: #1a2620;   --good-border: #2c4a3a;
  --warn: #e8a34a;   --warn-soft: #2a2216;   --warn-border: #4a3a22;
  --bad: #ef8a8a;    --bad-soft: #2c1c1e;    --bad-border: #4a2c2f;
  --info: #7cb7ec;   --info-soft: #18222e;   --info-border: #2a3e54;
  --purple: #c9a0f0; --purple-soft: #241d30; --purple-border: #3e3152;
}
```

- ライトモード・切替ボタンは作らない。`prefers-color-scheme` も見ない。
- `--text-4` は背景とのコントラストが 4.5:1 未満のため、**読ませる文章には使わない**（件数・未作成リンクの補助表示だけ）。

### 3.2 書体
| 用途 | 書体 | 太さ |
|---|---|---|
| 本文・見出し・UI | IBM Plex Sans JP | 400 / 500 / 700 |
| コード・パス・件数・ステータスバー・キー表示 | JetBrains Mono | 400 / 600 |

フォールバック：`"Yu Gothic UI", "Meiryo", sans-serif` ／ `"Consolas", monospace`。Google Fonts から読み込む。

### 3.3 文字サイズ・行間
| 要素 | サイズ | 太さ | 行間 | その他 |
|---|---|---|---|---|
| 本文 | 14px | 400 | 1.8 | 最大幅 72ch |
| h1 | 28px | 700 | 1.4 | 下余白 12px |
| h2 | 20px | 700 | 1.4 | 下線 `--border`、上余白 32px |
| h3 | 16px | 700 | 1.5 | 上余白 24px |
| ラベル（パネル見出し） | 11px | 500 | — | `letter-spacing: .08em`、`--text-3` |
| コード | 12.5px | 400 | 1.7 | JetBrains Mono |
| ステータスバー | 11px | 400 | — | JetBrains Mono |

### 3.4 余白・角丸
- 余白の基本単位は 4px（4 / 8 / 12 / 16 / 20 / 24 / 32 / 40）。
- 本文エリアの内側余白：上 20px、左右 40px（スマホ 16px）。
- 角丸：入力欄・ボタン・表の枠・コード・Callout は 6px、カードは 8px。

## 4. コンポーネント

### 4.1 Header
- 左：ロゴ（ファイル形のアイコン＋「Knowledge」、`/` へのリンク）。
- 中央：検索欄（最大幅 560px、高さ 36px、`--surface` 地に枠線）。右端に `Ctrl K` のキー表示。
  - Phase 1〜2：見た目のみ。
  - Phase 3：クリックか `Ctrl K` で検索パレットを開く（§4.7）。
- テーマ切替ボタンは置かない（ダークのみ）。

### 4.2 FolderTree（エクスプローラー）
- 見出し「エクスプローラー」（ラベル書式）。
- 1行の中身：`›` アイコン ／ 番号（JetBrains Mono・`--text-3`）／ 表示名（番号を除いた名前）／ 右端に件数（`--text-4`）。
- フォルダは `<details>`。現在地の祖先だけ `open`、`›` は開くと下向き。
- 現在のノート：背景 `--selected`・文字 `#fff`。`aria-current="page"` を付ける。
- 行の高さは 28px 以上。ホバーで背景 `--surface`。
- 出力するのは「トップレベルのフォルダ名」と「現在地の祖先フォルダの中身」だけ（全件は出さない）。

### 4.3 PathBar
- `docs / 10_基礎概念 / 05_シード（乱数シードとDBシード）.md`
- JetBrains Mono 12px・`--text-3`。フォルダ部分はフォルダページへのリンク。

### 4.4 NoteAside（右パネル）
上から3つの欄。見出しはラベル書式。
| 欄 | 中身 | 空のとき |
|---|---|---|
| アウトライン | h2 は左寄せ、h3 は 14px 字下げ。クリックでその見出しへ | 欄ごと出さない |
| リンク先 N | 出ているウィキリンク（重複を除く）。未作成は §4.6 の見た目 | 欄ごと出さない |
| プロパティ | `path`・`tags`（JetBrains Mono 12px、2列の定義リスト） | `tags` は「—」 |

Phase 3 で「このノートへのリンク N」（バックリンク）を2番目に足す。

### 4.5 StatusBar
- 背景 `--status-bg`・文字 `--status-text`・高さ 22px・JetBrains Mono 11px。
- 項目は左から並べ、`margin-left: auto` の項目だけ右端に寄せる。中身は §2.2。

### 4.6 本文の要素
| 要素 | 見た目 |
|---|---|
| リンク（ウィキリンク含む） | `--accent`、下線なし、ホバーで `--accent-hover` |
| 未作成のウィキリンク | `--text-4`、点線の下線、カーソル `help`、`title="未作成のノート"`、クリック不可 |
| 表 | 横スクロールの枠（枠線 `--border`・角丸 6px）。見出し行 `--surface`、行区切り `--border-soft`、セル余白 8px 12px |
| コードブロック | 背景 `--code-bg`・枠線 `--border`・角丸 6px・余白 14px 16px。色付けは Shiki `github-dark-default` |
| インラインコード | JetBrains Mono、背景 `--surface`、余白 1px 5px、角丸 4px |
| Callout | 下表 |

**Callout の種類と色**

| type（別名） | 表示名 | 文字・枠 | 背景 |
|---|---|---|---|
| note / info | メモ / 情報 | `--info` | `--info-soft` |
| abstract（summary, tldr） | 要約 | `--purple` | `--purple-soft` |
| tip（hint, important） | ヒント | `--good` | `--good-soft` |
| warning（caution, attention） | 注意 | `--warn` | `--warn-soft` |
| danger（error） | 危険 | `--bad` | `--bad-soft` |
| example | 例 | `--purple` | `--purple-soft` |

- 枠線 1px（`--*-border`）・角丸 6px。タイトル行は文字色を種類の色、太さ 500。
- `> [!tip]-` は閉じた `<details>`、`+` は開いた `<details>`。タイトル行にカーソル `pointer`。

### 4.7 後のフェーズの部品
| 部品 | Phase | 見た目の要点 |
|---|---|---|
| CommandPalette（`Ctrl K`） | 3 | 画面上部中央に幅 560px のパネル。入力欄＋候補リスト（ノート名・パス）。↑↓で選択、Enter で開く、Esc で閉じる |
| NoteTabs | 4 | 本文の上のタブ列（`--surface-2`）。選択中は背景 `--bg`・上辺 2px の `--accent`。× で閉じる |
| 最近開いたノート | 4 | トップのカード。ノート名と「2分前」などの相対時刻（JetBrains Mono・`--text-4`） |

## 5. 操作・アクセシビリティ

- クリックできるものは `<a href>` か `<button>` にする（`div` に `onclick` は付けない）。
- アイコンだけのボタンには `aria-label`、飾りの SVG には `aria-hidden="true"`。
- タップ・クリックの的は高さ 28px 以上（ツリー行）、ボタンは 36px 以上。
- フォーカスが見えること：`:focus-visible` に `outline: 2px solid var(--accent); outline-offset: 2px`。
- 本文 `--text` と補足 `--text-2` は背景に対して 4.5:1 以上。
- キーボード操作（Phase 3 以降）：`Ctrl K` / `⌘ K` でパレット、`/` でも開く。入力欄にフォーカスがあるときは奪わない。

## 6. 解説HTMLとの関係

- 解説HTML（`public/<章>/*.html`）は**独自の見た目のまま**表示する（ライト基調）。サイトの枠では包まない。
- サイト経由で開いたときだけ、パンくずの先頭に「Knowledge ›」を足して全体へ戻れるようにする（基本設計 §7.1）。
- サイトのトップからは「解説ページ（HTML）」欄で各章へ入る。
- そのため、ノート（ダーク）と解説HTML（ライト）を行き来すると明るさが変わる。これは「章ごとに独立させる」方針を優先した、意図したものとする。
